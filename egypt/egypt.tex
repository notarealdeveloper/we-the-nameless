\section*{NewGardiner: a small LuaLaTeX how-to}

Write Unicode hieroglyphs inside \verb|\egypt{...}|.  The helpers below are
ordinary TeX commands, so they nest: first make a cluster, then scale, raise,
mirror, rotate, or overlap it.  Their arguments remain normal, searchable
Unicode signs.

\demo{\string\egypt\{\egypt{𓂀𓆣𓇳}\}}{𓂀𓆣𓇳}
\demo{\string\egypt\{\string\egH\{\egypt{𓂀}\}\{\egypt{𓆣}\}\}}{\egH{𓂀}{𓆣}}
\demo{\string\egypt\{\string\egV\{\egypt{𓂀}\}\{\egypt{𓆣}\}\}}{\egV{𓂀}{𓆣}}
\demo{\string\egypt\{\string\egV\{\egypt{𓂀}\}\{\string\egH\{\egypt{𓆣}\}\{\egypt{𓇳}\}\}\}}{\egV{𓂀}{\egH{𓆣}{𓇳}}}
\demo{\string\egypt\{\string\egScale\{0.7\}\{\egypt{𓂀𓆣}\}\}}{\egScale{0.7}{𓂀𓆣}}
\demo{\string\egypt\{\string\egWide\{0.65\}\{\egypt{𓂀𓆣}\}\}}{\egWide{0.65}{𓂀𓆣}}
\demo{\string\egypt\{\string\egTall\{1.35\}\{\egypt{𓂀}\}\}}{\egTall{1.35}{𓂀}}
\demo{\string\egypt\{\egypt{𓂀}\string\egRaise\{0.3em\}\{\string\egScale\{0.55\}\{\egypt{𓇳}\}\}\}}{𓂀\egRaise{0.3em}{\egScale{0.55}{𓇳}}}

% The giant forearm/hand.
%
% After mirroring, the cut end of the forearm is on the left
% and the fingers point right.  TikZ will rotate the whole thing
% dynamically toward whichever head it is supposed to reach.
\newcommand{\JacobBlessingHand}{%
	\egypt{
		\egWide{2.8}{
			\egMirror{𓂝}
		}
	}%
}

% ------------------------------------------------------------
% Shared placement of all four people.
%
% Using one macro guarantees that the three diagrams differ ONLY
% in what Jacob's hands are doing.
% ------------------------------------------------------------

\newcommand{\JacobFamilyPeople}{%

	% --------------------------------------------------------
	% Jacob
	% --------------------------------------------------------

	\node[
		egypt person
	] (jacob) at
		(.30\linewidth,5em)
	{
		\egypt{
			\egScale{1.25}{
				\egMirror{𓀗}
			}
		}
	};

	\node[
		anchor=south,
		inner sep=0pt,
		yshift=.10em
	] at (jacob.north)
	{
		Jacob
	};

	% --------------------------------------------------------
	% Ephraim
	% --------------------------------------------------------

	\node[
		egypt person
	] (ephraim) at
		(.50\linewidth,7.15em)
	{
		\egypt{
			\egScale{.90}{𓀔}
		}
	};

	\node[
		anchor=south,
		inner sep=0pt,
		yshift=.22em
	] at (ephraim.north)
	{
		Ephraim
	};

	% --------------------------------------------------------
	% Manasseh
	% --------------------------------------------------------

	\node[
		egypt person
	] (manasseh) at
		(.50\linewidth,2.85em)
	{
		\egypt{
			\egScale{1.20}{𓀕}
		}
	};

	\node[
		anchor=north,
		inner sep=0pt,
		yshift=-.22
	] at (manasseh.south)
	{
		Manasseh
	};

	% --------------------------------------------------------
	% Joseph
	% --------------------------------------------------------

	\node[
		egypt person
	] (joseph) at
		(.68\linewidth,5em)
	{
		\egypt{
			\egScale{1.15}{𓀠}
		}
	};

	\node[
		anchor=south,
		inner sep=0pt,
		yshift=.10em
	] at (joseph.north)
	{
		Joseph
	};

	% --------------------------------------------------------
	% Anatomical anchor points for Jacob's hands
	% --------------------------------------------------------
	%
	% DO NOT anchor these to jacob.east.
	%
	% The staff is part of the 𓀗 glyph, so jacob.east is basically
	% "the far end of Jacob's stick", not Jacob's torso.
	%
	% Instead, take a point 46% of the way across the glyph itself.
	% On the mirrored 𓀗 this falls back on Jacob's upper body.
	%

	\coordinate (jacob-hand-axis) at
		($(jacob.west)!0.33!(jacob.east)$);

	% Two slightly separated origins on Jacob's upper body.
	\coordinate (jacob-left-root) at
		([yshift=.43em]jacob-hand-axis);

	\coordinate (jacob-right-root) at
		([yshift=.04em]jacob-hand-axis);

	% --------------------------------------------------------
	% Actual blessing targets: the boys' HEADS
	% --------------------------------------------------------
	%
	% Slightly left and down from node.north puts the target
	% approximately on the left side of the head, where a hand
	% arriving from Jacob should meet it.
	%

	\coordinate (ephraim-head) at
		([xshift=-.18em,yshift=-.28em]ephraim.north);

	\coordinate (manasseh-head) at
		([xshift=-.18em,yshift=-.28em]manasseh.north);

	% Handy debugging points if you ever want to inspect them:

	% \fill (jacob-left-root)  circle (.7pt);
	% \fill (jacob-right-root) circle (.7pt);
	% \fill (ephraim-head)     circle (.7pt);
	% \fill (manasseh-head)    circle (.7pt);
}

\subsection*{Manual Jacob and grandsons --- regular hands}

\begin{center}

\begin{tikzpicture}

	\path[use as bounding box]
		(0,0)
		rectangle
		(\linewidth,10em);

	\JacobFamilyPeople

	% --------------------------------------------------------
	% Hands
	% --------------------------------------------------------
	%
	% Draw them on the background layer.  Their roots therefore
	% disappear underneath Jacob's body instead of looking like
	% detached floating arms.
	%

	\begin{scope}[on background layer]

		% Left hand -> Ephraim
		%
		% pos=0      puts the hand at the START of the path.
		% anchor=west glues the LEFT/CUT end of the forearm
		%             precisely to jacob-left-root.
		% sloped      automatically aims it toward Ephraim's head.
		\path
			(jacob-left-root)
			--
			(ephraim-head)
			node[
				pos=0,
				anchor=west,
				inner sep=0pt,
				sloped
			]
			{
				\JacobBlessingHand
			};

		% Right hand -> Manasseh
		\path
			(jacob-right-root)
			--
			(manasseh-head)
			node[
				pos=0,
				anchor=west,
				inner sep=0pt,
				sloped
			]
			{
				\JacobBlessingHand
			};

	\end{scope}

\end{tikzpicture}

\end{center}



\subsection*{Manual Jacob and grandsons --- crossed hands}

\begin{center}

\begin{tikzpicture}

	\path[use as bounding box]
		(0,0)
		rectangle
		(\linewidth,10em);

	\JacobFamilyPeople

	% --------------------------------------------------------
	% Crossed hands
	% --------------------------------------------------------
	%
	% Put the CENTER of both giant forearm glyphs at the same
	% dynamically measured point. This forces a clean, visible X
	% through approximately the midpoint of the visible arms.
	%
	% The crossing point is measured from Jacob's anatomical hand
	% axis toward the midpoint between the two boys' heads. Moving
	% any of the people therefore moves the crossing automatically.
	%

	\coordinate (grandsons-mid) at
		($(ephraim-head)!0.5!(manasseh-head)$);

	\coordinate (hands-cross) at
		($(jacob-hand-axis)!0.58!(grandsons-mid)$);

	\begin{scope}[on background layer]

		% Arm ending at Ephraim.  Centering the glyph on hands-cross
		% makes its forearm extend back down-left toward Jacob.
		\path
			(hands-cross)
			--
			(ephraim-head)
			node[
				pos=0,
				anchor=center,
				inner sep=0pt,
				sloped
			]
			{
				\JacobBlessingHand
			};

		% Arm ending at Manasseh.  Same center, opposite slope, so
		% the two forearms visibly cross at their midpoints.
		\path
			(hands-cross)
			--
			(manasseh-head)
			node[
				pos=0,
				anchor=center,
				inner sep=0pt,
				sloped
			]
			{
				\JacobBlessingHand
			};

	\end{scope}

\end{tikzpicture}

\end{center}

\subsection*{Unicode controls and HieroJax}

Unicode also defines joiners, segment markers, insertions, enclosures,
mirroring, rotation selectors, blanks, and damage markers.  For example,
U+13430 is the vertical joiner (\egypt{𓐰}) and U+13431 is the horizontal
joiner (\egypt{𓐱}).  NewGardiner contains glyphs used by implementations of
that standard, but the plain TTF is a glyph source rather than a complete
layout engine: LuaLaTeX does not turn those controls into quadrats by itself.
Use the TeX helpers above for predictable PDF layout.  Use the
\href{https://nederhof.github.io/hierojax/}{HieroJax editor and renderer} when
you need the complete Unicode composition system; its
\href{https://nederhof.github.io/hierojax/syntax.html}{syntax table} is the
compact reference.  Font coverage and releases are documented in the
\href{https://github.com/nederhof/newgardiner}{NewGardiner repository}.
