\Chapter{27}

\Verse{1}
{
	\hP{וְעָשִׂיתָ אֶת הַמִּזְבֵּחַ עֲצֵי שִׁטִּים חָמֵשׁ אַמּוֹת אֹרֶךְ וְחָמֵשׁ אַמּוֹת רֹחַב רָבוּעַ יִהְיֶה הַמִּזְבֵּחַ וְשָׁלֹשׁ אַמּוֹת קֹמָתוֹ׃}
}
{
	\eP{
		27 “And you shall make the altar of acacia wood. Five
		cubits long and five cubits wide, the altar shall be
		square—and its height three cubits.
	}
}
{
%	\footnote{
%		And you shall make. The quantity of detail in these chapters is an
%		indication that these are authentic descriptions of the Tabernacle and
%		its accouterments. What motive would there be to make all of this up?
%		The dominant view in critical biblical scholarship for over a hundred
%		years has been that the Tabernacle is a fiction. The character of the
%		text, however, argues against that view as much as the content does.
%	}
}

\Verse{2}
{
	\hP{וְעָשִׂיתָ קַרְנֹתָיו עַל אַרְבַּע פִּנֹּתָיו מִמֶּנּוּ תִּהְיֶיןָ קַרְנֹתָיו וְצִפִּיתָ אֹתוֹ נְחֹשֶׁת׃}
}
{
	\eP{
		And you shall make its horns on its four corners. Its
		horns shall be part of it. And you shall plate it with
		bronze.
	}
}
{
}

\Verse{3}
{
	\hP{וְעָשִׂיתָ סִּירֹתָיו לְדַשְּׁנוֹ וְיָעָיו וּמִזְרְקֹתָיו וּמִזְלְגֹתָיו וּמַחְתֹּתָיו לְכל כֵּלָיו תַּעֲשֶׂה נְחֹשֶׁת׃}
}
{
	\eP{
		And you shall make its pots to remove ashes from it, and
		its shovels and its basins and its forks and its
		fire-holders. You shall make all of its equipment bronze.
	}
}
{
}

\Verse{4}
{
	\hP{וְעָשִׂיתָ לּוֹ מִכְבָּר מַעֲשֵׂה רֶשֶׁת נְחֹשֶׁת וְעָשִׂיתָ עַל הָרֶשֶׁת אַרְבַּע טַבְּעֹת נְחֹשֶׁת עַל אַרְבַּע קְצוֹתָיו׃}
}
{
	\eP{
		And you shall make a grate for it, a network of bronze,
		and on the net you shall make four rings of bronze on its
		four ends.
	}
}
{
}

\Verse{5}
{
	\hP{וְנָתַתָּה אֹתָהּ תַּחַת כַּרְכֹּב הַמִּזְבֵּחַ מִלְּמָטָּה וְהָיְתָה הָרֶשֶׁת עַד חֲצִי הַמִּזְבֵּחַ׃}
}
{
	\eP{
		And you shall place it under the altar’s ledge below so
		that the net will be up to the middle of the altar.
	}
}
{
}

\Verse{6}
{
	\hP{וְעָשִׂיתָ בַדִּים לַמִּזְבֵּחַ בַּדֵּי עֲצֵי שִׁטִּים וְצִפִּיתָ אֹתָם נְחֹשֶׁת׃}
}
{
	\eP{
		And you shall make poles for the altar, poles of acacia
		wood, and plate them with bronze.
	}
}
{
}

\Verse{7}
{
	\hP{וְהוּבָא אֶת בַּדָּיו בַּטַּבָּעֹת וְהָיוּ הַבַּדִּים עַל שְׁתֵּי צַלְעֹת הַמִּזְבֵּחַ בִּשְׂאֵת אֹתוֹ׃}
}
{
	\eP{
		And its poles shall be brought through rings so that the
		poles shall be on the altar’s two sides when carrying it.
	}
}
{
}

\Verse{8}
{
	\hP{נְבוּב לֻחֹת תַּעֲשֶׂה אֹתוֹ כַּאֲשֶׁר הֶרְאָה אֹתְךָ בָּהָר כֵּן יַעֲשׂוּ׃}
}
{
	\eP{
		You shall make it hollow of boards, as it was shown to you
		in the mountain. They shall do it so.
	}
}
{
}

\Verse{9}
{
	\hP{וְעָשִׂיתָ אֵת חֲצַר הַמִּשְׁכָּן לִפְאַת נֶגֶב תֵּימָנָה קְלָעִים לֶחָצֵר שֵׁשׁ משְׁזָר מֵאָה בָאַמָּה אֹרֶךְ לַפֵּאָה הָאֶחָת׃}
}
{
	\eP{
		“And you shall make the Tabernacle’s courtyard: for the
		south side—to the south, hangings for the courtyard of
		woven linen, one side having a hundred in cubits,
	}
}
{
}

\Verse{10}
{
	\hP{וְעַמֻּדָיו עֶשְׂרִים וְאַדְנֵיהֶם עֶשְׂרִים נְחֹשֶׁת וָוֵי הָעַמֻּדִים וַחֲשֻׁקֵיהֶם כָּסֶף׃}
}
{
	\eP{
		and its columns twenty, and their bases twenty of bronze,
		and the columns’ hooks and their rods of silver.
	}
}
{
}

\Verse{11}
{
	\hP{וְכֵן לִפְאַת צָפוֹן בָּאֹרֶךְ קְלָעִים מֵאָה אֹרֶךְ וְעַמֻּדָו עֶשְׂרִים וְאַדְנֵיהֶם עֶשְׂרִים נְחֹשֶׁת וָוֵי הָעַמֻּדִים וַחֲשֻׁקֵיהֶם כָּסֶף׃}
}
{
	\eP{
		And so for the north side: in length, hangings of a
		hundred long, and its columns twenty, and their bases
		twenty of bronze, and the columns’ hooks and their bands
		of silver.
	}
}
{
}

\Verse{12}
{
	\hP{וְרֹחַב הֶחָצֵר לִפְאַת יָם קְלָעִים חֲמִשִּׁים אַמָּה עַמֻּדֵיהֶם עֲשָׂרָה וְאַדְנֵיהֶם עֲשָׂרָה׃}
}
{
	\eP{
		And the courtyard’s width for the west side: hangings of
		fifty cubits, their columns ten and their bases ten.
	}
}
{
}

\Verse{13}
{
	\hP{וְרֹחַב הֶחָצֵר לִפְאַת קֵדְמָה מִזְרָחָה חֲמִשִּׁים אַמָּה׃}
}
{
	\eP{
		And the courtyard’s width for the east side—to the
		east—fifty cubits.
	}
}
{
}

\Verse{14}
{
	\hP{וַחֲמֵשׁ עֶשְׂרֵה אַמָּה קְלָעִים לַכָּתֵף עַמֻּדֵיהֶם שְׁלֹשָׁה וְאַדְנֵיהֶם שְׁלֹשָׁה׃}
}
{
	\eP{
		And the panel shall have fifteen cubits of hangings, their
		columns three and their bases three;
	}
}
{
}

\Verse{15}
{
	\hP{וְלַכָּתֵף הַשֵּׁנִית חֲמֵשׁ עֶשְׂרֵה קְלָעִים עַמֻּדֵיהֶם שְׁלֹשָׁה וְאַדְנֵיהֶם שְׁלֹשָׁה׃}
}
{
	\eP{
		and the second panel shall have fifteen of hangings, their
		columns three and their bases three.
	}
}
{
}

\Verse{16}
{
	\hP{וּלְשַׁעַר הֶחָצֵר מָסָךְ עֶשְׂרִים אַמָּה תְּכֵלֶת וְאַרְגָּמָן וְתוֹלַעַת שָׁנִי וְשֵׁשׁ משְׁזָר מַעֲשֵׂה רֹקֵם עַמֻּדֵיהֶם אַרְבָּעָה וְאַדְנֵיהֶם אַרְבָּעָה׃}
}
{
	\eP{
		And the courtyard’s gate shall have a cover of twenty
		cubits: blue and purple and scarlet and woven linen,
		embroiderer’s work, their columns four and their bases
		four.
	}
}
{
}

\Verse{17}
{
	\hP{כּל עַמּוּדֵי הֶחָצֵר סָבִיב מְחֻשָּׁקִים כֶּסֶף וָוֵיהֶם כָּסֶף וְאַדְנֵיהֶם נְחֹשֶׁת׃}
}
{
	\eP{
		All of the courtyard’s columns all around shall be banded
		with silver, their hooks of silver and their bases bronze.
	}
}
{
}

\Verse{18}
{
	\hP{אֹרֶךְ הֶחָצֵר מֵאָה בָאַמָּה וְרֹחַב חֲמִשִּׁים בַּחֲמִשִּׁים וְקֹמָה חָמֵשׁ אַמּוֹת שֵׁשׁ משְׁזָר וְאַדְנֵיהֶם נְחֹשֶׁת׃}
}
{
	\eP{
		The courtyard’s length a hundred in cubits, and width
		consistently fifty, and height five cubits of woven linen,
		and their bases of bronze.
	}
}
{
}

\Verse{19}
{
	\hP{לְכֹל כְּלֵי הַמִּשְׁכָּן בְּכֹל עֲבֹדָתוֹ וְכל יְתֵדֹתָיו וְכל יִתְדֹת הֶחָצֵר נְחֹשֶׁת׃}
}
{
	\eP{
		For all of the Tabernacle’s equipment in all of the
		service of it, and all of its pegs and all of the
		courtyard’s pegs: bronze.
	}
}
{
}

\Verse{20}
{
	\hP{וְאַתָּה תְּצַוֶּה אֶת בְּנֵי יִשְׂרָאֵל וְיִקְחוּ אֵלֶיךָ שֶׁמֶן זַיִת זָךְ כָּתִית לַמָּאוֹר לְהַעֲלֹת נֵר תָּמִיד׃}
}
{
	\eP{
		COMMAND “And you: you shall command the children of Israel
		that they shall bring clear pressed olive oil to you for
		the light, to keep up a lamp always.
	}
}
{
}

\Verse{21}
{
	\hP{בְּאֹהֶל מוֹעֵד מִחוּץ לַפָּרֹכֶת אֲשֶׁר עַל הָעֵדֻת יַעֲרֹךְ אֹתוֹ אַהֲרֹן וּבָנָיו מֵעֶרֶב עַד בֹּקֶר לִפְנֵי יְהֹוָה חֻקַּת עוֹלָם לְדֹרֹתָם מֵאֵת בְּנֵי יִשְׂרָאֵל׃}
}
{
	\eP{
		In the Tent of Meeting, outside the pavilion that is over
		the Testimony, Aaron and his sons shall arrange it from
		evening until morning in front of YHWH, an eternal law
		through their generations from the children of Israel.
	}
}
