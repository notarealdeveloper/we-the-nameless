
Yep—both are much more Hebrew-looking:

String	Possible reading	Meaning

תחש	תַּחַשׁ taḥaš	taḥash — the mysterious animal/material used for the Tabernacle coverings; traditionally “badger,” “porpoise,” etc., but actual identification is unknown. Also Tahash, a personal name in Gen 22:24.
תחס	תָּחֹס / תַּחֹס taḥos	From חוס “to pity, spare, have compassion”: roughly “you will pity/spare” (2ms), depending on vocalization/context.


So consonantally:

תחש → taḥash = mysterious taḥash hide/animal
תחס → taḥos = “you will spare / have pity”

And the שׁ/ס distinction is useful for wordplay because both can give you an /s/-ish endpoint depending on historical stage/dialect, although Biblical Hebrew תחש conventionally has /ʃ/: taḥaš.
