# Default translation

01-genesis to 05-deuteronomy uses the Friedman translation,
since it's really the only "correct" translation in existence.
Honestly the damn thing shouldn't even be able to be copyrighted,
it's not a fartsy literary pet project like Bob Alter's translation,
the Friedman translation is a goddamn law of physics, it's just *true.*
Sadly, it only goes Genesis through Deuteronomy, with the exception of J's
bits ("Super J") in 06-joshua through 09-kings, so we'll have to find another
translation we can tolerate (how?) for the remaining books of the primary history.
Against that background, 06-joshua to 09-kings use the JPS Tanak with some modifications.
