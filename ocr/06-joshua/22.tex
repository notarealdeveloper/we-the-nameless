\Verse{26}
{
	\hX{וַנֹּאמֶר נַעֲשֶׂה־נָּא לָנוּ לִבְנוֹת אֶת־הַמִּזְבֵּחַ לֹא לְעוֹלָה וְלֹא לְזָבַח׃}
}
{
	\eX{
		So we decided to provide [a witness] for ourselves by building an
		altar—not for burnt offerings or [other] sacrifices,
	}
}
{
}

\Verse{27}
{
	\hX{
		כִּי עֵד הוּא בֵּינֵינוּ וּבֵינֵיכֶם וּבֵין דֹּרוֹתֵינוּ אַחֲרֵינוּ לַעֲבֹד אֶת־עֲבֹדַת יְהֹוָה לְפָנָיו בְּעֹלוֹתֵינוּ וּבִזְבָחֵינוּ וּבִשְׁלָמֵינוּ וְלֹא־יֹאמְרוּ בְנֵיכֶם מָחָר
		לְבָנֵינוּ אֵין־לָכֶם חֵלֶק בַּיהֹוָה׃
	}
}
{
	\eX{
		but as a witness between you and us, and between the generations
		to come—that we may perform the service of YHWH before Him with
		our burnt offerings, our sacrifices, and our offerings of
		well-being; and that your children should not say to our children
		in time to come, ‘You have no share in YHWH.’
	}
}
{
}

\Verse{28}
{
	\hX{
		וַנֹּאמֶר וְהָיָה כִּי־יֹאמְרוּ אֵלֵינוּ וְאֶל־דֹּרֹתֵינוּ מָחָר וְאָמַרְנוּ רְאוּ אֶת־תַּבְנִית מִזְבַּח יְהֹוָה אֲשֶׁר־עָשׂוּ אֲבוֹתֵינוּ לֹא לְעוֹלָה וְלֹא לְזֶבַח כִּי־עֵד הוּא
		בֵּינֵינוּ וּבֵינֵיכֶם׃
	}
}
{
	\eX{
		We reasoned: should they speak thus to us and to our children in
		time to come, we would reply, ‘See the replica of YHWH’s altar,
		which our fathers made—not for burnt offerings or sacrifices, but
		as a witness between you and us.’
	}
}
{
}

\Verse{29}
{
	\hX{
		חָלִילָה לָּנוּ מִמֶּנּוּ לִמְרֹד בַּיהֹוָה וְלָשׁוּב הַיּוֹם מֵאַחֲרֵי יְהֹוָה לִבְנוֹת מִזְבֵּחַ לְעֹלָה לְמִנְחָה וּלְזָבַח מִלְּבַד מִזְבַּח יְהֹוָה אֱלֹהֵינוּ אֲשֶׁר לִפְנֵי
		מִשְׁכָּנוֹ׃
	}
}
{
	\eX{
		Far be it from us to rebel against YHWH, or to turn away this day
		from YHWH and build an altar for burnt offerings, meal offerings,
		and sacrifices other than the altar of YHWH our God which stands
		before His Tabernacle.”
	}
}
{
}

\Verse{30}
{
	\hX{
		וַיִּשְׁמַע פִּינְחָס הַכֹּהֵן וּנְשִׂיאֵי הָעֵדָה וְרָאשֵׁי אַלְפֵי יִשְׂרָאֵל אֲשֶׁר אִתּוֹ אֶת־הַדְּבָרִים אֲשֶׁר דִּבְּרוּ בְּנֵי־רְאוּבֵן וּבְנֵי־גָד וּבְנֵי מְנַשֶּׁה
		וַיִּיטַב בְּעֵינֵיהֶם׃
	}
}
{
	\eX{
		When the priest Phinehas and the chieftains of the community—the
		heads of the contingents of Israel—who were with him heard the
		explanation given by the Reubenites, the Gadites, and the
		Manassites, they approved.
	}
}
{
}

\Verse{31}
{
	\hX{
		וַיֹּאמֶר פִּינְחָס בֶּן־אֶלְעָזָר הַכֹּהֵן אֶל־בְּנֵי־רְאוּבֵן וְאֶל־בְּנֵי־גָד וְאֶל־בְּנֵי מְנַשֶּׁה הַיּוֹם יָדַעְנוּ כִּי־בְתוֹכֵנוּ יְהֹוָה אֲשֶׁר לֹא־מְעַלְתֶּם בַּיהֹוָה
		הַמַּעַל הַזֶּה אָז הִצַּלְתֶּם אֶת־בְּנֵי יִשְׂרָאֵל מִיַּד יְהֹוָה׃
	}
}
{
	\eX{
		The priest Phinehas son of Eleazar said to the Reubenites, the
		Gadites, and the Manassites, “Now we know that YHWH is in our
		midst, since you have not committed such treachery against YHWH.
		You have indeed saved the Israelites from punishment by YHWH.”
	}
}
{
}

\Verse{32}
{
	\hX{
		וַיָּשׁב פִּינְחָס בֶּן־אֶלְעָזָר הַכֹּהֵן וְהַנְּשִׂיאִים מֵאֵת בְּנֵי־רְאוּבֵן וּמֵאֵת בְּנֵי־גָד מֵאֶרֶץ הַגִּלְעָד אֶל־אֶרֶץ כְּנַעַן אֶל־בְּנֵי יִשְׂרָאֵל וַיָּשִׁבוּ אוֹתָם
		דָּבָר׃
	}
}
{
	\eX{
		Then the priest Phinehas son of Eleazar and the chieftains
		returned from the Reubenites and the Gadites in the land of Gilead
		to the Israelites in the land of Canaan, and gave them their
		report.
	}
}
{
}

\Verse{33}
{
	\hX{
		וַיִּיטַב הַדָּבָר בְּעֵינֵי בְּנֵי יִשְׂרָאֵל וַיְבָרְכוּ אֱלֹהִים בְּנֵי יִשְׂרָאֵל וְלֹא אָמְרוּ לַעֲלוֹת עֲלֵיהֶם לַצָּבָא לְשַׁחֵת אֶת־הָאָרֶץ אֲשֶׁר בְּנֵי־רְאוּבֵן
		וּבְנֵי־גָד יֹשְׁבִים בָּהּ׃
	}
}
{
	\eX{
		The Israelites were pleased, and the Israelites praised God; and
		they spoke no more of going to war against them, to ravage the
		land in which the Reubenites and Gadites dwelt.
	}
}
{
}

\Verse{34}
{
	\hX{וַיִּקְרְאוּ בְּנֵי־רְאוּבֵן וּבְנֵי־גָד לַמִּזְבֵּחַ כִּי עֵד הוּא בֵּינֹתֵינוּ כִּי יְהֹוָה הָאֱלֹהִים׃}
}
{
	\eX{
		The Reubenites and the Gadites named the altar [“Witness”],
		meaning, “It is a witness between us and them that YHWH is [our]
		God.”
	}
}
{
}
