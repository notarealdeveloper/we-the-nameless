\Chapter{5}

\Verse{1}
{
	\hX{
		וַיְהִי כִשְׁמֹעַ כּל־מַלְכֵי הָאֱמֹרִי אֲשֶׁר בְּעֵבֶר הַיַּרְדֵּן יָמָּה וְכל־מַלְכֵי הַכְּנַעֲנִי אֲשֶׁר עַל־הַיָּם אֵת אֲשֶׁר־הוֹבִישׁ יְהֹוָה אֶת־מֵי הַיַּרְדֵּן מִפְּנֵי
		בְנֵי־יִשְׂרָאֵל עַד־[עבְרָם] (עברנו) וַיִּמַּס לְבָבָם וְלֹא־הָיָה בָם עוֹד רוּחַ מִפְּנֵי בְּנֵי יִשְׂרָאֵל׃
	}
}
{
	\eX{
		When all the kings of the Amorites on the western side of the
		Jordan, and all the kings of the Canaanites near the Sea, heard
		how YHWH had dried up the waters of the Jordan for the sake of the
		Israelites until they crossed over, they lost heart, and no spirit
		was left in them because of the Israelites.
	}
}
{
	Qere Ketiv.
}

\Verse{2}
{
	\hX{בָּעֵת הַהִיא אָמַר יְהֹוָה אֶל־יְהוֹשֻׁעַ עֲשֵׂה לְךָ חַרְבוֹת צֻרִים וְשׁוּב מֹל אֶת־בְּנֵי־יִשְׂרָאֵל שֵׁנִית׃}
}
{
	\eX{
		At that time YHWH said to Joshua, “Make flint knives and proceed
		with a second circumcision of the Israelites.”
	}
}
{
}

\Verse{3}
{
	\hX{וַיַּעַשׂ־לוֹ יְהוֹשֻׁעַ חַרְבוֹת צֻרִים וַיָּמל אֶת־בְּנֵי יִשְׂרָאֵל אֶל־גִּבְעַת הָעֲרָלוֹת׃}
}
{
	\eX{
		So Joshua had flint knives made, and the Israelites were
		circumcised at Gibeath-haaraloth.
	}
}
{
}

\Verse{4}
{
	\hX{וְזֶה הַדָּבָר אֲשֶׁר־מָל יְהוֹשֻׁעַ כּל־הָעָם הַיֹּצֵא מִמִּצְרַיִם הַזְּכָרִים כֹּל אַנְשֵׁי הַמִּלְחָמָה מֵתוּ בַמִּדְבָּר בַּדֶּרֶךְ בְּצֵאתָם מִמִּצְרָיִם׃}
}
{
	\eX{
		This is the reason why Joshua had the circumcision performed: All
		the people who had come out of Egypt, all the males of military
		age, had died during the desert wanderings after leaving Egypt.
	}
}
{
}

\Verse{5}
{
	\hX{כִּי־מֻלִים הָיוּ כּל־הָעָם הַיֹּצְאִים וְכל־הָעָם הַיִּלֹּדִים בַּמִּדְבָּר בַּדֶּרֶךְ בְּצֵאתָם מִמִּצְרַיִם לֹא־מָלוּ׃}
}
{
	\eX{
		Now, whereas all the people who came out of Egypt had been
		circumcised, none of the people born after the exodus, during the
		desert wanderings, had been circumcised.
	}
}
{
}

\Verse{6}
{
	\hX{
		כִּי אַרְבָּעִים שָׁנָה הָלְכוּ בְנֵי־יִשְׂרָאֵל בַּמִּדְבָּר עַד־תֹּם כּל־הַגּוֹי אַנְשֵׁי הַמִּלְחָמָה הַיֹּצְאִים מִמִּצְרַיִם אֲשֶׁר לֹא־שָׁמְעוּ בְּקוֹל יְהֹוָה אֲשֶׁר
		נִשְׁבַּע יְהֹוָה לָהֶם לְבִלְתִּי הַרְאוֹתָם אֶת־הָאָרֶץ אֲשֶׁר נִשְׁבַּע יְהֹוָה לַאֲבוֹתָם לָתֶת לָנוּ אֶרֶץ זָבַת חָלָב וּדְבָשׁ׃
	}
}
{
	\eX{
		For the Israelites had traveled in the wilderness forty years,
		until the entire nation—the men of military age who had left
		Egypt—had perished; because they had not obeyed YHWH, and YHWH had
		sworn never to let them see the land that YHWH had sworn to their
		fathers to assign to us, a land flowing with milk and honey.
	}
}
{
}

\Verse{7}
{
	\hX{וְאֶת־בְּנֵיהֶם הֵקִים תַּחְתָּם אֹתָם מָל יְהוֹשֻׁעַ כִּי־עֲרֵלִים הָיוּ כִּי לֹא־מָלוּ אוֹתָם בַּדָּרֶךְ׃}
}
{
	\eX{
		But He had raised up their sons in their stead; and it was these
		that Joshua circumcised, for they were uncircumcised, not having
		been circumcised on the way.
	}
}
{
}

\Verse{8}
{
	\hX{וַיְהִי כַּאֲשֶׁר־תַּמּוּ כל־הַגּוֹי לְהִמּוֹל וַיֵּשְׁבוּ תַחְתָּם בַּמַּחֲנֶה עַד חֲיוֹתָם׃}
}
{
	\eX{
		After the circumcising of the whole nation was completed, they
		remained where they were, in the camp, until they recovered.
	}
}
{
}

\Verse{9}
{
	\hX{וַיֹּאמֶר יְהֹוָה אֶל־יְהוֹשֻׁעַ הַיּוֹם גַּלּוֹתִי אֶת־חֶרְפַּת מִצְרַיִם מֵעֲלֵיכֶם וַיִּקְרָא שֵׁם הַמָּקוֹם הַהוּא גִּלְגָּל עַד הַיּוֹם הַזֶּה׃}
}
{
	\eX{
		And YHWH said to Joshua, “Today I have rolled away from you the
		disgrace of Egypt.” So that place was called Gilgal, as it still
		is.
	}
}
{
}

\Verse{10}
{
	\hX{וַיַּחֲנוּ בְנֵי־יִשְׂרָאֵל בַּגִּלְגָּל וַיַּעֲשׂוּ אֶת־הַפֶּסַח בְּאַרְבָּעָה עָשָׂר יוֹם לַחֹדֶשׁ בָּעֶרֶב בְּעַרְבוֹת יְרִיחוֹ׃}
}
{
	\eX{

}
{
}

\Verse{11}
{
	\hX{וַיֹּאכְלוּ מֵעֲבוּר הָאָרֶץ מִמּחֳרַת הַפֶּסַח מַצּוֹת וְקָלוּי בְּעֶצֶם הַיּוֹם הַזֶּה׃}
}
{
	\eX{
		On the day after the passover offering, on that very day, they ate

	}
}
{
}

\Verse{12}
{
	\hX{וַיִּשְׁבֹּת הַמָּן מִמּחֳרָת בְּאכְלָם מֵעֲבוּר הָאָרֶץ וְלֹא־הָיָה עוֹד לִבְנֵי יִשְׂרָאֵל מָן וַיֹּאכְלוּ מִתְּבוּאַת אֶרֶץ כְּנַעַן בַּשָּׁנָה הַהִיא׃}
}
{
	\eX{
		On that same day, when they ate of the produce of the land, the
		manna ceased. The Israelites got no more manna; that year they ate
		of the yield of the land of Canaan.
	}
}
{
}

\Verse{13}
{
	\hX{
		וַיְהִי בִּהְיוֹת יְהוֹשֻׁעַ בִּירִיחוֹ וַיִּשָּׂא עֵינָיו וַיַּרְא וְהִנֵּה־אִישׁ עֹמֵד לְנֶגְדּוֹ וְחַרְבּוֹ שְׁלוּפָה בְּיָדוֹ וַיֵּלֶךְ יְהוֹשֻׁעַ אֵלָיו וַיֹּאמֶר לוֹ הֲלָנוּ
		אַתָּה אִם־לְצָרֵינוּ׃
	}
}
{
	\eX{
		Once, when Joshua was near Jericho, he looked up and saw a man
		standing before him, drawn sword in hand. Joshua went up to him
		and asked him, “Are you one of us or of our enemies?”
	}
}
{
%	\footnote{
%		Footnote 5:13. a man standing opposite him. The scene deliberately sounds like
%		Moses at the bush and Balaam on the road: a human sees a figure with a drawn sword
%		and then finds out that the question is not whether God is on his side. The
%		question is whether he is standing on holy ground.
%	}
}

\Verse{14}
{
	\hX{וַיֹּאמֶר לֹא כִּי אֲנִי שַׂר־צְבָא־יְהֹוָה עַתָּה בָאתִי וַיִּפֹּל יְהוֹשֻׁעַ אֶל־פָּנָיו אַרְצָה וַיִּשְׁתָּחוּ וַיֹּאמֶר לוֹ מָה אֲדֹנִי מְדַבֵּר אֶל־עַבְדּוֹ׃}
}
{
	\eX{
		He replied, “No, I am captain of YHWH’s host. Now I have come!”
		Joshua threw himself face down to the ground and, prostrating
		himself, said to him, “What does my lord command his servant?”
	}
}
{
}
