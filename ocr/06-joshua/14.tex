\Chapter{14}

\Verse{1}
{
	\hP{וְאֵלֶּה אֲשֶׁר־נָחֲלוּ בְנֵי־יִשְׂרָאֵל בְּאֶרֶץ כְּנָעַן אֲשֶׁר נִחֲלוּ אוֹתָם אֶלְעָזָר הַכֹּהֵן וִיהוֹשֻׁעַ בִּן־נוּן וְרָאשֵׁי אֲבוֹת הַמַּטּוֹת לִבְנֵי יִשְׂרָאֵל׃}
}
{
	\eP{
		And these are the allotments of the Israelites in the land of
		Canaan, that were apportioned to them by the priest Eleazar, by
		Joshua son of Nun, and by the heads of the ancestral houses of the
		Israelite tribes,
	}
}
{
}

\Verse{2}
{
	\hP{בְּגוֹרַל נַחֲלָתָם כַּאֲשֶׁר צִוָּה יְהֹוָה בְּיַד־מֹשֶׁה לְתִשְׁעַת הַמַּטּוֹת וַחֲצִי הַמַּטֶּה׃}
}
{
	\eP{
		the portions that fell to them by lot, as YHWH had commanded
		through Moses for the nine and a half tribes.
	}
}
{
}

\Verse{3}
{
	\hP{כִּי־נָתַן מֹשֶׁה נַחֲלַת שְׁנֵי הַמַּטּוֹת וַחֲצִי הַמַּטֶּה מֵעֵבֶר לַיַּרְדֵּן וְלַלְוִיִּם לֹא־נָתַן נַחֲלָה בְּתוֹכָם׃}
}
{
	\eP{
		For the portion of the other two and a half tribes had been
		assigned to them by Moses on the other side of the Jordan. He had
		not assigned any portion among them to the Levites;
	}
}
{
}

\Verse{4}
{
	\hP{כִּי־הָיוּ בְנֵי־יוֹסֵף שְׁנֵי מַטּוֹת מְנַשֶּׁה וְאֶפְרָיִם וְלֹא־נָתְנוּ חֵלֶק לַלְוִיִּם בָּאָרֶץ כִּי אִם־עָרִים לָשֶׁבֶת וּמִגְרְשֵׁיהֶם לְמִקְנֵיהֶם וּלְקִנְיָנָם׃}
}
{
	\eP{
		for whereas the descendants of Joseph constituted two tribes,
		Manasseh and Ephraim, the Levites were assigned no share in the
		land, but only some towns to live in, with the pastures for their
		livestock and cattle.
	}
}
{
}

\Verse{5}
{
	\hP{כַּאֲשֶׁר צִוָּה יְהֹוָה אֶת־מֹשֶׁה כֵּן עָשׂוּ בְּנֵי יִשְׂרָאֵל וַיַּחְלְקוּ אֶת־הָאָרֶץ׃}
}
{
	\eP{
		Just as YHWH had commanded Moses, so the Israelites did when they
		apportioned the land.
	}
}
{
}

\Verse{6}
{
	\hX{
		וַיִּגְּשׁוּ בְנֵי־יְהוּדָה אֶל־יְהוֹשֻׁעַ בַּגִּלְגָּל וַיֹּאמֶר אֵלָיו כָּלֵב בֶּן־יְפֻנֶּה הַקְּנִזִּי אַתָּה יָדַעְתָּ אֶת־הַדָּבָר אֲשֶׁר־דִּבֶּר יְהֹוָה אֶל־מֹשֶׁה
		אִישׁ־הָאֱלֹהִים עַל אֹדוֹתַי וְעַל אֹדוֹתֶיךָ
	}
	\hE{בְּקָדֵשׁ בַּרְנֵעַ׃}
}
{
	\eX{
		The Judites approached Joshua at Gilgal, and Caleb son of
		Jephunneh the Kenizzite said to him: “You know what instructions
		YHWH gave at
	}
	\eE{Kadesh-barnea}
	\eX{
		to Moses, the man of God, concerning you and me.
	}
}
{
}

\Verse{7}
{
	\hX{בֶּן־אַרְבָּעִים שָׁנָה אָנֹכִי בִּשְׁלֹחַ מֹשֶׁה עֶבֶד־יְהֹוָה אֹתִי מִקָּדֵשׁ בַּרְנֵעַ לְרַגֵּל אֶת־הָאָרֶץ וָאָשֵׁב אֹתוֹ דָּבָר כַּאֲשֶׁר עִם־לְבָבִי׃}
}
{
	\eX{
		I was forty years old when Moses the servant of YHWH sent me from
		Kadesh-barnea to spy out the land, and I gave him a forthright
		report.
	}
}
{
}

\Verse{8}
{
	\hE{וְאַחַי אֲשֶׁר עָלוּ עִמִּי הִמְסִיו אֶת־לֵב הָעָם וְאָנֹכִי מִלֵּאתִי אַחֲרֵי יְהֹוָה אֱלֹהָי׃}
}
{
	\eE{
		While my companions who went up with me took the heart out of the
		people, I was loyal to YHWH my God.
	}
}
{
}

\Verse{9}
{
	\hX{וַיִּשָּׁבַע מֹשֶׁה בַּיּוֹם הַהוּא לֵאמֹר אִם־לֹא הָאָרֶץ אֲשֶׁר דָּרְכָה רַגְלְךָ בָּהּ לְךָ תִהְיֶה לְנַחֲלָה וּלְבָנֶיךָ עַד־עוֹלָם כִּי מִלֵּאתָ אַחֲרֵי}
	\hE{יְהֹוָה אֱלֹהָי׃}
}
{
	\eX{
		On that day, Moses promised on oath, ‘The land on which your foot
		trod shall be a portion for you and your descendants forever,
		because you were loyal to
	}
	\eE{YHWH my God.’}
	\eX{
	}
}
{
}

\Verse{10}
{
	\hX{
		וְעַתָּה הִנֵּה הֶחֱיָה יְהֹוָה אוֹתִי כַּאֲשֶׁר דִּבֵּר זֶה אַרְבָּעִים וְחָמֵשׁ שָׁנָה מֵאָז דִּבֶּר יְהֹוָה אֶת־הַדָּבָר הַזֶּה אֶל־מֹשֶׁה אֲשֶׁר־הָלַךְ יִשְׂרָאֵל בַּמִּדְבָּר
		וְעַתָּה הִנֵּה אָנֹכִי הַיּוֹם בֶּן־חָמֵשׁ וּשְׁמֹנִים שָׁנָה׃
	}
}
{
	\eX{
		Now YHWH has preserved me, as He promised. It is forty-five years
		since YHWH made this promise to Moses, when Israel was journeying
		through the wilderness; and here I am today, eighty-five years
		old.
	}
}
{
}

\Verse{11}
{
	\hE{עוֹדֶנִּי הַיּוֹם חָזָק כַּאֲשֶׁר בְּיוֹם שְׁלֹחַ אוֹתִי מֹשֶׁה כְּכֹחִי אָז וּכְכֹחִי עָתָּה לַמִּלְחָמָה וְלָצֵאת וְלָבוֹא׃}
}
{
	\eE{
		I am still as strong today as on the day that Moses sent me; my
		strength is the same now as it was then, for battle and for
		activity.
	}
}
{
}

\Verse{12}
{
	\hX{
		וְעַתָּה תְּנָה־לִּי אֶת־הָהָר הַזֶּה אֲשֶׁר־דִּבֶּר יְהֹוָה בַּיּוֹם הַהוּא כִּי אַתָּה־שָׁמַעְתָּ בַיּוֹם הַהוּא כִּי־עֲנָקִים שָׁם וְעָרִים גְּדֹלוֹת בְּצֻרוֹת אוּלַי יְהֹוָה
		אוֹתִי וְהוֹרַשְׁתִּים כַּאֲשֶׁר דִּבֶּר יְהֹוָה׃
	}
}
{
	\eX{
		So assign to me this hill country as YHWH promised on that day.
		Though you too heard on that day that Anakites are there and great
		fortified cities, if only YHWH is with me, I will dispossess them,
		as YHWH promised.”
	}
}
{
}

\Verse{13}
{
	\hX{וַיְבָרְכֵהוּ יְהוֹשֻׁעַ וַיִּתֵּן אֶת־חֶבְרוֹן לְכָלֵב בֶּן־יְפֻנֶּה לְנַחֲלָה׃}
}
{
	\eX{
		So Joshua blessed Caleb son of Jephunneh and assigned Hebron to
		him as his portion.
	}
}
{
}

\Verse{14}
{
	\hX{עַל־כֵּן הָיְתָה־חֶבְרוֹן לְכָלֵב בֶּן־יְפֻנֶּה הַקְּנִזִּי לְנַחֲלָה עַד הַיּוֹם הַזֶּה יַעַן אֲשֶׁר מִלֵּא אַחֲרֵי}
	\hE{יְהֹוָה אֱלֹהֵי יִשְׂרָאֵל׃}
}
{
	\eX{
		Thus Hebron became the portion of Caleb son of Jephunneh the
		Kenizzite, as it still is, because he was loyal to
	}
	\eE{
		YHWH, the God of Israel.—
	}
}
{
}

\Verse{15}
{
	\hX{וְשֵׁם חֶבְרוֹן לְפָנִים קִרְיַת אַרְבַּע הָאָדָם הַגָּדוֹל בָּעֲנָקִים הוּא}

}
{

	}
	\eE{

	}
}
