\Chapter{23}

\Verse{1}
{
	\hX{וַיְהִי מִיָּמִים רַבִּים אַחֲרֵי אֲשֶׁר־הֵנִיחַ יְהֹוָה לְיִשְׂרָאֵל מִכּל־אֹיְבֵיהֶם מִסָּבִיב וִיהוֹשֻׁעַ זָקֵן בָּא בַּיָּמִים׃}
}
{
	\eX{
		Much later, after YHWH had given Israel rest from all the enemies
		around them, and when Joshua was old and well advanced in years,
	}
}
{
}

\Verse{2}
{
	\hX{וַיִּקְרָא יְהוֹשֻׁעַ לְכל־יִשְׂרָאֵל לִזְקֵנָיו וּלְרָאשָׁיו וּלְשֹׁפְטָיו וּלְשֹׁטְרָיו וַיֹּאמֶר אֲלֵהֶם אֲנִי זָקַנְתִּי בָּאתִי בַּיָּמִים׃}
}
{
	\eX{
		Joshua summoned all Israel, their elders and commanders, their
		magistrates and officials, and said to them: “I have grown old and
		am advanced in years.
	}
}
{
}

\Verse{3}
{
	\hX{וְאַתֶּם רְאִיתֶם אֵת כּל־אֲשֶׁר עָשָׂה יְהֹוָה אֱלֹהֵיכֶם לְכל־הַגּוֹיִם הָאֵלֶּה מִפְּנֵיכֶם כִּי יְהֹוָה אֱלֹהֵיכֶם הוּא הַנִּלְחָם לָכֶם׃}
}
{
	\eX{
		You have seen all that YHWH your God has done to all those nations
		on your account, for it was YHWH your God who fought for you.
	}
}
{
}

\Verse{4}
{
	\hX{רְאוּ הִפַּלְתִּי לָכֶם אֶת־הַגּוֹיִם הַנִּשְׁאָרִים הָאֵלֶּה בְּנַחֲלָה לְשִׁבְטֵיכֶם מִן־הַיַּרְדֵּן וְכל־הַגּוֹיִם אֲשֶׁר הִכְרַתִּי וְהַיָּם הַגָּדוֹל מְבוֹא הַשָּׁמֶשׁ׃}
}
{
	\eX{
		See, I have allotted to you, by your tribes, [the territory of]
		these nations that still remain, and that of all the nations that
		I have destroyed, from the Jordan to the Mediterranean Sea in the
		west.
	}
}
{
}

\Verse{5}
{
	\hX{וַיהֹוָה אֱלֹהֵיכֶם הוּא יֶהְדֳּפֵם מִפְּנֵיכֶם וְהוֹרִישׁ אֹתָם מִלִּפְנֵיכֶם וִירִשְׁתֶּם אֶת־אַרְצָם כַּאֲשֶׁר דִּבֶּר יְהֹוָה אֱלֹהֵיכֶם לָכֶם׃}
}
{
	\eX{
		YHWH your God Himself will thrust them out on your account and
		drive them out to make way for you, and you shall possess their
		land as YHWH your God promised you.
	}
}
{
}

\Verse{6}
{
	\hX{וַחֲזַקְתֶּם מְאֹד לִשְׁמֹר וְלַעֲשׂוֹת אֵת כּל־הַכָּתוּב בְּסֵפֶר תּוֹרַת מֹשֶׁה לְבִלְתִּי סוּר־מִמֶּנּוּ יָמִין וּשְׂמֹאול׃}
}
{
	\eX{
		“But be most resolute to observe faithfully all that is written in
		the Book of the Teaching of Moses, without ever deviating from it
		to the right or to the left,
	}
}
{
}

\Verse{7}
{
	\hX{לְבִלְתִּי־בֹא בַּגּוֹיִם הָאֵלֶּה הַנִּשְׁאָרִים הָאֵלֶּה אִתְּכֶם וּבְשֵׁם אֱלֹהֵיהֶם לֹא־תַזְכִּירוּ וְלֹא תַשְׁבִּיעוּ וְלֹא תַעַבְדוּם וְלֹא תִשְׁתַּחֲווּ לָהֶם׃}
}
{
	\eX{
		and without intermingling with these nations that are left among
		you. Do not utter the names of their gods or swear by them; do not
		serve them or bow down to them.
	}
}
{
}

\Verse{8}
{
	\hX{כִּי אִם־בַּיהֹוָה אֱלֹהֵיכֶם תִּדְבָּקוּ כַּאֲשֶׁר עֲשִׂיתֶם עַד הַיּוֹם הַזֶּה׃}
}
{
	\eX{
		But hold fast to YHWH your God as you have done to this day.
	}
}
{
}

\Verse{9}
{
	\hX{וַיּוֹרֶשׁ יְהֹוָה מִפְּנֵיכֶם גּוֹיִם גְּדֹלִים וַעֲצוּמִים וְאַתֶּם לֹא־עָמַד אִישׁ בִּפְנֵיכֶם עַד הַיּוֹם הַזֶּה׃}
}
{
	\eX{
		“YHWH has driven out great, powerful nations on your account, and
		not a man has withstood you to this day.
	}
}
{
}

\Verse{10}
{
	\hX{אִישׁ־אֶחָד מִכֶּם יִרְדּף־אָלֶף כִּי יְהֹוָה אֱלֹהֵיכֶם הוּא הַנִּלְחָם לָכֶם כַּאֲשֶׁר דִּבֶּר לָכֶם׃}
}
{
	\eX{
		A single man of you would put a thousand to flight, for YHWH your
		God Himself has been fighting for you, as He promised you.
	}
}
{
}

\Verse{11}
{
	\hX{וְנִשְׁמַרְתֶּם מְאֹד לְנַפְשֹׁתֵיכֶם לְאַהֲבָה אֶת־יְהֹוָה אֱלֹהֵיכֶם׃}
}
{
	\eX{
		For your own sakes, therefore, be most mindful to love YHWH your
		God.
	}
}
{
}

\Verse{12}
{
	\hX{כִּי אִם־שׁוֹב תָּשׁוּבוּ וּדְבַקְתֶּם בְּיֶתֶר הַגּוֹיִם הָאֵלֶּה הַנִּשְׁאָרִים הָאֵלֶּה אִתְּכֶם וְהִתְחַתַּנְתֶּם בָּהֶם וּבָאתֶם בָּהֶם וְהֵם בָּכֶם׃}
}
{
	\eX{
		For should you turn away and attach yourselves to the remnant of
		those nations—to those that are left among you—and intermarry with
		them, you joining them and they joining you,
	}
}
{
}

\Verse{13}
{
	\hX{
		יָדוֹעַ תֵּדְעוּ כִּי לֹא יוֹסִיף יְהֹוָה אֱלֹהֵיכֶם לְהוֹרִישׁ אֶת־הַגּוֹיִם הָאֵלֶּה מִלִּפְנֵיכֶם וְהָיוּ לָכֶם לְפַח וּלְמוֹקֵשׁ וּלְשֹׁטֵט בְּצִדֵּיכֶם וְלִצְנִנִים
		בְּעֵינֵיכֶם עַד־אֲבדְכֶם מֵעַל הָאֲדָמָה הַטּוֹבָה הַזֹּאת אֲשֶׁר נָתַן לָכֶם יְהֹוָה אֱלֹהֵיכֶם׃
	}
}
{
	\eX{
		know for certain that YHWH your God will not continue to drive
		these nations out before you; they shall become a snare and a trap
		for you, a scourge to your sides and thorns in your eyes, until
		you perish from this good land that YHWH your God has given you.
	}
}
{
}

\Verse{14}
{
	\hX{
		וְהִנֵּה אָנֹכִי הוֹלֵךְ הַיּוֹם בְּדֶרֶךְ כּל־הָאָרֶץ וִידַעְתֶּם בְּכל־לְבַבְכֶם וּבְכל־נַפְשְׁכֶם כִּי לֹא־נָפַל דָּבָר אֶחָד מִכֹּל הַדְּבָרִים הַטּוֹבִים אֲשֶׁר דִּבֶּר
		יְהֹוָה אֱלֹהֵיכֶם עֲלֵיכֶם הַכֹּל בָּאוּ לָכֶם לֹא־נָפַל מִמֶּנּוּ דָּבָר אֶחָד׃
	}
}
{
	\eX{
		“I am now going the way of all the earth. Acknowledge with all
		your heart and soul that not one of the good things that YHWH your
		God promised you has failed to happen; they have all come true for
		you, not a single one has failed.
	}
}
{
}

\Verse{15}
{
	\hX{
		וְהָיָה כַּאֲשֶׁר־בָּא עֲלֵיכֶם כּל־הַדָּבָר הַטּוֹב אֲשֶׁר דִּבֶּר יְהֹוָה אֱלֹהֵיכֶם אֲלֵיכֶם כֵּן יָבִיא יְהֹוָה עֲלֵיכֶם אֵת כּל־הַדָּבָר הָרָע עַד־הַשְׁמִידוֹ אוֹתְכֶם מֵעַל
		הָאֲדָמָה הַטּוֹבָה הַזֹּאת אֲשֶׁר נָתַן לָכֶם יְהֹוָה אֱלֹהֵיכֶם׃
	}
}
{
	\eX{
		But just as every good thing that YHWH your God promised you has
		been fulfilled for you, so YHWH can bring upon you every evil
		thing until He has wiped you off this good land that YHWH your God
		has given you.
	}
}
{
}

\Verse{16}
{
	\hX{
		בְּעבְרְכֶם אֶת־בְּרִית יְהֹוָה אֱלֹהֵיכֶם אֲשֶׁר צִוָּה אֶתְכֶם וַהֲלַכְתֶּם וַעֲבַדְתֶּם אֱלֹהִים אֲחֵרִים וְהִשְׁתַּחֲוִיתֶם לָהֶם וְחָרָה אַף־יְהֹוָה בָּכֶם וַאֲבַדְתֶּם
		מְהֵרָה מֵעַל הָאָרֶץ הַטּוֹבָה אֲשֶׁר נָתַן לָכֶם׃
	}
}
{
	\eX{
		If you break the covenant that YHWH your God enjoined upon you,
		and go and serve other gods and bow down to them, then YHWH’s
		anger will burn against you, and you shall quickly perish from the
		good land that He has given you.”
	}
}
{
}
