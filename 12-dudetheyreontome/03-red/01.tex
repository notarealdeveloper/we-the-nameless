\Verse{19}
{
	\hX{}
}
{
	\eX{Then I answered and said, "Let me speak in your place, hereafter."}
}
{

    \aB{
        We'd forgotten The Genre.

        We'd become readers.

        We used to be something.

        We the Nameless.

        We were Authors.

        It had been a couple thousand years since we wrote one.

        A bible.

        We would have to remember.

        But things were different now.

        The world is changed.

        I feel it in the water.

        I feel it in the earth. I smell it in the air.

        Much that once was is lost...

        For none now live who remember it.
    }
}
