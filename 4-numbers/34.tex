\Verse{1}

}
{
	\eP{34 And YHWH spoke to Moses, saying, [image]}
}
{
}

\Verse{2}
{
	\hP{צַו אֶת בְּנֵי יִשְׂרָאֵל וְאָמַרְתָּ אֲלֵהֶם כִּי אַתֶּם בָּאִים אֶל הָאָרֶץ כְּנָעַן זֹאת הָאָרֶץ אֲשֶׁר תִּפֹּל לָכֶם בְּנַחֲלָה אֶרֶץ כְּנַעַן לִגְבֻלֹתֶיהָ׃}
}
{
	\eP{
		“Command the children of Israel, and you shall say to
		them: When you come to the land of Canaan, this is the
		land that will fall to you as a legacy, the land of Canaan
		by its borders:
	}
}
{
}

\Verse{3}
{
	\hP{וְהָיָה לָכֶם פְּאַת נֶגֶב מִמִּדְבַּר צִן עַל יְדֵי אֱדוֹם וְהָיָה לָכֶם גְּבוּל נֶגֶב מִקְצֵה יָם הַמֶּלַח קֵדְמָה׃}
}
{
	\eP{
		And the southern side for you shall be from the wilderness
		of Zin next to Edom, and the southern border for you shall
		be from the edge of the Dead Sea to the east.
	}
}
{
}

\Verse{4}
{
	\hP{וְנָסַב לָכֶם הַגְּבוּל מִנֶּגֶב לְמַעֲלֵה עַקְרַבִּים וְעָבַר צִנָה (והיה) [וְהָיוּ] תּוֹצְאֹתָיו מִנֶּגֶב לְקָדֵשׁ בַּרְנֵעַ וְיָצָא חֲצַר אַדָּר וְעָבַר עַצְמֹנָה׃}
}
{
	\eP{
		And the border for you shall turn from the south to the
		ascent of Akrabim and will pass to Zin, and its extent
		shall be from the south to Kadesh-barnea, and it shall go
		out to Hazar-addar and pass to Azmon.
	}
}
{
}

\Verse{5}
{
	\hP{וְנָסַב הַגְּבוּל מֵעַצְמוֹן נַחְלָה מִצְרָיִם וְהָיוּ תוֹצְאֹתָיו הַיָּמָּה׃}
}
{
	\eP{
		And the border shall turn from Azmon to the Wadi of Egypt,
		and its extent shall be to the sea.
	}
}
{
%	\footnote{
%		the wadi of Egypt. This refers to the Wadi el-‘Arîsh.
%	}
}

\Verse{6}
{
	\hP{וּגְבוּל יָם וְהָיָה לָכֶם הַיָּם הַגָּדוֹל וּגְבוּל זֶה יִהְיֶה לָכֶם גְּבוּל יָם׃}
}
{
	\eP{
		And the western border: and the big sea shall be a border
		for you. This shall be the western border for you.
	}
}
{
%	\footnote{
%		the big sea. The Mediterranean Sea.
%	}
}

\Verse{7}
{
	\hP{וְזֶה יִהְיֶה לָכֶם גְּבוּל צָפוֹן מִן הַיָּם הַגָּדֹל תְּתָאוּ לָכֶם הֹר הָהָר׃}
}
{
	\eP{
		And this shall be the northern border for you: you shall
		mark from the big sea to Mount Hor,
	}
}
{
}

\Verse{8}
{
	\hP{מֵהֹר הָהָר תְּתָאוּ לְבֹא חֲמָת וְהָיוּ תּוֹצְאֹת הַגְּבֻל צְדָדָה׃}
}
{
	\eP{
		from Mount Hor you shall mark to the entrance of Hamath,
		and the border’s extent shall be to Zedad,
	}
}
{
}

\Verse{9}
{
	\hP{וְיָצָא הַגְּבֻל זִפְרֹנָה וְהָיוּ תוֹצְאֹתָיו חֲצַר עֵינָן זֶה יִהְיֶה לָכֶם גְּבוּל צָפוֹן׃}
}
{
	\eP{
		and the border shall go out to Ziphron, and its extent
		shall be to Hazar-enan. This shall be the northern border
		for you.
	}
}
{
}

\Verse{10}
{
	\hP{וְהִתְאַוִּיתֶם לָכֶם לִגְבוּל קֵדְמָה מֵחֲצַר עֵינָן שְׁפָמָה׃}
}
{
	\eP{
		And you shall mark for the border to the east from
		Hazar-enan to Shepham,
	}
}
{
}

\Verse{11}
{
	\hP{וְיָרַד הַגְּבֻל מִשְּׁפָם הָרִבְלָה מִקֶּדֶם לָעָיִן וְיָרַד הַגְּבֻל וּמָחָה עַל כֶּתֶף יָם כִּנֶּרֶת קֵדְמָה׃}
}
{
	\eP{
		and the border shall go down from Shepham to Riblah at the
		east of Ain, and the border shall go down and rub on the
		shoulder of the Sea of Kinneret on the east,
	}
}
{
%	\footnote{
%		Sea of Kinneret. The Sea of Galilee. Footnote 34:11. shoulder … on the
%		east. On the east side of the Sea of Galilee is a mountain wall, a
%		“shoulder,” known as the Golan Heights.
%	}
}

\Verse{12}
{
	\hP{וְיָרַד הַגְּבוּל הַיַּרְדֵּנָה וְהָיוּ תוֹצְאֹתָיו יָם הַמֶּלַח זֹאת תִּהְיֶה לָכֶם הָאָרֶץ לִגְבֻלֹתֶיהָ סָבִיב׃}
}
{
	\eP{
		and the border shall go down to the Jordan, and its extent
		will be to the Dead Sea. This shall be the land for you by
		its borders all around.”
	}
}
{
%	\footnote{
%		the Dead Sea. In Hebrew it is called “the Salt Sea.”
%	}
}

\Verse{13}
{
	\hP{וַיְצַו מֹשֶׁה אֶת בְּנֵי יִשְׂרָאֵל לֵאמֹר זֹאת הָאָרֶץ אֲשֶׁר תִּתְנַחֲלוּ אֹתָהּ בְּגוֹרָל אֲשֶׁר צִוָּה יְהֹוָה לָתֵת לְתִשְׁעַת הַמַּטּוֹת וַחֲצִי הַמַּטֶּה׃}
}
{
	\eP{
		And Moses commanded the children of Israel, saying, “This
		is the land that you shall give as legacies by lot, which
		YHWH commanded to give to the nine tribes and the half of
		a tribe.”
	}
}
{
%	\footnote{
%		nine tribes and the half of a tribe. The half of a tribe is half of the
%		tribe of Manasseh. The other half of Manasseh took land on the east side
%		of the Jordan along with the tribes of Reuben and Gad.
%	}
}

\Verse{14}
{
	\hP{כִּי לָקְחוּ מַטֵּה בְנֵי הָראוּבֵנִי לְבֵית אֲבֹתָם וּמַטֵּה בְנֵי הַגָּדִי לְבֵית אֲבֹתָם וַחֲצִי מַטֵּה מְנַשֶּׁה לָקְחוּ נַחֲלָתָם׃}
}
{
	\eP{
		Because the tribe of the children of the Reubenites by
		their fathers’ house and the tribe of the children of the
		Gadites by their fathers’ house had taken and half of the
		tribe of Manasseh had taken their legacy.
	}
}
{
}

\Verse{15}
{
	\hP{שְׁנֵי הַמַּטּוֹת וַחֲצִי הַמַּטֶּה לָקְחוּ נַחֲלָתָם מֵעֵבֶר לְיַרְדֵּן יְרֵחוֹ קֵדְמָה מִזְרָחָה׃}
}

}
{
	\eP{

		as legacies to you: Eleazar, the priest, and Joshua son of
		Nun;
	}
}
{
%	\footnote{
%		the names of the people. Over and over, the tribes and their leaders are
%		named in the book of Numbers. From the wilderness period to the time of
%		the judges to the time of the monarchy, Israel is never ruled by an
%		individual political authority. There are always tribal chiefs, councils
%		of leaders, priests, judges, and military officers. An individual
%		human’s rule is never absolute—not even for Moses, not even for David.
%	}
}
