\Chapter{1}

\Verse{1}
{
	\hX{דִּבְרֵי נְחֶמְיָה בֶּן־חֲכַלְיָה וַיְהִי בְחֹדֶשׁ־כִּסְלֵו שְׁנַת עֶשְׂרִים וַאֲנִי הָיִיתִי בְּשׁוּשַׁן הַבִּירָה׃}
}
{
	\eX{
		The words of Nehemiah the son of Hacaliah. And it was in the
		month Kislev, in year twenty, and I was in Susa the fortress,
	}
}
{
}

\Verse{2}
{
	\hX{וַיָּבֹא חֲנָנִי אֶחָד מֵאַחַי הוּא וַאֲנָשִׁים מִיהוּדָה וָאֶשְׁאָלֵם עַל־הַיְּהוּדִים הַפְּלֵיטָה אֲשֶׁר־נִשְׁאֲרוּ מִן־הַשֶּׁבִי וְעַל־יְרוּשָׁלָ͏ִם׃}
}
{
	\eX{
		that Hanani, one of my brothers, came, he and men from Judah.
		And I asked them about the Jews who had escaped, who were left
		from the captivity, and about Jerusalem.
	}
}
{
}

\Verse{3}
{
	\hX{וַיֹּאמְרוּ לִי הַנִּשְׁאָרִים אֲשֶׁר־נִשְׁאֲרוּ מִן־הַשְּׁבִי שָׁם בַּמְּדִינָה בְּרָעָה גְדֹלָה וּבְחֶרְפָּה וְחוֹמַת יְרוּשָׁלַ͏ִם מְפֹרָצֶת וּשְׁעָרֶיהָ נִצְּתוּ בָאֵשׁ׃}
}
{
	\eX{
		And they said to me, The survivors who are left from the
		captivity there in the province are in a great bad state and in
		disgrace, and Jerusalem's wall is broken down, and its gates
		have been burned with fire.
	}
}
{
}

\Verse{4}
{
	\hX{וַיְהִי כְּשׁמְעִי אֶת־הַדְּבָרִים הָאֵלֶּה יָשַׁבְתִּי וָאֶבְכֶּה וָאֶתְאַבְּלָה יָמִים וָאֱהִי צָם וּמִתְפַּלֵּל לִפְנֵי אֱלֹהֵי הַשָּׁמָיִם׃}
}
{
	\eX{
		And it was, when I heard these words, that I sat down and wept
		and mourned for days, and I was fasting and praying before the
		God of the skies.
	}
}
{
}

\Verse{5}
{
	\hX{וָאֹמַר אָנָּא יְהֹוָה אֱלֹהֵי הַשָּׁמַיִם הָאֵל הַגָּדוֹל וְהַנּוֹרָא שֹׁמֵר הַבְּרִית וָחֶסֶד לְאֹהֲבָיו וּלְשֹׁמְרֵי מִצְוֺתָיו׃}
}
{
	\eX{
		And I said, I ask, YHWH God of the skies, the great and fearsome
		God, who keeps covenant and loyalty for those who love Him and
		observe His commandments:
	}
}
{
}

\Verse{6}
{
	\hX{
		תְּהִי נָא אזְנְךָ־קַשֶּׁבֶת וְעֵינֶיךָ פְתוּחוֹת לִשְׁמֹעַ אֶל־תְּפִלַּת עַבְדְּךָ אֲשֶׁר אָנֹכִי מִתְפַּלֵּל לְפָנֶיךָ הַיּוֹם יוֹמָם וָלַיְלָה עַל־בְּנֵי יִשְׂרָאֵל עֲבָדֶיךָ
		וּמִתְוַדֶּה עַל־חַטֹּאות בְּנֵי־יִשְׂרָאֵל אֲשֶׁר חָטָאנוּ לָךְ וַאֲנִי וּבֵית־אָבִי חָטָאנוּ׃
	}
}
{
	\eX{
		Let Your ear now be attentive and Your eyes open, to listen to
		Your servant's prayer, that I pray before You now, day and
		night, for the children of Israel Your servants, and confessing
		the sins of the children of Israel, that we have sinned against
		You. And I and my father's house have sinned.
	}
}
{
}

\Verse{7}
{
	\hX{חֲבֹל חָבַלְנוּ לָךְ וְלֹא־שָׁמַרְנוּ אֶת־הַמִּצְוֺת וְאֶת־הַחֻקִּים וְאֶת־הַמִּשְׁפָּטִים אֲשֶׁר צִוִּיתָ אֶת־מֹשֶׁה עַבְדֶּךָ׃}
}
{
	\eX{
		We have dealt corruptly against You, and we have not observed
		the commandments and the laws and the judgments that You
		commanded Moses Your servant.
	}
}
{
}

\Verse{8}
{
	\hX{זְכר־נָא אֶת־הַדָּבָר אֲשֶׁר צִוִּיתָ אֶת־מֹשֶׁה עַבְדְּךָ לֵאמֹר אַתֶּם תִּמְעָלוּ אֲנִי אָפִיץ אֶתְכֶם בָּעַמִּים׃}
}
{
	\eX{
		Remember, please, the word that You commanded Moses Your
		servant, saying: If you act unfaithfully, I'll scatter you among
		the peoples.
	}
}
{
}

\Verse{9}
{
	\hX{
		וְשַׁבְתֶּם אֵלַי וּשְׁמַרְתֶּם מִצְוֺתַי וַעֲשִׂיתֶם אֹתָם אִם־יִהְיֶה נִדַּחֲכֶם בִּקְצֵה הַשָּׁמַיִם מִשָּׁם אֲקַבְּצֵם (והבואתים) [וַהֲבִיאוֹתִים] אֶל־הַמָּקוֹם אֲשֶׁר
		בָּחַרְתִּי לְשַׁכֵּן אֶת־שְׁמִי שָׁם׃
	}
}
{
	\eX{
		And if you return to Me and observe My commandments and do them,
		if your scattered ones are at the end of the skies, from there
		I'll gather them and bring them to the place where I chose to
		make My name live.
	}
}
{
}

\Verse{10}
{
	\hX{וְהֵם עֲבָדֶיךָ וְעַמֶּךָ אֲשֶׁר פָּדִיתָ בְּכֹחֲךָ הַגָּדוֹל וּבְיָדְךָ הַחֲזָקָה׃}
}
{
	\eX{
		And they are Your servants and Your people, whom You redeemed by
		Your great power and by Your strong hand.
	}
}
{
}

\Verse{11}
{
	\hX{
		אָנָּא אֲדֹנָי תְּהִי נָא אזְנְךָ־קַשֶּׁבֶת אֶל־תְּפִלַּת עַבְדְּךָ וְאֶל־תְּפִלַּת עֲבָדֶיךָ הַחֲפֵצִים לְיִרְאָה אֶת־שְׁמֶךָ וְהַצְלִיחָה־נָּא לְעַבְדְּךָ הַיּוֹם וּתְנֵהוּ
		לְרַחֲמִים לִפְנֵי הָאִישׁ הַזֶּה וַאֲנִי הָיִיתִי מַשְׁקֶה לַמֶּלֶךְ׃
	}
}
{
	\eX{
		Please, my Lord, let Your ear be attentive to Your servant's
		prayer and to the prayer of Your servants who desire to fear
		Your name. And give success, please, to Your servant today, and
		give him mercy in front of this man. And I was cupbearer to the
		king.
	}
}
{
}
