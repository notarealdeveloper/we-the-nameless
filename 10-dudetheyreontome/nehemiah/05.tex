\Chapter{5}

\Verse{1}
{
	\hX{וַתְּהִי צַעֲקַת הָעָם וּנְשֵׁיהֶם גְּדוֹלָה אֶל־אֲחֵיהֶם הַיְּהוּדִים׃}
}
{
	\eX{
		There was a great outcry by the common folk and their wives
		against their brother Jews.
	}
}
{
}

\Verse{2}
{
	\hX{וְיֵשׁ אֲשֶׁר אֹמְרִים בָּנֵינוּ וּבְנֹתֵינוּ אֲנַחְנוּ רַבִּים וְנִקְחָה דָגָן וְנֹאכְלָה וְנִחְיֶה׃}
}
{
	\eX{
		Some said, “Our sons and daughters are numerous; we must get grain
		to eat in order that we may live!”
	}
}
{
}

\Verse{3}
{
	\hX{וְיֵשׁ אֲשֶׁר אֹמְרִים שְׂדֹתֵינוּ וּכְרָמֵינוּ וּבָתֵּינוּ אֲנַחְנוּ עֹרְבִים וְנִקְחָה דָגָן בָּרָעָב׃}
}
{
	\eX{
		Others said, “We must pawn our fields, our vineyards, and our
		homes to get grain to stave off hunger.”
	}
}
{
}

\Verse{4}
{
	\hX{וְיֵשׁ אֲשֶׁר אֹמְרִים לָוִינוּ כֶסֶף לְמִדַּת הַמֶּלֶךְ שְׂדֹתֵינוּ וּכְרָמֵינוּ׃}
}
{
	\eX{
		Yet others said, “We have borrowed money against our fields and
		vineyards to pay the king’s tax.
	}
}
{
}

\Verse{5}
{
	\hX{
		וְעַתָּה כִּבְשַׂר אַחֵינוּ בְּשָׂרֵנוּ כִּבְנֵיהֶם בָּנֵינוּ וְהִנֵּה אֲנַחְנוּ כֹבְשִׁים אֶת־בָּנֵינוּ וְאֶת־בְּנֹתֵינוּ לַעֲבָדִים וְיֵשׁ מִבְּנֹתֵינוּ נִכְבָּשׁוֹת וְאֵין לְאֵל
		יָדֵנוּ וּשְׂדֹתֵינוּ וּכְרָמֵינוּ לַאֲחֵרִים׃
	}
}
{
	\eX{
		Now we are as good as our brothers, and our children as good as
		theirs; yet here we are subjecting our sons and daughters to
		slavery—some of our daughters are already subjected—and we are
		powerless, while our fields and vineyards belong to others.”
	}
}
{
}

\Verse{6}
{
	\hX{וַיִּחַר לִי מְאֹד כַּאֲשֶׁר שָׁמַעְתִּי אֶת־זַעֲקָתָם וְאֵת הַדְּבָרִים הָאֵלֶּה׃}
}
{
	\eX{
		It angered me very much to hear their outcry and these complaints.
	}
}
{
}

\Verse{7}
{
	\hX{וַיִּמָּלֵךְ לִבִּי עָלַי וָאָרִיבָה אֶת־הַחֹרִים וְאֶת־הַסְּגָנִים וָאֹמְרָה לָהֶם מַשָּׁא אִישׁ־בְּאָחִיו אַתֶּם (נשאים) [נֹשִׁים] וָאֶתֵּן עֲלֵיהֶם קְהִלָּה גְדוֹלָה׃}
}
{
	\eX{
		After pondering the matter carefully, I censured the nobles and
		the prefects, saying, “Are you pressing claims on loans made to
		your brothers?” Then I raised a large crowd against them
	}
}
{
	Qere Ketiv.
}

\Verse{8}
{
	\hX{
		וָאֹמְרָה לָהֶם אֲנַחְנוּ קָנִינוּ אֶת־אַחֵינוּ הַיְּהוּדִים הַנִּמְכָּרִים לַגּוֹיִם כְּדֵי בָנוּ וְגַם־אַתֶּם תִּמְכְּרוּ אֶת־אֲחֵיכֶם וְנִמְכְּרוּ־לָנוּ וַיַּחֲרִישׁוּ וְלֹא
		מָצְאוּ דָּבָר׃
	}
}
{
	\eX{
		and said to them, “We have done our best to buy back our Jewish
		brothers who were sold to the nations; will you now sell your
		brothers so that they must be sold [back] to us?” They kept
		silent, for they found nothing to answer.
	}
}
{
}

\Verse{9}
{
	\hX{(ויאמר) [וָאוֹמַר] לֹא־טוֹב הַדָּבָר אֲשֶׁר־אַתֶּם עֹשִׂים הֲלוֹא בְּיִרְאַת אֱלֹהֵינוּ תֵּלֵכוּ מֵחֶרְפַּת הַגּוֹיִם אוֹיְבֵינוּ׃}
}
{
	\eX{
		So I continued, “What you are doing is not right. You ought to act
		in a God-fearing way so as not to give our enemies, the nations,
		room to reproach us.
	}
}
{
	Qere Ketiv.
}

\Verse{10}
{
	\hX{וְגַם־אֲנִי אַחַי וּנְעָרַי נֹשִׁים בָּהֶם כֶּסֶף וְדָגָן נַעַזְבָה־נָּא אֶת־הַמַּשָּׁא הַזֶּה׃}
}
{
	\eX{
		I, my brothers, and my servants also have claims of money and
		grain against them; let us now abandon those claims!
	}
}
{
}

\Verse{11}
{
	\hX{הָשִׁיבוּ נָא לָהֶם כְּהַיּוֹם שְׂדֹתֵיהֶם כַּרְמֵיהֶם זֵיתֵיהֶם וּבָתֵּיהֶם וּמְאַת הַכֶּסֶף וְהַדָּגָן הַתִּירוֹשׁ וְהַיִּצְהָר אֲשֶׁר אַתֶּם נֹשִׁים בָּהֶם׃}
}
{
	\eX{
		Give back at once their fields, their vineyards, their olive
		trees, and their homes, and [abandon] the claims for the hundred
		pieces of silver, the grain, the wine, and the oil that you have
		been pressing against them!”
	}
}
{
}

\Verse{12}
{
	\hX{וַיֹּאמְרוּ נָשִׁיב וּמֵהֶם לֹא נְבַקֵּשׁ כֵּן נַעֲשֶׂה כַּאֲשֶׁר אַתָּה אוֹמֵר וָאֶקְרָא אֶת־הַכֹּהֲנִים וָאַשְׁבִּיעֵם לַעֲשׂוֹת כַּדָּבָר הַזֶּה׃}
}
{
	\eX{
		They replied, “We shall give them back, and not demand anything of
		them; we shall do just as you say.” Summoning the priests, I put
		them under oath to keep this promise.
	}
}
{
}

\Verse{13}
{
	\hX{
		גַּם־חצְנִי נָעַרְתִּי וָאֹמְרָה כָּכָה יְנַעֵר הָאֱלֹהִים אֶת־כּל־הָאִישׁ אֲשֶׁר לֹא־יָקִים אֶת־הַדָּבָר הַזֶּה מִבֵּיתוֹ וּמִיגִיעוֹ וְכָכָה יִהְיֶה נָעוּר וָרֵק וַיֹּאמְרוּ
		כל־הַקָּהָל אָמֵן וַיְהַלְלוּ אֶת־יְהֹוָה וַיַּעַשׂ הָעָם כַּדָּבָר הַזֶּה׃
	}
}
{
	\eX{
		I also shook out the bosom of my garment and said, “So may God
		shake free of his household and property any man who fails to keep
		this promise; may he be thus shaken out and stripped.” All the
		assembled answered, “Amen,” and praised YHWH. The people kept this
		promise.
	}
}
{
}

\Verse{14}
{
	\hX{
		גַּם מִיּוֹם אֲשֶׁר־צִוָּה אוֹתִי לִהְיוֹת פֶּחָם בְּאֶרֶץ יְהוּדָה מִשְּׁנַת עֶשְׂרִים וְעַד שְׁנַת שְׁלֹשִׁים וּשְׁתַּיִם לְאַרְתַּחְשַׁסְתְּא הַמֶּלֶךְ שָׁנִים שְׁתֵּים עֶשְׂרֵה
		אֲנִי וְאַחַי לֶחֶם הַפֶּחָה לֹא אָכַלְתִּי׃
	}
}
{
	\eX{
		Furthermore, from the day I was commissioned to be governor in the
		land of Judah—from the twentieth year of King Artaxerxes until his
		thirty-second year, twelve years in all—neither I nor my brothers
		ever ate of the governor’s food allowance.
	}
}
{
}

\Verse{15}
{
	\hX{
		וְהַפַּחוֹת הָרִאשֹׁנִים אֲשֶׁר־לְפָנַי הִכְבִּידוּ עַל־הָעָם וַיִּקְחוּ מֵהֶם בְּלֶחֶם וָיַיִן אַחַר כֶּסֶף־שְׁקָלִים אַרְבָּעִים גַּם נַעֲרֵיהֶם שָׁלְטוּ עַל־הָעָם וַאֲנִי
		לֹא־עָשִׂיתִי כֵן מִפְּנֵי יִרְאַת אֱלֹהִים׃
	}
}
{
	\eX{
		The former governors who preceded me laid heavy burdens on the
		people, and took from them for bread and wine more than forty
		shekels of silver. Their servants also tyrannized over the people.
		But I, out of the fear of God, did not do so.
	}
}
{
}

\Verse{16}
{
	\hX{וְגַם בִּמְלֶאכֶת הַחוֹמָה הַזֹּאת הֶחֱזַקְתִּי וְשָׂדֶה לֹא קָנִינוּ וְכל־נְעָרַי קְבוּצִים שָׁם עַל־הַמְּלָאכָה׃}
}
{
	\eX{
		I also supported the work on this wall; we did not buy any land,
		and all my servants were gathered there at the work.
	}
}
{
}

\Verse{17}
{
	\hX{וְהַיְּהוּדִים וְהַסְּגָנִים מֵאָה וַחֲמִשִּׁים אִישׁ וְהַבָּאִים אֵלֵינוּ מִן־הַגּוֹיִם אֲשֶׁר־סְבִיבֹתֵינוּ עַל־שֻׁלְחָנִי׃}
}
{
	\eX{
		Although there were at my table, between Jews and prefects, one
		hundred and fifty men in all, beside those who came to us from
		surrounding nations;
	}
}
{
}

\Verse{18}
{
	\hX{
		וַאֲשֶׁר הָיָה נַעֲשֶׂה לְיוֹם אֶחָד שׁוֹר אֶחָד צֹאן שֵׁשׁ־בְּרֻרוֹת וְצִפֳּרִים נַעֲשׂוּ־לִי וּבֵין עֲשֶׂרֶת יָמִים בְּכל־יַיִן לְהַרְבֵּה וְעִם־זֶה לֶחֶם הַפֶּחָה לֹא
		בִקַּשְׁתִּי כִּי־כָבְדָה הָעֲבֹדָה עַל־הָעָם הַזֶּה׃
	}
}
{
	\eX{
		and although what was prepared for each day came to one ox, six
		select sheep, and fowl, all prepared for me, and at ten-day
		intervals all sorts of wine in abundance—yet I did not resort to
		the governor’s food allowance, for the [king’s] service lay
		heavily on the people.
	}
}
{
}

\Verse{19}
{
	\hX{זכְרָה־לִּי אֱלֹהַי לְטוֹבָה כֹּל אֲשֶׁר־עָשִׂיתִי עַל־הָעָם הַזֶּה׃}
}
{
	\eX{
		O my God, remember to my credit all that I have done for this
		people!
	}
}
{
}
