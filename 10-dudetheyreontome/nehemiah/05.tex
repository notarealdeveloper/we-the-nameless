\Chapter{5}

\Verse{1}
{
	\hX{וַתְּהִי צַעֲקַת הָעָם וּנְשֵׁיהֶם גְּדוֹלָה אֶל־אֲחֵיהֶם הַיְּהוּדִים׃}
}
{
	\eX{
		And there was a great cry of the people and of their wives
		against their brothers the Jews.
	}
}
{
}

\Verse{2}
{
	\hX{וְיֵשׁ אֲשֶׁר אֹמְרִים בָּנֵינוּ וּבְנֹתֵינוּ אֲנַחְנוּ רַבִּים וְנִקְחָה דָגָן וְנֹאכְלָה וְנִחְיֶה׃}
}
{
	\eX{
		For there were that said, We, our sons, and our daughters, are
		many: therefore we take up grain for them, that we may eat, and
		live.
	}
}
{
}

\Verse{3}
{
	\hX{וְיֵשׁ אֲשֶׁר אֹמְרִים שְׂדֹתֵינוּ וּכְרָמֵינוּ וּבָתֵּינוּ אֲנַחְנוּ עֹרְבִים וְנִקְחָה דָגָן בָּרָעָב׃}
}
{
	\eX{
		Some also there were that said, We have mortgaged our lands,
		vineyards, and houses, that we might buy grain, because of the
		dearth.
	}
}
{
}

\Verse{4}
{
	\hX{וְיֵשׁ אֲשֶׁר אֹמְרִים לָוִינוּ כֶסֶף לְמִדַּת הַמֶּלֶךְ שְׂדֹתֵינוּ וּכְרָמֵינוּ׃}
}
{
	\eX{
		There were also that said, We have borrowed money for the king's
		tribute, and that upon our lands and vineyards.
	}
}
{
}

\Verse{5}
{
	\hX{
		וְעַתָּה כִּבְשַׂר אַחֵינוּ בְּשָׂרֵנוּ כִּבְנֵיהֶם בָּנֵינוּ וְהִנֵּה אֲנַחְנוּ כֹבְשִׁים אֶת־בָּנֵינוּ וְאֶת־בְּנֹתֵינוּ לַעֲבָדִים וְיֵשׁ מִבְּנֹתֵינוּ נִכְבָּשׁוֹת וְאֵין לְאֵל
		יָדֵנוּ וּשְׂדֹתֵינוּ וּכְרָמֵינוּ לַאֲחֵרִים׃
	}
}
{
	\eX{
		Yet now our flesh is as the flesh of our brothers, our children
		as their children: and, here, we bring into slavery our sons and
		our daughters to be servants, and some of our daughters are
		brought to slavery already: nor is it in our power to redeem
		them; for other men have our lands and vineyards.
	}
}
{
}

\Verse{6}
{
	\hX{וַיִּחַר לִי מְאֹד כַּאֲשֶׁר שָׁמַעְתִּי אֶת־זַעֲקָתָם וְאֵת הַדְּבָרִים הָאֵלֶּה׃}
}
{
	\eX{And I was very angry when I heard their cry and these words.}
}
{
}

\Verse{7}
{
	\hX{וַיִּמָּלֵךְ לִבִּי עָלַי וָאָרִיבָה אֶת־הַחֹרִים וְאֶת־הַסְּגָנִים וָאֹמְרָה לָהֶם מַשָּׁא אִישׁ־בְּאָחִיו אַתֶּם (נשאים) [נֹשִׁים] וָאֶתֵּן עֲלֵיהֶם קְהִלָּה גְדוֹלָה׃}
}
{
	\eX{
		And I consulted with myself, and I rebuked the nobles, and the
		rulers, and said to them, You exact usury, everyone of his
		brother. And I set a great assembly against them.
	}
}
{
	Qere Ketiv.
}

\Verse{8}
{
	\hX{
		וָאֹמְרָה לָהֶם אֲנַחְנוּ קָנִינוּ אֶת־אַחֵינוּ הַיְּהוּדִים הַנִּמְכָּרִים לַגּוֹיִם כְּדֵי בָנוּ וְגַם־אַתֶּם תִּמְכְּרוּ אֶת־אֲחֵיכֶם וְנִמְכְּרוּ־לָנוּ וַיַּחֲרִישׁוּ וְלֹא
		מָצְאוּ דָּבָר׃
	}
}
{
	\eX{
		And I said to them, We after our ability have redeemed our
		brothers the Jews, that were sold to the nations; and will you
		sell your brothers, and shall they be sold to us? Then they were
		silent, and found nothing to answer.
	}
}
{
}

\Verse{9}
{
	\hX{(ויאמר) [וָאוֹמַר] לֹא־טוֹב הַדָּבָר אֲשֶׁר־אַתֶּם עֹשִׂים הֲלוֹא בְּיִרְאַת אֱלֹהֵינוּ תֵּלֵכוּ מֵחֶרְפַּת הַגּוֹיִם אוֹיְבֵינוּ׃}
}
{
	\eX{
		Also I said, It is not good that you do: ought you not to walk
		in the fear of our God because of the disgrace of the nations
		our enemies?
	}
}
{
	Qere Ketiv.
}

\Verse{10}
{
	\hX{וְגַם־אֲנִי אַחַי וּנְעָרַי נֹשִׁים בָּהֶם כֶּסֶף וְדָגָן נַעַזְבָה־נָּא אֶת־הַמַּשָּׁא הַזֶּה׃}
}
{
	\eX{
		I likewise, and my brothers, and my servants, might exact of
		them money and grain: please, let us leave off this usury.
	}
}
{
}

\Verse{11}
{
	\hX{הָשִׁיבוּ נָא לָהֶם כְּהַיּוֹם שְׂדֹתֵיהֶם כַּרְמֵיהֶם זֵיתֵיהֶם וּבָתֵּיהֶם וּמְאַת הַכֶּסֶף וְהַדָּגָן הַתִּירוֹשׁ וְהַיִּצְהָר אֲשֶׁר אַתֶּם נֹשִׁים בָּהֶם׃}
}
{
	\eX{
		Restore, please, to them, even this day, their lands, their
		vineyards, their oliveyards, and their houses, also the
		hundredth part of the money, and of the grain, the wine, and the
		oil, that you exact of them.
	}
}
{
}

\Verse{12}
{
	\hX{וַיֹּאמְרוּ נָשִׁיב וּמֵהֶם לֹא נְבַקֵּשׁ כֵּן נַעֲשֶׂה כַּאֲשֶׁר אַתָּה אוֹמֵר וָאֶקְרָא אֶת־הַכֹּהֲנִים וָאַשְׁבִּיעֵם לַעֲשׂוֹת כַּדָּבָר הַזֶּה׃}
}
{
	\eX{
		Then said they, We will restore them, and will require nothing
		of them; so will we do as you say. And I called the priests, and
		took an oath of them, that they should do according to this
		promise.
	}
}
{
}

\Verse{13}
{
	\hX{
		גַּם־חצְנִי נָעַרְתִּי וָאֹמְרָה כָּכָה יְנַעֵר הָאֱלֹהִים אֶת־כּל־הָאִישׁ אֲשֶׁר לֹא־יָקִים אֶת־הַדָּבָר הַזֶּה מִבֵּיתוֹ וּמִיגִיעוֹ וְכָכָה יִהְיֶה נָעוּר וָרֵק וַיֹּאמְרוּ
		כל־הַקָּהָל אָמֵן וַיְהַלְלוּ אֶת־יְהֹוָה וַיַּעַשׂ הָעָם כַּדָּבָר הַזֶּה׃
	}
}
{
	\eX{
		Also I shook my lap, and said, So God shake out every man from
		his house, and from his work, that performs not this promise,
		even thus be he shaken out, and emptied. And all the assembly
		said, Amen, and praised YHWH. And the people did according to
		this promise.
	}
}
{
}

\Verse{14}
{
	\hX{
		גַּם מִיּוֹם אֲשֶׁר־צִוָּה אוֹתִי לִהְיוֹת פֶּחָם בְּאֶרֶץ יְהוּדָה מִשְּׁנַת עֶשְׂרִים וְעַד שְׁנַת שְׁלֹשִׁים וּשְׁתַּיִם לְאַרְתַּחְשַׁסְתְּא הַמֶּלֶךְ שָׁנִים שְׁתֵּים עֶשְׂרֵה
		אֲנִי וְאַחַי לֶחֶם הַפֶּחָה לֹא אָכַלְתִּי׃
	}
}
{
	\eX{
		Moreover from the time that I was appointed to be their governor
		in the land of Judah, from the twentieth year to the
		thirty-second year of Artaxerxes the king, that is, twelve
		years, I and my brothers have not eaten the bread of the
		governor.
	}
}
{
}

\Verse{15}
{
	\hX{
		וְהַפַּחוֹת הָרִאשֹׁנִים אֲשֶׁר־לְפָנַי הִכְבִּידוּ עַל־הָעָם וַיִּקְחוּ מֵהֶם בְּלֶחֶם וָיַיִן אַחַר כֶּסֶף־שְׁקָלִים אַרְבָּעִים גַּם נַעֲרֵיהֶם שָׁלְטוּ עַל־הָעָם וַאֲנִי
		לֹא־עָשִׂיתִי כֵן מִפְּנֵי יִרְאַת אֱלֹהִים׃
	}
}
{
	\eX{
		But the former governors that had been before me were chargeable
		to the people, and had taken of them bread and wine, beside
		forty shekels of silver; yea, even their servants bare rule over
		the people: but so did not I, because of the fear of God.
	}
}
{
}

\Verse{16}
{
	\hX{וְגַם בִּמְלֶאכֶת הַחוֹמָה הַזֹּאת הֶחֱזַקְתִּי וְשָׂדֶה לֹא קָנִינוּ וְכל־נְעָרַי קְבוּצִים שָׁם עַל־הַמְּלָאכָה׃}
}
{
	\eX{
		And also I continued in the work of this wall, nor bought we any
		land: and all my servants were gathered there to the work.
	}
}
{
}

\Verse{17}
{
	\hX{וְהַיְּהוּדִים וְהַסְּגָנִים מֵאָה וַחֲמִשִּׁים אִישׁ וְהַבָּאִים אֵלֵינוּ מִן־הַגּוֹיִם אֲשֶׁר־סְבִיבֹתֵינוּ עַל־שֻׁלְחָנִי׃}
}
{
	\eX{
		Moreover there were at my table a hundred and fifty of the Jews
		and rulers, beside those that came to us from among the nations
		that are about us.
	}
}
{
}

\Verse{18}
{
	\hX{
		וַאֲשֶׁר הָיָה נַעֲשֶׂה לְיוֹם אֶחָד שׁוֹר אֶחָד צֹאן שֵׁשׁ־בְּרֻרוֹת וְצִפֳּרִים נַעֲשׂוּ־לִי וּבֵין עֲשֶׂרֶת יָמִים בְּכל־יַיִן לְהַרְבֵּה וְעִם־זֶה לֶחֶם הַפֶּחָה לֹא
		בִקַּשְׁתִּי כִּי־כָבְדָה הָעֲבֹדָה עַל־הָעָם הַזֶּה׃
	}
}
{
	\eX{
		Now that was prepared for me daily was one ox and six choice
		sheep; also birds were prepared for me, and once in ten days all
		kinds of wine in abundance: yet for all this I did not require
		the bread of the governor, because the slavery was heavy upon
		this people.
	}
}
{
}

\Verse{19}
{
	\hX{זכְרָה־לִּי אֱלֹהַי לְטוֹבָה כֹּל אֲשֶׁר־עָשִׂיתִי עַל־הָעָם הַזֶּה׃}
}
{
	\eX{
		Think upon me, my God, for good, according to all that I have
		done for this people.
	}
}
{
}
