\Chapter{3}

\Verse{1}
{
	\hX{וַיִּגַּע הַחֹדֶשׁ הַשְּׁבִיעִי וּבְנֵי יִשְׂרָאֵל בֶּעָרִיםוַיֵּאָסְפוּ הָעָם כְּאִישׁ אֶחָד אֶל־יְרוּשָׁלָ͏ִם׃}
}
{
	\eX{
		When the seventh month arrived—the Israelites being settled in
		their towns—the entire people assembled as one man in Jerusalem.
	}
}
{
}

\Verse{2}
{
	\hX{
		וַיָּקם יֵשׁוּעַ בֶּן־יוֹצָדָק וְאֶחָיו הַכֹּהֲנִים וּזְרֻבָּבֶל בֶּן־שְׁאַלְתִּיאֵל וְאֶחָיו וַיִּבְנוּ אֶת־מִזְבַּח אֱלֹהֵי יִשְׂרָאֵל לְהַעֲלוֹת עָלָיו עֹלוֹת כַּכָּתוּב
		בְּתוֹרַת מֹשֶׁה אִישׁ־הָאֱלֹהִים׃
	}
}
{
	\eX{
		Then Jeshua son of Jozadak and his brother priests, and Zerubbabel
		son of Shealtiel and his brothers set to and built the altar of
		the God of Israel to offer burnt offerings upon it as is written
		in the Teaching of Moses, the man of God.
	}
}
{
}

\Verse{3}
{
	\hX{וַיָּכִינוּ הַמִּזְבֵּחַ עַל־מְכוֹנֹתָיו כִּי בְּאֵימָה עֲלֵיהֶם מֵעַמֵּי הָאֲרָצוֹת (ויעל) [וַיַּעֲלוּ] עָלָיו עֹלוֹת לַיהֹוָה עֹלוֹת לַבֹּקֶר וְלָעָרֶב׃}
}
{
	\eX{
		They set up the altar on its site because they were in fear of the
		peoples of the land, and they offered burnt offerings on it to
		YHWH, burnt offerings each morning and evening.
	}
}
{
	Qere Ketiv.
}

\Verse{4}
{
	\hX{וַיַּעֲשׂוּ אֶת־חַג הַסֻּכּוֹת כַּכָּתוּב וְעֹלַת יוֹם בְּיוֹם בְּמִסְפָּר כְּמִשְׁפַּט דְּבַר־יוֹם בְּיוֹמוֹ׃}
}
{
	\eX{
		Then they celebrated the festival of Tabernacles as is written,
		with its daily burnt offerings in the proper quantities, on each
		day as is prescribed for it,
	}
}
{
}

\Verse{5}
{
	\hX{וְאַחֲרֵי־כֵן עֹלַת תָּמִיד וְלֶחֳדָשִׁים וּלְכל־מוֹעֲדֵי יְהֹוָה הַמְקֻדָּשִׁים וּלְכֹל מִתְנַדֵּב נְדָבָה לַיהֹוָה׃}
}
{
	\eX{
		followed by the regular burnt offering and the offerings for the
		new moons and for all the sacred fixed times of YHWH, and whatever
		freewill offerings were made to YHWH.
	}
}
{
}

\Verse{6}
{
	\hX{מִיּוֹם אֶחָד לַחֹדֶשׁ הַשְּׁבִיעִי הֵחֵלּוּ לְהַעֲלוֹת עֹלוֹת לַיהֹוָה וְהֵיכַל יְהֹוָה לֹא יֻסָּד׃}
}
{
	\eX{
		From the first day of the seventh month they began to make burnt
		offerings to YHWH, though the foundation of the Temple of YHWH had
		not been laid.
	}
}
{
}

\Verse{7}
{
	\hX{
		וַיִּתְּנוּ־כֶסֶף לַחֹצְבִים וְלֶחָרָשִׁים וּמַאֲכָל וּמִשְׁתֶּה וָשֶׁמֶן לַצִּדֹנִים וְלַצֹּרִים לְהָבִיא עֲצֵי אֲרָזִים מִן־הַלְּבָנוֹן אֶל־יָם יָפוֹא כְּרִשְׁיוֹן כּוֹרֶשׁ
		מֶלֶךְ־פָּרַס עֲלֵיהֶם׃
	}
}
{
	\eX{
		They paid the hewers and craftsmen with money, and the Sidonians
		and Tyrians with food, drink, and oil to bring cedarwood from
		Lebanon by sea to Joppa, in accord with the authorization granted
		them by King Cyrus of Persia.
	}
}
{
}

\Verse{8}
{
	\hX{
		וּבַשָּׁנָה הַשֵּׁנִית לְבוֹאָם אֶל־בֵּית הָאֱלֹהִים לִירוּשָׁלַ͏ִם בַּחֹדֶשׁ הַשֵּׁנִי הֵחֵלּוּ זְרֻבָּבֶל בֶּן־שְׁאַלְתִּיאֵל וְיֵשׁוּעַ בֶּן־יוֹצָדָק וּשְׁאָר אֲחֵיהֶם
		הַכֹּהֲנִים וְהַלְוִיִּם וְכל־הַבָּאִים מֵהַשְּׁבִי יְרוּשָׁלַ͏ִם וַיַּעֲמִידוּ אֶת־הַלְוִיִּם מִבֶּן עֶשְׂרִים שָׁנָה וָמַעְלָה לְנַצֵּחַ עַל־מְלֶאכֶת בֵּית־יְהֹוָה׃
	}
}
{
	\eX{
		In the second year after their arrival at the House of God, at
		Jerusalem, in the second month, Zerubbabel son of Shealtiel and
		Jeshua son of Jozadak, and the rest of their brother priests and
		Levites, and all who had come from the captivity to Jerusalem, as
		their first step appointed Levites from the age of twenty and
		upward to supervise the work of the House of YHWH.
	}
}
{
}

\Verse{9}
{
	\hX{וַיַּעֲמֹד יֵשׁוּעַ בָּנָיו וְאֶחָיו קַדְמִיאֵל וּבָנָיו בְּנֵי־יְהוּדָה כְּאֶחָד לְנַצֵּחַ עַל־עֹשֵׂה הַמְּלָאכָה בְּבֵית הָאֱלֹהִיםבְּנֵי חֵנָדָד בְּנֵיהֶם וַאֲחֵיהֶם הַלְוִיִּם׃}
}
{
	\eX{
		Jeshua, his sons and brothers, Kadmiel and his sons, the sons of
		Judah, together were appointed in charge of those who did the work
		in the House of God; also the sons of Henadad, their sons and
		brother Levites.
	}
}
{
}

\Verse{10}
{
	\hX{
		וְיִסְּדוּ הַבֹּנִים אֶת־הֵיכַל יְהֹוָה וַיַּעֲמִידוּ הַכֹּהֲנִים מְלֻבָּשִׁים בַּחֲצֹצְרוֹת וְהַלְוִיִּם בְּנֵי־אָסָף בַּמְצִלְתַּיִם לְהַלֵּל אֶת־יְהֹוָה עַל־יְדֵי דָּוִיד
		מֶלֶךְ־יִשְׂרָאֵל׃
	}
}
{
	\eX{
		When the builders had laid the foundation of the Temple of YHWH,
		priests in their vestments with trumpets, and Levites sons of
		Asaph with cymbals were stationed to give praise to YHWH, as King
		David of Israel had ordained.
	}
}
{
}

\Verse{11}
{
	\hX{וַיַּעֲנוּ בְּהַלֵּל וּבְהוֹדֹת לַיהֹוָה כִּי טוֹב כִּי־לְעוֹלָם חַסְדּוֹ עַל־יִשְׂרָאֵל וְכל־הָעָם הֵרִיעוּ תְרוּעָה גְדוֹלָה בְהַלֵּל לַיהֹוָה עַל הוּסַד בֵּית־יְהֹוָה׃}
}
{
	\eX{
		They sang songs extolling and praising YHWH, “For He is good, His
		steadfast love for Israel is eternal.” All the people raised a
		great shout extolling YHWH because the foundation of the House of
		YHWH had been laid.
	}
}
{
}

\Verse{12}
{
	\hX{
		וְרַבִּים מֵהַכֹּהֲנִים וְהַלְוִיִּם וְרָאשֵׁי הָאָבוֹת הַזְּקֵנִים אֲשֶׁר רָאוּ אֶת־הַבַּיִת הָרִאשׁוֹן בְּיסְדוֹ זֶה הַבַּיִת בְּעֵינֵיהֶם בֹּכִים בְּקוֹל גָּדוֹל וְרַבִּים
		בִּתְרוּעָה בְשִׂמְחָה לְהָרִים קוֹל׃
	}
}
{
	\eX{
		Many of the priests and Levites and the chiefs of the clans, the
		old men who had seen the first house, wept loudly at the sight of
		the founding of this house. Many others shouted joyously at the
		top of their voices.
	}
}
{
}

\Verse{13}
{
	\hX{וְאֵין הָעָם מַכִּירִים קוֹל תְּרוּעַת הַשִּׂמְחָה לְקוֹל בְּכִי הָעָם כִּי הָעָם מְרִיעִים תְּרוּעָה גְדוֹלָה וְהַקּוֹל נִשְׁמַע עַד־לְמֵרָחוֹק׃}
}
{
	\eX{
		The people could not distinguish the shouts of joy from the
		people’s weeping, for the people raised a great shout, the sound
		of which could be heard from afar.
	}
}
{
}
