{
	\hX{וּמִבְּנֵי הַכֹּהֲנִים בְּנֵי חֳבַיָּה בְּנֵי הַקּוֹץ בְּנֵי בַרְזִלַּי אֲשֶׁר לָקַח מִבְּנוֹת בַּרְזִלַּי הַגִּלְעָדִי אִשָּׁה וַיִּקָּרֵא עַל־שְׁמָם׃}
}
{
	\eX{
		And of the children of the priests: the children of Habaiah, the

		their name:
	}
}
{
}

\Verse{62}
{
	\hX{אֵלֶּה בִּקְשׁוּ כְתָבָם הַמִּתְיַחְשִׂים וְלֹא נִמְצָאוּ וַיְגֹאֲלוּ מִן־הַכְּהֻנָּה׃}
}
{
	\eX{
		These sought their register among those that were reckoned by
		genealogy, but they weren't found: therefore were they, as
		impure, put from the priesthood.
	}
}
{

%		Footnote 2:62. The priests without a written genealogy are excluded from the
%		priesthood. In this book, ink can decide holiness. A missing document is a cultic
%		event.
