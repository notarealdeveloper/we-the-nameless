\Chapter{1}

\Verse{1}
{
	\hX{
		וּבִשְׁנַת אַחַת לְכוֹרֶשׁ מֶלֶךְ פָּרַס לִכְלוֹת דְּבַר־יְהֹוָה מִפִּי יִרְמְיָה הֵעִיר יְהֹוָה אֶת־רוּחַ כֹּרֶשׁ מֶלֶךְ־פָּרַס וַיַּעֲבֶר־קוֹל בְּכל־מַלְכוּתוֹ וְגַם־בְּמִכְתָּב
		לֵאמֹר׃
	}
}
{
	\eX{
		And in the first year of Cyrus king of Persia, to finish YHWH's
		word from the mouth of Jeremiah, YHWH stirred the spirit of
		Cyrus king of Persia, and he passed a voice through all his
		kingdom, and also in writing, saying:
	}
}
{
%	\footnote{
%		Footnote 1:1. Cyrus' spirit is stirred by YHWH, and the exiles' spirits are
%		stirred by God in v. 5. Empire and return move by the same verb. The text is not
%		subtle about who has the hand on the switch.
%	}
}

\Verse{2}
{
	\hX{כֹּה אָמַר כֹּרֶשׁ מֶלֶךְ פָּרַס כֹּל מַמְלְכוֹת הָאָרֶץ נָתַן לִי יְהֹוָה אֱלֹהֵי הַשָּׁמָיִם וְהוּא־פָקַד עָלַי לִבְנוֹת־לוֹ בַיִת בִּירוּשָׁלַ͏ִם אֲשֶׁר בִּיהוּדָה׃}
}
{
	\eX{
		Thus says Cyrus king of Persia: YHWH, God of the skies, has
		given me all the kingdoms of the earth, and He has charged me to
		build Him a house in Jerusalem, that is in Judah.
	}
}
{
}

\Verse{3}
{
	\hX{מִי־בָכֶם מִכּל־עַמּוֹ יְהִי אֱלֹהָיו עִמּוֹ וְיַעַל לִירוּשָׁלַ͏ִם אֲשֶׁר בִּיהוּדָה וְיִבֶן אֶת־בֵּית יְהֹוָה אֱלֹהֵי יִשְׂרָאֵל הוּא הָאֱלֹהִים אֲשֶׁר בִּירוּשָׁלָ͏ִם׃}
}
{
	\eX{
		Who among you is from all His people? May his God be with him,
		and let him go up to Jerusalem, that is in Judah, and build the
		house of YHWH, God of Israel: He is the God who is in Jerusalem.
	}
}
{
}

\Verse{4}
{
	\hX{
		וְכל־הַנִּשְׁאָר מִכּל־הַמְּקֹמוֹת אֲשֶׁר הוּא גָר־שָׁם יְנַשְּׂאוּהוּ אַנְשֵׁי מְקֹמוֹ בְּכֶסֶף וּבְזָהָב וּבִרְכוּשׁ וּבִבְהֵמָה עִם־הַנְּדָבָה לְבֵית הָאֱלֹהִים אֲשֶׁר
		בִּירוּשָׁלָ͏ִם׃
	}
}
{
	\eX{
		And everyone who remains, from all the places where he lives as
		an alien, let the men of his place lift him up with silver and
		with gold and with goods and with animals, besides the freewill
		offering for the house of God that is in Jerusalem.
	}
}
{
}

\Verse{5}
{
	\hX{וַיָּקוּמוּ רָאשֵׁי הָאָבוֹת לִיהוּדָה וּבִנְיָמִן וְהַכֹּהֲנִים וְהַלְוִיִּם לְכֹל הֵעִיר הָאֱלֹהִים אֶת־רוּחוֹ לַעֲלוֹת לִבְנוֹת אֶת־בֵּית יְהֹוָה אֲשֶׁר בִּירוּשָׁלָ͏ִם׃}
}
{
	\eX{
		And the heads of the fathers of Judah and Benjamin, and the
		priests and the Levites, got up: everyone whose spirit God had
		stirred to go up to build the house of YHWH that is in
		Jerusalem.
	}
}
{
}

\Verse{6}
{
	\hX{וְכל־סְבִיבֹתֵיהֶם חִזְּקוּ בִידֵיהֶם בִּכְלֵי־כֶסֶף בַּזָּהָב בָּרְכוּשׁ וּבַבְּהֵמָה וּבַמִּגְדָּנוֹת לְבַד עַל־כּל־הִתְנַדֵּב׃}
}
{
	\eX{
		And all who were around them strengthened their hands with
		things of silver, with gold, with goods, and with animals, and
		with precious things, besides all that was freely offered.
	}
}
{
}

\Verse{7}
{
	\hX{וְהַמֶּלֶךְ כּוֹרֶשׁ הוֹצִיא אֶת־כְּלֵי בֵית־יְהֹוָה אֲשֶׁר הוֹצִיא נְבוּכַדְנֶצַּר מִירוּשָׁלַ͏ִם וַיִּתְּנֵם בְּבֵית אֱלֹהָיו׃}
}
{
	\eX{
		And King Cyrus brought out the things of the house of YHWH, that
		Nebuchadnezzar had brought out from Jerusalem and had put in the
		house of his god.
	}
}
{
}

\Verse{8}
{
	\hX{וַיּוֹצִיאֵם כּוֹרֶשׁ מֶלֶךְ פָּרַס עַל־יַד מִתְרְדָת הַגִּזְבָּר וַיִּסְפְּרֵם לְשֵׁשְׁבַּצַּר הַנָּשִׂיא לִיהוּדָה׃}
}
{
	\eX{
		And Cyrus king of Persia brought them out by the hand of
		Mithredath the treasurer, and he counted them out to Sheshbazzar
		the chieftain of Judah.
	}
}
{
%	\footnote{
%		Footnote 1:8. Sheshbazzar is called the chieftain of Judah. The title keeps the
%		old tribal word inside the Persian administrative world. Bureaucracy has arrived,
%		but the old names haven't left.
%	}
}

\Verse{9}
{
	\hX{וְאֵלֶּה מִסְפָּרָם אֲגַרְטְלֵי זָהָב שְׁלֹשִׁים אֲגַרְטְלֵי־כֶסֶף אָלֶף מַחֲלָפִים תִּשְׁעָה וְעֶשְׂרִים׃}
}
{
	\eX{
		And these are their number: thirty gold basins, a thousand
		silver basins, twenty-nine knives,
	}
}
{
}

\Verse{10}
{
	\hX{כְּפוֹרֵי זָהָב שְׁלֹשִׁים כְּפוֹרֵי כֶסֶף מִשְׁנִים אַרְבַּע מֵאוֹת וַעֲשָׂרָה כֵּלִים אֲחֵרִים אָלֶף׃}
}
{
	\eX{
		thirty gold bowls, four hundred ten second-grade silver bowls,
		and a thousand other things.
	}
}
{
}

\Verse{11}
{
	\hX{כּל־כֵּלִים לַזָּהָב וְלַכֶּסֶף חֲמֵשֶׁת אֲלָפִים וְאַרְבַּע מֵאוֹת הַכֹּל הֶעֱלָה שֵׁשְׁבַּצַּר עִם הֵעָלוֹת הַגּוֹלָה מִבָּבֶל לִירוּשָׁלָ͏ִם׃}
}
{
	\eX{
		All the things of gold and of silver were five thousand four
		hundred. Sheshbazzar brought all up when the exile was brought
		up from Babylon to Jerusalem.
	}
}
{
}
