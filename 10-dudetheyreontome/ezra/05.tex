\Chapter{5}

\Verse{1}
{
	\hX{וְהִתְנַבִּי חַגַּי (נביאה) [נְבִיָּא] וּזְכַרְיָה בַר־עִדּוֹא נְבִיַּאיָּא עַל־יְהוּדָיֵא דִּי בִיהוּד וּבִירוּשְׁלֶם בְּשֻׁם אֱלָהּ יִשְׂרָאֵל עֲלֵיהוֹן׃}
}
{
	\eX{
		Then the prophets, Haggai the prophet and Zechariah son of Iddo,
		prophesied to the Jews in Judah and Jerusalem, inspired by the God
		of Israel.
	}
}
{
	Qere Ketiv.
}

\Verse{2}
{
	\hX{בֵּאדַיִן קָמוּ זְרֻבָּבֶל בַּר־שְׁאַלְתִּיאֵל וְיֵשׁוּעַ בַּר־יוֹצָדָק וְשָׁרִיו לְמִבְנֵא בֵּית אֱלָהָא דִּי בִירוּשְׁלֶם וְעִמְּהוֹן נְבִיַּאיָּא דִי־אֱלָהָא מְסָעֲדִין לְהוֹן׃}
}
{
	\eX{
		Thereupon Zerubbabel son of Shealtiel and Jeshua son of Jozadak
		began rebuilding the House of God in Jerusalem, with the full
		support of the prophets of God.
	}
}
{
}

\Verse{3}
{
	\hX{
		בֵּהּ־זִמְנָא אֲתָה עֲלֵיהוֹן תַּתְּנַי פַּחַת עֲבַר־נַהֲרָה וּשְׁתַר בּוֹזְנַי וּכְנָוָתְהוֹן וְכֵן אָמְרִין לְהֹם מַן־שָׂם לְכֹם טְעֵם בַּיְתָא דְנָה לִבְּנֵא וְאֻשַּׁרְנָא דְנָה
		לְשַׁכְלָלָה׃
	}
}
{
	\eX{
		At once Tattenai, governor of the province of Beyond the River,
		Shethar-bozenai, and their colleagues descended upon them and said
		this to them, “Who issued orders to you to rebuild this house and
		complete its furnishing?”
	}
}
{
}

\Verse{4}
{
	\hX{אֱדַיִן כְּנֵמָא אֲמַרְנָא לְּהֹם מַן־אִנּוּן שְׁמָהָת גֻּבְרַיָּא דִּי־דְנָה בִנְיָנָא בָּנַיִן׃}
}
{
	\eX{
		Then we said to them, “What are the names of the men who are
		engaged in the building?”
	}
}
{
}

\Verse{5}
{
	\hX{וְעֵין אֱלָהֲהֹם הֲוָת עַל־שָׂבֵי יְהוּדָיֵא וְלָא־בַטִּלוּ הִמּוֹ עַד־טַעְמָא לְדָרְיָוֶשׁ יְהָךְ וֶאֱדַיִן יְתִיבוּן נִשְׁתְּוָנָא עַל־דְּנָה׃}
}
{
	\eX{
		But God watched over the elders of the Jews and they were not
		stopped while a report went to Darius and a letter was sent back
		in reply to it.
	}
}
{
}

\Verse{6}
{
	\hX{פַּרְשֶׁגֶן אִגַּרְתָּא דִּי־שְׁלַח תַּתְּנַי פַּחַת עֲבַר־נַהֲרָה וּשְׁתַר בּוֹזְנַי וּכְנָוָתֵהּ אֲפַרְסְכָיֵא דִּי בַּעֲבַר נַהֲרָה עַל־דָּרְיָוֶשׁ מַלְכָּא׃}
}
{
	\eX{
		This is the text of the letter that Tattenai, governor of the
		province of Beyond the River, and Shethar-bozenai and his
		colleagues, the officials of Beyond the River, sent to King
		Darius.
	}
}
{
}

\Verse{7}
{
	\hX{פִּתְגָמָא שְׁלַחוּ עֲלוֹהִי וְכִדְנָה כְּתִיב בְּגַוֵּהּ לְדָרְיָוֶשׁ מַלְכָּא שְׁלָמָא כֹלָּא׃}
}
{
	\eX{
		They sent a message to him and this is what was written in it: “To
		King Darius, greetings, and so forth.
	}
}
{
}

\Verse{8}
{
	\hX{
		יְדִיעַ לֶהֱוֵא לְמַלְכָּא דִּי־אֲזַלְנָא לִיהוּד מְדִינְתָּא לְבֵית אֱלָהָא רַבָּא וְהוּא מִתְבְּנֵא אֶבֶן גְּלָל וְאָע מִתְּשָׂם בְּכֻתְלַיָּא וַעֲבִידְתָּא דָךְ אסְפַּרְנָא
		מִתְעַבְדָא וּמַצְלַח בְּיֶדְהֹם׃
	}
}
{
	\eX{
		Be it known to the king, that we went to the province of Judah, to
		the house of the great God. It is being rebuilt of hewn stone, and
		wood is being laid in the walls. The work is being done with
		dispatch and is going well.
	}
}
{
}

\Verse{9}
{
	\hX{אֱדַיִן שְׁאֵלְנָא לְשָׂבַיָּא אִלֵּךְ כְּנֵמָא אֲמַרְנָא לְּהֹם מַן־שָׂם לְכֹם טְעֵם בַּיְתָא דְנָה לְמִבְנְיָה וְאֻשַּׁרְנָא דְנָה לְשַׁכְלָלָה׃}
}
{
	\eX{
		Thereupon we directed this question to these elders, ‘Who issued
		orders to you to rebuild this house and to complete its
		furnishings?’
	}
}
{
}

\Verse{10}
{
	\hX{וְאַף שְׁמָהָתְהֹם שְׁאֵלְנָא לְּהֹם לְהוֹדָעוּתָךְ דִּי נִכְתֻּב שֻׁם־גֻּבְרַיָּא דִּי בְרָאשֵׁיהֹם׃}
}
{
	\eX{
		We also asked their names so that we could write down the names of
		their leaders for your information.
	}
}
{
}

\Verse{11}
{
	\hX{
		וּכְנֵמָא פִתְגָמָא הֲתִיבוּנָא לְמֵמַר אֲנַחְנָא הִמּוֹ עַבְדוֹהִי דִי־אֱלָהּ שְׁמַיָּא וְאַרְעָא וּבָנַיִן בַּיְתָא דִּי־הֲוָא בְנֵה מִקַּדְמַת דְּנָה שְׁנִין שַׂגִּיאָן וּמֶלֶךְ
		לְיִשְׂרָאֵל רַב בְּנָהִי וְשַׁכְלְלֵהּ׃
	}
}
{
	\eX{
		This is what they answered us: ‘We are the servants of the God of
		heaven and earth; we are rebuilding the house that was originally
		built many years ago; a great king of Israel built it and
		completed it.
	}
}
{
}

\Verse{12}
{
	\hX{לָהֵן מִן־דִּי הַרְגִּזוּ אֲבָהָתַנָא לֶאֱלָהּ שְׁמַיָּא יְהַב הִמּוֹ בְּיַד נְבוּכַדְנֶצַּר מֶלֶךְ־בָּבֶל (כסדיא) [כַּסְדָּאָה] וּבַיְתָה דְנָה סַתְרֵהּ וְעַמָּה הַגְלִי לְבָבֶל׃}
}
{
	\eX{
		But because our fathers angered the God of Heaven, He handed them
		over to Nebuchadnezzar the Chaldean, king of Babylon, who
		demolished this house and exiled the people to Babylon.
	}
}
{
	Qere Ketiv.
}

\Verse{13}
{
	\hX{בְּרַם בִּשְׁנַת חֲדָה לְכוֹרֶשׁ מַלְכָּא דִּי בָבֶל כּוֹרֶשׁ מַלְכָּא שָׂם טְעֵם בֵּית־אֱלָהָא דְנָה לִבְּנֵא׃}
}
{
	\eX{
		But in the first year of King Cyrus of Babylon, King Cyrus issued
		an order to rebuild this House of God.
	}
}
{
}

\Verse{14}
{
	\hX{
		וְאַף מָאנַיָּא דִי־בֵית־אֱלָהָא דִּי דַהֲבָה וְכַסְפָּא דִּי נְבוּכַדְנֶצַּר הַנְפֵּק מִן־הֵיכְלָא דִּי בִירוּשְׁלֶם וְהֵיבֵל הִמּוֹ לְהֵיכְלָא דִּי בָבֶל הַנְפֵּק הִמּוֹ כּוֹרֶשׁ
		מַלְכָּא מִן־הֵיכְלָא דִּי בָבֶל וִיהִיבוּ לְשֵׁשְׁבַּצַּר שְׁמֵהּ דִּי פֶחָה שָׂמֵהּ׃
	}
}
{
	\eX{
		Also the silver and gold vessels of the House of God that
		Nebuchadnezzar had taken away from the temple in Jerusalem and
		brought to the temple in Babylon—King Cyrus released them from the
		temple in Babylon to be given to the one called Sheshbazzar whom
		he had appointed governor.
	}
}
{
}

\Verse{15}
{
	\hX{וַאֲמַר־לֵהּ (אלה) [אֵל] מָאנַיָּא שֵׂא אֵזֶל־אֲחֵת הִמּוֹ בְּהֵיכְלָא דִּי בִירוּשְׁלֶם וּבֵית אֱלָהָא יִתְבְּנֵא עַל־אַתְרֵהּ׃}
}
{
	\eX{
		He said to him, “Take these vessels, go, deposit them in the
		temple in Jerusalem, and let the House of God be rebuilt on its
		original site.”
	}
}
{
	Qere Ketiv.
}

\Verse{16}
{
	\hX{אֱדַיִן שֵׁשְׁבַּצַּר דֵּךְ אֲתָא יְהַב אֻשַּׁיָּא דִּי־בֵית אֱלָהָא דִּי בִירוּשְׁלֶם וּמִן־אֱדַיִן וְעַד־כְּעַן מִתְבְּנֵא וְלָא שְׁלִם׃}
}
{
	\eX{
		That same Sheshbazzar then came and laid the foundations for the
		House of God in Jerusalem; and ever since then it has been under
		construction, but is not yet finished.’
	}
}
{
}

\Verse{17}
{
	\hX{
		וּכְעַן הֵן עַל־מַלְכָּא טָב יִתְבַּקַּר בְּבֵית גִּנְזַיָּא דִּי־מַלְכָּא תַמָּה דִּי בְּבָבֶל הֵן אִיתַי דִּי־מִן־כּוֹרֶשׁ מַלְכָּא שִׂים טְעֵם לְמִבְנֵא בֵּית־אֱלָהָא דֵךְ
		בִּירוּשְׁלֶם וּרְעוּת מַלְכָּא עַל־דְּנָה יִשְׁלַח עֲלֶינָא׃
	}
}
{
	\eX{
		And now, if it please the king, let the royal archives there in
		Babylon be searched to see whether indeed an order had been issued
		by King Cyrus to rebuild this House of God in Jerusalem. May the
		king convey to us his pleasure in this matter.”
	}
}
{
