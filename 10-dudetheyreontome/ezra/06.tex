\Chapter{6}

\Verse{1}
{
	\hX{בֵּאדַיִן דָּרְיָוֶשׁ מַלְכָּא שָׂם טְעֵם וּבַקַּרוּ בְּבֵית סִפְרַיָּא דִּי גִנְזַיָּא מְהַחֲתִין תַּמָּה בְּבָבֶל׃}
}
{
	\eX{
		Then Darius the king made a decree, and search was made in the
		house of the rolls, where the treasures were laid up in Babylon.
	}
}
{
}

\Verse{2}
{
	\hX{וְהִשְׁתְּכַח בְּאַחְמְתָא בְּבִירְתָא דִּי בְּמָדַי מְדִינְתָּא מְגִלָּה חֲדָה וְכֵן־כְּתִיב בְּגַוַּהּ דִּכְרוֹנָה׃}
}
{
	\eX{
		And there was found at Achmetha, in the fortress that is in the
		province of the Medes, a roll, and in it was a record thus
		written:
	}
}
{
}

\Verse{3}
{
	\hX{
		בִּשְׁנַת חֲדָה לְכוֹרֶשׁ מַלְכָּא כּוֹרֶשׁ מַלְכָּא שָׂם טְעֵם בֵּית־אֱלָהָא בִירוּשְׁלֶם בַּיְתָא יִתְבְּנֵא אֲתַר דִּי־דָבְחִין דִּבְחִין וְאֻשּׁוֹהִי מְסוֹבְלִין רוּמֵהּ
		אַמִּין שִׁתִּין פְּתָיֵהּ אַמִּין שִׁתִּין׃
	}
}
{
	\eX{
		In the first year of Cyrus the king the that Cyrus the king made
		a decree concerning the house of God at Jerusalem, Let the house
		be built, the place where they offered sacrifices, and let the
		foundations of it be strongly laid; the height of it sixty
		cubits, and the breadth of it sixty cubits;
	}
}
{
}

\Verse{4}
{
	\hX{נִדְבָּכִין דִּי־אֶבֶן גְּלָל תְּלָתָא וְנִדְבָּךְ דִּי־אָע חֲדַת וְנִפְקְתָא מִן־בֵּית מַלְכָּא תִּתְיְהִב׃}
}
{
	\eX{
		With three rows of great stones, and a row of new timber: and
		let the expenses be given out of the king's house:
	}
}
{
}

\Verse{5}
{
	\hX{
		וְאַף מָאנֵי בֵית־אֱלָהָא דִּי דַהֲבָה וְכַסְפָּא דִּי נְבוּכַדְנֶצַּר הַנְפֵּק מִן־הֵיכְלָא דִי־בִירוּשְׁלֶם וְהֵיבֵל לְבָבֶל יַהֲתִיבוּן וִיהָךְ לְהֵיכְלָא דִי־בִירוּשְׁלֶם
		לְאַתְרֵהּ וְתַחֵת בְּבֵית אֱלָהָא׃
	}
}
{
	\eX{
		And also let the golden and silver things of the house of God,
		that Nebuchadnezzar took forth out of the temple that is at
		Jerusalem, and brought to Babylon, be restored, and brought
		again to the temple that is at Jerusalem, everyone to his place,
		and place them in the house of God.
	}
}
{
}

\Verse{6}
{
	\hX{כְּעַן תַּתְּנַי פַּחַת עֲבַר־נַהֲרָה שְׁתַר בּוֹזְנַי וּכְנָוָתְהוֹן אֲפַרְסְכָיֵא דִּי בַּעֲבַר נַהֲרָה רַחִיקִין הֲווֹ מִן־תַּמָּה׃}
}
{
	\eX{
		And now, Tatnai, governor across the River, Shetharboznai, and
		your companions the Apharsachites, that are across the River, be
		you far from there:
	}
}
{
}

\Verse{7}
{
	\hX{שְׁבֻקוּ לַעֲבִידַת בֵּית־אֱלָהָא דֵךְ פַּחַת יְהוּדָיֵא וּלְשָׂבֵי יְהוּדָיֵא בֵּית־אֱלָהָא דֵךְ יִבְנוֹן עַל־אַתְרֵהּ׃}
}
{
	\eX{
		Let the work of this house of God alone; let the governor of the
		Jews and the elders of the Jews build this house of God in his
		place.
	}
}
{
}

\Verse{8}
{
	\hX{
		וּמִנִּי שִׂים טְעֵם לְמָא דִי־תַעַבְדוּן עִם־שָׂבֵי יְהוּדָיֵא אִלֵּךְ לְמִבְנֵא בֵּית־אֱלָהָא דֵךְ וּמִנִּכְסֵי מַלְכָּא דִּי מִדַּת עֲבַר נַהֲרָה אסְפַּרְנָא נִפְקְתָא תֶּהֱוֵא
		מִתְיַהֲבָא לְגֻבְרַיָּא אִלֵּךְ דִּי־לָא לְבַטָּלָא׃
	}
}
{
	\eX{
		Moreover I make a decree what you shall do to the elders of
		these Jews for the building of this house of God: that of the
		king's goods, even of the tribute across the River, forthwith
		expenses be given to these men, that they be not hindered.
	}
}
{
}

\Verse{9}
{
	\hX{
		וּמָה חַשְׁחָן וּבְנֵי תוֹרִין וְדִכְרִין וְאִמְּרִין לַעֲלָוָן לֶאֱלָהּ שְׁמַיָּא חִנְטִין מְלַח חֲמַר וּמְשַׁח כְּמֵאמַר כָּהֲנַיָּא דִי־בִירוּשְׁלֶם לֶהֱוֵא מִתְיְהֵב לְהֹם יוֹם
		בְּיוֹם דִּי־לָא שָׁלוּ׃
	}
}
{
	\eX{
		And that they have need of, both young bulls, and rams, and
		lambs, for the burnt offerings of the God of the skies, wheat,
		salt, wine, and oil, according to the appointment of the priests
		that are at Jerusalem, let it be given them day by day without
		fail:
	}
}
{
}

\Verse{10}
{
	\hX{דִּי־לֶהֱוֺן מְהַקְרְבִין נִיחוֹחִין לֶאֱלָהּ שְׁמַיָּא וּמְצַלַּיִן לְחַיֵּי מַלְכָּא וּבְנוֹהִי׃}
}
{
	\eX{
		That they may offer sacrifices of sweet savours to the God of
		the skies, and pray for the life of the king, and of his sons.
	}
}
{
}

\Verse{11}
{
	\hX{וּמִנִּי שִׂים טְעֵם דִּי כל־אֱנָשׁ דִּי יְהַשְׁנֵא פִּתְגָמָא דְנָה יִתְנְסַח אָע מִן־בַּיְתֵהּ וּזְקִיף יִתְמְחֵא עֲלֹהִי וּבַיְתֵהּ נְוָלוּ יִתְעֲבֵד עַל־דְּנָה׃}
}
{
	\eX{
		Also I have made a decree, that whoever shall change this word,
		let timber be pulled down from his house, and being set up, let
		him be hanged on it; and let his house be made a trash heap for
		this.
	}
}
{
}

\Verse{12}
{
	\hX{
		וֵאלָהָא דִּי שַׁכִּן שְׁמֵהּ תַּמָּה יְמַגַּר כּל־מֶלֶךְ וְעַם דִּי יִשְׁלַח יְדֵהּ לְהַשְׁנָיָה לְחַבָּלָה בֵּית־אֱלָהָא דֵךְ דִּי בִירוּשְׁלֶם אֲנָה דָרְיָוֶשׁ שָׂמֶת טְעֵם
		אסְפַּרְנָא יִתְעֲבִד׃
	}
}
{
	\eX{
		And the God that has caused his name to dwell there destroy all
		kings and people, that shall put to their hand to alter and to
		destroy this house of God that is at Jerusalem. I Darius have
		made a decree; let it be done quickly.
	}
}
{
}

\Verse{13}
{
	\hX{אֱדַיִן תַּתְּנַי פַּחַת עֲבַר־נַהֲרָה שְׁתַר בּוֹזְנַי וּכְנָוָתְהוֹן לקֳבֵל דִּי־שְׁלַח דָּרְיָוֶשׁ מַלְכָּא כְּנֵמָא אסְפַּרְנָא עֲבַדוּ׃}
}
{
	\eX{
		Then Tatnai, governor across the river, Shetharboznai, and their
		companions, according to what Darius the king had sent, so they
		did quickly.
	}
}
{
}

\Verse{14}
{
	\hX{
		וְשָׂבֵי יְהוּדָיֵא בָּנַיִן וּמַצְלְחִין בִּנְבוּאַת חַגַּי (נביאה) [נְבִיָּא] וּזְכַרְיָה בַּר־עִדּוֹא וּבְנוֹ וְשַׁכְלִלוּ מִן־טַעַם אֱלָהּ יִשְׂרָאֵל וּמִטְּעֵם כּוֹרֶשׁ
		וְדָרְיָוֶשׁ וְאַרְתַּחְשַׁשְׂתְּא מֶלֶךְ פָּרָס׃
	}
}
{
	\eX{
		And the elders of the Jews built, and they prospered through the
		prophesying of Haggai the prophet and Zechariah the son of Iddo.
		And they built, and finished it, according to the commandment of
		the God of Israel, and according to the commandment of Cyrus,
		and Darius, and Artaxerxes king of Persia.
	}
}

	Qere Ketiv.
}

}

}

\Verse{17}
{
	\hX{
		וְהַקְרִבוּ לַחֲנֻכַּת בֵּית־אֱלָהָא דְנָה תּוֹרִין מְאָה דִּכְרִין מָאתַיִן אִמְּרִין אַרְבַּע מְאָה וּצְפִירֵי עִזִּין (לחטיא) [לְחַטָּאָה] עַל־כּל־יִשְׂרָאֵל תְּרֵי־עֲשַׂר

	}
}
{
	\eX{
		And offered at the dedication of this house of God a hundred
		bulls, two hundred rams, four hundred lambs; and for a sin
		offering for all Israel, twelve he goats, according to the
		number of the tribes of Israel.
	}
}
{
	Qere Ketiv.
}

\Verse{21}

}
{
}

\Verse{22}
{

	}
}
{
