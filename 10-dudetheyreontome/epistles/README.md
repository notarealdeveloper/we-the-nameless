Each `.tex` file here is a separate book within the Epistles collection.
Both the full book and `make dudetheyreontome` discover these files automatically,
in filename order. No edits to `master.tex` or the Makefile are needed.

Use lowercase words and numbers separated by hyphens: `1-jephesians.tex` becomes
“1 Jephesians”, `2-jephesians.tex` becomes “2 Jephesians”, and `1-gal.tex` becomes
“1 Gal”. Use the full name in the filename if that is what should appear in print.

Start the file with `\Chapter{1}`, followed by the usual `\Verse` blocks. Further
`\Chapter{2}`, etc. commands belong in the same file. The collection supplies
the book name for chapter headings, running heads, verse labels, and links, and
lists each book beneath Epistles in the Dudetheyreontome contents.
