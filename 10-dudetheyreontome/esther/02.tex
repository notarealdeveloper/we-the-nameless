\Verse{3}

	\hX{

		הַמֶּלֶךְ שֹׁמֵר הַנָּשִׁים וְנָתוֹן תַּמְרֻקֵיהֶן׃
	}
}
{
	\eX{
		Let Your Majesty appoint officers in every province of your realm
		to assemble all the beautiful young virgins at the fortress
		Shushan, in the harem under the supervision of Hege, the king’s
		eunuch, guardian of the women. Let them be provided with their
		cosmetics.
	}
}
{
}

\Verse{4}
{
	\hX{וְהַנַּעֲרָה אֲשֶׁר תִּיטַב בְּעֵינֵי הַמֶּלֶךְ תִּמְלֹךְ תַּחַת וַשְׁתִּי וַיִּיטַב הַדָּבָר בְּעֵינֵי הַמֶּלֶךְ וַיַּעַשׂ כֵּן׃}
}
{
	\eX{
		And let the maiden who pleases Your Majesty be queen instead of
		Vashti.” The proposal pleased the king, and he acted upon it.
	}
}
{
}

\Verse{5}

	\hX{אִישׁ יְהוּדִי הָיָה בְּשׁוּשַׁן הַבִּירָה וּשְׁמוֹ מרְדֳּכַי בֶּן יָאִיר בֶּן־שִׁמְעִי בֶּן־קִישׁ אִישׁ יְמִינִי׃}
}
{
	\eX{
		In the fortress Shushan lived a Jew by the name of Mordecai, son
		of Jair son of Shimei son of Kish, a Benjaminite.
	}
}
{
}

\Verse{6}
{
	\hX{אֲשֶׁר הגְלָה מִירוּשָׁלַיִם עִם־הַגֹּלָה אֲשֶׁר הגְלְתָה עִם יְכנְיָה מֶלֶךְ־יְהוּדָה אֲשֶׁר הֶגְלָה נְבוּכַדְנֶצַּר מֶלֶךְ בָּבֶל׃}
}
{
	\eX{
		[Kish] had been exiled from Jerusalem in the group that was
		carried into exile along with King Jeconiah of Judah, which had
		been driven into exile by King Nebuchadnezzar of Babylon.
	}
}
{
}

\Verse{7}

	\hX{וַיְהִי אֹמֵן אֶת־הֲדַסָּה הִיא אֶסְתֵּר בַּת־דֹּדוֹ כִּי אֵין לָהּ אָב וָאֵם וְהַנַּעֲרָה יְפַת־תֹּאַר וְטוֹבַת מַרְאֶה וּבְמוֹת אָבִיהָ וְאִמָּהּ לְקָחָהּ מרְדֳּכַי לוֹ לְבַת׃}
}
{
	\eX{
		He was foster father to Hadassah—that is, Esther—his uncle’s
		daughter, for she had neither father nor mother. The maiden was
		shapely and beautiful; and when her father and mother died,
		Mordecai adopted her as his own daughter.
	}
}
{
}

\Verse{8}
{
	\hX{
		וַיְהִי בְּהִשָּׁמַע דְּבַר־הַמֶּלֶךְ וְדָתוֹ וּבְהִקָּבֵץ נְעָרוֹת רַבּוֹת אֶל־שׁוּשַׁן הַבִּירָה אֶל־יַד הֵגָי וַתִּלָּקַח אֶסְתֵּר אֶל־בֵּית הַמֶּלֶךְ אֶל־יַד הֵגַי שֹׁמֵר
		הַנָּשִׁים׃
	}
}
{
	\eX{
		When the king’s order and edict was proclaimed, and when many
		girls were assembled in the fortress Shushan under the supervision
		of Hegai, Esther too was taken into the king’s palace under the
		supervision of Hegai, guardian of the women.
	}
}
{
}

\Verse{9}
{
	\hX{
		וַתִּיטַב הַנַּעֲרָה בְעֵינָיו וַתִּשָּׂא חֶסֶד לְפָנָיו וַיְבַהֵל אֶת־תַּמְרוּקֶיהָ וְאֶת־מָנוֹתֶהָ לָתֵת לָהּ וְאֵת שֶׁבַע הַנְּעָרוֹת הָרְאֻיוֹת לָתֶת־לָהּ מִבֵּית הַמֶּלֶךְ
		וַיְשַׁנֶּהָ וְאֶת־נַעֲרוֹתֶיהָ לְטוֹב בֵּית הַנָּשִׁים׃
	}
}
{
	\eX{
		The girl pleased him and won his favor, and he hastened to furnish
		her with her cosmetics and her rations, as well as with the seven
		maids who were her due from the king’s palace; and he treated her
		and her maids with special kindness in the harem.
	}
}
{
}

\Verse{10}
{
	\hX{לֹא־הִגִּידָה אֶסְתֵּר אֶת־עַמָּהּ וְאֶת־מוֹלַדְתָּהּ כִּי מרְדֳּכַי צִוָּה עָלֶיהָ אֲשֶׁר לֹא־תַגִּיד׃}
}
{
	\eX{

		told her not to reveal it.
	}
}
{
}

\Verse{11}

	\hX{וּבְכל־יוֹם וָיוֹם מרְדֳּכַי מִתְהַלֵּךְ לִפְנֵי חֲצַר בֵּית־הַנָּשִׁים לָדַעַת אֶת־שְׁלוֹם אֶסְתֵּר וּמַה־יֵּעָשֶׂה בָּהּ׃}
}
{
	\eX{

		of the harem, to learn how Esther was faring and what was
		happening to her.
	}
}
{
}

\Verse{12}
{
	\hX{

		חֳדָשִׁים בְּשֶׁמֶן הַמֹּר וְשִׁשָּׁה חֳדָשִׁים בַּבְּשָׂמִים וּבְתַמְרוּקֵי הַנָּשִׁים׃
	}
}
{
	\eX{
		When each girl’s turn came to go to King Ahasuerus at the end of
		the twelve months’ treatment prescribed for women (for that was
		the period spent on beautifying them: six months with oil of myrrh
		and six months with perfumes and women’s cosmetics,
	}
}
{
}

\Verse{13}

	\hX{וּבָזֶה הַנַּעֲרָה בָּאָה אֶל־הַמֶּלֶךְ אֵת כּל־אֲשֶׁר תֹּאמַר יִנָּתֵן לָהּ לָבוֹא עִמָּהּ מִבֵּית הַנָּשִׁים עַד־בֵּית הַמֶּלֶךְ׃}
}
{
	\eX{

		whatever she asked for would be given her to take with her from
		the harem to the king’s palace.

{
}

\Verse{14}

		harem in charge of Shaashgaz, the king’s eunuch, guardian of the

		wanted her, when she would be summoned by name.
	}
}
{
}

\Verse{15}
{
	\hX{
		וּבְהַגִּיעַ תֹּר־אֶסְתֵּר בַּת־אֲבִיחַיִל דֹּד מרְדֳּכַי אֲשֶׁר לָקַח־לוֹ לְבַת לָבוֹא אֶל־הַמֶּלֶךְ לֹא בִקְשָׁה דָּבָר כִּי אִם אֶת־אֲשֶׁר יֹאמַר הֵגַי סְרִיס־הַמֶּלֶךְ שֹׁמֵר
		הַנָּשִׁים וַתְּהִי אֶסְתֵּר נֹשֵׂאת חֵן בְּעֵינֵי כּל־רֹאֶיהָ׃
	}
}
{
	\eX{
		When the turn came for Esther daughter of Abihail—the uncle of
		Mordecai, who had adopted her as his own daughter—to go to the
		king, she did not ask for anything but what Hegai, the king’s
		eunuch, guardian of the women, advised. Yet Esther won the
		admiration of all who saw her.
	}
}
{
}

\Verse{16}

}
{
	\eX{
		Esther was taken to King Ahasuerus, in his royal palace, in the
		tenth month, which is the month of Tebeth, in the seventh year of
		his reign.
	}
}
{
}
