\Chapter{1}

\Verse{1}
{
	\hX{וַיְהִי בִּימֵי אֲחַשְׁוֵרוֹשׁ הוּא אֲחַשְׁוֵרוֹשׁ הַמֹּלֵךְ מֵהֹדּוּ וְעַד־כּוּשׁ שֶׁבַע וְעֶשְׂרִים וּמֵאָה מְדִינָה׃}
}
{
	\eX{
		Now it came to pass in the days of Ahasuerus, (this is Ahasuerus
		which reigned, from India even unto Ethiopia, over an hundred
		and seven and twenty provinces:)
	}
}
{
}

\Verse{2}
{
	\hX{בַּיָּמִים הָהֵם כְּשֶׁבֶת הַמֶּלֶךְ אֲחַשְׁוֵרוֹשׁ עַל כִּסֵּא מַלְכוּתוֹ אֲשֶׁר בְּשׁוּשַׁן הַבִּירָה׃}
}
{
	\eX{
		That in those days, when the king Ahasuerus sat on the throne of
		his kingdom, which was in Shushan the palace,
	}
}
{
}

\Verse{3}
{
	\hX{בִּשְׁנַת שָׁלוֹשׁ לְמלְכוֹ עָשָׂה מִשְׁתֶּה לְכל־שָׂרָיו וַעֲבָדָיו חֵיל פָּרַס וּמָדַי הַפַּרְתְּמִים וְשָׂרֵי הַמְּדִינוֹת לְפָנָיו׃}
}
{
	\eX{
		In the third year of his reign, he made a feast unto all his
		princes and his servants; the power of Persia and Media, the
		nobles and princes of the provinces, being before him:
	}
}
{
}

\Verse{4}
{
	\hX{בְּהַרְאֹתוֹ אֶת־עֹשֶׁר כְּבוֹד מַלְכוּתוֹ וְאֶת־יְקָר תִּפְאֶרֶת גְּדוּלָּתוֹ יָמִים רַבִּים שְׁמוֹנִים וּמְאַת יוֹם׃}
}
{
	\eX{
		When he shewed the riches of his glorious kingdom and the honour
		of his excellent majesty many days, even an hundred and
		fourscore days.
	}
}
{
}

\Verse{5}
{
	\hX{וּבִמְלוֹאת הַיָּמִים הָאֵלֶּה עָשָׂה הַמֶּלֶךְ לְכל־הָעָם הַנִּמְצְאִים בְּשׁוּשַׁן הַבִּירָה לְמִגָּדוֹל וְעַד־קָטָן מִשְׁתֶּה שִׁבְעַת יָמִים בַּחֲצַר גִּנַּת בִּיתַן הַמֶּלֶךְ׃}
}
{
	\eX{
		And when these days were expired, the king made a feast unto all
		the people that were present in Shushan the palace, both unto
		great and small, seven days, in the court of the garden of the
		king’s palace;
	}
}
{
}

\Verse{6}
{
	\hX{חוּר כַּרְפַּס וּתְכֵלֶת אָחוּז בְּחַבְלֵי־בוּץ וְאַרְגָּמָן עַל־גְּלִילֵי כֶסֶף וְעַמּוּדֵי שֵׁשׁ מִטּוֹת זָהָב וָכֶסֶף עַל רִצְפַת בַּהַט־וָשֵׁשׁ וְדַר וְסֹחָרֶת׃}
}
{
	\eX{
		Where were white, green, and blue, hangings, fastened with cords
		of fine linen and purple to silver rings and pillars of marble:
		the beds were of gold and silver, upon a pavement of red, and
		blue, and white, and black, marble.
	}
}
{
}

\Verse{7}
{
	\hX{וְהַשְׁקוֹת בִּכְלֵי זָהָב וְכֵלִים מִכֵּלִים שׁוֹנִים וְיֵין מַלְכוּת רָב כְּיַד הַמֶּלֶךְ׃}
}
{
	\eX{
		And they gave them drink in vessels of gold, (the vessels being
		diverse one from another,) and royal wine in abundance,
		according to the state of the king.
	}
}
{
}

\Verse{8}
{
	\hX{וְהַשְּׁתִיָּה כַדָּת אֵין אֹנֵס כִּי־כֵן יִסַּד הַמֶּלֶךְ עַל כּל־רַב בֵּיתוֹ לַעֲשׂוֹת כִּרְצוֹן אִישׁ־וָאִישׁ׃}
}
{
	\eX{
		And the drinking was according to the law; none did compel: for
		so the king had appointed to all the officers of his house, that
		they should do according to every man’s pleasure.
	}
}
{
}

\Verse{9}
{
	\hX{גַּם וַשְׁתִּי הַמַּלְכָּה עָשְׂתָה מִשְׁתֵּה נָשִׁים בֵּית הַמַּלְכוּת אֲשֶׁר לַמֶּלֶךְ אֲחַשְׁוֵרוֹשׁ׃}
}
{
	\eX{
		Also Vashti the queen made a feast for the women in the royal
		house which belonged to king Ahasuerus.
	}
}
{
}

\Verse{10}
{
	\hX{
		בַּיּוֹם הַשְּׁבִיעִי כְּטוֹב לֵב־הַמֶּלֶךְ בַּיָּיִן אָמַר לִמְהוּמָן בִּזְּתָא חַרְבוֹנָא בִּגְתָא וַאֲבַגְתָא זֵתַר וְכַרְכַּס שִׁבְעַת הַסָּרִיסִים הַמְשָׁרְתִים אֶת־פְּנֵי
		הַמֶּלֶךְ אֲחַשְׁוֵרוֹשׁ׃
	}
}
{
	\eX{
		On the seventh day, when the heart of the king was merry with
		wine, he commanded Mehuman, Biztha, Harbona, Bigtha, and
		Abagtha, Zethar, and Carcas, the seven chamberlains that served
		in the presence of Ahasuerus the king,
	}
}
{
}

\Verse{11}
{
	\hX{לְהָבִיא אֶת־וַשְׁתִּי הַמַּלְכָּה לִפְנֵי הַמֶּלֶךְ בְּכֶתֶר מַלְכוּת לְהַרְאוֹת הָעַמִּים וְהַשָּׂרִים אֶת־יפְיָהּ כִּי־טוֹבַת מַרְאֶה הִיא׃}
}
{
	\eX{
		To bring Vashti the queen before the king with the crown royal,
		to shew the people and the princes her beauty: for she was fair
		to look on.
	}
}
{
}

\Verse{12}
{
	\hX{וַתְּמָאֵן הַמַּלְכָּה וַשְׁתִּי לָבוֹא בִּדְבַר הַמֶּלֶךְ אֲשֶׁר בְּיַד הַסָּרִיסִים וַיִּקְצֹף הַמֶּלֶךְ מְאֹד וַחֲמָתוֹ בָּעֲרָה בוֹ׃}
}
{
	\eX{
		But the queen Vashti refused to come at the king’s commandment
		by his chamberlains: therefore was the king very wroth, and his
		anger burned in him.
	}
}
{
}

\Verse{13}
{
	\hX{וַיֹּאמֶר הַמֶּלֶךְ לַחֲכָמִים יֹדְעֵי הָעִתִּים כִּי־כֵן דְּבַר הַמֶּלֶךְ לִפְנֵי כּל־יֹדְעֵי דָּת וָדִין׃}
}
{
	\eX{
		Then the king said to the wise men, which knew the times, (for
		so was the king’s manner toward all that knew law and judgment:
	}
}
{
}

\Verse{14}
{
	\hX{וְהַקָּרֹב אֵלָיו כַּרְשְׁנָא שֵׁתָר אַדְמָתָא תַרְשִׁישׁ מֶרֶס מַרְסְנָא מְמוּכָן שִׁבְעַת שָׂרֵי פָּרַס וּמָדַי רֹאֵי פְּנֵי הַמֶּלֶךְ הַיֹּשְׁבִים רִאשֹׁנָה בַּמַּלְכוּת׃}
}
{
	\eX{
		And the next unto him was Carshena, Shethar, Admatha, Tarshish,
		Meres, Marsena, and Memucan, the seven princes of Persia and
		Media, which saw the king’s face, and which sat the first in the
		kingdom;)
	}
}
{
}

\Verse{15}
{
	\hX{כְּדָת מַה־לַּעֲשׂוֹת בַּמַּלְכָּה וַשְׁתִּי עַל אֲשֶׁר לֹא־עָשְׂתָה אֶת־מַאֲמַר הַמֶּלֶךְ אֲחַשְׁוֵרוֹשׁ בְּיַד הַסָּרִיסִים׃}
}
{
	\eX{
		What shall we do unto the queen Vashti according to law, because
		she hath not performed the commandment of the king Ahasuerus by
		the chamberlains?
	}
}
{
}

\Verse{16}
{
	\hX{
		וַיֹּאמֶר (מומכן) [מְמוּכָן] לִפְנֵי הַמֶּלֶךְ וְהַשָּׂרִים לֹא עַל־הַמֶּלֶךְ לְבַדּוֹ עָוְתָה וַשְׁתִּי הַמַּלְכָּה כִּי עַל־כּל־הַשָּׂרִים וְעַל־כּל־הָעַמִּים אֲשֶׁר
		בְּכל־מְדִינוֹת הַמֶּלֶךְ אֲחַשְׁוֵרוֹשׁ׃
	}
}
{
	\eX{
		And Memucan answered before the king and the princes, Vashti the
		queen hath not done wrong to the king only, but also to all the
		princes, and to all the people that are in all the provinces of
		the king Ahasuerus.
	}
}
{
}

\Verse{17}
{
	\hX{
		כִּי־יֵצֵא דְבַר־הַמַּלְכָּה עַל־כּל־הַנָּשִׁים לְהַבְזוֹת בַּעְלֵיהֶן בְּעֵינֵיהֶן בְּאמְרָם הַמֶּלֶךְ אֲחַשְׁוֵרוֹשׁ אָמַר לְהָבִיא אֶת־וַשְׁתִּי הַמַּלְכָּה לְפָנָיו
		וְלֹא־בָאָה׃
	}
}
{
	\eX{
		For this deed of the queen shall come abroad unto all women, so
		that they shall despise their husbands in their eyes, when it
		shall be reported, The king Ahasuerus commanded Vashti the queen
		to be brought in before him, but she came not.
	}
}
{
}

\Verse{18}
{
	\hX{וְהַיּוֹם הַזֶּה תֹּאמַרְנָה שָׂרוֹת פָּרַס־וּמָדַי אֲשֶׁר שָׁמְעוּ אֶת־דְּבַר הַמַּלְכָּה לְכֹל שָׂרֵי הַמֶּלֶךְ וּכְדַי בִּזָּיוֹן וָקָצֶף׃}
}
{
	\eX{
		Likewise shall the ladies of Persia and Media say this day unto
		all the king’s princes, which have heard of the deed of the
		queen. Thus shall there arise too much contempt and wrath.
	}
}
{
}

\Verse{19}
{
	\hX{
		אִם־עַל־הַמֶּלֶךְ טוֹב יֵצֵא דְבַר־מַלְכוּת מִלְּפָנָיו וְיִכָּתֵב בְּדָתֵי פָרַס־וּמָדַי וְלֹא יַעֲבוֹר אֲשֶׁר לֹא־תָבוֹא וַשְׁתִּי לִפְנֵי הַמֶּלֶךְ אֲחַשְׁוֵרוֹשׁ וּמַלְכוּתָהּ
		יִתֵּן הַמֶּלֶךְ לִרְעוּתָהּ הַטּוֹבָה מִמֶּנָּה׃
	}
}
{
	\eX{
		If it please the king, let there go a royal commandment from
		him, and let it be written among the laws of the Persians and
		the Medes, that it be not altered, That Vashti come no more
		before king Ahasuerus; and let the king give her royal estate
		unto another that is better than she.
	}
}
{
}

\Verse{20}
{
	\hX{וְנִשְׁמַע פִּתְגָם הַמֶּלֶךְ אֲשֶׁר־יַעֲשֶׂה בְּכל־מַלְכוּתוֹ כִּי רַבָּה הִיא וְכל־הַנָּשִׁים יִתְּנוּ יְקָר לְבַעְלֵיהֶן לְמִגָּדוֹל וְעַד־קָטָן׃}
}
{
	\eX{
		And when the king’s decree which he shall make shall be
		published throughout all his empire, (for it is great,) all the
		wives shall give to their husbands honour, both to great and
		small.
	}
}
{
}

\Verse{21}
{
	\hX{וַיִּיטַב הַדָּבָר בְּעֵינֵי הַמֶּלֶךְ וְהַשָּׂרִים וַיַּעַשׂ הַמֶּלֶךְ כִּדְבַר מְמוּכָן׃}
}
{
	\eX{
		And the saying pleased the king and the princes; and the king
		did according to the word of Memucan:
	}
}
{
}

\Verse{22}
{
	\hX{וַיִּשְׁלַח סְפָרִים אֶל־כּל־מְדִינוֹת הַמֶּלֶךְ אֶל־מְדִינָה וּמְדִינָה כִּכְתָבָהּ וְאֶל־עַם וָעָם כִּלְשׁוֹנוֹ לִהְיוֹת כּל־אִישׁ שֹׂרֵר בְּבֵיתוֹ וּמְדַבֵּר כִּלְשׁוֹן עַמּוֹ׃}
}
{
	\eX{
		For he sent letters into all the king’s provinces, into every
		province according to the writing thereof, and to every people
		after their language, that every man should bear rule in his own
		house, and that it should be published according to the language
		of every people.
	}
}
{
}
