\Chapter{19}

\Verse{1}
{
	\hDtn{כִּי יַכְרִית יְהֹוָה אֱלֹהֶיךָ אֶת הַגּוֹיִם אֲשֶׁר יְהֹוָה אֱלֹהֶיךָ נֹתֵן לְךָ אֶת אַרְצָם וִירִשְׁתָּם וְיָשַׁבְתָּ בְעָרֵיהֶם וּבְבָתֵּיהֶם׃}
}
{
	\eDtn{
		19 “When YHWH, your God, will cut off the nations whose
		land YHWH, your God, is giving you, and you’ll dispossess
		them and live in their cities and in their houses,
	}
}
{
}

\Verse{2}
{
	\hDtn{שָׁלוֹשׁ עָרִים תַּבְדִּיל לָךְ בְּתוֹךְ אַרְצְךָ אֲשֶׁר יְהֹוָה אֱלֹהֶיךָ נֹתֵן לְךָ לְרִשְׁתָּהּ׃}
}
{
	\eDtn{
		you shall distinguish three cities within your land that
		YHWH, your God, is giving you to take possession of it.
	}
}
{
}

\Verse{3}
{
	\hDtn{תָּכִין לְךָ הַדֶּרֶךְ וְשִׁלַּשְׁתָּ אֶת גְּבוּל אַרְצְךָ אֲשֶׁר יַנְחִילְךָ יְהֹוָה אֱלֹהֶיךָ וְהָיָה לָנוּס שָׁמָּה כּל רֹצֵחַ׃}
}
{
	\eDtn{
		You shall prepare the way and divide the border of your
		land that YHWH, your God, will give you as a legacy into
		three sections, and it will be for any murderer to flee
		there.
	}
}
{
}

\Verse{4}
{
	\hDtn{וְזֶה דְּבַר הָרֹצֵחַ אֲשֶׁר יָנוּס שָׁמָּה וָחָי אֲשֶׁר יַכֶּה אֶת רֵעֵהוּ בִּבְלִי דַעַת וְהוּא לֹא שֹׂנֵא לוֹ מִתְּמֹל שִׁלְשֹׁם׃}
}
{
	\eDtn{
		And this is the case of the manslayer who will flee there
		and live: one who will strike his neighbor without
		knowing, when he did not hate him from the day before
		yesterday;
	}
}
{
%	\footnote{
%		from the day before yesterday. Meaning: he had no prior malice toward
%		the person whom he killed.
%	}
}

\Verse{5}
{
	\hDtn{וַאֲשֶׁר יָבֹא אֶת רֵעֵהוּ בַיַּעַר לַחְטֹב עֵצִים וְנִדְּחָה יָדוֹ בַגַּרְזֶן לִכְרֹת הָעֵץ וְנָשַׁל הַבַּרְזֶל מִן הָעֵץ וּמָצָא אֶת רֵעֵהוּ וָמֵת הוּא יָנוּס אֶל אַחַת הֶעָרִים הָאֵלֶּה וָחָי׃}
}
{
	\eDtn{
		and one who will come with his neighbor into the forest to
		cut down trees, and his hand will be moved with the axe to
		cut down the tree, and the axe head will come off the wood
		and find his neighbor, and he dies. He shall flee to one
		of these cities and live.
	}
}
{
}

\Verse{6}
{
	\hDtn{פֶּן יִרְדֹּף גֹּאֵל הַדָּם אַחֲרֵי הָרֹצֵחַ כִּי יֵחַם לְבָבוֹ וְהִשִּׂיגוֹ כִּי יִרְבֶּה הַדֶּרֶךְ וְהִכָּהוּ נָפֶשׁ וְלוֹ אֵין מִשְׁפַּט מָוֶת כִּי לֹא שֹׂנֵא הוּא לוֹ מִתְּמוֹל שִׁלְשׁוֹם׃}
}
{
	\eDtn{
		In case an avenger of blood will pursue the manslayer when
		his heart will be hot and will catch up to him because the
		way will be long, and he’ll strike him mortally though he
		does not have a sentence of death, because he did not hate
		him from the day before yesterday,
	}
}
{
}

\Verse{7}
{
	\hDtn{עַל כֵּן אָנֹכִי מְצַוְּךָ לֵאמֹר שָׁלֹשׁ עָרִים תַּבְדִּיל לָךְ׃}
}

\Verse{8}

}

	\eDtn{

	}
}
{
}

\Verse{9}
{
	\hDtn{כִּי תִשְׁמֹר אֶת כּל הַמִּצְוָה הַזֹּאת לַעֲשֹׂתָהּ אֲשֶׁר אָנֹכִי מְצַוְּךָ הַיּוֹם לְאַהֲבָה אֶת יְהֹוָה אֱלֹהֶיךָ וְלָלֶכֶת בִּדְרָכָיו כּל הַיָּמִים וְיָסַפְתָּ לְךָ עוֹד שָׁלֹשׁ עָרִים עַל הַשָּׁלֹשׁ הָאֵלֶּה׃}

{
	\eDtn{

	}
}
{
}

\Verse{10}
{
	\hDtn{וְלֹא יִשָּׁפֵךְ דָּם נָקִי בְּקֶרֶב אַרְצְךָ אֲשֶׁר יְהֹוָה אֱלֹהֶיךָ נֹתֵן לְךָ נַחֲלָה וְהָיָה עָלֶיךָ דָּמִים׃}

{

{
}

\Verse{12}
{
	\hDtn{וְשָׁלְחוּ זִקְנֵי עִירוֹ וְלָקְחוּ אֹתוֹ מִשָּׁם וְנָתְנוּ אֹתוֹ בְּיַד גֹּאֵל הַדָּם וָמֵת׃}

\Verse{13}
{
	\hDtn{לֹא תָחוֹס עֵינְךָ עָלָיו וּבִעַרְתָּ דַם הַנָּקִי מִיִּשְׂרָאֵל וְטוֹב לָךְ׃}
}

{
}

\Verse{14}
{
	\hDtn{לֹא תַסִּיג גְּבוּל רֵעֲךָ אֲשֶׁר גָּבְלוּ רִאשֹׁנִים בְּנַחֲלָתְךָ אֲשֶׁר תִּנְחַל בָּאָרֶץ אֲשֶׁר יְהֹוָה אֱלֹהֶיךָ נֹתֵן לְךָ לְרִשְׁתָּהּ׃}
}
{
	\eDtn{
		“You shall not move your neighbor’s landmark that the
		first ones set, in your legacy that you will have in the
		land that YHWH, your God, is giving you to take possession
		of it.
	}
}
{
%	\footnote{
%		your legacy that you will have in the land. This chapter gives laws
%		protecting lives and property, which will apply once the people arrive
%		in the land. Most of the Torah thus looks toward the well-being of the
%		land from outside it. Only about 29 of the Torah’s 187 chapters take
%		place in the promised land. Moses never sets foot in the land. And the
%		phrase “Land of Israel” never occurs in the Torah. (The land acquires
%		this name only after the people of Israel have settled there. It first
%		occurs in 1 Sam 13:19.) Yet the Torah’s story is focused on and directed
%		toward Israel constantly. It is the promise of the covenant with
%		Abraham. The promise is renewed to Isaac and Jacob. Jacob’s body is
%		returned from Egypt to be buried there. Joseph asks to be taken back for
%		burial there someday as well. And almost the entire content of Exodus
%		through Numbers is the story of the people’s liberation and journey
%		home. The Torah thus already relates to the experience of the Jewish
%		people in the postbiblical world: For the last two millennia most of the
%		Jews have lived outside the promised land. They have lived all over the
%		world and have been good citizens of the countries where they settled
%		while having affection for the land of Israel, a consciousness of their
%		origin there, and a desire to contribute to it, travel there, and seek
%		its well-being.
%	}
}
