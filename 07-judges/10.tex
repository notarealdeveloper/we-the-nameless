\Chapter{10}

\Verse{1}
{
	\hX{וַיָּקם אַחֲרֵי אֲבִימֶלֶךְ לְהוֹשִׁיעַ אֶת־יִשְׂרָאֵל תּוֹלָע בֶּן־פּוּאָה בֶּן־דּוֹדוֹ אִישׁ יִשָּׂשכָר וְהוּא־יֹשֵׁב בְּשָׁמִיר בְּהַר אֶפְרָיִם׃}
}
{
	\eX{
		And after Abimelech there arose to defend Israel Tola the son of
		Puah, the son of Dodo, a man of Issachar: and he lived in Shamir
		in Mountain of Ephraim.
	}
}
{
}

\Verse{2}
{
	\hX{וַיִּשְׁפֹּט אֶת־יִשְׂרָאֵל עֶשְׂרִים וְשָׁלֹשׁ שָׁנָה וַיָּמת וַיִּקָּבֵר בְּשָׁמִיר׃}
}
{
	\eX{
		And he judged Israel twenty and three years, and died, and was
		buried in Shamir.
	}
}
{
}

\Verse{3}
{
	\hX{וַיָּקם אַחֲרָיו יָאִיר הַגִּלְעָדִי וַיִּשְׁפֹּט אֶת־יִשְׂרָאֵל עֶשְׂרִים וּשְׁתַּיִם שָׁנָה׃}
}
{
	\eX{
		And after him arose Jair, a Gileadite, and judged Israel twenty
		and two years.
	}
}
{
}

\Verse{4}
{
	\hX{וַיְהִי־לוֹ שְׁלֹשִׁים בָּנִים רֹכְבִים עַל־שְׁלֹשִׁים עֲיָרִים וּשְׁלֹשִׁים עֲיָרִים לָהֶם לָהֶם יִקְרְאוּ חַוֺּת יָאִיר עַד הַיּוֹם הַזֶּה אֲשֶׁר בְּאֶרֶץ הַגִּלְעָד׃}
}
{
	\eX{
		And he had thirty sons that rode on thirty ass colts, and they
		had thirty cities, that are called Havothjair to this day, that
		are in the land of Gilead.
	}
}
{
}

\Verse{5}
{
	\hX{וַיָּמת יָאִיר וַיִּקָּבֵר בְּקָמוֹן׃}
}
{
	\eX{And Jair died, and was buried in Camon.}
}
{
}

\Verse{6}
{
	\hX{
		וַיֹּסִיפוּ בְּנֵי יִשְׂרָאֵל לַעֲשׂוֹת הָרַע בְּעֵינֵי יְהֹוָה וַיַּעַבְדוּ אֶת־הַבְּעָלִים וְאֶת־הָעַשְׁתָּרוֹת וְאֶת־אֱלֹהֵי אֲרָם וְאֶת־אֱלֹהֵי צִידוֹן וְאֵת אֱלֹהֵי מוֹאָב
		וְאֵת אֱלֹהֵי בְנֵי־עַמּוֹן וְאֵת אֱלֹהֵי פְלִשְׁתִּים וַיַּעַזְבוּ אֶת־יְהֹוָה וְלֹא עֲבָדוּהוּ׃
	}
}
{
	\eX{
		And the children of Israel did what was bad again in the eyes of
		YHWH, and served Baals, and Ashtaroth, and the gods of Syria,
		and the gods of Sidon, and the gods of Moab, and the gods of the
		children of Ammon, and the gods of the Philistines, and forsook
		YHWH, and served not him.
	}
}
{
}

\Verse{7}
{
	\hX{וַיִּחַר־אַף יְהֹוָה בְּיִשְׂרָאֵל וַיִּמְכְּרֵם בְּיַד־פְּלִשְׁתִּים וּבְיַד בְּנֵי עַמּוֹן׃}
}
{
	\eX{
		And the anger of YHWH was hot against Israel, and he sold them
		in the hands of the Philistines, and in the hands of the
		children of Ammon.
	}
}
{
}

\Verse{8}
{
	\hX{
		וַיִּרְעֲצוּ וַיְרֹצְצוּ אֶת־בְּנֵי יִשְׂרָאֵל בַּשָּׁנָה הַהִיא שְׁמֹנֶה עֶשְׂרֵה שָׁנָה אֶת־כּל־בְּנֵי יִשְׂרָאֵל אֲשֶׁר בְּעֵבֶר הַיַּרְדֵּן בְּאֶרֶץ הָאֱמֹרִי אֲשֶׁר
		בַּגִּלְעָד׃
	}
}
{
	\eX{
		And that year they vexed and oppressed the children of Israel:
		eighteen years, all the children of Israel that were on the
		other side Jordan in the land of the Amorite, that is in Gilead.
	}
}
{
}

\Verse{9}
{
	\hX{וַיַּעַבְרוּ בְנֵי־עַמּוֹן אֶת־הַיַּרְדֵּן לְהִלָּחֵם גַּם־בִּיהוּדָה וּבְבִנְיָמִין וּבְבֵית אֶפְרָיִם וַתֵּצֶר לְיִשְׂרָאֵל מְאֹד׃}
}
{
	\eX{
		Moreover the children of Ammon passed over Jordan to fight also
		against Judah, and against Benjamin, and against the house of
		Ephraim; so that Israel was sore distressed.
	}
}
{
}

\Verse{10}
{
	\hX{וַיִּזְעֲקוּ בְּנֵי יִשְׂרָאֵל אֶל־יְהֹוָה לֵאמֹר חָטָאנוּ לָךְ וְכִי עָזַבְנוּ אֶת־אֱלֹהֵינוּ וַנַּעֲבֹד אֶת־הַבְּעָלִים׃}
}
{
	\eX{
		And the children of Israel cried to YHWH, saying, We have sinned
		against you, both because we’ve forsaken our God, and also
		served Baals.
	}
}
{
}

\Verse{11}
{
	\hX{וַיֹּאמֶר יְהֹוָה אֶל־בְּנֵי יִשְׂרָאֵל הֲלֹא מִמִּצְרַיִם וּמִן־הָאֱמֹרִי וּמִן־בְּנֵי עַמּוֹן וּמִן־פְּלִשְׁתִּים׃}
}
{
	\eX{
		And YHWH said to the children of Israel, Did not I rescue you
		from the Egyptians, and from the Amorite, from the children of
		Ammon, and from the Philistines?
	}
}
{
}

\Verse{12}
{
	\hX{וְצִידוֹנִים וַעֲמָלֵק וּמָעוֹן לָחֲצוּ אֶתְכֶם וַתִּצְעֲקוּ אֵלַי וָאוֹשִׁיעָה אֶתְכֶם מִיָּדָם׃}
}
{
	\eX{
		The Zidonians also, and the Amalekites, and the Maonites, did
		oppress you: and you cried to me, and I gave you out of their
		hand.
	}
}
{
}

\Verse{13}
{
	\hX{וְאַתֶּם עֲזַבְתֶּם אוֹתִי וַתַּעַבְדוּ אֱלֹהִים אֲחֵרִים לָכֵן לֹא־אוֹסִיף לְהוֹשִׁיעַ אֶתְכֶם׃}
}
{
	\eX{
		Yet you have forsaken me, and served other gods: therefore I’ll
		rescue you no more.
	}
}
{
}

\Verse{14}
{
	\hX{לְכוּ וְזַעֲקוּ אֶל־הָאֱלֹהִים אֲשֶׁר בְּחַרְתֶּם בָּם הֵמָּה יוֹשִׁיעוּ לָכֶם בְּעֵת צָרַתְכֶם׃}
}
{
	\eX{
		Go and cry to the gods that you have chosen; let them rescue you
		in the time of your tribulation.
	}
}
{
}

\Verse{15}
{
	\hX{וַיֹּאמְרוּ בְנֵי־יִשְׂרָאֵל אֶל־יְהֹוָה חָטָאנוּ עֲשֵׂה־אַתָּה לָנוּ כְּכל־הַטּוֹב בְּעֵינֶיךָ אַךְ הַצִּילֵנוּ נָא הַיּוֹם הַזֶּה׃}
}
{
	\eX{
		And the children of Israel said to YHWH, We have sinned: do you
		to us whatever seems good to you; rescue us only, we please,
		this day.
	}
}
{
}

\Verse{16}
{
	\hX{וַיָּסִירוּ אֶת־אֱלֹהֵי הַנֵּכָר מִקִּרְבָּם וַיַּעַבְדוּ אֶת־יְהֹוָה וַתִּקְצַר נַפְשׁוֹ בַּעֲמַל יִשְׂרָאֵל׃}
}
{
	\eX{
		And they put away the foreign gods from among them, and served
		YHWH: and his soul was grieved for the misery of Israel.
	}
}
{
}

\Verse{17}
{
	\hX{וַיִּצָּעֲקוּ בְּנֵי עַמּוֹן וַיַּחֲנוּ בַּגִּלְעָד וַיֵּאָסְפוּ בְּנֵי יִשְׂרָאֵל וַיַּחֲנוּ בַּמִּצְפָּה׃}
}
{
	\eX{
		Then the children of Ammon were gathered, and encamped in
		Gilead. And the children of Israel assembled themselves
		together, and encamped in Mizpah.
	}
}
{
}

\Verse{18}
{
	\hX{וַיֹּאמְרוּ הָעָם שָׂרֵי גִלְעָד אִישׁ אֶל־רֵעֵהוּ מִי הָאִישׁ אֲשֶׁר יָחֵל לְהִלָּחֵם בִּבְנֵי עַמּוֹן יִהְיֶה לְרֹאשׁ לְכֹל יֹשְׁבֵי גִלְעָד׃}
}
{
	\eX{
		And the people and princes of Gilead said one to another, What
		man is he that will begin to fight against the children of
		Ammon? he shall be head over all the inhabitants of Gilead.
	}
}
{
}
