\Chapter{2}

\Verse{1}
{
	\hX{
		וַיַּעַל מַלְאַךְ־יְהֹוָה מִן־הַגִּלְגָּל אֶל־הַבֹּכִיםוַיֹּאמֶר אַעֲלֶה אֶתְכֶם מִמִּצְרַיִם וָאָבִיא אֶתְכֶם אֶל־הָאָרֶץ אֲשֶׁר נִשְׁבַּעְתִּי לַאֲבֹתֵיכֶם וָאֹמַר לֹא־אָפֵר
		בְּרִיתִי אִתְּכֶם לְעוֹלָם׃
	}
}
{
	\eX{
		And an angel of YHWH came up from Gilgal to Bochim, and said, I
		brought you up out of Egypt, and I brought you to the land that
		I swore to your fathers: and I said, I will not break my
		covenant with you.
	}
}
{
}

\Verse{2}
{
	\hX{וְאַתֶּם לֹא־תִכְרְתוּ בְרִית לְיוֹשְׁבֵי הָאָרֶץ הַזֹּאת מִזְבְּחוֹתֵיהֶם תִּתֹּצוּן וְלֹא־שְׁמַעְתֶּם בְּקוֹלִי מַה־זֹּאת עֲשִׂיתֶם׃}
}
{
	\eX{
		And you shall make no covenant with the inhabitants of this
		land; you shall break down their altars: but you have not
		listened to my voice: why have you done this?
	}
}
{
}

\Verse{3}
{
	\hX{וְגַם אָמַרְתִּי לֹא־אֲגָרֵשׁ אוֹתָם מִפְּנֵיכֶם וְהָיוּ לָכֶם לְצִדִּים וֵאלֹהֵיהֶם יִהְיוּ לָכֶם לְמוֹקֵשׁ׃}
}
{
	\eX{
		And I also said, I’ll not drive them out from in front of you;
		but they shall be as thorns in your sides, and their gods shall
		be a snare to you.
	}
}
{
}

\Verse{4}
{
	\hX{וַיְהִי כְּדַבֵּר מַלְאַךְ יְהֹוָה אֶת־הַדְּבָרִים הָאֵלֶּה אֶל־כּל־בְּנֵי יִשְׂרָאֵל וַיִּשְׂאוּ הָעָם אֶת־קוֹלָם וַיִּבְכּוּ׃}
}
{
	\eX{
		And it was when the angel of YHWH spoke these words to all the
		children of Israel, that the people lifted their voice, and
		wept.
	}
}
{
}

\Verse{5}
{
	\hX{וַיִּקְרְאוּ שֵׁם־הַמָּקוֹם הַהוּא בֹּכִים וַיִּזְבְּחוּ־שָׁם לַיהֹוָה׃}
}
{
	\eX{
		And they called the name of that place Bochim: and they
		sacrificed there to YHWH.
	}
}
{
}

\Verse{6}
{
	\hX{וַיְשַׁלַּח יְהוֹשֻׁעַ אֶת־הָעָם וַיֵּלְכוּ בְנֵי־יִשְׂרָאֵל אִישׁ לְנַחֲלָתוֹ לָרֶשֶׁת אֶת־הָאָרֶץ׃}
}
{
	\eX{
		And when Joshua had let the people go, the children of Israel
		went each man to his legacy to take possession of the land.
	}
}
{
}

\Verse{7}
{
	\hX{
		וַיַּעַבְדוּ הָעָם אֶת־יְהֹוָה כֹּל יְמֵי יְהוֹשֻׁעַ וְכֹל יְמֵי הַזְּקֵנִים אֲשֶׁר הֶאֱרִיכוּ יָמִים אַחֲרֵי יְהוֹשׁוּעַ אֲשֶׁר רָאוּ אֵת כּל־מַעֲשֵׂה יְהֹוָה הַגָּדוֹל אֲשֶׁר
		עָשָׂה לְיִשְׂרָאֵל׃
	}
}
{
	\eX{
		And the people served YHWH all the days of Joshua, and all the
		days of the elders that lengthened days after Joshua, who had
		seen all the great work of YHWH, that he did for Israel.
	}
}
{
}

\Verse{8}
{
	\hX{וַיָּמת יְהוֹשֻׁעַ בִּן־נוּן עֶבֶד יְהֹוָה בֶּן־מֵאָה וָעֶשֶׂר שָׁנִים׃}
}
{
	\eX{
		And Joshua the son of Nun, the servant of YHWH, died, a hundred
		and ten years old.
	}
}
{
}

\Verse{9}
{
	\hX{וַיִּקְבְּרוּ אוֹתוֹ בִּגְבוּל נַחֲלָתוֹ בְּתִמְנַת־חֶרֶס בְּהַר אֶפְרָיִם מִצְּפוֹן לְהַר־גָּעַשׁ׃}
}
{
	\eX{
		And they buried him in the border of his legacy in
		Timnath-heres, in the Mountain of Ephraim, on the north side of
		the Mount Gaash.
	}
}
{
}

\Verse{10}
{
	\hX{וְגַם כּל־הַדּוֹר הַהוּא נֶאֶסְפוּ אֶל־אֲבוֹתָיו וַיָּקם דּוֹר אַחֵר אַחֲרֵיהֶם אֲשֶׁר לֹא־יָדְעוּ אֶת־יְהֹוָה וְגַם אֶת־הַמַּעֲשֶׂה אֲשֶׁר עָשָׂה לְיִשְׂרָאֵל׃}
}
{
	\eX{
		And also all that generation were gathered to their fathers, and
		another generation got up after them that did not know YHWH, and
		also the work that He had done for Israel.
	}
}
{
%	\footnote{
%		Footnote 2:10. A generation that did not know YHWH is not ignorance as lack of
%		data. In this book, not knowing becomes not serving, and then serving the wrong
%		gods.
%	}
}

\Verse{11}
{
	\hX{וַיַּעֲשׂוּ בְנֵי־יִשְׂרָאֵל אֶת־הָרַע בְּעֵינֵי יְהֹוָה וַיַּעַבְדוּ אֶת־הַבְּעָלִים׃}
}
{
	\eX{
		And the children of Israel did what was bad in the eyes of YHWH,
		and served Baals:
	}
}
{
}

\Verse{12}
{
	\hX{
		וַיַּעַזְבוּ אֶת־יְהֹוָה אֱלֹהֵי אֲבוֹתָם הַמּוֹצִיא אוֹתָם מֵאֶרֶץ מִצְרַיִם וַיֵּלְכוּ אַחֲרֵי אֱלֹהִים אֲחֵרִים מֵאֱלֹהֵי הָעַמִּים אֲשֶׁר סְבִיבוֹתֵיהֶם וַיִּשְׁתַּחֲווּ לָהֶם
		וַיַּכְעִסוּ אֶת־יְהֹוָה׃
	}
}
{
	\eX{
		And they forsook YHWH God of their fathers, that brought them
		out of the land of Egypt, and followed other gods, of the gods
		of the peoples that were around them, and bowed to them, and
		angered YHWH.
	}
}
{
}

\Verse{13}
{
	\hX{וַיַּעַזְבוּ אֶת־יְהֹוָה וַיַּעַבְדוּ לַבַּעַל וְלָעַשְׁתָּרוֹת׃}
}
{
	\eX{And they forsook YHWH, and served the Baal and the Ashtaroth.}
}
{
}

\Verse{14}
{
	\hX{וַיִּחַר־אַף יְהֹוָה בְּיִשְׂרָאֵל וַיִּתְּנֵם בְּיַד־שֹׁסִים וַיָּשֹׁסּוּ אוֹתָם וַיִּמְכְּרֵם בְּיַד אוֹיְבֵיהֶם מִסָּבִיב וְלֹא־יָכְלוּ עוֹד לַעֲמֹד לִפְנֵי אוֹיְבֵיהֶם׃}
}
{
	\eX{
		And the anger of YHWH was hot against Israel, and he gave them
		in the hand of plunderers, and they plundered them, and he sold
		them in the hands of their enemies all around, so that they
		could not any longer stand before their enemies.
	}
}
{
}

\Verse{15}
{
	\hX{בְּכֹל אֲשֶׁר יָצְאוּ יַד־יְהֹוָה הָיְתָה־בָּם לְרָעָה כַּאֲשֶׁר דִּבֶּר יְהֹוָה וְכַאֲשֶׁר נִשְׁבַּע יְהֹוָה לָהֶם וַיֵּצֶר לָהֶם מְאֹד׃}
}
{
	\eX{
		Wherever they went out, the hand of YHWH was against them for
		bad, as YHWH had said, and as YHWH had sworn to them: and they
		were greatly distressed.
	}
}
{
}

\Verse{16}
{
	\hX{וַיָּקֶם יְהֹוָה שֹׁפְטִים וַיּוֹשִׁיעוּם מִיַּד שֹׁסֵיהֶם׃}
}
{
	\eX{
		Nevertheless YHWH raised up judges, that rescued them from the
		hand of those that plundered them.
	}
}
{
}

\Verse{17}
{
	\hX{
		וְגַם אֶל־שֹׁפְטֵיהֶם לֹא שָׁמֵעוּ כִּי זָנוּ אַחֲרֵי אֱלֹהִים אֲחֵרִים וַיִּשְׁתַּחֲווּ לָהֶם סָרוּ מַהֵר מִן־הַדֶּרֶךְ אֲשֶׁר הָלְכוּ אֲבוֹתָם לִשְׁמֹעַ מִצְוֺת־יְהֹוָה
		לֹא־עָשׂוּ כֵן׃
	}
}
{
	\eX{
		And yet they would not listen to their judges, but they whored
		after other gods, and bowed to them: they turned quickly out of
		the way that their fathers walked in, obeying YHWH’s
		commandments; but they did not do so.
	}
}
{
}

\Verse{18}
{
	\hX{
		וְכִי־הֵקִים יְהֹוָה לָהֶם שֹׁפְטִים וְהָיָה יְהֹוָה עִם־הַשֹּׁפֵט וְהוֹשִׁיעָם מִיַּד אֹיְבֵיהֶם כֹּל יְמֵי הַשּׁוֹפֵט כִּי־יִנָּחֵם יְהֹוָה מִנַּאֲקָתָם מִפְּנֵי לֹחֲצֵיהֶם
		וְדֹחֲקֵיהֶם׃
	}
}
{
	\eX{
		And when YHWH raised them up judges, then YHWH was with the
		judge, and rescued them from the hand of their enemies all the
		days of the judge: for it YHWH was moved by their groaning
		because of those pressing them and squeezing them.
	}
}
{
}

\Verse{19}
{
	\hX{
		וְהָיָה בְּמוֹת הַשּׁוֹפֵט יָשֻׁבוּ וְהִשְׁחִיתוּ מֵאֲבוֹתָם לָלֶכֶת אַחֲרֵי אֱלֹהִים אֲחֵרִים לְעבְדָם וּלְהִשְׁתַּחֲוֺת לָהֶם לֹא הִפִּילוּ מִמַּעַלְלֵיהֶם וּמִדַּרְכָּם
		הַקָּשָׁה׃
	}
}
{
	\eX{
		And it was when the judge was dead, that they returned, and
		corrupted themselves more than their fathers, in following other
		gods to serve them, and to bow down to them; they did not drop
		from their own doings, and not from their stubborn way.
	}
}
{
}

\Verse{20}
{
	\hX{וַיִּחַר־אַף יְהֹוָה בְּיִשְׂרָאֵל וַיֹּאמֶר יַעַן אֲשֶׁר עָבְרוּ הַגּוֹי הַזֶּה אֶת־בְּרִיתִי אֲשֶׁר צִוִּיתִי אֶת־אֲבוֹתָם וְלֹא שָׁמְעוּ לְקוֹלִי׃}
}
{
	\eX{
		And the anger of YHWH was hot against Israel: and he said,
		Because this people have transgressed my covenant that I
		commanded their fathers, and have not listened to my voice;
	}
}
{
}

\Verse{21}
{
	\hX{גַּם־אֲנִי לֹא אוֹסִיף לְהוֹרִישׁ אִישׁ מִפְּנֵיהֶם מִן־הַגּוֹיִם אֲשֶׁר־עָזַב יְהוֹשֻׁעַ וַיָּמֹת׃}
}
{
	\eX{
		I also won’t again drive out any from in front of them of the
		nations that Joshua left when he died:
	}
}
{
}

\Verse{22}
{
	\hX{לְמַעַן נַסּוֹת בָּם אֶת־יִשְׂרָאֵל הֲשֹׁמְרִים הֵם אֶת־דֶּרֶךְ יְהֹוָה לָלֶכֶת בָּם כַּאֲשֶׁר שָׁמְרוּ אֲבוֹתָם אִם־לֹא׃}
}
{
	\eX{
		That through them I may test Israel, whether they are keeping
		the way of YHWH to walk in it, as their fathers kept it, or not.
	}
}
{
}

\Verse{23}
{
	\hX{וַיַּנַּח יְהֹוָה אֶת־הַגּוֹיִם הָאֵלֶּה לְבִלְתִּי הוֹרִישָׁם מַהֵר וְלֹא נְתָנָם בְּיַד־יְהוֹשֻׁעַ׃}
}
{
	\eX{
		Therefore YHWH left those nations, without driving them out
		hastily: and He did not give them in the hand of Joshua.
	}
}
{
}
