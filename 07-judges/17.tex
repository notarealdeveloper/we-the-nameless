\Chapter{17}

\Verse{1}
{
	\hX{וַיְהִי־אִישׁ מֵהַר־אֶפְרָיִם וּשְׁמוֹ מִיכָיְהוּ׃}
}
{
	\eX{
		And there was a man of Mountain of Ephraim, whose name was
		Micah.
	}
}
{
}

\Verse{2}
{
	\hX{
		וַיֹּאמֶר לְאִמּוֹ אֶלֶף וּמֵאָה הַכֶּסֶף אֲשֶׁר לֻקַּח־לָךְ (ואתי) [וְאַתְּ] אָלִית וְגַם אָמַרְתְּ בְּאזְנַי הִנֵּה־הַכֶּסֶף אִתִּי אֲנִי לְקַחְתִּיו וַתֹּאמֶר אִמּוֹ בָּרוּךְ
		בְּנִי לַיהֹוָה׃
	}
}
{
	\eX{
		And he said to his mother, The eleven hundred shekels of silver
		that was taken from you, about that you cursed, and spoke of
		also in my ears, here, the silver is with me; I took it. And his
		mother said, Blessed be you of YHWH, my son.
	}
}
{
}

\Verse{3}
{
	\hX{
		וַיָּשֶׁב אֶת־אֶלֶף־וּמֵאָה הַכֶּסֶף לְאִמּוֹ וַתֹּאמֶר אִמּוֹ הַקְדֵּשׁ הִקְדַּשְׁתִּי אֶת־הַכֶּסֶף לַיהֹוָה מִיָּדִי לִבְנִי לַעֲשׂוֹת פֶּסֶל וּמַסֵּכָה וְעַתָּה אֲשִׁיבֶנּוּ
		לָךְ׃
	}
}
{
	\eX{
		And when he had restored the eleven hundred shekels of silver to
		his mother, his mother said, I had wholly dedicated the silver
		to YHWH from my hand for my son, to make a carved image and a
		cast image: now therefore I’ll restore it to you.
	}
}
{
}

\Verse{4}
{
	\hX{וַיָּשֶׁב אֶת־הַכֶּסֶף לְאִמּוֹ וַתִּקַּח אִמּוֹ מָאתַיִם כֶּסֶף וַתִּתְּנֵהוּ לַצּוֹרֵף וַיַּעֲשֵׂהוּ פֶּסֶל וּמַסֵּכָה וַיְהִי בְּבֵית מִיכָיְהוּ׃}
}
{
	\eX{
		Yet he restored the money to his mother: and his mother took two
		hundred shekels of silver, and gave them to the founder, who
		made of it a carved image and a cast image: and they were in the
		house of Micah.
	}
}
{
}

\Verse{5}
{
	\hX{וְהָאִישׁ מִיכָה לוֹ בֵּית אֱלֹהִים וַיַּעַשׂ אֵפוֹד וּתְרָפִים וַיְמַלֵּא אֶת־יַד אַחַד מִבָּנָיו וַיְהִי־לוֹ לְכֹהֵן׃}
}
{
	\eX{
		And the man Micah had a house of gods, and made an ephod, and
		teraphim, and consecrated one of his sons, who became his
		priest.
	}
}
{
}

\Verse{6}
{
	\hX{בַּיָּמִים הָהֵם אֵין מֶלֶךְ בְּיִשְׂרָאֵל אִישׁ הַיָּשָׁר בְּעֵינָיו יַעֲשֶׂה׃}
}
{
	\eX{
		In those days there was no king in Israel: each man would do
		what was straight in his eyes.
	}
}
{
%	\footnote{
%		Footnote 17:6. No king in Israel is not a neutral date-stamp. It is the book's
%		refrain for moral weather.
%	}
}

\Verse{7}
{
	\hX{וַיְהִי־נַעַר מִבֵּית לֶחֶם יְהוּדָה מִמִּשְׁפַּחַת יְהוּדָה וְהוּא לֵוִי וְהוּא גָר־שָׁם׃}
}
{
	\eX{
		And there was a young man out of Bethlehem in Judah of the
		family of Judah, who was a Levite, and he sojourned there.
	}
}
{
}

\Verse{8}
{
	\hX{וַיֵּלֶךְ הָאִישׁ מֵהָעִיר מִבֵּית לֶחֶם יְהוּדָה לָגוּר בַּאֲשֶׁר יִמְצָא וַיָּבֹא הַר־אֶפְרַיִם עַד־בֵּית מִיכָה לַעֲשׂוֹת דַּרְכּוֹ׃}
}
{
	\eX{
		And the man departed out of the city from Bethlehem in Judah to
		sojourn where he could find a place: and he came to Mountain of
		Ephraim to the house of Micah, as he journeyed.
	}
}
{
}

\Verse{9}
{
	\hX{וַיֹּאמֶר־לוֹ מִיכָה מֵאַיִן תָּבוֹא וַיֹּאמֶר אֵלָיו לֵוִי אָנֹכִי מִבֵּית לֶחֶם יְהוּדָה וְאָנֹכִי הֹלֵךְ לָגוּר בַּאֲשֶׁר אֶמְצָא׃}
}
{
	\eX{
		And Micah said to him, Whence are you coming? And he said to
		him, I’m a Levite of Bethlehem in Judah, and I go to sojourn
		where I may find a place.
	}
}
{
}

\Verse{10}
{
	\hX{וַיֹּאמֶר לוֹ מִיכָה שְׁבָה עִמָּדִי וֶהְיֵה־לִי לְאָב וּלְכֹהֵן וְאָנֹכִי אֶתֶּן־לְךָ עֲשֶׂרֶת כֶּסֶף לַיָּמִים וְעֵרֶךְ בְּגָדִים וּמִחְיָתֶךָ וַיֵּלֶךְ הַלֵּוִי׃}
}
{
	\eX{
		And Micah said to him, Live with me, and be to me a father and a
		priest, and I’ll give you ten shekels of silver for the days,
		and a array of clothes, and your provisions. So the Levite went
		in.
	}
}
{
}

\Verse{11}
{
	\hX{וַיּוֹאֶל הַלֵּוִי לָשֶׁבֶת אֶת־הָאִישׁ וַיְהִי הַנַּעַר לוֹ כְּאַחַד מִבָּנָיו׃}
}
{
	\eX{
		And the Levite was content to live with the man: and the young
		man was to him as one of his sons.
	}
}
{
}

\Verse{12}
{
	\hX{וַיְמַלֵּא מִיכָה אֶת־יַד הַלֵּוִי וַיְהִי־לוֹ הַנַּעַר לְכֹהֵן וַיְהִי בְּבֵית מִיכָה׃}
}
{
	\eX{
		And Micah consecrated the Levite: and the young man became his
		priest, and was in the house of Micah.
	}
}
{
}

\Verse{13}
{
	\hX{וַיֹּאמֶר מִיכָה עַתָּה יָדַעְתִּי כִּי־יֵיטִיב יְהֹוָה לִי כִּי הָיָה־לִי הַלֵּוִי לְכֹהֵן׃}
}
{
	\eX{
		And Micah said, Now I know that YHWH will do me good, seeing
		I’ve a Levite as my priest.
	}
}
{
}
