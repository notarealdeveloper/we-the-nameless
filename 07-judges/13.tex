{
	\eJ{

}

	\eJ{

{
	\hJ{
		כִּי הִנָּךְ הָרָה וְיֹלַדְתְּ בֵּן וּמוֹרָה לֹא־יַעֲלֶה עַל־רֹאשׁוֹ כִּי־נְזִיר אֱלֹהִים יִהְיֶה הַנַּעַר מִן־הַבָּטֶן וְהוּא יָחֵל לְהוֹשִׁיעַ אֶת־יִשְׂרָאֵל מִיַּד
		פְּלִשְׁתִּים׃

}
{
	\eJ{
		For, lo, you shall conceive, and bear a son: and no razor shall
		come on his head: for the child shall be a Nazirite to God from
		the womb: and he shall begin to rescue Israel from the hand of
		the Philistines.
	}
}
{
}

		לֹא־הִגִּיד לִי׃
	}
}
{
	\eJ{
		Then the woman came and told her husband, saying, A man of God
		came to me, and his countenance was like the countenance of an
		angel of God, very terrible: but I asked him not from where he
		was, and not told he me his name:
	}
}
{
}

\Verse{7}
{
	\hJ{וַיֹּאמֶר לִי הִנָּךְ הָרָה וְיֹלַדְתְּ בֵּן וְעַתָּה אַל־תִּשְׁתִּי יַיִן וְשֵׁכָר וְאַל־תֹּאכְלִי כּל־טֻמְאָה כִּי־נְזִיר אֱלֹהִים יִהְיֶה הַנַּעַר מִן־הַבֶּטֶן עַד־יוֹם מוֹתוֹ׃}
}
{
	\eJ{
		But he said to me, Here, you shall conceive, and bear a son: and
		now drink no wine and not strong drink, and not eat any unclean
		thing: for the child shall be a Nazirite to God from the womb to
		the day of his death.
	}
}
{
}

}
{
	\eJ{

{
}
