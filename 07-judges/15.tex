\Verse{1}
{
	\hJ{וַיְהִי מִיָּמִים בִּימֵי קְצִיר־חִטִּים וַיִּפְקֹד שִׁמְשׁוֹן אֶת־אִשְׁתּוֹ בִּגְדִי עִזִּים וַיֹּאמֶר אָבֹאָה אֶל־אִשְׁתִּי הֶחָדְרָה וְלֹא־נְתָנוֹ אָבִיהָ לָבוֹא׃}
}
{
	\eJ{
		Some time later, in the season of the wheat harvest, Samson came
		to visit his wife, bringing a kid as a gift. He said, “Let me go
		into the chamber to my wife.” But her father would not let him go
		in.
	}
}
{
}

\Verse{2}
{
	\hJ{וַיֹּאמֶר אָבִיהָ אָמֹר אָמַרְתִּי כִּי־שָׂנֹא שְׂנֵאתָהּ וָאֶתְּנֶנָּה לְמֵרֵעֶךָ הֲלֹא אֲחוֹתָהּ הַקְּטַנָּה טוֹבָה מִמֶּנָּה תְּהִי־נָא לְךָ תַּחְתֶּיהָ׃}
}
{
	\eJ{
		“I was sure,” said her father, “that you had taken a dislike to
		her, so I gave her to your wedding companion. But her younger
		sister is more beautiful than she; let her become your wife
		instead.”
	}
}
{
}

\Verse{3}
{
	\hJ{וַיֹּאמֶר לָהֶם שִׁמְשׁוֹן נִקֵּיתִי הַפַּעַם מִפְּלִשְׁתִּים כִּי־עֹשֶׂה אֲנִי עִמָּם רָעָה׃}
}
{
	\eJ{

	}
}
{
}

\Verse{4}
{
	\hJ{וַיֵּלֶךְ שִׁמְשׁוֹן וַיִּלְכֹּד שְׁלֹשׁ־מֵאוֹת שׁוּעָלִים וַיִּקַּח לַפִּדִים וַיֶּפֶן זָנָב אֶל־זָנָב וַיָּשֶׂם לַפִּיד אֶחָד בֵּין־שְׁנֵי הַזְּנָבוֹת בַּתָּוֶךְ׃}
}
{
	\eJ{
		Samson went and caught three hundred foxes. He took torches and,
		turning [the foxes] tail to tail, he placed a torch between each
		pair of tails.
	}
}
{
}

\Verse{5}
{
	\hJ{וַיַּבְעֶר־אֵשׁ בַּלַּפִּידִים וַיְשַׁלַּח בְּקָמוֹת פְּלִשְׁתִּים וַיַּבְעֵר מִגָּדִישׁ וְעַד־קָמָה וְעַד־כֶּרֶם זָיִת׃}
}
{
	\eJ{
		He lit the torches and turned [the foxes] loose among the standing
		grain of the Philistines, setting fire to stacked grain, standing
		grain, vineyards, [and] olive trees.
	}
}
{
}

\Verse{6}
{
	\hJ{
		וַיֹּאמְרוּ פְלִשְׁתִּים מִי עָשָׂה זֹאת וַיֹּאמְרוּ שִׁמְשׁוֹן חֲתַן הַתִּמְנִי כִּי לָקַח אֶת־אִשְׁתּוֹ וַיִּתְּנָהּ לְמֵרֵעֵהוּ וַיַּעֲלוּ פְלִשְׁתִּים וַיִּשְׂרְפוּ אוֹתָהּ
		וְאֶת־אָבִיהָ בָּאֵשׁ׃
	}
}
{
	\eJ{
		The Philistines asked, “Who did this?” And they were told, “It was
		Samson, the son-in-law of the Timnite, who took Samson’s wife and
		gave her to his wedding companion.” Thereupon the Philistines came
		up and put her and her father to the fire.
	}
}
{
}

{
	\hJ{וַיֹּאמֶר לָהֶם שִׁמְשׁוֹן אִם־תַּעֲשׂוּן כָּזֹאת כִּי אִם־נִקַּמְתִּי בָכֶם וְאַחַר אֶחְדָּל׃}
}
{
	\eJ{

{
}

	\hJ{וַיַּךְ אוֹתָם שׁוֹק עַל־יָרֵךְ מַכָּה גְדוֹלָה וַיֵּרֶד וַיֵּשֶׁב בִּסְעִיף סֶלַע עֵיטָם׃}
}
{
	\eJ{

}
{
}

\Verse{9}
{
	\hJ{וַיַּעֲלוּ פְלִשְׁתִּים וַיַּחֲנוּ בִּיהוּדָה וַיִּנָּטְשׁוּ בַּלֶּחִי׃}
}

}

\Verse{10}

}

{
}

\Verse{11}
{
	\hJ{

		וַיֹּאמֶר לָהֶם כַּאֲשֶׁר עָשׂוּ לִי כֵּן עָשִׂיתִי לָהֶם׃
	}
}
{
	\eJ{
		Thereupon three thousand men of Judah went down to the cave of the
		rock of Etam, and they said to Samson, “You knew that the
		Philistines rule over us; why have you done this to us?” He
		replied, “As they did to me, so I did to them.”
	}
}
{
}

\Verse{12}

}
{
	\eJ{
		“We have come down,” they told him, “to take you prisoner and to

		to them, “that you yourselves will not attack me.”
	}
}
{
}

\Verse{13}
{
	\hJ{וַיֹּאמְרוּ לוֹ לֵאמֹר לֹא כִּי־אָסֹר נֶאֱסרְךָ וּנְתַנּוּךָ בְיָדָם וְהָמֵת לֹא נְמִיתֶךָ וַיַּאַסְרֻהוּ בִּשְׁנַיִם עֲבֹתִים חֲדָשִׁים וַיַּעֲלוּהוּ מִן־הַסָּלַע׃}
}
{
	\eJ{
		“We won’t,” they replied. “We will only take you prisoner and hand
		you over to them; we will not slay you.” So they bound him with

	}
}
{
}

\Verse{14}
{
	\hJ{

	}
}
{
	\eJ{
		When he reached Lehi, the Philistines came shouting to meet him.
		Thereupon the spirit of YHWH gripped him, and the ropes on his

		hands.
	}
}
{
}

}

}
{
}

\Verse{19}

}
