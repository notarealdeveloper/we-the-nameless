\Chapter{15}

\Verse{1}
{
	\hJ{וַיְהִי מִיָּמִים בִּימֵי קְצִיר־חִטִּים וַיִּפְקֹד שִׁמְשׁוֹן אֶת־אִשְׁתּוֹ בִּגְדִי עִזִּים וַיֹּאמֶר אָבֹאָה אֶל־אִשְׁתִּי הֶחָדְרָה וְלֹא־נְתָנוֹ אָבִיהָ לָבוֹא׃}
}
{
	\eJ{
		But it was after days, in the time of wheat harvest, that Samson
		visited his wife with a kid: and he said, I’ll go in to my wife
		to the room. But her father would not allow him to go in.
	}
}
{
}

\Verse{2}
{
	\hJ{וַיֹּאמֶר אָבִיהָ אָמֹר אָמַרְתִּי כִּי־שָׂנֹא שְׂנֵאתָהּ וָאֶתְּנֶנָּה לְמֵרֵעֶךָ הֲלֹא אֲחוֹתָהּ הַקְּטַנָּה טוֹבָה מִמֶּנָּה תְּהִי־נָא לְךָ תַּחְתֶּיהָ׃}
}
{
	\eJ{
		And her father said, I verily thought that you had completely
		hated her; therefore I gave her to your companion: isn’t her
		younger sister fairer than she? take her, please, instead of
		her.
	}
}
{
}

\Verse{3}
{
	\hJ{וַיֹּאמֶר לָהֶם שִׁמְשׁוֹן נִקֵּיתִי הַפַּעַם מִפְּלִשְׁתִּים כִּי־עֹשֶׂה אֲנִי עִמָּם רָעָה׃}
}
{
	\eJ{
		And Samson said concerning them, And shall I be more blameless
		than the Philistines, though I do them a displeasure.
	}
}
{
}

\Verse{4}
{
	\hJ{וַיֵּלֶךְ שִׁמְשׁוֹן וַיִּלְכֹּד שְׁלֹשׁ־מֵאוֹת שׁוּעָלִים וַיִּקַּח לַפִּדִים וַיֶּפֶן זָנָב אֶל־זָנָב וַיָּשֶׂם לַפִּיד אֶחָד בֵּין־שְׁנֵי הַזְּנָבוֹת בַּתָּוֶךְ׃}
}
{
	\eJ{
		And Samson went and caught three hundred foxes, and took
		firebrands, and turned tail to tail, and put a firebrand inside
		between two tails.
	}
}
{
}

\Verse{5}
{
	\hJ{וַיַּבְעֶר־אֵשׁ בַּלַּפִּידִים וַיְשַׁלַּח בְּקָמוֹת פְּלִשְׁתִּים וַיַּבְעֵר מִגָּדִישׁ וְעַד־קָמָה וְעַד־כֶּרֶם זָיִת׃}
}
{
	\eJ{
		And when he had set the brands on fire, he let them go into the
		standing corn of the Philistines, and burned up both the shocks,
		and also the standing corn, with the vineyards and olives.
	}
}
{
}

\Verse{6}
{
	\hJ{
		וַיֹּאמְרוּ פְלִשְׁתִּים מִי עָשָׂה זֹאת וַיֹּאמְרוּ שִׁמְשׁוֹן חֲתַן הַתִּמְנִי כִּי לָקַח אֶת־אִשְׁתּוֹ וַיִּתְּנָהּ לְמֵרֵעֵהוּ וַיַּעֲלוּ פְלִשְׁתִּים וַיִּשְׂרְפוּ אוֹתָהּ
		וְאֶת־אָבִיהָ בָּאֵשׁ׃
	}
}
{
	\eJ{
		Then the Philistines said, Who has done this? And they answered,
		Samson, the son-in-law of the Timnite, because he captured his
		wife, and given her to his companion. And the Philistines came
		up, and burned her and her father with fire.
	}
}
{
}

\Verse{7}
{
	\hJ{וַיֹּאמֶר לָהֶם שִׁמְשׁוֹן אִם־תַּעֲשׂוּן כָּזֹאת כִּי אִם־נִקַּמְתִּי בָכֶם וְאַחַר אֶחְדָּל׃}
}
{
	\eJ{
		And Samson said to them, Yough you have done this, yet will I be
		avenged of you, and after that I’ll cease.
	}
}
{
}

\Verse{8}
{
	\hJ{וַיַּךְ אוֹתָם שׁוֹק עַל־יָרֵךְ מַכָּה גְדוֹלָה וַיֵּרֶד וַיֵּשֶׁב בִּסְעִיף סֶלַע עֵיטָם׃}
}
{
	\eJ{
		And he struck them hip and thigh with a great slaughter: and he
		went down and lived in the top of the rock Etam.
	}
}
{
}

\Verse{9}
{
	\hJ{וַיַּעֲלוּ פְלִשְׁתִּים וַיַּחֲנוּ בִּיהוּדָה וַיִּנָּטְשׁוּ בַּלֶּחִי׃}
}
{
	\eJ{
		Then the Philistines went up, and pitched in Judah, and spread
		themselves in Lehi.
	}
}
{
}

\Verse{10}
{
	\hJ{וַיֹּאמְרוּ אִישׁ יְהוּדָה לָמָה עֲלִיתֶם עָלֵינוּ וַיֹּאמְרוּ לֶאֱסוֹר אֶת־שִׁמְשׁוֹן עָלִינוּ לַעֲשׂוֹת לוֹ כַּאֲשֶׁר עָשָׂה לָנוּ׃}
}
{
	\eJ{
		And the men of Judah said, Why are you come up against us? And
		they answered, To bind Samson are we come up, to do to him as he
		has done to us.
	}
}
{
}

\Verse{11}
{
	\hJ{
		וַיֵּרְדוּ שְׁלֹשֶׁת אֲלָפִים אִישׁ מִיהוּדָה אֶל־סְעִיף סֶלַע עֵיטָם וַיֹּאמְרוּ לְשִׁמְשׁוֹן הֲלֹא יָדַעְתָּ כִּי־מֹשְׁלִים בָּנוּ פְּלִשְׁתִּים וּמַה־זֹּאת עָשִׂיתָ לָּנוּ
		וַיֹּאמֶר לָהֶם כַּאֲשֶׁר עָשׂוּ לִי כֵּן עָשִׂיתִי לָהֶם׃
	}
}
{
	\eJ{
		Then three thousand men of Judah went to the top of the rock
		Etam, and said to Samson, Don’t you know that the Philistines
		are rulers over us? what is this that you have done to us? And
		he said to them, As they did to me, so have I done to them.
	}
}
{
}

\Verse{12}
{
	\hJ{וַיֹּאמְרוּ לוֹ לֶאֱסרְךָ יָרַדְנוּ לְתִתְּךָ בְּיַד־פְּלִשְׁתִּים וַיֹּאמֶר לָהֶם שִׁמְשׁוֹן הִשָּׁבְעוּ לִי פֶּן־תִּפְגְּעוּן בִּי אַתֶּם׃}
}
{
	\eJ{
		And they said to him, We are come down to bind you, that we may
		rescue you in the hand of the Philistines. And Samson said to
		them, Swear to me, that you’ll not fall upon me yourselves.
	}
}
{
}

\Verse{13}
{
	\hJ{וַיֹּאמְרוּ לוֹ לֵאמֹר לֹא כִּי־אָסֹר נֶאֱסרְךָ וּנְתַנּוּךָ בְיָדָם וְהָמֵת לֹא נְמִיתֶךָ וַיַּאַסְרֻהוּ בִּשְׁנַיִם עֲבֹתִים חֲדָשִׁים וַיַּעֲלוּהוּ מִן־הַסָּלַע׃}
}
{
	\eJ{
		And they spoke to him, saying, No: but we’ll bind you fast, and
		rescue you into their hand: but surely we’ll not kill you. And
		they bound him with two new cords, and brought him up from the
		rock.
	}
}
{
}

\Verse{14}
{
	\hJ{
		הוּא־בָא עַד־לֶחִי וּפְלִשְׁתִּים הֵרִיעוּ לִקְרָאתוֹ וַתִּצְלַח עָלָיו רוּחַ יְהֹוָה וַתִּהְיֶינָה הָעֲבֹתִים אֲשֶׁר עַל־זְרוֹעוֹתָיו כַּפִּשְׁתִּים אֲשֶׁר בָּעֲרוּ בָאֵשׁ
		וַיִּמַּסּוּ אֱסוּרָיו מֵעַל יָדָיו׃
	}
}
{
	\eJ{
		And when he came to Lehi, the Philistines shouted against him:
		and spirit of YHWH came mightily upon him, and the cords that
		were upon his arms became as flax that was burned with fire, and
		his bands loosed from off his hands.
	}
}
{
}

\Verse{15}
{
	\hJ{וַיִּמְצָא לְחִי־חֲמוֹר טְרִיָּה וַיִּשְׁלַח יָדוֹ וַיִּקָּחֶהָ וַיַּךְ־בָּהּ אֶלֶף אִישׁ׃}
}

}
{
}

\Verse{16}
{
	\hJ{וַיֹּאמֶר שִׁמְשׁוֹן בִּלְחִי הַחֲמוֹר חֲמוֹר חֲמֹרָתָיִם בִּלְחִי הַחֲמוֹר הִכֵּיתִי אֶלֶף אִישׁ׃}
}
{
	\eJ{
		And Samson said, With the jawbone of an ass, heaps upon heaps,
		with the jaw of an ass have I killed a thousand companions.
	}
}
{
}

\Verse{17}
{
	\hJ{וַיְהִי כְּכַלֹּתוֹ לְדַבֵּר וַיַּשְׁלֵךְ הַלְּחִי מִיָּדוֹ וַיִּקְרָא לַמָּקוֹם הַהוּא רָמַת לֶחִי׃}
}
{
	\eJ{
		And it was when he had made an end of speaking, that he cast

	}
}
{
}

\Verse{18}
{
	\hJ{וַיִּצְמָא מְאֹד וַיִּקְרָא אֶל־יְהֹוָה וַיֹּאמַר אַתָּה נָתַתָּ בְיַד־עַבְדְּךָ אֶת־הַתְּשׁוּעָה הַגְּדֹלָה הַזֹּאת וְעַתָּה אָמוּת בַּצָּמָא וְנָפַלְתִּי בְּיַד הָעֲרֵלִים׃}
}
{
	\eJ{
		And he was sore athirst, and called on YHWH, and said, You have
		given this great deliverance in the hand of your servant: and
		now shall I die for thirst, and fall in the hand of the
		uncircumcised?
	}
}
{
}

\Verse{19}
{
	\hJ{
		וַיִּבְקַע אֱלֹהִים אֶת־הַמַּכְתֵּשׁ אֲשֶׁר־בַּלֶּחִי וַיֵּצְאוּ מִמֶּנּוּ מַיִם וַיֵּשְׁתְּ וַתָּשׁב רוּחוֹ וַיֶּחִי עַל־כֵּן קָרָא שְׁמָהּ עֵין הַקּוֹרֵא אֲשֶׁר בַּלֶּחִי עַד
		הַיּוֹם הַזֶּה׃
	}
}
{
	\eJ{
		But God split an hollow place that was in the jaw, and there
		came water from it: and when he had drunk, his spirit came
		again, and he revived: therefore he called the name of it
		Enhakkore, that is in Lehi to this day.
	}
}
{
}
