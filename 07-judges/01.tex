	\hX{אָשֵׁר לֹא הוֹרִישׁ אֶת־יֹשְׁבֵי עַכּוֹ וְאֶת־יוֹשְׁבֵי צִידוֹן וְאֶת־אַחְלָב וְאֶת־אַכְזִיב וְאֶת־חֶלְבָּה וְאֶת־אֲפִיק וְאֶת־רְחֹב׃}
}
{
	\eX{
		And Asher drive out the inhabitants of Acco, and not the
		inhabitants of Sidon, and not of Ahlab, and not of Achzib, and
		not of Helbah, and not of Aphik, and not of Rehob:
	}
}
{
}

\Verse{32}
{
	\hX{וַיֵּשֶׁב הָאָשֵׁרִי בְּקֶרֶב הַכְּנַעֲנִי יֹשְׁבֵי הָאָרֶץ כִּי לֹא הוֹרִישׁוֹ׃}
}
{
	\eX{
		But the Asherites lived among the Canaanite, the inhabitants of
		the land: for they didn’t drive them out.
	}
}
{
}

\Verse{33}
{
	\hX{נַפְתָּלִי לֹא־הוֹרִישׁ אֶת־יֹשְׁבֵי בֵית־שֶׁמֶשׁ וְאֶת־יֹשְׁבֵי בֵית־עֲנָת וַיֵּשֶׁב בְּקֶרֶב הַכְּנַעֲנִי יֹשְׁבֵי הָאָרֶץ וְיֹשְׁבֵי בֵית־שֶׁמֶשׁ וּבֵית עֲנָת הָיוּ לָהֶם לָמַס׃}
}
{
	\eX{
		And Naphtali drive out the inhabitants of Bethshemesh, and not
		the inhabitants of Bethanath; but he lived among the Canaanite,
		the inhabitants of the land: nevertheless the inhabitants of
		Bethshemesh and of Bethanath became forced labor to them.
	}
}
{
}

\Verse{34}
{
	\hX{וַיִּלְחֲצוּ הָאֱמֹרִי אֶת־בְּנֵי־דָן הָהָרָה כִּי־לֹא נְתָנוֹ לָרֶדֶת לָעֵמֶק׃}
}
{
	\eX{
		And the Amorite forced the children of Dan into the mountain:
		for they would not allow them to come down to the valley:
	}
}
{
}

\Verse{35}
{
	\hX{וַיּוֹאֶל הָאֱמֹרִי לָשֶׁבֶת בְּהַר־חֶרֶס בְּאַיָּלוֹן וּבְשַׁעַלְבִים וַתִּכְבַּד יַד בֵּית־יוֹסֵף וַיִּהְיוּ לָמַס׃}
}
{
	\eX{
		But the Amorite would live in Mountain Heres in Aijalon, and in
		Shaalbim: yet the hand of the house of Joseph prevailed, so that
		they became forced labor.
	}
}
{
}

\Verse{36}
{
	\hX{וּגְבוּל הָאֱמֹרִי מִמַּעֲלֵה עַקְרַבִּים מֵהַסֶּלַע וָמָעְלָה׃}
}
{
	\eX{
		And the border of the Amorite was from the going up to Akrabbim,
		from the rock, and upward.
	}
}
{
}
