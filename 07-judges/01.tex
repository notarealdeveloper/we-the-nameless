\Verse{31}
{
	\hX{אָשֵׁר לֹא הוֹרִישׁ אֶת־יֹשְׁבֵי עַכּוֹ וְאֶת־יוֹשְׁבֵי צִידוֹן וְאֶת־אַחְלָב וְאֶת־אַכְזִיב וְאֶת־חֶלְבָּה וְאֶת־אֲפִיק וְאֶת־רְחֹב׃}
}
{
	\eX{
		Asher did not dispossess the inhabitants of Acco or the
		inhabitants of Sidon, Ahlab, Achzib, Helbah, Aphik, and Rehob.
	}
}
{
}

\Verse{32}
{
	\hX{וַיֵּשֶׁב הָאָשֵׁרִי בְּקֶרֶב הַכְּנַעֲנִי יֹשְׁבֵי הָאָרֶץ כִּי לֹא הוֹרִישׁוֹ׃}
}
{
	\eX{
		So the Asherites dwelt in the midst of the Canaanites, the
		inhabitants of the land, for they did not dispossess them.
	}
}
{
}

\Verse{33}
{
	\hX{נַפְתָּלִי לֹא־הוֹרִישׁ אֶת־יֹשְׁבֵי בֵית־שֶׁמֶשׁ וְאֶת־יֹשְׁבֵי בֵית־עֲנָת וַיֵּשֶׁב בְּקֶרֶב הַכְּנַעֲנִי יֹשְׁבֵי הָאָרֶץ וְיֹשְׁבֵי בֵית־שֶׁמֶשׁ וּבֵית עֲנָת הָיוּ לָהֶם לָמַס׃}
}
{
	\eX{
		Naphtali did not dispossess the inhabitants of Beth-shemesh or the
		inhabitants of Beth-anath. But they settled in the midst of the
		Canaanite inhabitants of the land, and the inhabitants of
		Beth-shemesh and Beth-anath had to perform forced labor for them.
	}
}
{
}

\Verse{34}
{
	\hX{וַיִּלְחֲצוּ הָאֱמֹרִי אֶת־בְּנֵי־דָן הָהָרָה כִּי־לֹא נְתָנוֹ לָרֶדֶת לָעֵמֶק׃}
}
{
	\eX{
		The Amorites pressed the Danites into the hill country; they would
		not let them come down to the plain.
	}
}
{
}

\Verse{35}
{
	\hX{וַיּוֹאֶל הָאֱמֹרִי לָשֶׁבֶת בְּהַר־חֶרֶס בְּאַיָּלוֹן וּבְשַׁעַלְבִים וַתִּכְבַּד יַד בֵּית־יוֹסֵף וַיִּהְיוּ לָמַס׃}
}
{
	\eX{
		The Amorites also persisted in dwelling in Har-heres, in Aijalon,
		and in Shaalbim. But the hand of the House of Joseph bore heavily
		on them and they had to perform forced labor.
	}
}
{
}

\Verse{36}
{
	\hX{וּגְבוּל הָאֱמֹרִי מִמַּעֲלֵה עַקְרַבִּים מֵהַסֶּלַע וָמָעְלָה׃}
}
{
	\eX{
		The territory of the Amorites extended from the Ascent of
		Akrabbim—from Sela—onward.
	}
}
{
}
