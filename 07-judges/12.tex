\Chapter{12}

\Verse{1}
{
	\hX{
		וַיִּצָּעֵק אִישׁ אֶפְרַיִם וַיַּעֲבֹר צָפוֹנָה וַיֹּאמְרוּ לְיִפְתָּח מַדּוּעַ עָבַרְתָּ לְהִלָּחֵם בִּבְנֵי־עַמּוֹן וְלָנוּ לֹא קָרָאתָ לָלֶכֶת עִמָּךְ בֵּיתְךָ נִשְׂרֹף עָלֶיךָ
		בָּאֵשׁ׃
	}
}
{
	\eX{
		And the men of Ephraim gathered themselves together, and went
		northward, and said to Jephthah, Why did you pass over over to
		fight against the children of Ammon, and didn’t call us to go
		with you? We’ll burn your house upon you with fire.
	}
}
{
}

\Verse{2}
{
	\hX{וַיֹּאמֶר יִפְתָּח אֲלֵיהֶם אִישׁ רִיב הָיִיתִי אֲנִי וְעַמִּי וּבְנֵי־עַמּוֹן מְאֹד וָאֶזְעַק אֶתְכֶם וְלֹא־הוֹשַׁעְתֶּם אוֹתִי מִיָּדָם׃}
}
{
	\eX{
		And Jephthah said to them, I and my people were at great strife
		with the children of Ammon: and when I called you, you gave me
		not out of their hands.
	}
}
{
}

\Verse{3}
{
	\hX{וָאֶרְאֶה כִּי־אֵינְךָ מוֹשִׁיעַ וָאָשִׂימָה נַפְשִׁי בְכַפִּי וָאֶעְבְּרָה אֶל־בְּנֵי עַמּוֹן וַיִּתְּנֵם יְהֹוָה בְּיָדִי וְלָמָה עֲלִיתֶם אֵלַי הַיּוֹם הַזֶּה לְהִלָּחֶם בִּי׃}
}
{
	\eX{
		And when I saw that you gave me not, I put my life in my hands,
		and passed over against the children of Ammon, and YHWH gave
		them into my hand: therefore then are you come up to me this
		day, to fight against me?
	}
}
{
}

\Verse{4}
{
	\hX{
		וַיִּקְבֹּץ יִפְתָּח אֶת־כּל־אַנְשֵׁי גִלְעָד וַיִּלָּחֶם אֶת־אֶפְרָיִם וַיַּכּוּ אַנְשֵׁי גִלְעָד אֶת־אֶפְרַיִם כִּי אָמְרוּ פְּלִיטֵי אֶפְרַיִם אַתֶּם גִּלְעָד בְּתוֹךְ אֶפְרַיִם
		בְּתוֹךְ מְנַשֶּׁה׃
	}
}
{
	\eX{
		Then Jephthah gathered all the men of Gilead, and fought with
		Ephraim: and the men of Gilead struck Ephraim, because they
		said, You Gileadites are fugitives of Ephraim among the
		Ephraimites, and among the Manassites.
	}
}
{
}

\Verse{5}
{
	\hX{וַיִּלְכֹּד גִּלְעָד אֶת־מַעְבְּרוֹת הַיַּרְדֵּן לְאֶפְרָיִם וְהָיָה כִּי יֹאמְרוּ פְּלִיטֵי אֶפְרַיִם אֶעֱבֹרָה וַיֹּאמְרוּ לוֹ אַנְשֵׁי־גִלְעָד הַאֶפְרָתִי אַתָּה וַיֹּאמֶר לֹא׃}
}
{
	\eX{
		And the Gileadites took the crossings of the Jordan before the
		Ephraimites: and it was so, that when those Ephraimites that
		were escaped said, Let me go over; that the men of Gilead said
		to him, Are you an Ephraimite? If he said, No;
	}
}
{
}

\Verse{6}
{
	\hX{
		וַיֹּאמְרוּ לוֹ אֱמר־נָא שִׁבֹּלֶת וַיֹּאמֶר סִבֹּלֶת וְלֹא יָכִין לְדַבֵּר כֵּן וַיֹּאחֲזוּ אוֹתוֹ וַיִּשְׁחָטוּהוּ אֶל־מַעְבְּרוֹת הַיַּרְדֵּן וַיִּפֹּל בָּעֵת הַהִיא מֵאֶפְרַיִם
		אַרְבָּעִים וּשְׁנַיִם אָלֶף׃
	}
}
{
	\eX{
		And they said to him, Say now Shibboleth: and he said Sibboleth:
		for he could not set his mouth to speak it right. Then they took
		him, and killed him at the crossings of the Jordan: and there
		fell at that time from Ephraim forty-two thousand.
	}
}
{
}

\Verse{7}
{
	\hX{וַיִּשְׁפֹּט יִפְתָּח אֶת־יִשְׂרָאֵל שֵׁשׁ שָׁנִים וַיָּמת יִפְתָּח הַגִּלְעָדִי וַיִּקָּבֵר בְּעָרֵי גִלְעָד׃}
}
{
	\eX{
		And Jephthah judged Israel six years. Then died Jephthah the
		Gileadite, and was buried in one of the cities of Gilead.
	}
}
{
}

\Verse{8}
{
	\hX{וַיִּשְׁפֹּט אַחֲרָיו אֶת־יִשְׂרָאֵל אִבְצָן מִבֵּית לָחֶם׃}
}
{
	\eX{And after him Ibzan of Bethlehem judged Israel.}
}
{
}

\Verse{9}
{
	\hX{וַיְהִי־לוֹ שְׁלֹשִׁים בָּנִים וּשְׁלֹשִׁים בָּנוֹת שִׁלַּח הַחוּצָה וּשְׁלֹשִׁים בָּנוֹת הֵבִיא לְבָנָיו מִן־הַחוּץ וַיִּשְׁפֹּט אֶת־יִשְׂרָאֵל שֶׁבַע שָׁנִים׃}
}
{
	\eX{
		And he had thirty sons, and thirty daughters, whom he sent
		abroad, and took in thirty daughters from abroad for his sons.
		And he judged Israel seven years.
	}
}
{
}

\Verse{10}
{
	\hX{וַיָּמת אִבְצָן וַיִּקָּבֵר בְּבֵית לָחֶם׃}
}
{
	\eX{Then died Ibzan, and was buried at Bethlehem.}
}
{
}

\Verse{11}
{
	\hX{וַיִּשְׁפֹּט אַחֲרָיו אֶת־יִשְׂרָאֵל אֵילוֹן הַזְּבוּלֹנִי וַיִּשְׁפֹּט אֶת־יִשְׂרָאֵל עֶשֶׂר שָׁנִים׃}
}
{
	\eX{
		And after him Elon, a Zebulonite, judged Israel: and he judged
		Israel ten years.
	}
}
{
}

\Verse{12}
{
	\hX{וַיָּמת אֵילוֹן הַזְּבוּלֹנִי וַיִּקָּבֵר בְּאַיָּלוֹן בְּאֶרֶץ זְבוּלֻן׃}
}
{
	\eX{
		And Elon the Zebulonite died, and was buried in Aijalon in the
		country of Zebulun.
	}
}
{
}

\Verse{13}
{
	\hX{וַיִּשְׁפֹּט אַחֲרָיו אֶת־יִשְׂרָאֵל עַבְדּוֹן בֶּן־הִלֵּל הַפִּרְעָתוֹנִי׃}
}
{
	\eX{
		And after him Abdon the son of Hillel, a Pirathonite, judged
		Israel.
	}
}
{
}

\Verse{14}
{
	\hX{וַיְהִי־לוֹ אַרְבָּעִים בָּנִים וּשְׁלֹשִׁים בְּנֵי בָנִים רֹכְבִים עַל־שִׁבְעִים עֲיָרִם וַיִּשְׁפֹּט אֶת־יִשְׂרָאֵל שְׁמֹנֶה שָׁנִים׃}
}
{
	\eX{
		And he had forty sons and thirty nephews, that rode on seventy
		and ten ass colts: and he judged Israel eight years.
	}
}
{
}

\Verse{15}
{
	\hX{וַיָּמת עַבְדּוֹן בֶּן־הִלֵּל הַפִּרְעָתוֹנִי וַיִּקָּבֵר בְּפִרְעָתוֹן בְּאֶרֶץ אֶפְרַיִם בְּהַר הָעֲמָלֵקִי׃}
}
{
	\eX{
		And Abdon the son of Hillel the Pirathonite died, and was buried
		in Pirathon in the land of Ephraim, in the mount of the
		Amalekites.
	}
}
{
}
