\Chapter{14}

\Verse{1}
{
	\hX{וַיֵּרֶד שִׁמְשׁוֹן תִּמְנָתָה וַיַּרְא אִשָּׁה בְּתִמְנָתָה מִבְּנוֹת פְּלִשְׁתִּים׃}
}
{
	\eX{
		And Samson went down to Timnath, and saw a woman in Timnath of
		the daughters of the Philistines.
	}
}
{
}

\Verse{2}
{
	\hX{וַיַּעַל וַיַּגֵּד לְאָבִיו וּלְאִמּוֹ וַיֹּאמֶר אִשָּׁה רָאִיתִי בְתִמְנָתָה מִבְּנוֹת פְּלִשְׁתִּים וְעַתָּה קְחוּ־אוֹתָהּ לִי לְאִשָּׁה׃}
}
{
	\eX{
		And he came up, and told his father and his mother, and said,
		I’ve seen a woman in Timnath of the daughters of the
		Philistines: now therefore get her for me as a wife.
	}
}
{
}

\Verse{3}
{
	\hX{
		וַיֹּאמֶר לוֹ אָבִיו וְאִמּוֹ הַאֵין בִּבְנוֹת אַחֶיךָ וּבְכל־עַמִּי אִשָּׁה כִּי־אַתָּה הוֹלֵךְ לָקַחַת אִשָּׁה מִפְּלִשְׁתִּים הָעֲרֵלִים וַיֹּאמֶר שִׁמְשׁוֹן אֶל־אָבִיו אוֹתָהּ
		קַח־לִי כִּי־הִיא יָשְׁרָה בְעֵינָי׃
	}
}
{
	\eX{
		Then his father and his mother said to him, Is there never a
		woman among the daughters of your brothers, or among all my
		people, that you go to take a wife of the uncircumcised
		Philistines? And Samson said to his father, Get her for me: for
		she pleases me well.
	}
}
{
}

\Verse{4}
{
	\hX{וְאָבִיו וְאִמּוֹ לֹא יָדְעוּ כִּי מֵיְהֹוָה הִיא כִּי־תֹאֲנָה הוּא־מְבַקֵּשׁ מִפְּלִשְׁתִּים וּבָעֵת הַהִיא פְּלִשְׁתִּים מֹשְׁלִים בְּיִשְׂרָאֵל׃}
}
{
	\eX{
		But his father and his mother knew not that it was of YHWH, that
		he sought an occasion against the Philistines: for at that time
		the Philistines had dominion over Israel.
	}
}
{
}

\Verse{5}
{
	\hX{וַיֵּרֶד שִׁמְשׁוֹן וְאָבִיו וְאִמּוֹ תִּמְנָתָה וַיָּבֹאוּ עַד־כַּרְמֵי תִמְנָתָה וְהִנֵּה כְּפִיר אֲרָיוֹת שֹׁאֵג לִקְרָאתוֹ׃}
}
{
	\eX{
		And Samson went down, and his father and his mother, to Timnath,
		and came to the vineyards of Timnath: and here, a young lion
		roared against him.
	}
}
{
}

\Verse{6}
{
	\hX{וַתִּצְלַח עָלָיו רוּחַ יְהֹוָה וַיְשַׁסְּעֵהוּ כְּשַׁסַּע הַגְּדִי וּמְאוּמָה אֵין בְּיָדוֹ וְלֹא הִגִּיד לְאָבִיו וּלְאִמּוֹ אֵת אֲשֶׁר עָשָׂה׃}
}
{
	\eX{
		And spirit of YHWH came mightily upon him, and he rent him as he
		would have rent a kid, and he had nothing in his hand: but he
		told not his father or his mother what he had done.
	}
}
{
}

\Verse{7}
{
	\hX{וַיֵּרֶד וַיְדַבֵּר לָאִשָּׁה וַתִּישַׁר בְּעֵינֵי שִׁמְשׁוֹן׃}
}
{
	\eX{
		And he went down, and talked with the woman: and she pleased
		Samson well.
	}
}
{
}

\Verse{8}
{
	\hX{וַיָּשׁב מִיָּמִים לְקַחְתָּהּ וַיָּסַר לִרְאוֹת אֵת מַפֶּלֶת הָאַרְיֵה וְהִנֵּה עֲדַת דְּבוֹרִים בִּגְוִיַּת הָאַרְיֵה וּדְבָשׁ׃}
}
{
	\eX{
		And after a time he returned to take her, and he turned aside to
		see the carcase of the lion: and here: there was a swarm of bees
		and honey in the carcase of the lion.
	}
}
{
}

\Verse{9}
{
	\hX{וַיִּרְדֵּהוּ אֶל־כַּפָּיו וַיֵּלֶךְ הָלוֹךְ וְאָכֹל וַיֵּלֶךְ אֶל־אָבִיו וְאֶל־אִמּוֹ וַיִּתֵּן לָהֶם וַיֹּאכֵלוּ וְלֹא־הִגִּיד לָהֶם כִּי מִגְּוִיַּת הָאַרְיֵה רָדָה הַדְּבָשׁ׃}
}
{
	\eX{
		And he took of it in his hands, and went on eating, and came to
		his father and mother, and he gave them, and they ate: but he
		told not them that he captured the honey out of the carcase of
		the lion.
	}
}
{
}

\Verse{10}
{
	\hX{וַיֵּרֶד אָבִיהוּ אֶל־הָאִשָּׁה וַיַּעַשׂ שָׁם שִׁמְשׁוֹן מִשְׁתֶּה כִּי כֵּן יַעֲשׂוּ הַבַּחוּרִים׃}
}
{
	\eX{
		So his father went down to the woman: and Samson made there a
		feast: for so used the young men to do.
	}
}
{
}

\Verse{11}
{
	\hX{וַיְהִי כִּרְאוֹתָם אוֹתוֹ וַיִּקְחוּ שְׁלֹשִׁים מֵרֵעִים וַיִּהְיוּ אִתּוֹ׃}
}
{
	\eX{
		And it was when they saw him, that they brought thirty
		companions to be with him.
	}
}
{
}

\Verse{12}
{
	\hX{
		וַיֹּאמֶר לָהֶם שִׁמְשׁוֹן אָחוּדָה־נָּא לָכֶם חִידָה אִם־הַגֵּד תַּגִּידוּ אוֹתָהּ לִי שִׁבְעַת יְמֵי הַמִּשְׁתֶּה וּמְצָאתֶם וְנָתַתִּי לָכֶם שְׁלֹשִׁים סְדִינִים וּשְׁלֹשִׁים
		חֲלִפֹת בְּגָדִים׃
	}
}
{
	\eX{
		And Samson said to them, I’ll now put out a riddle to you: if
		you can certainly declare it me within the seven days of the
		feast, and find it out, then I’ll give you thirty sheets and
		thirty change of garments:
	}
}
{
}

\Verse{13}
{
	\hX{וְאִם־לֹא תוּכְלוּ לְהַגִּיד לִי וּנְתַתֶּם אַתֶּם לִי שְׁלֹשִׁים סְדִינִים וּשְׁלֹשִׁים חֲלִיפוֹת בְּגָדִים וַיֹּאמְרוּ לוֹ חוּדָה חִידָתְךָ וְנִשְׁמָעֶנָּה׃}
}
{
	\eX{
		But if you can’t declare it me, then shall you give me thirty
		sheets and thirty change of garments. And they said to him, put
		out your riddle, that we may hear it.
	}
}
{
}

\Verse{14}
{
	\hX{וַיֹּאמֶר לָהֶם מֵהָאֹכֵל יָצָא מַאֲכָל וּמֵעַז יָצָא מָתוֹק וְלֹא יָכְלוּ לְהַגִּיד הַחִידָה שְׁלֹשֶׁת יָמִים׃}
}
{
	\eX{
		And he said to them, From the eater came out food, and from the
		strong came out sweet. And they could not tell the riddle in
		three days.
	}
}
{

%		Footnote 14:14. Samson's riddle is clever, unfair, and born from a carcass he
%		should not have touched. This is Judges in miniature: wit with flies on it.
%	}
}

\Verse{15}
{
	\hX{
		וַיְהִי בַּיּוֹם הַשְּׁבִיעִי וַיֹּאמְרוּ לְאֵשֶׁת־שִׁמְשׁוֹן פַּתִּי אֶת־אִישֵׁךְ וְיַגֶּד־לָנוּ אֶת־הַחִידָה פֶּן־נִשְׂרֹף אוֹתָךְ וְאֶת־בֵּית אָבִיךְ בָּאֵשׁ הַלְירְשֵׁנוּ
		קְרָאתֶם לָנוּ הֲלֹא׃
	}
}
{
	\eX{
		And it was on the seventh day, that they said to Samson’s wife,
		Entice your husband, that he may tell us the riddle, lest we
		burn you and your father’s house with fire: have you called us
		to dispossess us? Isn’t it so?
	}
}
{
}

\Verse{16}
{
	\hX{
		וַתֵּבְךְּ אֵשֶׁת שִׁמְשׁוֹן עָלָיו וַתֹּאמֶר רַק־שְׂנֵאתַנִי וְלֹא אֲהַבְתָּנִי הַחִידָה חַדְתָּ לִבְנֵי עַמִּי וְלִי לֹא הִגַּדְתָּה וַיֹּאמֶר לָהּ הִנֵּה לְאָבִי וּלְאִמִּי לֹא
		הִגַּדְתִּי וְלָךְ אַגִּיד׃
	}
}
{
	\eX{
		And Samson’s wife wept before him, and said, You only hate me,
		and you don’t love me: you have put out a riddle to the children
		of my people, and have not told it to me. And he said to her,
		Here, I’ve not told it to my father and not my mother, and shall
		I tell it to you?
	}
}
{
}

\Verse{17}
{
	\hX{וַתֵּבְךְּ עָלָיו שִׁבְעַת הַיָּמִים אֲשֶׁר־הָיָה לָהֶם הַמִּשְׁתֶּה וַיְהִי בַּיּוֹם הַשְּׁבִיעִי וַיַּגֶּד־לָהּ כִּי הֱצִיקַתְהוּ וַתַּגֵּד הַחִידָה לִבְנֵי עַמָּהּ׃}
}
{
	\eX{
		And she wept before him the seven days, while their feast
		lasted: and it was on the seventh day, that he told her, because
		she lay sore upon him: and she told the riddle to the children
		of her people.
	}
}
{
}

\Verse{18}
{
	\hX{
		וַיֹּאמְרוּ לוֹ אַנְשֵׁי הָעִיר בַּיּוֹם הַשְּׁבִיעִי בְּטֶרֶם יָבֹא הַחַרְסָה מַה־מָּתוֹק מִדְּבַשׁ וּמֶה עַז מֵאֲרִי וַיֹּאמֶר לָהֶם לוּלֵא חֲרַשְׁתֶּם בְּעֶגְלָתִי לֹא מְצָאתֶם
		חִידָתִי׃
	}
}
{
	\eX{
		And the men of the city said to him on the seventh day before
		the sun went down, What is sweeter than honey? And what is
		stronger than a lion? and he said to them, If you had not plowed
		with my heifer, you had not found out my riddle.
	}
}
{
}

\Verse{19}
{
	\hX{
		וַתִּצְלַח עָלָיו רוּחַ יְהֹוָה וַיֵּרֶד אַשְׁקְלוֹן וַיַּךְ מֵהֶם שְׁלֹשִׁים אִישׁ וַיִּקַּח אֶת־חֲלִיצוֹתָם וַיִּתֵּן הַחֲלִיפוֹת לְמַגִּידֵי הַחִידָה וַיִּחַר אַפּוֹ וַיַּעַל
		בֵּית אָבִיהוּ׃
	}
}
{
	\eX{
		And spirit of YHWH came upon him, and he went down to Ashkelon,
		and killed thirty men of them, and took their plunder, and gave
		change of garments to them that expounded the riddle. And his
		anger was kindled, and he went up to his father’s house.
	}
}
{
}
