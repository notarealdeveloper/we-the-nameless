\Chapter{9}

\Verse{1}

}
{
	\eX{
		Standing in their places, they read from the scroll of the

		YHWH their God.

}

	\eX{

	}
}
{
	\eX{
		The Levites Jeshua, Kadmiel, Bani, Hashabniah, Sherebiah, Hodiah,

		exalted though it is above every blessing and praise!’

}

	\eX{
		“You alone are YHWH. You made the heavens, the highest heavens,

\Verse{27}
{
	\hX{
		וַתִּתְּנֵם בְּיַד צָרֵיהֶם וַיָּצֵרוּ לָהֶם וּבְעֵת צָרָתָם יִצְעֲקוּ אֵלֶיךָ וְאַתָּה מִשָּׁמַיִם תִּשְׁמָע וּכְרַחֲמֶיךָ הָרַבִּים תִּתֵּן לָהֶם מוֹשִׁיעִים וְיוֹשִׁיעוּם מִיַּד
		צָרֵיהֶם׃
	}
}
{
	\eX{
		“You delivered them into the power of their adversaries who
		oppressed them. In their time of trouble they cried to You; You in
		heaven heard them, and in Your abundant compassion gave them
		saviors who saved them from the power of their adversaries.
	}
}
{
}

\Verse{28}
{
	\hX{
		וּכְנוֹחַ לָהֶם יָשׁוּבוּ לַעֲשׂוֹת רַע לְפָנֶיךָ וַתַּעַזְבֵם בְּיַד אֹיְבֵיהֶם וַיִּרְדּוּ בָהֶם וַיָּשׁוּבוּ וַיִּזְעָקוּךָ וְאַתָּה מִשָּׁמַיִם תִּשְׁמַע וְתַצִּילֵם
		כְּרַחֲמֶיךָ רַבּוֹת עִתִּים׃
	}
}
{
	\eX{
		But when they had relief, they again did what was evil in Your
		sight, so You abandoned them to the power of their enemies, who
		subjugated them. Again they cried to You, and You in heaven heard
		and rescued them in Your compassion, time after time.
	}
}
{
}

\Verse{29}
{
	\hX{
		וַתָּעַד בָּהֶם לַהֲשִׁיבָם אֶל־תּוֹרָתֶךָ וְהֵמָּה הֵזִידוּ וְלֹא־שָׁמְעוּ לְמִצְוֺתֶיךָ וּבְמִשְׁפָּטֶיךָ חָטְאוּ־בָם אֲשֶׁר־יַעֲשֶׂה אָדָם וְחָיָה בָהֶם וַיִּתְּנוּ כָתֵף
		סוֹרֶרֶת וְערְפָּם הִקְשׁוּ וְלֹא שָׁמֵעוּ׃
	}
}
{
	\eX{
		You admonished them in order to turn them back to Your Teaching,
		but they acted presumptuously and disobeyed Your commandments, and
		sinned against Your rules, by following which a man shall live.
		They turned a defiant shoulder, stiffened their neck, and would
		not obey.
	}
}
{
}

\Verse{30}
{
	\hX{וַתִּמְשֹׁךְ עֲלֵיהֶם שָׁנִים רַבּוֹת וַתָּעַד בָּם בְּרוּחֲךָ בְּיַד־נְבִיאֶיךָ וְלֹא הֶאֱזִינוּ וַתִּתְּנֵם בְּיַד עַמֵּי הָאֲרָצֹת׃}
}
{
	\eX{
		You bore with them for many years, admonished them by Your spirit
		through Your prophets, but they would not give ear, so You
		delivered them into the power of the peoples of the lands.
	}
}
{
}

\Verse{31}
{
	\hX{וּבְרַחֲמֶיךָ הָרַבִּים לֹא־עֲשִׂיתָם כָּלָה וְלֹא עֲזַבְתָּם כִּי אֵל־חַנּוּן וְרַחוּם אָתָּה׃}
}
{
	\eX{
		Still, in Your great compassion You did not make an end of them or
		abandon them, for You are a gracious and compassionate God.
	}
}
{
}

\Verse{32}
{
	\hX{
		וְעַתָּה אֱלֹהֵינוּ הָאֵל הַגָּדוֹל הַגִּבּוֹר וְהַנּוֹרָא שׁוֹמֵר הַבְּרִית וְהַחֶסֶד אַל־יִמְעַט לְפָנֶיךָ אֵת כּל־הַתְּלָאָה אֲשֶׁר־מְצָאַתְנוּ לִמְלָכֵינוּ לְשָׂרֵינוּ
		וּלְכֹהֲנֵינוּ וְלִנְבִיאֵינוּ וְלַאֲבֹתֵינוּ וּלְכל־עַמֶּךָ מִימֵי מַלְכֵי אַשּׁוּר עַד הַיּוֹם הַזֶּה׃
	}
}
{
	\eX{
		“And now, our God, great, mighty, and awesome God, who stays
		faithful to His covenant, do not treat lightly all the suffering
		that has overtaken us—our kings, our officers, our priests, our
		prophets, our fathers, and all Your people—from the time of the
		Assyrian kings to this day.
	}
}
{
}

\Verse{33}
{
	\hX{וְאַתָּה צַדִּיק עַל כּל־הַבָּא עָלֵינוּ כִּי־אֱמֶת עָשִׂיתָ וַאֲנַחְנוּ הִרְשָׁעְנוּ׃}
}
{
	\eX{
		Surely You are in the right with respect to all that has come upon
		us, for You have acted faithfully, and we have been wicked.
	}
}
{
}

\Verse{34}
{
	\hX{וְאֶת־מְלָכֵינוּ שָׂרֵינוּ כֹּהֲנֵינוּ וַאֲבֹתֵינוּ לֹא עָשׂוּ תּוֹרָתֶךָ וְלֹא הִקְשִׁיבוּ אֶל־מִצְוֺתֶיךָ וּלְעֵדְוֺתֶיךָ אֲשֶׁר הַעִידֹתָ בָּהֶם׃}
}
{
	\eX{
		Our kings, officers, priests, and fathers did not follow Your
		Teaching, and did not listen to Your commandments or to the
		warnings that You gave them.
	}
}
{
}

\Verse{35}
{
	\hX{וְהֵם בְּמַלְכוּתָם וּבְטוּבְךָ הָרָב אֲשֶׁר־נָתַתָּ לָהֶם וּבְאֶרֶץ הָרְחָבָה וְהַשְּׁמֵנָה אֲשֶׁר־נָתַתָּ לִפְנֵיהֶם לֹא עֲבָדוּךָ וְלֹא־שָׁבוּ מִמַּעַלְלֵיהֶם הָרָעִים׃}
}
{
	\eX{
		When they had their own kings and enjoyed the good that You
		lavished upon them, and the broad and rich land that You put at
		their disposal, they would not serve You, and did not turn from
		their wicked deeds.
	}
}
{
}

\Verse{36}
{
	\hX{הִנֵּה אֲנַחְנוּ הַיּוֹם עֲבָדִים וְהָאָרֶץ אֲשֶׁר־נָתַתָּה לַאֲבֹתֵינוּ לֶאֱכֹל אֶת־פִּרְיָהּ וְאֶת־טוּבָהּ הִנֵּה אֲנַחְנוּ עֲבָדִים עָלֶיהָ׃}
}
{
	\eX{

		enjoy its fruit and bounty—here we are slaves on it!
	}
}
{
}

\Verse{37}
{
	\hX{וּתְבוּאָתָהּ מַרְבָּה לַמְּלָכִים אֲשֶׁר־נָתַתָּה עָלֵינוּ בְּחַטֹּאותֵינוּ וְעַל גְּוִיֹּתֵינוּ מֹשְׁלִים וּבִבְהֶמְתֵּנוּ כִּרְצוֹנָם וּבְצָרָה גְדֹלָה אֲנָחְנוּ׃}
}
{
	\eX{
		On account of our sins it yields its abundant crops to kings whom
		You have set over us. They rule over our bodies and our beasts as
		they please, and we are in great distress.
	}
}
