\Chapter{2}

\Verse{1}
{
	\hX{וַיְהִי בְּחֹדֶשׁ נִיסָן שְׁנַת עֶשְׂרִים לְאַרְתַּחְשַׁסְתְּא הַמֶּלֶךְ יַיִן לְפָנָיו וָאֶשָּׂא אֶת־הַיַּיִן וָאֶתְּנָה לַמֶּלֶךְ וְלֹא־הָיִיתִי רַע לְפָנָיו׃}
}
{
	\eX{
		In the month of Nisan, in the twentieth year of King Artaxerxes,
		wine was set before him; I took the wine and gave it to the king—I
		had never been out of sorts in his presence.
	}
}
{
}

\Verse{2}
{
	\hX{וַיֹּאמֶר לִי הַמֶּלֶךְ מַדּוּעַ פָּנֶיךָ רָעִים וְאַתָּה אֵינְךָ חוֹלֶה אֵין זֶה כִּי־אִם רֹעַ לֵב וָאִירָא הַרְבֵּה מְאֹד׃}
}
{
	\eX{
		The king said to me, “How is it that you look bad, though you are
		not ill? It must be bad thoughts.” I was very frightened,
	}
}
{
}

\Verse{3}
{
	\hX{וָאֹמַר לַמֶּלֶךְ הַמֶּלֶךְ לְעוֹלָם יִחְיֶה מַדּוּעַ לֹא־יֵרְעוּ פָנַי אֲשֶׁר הָעִיר בֵּית־קִבְרוֹת אֲבֹתַי חֲרֵבָה וּשְׁעָרֶיהָ אֻכְּלוּ בָאֵשׁ׃}
}
{
	\eX{
		but I answered the king, “May the king live forever! How should I
		not look bad when the city of the graveyard of my ancestors lies
		in ruins, and its gates have been consumed by fire?”
	}
}
{
}

\Verse{4}
{
	\hX{וַיֹּאמֶר לִי הַמֶּלֶךְ עַל־מַה־זֶּה אַתָּה מְבַקֵּשׁ וָאֶתְפַּלֵּל אֶל־אֱלֹהֵי הַשָּׁמָיִם׃}
}
{
	\eX{
		The king said to me, “What is your request?” With a prayer to the
		God of Heaven,
	}
}
{
}

\Verse{5}
{
	\hX{וָאֹמַר לַמֶּלֶךְ אִם־עַל־הַמֶּלֶךְ טוֹב וְאִם־יִיטַב עַבְדְּךָ לְפָנֶיךָ אֲשֶׁר תִּשְׁלָחֵנִי אֶל־יְהוּדָה אֶל־עִיר קִבְרוֹת אֲבֹתַי וְאֶבְנֶנָּה׃}
}
{
	\eX{
		I answered the king, “If it please the king, and if your servant
		has found favor with you, send me to Judah, to the city of my
		ancestors’ graves, to rebuild it.”
	}
}
{
%	\footnote{
%		Footnote 2:5. Nehemiah asks to be sent to the city of his fathers' graves. Before
%		it is a building project, it is kinship and bones.
%	}
}

\Verse{6}
{
	\hX{וַיֹּאמֶר לִי הַמֶּלֶךְ וְהַשֵּׁגַל יוֹשֶׁבֶת אֶצְלוֹ עַד־מָתַי יִהְיֶה מַהֲלָכְךָ וּמָתַי תָּשׁוּב וַיִּיטַב לִפְנֵי־הַמֶּלֶךְ וַיִּשְׁלָחֵנִי וָאֶתְּנָה לוֹ זְמָן׃}
}
{
	\eX{
		With the consort seated at his side, the king said to me, “How
		long will you be gone and when will you return?” So it was
		agreeable to the king to send me, and I gave him a date.
	}
}
{
}

\Verse{7}
{
	\hX{וָאוֹמַר לַמֶּלֶךְ אִם־עַל־הַמֶּלֶךְ טוֹב אִגְּרוֹת יִתְּנוּ־לִי עַל־פַּחֲווֹת עֵבֶר הַנָּהָר אֲשֶׁר יַעֲבִירוּנִי עַד אֲשֶׁר־אָבוֹא אֶל־יְהוּדָה׃}
}
{
	\eX{
		Then I said to the king, “If it please the king, let me have
		letters to the governors of the province of Beyond the River,
		directing them to grant me passage until I reach Judah;
	}
}
{
}

\Verse{8}
{
	\hX{
		וְאִגֶּרֶת אֶל־אָסָף שֹׁמֵר הַפַּרְדֵּס אֲשֶׁר לַמֶּלֶךְ אֲשֶׁר יִתֶּן־לִי עֵצִים לְקָרוֹת אֶת־שַׁעֲרֵי הַבִּירָה אֲשֶׁר־לַבַּיִת וּלְחוֹמַת הָעִיר וְלַבַּיִת אֲשֶׁר־אָבוֹא אֵלָיו
		וַיִּתֶּן־לִי הַמֶּלֶךְ כְּיַד־אֱלֹהַי הַטּוֹבָה עָלָי׃
	}
}
{
	\eX{
		likewise, a letter to Asaph, the keeper of the King’s Park,
		directing him to give me timber for roofing the gatehouses of the
		temple fortress and the city walls and for the house I shall
		occupy.” The king gave me these, thanks to my God’s benevolent
		care for me.
	}
}
{
}

\Verse{9}
{
	\hX{וָאָבוֹא אֶל־פַּחֲווֹת עֵבֶר הַנָּהָר וָאֶתְּנָה לָהֶם אֵת אִגְּרוֹת הַמֶּלֶךְ וַיִּשְׁלַח עִמִּי הַמֶּלֶךְ שָׂרֵי חַיִל וּפָרָשִׁים׃}
}
{
	\eX{
		When I came to the governors of the province of Beyond the River I
		gave them the king’s letters. The king also sent army officers and
		cavalry with me.
	}
}
{
}

\Verse{10}
{
	\hX{וַיִּשְׁמַע סַנְבַלַּט הַחֹרֹנִי וְטוֹבִיָּה הָעֶבֶד הָעַמֹּנִי וַיֵּרַע לָהֶם רָעָה גְדֹלָה אֲשֶׁר־בָּא אָדָם לְבַקֵּשׁ טוֹבָה לִבְנֵי יִשְׂרָאֵל׃}
}
{
	\eX{
		When Sanballat the Horonite and Tobiah the Ammonite servant heard,
		it displeased them greatly that someone had come, intent on
		improving the condition of the Israelites.
	}
}
{
}

\Verse{11}
{
	\hX{וָאָבוֹא אֶל־יְרוּשָׁלָ͏ִם וָאֱהִי־שָׁם יָמִים שְׁלֹשָׁה׃}
}
{
	\eX{I arrived in Jerusalem. After I was there three days}
}
{
}

\Verse{12}
{
	\hX{
		וָאָקוּם לַיְלָה אֲנִי וַאֲנָשִׁים מְעַט עִמִּי וְלֹא־הִגַּדְתִּי לְאָדָם מָה אֱלֹהַי נֹתֵן אֶל־לִבִּי לַעֲשׂוֹת לִירוּשָׁלָ͏ִם וּבְהֵמָה אֵין עִמִּי כִּי אִם־הַבְּהֵמָה אֲשֶׁר
		אֲנִי רֹכֵב בָּהּ׃
	}
}
{
	\eX{
		I got up at night, I and a few men with me, and telling no one
		what my God had put into my mind to do for Jerusalem, and taking
		no other beast than the one on which I was riding,
	}
}
{
}

\Verse{13}
{
	\hX{
		וָאֵצְאָה בְשַׁעַר־הַגַּיְא לַיְלָה וְאֶל־פְּנֵי עֵין הַתַּנִּין וְאֶל־שַׁעַר הָאַשְׁפֹּת וָאֱהִי שֹׂבֵר בְּחוֹמֹת יְרוּשָׁלַ͏ִם אֲשֶׁר־[הֵם פְּרוּצִים] (המפרוצים) וּשְׁעָרֶיהָ
		אֻכְּלוּ בָאֵשׁ׃
	}
}
{
	\eX{
		I went out by the Valley Gate, at night, toward the Jackals’
		Spring and the Dung Gate; and I surveyed the walls of Jerusalem
		that were breached, and its gates, consumed by fire.
	}
}
{
	Qere Ketiv.
}

\Verse{14}
{
	\hX{וָאֶעֱבֹר אֶל־שַׁעַר הָעַיִן וְאֶל־בְּרֵכַת הַמֶּלֶךְ וְאֵין־מָקוֹם לַבְּהֵמָה לַעֲבֹר תַּחְתָּי׃}
}
{
	\eX{
		I proceeded to the Fountain Gate and to the King’s Pool, where
		there was no room for the beast under me to continue.
	}
}
{
}

\Verse{15}
{
	\hX{וָאֱהִי עֹלֶה בַנַּחַל לַיְלָה וָאֱהִי שֹׂבֵר בַּחוֹמָה וָאָשׁוּב וָאָבוֹא בְּשַׁעַר הַגַּיְא וָאָשׁוּב׃}
}
{
	\eX{
		So I went up the wadi by night, surveying the wall, and, entering
		again by the Valley Gate, I returned.
	}
}
{
}

\Verse{16}
{
	\hX{וְהַסְּגָנִים לֹא יָדְעוּ אָנָה הָלַכְתִּי וּמָה אֲנִי עֹשֶׂה וְלַיְּהוּדִים וְלַכֹּהֲנִים וְלַחֹרִים וְלַסְּגָנִים וּלְיֶתֶר עֹשֵׂה הַמְּלָאכָה עַד־כֵּן לֹא הִגַּדְתִּי׃}
}
{
	\eX{
		The prefects knew nothing of where I had gone or what I had done,
		since I had not yet divulged it to the Jews—the priests, the
		nobles, the prefects, or the rest of the officials.
	}
}
{
}

\Verse{17}
{
	\hX{
		וָאוֹמַר אֲלֵהֶם אַתֶּם רֹאִים הָרָעָה אֲשֶׁר אֲנַחְנוּ בָהּ אֲשֶׁר יְרוּשָׁלַ͏ִם חֲרֵבָה וּשְׁעָרֶיהָ נִצְּתוּ בָאֵשׁ לְכוּ וְנִבְנֶה אֶת־חוֹמַת יְרוּשָׁלַ͏ִם וְלֹא־נִהְיֶה עוֹד
		חֶרְפָּה׃
	}
}
{
	\eX{
		Then I said to them, “You see the bad state we are in—Jerusalem
		lying in ruins and its gates destroyed by fire. Come, let us
		rebuild the wall of Jerusalem and suffer no more disgrace.”
	}
}
{
}

\Verse{18}
{
	\hX{וָאַגִּיד לָהֶם אֶת־יַד אֱלֹהַי אֲשֶׁר־הִיא טוֹבָה עָלַי וְאַף־דִּבְרֵי הַמֶּלֶךְ אֲשֶׁר אָמַר־לִי וַיֹּאמְרוּ נָקוּם וּבָנִינוּ וַיְחַזְּקוּ יְדֵיהֶם לַטּוֹבָה׃}
}
{
	\eX{
		I told them of my God’s benevolent care for me, also of the things
		that the king had said to me, and they said, “Let us start
		building!” They were encouraged by [His] benevolence.
	}
}
{
}

\Verse{19}
{
	\hX{
		וַיִּשְׁמַע סַנְבַלַּט הַחֹרֹנִי וְטֹבִיָּה הָעֶבֶד הָעַמּוֹנִי וְגֶשֶׁם הָעַרְבִי וַיַּלְעִגוּ לָנוּ וַיִּבְזוּ עָלֵינוּ וַיֹּאמְרוּ מָה־הַדָּבָר הַזֶּה אֲשֶׁר אַתֶּם עֹשִׂים
		הַעַל הַמֶּלֶךְ אַתֶּם מֹרְדִים׃
	}
}
{
	\eX{
		When Sanballat the Horonite and Tobiah the Ammonite servant and
		Geshem the Arab heard, they mocked us and held us in contempt and
		said, “What is this that you are doing? Are you rebelling against
		the king?”
	}
}
{
}

\Verse{20}
{
	\hX{וָאָשִׁיב אוֹתָם דָּבָר וָאוֹמַר לָהֶם אֱלֹהֵי הַשָּׁמַיִם הוּא יַצְלִיחַ לָנוּ וַאֲנַחְנוּ עֲבָדָיו נָקוּם וּבָנִינוּ וְלָכֶם אֵין־חֵלֶק וּצְדָקָה וְזִכָּרוֹן בִּירוּשָׁלָ͏ִם׃}
}
{
	\eX{
		I said to them in reply, “The God of Heaven will grant us success,
		and we, His servants, will start building. But you have no share
		or claim or stake in Jerusalem!”
	}
}
{
