\Chapter{16}

\Verse{1}
{
	\hJ{וְדָוִד עָבַר מְעַט מֵהָרֹאשׁ וְהִנֵּה צִיבָא נַעַר מְפִיבֹשֶׁת לִקְרָאתוֹ וְצֶמֶד חֲמֹרִים חֲבֻשִׁים וַעֲלֵיהֶם מָאתַיִם לֶחֶם וּמֵאָה צִמּוּקִים וּמֵאָה קַיִץ וְנֵבֶל יָיִן׃}
}
{
	\eJ{
		David had passed a little beyond the summit when Ziba the servant
		of Mephibosheth came toward him with a pair of saddled asses
		carrying two hundred loaves of bread, one hundred cakes of raisin,
		one hundred cakes of figs, and a jar of wine.
	}
}
{
}

\Verse{2}
{
	\hJ{
		וַיֹּאמֶר הַמֶּלֶךְ אֶל־צִיבָא מָה־אֵלֶּה לָּךְ וַיֹּאמֶר צִיבָא הַחֲמוֹרִים לְבֵית־הַמֶּלֶךְ לִרְכֹּב (ולהלחם) [וְהַלֶּחֶם] וְהַקַּיִץ לֶאֱכוֹל הַנְּעָרִים וְהַיַּיִן לִשְׁתּוֹת
		הַיָּעֵף בַּמִּדְבָּר׃
	}
}
{
	\eJ{
		The king asked Ziba, “What are you doing with these?” Ziba
		answered, “The asses are for Your Majesty’s family to ride on, the
		bread and figs are for the attendants to eat, and the wine is to
		be drunk by any who are exhausted in the wilderness.”
	}
}
{
	Qere Ketiv.
}

\Verse{3}
{
	\hJ{וַיֹּאמֶר הַמֶּלֶךְ וְאַיֵּה בֶּן־אֲדֹנֶיךָ וַיֹּאמֶר צִיבָא אֶל־הַמֶּלֶךְ הִנֵּה יוֹשֵׁב בִּירוּשָׁלַ͏ִם כִּי אָמַר הַיּוֹם יָשִׁיבוּ לִי בֵּית יִשְׂרָאֵל אֵת מַמְלְכוּת אָבִי׃}
}
{
	\eJ{
		“And where is your master’s son?” the king asked. “He is staying
		in Jerusalem,” Ziba replied to the king, “for he thinks that the
		House of Israel will now give him back the throne of his
		grandfather.”
	}
}
{
}

\Verse{4}
{
	\hJ{וַיֹּאמֶר הַמֶּלֶךְ לְצִבָא הִנֵּה לְךָ כֹּל אֲשֶׁר לִמְפִיבֹשֶׁת וַיֹּאמֶר צִיבָא הִשְׁתַּחֲוֵיתִי אֶמְצָא־חֵן בְּעֵינֶיךָ אֲדֹנִי הַמֶּלֶךְ׃}
}
{
	\eJ{
		The king said to Ziba, “Then all that belongs to Mephibosheth is
		now yours!” And Ziba replied, “I bow low. Your Majesty is most
		gracious to me.”
	}
}
{
}

\Verse{5}

	\hJ{וּבָא הַמֶּלֶךְ דָּוִד עַד־בַּחוּרִים וְהִנֵּה מִשָּׁם אִישׁ יוֹצֵא מִמִּשְׁפַּחַת בֵּית־שָׁאוּל וּשְׁמוֹ שִׁמְעִי בֶן־גֵּרָא יֹצֵא יָצוֹא וּמְקַלֵּל׃}
}
{
	\eJ{
		As King David was approaching Bahurim, a member of Saul’s clan—a

}
{
}

\Verse{6}
{
	\hJ{וַיְסַקֵּל בָּאֲבָנִים אֶת־דָּוִד וְאֶת־כּל־עַבְדֵי הַמֶּלֶךְ דָּוִד וְכל־הָעָם וְכל־הַגִּבֹּרִים מִימִינוֹ וּמִשְּׂמֹאלוֹ׃}
}
{
	\eJ{

{

\Verse{7}

	\hJ{וְכֹה־אָמַר שִׁמְעִי בְּקַלְלוֹ צֵא צֵא אִישׁ הַדָּמִים וְאִישׁ הַבְּלִיָּעַל׃}
}
{
	\eJ{
		And these are the insults that Shimei hurled: “Get out, get out,

{

\Verse{8}
{
	\hJ{
		הֵשִׁיב עָלֶיךָ יְהֹוָה כֹּל דְּמֵי בֵית־שָׁאוּל אֲשֶׁר מָלַכְתָּ תַּחְתָּו וַיִּתֵּן יְהֹוָה אֶת־הַמְּלוּכָה בְּיַד אַבְשָׁלוֹם בְּנֶךָ וְהִנְּךָ בְּרָעָתֶךָ כִּי אִישׁ דָּמִים
		אָתָּה׃
	}
}
{
	\eJ{
		YHWH is paying you back for all your crimes against the family of
		Saul, whose throne you seized. YHWH is handing over the throne to
		your son Absalom; you are in trouble because you are a criminal!”
	}
}
{
}

\Verse{9}
{
	\hJ{וַיֹּאמֶר אֲבִישַׁי בֶּן־צְרוּיָה אֶל־הַמֶּלֶךְ לָמָּה יְקַלֵּל הַכֶּלֶב הַמֵּת הַזֶּה אֶת־אֲדֹנִי הַמֶּלֶךְ אֶעְבְּרָה־נָּא וְאָסִירָה אֶת־רֹאשׁוֹ׃}
}
{
	\eJ{

}

\Verse{10}
{
	\hJ{וַיֹּאמֶר הַמֶּלֶךְ מַה־לִּי וְלָכֶם בְּנֵי צְרֻיָה (כי) [כֹּה] יְקַלֵּל (וכי) [כִּי] יְהֹוָה אָמַר לוֹ קַלֵּל אֶת־דָּוִד וּמִי יֹאמַר מַדּוּעַ עָשִׂיתָה כֵּן׃}
}
{
	\eJ{
		But the king said, “What has this to do with you, you sons of

\Verse{11}

	\hJ{
		וַיֹּאמֶר דָּוִד אֶל־אֲבִישַׁי וְאֶל־כּל־עֲבָדָיו הִנֵּה בְנִי אֲשֶׁר־יָצָא מִמֵּעַי מְבַקֵּשׁ אֶת־נַפְשִׁי וְאַף כִּי־עַתָּה בֶּן־הַיְמִינִי הַנִּחוּ לוֹ וִיקַלֵּל כִּי אָמַר־לוֹ

}
{
	\eJ{
		David said further to Abishai and all the courtiers, “If my son,

}
{
}
