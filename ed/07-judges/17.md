\Chapter{17}

\Verse{1}
{
	\hJ{וַיְהִי־אִישׁ מֵהַר־אֶפְרָיִם וּשְׁמוֹ מִיכָיְהוּ׃}
}
{
	\eJ{
		There was a man in the hill country of Ephraim whose name was
		Micah.
	}
}
{
}

\Verse{2}
{
	\hJ{
		וַיֹּאמֶר לְאִמּוֹ אֶלֶף וּמֵאָה הַכֶּסֶף אֲשֶׁר לֻקַּח־לָךְ (ואתי) [וְאַתְּ] אָלִית וְגַם אָמַרְתְּ בְּאזְנַי הִנֵּה־הַכֶּסֶף אִתִּי אֲנִי לְקַחְתִּיו וַתֹּאמֶר אִמּוֹ בָּרוּךְ
		בְּנִי לַיהֹוָה׃
	}
}
{
	\eJ{
		He said to his mother, “The eleven hundred shekels of silver that
		were taken from you, so that you uttered an imprecation which you
		repeated in my hearing—I have that silver; I took it.” “Blessed of
		YHWH be my son,” said his mother.
	}
}
{
	Qere Ketiv.
}

\Verse{3}
{
	\hJ{
		וַיָּשֶׁב אֶת־אֶלֶף־וּמֵאָה הַכֶּסֶף לְאִמּוֹ וַתֹּאמֶר אִמּוֹ הַקְדֵּשׁ הִקְדַּשְׁתִּי אֶת־הַכֶּסֶף לַיהֹוָה מִיָּדִי לִבְנִי לַעֲשׂוֹת פֶּסֶל וּמַסֵּכָה וְעַתָּה אֲשִׁיבֶנּוּ
		לָךְ׃
	}
}
{
	\eJ{
		He returned the eleven hundred shekels of silver to his mother;
		but his mother said, “I herewith consecrate the silver to YHWH,
		transferring it to my son to make a sculptured image and a molten
		image. I now return it to you.”
	}
}
{
}

\Verse{4}
{
	\hJ{וַיָּשֶׁב אֶת־הַכֶּסֶף לְאִמּוֹ וַתִּקַּח אִמּוֹ מָאתַיִם כֶּסֶף וַתִּתְּנֵהוּ לַצּוֹרֵף וַיַּעֲשֵׂהוּ פֶּסֶל וּמַסֵּכָה וַיְהִי בְּבֵית מִיכָיְהוּ׃}
}
{
	\eJ{
		So when he gave the silver back to his mother, his mother took two
		hundred shekels of silver and gave it to a smith. He made of it a
		sculptured image and a molten image, which were kept in the house
		of Micah.
	}
}
{
}

\Verse{5}
{
	\hJ{וְהָאִישׁ מִיכָה לוֹ בֵּית אֱלֹהִים וַיַּעַשׂ אֵפוֹד וּתְרָפִים וַיְמַלֵּא אֶת־יַד אַחַד מִבָּנָיו וַיְהִי־לוֹ לְכֹהֵן׃}
}
{
	\eJ{
		Now the man Micah had a house of God; he had made an ephod and
		teraphim and he had inducted one of his sons to be his priest.
	}
}
{
}

\Verse{6}
{
	\hJ{בַּיָּמִים הָהֵם אֵין מֶלֶךְ בְּיִשְׂרָאֵל אִישׁ הַיָּשָׁר בְּעֵינָיו יַעֲשֶׂה׃}
}
{
	\eJ{
		In those days there was no king in Israel; every man did as he
		pleased.
	}
}
{
%	\footnote{
%		Footnote 17:6. No king in Israel is not a neutral date-stamp. It is the book's
%		refrain for moral weather.
%	}
}

\Verse{7}
{
	\hJ{וַיְהִי־נַעַר מִבֵּית לֶחֶם יְהוּדָה מִמִּשְׁפַּחַת יְהוּדָה וְהוּא לֵוִי וְהוּא גָר־שָׁם׃}
}
{
	\eJ{
		There was a young man from Bethlehem of Judah, from the clan seat
		of Judah; he was a Levite and had resided there as a sojourner.
	}
}
{
}

\Verse{8}
{
	\hJ{וַיֵּלֶךְ הָאִישׁ מֵהָעִיר מִבֵּית לֶחֶם יְהוּדָה לָגוּר בַּאֲשֶׁר יִמְצָא וַיָּבֹא הַר־אֶפְרַיִם עַד־בֵּית מִיכָה לַעֲשׂוֹת דַּרְכּוֹ׃}
}
{
	\eJ{
		This man had left the town of Bethlehem of Judah to take up
		residence wherever he could find a place. On his way, he came to
		the house of Micah in the hill country of Ephraim.
	}
}
{
}

\Verse{9}
{
	\hJ{וַיֹּאמֶר־לוֹ מִיכָה מֵאַיִן תָּבוֹא וַיֹּאמֶר אֵלָיו לֵוִי אָנֹכִי מִבֵּית לֶחֶם יְהוּדָה וְאָנֹכִי הֹלֵךְ לָגוּר בַּאֲשֶׁר אֶמְצָא׃}
}
{
	\eJ{
		“Where do you come from?” Micah asked him. He replied, “I am a
		Levite from Bethlehem of Judah, and I am traveling to take up
		residence wherever I can find a place.”
	}
}
{
}

\Verse{10}
{
	\hJ{וַיֹּאמֶר לוֹ מִיכָה שְׁבָה עִמָּדִי וֶהְיֵה־לִי לְאָב וּלְכֹהֵן וְאָנֹכִי אֶתֶּן־לְךָ עֲשֶׂרֶת כֶּסֶף לַיָּמִים וְעֵרֶךְ בְּגָדִים וּמִחְיָתֶךָ וַיֵּלֶךְ הַלֵּוִי׃}
}
{
	\eJ{
		“Stay with me,” Micah said to him, “and be a father and a priest
		to me, and I will pay you ten shekels of silver a year, an
		allowance of clothing, and your food.” The Levite went.
	}
}
{
}

\Verse{11}
{
	\hJ{וַיּוֹאֶל הַלֵּוִי לָשֶׁבֶת אֶת־הָאִישׁ וַיְהִי הַנַּעַר לוֹ כְּאַחַד מִבָּנָיו׃}
}
{
	\eJ{
		The Levite agreed to stay with the man, and the youth became like
		one of his own sons.
	}
}
{
}

\Verse{12}
{
	\hJ{וַיְמַלֵּא מִיכָה אֶת־יַד הַלֵּוִי וַיְהִי־לוֹ הַנַּעַר לְכֹהֵן וַיְהִי בְּבֵית מִיכָה׃}
}
{
	\eJ{
		Micah inducted the Levite, and the young man became his priest and
		remained in Micah’s shrine.
	}
}
{
}

\Verse{13}
{
	\hJ{וַיֹּאמֶר מִיכָה עַתָּה יָדַעְתִּי כִּי־יֵיטִיב יְהֹוָה לִי כִּי הָיָה־לִי הַלֵּוִי לְכֹהֵן׃}
}
{
	\eJ{
		“Now I know,” Micah told himself, “that YHWH will prosper me,
		since the Levite has become my priest.”
	}
}
{
}
