\Chapter{1}

\Verse{1}
{
	\hJ{וַיְהִי אַחֲרֵי מוֹת מֹשֶׁה עֶבֶד יְהֹוָה וַיֹּאמֶר יְהֹוָה אֶל־יְהוֹשֻׁעַ בִּן־נוּן מְשָׁרֵת מֹשֶׁה לֵאמֹר׃}
}
{
	\eJ{
		After the death of Moses the servant of YHWH, YHWH said to Joshua
		son of Nun, Moses’ attendant:
	}
}
{
%	\footnote{
%		Footnote 1:1. Moses' attendant. The Hebrew calls Joshua Moses' m'sharet, the one
%		who serves or attends him. At the end of the book Joshua will be called YHWH's
%		servant. The title is not just promotion. It is the whole plot in two words.
%	}
}

\Verse{2}
{
	\hDtrH{מֹשֶׁה עַבְדִּי מֵת וְעַתָּה קוּם עֲבֹר אֶת־הַיַּרְדֵּן הַזֶּה אַתָּה וְכל־הָעָם הַזֶּה אֶל־הָאָרֶץ אֲשֶׁר אָנֹכִי נֹתֵן לָהֶם לִבְנֵי יִשְׂרָאֵל׃}
}
{
	\eDtrH{
		“My servant Moses is dead. Prepare to cross the Jordan, together
		with all this people, into the land that I am giving to the
		Israelites.
	}
}
{
}

\Verse{3}
{
	\hDtrH{כּל־מָקוֹם אֲשֶׁר תִּדְרֹךְ כַּף־רַגְלְכֶם בּוֹ לָכֶם נְתַתִּיו כַּאֲשֶׁר דִּבַּרְתִּי אֶל־מֹשֶׁה׃}
}
{
	\eDtrH{
		Every spot on which your foot treads I give to you, as I promised
		Moses.
	}
}
{
}

\Verse{4}
{
	\hDtrH{מֵהַמִּדְבָּר וְהַלְּבָנוֹן הַזֶּה וְעַד־הַנָּהָר הַגָּדוֹל נְהַר־פְּרָת כֹּל אֶרֶץ הַחִתִּים וְעַד־הַיָּם הַגָּדוֹל מְבוֹא הַשָּׁמֶשׁ יִהְיֶה גְּבוּלְכֶם׃}
}
{
	\eDtrH{
		Your territory shall extend from the wilderness and the Lebanon to
		the Great River, the River Euphrates [on the east]—the whole
		Hittite country—and up to the Mediterranean Sea on the west.
	}
}
{
}

\Verse{5}
{
	\hDtrH{לֹא־יִתְיַצֵּב אִישׁ לְפָנֶיךָ כֹּל יְמֵי חַיֶּיךָ כַּאֲשֶׁר הָיִיתִי עִם־מֹשֶׁה אֶהְיֶה עִמָּךְ לֹא אַרְפְּךָ וְלֹא אֶעֶזְבֶךָּ׃}
}
{
	\eDtrH{
		No one shall be able to resist you as long as you live. As I was
		with Moses, so I will be with you; I will not fail you or forsake
		you.
	}
}
{
}

\Verse{6}
{
	\hJ{חֲזַק וֶאֱמָץ כִּי אַתָּה תַּנְחִיל אֶת־הָעָם הַזֶּה אֶת־הָאָרֶץ אֲשֶׁר־נִשְׁבַּעְתִּי לַאֲבוֹתָם לָתֵת לָהֶם׃}
}
{
	\eJ{
		“Be strong and resolute, for you shall apportion to this people
		the land that I swore to their fathers to assign to them.
	}
}
{
}

\Verse{7}
{
	\hDtrH{רַק חֲזַק וֶאֱמַץ מְאֹד לִשְׁמֹר לַעֲשׂוֹת כְּכל־הַתּוֹרָה אֲשֶׁר צִוְּךָ מֹשֶׁה עַבְדִּי אַל־תָּסוּר מִמֶּנּוּ יָמִין וּשְׂמֹאול לְמַעַן תַּשְׂכִּיל בְּכֹל אֲשֶׁר תֵּלֵךְ׃}
}
{
	\eDtrH{
		But you must be very strong and resolute to observe faithfully all
		the Teaching that My servant Moses enjoined upon you. Do not
		deviate from it to the right or to the left, that you may be
		successful wherever you go.
	}
}
{
}

\Verse{8}
{
	\hDtrH{לֹא־יָמוּשׁ סֵפֶר הַתּוֹרָה הַזֶּה מִפִּיךָ וְהָגִיתָ בּוֹ יוֹמָם וָלַיְלָה לְמַעַן תִּשְׁמֹר לַעֲשׂוֹת כְּכל־הַכָּתוּב בּוֹ כִּי־אָז תַּצְלִיחַ אֶת־דְּרָכֶךָ וְאָז תַּשְׂכִּיל׃}
}
{
	\eDtrH{
		Let not this Book of the Teaching cease from your lips, but recite
		it day and night, so that you may observe faithfully all that is
		written in it. Only then will you prosper in your undertakings and
		only then will you be successful.
	}
}
{
}

\Verse{9}
{
	\hJ{הֲלוֹא צִוִּיתִיךָ חֲזַק וֶאֱמָץ אַל־תַּעֲרֹץ וְאַל־תֵּחָת כִּי עִמְּךָ יְהֹוָה אֱלֹהֶיךָ בְּכֹל אֲשֶׁר תֵּלֵךְ׃}
}
{
	\eJ{
		“I charge you: Be strong and resolute; do not be terrified or
		dismayed, for YHWH your God is with you wherever you go.”
	}
}
{
}

\Verse{10}
{
	\hDtrH{וַיְצַו יְהוֹשֻׁעַ אֶת־שֹׁטְרֵי הָעָם לֵאמֹר׃}
}
{
	\eDtrH{
		Joshua thereupon gave orders to the officials of the people:
	}
}
{
}

\Verse{11}
{
	\hDtrH{
		עִבְרוּ בְּקֶרֶב הַמַּחֲנֶה וְצַוּוּ אֶת־הָעָם לֵאמֹר הָכִינוּ לָכֶם צֵידָה כִּי בְּעוֹד שְׁלֹשֶׁת יָמִים אַתֶּם עֹבְרִים אֶת־הַיַּרְדֵּן הַזֶּה לָבוֹא לָרֶשֶׁת אֶת־הָאָרֶץ אֲשֶׁר
		יְהֹוָה אֱלֹהֵיכֶם נֹתֵן לָכֶם לְרִשְׁתָּהּ׃
	}
}
{
	\eDtrH{
		“Go through the camp and charge the people thus: Get provisions
		ready, for in three days’ time you are to cross the Jordan, in
		order to enter and possess the land that YHWH your God is giving
		you as a possession.”
	}
}
{
}

\Verse{12}
{
	\hDtrH{וְלָראוּבֵנִי וְלַגָּדִי וְלַחֲצִי שֵׁבֶט הַמְנַשֶּׁה אָמַר יְהוֹשֻׁעַ לֵאמֹר׃}
}
{
	\eDtrH{
		Then Joshua said to the Reubenites, the Gadites, and the
		half-tribe of Manasseh,
	}
}
{
}

\Verse{13}
{
	\hDtrH{זָכוֹר אֶת־הַדָּבָר אֲשֶׁר צִוָּה אֶתְכֶם מֹשֶׁה עֶבֶד־יְהֹוָה לֵאמֹר יְהֹוָה אֱלֹהֵיכֶם מֵנִיחַ לָכֶם וְנָתַן לָכֶם אֶת־הָאָרֶץ הַזֹּאת׃}
}
{
	\eDtrH{
		“Remember what Moses the servant of YHWH enjoined upon you, when
		he said, ‘YHWH your God is granting you a haven; He has assigned
		this territory to you’:
	}
}
{
}

\Verse{14}
{
	\hDtrH{
		נְשֵׁיכֶם טַפְּכֶם וּמִקְנֵיכֶם יֵשְׁבוּ בָּאָרֶץ אֲשֶׁר נָתַן לָכֶם מֹשֶׁה בְּעֵבֶר הַיַּרְדֵּן וְאַתֶּם תַּעַבְרוּ חֲמֻשִׁים לִפְנֵי אֲחֵיכֶם כֹּל גִּבּוֹרֵי הַחַיִל וַעֲזַרְתֶּם
		אוֹתָם׃
	}
}
{
	\eDtrH{
		Let your wives, children, and livestock remain in the land that
		Moses assigned to you on this side of the Jordan; but every one of
		your fighting men shall go across armed in the van of your
		kinsmen. And you shall assist them
	}
}
{
}

\Verse{15}
{
	\hDtrH{
		עַד אֲשֶׁר־יָנִיחַ יְהֹוָה לַאֲחֵיכֶם כָּכֶם וְיָרְשׁוּ גַם־הֵמָּה אֶת־הָאָרֶץ אֲשֶׁר־יְהֹוָה אֱלֹהֵיכֶם נֹתֵן לָהֶם וְשַׁבְתֶּם לְאֶרֶץ יְרֻשַּׁתְכֶם וִירִשְׁתֶּם אוֹתָהּ אֲשֶׁר
		נָתַן לָכֶם מֹשֶׁה עֶבֶד יְהֹוָה בְּעֵבֶר הַיַּרְדֵּן מִזְרַח הַשָּׁמֶשׁ׃
	}
}
{
	\eDtrH{
		until YHWH has given your kinsmen a haven, such as you have, and
		they too have gained possession of the land that YHWH your God has
		assigned to them. Then you may return to the land on the east side
		of the Jordan, which Moses the servant of YHWH assigned to you as
		your possession, and you may possess it.”
	}
}
{
}

\Verse{16}
{
	\hDtrH{וַיַּעֲנוּ אֶת־יְהוֹשֻׁעַ לֵאמֹר כֹּל אֲשֶׁר־צִוִּיתָנוּ נַעֲשֶׂה וְאֶל־כּל־אֲשֶׁר תִּשְׁלָחֵנוּ נֵלֵךְ׃}
}
{
	\eDtrH{
		They answered Joshua, “We will do everything you have commanded us
		and we will go wherever you send us.
	}
}
{
}

\Verse{17}
{
	\hDtrH{כְּכֹל אֲשֶׁר־שָׁמַעְנוּ אֶל־מֹשֶׁה כֵּן נִשְׁמַע אֵלֶיךָ רַק יִהְיֶה יְהֹוָה אֱלֹהֶיךָ עִמָּךְ כַּאֲשֶׁר הָיָה עִם־מֹשֶׁה׃}
}
{
	\eDtrH{
		We will obey you just as we obeyed Moses; let but YHWH your God be
		with you as He was with Moses!
	}
}
{
}

\Verse{18}
{
	\hDtrH{כּל־אִישׁ אֲשֶׁר־יַמְרֶה אֶת־פִּיךָ וְלֹא־יִשְׁמַע אֶת־דְּבָרֶיךָ לְכֹל אֲשֶׁר־תְּצַוֶּנּוּ יוּמָת רַק חֲזַק וֶאֱמָץ׃}
}
{
	\eDtrH{
		Any man who flouts your commands and does not obey every order you
		give him shall be put to death. Only be strong and resolute!”
	}
}
{
}
