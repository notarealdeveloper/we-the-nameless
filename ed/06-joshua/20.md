\Chapter{20}

\Verse{1}
{
	\hP{וַיְדַבֵּר יְהֹוָה אֶל־יְהוֹשֻׁעַ לֵאמֹר׃}
}
{
	\eP{YHWH said to Joshua:}
}
{
}

\Verse{2}
{
	\hP{דַּבֵּר אֶל־בְּנֵי יִשְׂרָאֵל לֵאמֹר תְּנוּ לָכֶם אֶת־עָרֵי הַמִּקְלָט אֲשֶׁר־דִּבַּרְתִּי אֲלֵיכֶם בְּיַד־מֹשֶׁה׃}
}
{
	\eP{
		“Speak to the Israelites: Designate the cities of refuge—about
		which I commanded you through Moses—
	}
}
{
}

\Verse{3}
{
	\hP{לָנוּס שָׁמָּה רוֹצֵחַ מַכֵּה־נֶפֶשׁ בִּשְׁגָגָה בִּבְלִי־דָעַת וְהָיוּ לָכֶם לְמִקְלָט מִגֹּאֵל הַדָּם׃}
}
{
	\eP{
		to which a manslayer who kills a person by mistake,
		unintentionally, may flee. They shall serve you as a refuge from
		the blood avenger.
	}
}
{
}

\Verse{4}
{
	\hP{
		וְנָס אֶל־אַחַת מֵהֶעָרִים הָאֵלֶּה וְעָמַד פֶּתַח שַׁעַר הָעִיר וְדִבֶּר בְּאזְנֵי זִקְנֵי־הָעִיר הַהִיא אֶת־דְּבָרָיו וְאָסְפוּ אֹתוֹ הָעִירָה אֲלֵיהֶם וְנָתְנוּ־לוֹ מָקוֹם
		וְיָשַׁב עִמָּם׃
	}
}
{
	\eP{
		He shall flee to one of those cities, present himself at the
		entrance to the city gate, and plead his case before the elders of
		that city; and they shall admit him into the city and give him a
		place in which to live among them.
	}
}
{
}

\Verse{5}
{
	\hP{וְכִי יִרְדֹּף גֹּאֵל הַדָּם אַחֲרָיו וְלֹא־יַסְגִּרוּ אֶת־הָרֹצֵחַ בְּיָדוֹ כִּי בִבְלִי־דַעַת הִכָּה אֶת־רֵעֵהוּ וְלֹא־שֹׂנֵא הוּא לוֹ מִתְּמוֹל שִׁלְשׁוֹם׃}
}
{
	\eP{
		Should the blood avenger pursue him, they shall not hand the
		manslayer over to him, since he killed the other person without
		intent and had not been his enemy in the past.
	}
}
{
}

\Verse{6}
{
	\hP{
		וְיָשַׁב בָּעִיר הַהִיא עַד־עמְדוֹ לִפְנֵי הָעֵדָה לַמִּשְׁפָּט עַד־מוֹת הַכֹּהֵן הַגָּדוֹל אֲשֶׁר יִהְיֶה בַּיָּמִים הָהֵם אָז יָשׁוּב הָרוֹצֵחַ וּבָא אֶל־עִירוֹ וְאֶל־בֵּיתוֹ
		אֶל־הָעִיר אֲשֶׁר־נָס מִשָּׁם׃
	}
}
{
	\eP{
		He shall live in that city until he can stand trial before the
		assembly, [and remain there] until the death of the high priest
		who is in office at that time. Thereafter, the manslayer may go
		back to his home in his own town, to the town from which he fled.”
	}
}
{
}

\Verse{7}
{
	\hP{וַיַּקְדִּשׁוּ אֶת־קֶדֶשׁ בַּגָּלִיל בְּהַר נַפְתָּלִי וְאֶת־שְׁכֶם בְּהַר אֶפְרָיִם וְאֶת־קִרְיַת אַרְבַּע הִיא חֶבְרוֹן בְּהַר יְהוּדָה׃}
}
{
	\eP{
		So they set aside Kedesh in the hill country of Naphtali in
		Galilee, Shechem in the hill country of Ephraim, and
		Kiriath-arba—that is, Hebron—in the hill country of Judah.
	}
}
{
}

\Verse{8}
{
	\hP{
		וּמֵעֵבֶר לְיַרְדֵּן יְרִיחוֹ מִזְרָחָה נָתְנוּ אֶת־בֶּצֶר בַּמִּדְבָּר בַּמִּישֹׁר מִמַּטֵּה רְאוּבֵן וְאֶת־רָאמֹת בַּגִּלְעָד מִמַּטֵּה־גָד וְאֶת־[גּוֹלָן] (גלון) בַּבָּשָׁן
		מִמַּטֵּה מְנַשֶּׁה׃
	}
}
{
	\eP{
		And across the Jordan, east of Jericho, they assigned Bezer in the
		wilderness, in the Tableland, from the tribe of Reuben; Ramoth in
		Gilead from the tribe of Gad; and Golan in Bashan from the tribe
		of Manasseh.
	}
}
{
	Qere Ketiv.
}

\Verse{9}
{
	\hP{
		אֵלֶּה הָיוּ עָרֵי הַמּוּעָדָה לְכֹל בְּנֵי יִשְׂרָאֵל וְלַגֵּר הַגָּר בְּתוֹכָם לָנוּס שָׁמָּה כּל־מַכֵּה־נֶפֶשׁ בִּשְׁגָגָה וְלֹא יָמוּת בְּיַד גֹּאֵל הַדָּם עַד־עמְדוֹ לִפְנֵי
		הָעֵדָה׃
	}
}
{
	\eP{
		Those were the towns designated for all the Israelites and for
		aliens residing among them, to which anyone who killed a person
		unintentionally might flee, and not die by the hand of the blood
		avenger before standing trial by the assembly.
	}
}
{
}
