\Chapter{12}

\Verse{1}
{
	\hX{בִּשְׁנַת־שֶׁבַע לְיֵהוּא מָלַךְ יְהוֹאָשׁ וְאַרְבָּעִים שָׁנָה מָלַךְ בִּירוּשָׁלָ͏ִם וְשֵׁם אִמּוֹ צִבְיָה מִבְּאֵר שָׁבַע׃}
}
{
	\eX{
		Jehoash began his reign in the seventh year of Jehu, and he
		reigned in Jerusalem forty years. His mother’s name was Zibiah of
		Beer-sheba.
	}
}
{
}

\Verse{2}
{
	\hX{וַיַּעַשׂ יְהוֹאָשׁ הַיָּשָׁר בְּעֵינֵי יְהֹוָה כּל־יָמָיו אֲשֶׁר הוֹרָהוּ יְהוֹיָדָע הַכֹּהֵן׃}
}
{
	\eX{
		All his days Jehoash did what was pleasing to YHWH, as the priest
		Jehoiada instructed him.
	}
}
{
}

\Verse{3}
{
	\hX{רַק הַבָּמוֹת לֹא־סָרוּ עוֹד הָעָם מְזַבְּחִים וּמְקַטְּרִים בַּבָּמוֹת׃}
}
{
	\eX{
		The shrines, however, were not removed; the people continued to
		sacrifice and offer at the shrines.
	}
}
{
}

\Verse{4}
{
	\hX{
		וַיֹּאמֶר יְהוֹאָשׁ אֶל־הַכֹּהֲנִים כֹּל כֶּסֶף הַקֳּדָשִׁים אֲשֶׁר־יוּבָא בֵית־יְהֹוָה כֶּסֶף עוֹבֵר אִישׁ כֶּסֶף נַפְשׁוֹת עֶרְכּוֹ כּל־כֶּסֶף אֲשֶׁר יַעֲלֶה עַל לֶב־אִישׁ
		לְהָבִיא בֵּית יְהֹוָה׃
	}
}
{
	\eX{
		Jehoash said to the priests, “All the money, current money,
		brought into the House of YHWH as sacred donations—any money a man
		may pay as the money equivalent of persons, or any other money
		that a man may be minded to bring to the House of YHWH—
	}
}
{
}

\Verse{5}
{
	\hX{יִקְחוּ לָהֶם הַכֹּהֲנִים אִישׁ מֵאֵת מַכָּרוֹ וְהֵם יְחַזְּקוּ אֶת־בֶּדֶק הַבַּיִת לְכֹל אֲשֶׁר־יִמָּצֵא שָׁם בָּדֶק׃}
}
{
	\eX{
		let the priests receive it, each from his benefactor; they, in
		turn, shall make repairs on the House, wherever damage may be
		found.”
	}
}
{
}

\Verse{6}
{
	\hX{וַיְהִי בִּשְׁנַת עֶשְׂרִים וְשָׁלֹשׁ שָׁנָה לַמֶּלֶךְ יְהוֹאָשׁ לֹא־חִזְּקוּ הַכֹּהֲנִים אֶת־בֶּדֶק הַבָּיִת׃}
}
{
	\eX{
		But in the twenty-third year of King Jehoash, [it was found that]
		the priests had not made the repairs on the House.
	}
}
{
}

\Verse{7}
{
	\hX{
		וַיִּקְרָא הַמֶּלֶךְ יְהוֹאָשׁ לִיהוֹיָדָע הַכֹּהֵן וְלַכֹּהֲנִים וַיֹּאמֶר אֲלֵהֶם מַדּוּעַ אֵינְכֶם מְחַזְּקִים אֶת־בֶּדֶק הַבָּיִת וְעַתָּה אַל־תִּקְחוּ־כֶסֶף מֵאֵת מַכָּרֵיכֶם
		כִּי־לְבֶדֶק הַבַּיִת תִּתְּנֻהוּ׃
	}
}
{
	\eX{
		So King Jehoash summoned the priest Jehoiada and the other priests
		and said to them, “Why have you not kept the House in repair? Now
		do not accept money from your benefactors any more, but have it
		donated for the repair of the House.”
	}
}
{
}

\Verse{8}
{
	\hX{וַיֵּאֹתוּ הַכֹּהֲנִים לְבִלְתִּי קְחַת־כֶּסֶף מֵאֵת הָעָם וּלְבִלְתִּי חַזֵּק אֶת־בֶּדֶק הַבָּיִת׃}
}
{
	\eX{
		The priests agreed that they would neither accept money from the
		people nor make repairs on the House.
	}
}
{
}

\Verse{9}
{
	\hX{
		וַיִּקַּח יְהוֹיָדָע הַכֹּהֵן אֲרוֹן אֶחָד וַיִּקֹּב חֹר בְּדַלְתּוֹ וַיִּתֵּן אֹתוֹ אֵצֶל הַמִּזְבֵּחַ (בימין) [מִיָּמִין] בְּבוֹא־אִישׁ בֵּית יְהֹוָה וְנָתְנוּ־שָׁמָּה
		הַכֹּהֲנִים שֹׁמְרֵי הַסַּף אֶת־כּל־הַכֶּסֶף הַמּוּבָא בֵית־יְהֹוָה׃
	}
}
{
	\eX{
		And the priest Jehoiada took a chest and bored a hole in its lid.
		He placed it at the right side of the altar as one entered the
		House of YHWH, and the priestly guards of the threshold deposited
		there all the money that was brought into the House of YHWH.
	}
}
{
	Qere Ketiv.
}

\Verse{10}
{
	\hX{וַיְהִי כִּרְאוֹתָם כִּי־רַב הַכֶּסֶף בָּאָרוֹן וַיַּעַל סֹפֵר הַמֶּלֶךְ וְהַכֹּהֵן הַגָּדוֹל וַיָּצֻרוּ וַיִּמְנוּ אֶת־הַכֶּסֶף הַנִּמְצָא בֵית־יְהֹוָה׃}
}
{
	\eX{
		Whenever they saw that there was much money in the chest, the
		royal scribe and the high priest would come up and put the money
		accumulated in the House of YHWH into bags, and they would count
		it.
	}
}
{
}

\Verse{11}
{
	\hX{וְנָתְנוּ אֶת־הַכֶּסֶף הַמְתֻכָּן עַל־[יְדֵי] (יד) עֹשֵׂי הַמְּלָאכָה (הפקדים) [הַמֻּפְקָדִים] בֵּית יְהֹוָה וַיּוֹצִיאֻהוּ לְחָרָשֵׁי הָעֵץ וְלַבֹּנִים הָעֹשִׂים בֵּית יְהֹוָה׃}
}
{
	\eX{
		Then they would deliver the money that was weighed out to the
		overseers of the work, who were in charge of the House of YHWH.
		These, in turn, used to pay the carpenters and the laborers who
		worked on the House of YHWH,
	}
}
{
	Qere Ketiv.
}

\Verse{12}
{
	\hX{וְלַגֹּדְרִים וּלְחֹצְבֵי הָאֶבֶן וְלִקְנוֹת עֵצִים וְאַבְנֵי מַחְצֵב לְחַזֵּק אֶת־בֶּדֶק בֵּית־יְהֹוָה וּלְכֹל אֲשֶׁר־יֵצֵא עַל־הַבַּיִת לְחזְקָה׃}
}
{
	\eX{
		and the masons and the stonecutters. They also paid for wood and
		for quarried stone with which to make the repairs on the House of
		YHWH, and for every other expenditure that had to be made in
		repairing the House.
	}
}
{
}

\Verse{13}
{
	\hX{אַךְ לֹא יֵעָשֶׂה בֵּית יְהֹוָה סִפּוֹת כֶּסֶף מְזַמְּרוֹת מִזְרָקוֹת חֲצֹצְרוֹת כּל־כְּלִי זָהָב וּכְלִי־כָסֶף מִן־הַכֶּסֶף הַמּוּבָא בֵית־יְהֹוָה׃}
}
{
	\eX{
		However, no silver bowls and no snuffers, basins, or trumpets—no
		vessels of gold or silver—were made at the House of YHWH from the
		money brought into the House of YHWH;
	}
}
{
}

\Verse{14}
{
	\hX{כִּי־לְעֹשֵׂי הַמְּלָאכָה יִתְּנֻהוּ וְחִזְּקוּ־בוֹ אֶת־בֵּית יְהֹוָה׃}
}
{
	\eX{
		this was given only to the overseers of the work for the repair of
		the House of YHWH.
	}
}
{
}

\Verse{15}
{
	\hX{וְלֹא יְחַשְּׁבוּ אֶת־הָאֲנָשִׁים אֲשֶׁר יִתְּנוּ אֶת־הַכֶּסֶף עַל־יָדָם לָתֵת לְעֹשֵׂי הַמְּלָאכָה כִּי בֶאֱמֻנָה הֵם עֹשִׂים׃}
}
{
	\eX{
		No check was kept on the men to whom the money was delivered to
		pay the workers; for they dealt honestly.
	}
}
{
}

\Verse{16}
{
	\hX{כֶּסֶף אָשָׁם וְכֶסֶף חַטָּאוֹת לֹא יוּבָא בֵּית יְהֹוָה לַכֹּהֲנִים יִהְיוּ׃}
}
{
	\eX{
		Money brought as a guilt offering or as a sin offering was not
		deposited in the House of YHWH; it went to the priests.
	}
}
{
}

\Verse{17}
{
	\hX{אָז יַעֲלֶה חֲזָאֵל מֶלֶךְ אֲרָם וַיִּלָּחֶם עַל־גַּת וַיִּלְכְּדָהּ וַיָּשֶׂם חֲזָאֵל פָּנָיו לַעֲלוֹת עַל־יְרוּשָׁלָ͏ִם׃}
}
{
	\eX{
		At that time, King Hazael of Aram came up and attacked Gath and
		captured it; and Hazael proceeded to march on Jerusalem.
	}
}
{
}

\Verse{18}
{
	\hX{
		וַיִּקַּח יְהוֹאָשׁ מֶלֶךְ־יְהוּדָה אֵת כּל־הַקֳּדָשִׁים אֲשֶׁר־הִקְדִּישׁוּ יְהוֹשָׁפָט וִיהוֹרָם וַאֲחַזְיָהוּ אֲבֹתָיו מַלְכֵי יְהוּדָה וְאֶת־קֳדָשָׁיו וְאֵת כּל־הַזָּהָב
		הַנִּמְצָא בְּאֹצְרוֹת בֵּית־יְהֹוָה וּבֵית הַמֶּלֶךְ וַיִּשְׁלַח לַחֲזָאֵל מֶלֶךְ אֲרָם וַיַּעַל מֵעַל יְרוּשָׁלָ͏ִם׃
	}
}
{
	\eX{
		Thereupon King Joash of Judah took all the objects that had been
		consecrated by his fathers, Kings Jehoshaphat, Jehoram, and
		Ahaziah of Judah, and by himself, and all the gold that there was
		in the treasuries of the Temple of YHWH and in the royal palace,
		and he sent them to King Hazael of Aram, who then turned back from
		his march on Jerusalem.
	}
}
{
}

\Verse{19}
{
	\hX{וְיֶתֶר דִּבְרֵי יוֹאָשׁ וְכל־אֲשֶׁר עָשָׂה הֲלוֹא־הֵם כְּתוּבִים עַל־סֵפֶר דִּבְרֵי הַיָּמִים לְמַלְכֵי יְהוּדָה׃}
}
{
	\eX{
		The other events of Joash’s reign, and all his actions, are
		recorded in the Annals of the Kings of Judah.
	}
}
{
}

\Verse{20}
{
	\hX{וַיָּקֻמוּ עֲבָדָיו וַיִּקְשְׁרוּ־קָשֶׁר וַיַּכּוּ אֶת־יוֹאָשׁ בֵּית מִלֹּא הַיֹּרֵד סִלָּא׃}
}
{
	\eX{
		His courtiers formed a conspiracy against Joash and assassinated
		him at Beth-millo that leads down to Silla.
	}
}
{
}

\Verse{21}
{
	\hX{וְיוֹזָכָר בֶּן־שִׁמְעָת וִיהוֹזָבָד בֶּן־שֹׁמֵר עֲבָדָיו הִכֻּהוּ וַיָּמֹת וַיִּקְבְּרוּ אֹתוֹ עִם־אֲבֹתָיו בְּעִיר דָּוִד וַיִּמְלֹךְ אֲמַצְיָה בְנוֹ תַּחְתָּיו׃}
}
{
	\eX{
		The courtiers who assassinated him were Jozacar son of Shimeath
		and Jehozabad son of Shomer. He died and was buried with his
		fathers in the City of David; and his son Amaziah succeeded him as
		king.
	}
}
{
}
