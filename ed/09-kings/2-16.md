\Chapter{16}

\Verse{1}
{
	\hX{בִּשְׁנַת שְׁבַע־עֶשְׂרֵה שָׁנָה לְפֶקַח בֶּן־רְמַלְיָהוּ מָלַךְ אָחָז בֶּן־יוֹתָם מֶלֶךְ יְהוּדָה׃}
}
{
	\eX{
		In the seventeenth year of Pekah son of Remaliah, Ahaz son of King
		Jotham of Judah became king.
	}
}
{
}

\Verse{2}
{
	\hX{בֶּן־עֶשְׂרִים שָׁנָה אָחָז בְּמלְכוֹ וְשֵׁשׁ־עֶשְׂרֵה שָׁנָה מָלַךְ בִּירוּשָׁלָ͏ִם וְלֹא־עָשָׂה הַיָּשָׁר בְּעֵינֵי יְהֹוָה אֱלֹהָיו כְּדָוִד אָבִיו׃}
}
{
	\eX{
		Ahaz was twenty years old when he became king, and he reigned
		sixteen years in Jerusalem. He did not do what was pleasing to
		YHWH his God, as his ancestor David had done,
	}
}
{
}

\Verse{3}
{
	\hX{וַיֵּלֶךְ בְּדֶרֶךְ מַלְכֵי יִשְׂרָאֵל וְגַם אֶת־בְּנוֹ הֶעֱבִיר בָּאֵשׁ כְּתֹעֲבוֹת הַגּוֹיִם אֲשֶׁר הוֹרִישׁ יְהֹוָה אֹתָם מִפְּנֵי בְּנֵי יִשְׂרָאֵל׃}
}
{
	\eX{
		but followed the ways of the kings of Israel. He even consigned
		his son to the fire, in the abhorrent fashion of the nations which
		YHWH had dispossessed before the Israelites.
	}
}
{
}

\Verse{4}
{
	\hX{וַיְזַבֵּחַ וַיְקַטֵּר בַּבָּמוֹת וְעַל־הַגְּבָעוֹת וְתַחַת כּל־עֵץ רַעֲנָן׃}
}
{
	\eX{
		He sacrificed and made offerings at the shrines, on the hills, and
		under every leafy tree.
	}
}
{
}

\Verse{5}
{
	\hX{אָז יַעֲלֶה רְצִין מֶלֶךְ־אֲרָם וּפֶקַח בֶּן־רְמַלְיָהוּ מֶלֶךְ־יִשְׂרָאֵל יְרוּשָׁלַ͏ִם לַמִּלְחָמָה וַיָּצֻרוּ עַל־אָחָז וְלֹא יָכְלוּ לְהִלָּחֵם׃}
}
{
	\eX{
		Then King Rezin of Aram and King Pekah son of Remaliah of Israel
		advanced on Jerusalem for battle. They besieged Ahaz, but could
		not overcome [him].
	}
}
{
}

\Verse{6}
{
	\hX{בָּעֵת הַהִיא הֵשִׁיב רְצִין מֶלֶךְ־אֲרָם אֶת־אֵילַת לַאֲרָם וַיְנַשֵּׁל אֶת־הַיְּהוּדִים מֵאֵילוֹת (וארמים) [וַאֲדֹמִים] בָּאוּ אֵילַת וַיֵּשְׁבוּ שָׁם עַד הַיּוֹם הַזֶּה׃}
}
{
	\eX{
		At that time King Rezin of Aram recovered Elath for Aram; he drove
		out the Judites from Elath, and Edomites came to Elath and settled
		there, as is still the case.
	}
}
{
	Qere Ketiv.
}

\Verse{7}
{
	\hX{
		וַיִּשְׁלַח אָחָז מַלְאָכִים אֶל־תִּגְלַת פְּלֶסֶר מֶלֶךְ־אַשּׁוּר לֵאמֹר עַבְדְּךָ וּבִנְךָ אָנִי עֲלֵה וְהוֹשִׁעֵנִי מִכַּף מֶלֶךְ־אֲרָם וּמִכַּף מֶלֶךְ יִשְׂרָאֵל הַקּוֹמִים
		עָלָי׃
	}
}
{
	\eX{
		Ahaz sent messengers to King Tiglath-pileser of Assyria to say, “I
		am your servant and your son; come and deliver me from the hands
		of the king of Aram and from the hands of the king of Israel, who
		are attacking me.”
	}
}
{
}

\Verse{8}
{
	\hX{וַיִּקַּח אָחָז אֶת־הַכֶּסֶף וְאֶת־הַזָּהָב הַנִּמְצָא בֵּית יְהֹוָה וּבְאֹצְרוֹת בֵּית הַמֶּלֶךְ וַיִּשְׁלַח לְמֶלֶךְ־אַשּׁוּר שֹׁחַד׃}
}
{
	\eX{
		Ahaz took the gold and silver that were on hand in the House of
		YHWH and in the treasuries of the royal palace and sent them as a
		gift to the king of Assyria.
	}
}
{
}

\Verse{9}
{
	\hX{וַיִּשְׁמַע אֵלָיו מֶלֶךְ אַשּׁוּר וַיַּעַל מֶלֶךְ אַשּׁוּר אֶל־דַּמֶּשֶׂק וַיִּתְפְּשֶׂהָ וַיַּגְלֶהָ קִירָה וְאֶת־רְצִין הֵמִית׃}
}
{
	\eX{
		The king of Assyria responded to his request; the king of Assyria
		marched against Damascus and captured it. He deported its
		inhabitants to Kir and put Rezin to death.
	}
}
{
}

\Verse{10}
{
	\hX{
		וַיֵּלֶךְ הַמֶּלֶךְ אָחָז לִקְרַאת תִּגְלַת פִּלְאֶסֶר מֶלֶךְ־אַשּׁוּר דּוּמֶּשֶׂק וַיַּרְא אֶת־הַמִּזְבֵּחַ אֲשֶׁר בְּדַמָּשֶׂק וַיִּשְׁלַח הַמֶּלֶךְ אָחָז אֶל־אוּרִיָּה הַכֹּהֵן
		אֶת־דְּמוּת הַמִּזְבֵּחַ וְאֶת־תַּבְנִיתוֹ לְכל־מַעֲשֵׂהוּ׃
	}
}
{
	\eX{
		When King Ahaz went to Damascus to greet King Tiglath-pileser of
		Assyria, he saw the altar in Damascus. King Ahaz sent the priest
		Uriah a sketch of the altar and a detailed plan of its
		construction.
	}
}
{
}

\Verse{11}
{
	\hX{וַיִּבֶן אוּרִיָּה הַכֹּהֵן אֶת־הַמִּזְבֵּחַ כְּכֹל אֲשֶׁר־שָׁלַח הַמֶּלֶךְ אָחָז מִדַּמֶּשֶׂק כֵּן עָשָׂה אוּרִיָּה הַכֹּהֵן עַד־בּוֹא הַמֶּלֶךְ־אָחָז מִדַּמָּשֶׂק׃}
}
{
	\eX{
		The priest Uriah did just as King Ahaz had instructed him from
		Damascus; the priest Uriah built the altar before King Ahaz
		returned from Damascus.
	}
}
{
}

\Verse{12}
{
	\hX{וַיָּבֹא הַמֶּלֶךְ מִדַּמֶּשֶׂק וַיַּרְא הַמֶּלֶךְ אֶת־הַמִּזְבֵּחַ וַיִּקְרַב הַמֶּלֶךְ עַל־הַמִּזְבֵּחַ וַיַּעַל עָלָיו׃}
}
{
	\eX{
		When the king returned from Damascus, and when the king saw the
		altar, the king drew near the altar, ascended it,
	}
}
{
}

\Verse{13}
{
	\hX{וַיַּקְטֵר אֶת־עֹלָתוֹ וְאֶת־מִנְחָתוֹ וַיַּסֵּךְ אֶת־נִסְכּוֹ וַיִּזְרֹק אֶת־דַּם־הַשְּׁלָמִים אֲשֶׁר־לוֹ עַל־הַמִּזְבֵּחַ׃}
}
{
	\eX{
		and offered his burnt offering and meal offering; he poured his
		libation, and he dashed the blood of his offering of well-being
		against the altar.
	}
}
{
}

\Verse{14}
{
	\hX{וְאֵת הַמִּזְבַּח הַנְּחֹשֶׁת אֲשֶׁר לִפְנֵי יְהֹוָה וַיַּקְרֵב מֵאֵת פְּנֵי הַבַּיִת מִבֵּין הַמִּזְבֵּחַ וּמִבֵּין בֵּית יְהֹוָה וַיִּתֵּן אֹתוֹ עַל־יֶרֶךְ הַמִּזְבֵּחַ צָפוֹנָה׃}
}
{
	\eX{
		As for the bronze altar which had been before YHWH, he moved it
		from its place in front of the Temple, between the [new] altar and
		the House of YHWH, and placed it on the north side of the [new]
		altar.
	}
}
{
}

\Verse{15}
{
	\hX{
		(ויצוהו) [וַיְצַוֶּה] הַמֶּלֶךְ־אָחָז אֶת־אוּרִיָּה הַכֹּהֵן לֵאמֹר עַל הַמִּזְבֵּחַ הַגָּדוֹל הַקְטֵר אֶת־עֹלַת־הַבֹּקֶר וְאֶת־מִנְחַת הָעֶרֶב וְאֶת־עֹלַת הַמֶּלֶךְ
		וְאֶת־מִנְחָתוֹ וְאֵת עֹלַת כּל־עַם הָאָרֶץ וּמִנְחָתָם וְנִסְכֵּיהֶם וְכל־דַּם עֹלָה וְכל־דַּם־זֶבַח עָלָיו תִּזְרֹק וּמִזְבַּח הַנְּחֹשֶׁת יִהְיֶה־לִּי לְבַקֵּר׃
	}
}
{
	\eX{
		And King Ahaz commanded the priest Uriah: “On the great altar you
		shall offer the morning burnt offering and the evening meal
		offering and the king’s burnt offering and his meal offering, with
		the burnt offerings of all the people of the land, their meal
		offerings and their libations. And against it you shall dash the
		blood of all the burnt offerings and all the blood of the
		sacrifices. And I will decide about the bronze altar.”
	}
}
{
	Qere Ketiv.
}

\Verse{16}
{
	\hX{וַיַּעַשׂ אוּרִיָּה הַכֹּהֵן כְּכֹל אֲשֶׁר־צִוָּה הַמֶּלֶךְ אָחָז׃}
}
{
	\eX{Uriah did just as King Ahaz commanded.}
}
{
}

\Verse{17}
{
	\hX{
		וַיְקַצֵּץ הַמֶּלֶךְ אָחָז אֶת־הַמִּסְגְּרוֹת הַמְּכוֹנֹת וַיָּסַר מֵעֲלֵיהֶם (ואת) [אֶת־]הַכִּיֹּר וְאֶת־הַיָּם הוֹרִד מֵעַל הַבָּקָר הַנְּחֹשֶׁת אֲשֶׁר תַּחְתֶּיהָ וַיִּתֵּן
		אֹתוֹ עַל מַרְצֶפֶת אֲבָנִים׃
	}
}
{
	\eX{
		King Ahaz cut off the insets—the laver stands—and removed the
		lavers from them. He also removed the tank from the bronze oxen
		that supported it and set it on a stone pavement—
	}
}
{
	Qere Ketiv.
}

\Verse{18}
{
	\hX{וְאֶת־[מוּסַךְ] (מיסך) הַשַּׁבָּת אֲשֶׁר־בָּנוּ בַבַּיִת וְאֶת־מְבוֹא הַמֶּלֶךְ הַחִיצוֹנָה הֵסֵב בֵּית יְהֹוָה מִפְּנֵי מֶלֶךְ אַשּׁוּר׃}
}
{
	\eX{
		on account of the king of Assyria. He also extended to the House
		of YHWH the sabbath passage that had been built in the palace and
		the king’s outer entrance.
	}
}
{
	Qere Ketiv.
}

\Verse{19}
{
	\hX{וְיֶתֶר דִּבְרֵי אָחָז אֲשֶׁר עָשָׂה הֲלֹא־הֵם כְּתוּבִים עַל־סֵפֶר דִּבְרֵי הַיָּמִים לְמַלְכֵי יְהוּדָה׃}
}
{
	\eX{
		The other events of Ahaz’s reign, and his actions, are recorded in
		the Annals of the Kings of Judah.
	}
}
{
}

\Verse{20}
{
	\hX{וַיִּשְׁכַּב אָחָז עִם־אֲבֹתָיו וַיִּקָּבֵר עִם־אֲבֹתָיו בְּעִיר דָּוִד וַיִּמְלֹךְ חִזְקִיָּהוּ בְנוֹ תַּחְתָּיו׃}
}
{
	\eX{
		Ahaz slept with his fathers and was buried with his fathers in the
		City of David; his son Hezekiah succeeded him as king.
	}
}
{
}
