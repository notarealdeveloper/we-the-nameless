\Chapter{11}

\Verse{1}
{
	\hX{וַעֲתַלְיָה אֵם אֲחַזְיָהוּ (וראתה) [רָאֲתָה] כִּי מֵת בְּנָהּ וַתָּקם וַתְּאַבֵּד אֵת כּל־זֶרַע הַמַּמְלָכָה׃}
}
{
	\eX{
		When Athaliah, the mother of Ahaziah, learned that her son was
		dead, she promptly killed off all who were of royal stock.
	}
}
{
	Qere Ketiv.
}

\Verse{2}
{
	\hX{
		וַתִּקַּח יְהוֹשֶׁבַע בַּת־הַמֶּלֶךְ־יוֹרָם אֲחוֹת אֲחַזְיָהוּ אֶת־יוֹאָשׁ בֶּן־אֲחַזְיָה וַתִּגְנֹב אֹתוֹ מִתּוֹךְ בְּנֵי־הַמֶּלֶךְ (הממותתים) [הַמּוּמָתִים] אֹתוֹ
		וְאֶת־מֵינִקְתּוֹ בַּחֲדַר הַמִּטּוֹת וַיַּסְתִּרוּ אֹתוֹ מִפְּנֵי עֲתַלְיָהוּ וְלֹא הוּמָת׃
	}
}
{
	\eX{
		But Jehosheba, daughter of King Joram and sister of Ahaziah,
		secretly took Ahaziah’s son Joash away from among the princes who
		were being slain, and [put] him and his nurse in a bedroom. And
		they kept him hidden from Athaliah so that he was not put to
		death.
	}
}
{
	Qere Ketiv.
}

\Verse{3}
{
	\hX{וַיְהִי אִתָּהּ בֵּית יְהֹוָה מִתְחַבֵּא שֵׁשׁ שָׁנִים וַעֲתַלְיָה מֹלֶכֶת עַל־הָאָרֶץ׃}
}
{
	\eX{
		He stayed with her for six years, hidden in the House of YHWH,
		while Athaliah reigned over the land.
	}
}
{
}

\Verse{4}
{
	\hX{
		וּבַשָּׁנָה הַשְּׁבִיעִית שָׁלַח יְהוֹיָדָע וַיִּקַּח אֶת־שָׂרֵי (המאיות) [הַמֵּאוֹת] לַכָּרִי וְלָרָצִים וַיָּבֵא אֹתָם אֵלָיו בֵּית יְהֹוָה וַיִּכְרֹת לָהֶם בְּרִית וַיַּשְׁבַּע
		אֹתָם בְּבֵית יְהֹוָה וַיַּרְא אֹתָם אֶת־בֶּן־הַמֶּלֶךְ׃
	}
}
{
	\eX{
		In the seventh year, Jehoiada sent for the chiefs of the hundreds
		of the Carites and of the guards, and had them come to him in the
		House of YHWH. He made a pact with them, exacting an oath from
		them in the House of YHWH, and he showed them the king’s son.
	}
}
{
	Qere Ketiv.
}

\Verse{5}
{
	\hX{וַיְצַוֵּם לֵאמֹר זֶה הַדָּבָר אֲשֶׁר תַּעֲשׂוּן הַשְּׁלִשִׁית מִכֶּם בָּאֵי הַשַּׁבָּת וְשֹׁמְרֵי מִשְׁמֶרֶת בֵּית הַמֶּלֶךְ׃}
}
{
	\eX{
		He instructed them: “This is what you must do: One-third of those
		who are on duty for the week shall maintain guard over the royal
		palace;
	}
}
{
}

\Verse{6}
{
	\hX{וְהַשְּׁלִשִׁית בְּשַׁעַר סוּר וְהַשְּׁלִשִׁית בַּשַּׁעַר אַחַר הָרָצִים וּשְׁמַרְתֶּם אֶת־מִשְׁמֶרֶת הַבַּיִת מַסָּח׃}
}
{
	\eX{
		another third shall be [stationed] at the Sur Gate; and the other
		third shall be at the gate behind the guards; you shall keep guard
		over the House on every side.
	}
}
{
}

\Verse{7}
{
	\hX{וּשְׁתֵּי הַיָּדוֹת בָּכֶם כֹּל יֹצְאֵי הַשַּׁבָּת וְשָׁמְרוּ אֶת־מִשְׁמֶרֶת בֵּית־יְהֹוָה אֶל־הַמֶּלֶךְ׃}
}
{
	\eX{
		The two divisions of yours who are off duty this week shall keep
		guard over the House of YHWH for the protection of the king.
	}
}
{
}

\Verse{8}
{
	\hX{וְהִקַּפְתֶּם עַל־הַמֶּלֶךְ סָבִיב אִישׁ וְכֵלָיו בְּיָדוֹ וְהַבָּא אֶל־הַשְּׂדֵרוֹת יוּמָת וִהְיוּ אֶת־הַמֶּלֶךְ בְּצֵאתוֹ וּבְבֹאוֹ׃}
}
{
	\eX{
		You shall surround the king on every side, every man with his
		weapons at the ready; and whoever breaks through the ranks shall
		be killed. Stay close to the king in his comings and goings.”
	}
}
{
}

\Verse{9}
{
	\hX{
		וַיַּעֲשׂוּ שָׂרֵי (המאיות) [הַמֵּאוֹת] כְּכֹל אֲשֶׁר־צִוָּה יְהוֹיָדָע הַכֹּהֵן וַיִּקְחוּ אִישׁ אֶת־אֲנָשָׁיו בָּאֵי הַשַּׁבָּת עִם יֹצְאֵי הַשַּׁבָּת וַיָּבֹאוּ אֶל־יְהוֹיָדָע
		הַכֹּהֵן׃
	}
}
{
	\eX{
		The chiefs of hundreds did just as Jehoiada ordered: Each took his
		men—those who were on duty that week and those who were off duty
		that week—and they presented themselves to Jehoiada the priest.
	}
}
{
	Qere Ketiv.
}

\Verse{10}
{
	\hX{וַיִּתֵּן הַכֹּהֵן לְשָׂרֵי (המאיות) [הַמֵּאוֹת] אֶת־הַחֲנִית וְאֶת־הַשְּׁלָטִים אֲשֶׁר לַמֶּלֶךְ דָּוִד אֲשֶׁר בְּבֵית יְהֹוָה׃}
}
{
	\eX{
		The priest gave the chiefs of hundreds King David’s spears and
		quivers that were kept in the House of YHWH.
	}
}
{
	Qere Ketiv.
}

\Verse{11}
{
	\hX{וַיַּעַמְדוּ הָרָצִים אִישׁ וְכֵלָיו בְּיָדוֹ מִכֶּתֶף הַבַּיִת הַיְמָנִית עַד־כֶּתֶף הַבַּיִת הַשְּׂמָאלִית לַמִּזְבֵּחַ וְלַבָּיִת עַל־הַמֶּלֶךְ סָבִיב׃}
}
{
	\eX{
		The guards, each with his weapons at the ready, stationed
		themselves—from the south end of the House to the north end of the
		House, at the altar and the House—to guard the king on every side.
	}
}
{
}

\Verse{12}
{
	\hX{וַיּוֹצִא אֶת־בֶּן־הַמֶּלֶךְ וַיִּתֵּן עָלָיו אֶת־הַנֵּזֶר וְאֶת־הָעֵדוּת וַיַּמְלִכוּ אֹתוֹ וַיִּמְשָׁחֻהוּ וַיַּכּוּ־כָף וַיֹּאמְרוּ יְחִי הַמֶּלֶךְ׃}
}
{
	\eX{
		[Jehoiada] then brought out the king’s son, and placed upon him
		the crown and the insignia. They anointed him and proclaimed him
		king; they clapped their hands and shouted, “Long live the king!”
	}
}
{
}

\Verse{13}
{
	\hX{וַתִּשְׁמַע עֲתַלְיָה אֶת־קוֹל הָרָצִין הָעָם וַתָּבֹא אֶל־הָעָם בֵּית יְהֹוָה׃}
}
{
	\eX{
		When Athaliah heard the shouting of the guards [and] the people,
		she came out to the people in the House of YHWH.
	}
}
{
}

\Verse{14}
{
	\hX{
		וַתֵּרֶא וְהִנֵּה הַמֶּלֶךְ עֹמֵד עַל־הָעַמּוּד כַּמִּשְׁפָּט וְהַשָּׂרִים וְהַחֲצֹצְרוֹת אֶל־הַמֶּלֶךְ וְכל־עַם הָאָרֶץ שָׂמֵחַ וְתֹקֵעַ בַּחֲצֹצְרוֹת וַתִּקְרַע עֲתַלְיָה
		אֶת־בְּגָדֶיהָ וַתִּקְרָא קֶשֶׁר קָשֶׁר׃
	}
}
{
	\eX{
		She looked about and saw the king standing by the pillar, as was
		the custom, the chiefs with their trumpets beside the king, and
		all the people of the land rejoicing and blowing trumpets.
		Athaliah rent her garments and cried out, “Treason, treason!”
	}
}
{
}

\Verse{15}
{
	\hX{
		וַיְצַו יְהוֹיָדָע הַכֹּהֵן אֶת־שָׂרֵי (המאיות) [הַמֵּאוֹת ] פְּקֻדֵי הַחַיִל וַיֹּאמֶר אֲלֵיהֶם הוֹצִיאוּ אֹתָהּ אֶל־מִבֵּית לַשְּׂדֵרֹת וְהַבָּא אַחֲרֶיהָ הָמֵת בֶּחָרֶב כִּי
		אָמַר הַכֹּהֵן אַל־תּוּמַת בֵּית יְהֹוָה׃
	}
}
{
	\eX{
		Then the priest Jehoiada gave the command to the army officers,
		the chiefs of hundreds, and said to them, “Take her out between
		the ranks and, if anyone follows her, put him to the sword.” For
		the priest thought: “Let her not be put to death in the House of
		YHWH.”
	}
}
{
	Qere Ketiv.
}

\Verse{16}
{
	\hX{וַיָּשִׂמוּ לָהּ יָדַיִם וַתָּבוֹא דֶּרֶךְ־מְבוֹא הַסּוּסִים בֵּית הַמֶּלֶךְ וַתּוּמַת שָׁם׃}
}
{
	\eX{
		They cleared a passageway for her and she entered the royal palace
		through the horses’ entrance: there she was put to death.
	}
}
{
}

\Verse{17}
{
	\hX{וַיִּכְרֹת יְהוֹיָדָע אֶת־הַבְּרִית בֵּין יְהֹוָה וּבֵין הַמֶּלֶךְ וּבֵין הָעָם לִהְיוֹת לְעָם לַיהֹוָה וּבֵין הַמֶּלֶךְ וּבֵין הָעָם׃}
}
{
	\eX{
		And Jehoiada solemnized the covenant between YHWH, on the one
		hand, and the king and the people, on the other—as well as between
		the king and the people—that they should be the people of YHWH.
	}
}
{
}

\Verse{18}
{
	\hX{
		וַיָּבֹאוּ כל־עַם הָאָרֶץ בֵּית־הַבַּעַל וַיִּתְּצֻהוּ אֶת־מִזְבְּחֹתָו וְאֶת־צְלָמָיו שִׁבְּרוּ הֵיטֵב וְאֵת מַתָּן כֹּהֵן הַבַּעַל הָרְגוּ לִפְנֵי הַמִּזְבְּחוֹת וַיָּשֶׂם
		הַכֹּהֵן פְּקֻדֹּת עַל־בֵּית יְהֹוָה׃
	}
}
{
	\eX{
		Thereupon all the people of the land went to the temple of Baal.
		They tore it down and smashed its altars and images to bits, and
		they slew Mattan, the priest of Baal, in front of the altars.
		[Jehoiada] the priest then placed guards over the House of YHWH.
	}
}
{
}

\Verse{19}
{
	\hX{
		וַיִּקַּח אֶת־שָׂרֵי הַמֵּאוֹת וְאֶת־הַכָּרִי וְאֶת־הָרָצִים וְאֵת כּל־עַם הָאָרֶץ וַיֹּרִידוּ אֶת־הַמֶּלֶךְ מִבֵּית יְהֹוָה וַיָּבוֹאוּ דֶּרֶךְ־שַׁעַר הָרָצִים בֵּית הַמֶּלֶךְ
		וַיֵּשֶׁב עַל־כִּסֵּא הַמְּלָכִים׃
	}
}
{
	\eX{
		He took the chiefs of hundreds, the Carites, the guards, and all
		the people of the land, and they escorted the king from the House
		of YHWH into the royal palace by the gate of the guards. And he
		ascended the royal throne.
	}
}
{
}

\Verse{20}
{
	\hX{וַיִּשְׂמַח כּל־עַם־הָאָרֶץ וְהָעִיר שָׁקָטָה וְאֶת־עֲתַלְיָהוּ הֵמִיתוּ בַחֶרֶב בֵּית (מלך) [הַמֶּלֶךְ]׃}
}
{
	\eX{
		All the people of the land rejoiced, and the city was quiet. As

	}
}
{

}
