\Verse{3}

	\hX{וַיֵּלֶךְ בְּכל־חַטֹּאות אָבִיו אֲשֶׁר־עָשָׂה לְפָנָיו וְלֹא־הָיָה לְבָבוֹ שָׁלֵם עִם־יְהֹוָה אֱלֹהָיו כִּלְבַב דָּוִד אָבִיו׃}
}
{
	\eX{
		He continued in all the sins that his father before him had
		committed; he was not wholehearted with YHWH his God, like his

{
}

\Verse{4}

	\hX{כִּי לְמַעַן דָּוִד נָתַן יְהֹוָה אֱלֹהָיו לוֹ נִיר בִּירוּשָׁלָ͏ִם לְהָקִים אֶת־בְּנוֹ אַחֲרָיו וּלְהַעֲמִיד אֶת־יְרוּשָׁלָ͏ִם׃}
}
{
	\eX{
		Yet, for the sake of David, YHWH his God gave him a lamp in
		Jerusalem, by raising up his descendant after him and by
		preserving Jerusalem.

{
}

\Verse{5}

}
{
	\eX{

}
{
}

\Verse{6}
{
	\hX{וּמִלְחָמָה הָיְתָה בֵין־רְחַבְעָם וּבֵין יָרבְעָם כּל־יְמֵי חַיָּיו׃}
}

}

	\eX{

}
{
	\eX{

		because she had made an abominable thing for [the goddess]

		Wadi Kidron.
	}
}
{
}

		אָסָא אֶל־בֶּן־הֲדַד בֶּן־טַבְרִמֹּן בֶּן־חֶזְיוֹן מֶלֶךְ אֲרָם הַיֹּשֵׁב בְּדַמֶּשֶׂק לֵאמֹר׃
	}
}

	\eX{
		So Asa took all the silver and gold that remained in the
		treasuries of the House of YHWH as well as the treasuries of the

	}
}
{
}

}
{
}

{
