}
{
	\eX{
		For the entrance of the Great Hall, too, he made doorposts of

}
{
}

\Verse{34}
{
	\hX{וּשְׁתֵּי דַלְתוֹת עֲצֵי בְרוֹשִׁים שְׁנֵי צְלָעִים הַדֶּלֶת הָאַחַת גְּלִילִים וּשְׁנֵי קְלָעִים הַדֶּלֶת הַשֵּׁנִית גְּלִילִים׃}
}
{
	\eX{
		and the double doors of cypress wood, each door consisting of two
		rounded planks.
	}
}
{
}

\Verse{35}
{
	\hX{וְקָלַע כְּרוּבִים וְתִמֹרוֹת וּפְטֻרֵי צִצִּים וְצִפָּה זָהָב מְיֻשָּׁר עַל־הַמְּחֻקֶּה׃}
}
{
	\eX{
		On them he carved cherubim, palms, and calyxes, overlaying them
		with gold applied evenly over the carvings.
	}
}
{
}

}
{
	\eX{
		He built the inner enclosure of three courses of hewn stones and

	}
}
{
}

}

{
	\eX{
