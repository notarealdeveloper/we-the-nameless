
Conventions:

A = א
O = ע
X = ח
H = ה
w = ו
y = י
t = ת
n = נ
h = ה
i = י
m = ם
k = ך / כ when suffixal

Wayyiqtol/story forms translated as narrative present:

> “and he says”
> “and she sees”
> “and he goes”

not “and he said/saw/went.”

This is the useful compressed rule-set behind the examples:

ROOT
yROOT        = he/they prefix
tROOT        = she/you prefix
aROOT        = I prefix
nROOT        = we prefix
ROOTti       = I completed
ROOTt        = you completed
ROOTh        = she completed
ROOTw        = they completed
w + prefix   = story-and / narrative-present chain

Common weak-root rewrite rules:

ABH + suffix  -> AB + suffix
yABH story    -> yAB
tABH story    -> tAB
yABH + w      -> yABw

BWA story     -> BA
QWM story     -> QM
MWT story     -> MT

LQX prefix    -> QX
NTN prefix    -> TN

yYBC          -> yBC

In prose, this is the practical machine:

root
→ add person marker
→ apply weak-root rewrite if needed
→ optionally add story-w
→ read as narrative present
