
# MASTER TABLE — STANDARD VERB

Base root:

```text
XXX = חחח
```

Rules assumed here:

```text
yROOT   = he/they prefix
tROOT   = she/you prefix
aROOT   = I prefix
nROOT   = we prefix

ROOTti  = I completed
ROOTt   = you completed
ROOTh   = she completed
ROOTnw  = we completed
ROOTtm  = you-all-m completed
ROOTtn  = you-all-f completed
ROOTw   = they completed
ROOTnh  = they-f completed

w + prefix-form = story-present chain
```


# Grand Reduction

The whole CBH finite verb machine is approximately:

```text
ROOT
→ add person marker
→ add plurality marker if needed
→ apply weak-root rewrite rules
→ optionally shorten story form
→ optionally prepend story-w
```

And narratively:

```text
wyXXX
wtXXX
wyXXXw
```

function much closer to:

```text
“and he says”
“and she goes”
“and they see”
```

than to rigid Indo-European past tense.
