The script now most plausibly appears to be:

- Northwest Semitic
- strongly connected to Proto-Sinaitic traditions
- probably not a pure alphabet
- likely consonantal with partial syllabic/vocalic behavior
- possibly transitional between:
  - proto-alphabetic
  - defective syllabary
  - consonant+vowel sign system

The strongest identifiable lexical anchors currently are:

- BLT ≈ Baalat
- GBL ≈ Gebal / Byblos
- BRK ≈ bless

Which is honestly an impressively coherent cluster for a hypothetical Middle Bronze Age Byblos inscription.

# Most important new observation

The inscriptions increasingly behave like:

```text
CV-CV-CV roots
```

rather than:

```text
single consonant alphabetic strings
```

especially because:

| Pattern | Observed |
|---|---|
| B1 vs B3 | same consonant class, different vowel |
| L1 vs L2 | same consonant class, different vowel |
| T1/T2/T3 | same coronal, different vocalic/emphatic values |
| repeated lexical stems with sign variation | extremely common |

This is exactly what you’d expect from a Semitic syllabary or abugida-like system.
