\Chapter{12}

\Verse{1}
{
	\hX{
		וְאֵלֶּה מַלְכֵי הָאָרֶץ אֲשֶׁר הִכּוּ בְנֵי־יִשְׂרָאֵל וַיִּרְשׁוּ אֶת־אַרְצָם בְּעֵבֶר הַיַּרְדֵּן מִזְרְחָה הַשָּׁמֶשׁ מִנַּחַל אַרְנוֹן עַד־הַר חֶרְמוֹן וְכל־הָעֲרָבָה
		מִזְרָחָה׃
	}
}
{
	\eX{
		Now these are the kings of the land, that the children of Israel
		struck, and possessed their land across the Jordan toward the
		rising of the sun, from the river Arnon to mount Hermon, and all
		the plain on the east:
	}
}
{
}

\Verse{2}
{
	\hX{
		סִיחוֹן מֶלֶךְ הָאֱמֹרִי הַיּוֹשֵׁב בְּחֶשְׁבּוֹן מֹשֵׁל מֵעֲרוֹעֵר אֲשֶׁר עַל־שְׂפַת־נַחַל אַרְנוֹן וְתוֹךְ הַנַּחַל וַחֲצִי הַגִּלְעָד וְעַד יַבֹּק הַנַּחַל גְּבוּל בְּנֵי
		עַמּוֹן׃
	}
}
{
	\eX{
		Sihon king of the Amorites, who lived in Heshbon, and ruled from
		Aroer, that is on the bank of the river Arnon, and from the
		middle of the river, and from half Gilead, even to the river
		Jabbok, that is the border of the children of Ammon;
	}
}
{
}

\Verse{3}
{
	\hX{וְהָעֲרָבָה עַד־יָם כִּנְרוֹת מִזְרָחָה וְעַד יָם הָעֲרָבָה יָם־הַמֶּלַח מִזְרָחָה דֶּרֶךְ בֵּית הַיְשִׁמוֹת וּמִתֵּימָן תַּחַת אַשְׁדּוֹת הַפִּסְגָּה׃}
}
{
	\eX{
		And from the plain to the sea of Chinneroth on the east, and to
		the sea of the plain, even the Salt Sea on the east, the way to
		Bethjeshimoth; and from the south, under Ashdothpisgah:
	}
}
{
}

\Verse{4}
{
	\hX{וּגְבוּל עוֹג מֶלֶךְ הַבָּשָׁן מִיֶּתֶר הָרְפָאִים הַיּוֹשֵׁב בְּעַשְׁתָּרוֹת וּבְאֶדְרֶעִי׃}
}
{
	\eX{
		And the border of Og king of Bashan, that was of the remnant of
		the giants, who lived at Ashtaroth and at Edrei,
	}
}
{
}

\Verse{5}
{
	\hX{וּמֹשֵׁל בְּהַר חֶרְמוֹן וּבְסַלְכָה וּבְכל־הַבָּשָׁן עַד־גְּבוּל הַגְּשׁוּרִי וְהַמַּעֲכָתִי וַחֲצִי הַגִּלְעָד גְּבוּל סִיחוֹן מֶלֶךְ־חֶשְׁבּוֹן׃}
}
{
	\eX{
		And reigned in mount Hermon, and in Salcah, and in all Bashan,
		to the border of the Geshurites and the Maachathites, and half
		Gilead, the border of Sihon king of Heshbon.
	}
}
{
}

\Verse{6}
{
	\hX{מֹשֶׁה עֶבֶד־יְהֹוָה וּבְנֵי יִשְׂרָאֵל הִכּוּם וַיִּתְּנָהּ מֹשֶׁה עֶבֶד־יְהֹוָה יְרֻשָּׁה לָראוּבֵנִי וְלַגָּדִי וְלַחֲצִי שֵׁבֶט הַמְנַשֶּׁה׃}
}
{
	\eX{
		Moses, YHWH’s servant, and the children of Israel struck them:
		and Moses the servant of YHWH gave it for a possession to the
		Reubenites, and the Gadites, and the half tribe of Manasseh.
	}
}
{
}

\Verse{7}
{
	\hX{
		וְאֵלֶּה מַלְכֵי הָאָרֶץ אֲשֶׁר הִכָּה יְהוֹשֻׁעַ וּבְנֵי יִשְׂרָאֵל בְּעֵבֶר הַיַּרְדֵּן יָמָּה מִבַּעַל גָּד בְּבִקְעַת הַלְּבָנוֹן וְעַד־הָהָר הֶחָלָק הָעֹלֶה שֵׂעִירָה
		וַיִּתְּנָהּ יְהוֹשֻׁעַ לְשִׁבְטֵי יִשְׂרָאֵל יְרֻשָּׁה כְּמַחְלְקֹתָם׃
	}
}
{
	\eX{
		And these are the kings of the country that Joshua and the
		children of Israel struck across the Jordan on the west, from
		Baalgad in the valley of Lebanon even to the mount Halak, that
		goes up to Seir; that Joshua gave to the tribes of Israel for a
		possession according to their divisions;
	}
}
{
}
