\Chapter{23}

\Verse{1}
{
	\hX{וַיְהִי מִיָּמִים רַבִּים אַחֲרֵי אֲשֶׁר־הֵנִיחַ יְהֹוָה לְיִשְׂרָאֵל מִכּל־אֹיְבֵיהֶם מִסָּבִיב וִיהוֹשֻׁעַ זָקֵן בָּא בַּיָּמִים׃}
}
{
	\eX{
		And it was a long time after that YHWH had given rest to Israel
		from all their enemies round about, that Joshua grew old and
		stricken in age.
	}
}
{
}

\Verse{2}
{
	\hX{וַיִּקְרָא יְהוֹשֻׁעַ לְכל־יִשְׂרָאֵל לִזְקֵנָיו וּלְרָאשָׁיו וּלְשֹׁפְטָיו וּלְשֹׁטְרָיו וַיֹּאמֶר אֲלֵהֶם אֲנִי זָקַנְתִּי בָּאתִי בַּיָּמִים׃}
}
{
	\eX{
		And Joshua called for all Israel, and for their elders, and for
		their heads, and for their judges, and for their officers, and
		said to them, I am old and stricken in age:
	}
}
{
}

\Verse{3}
{
	\hX{וְאַתֶּם רְאִיתֶם אֵת כּל־אֲשֶׁר עָשָׂה יְהֹוָה אֱלֹהֵיכֶם לְכל־הַגּוֹיִם הָאֵלֶּה מִפְּנֵיכֶם כִּי יְהֹוָה אֱלֹהֵיכֶם הוּא הַנִּלְחָם לָכֶם׃}
}
{
	\eX{
		And you have seen all that YHWH your God has done to all these
		nations because of you; for YHWH your God is he that has fought
		for you.
	}
}
{
}

\Verse{4}
{
	\hX{רְאוּ הִפַּלְתִּי לָכֶם אֶת־הַגּוֹיִם הַנִּשְׁאָרִים הָאֵלֶּה בְּנַחֲלָה לְשִׁבְטֵיכֶם מִן־הַיַּרְדֵּן וְכל־הַגּוֹיִם אֲשֶׁר הִכְרַתִּי וְהַיָּם הַגָּדוֹל מְבוֹא הַשָּׁמֶשׁ׃}
}
{
	\eX{
		Here, I have divided to you by lot these nations that stay, to
		be an inheritance for your tribes, from Jordan, with all the
		nations that I have cut off, even to the great sea westward.
	}
}
{
}

\Verse{5}
{
	\hX{וַיהֹוָה אֱלֹהֵיכֶם הוּא יֶהְדֳּפֵם מִפְּנֵיכֶם וְהוֹרִישׁ אֹתָם מִלִּפְנֵיכֶם וִירִשְׁתֶּם אֶת־אַרְצָם כַּאֲשֶׁר דִּבֶּר יְהֹוָה אֱלֹהֵיכֶם לָכֶם׃}
}
{
	\eX{
		And YHWH your God, He shall expel them from before you, and
		drive them from out of your sight; and you shall possess their
		land, as YHWH your God has promised to you.
	}
}
{
}

\Verse{6}
{
	\hX{וַחֲזַקְתֶּם מְאֹד לִשְׁמֹר וְלַעֲשׂוֹת אֵת כּל־הַכָּתוּב בְּסֵפֶר תּוֹרַת מֹשֶׁה לְבִלְתִּי סוּר־מִמֶּנּוּ יָמִין וּשְׂמֹאול׃}
}
{
	\eX{
		Be you therefore very courageous to keep and to do all that is
		written in the book of the law of Moses, that you turn not aside
		from it to the right hand or to the left;
	}
}
{
}

\Verse{7}
{
	\hX{לְבִלְתִּי־בֹא בַּגּוֹיִם הָאֵלֶּה הַנִּשְׁאָרִים הָאֵלֶּה אִתְּכֶם וּבְשֵׁם אֱלֹהֵיהֶם לֹא־תַזְכִּירוּ וְלֹא תַשְׁבִּיעוּ וְלֹא תַעַבְדוּם וְלֹא תִשְׁתַּחֲווּ לָהֶם׃}
}
{
	\eX{
		That you come not among these nations, these that stay among
		you; neither make mention of the name of their gods, nor cause
		to swear by them, neither serve them, nor bow yourselves to
		them:
	}
}
{
}

\Verse{8}
{
	\hX{כִּי אִם־בַּיהֹוָה אֱלֹהֵיכֶם תִּדְבָּקוּ כַּאֲשֶׁר עֲשִׂיתֶם עַד הַיּוֹם הַזֶּה׃}
}
{
	\eX{But cling to YHWH your God, as you have done to this day.}
}
{
}

\Verse{9}
{
	\hX{וַיּוֹרֶשׁ יְהֹוָה מִפְּנֵיכֶם גּוֹיִם גְּדֹלִים וַעֲצוּמִים וְאַתֶּם לֹא־עָמַד אִישׁ בִּפְנֵיכֶם עַד הַיּוֹם הַזֶּה׃}
}
{
	\eX{
		For YHWH has driven out from before you great nations and
		strong: but as for you, no man has been able to stand before you
		to this day.
	}
}
{
}

\Verse{10}
{
	\hX{אִישׁ־אֶחָד מִכֶּם יִרְדּף־אָלֶף כִּי יְהֹוָה אֱלֹהֵיכֶם הוּא הַנִּלְחָם לָכֶם כַּאֲשֶׁר דִּבֶּר לָכֶם׃}
}
{
	\eX{
		One man of you shall chase a thousand: for YHWH your God, He is
		the one that fights for you, as He has promised you.
	}
}
{
}

\Verse{11}
{
	\hX{וְנִשְׁמַרְתֶּם מְאֹד לְנַפְשֹׁתֵיכֶם לְאַהֲבָה אֶת־יְהֹוָה אֱלֹהֵיכֶם׃}
}
{
	\eX{
		Take good heed therefore to yourselves, that you love YHWH your
		God.
	}
}
{
}

\Verse{12}
{
	\hX{כִּי אִם־שׁוֹב תָּשׁוּבוּ וּדְבַקְתֶּם בְּיֶתֶר הַגּוֹיִם הָאֵלֶּה הַנִּשְׁאָרִים הָאֵלֶּה אִתְּכֶם וְהִתְחַתַּנְתֶּם בָּהֶם וּבָאתֶם בָּהֶם וְהֵם בָּכֶם׃}
}
{
	\eX{
		Else if you do just go back, and cling to the remnant of these
		nations, even these that stay among you, and shall make
		marriages with them, and go in to them, and they to you:
	}
}
{
}

\Verse{13}
{
	\hX{
		יָדוֹעַ תֵּדְעוּ כִּי לֹא יוֹסִיף יְהֹוָה אֱלֹהֵיכֶם לְהוֹרִישׁ אֶת־הַגּוֹיִם הָאֵלֶּה מִלִּפְנֵיכֶם וְהָיוּ לָכֶם לְפַח וּלְמוֹקֵשׁ וּלְשֹׁטֵט בְּצִדֵּיכֶם וְלִצְנִנִים
		בְּעֵינֵיכֶם עַד־אֲבדְכֶם מֵעַל הָאֲדָמָה הַטּוֹבָה הַזֹּאת אֲשֶׁר נָתַן לָכֶם יְהֹוָה אֱלֹהֵיכֶם׃
	}
}
{
	\eX{
		Know for a certainty that YHWH your God will no more drive out
		any of these nations from before you; but they shall be snares
		and traps to you, and scourges in your sides, and thorns in your
		eyes, until you perish from off this good land that YHWH your
		God has given you.
	}
}
{
}

\Verse{14}
{
	\hX{
		וְהִנֵּה אָנֹכִי הוֹלֵךְ הַיּוֹם בְּדֶרֶךְ כּל־הָאָרֶץ וִידַעְתֶּם בְּכל־לְבַבְכֶם וּבְכל־נַפְשְׁכֶם כִּי לֹא־נָפַל דָּבָר אֶחָד מִכֹּל הַדְּבָרִים הַטּוֹבִים אֲשֶׁר דִּבֶּר
		יְהֹוָה אֱלֹהֵיכֶם עֲלֵיכֶם הַכֹּל בָּאוּ לָכֶם לֹא־נָפַל מִמֶּנּוּ דָּבָר אֶחָד׃
	}
}
{
	\eX{
		And, here, this day I am going the way of all the earth: and you
		know in all your hearts and in all your souls, that not one
		thing has failed of all the good things that YHWH your God spoke
		concerning you; all are come to pass to you, and not one thing
		has failed of it.
	}
}
{
}

\Verse{15}
{
	\hX{
		וְהָיָה כַּאֲשֶׁר־בָּא עֲלֵיכֶם כּל־הַדָּבָר הַטּוֹב אֲשֶׁר דִּבֶּר יְהֹוָה אֱלֹהֵיכֶם אֲלֵיכֶם כֵּן יָבִיא יְהֹוָה עֲלֵיכֶם אֵת כּל־הַדָּבָר הָרָע עַד־הַשְׁמִידוֹ אוֹתְכֶם מֵעַל
		הָאֲדָמָה הַטּוֹבָה הַזֹּאת אֲשֶׁר נָתַן לָכֶם יְהֹוָה אֱלֹהֵיכֶם׃
	}
}
{
	\eX{
		Therefore it shall come to pass, that as all good things are
		come on you, that YHWH your God promised you; so shall YHWH
		bring on you all evil things, until he have destroyed you from
		off this good land that YHWH your God has given you.
	}
}
{
}

\Verse{16}
{
	\hX{
		בְּעבְרְכֶם אֶת־בְּרִית יְהֹוָה אֱלֹהֵיכֶם אֲשֶׁר צִוָּה אֶתְכֶם וַהֲלַכְתֶּם וַעֲבַדְתֶּם אֱלֹהִים אֲחֵרִים וְהִשְׁתַּחֲוִיתֶם לָהֶם וְחָרָה אַף־יְהֹוָה בָּכֶם וַאֲבַדְתֶּם
		מְהֵרָה מֵעַל הָאָרֶץ הַטּוֹבָה אֲשֶׁר נָתַן לָכֶם׃
	}
}
{
	\eX{
		When you have transgressed the covenant of YHWH your God, that
		he commanded you, and have gone and served other gods, and bowed
		yourselves to them; then shall the anger of YHWH be kindled
		against you, and you shall perish quickly from off the good land
		that he has given to you.
	}
}
{
}
