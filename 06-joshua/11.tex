\Chapter{11}

\Verse{1}
{
	\hX{וַיְהִי כִּשְׁמֹעַ יָבִין מֶלֶךְ־חָצוֹר וַיִּשְׁלַח אֶל־יוֹבָב מֶלֶךְ מָדוֹן וְאֶל־מֶלֶךְ שִׁמְרוֹן וְאֶל־מֶלֶךְ אַכְשָׁף׃}
}
{
	\eX{
		And it was, when Jabin king of Hazor had heard those things,
		that he sent to Jobab king of Madon, and to the king of Shimron,
		and to the king of Achshaph,
	}
}
{
}

\Verse{2}
{
	\hX{וְאֶל־הַמְּלָכִים אֲשֶׁר מִצְּפוֹן בָּהָר וּבָעֲרָבָה נֶגֶב כִּנְרוֹת וּבַשְּׁפֵלָה וּבְנָפוֹת דּוֹר מִיָּם׃}
}
{
	\eX{
		And to the kings that were on the north of the mountains, and of
		the plains south of Chinneroth, and in the valley, and in the
		borders of Dor on the west,
	}
}
{
}

\Verse{3}
{
	\hX{הַכְּנַעֲנִי מִמִּזְרָח וּמִיָּם וְהָאֱמֹרִי וְהַחִתִּי וְהַפְּרִזִּי וְהַיְבוּסִי בָּהָר וְהַחִוִּי תַּחַת חֶרְמוֹן בְּאֶרֶץ הַמִּצְפָּה׃}
}
{
	\eX{
		And to the Canaanite on the east and on the west, and to the
		Amorite, and the Hittite, and the Perizzite, and the Jebusite in
		the mountains, and to the Hivite under Hermon in the land of
		Mizpeh.
	}
}
{
}

\Verse{4}
{
	\hX{וַיֵּצְאוּ הֵם וְכל־מַחֲנֵיהֶם עִמָּם עַם־רָב כַּחוֹל אֲשֶׁר עַל־שְׂפַת־הַיָּם לָרֹב וְסוּס וָרֶכֶב רַב־מְאֹד׃}
}
{
	\eX{
		And they went out, they and all their armies with them, much
		people, even as the sand that is on the sea shore in multitude,
		with horses and chariots very many.
	}
}
{
}

\Verse{5}
{
	\hX{וַיִּוָּעֲדוּ כֹּל הַמְּלָכִים הָאֵלֶּה וַיָּבֹאוּ וַיַּחֲנוּ יַחְדָּו אֶל־מֵי מֵרוֹם לְהִלָּחֵם עִם־יִשְׂרָאֵל׃}
}
{
	\eX{
		And when all these kings were met together, they came and camped
		together at the waters of Merom, to fight against Israel.
	}
}
{
}

\Verse{6}
{
	\hX{
		וַיֹּאמֶר יְהֹוָה אֶל־יְהוֹשֻׁעַ אַל־תִּירָא מִפְּנֵיהֶם כִּי־מָחָר כָּעֵת הַזֹּאת אָנֹכִי נֹתֵן אֶת־כֻּלָּם חֲלָלִים לִפְנֵי יִשְׂרָאֵל אֶת־סוּסֵיהֶם תְּעַקֵּר
		וְאֶת־מַרְכְּבֹתֵיהֶם תִּשְׂרֹף בָּאֵשׁ׃
	}
}
{
	\eX{
		And YHWH said to Joshua, Be not afraid because of them: for to
		next day about this time will I deliver them up all slain before
		Israel: you shall hough their horses, and burn their chariots
		with fire.
	}
}
{
}

\Verse{7}
{
	\hX{וַיָּבֹא יְהוֹשֻׁעַ וְכל־עַם הַמִּלְחָמָה עִמּוֹ עֲלֵיהֶם עַל־מֵי מֵרוֹם פִּתְאֹם וַיִּפְּלוּ בָּהֶם׃}
}
{
	\eX{
		And Joshua came, and all the people of war with him, against
		them by the waters of Merom suddenly; and they fell on them.
	}
}
{
}

\Verse{8}
{
	\hX{
		וַיִּתְּנֵם יְהֹוָה בְּיַד־יִשְׂרָאֵל וַיַּכּוּם וַיִּרְדְּפוּם עַד־צִידוֹן רַבָּה וְעַד מִשְׂרְפוֹת מַיִם וְעַד־בִּקְעַת מִצְפֶּה מִזְרָחָה וַיַּכֻּם עַד־בִּלְתִּי הִשְׁאִיר־לָהֶם
		שָׂרִיד׃
	}
}
{
	\eX{
		And YHWH delivered them into the hand of Israel, who struck
		them, and chased them to great Zidon, and to Misrephothmaim, and
		to the valley of Mizpeh eastward; and they struck them, until
		they left them none remaining.
	}
}
{
}

\Verse{9}
{
	\hX{וַיַּעַשׂ לָהֶם יְהוֹשֻׁעַ כַּאֲשֶׁר אָמַר־לוֹ יְהֹוָה אֶת־סוּסֵיהֶם עִקֵּר וְאֶת־מַרְכְּבֹתֵיהֶם שָׂרַף בָּאֵשׁ׃}
}
{
	\eX{
		And Joshua did to them as YHWH bade him: he houghed their
		horses, and burnt their chariots with fire.
	}
}
{
}

\Verse{10}
{
	\hX{וַיָּשׁב יְהוֹשֻׁעַ בָּעֵת הַהִיא וַיִּלְכֹּד אֶת־חָצוֹר וְאֶת־מַלְכָּהּ הִכָּה בֶחָרֶב כִּי־חָצוֹר לְפָנִים הִיא רֹאשׁ כּל־הַמַּמְלָכוֹת הָאֵלֶּה׃}
}
{
	\eX{
		And Joshua at that time turned back, and took Hazor, and struck
		the king of it with the sword: for Hazor beforetime was the head
		of all those kingdoms.
	}
}
{
}

\Verse{11}
{
	\hX{וַיַּכּוּ אֶת־כּל־הַנֶּפֶשׁ אֲשֶׁר־בָּהּ לְפִי־חֶרֶב הַחֲרֵם לֹא נוֹתַר כּל־נְשָׁמָה וְאֶת־חָצוֹר שָׂרַף בָּאֵשׁ׃}
}
{
	\eX{
		And they struck all the souls that were in it by the mouth of
		the sword, put under the baning them: there was not any left to
		breathe: and he burnt Hazor with fire.
	}
}
{
}

\Verse{12}
{
	\hX{וְאֶת־כּל־עָרֵי הַמְּלָכִים־הָאֵלֶּה וְאֶת־כּל־מַלְכֵיהֶם לָכַד יְהוֹשֻׁעַ וַיַּכֵּם לְפִי־חֶרֶב הֶחֱרִים אוֹתָם כַּאֲשֶׁר צִוָּה מֹשֶׁה עֶבֶד יְהֹוָה׃}
}
{
	\eX{
		And all the cities of those kings, and all the kings of them,
		did Joshua take, and struck them by the mouth of the sword, and
		he put them under the ban, as Moses the servant of YHWH
		commanded.
	}
}
{
}

\Verse{13}
{
	\hX{רַק כּל־הֶעָרִים הָעֹמְדוֹת עַל־תִּלָּם לֹא שְׂרָפָם יִשְׂרָאֵל זוּלָתִי אֶת־חָצוֹר לְבַדָּהּ שָׂרַף יְהוֹשֻׁעַ׃}
}
{
	\eX{
		But as for the cities that stood still in their strength, Israel
		burned none of them, except Hazor only; that did Joshua burn.
	}
}
{
}

\Verse{14}
{
	\hX{וְכֹל שְׁלַל הֶעָרִים הָאֵלֶּה וְהַבְּהֵמָה בָּזְזוּ לָהֶם בְּנֵי יִשְׂרָאֵל רַק אֶת־כּל־הָאָדָם הִכּוּ לְפִי־חֶרֶב עַד־הִשְׁמִדָם אוֹתָם לֹא הִשְׁאִירוּ כּל־נְשָׁמָה׃}
}
{
	\eX{
		And all the spoil of these cities, and the cattle, the children
		of Israel took for a prey to themselves; but every man they
		struck by the mouth of the sword, until they had destroyed them,
		neither left they any to breathe.
	}
}
{
}

\Verse{15}
{
	\hX{כַּאֲשֶׁר צִוָּה יְהֹוָה אֶת־מֹשֶׁה עַבְדּוֹ כֵּן־צִוָּה מֹשֶׁה אֶת־יְהוֹשֻׁעַ וְכֵן עָשָׂה יְהוֹשֻׁעַ לֹא־הֵסִיר דָּבָר מִכֹּל אֲשֶׁר־צִוָּה יְהֹוָה אֶת־מֹשֶׁה׃}
}
{
	\eX{
		As YHWH commanded Moses his servant, so did Moses command
		Joshua, and so did Joshua; he left nothing undone of all that
		YHWH commanded Moses.
	}
}
{
}

\Verse{16}
{
	\hX{וַיִּקַּח יְהוֹשֻׁעַ אֶת־כּל־הָאָרֶץ הַזֹּאת הָהָר וְאֶת־כּל־הַנֶּגֶב וְאֵת כּל־אֶרֶץ הַגֹּשֶׁן וְאֶת־הַשְּׁפֵלָה וְאֶת־הָעֲרָבָה וְאֶת־הַר יִשְׂרָאֵל וּשְׁפֵלָתֹה׃}
}
{
	\eX{
		And Joshua took all that land, the hills, and all the south
		country, and all the land of Goshen, and the valley, and the
		plain, and the mountain of Israel, and the valley of the same;
	}
}
{
}

\Verse{17}
{
	\hX{מִן־הָהָר הֶחָלָק הָעוֹלֶה שֵׂעִיר וְעַד־בַּעַל גָּד בְּבִקְעַת הַלְּבָנוֹן תַּחַת הַר־חֶרְמוֹן וְאֵת כּל־מַלְכֵיהֶם לָכַד וַיַּכֵּם וַיְמִיתֵם׃}
}
{
	\eX{
		Even from the mount Halak, that goes up to Seir, even to Baalgad
		in the valley of Lebanon under mount Hermon: and all their kings
		he took, and struck them, and struck them.
	}
}
{
}

\Verse{18}
{
	\hX{יָמִים רַבִּים עָשָׂה יְהוֹשֻׁעַ אֶת־כּל־הַמְּלָכִים הָאֵלֶּה מִלְחָמָה׃}
}
{
	\eX{Joshua made war a long time with all those kings.}
}
{
}

\Verse{19}
{
	\hX{לֹא־הָיְתָה עִיר אֲשֶׁר הִשְׁלִימָה אֶל־בְּנֵי יִשְׂרָאֵל בִּלְתִּי הַחִוִּי יֹשְׁבֵי גִבְעוֹן אֶת־הַכֹּל לָקְחוּ בַמִּלְחָמָה׃}
}
{
	\eX{
		There was not a city that made peace with the children of
		Israel, except the Hivites the inhabitants of Gibeon: all other
		they took in battle.
	}
}
{
}

\Verse{20}
{
	\hX{
		כִּי מֵאֵת יְהֹוָה הָיְתָה לְחַזֵּק אֶת־לִבָּם לִקְרַאת הַמִּלְחָמָה אֶת־יִשְׂרָאֵל לְמַעַן הַחֲרִימָם לְבִלְתִּי הֱיוֹת־לָהֶם תְּחִנָּה כִּי לְמַעַן הַשְׁמִידָם כַּאֲשֶׁר צִוָּה
		יְהֹוָה אֶת־מֹשֶׁה׃
	}
}
{
	\eX{
		For it was of YHWH to harden their hearts, that they should come
		against Israel in battle, that he might destroy them utterly,
		and that they might have no favour, but that he might destroy
		them, as YHWH commanded Moses.
	}
}
{
}

\Verse{21}
{
	\hX{
		וַיָּבֹא יְהוֹשֻׁעַ בָּעֵת הַהִיא וַיַּכְרֵת אֶת־הָעֲנָקִים מִן־הָהָר מִן־חֶבְרוֹן מִן־דְּבִר מִן־עֲנָב וּמִכֹּל הַר יְהוּדָה וּמִכֹּל הַר יִשְׂרָאֵל עִם־עָרֵיהֶם הֶחֱרִימָם
		יְהוֹשֻׁעַ׃
	}
}
{
	\eX{
		And at that time came Joshua, and cut off the Anakims from the
		mountains, from Hebron, from Debir, from Anab, and from all the
		mountains of Judah, and from all the mountains of Israel: Joshua
		destroyed them utterly with their cities.
	}
}
{
}

\Verse{22}
{
	\hX{לֹא־נוֹתַר עֲנָקִים בְּאֶרֶץ בְּנֵי יִשְׂרָאֵל רַק בְּעַזָּה בְּגַת וּבְאַשְׁדּוֹד נִשְׁאָרוּ׃}
}
{
	\eX{
		There was none of the Anakims left in the land of the children
		of Israel: only in Gaza, in Gath, and in Ashdod, there remained.
	}
}
{
}

\Verse{23}
{
	\hX{
		וַיִּקַּח יְהוֹשֻׁעַ אֶת־כּל־הָאָרֶץ כְּכֹל אֲשֶׁר דִּבֶּר יְהֹוָה אֶל־מֹשֶׁה וַיִּתְּנָהּ יְהוֹשֻׁעַ לְנַחֲלָה לְיִשְׂרָאֵל כְּמַחְלְקֹתָם לְשִׁבְטֵיהֶם וְהָאָרֶץ שָׁקְטָה
		מִמִּלְחָמָה׃
	}
}
{
	\eX{
		And Joshua took the whole land, according to all that YHWH said
		to Moses; and Joshua gave it for an inheritance to Israel
		according to their divisions by their tribes. And the land
		rested from war.
	}
}
{
}
