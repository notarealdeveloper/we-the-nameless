\Chapter{11}

\Verse{1}
{
	\hJ{וַיְהִי כִּשְׁמֹעַ יָבִין מֶלֶךְ־חָצוֹר וַיִּשְׁלַח אֶל־יוֹבָב מֶלֶךְ מָדוֹן וְאֶל־מֶלֶךְ שִׁמְרוֹן וְאֶל־מֶלֶךְ אַכְשָׁף׃}
}
{
	\eJ{
		When the news reached King Jabin of Hazor, he sent messages to
		King Jobab of Madon, to the king of Shimron, to the king of
		Achshaph,
	}
}
{
}

\Verse{2}
{
	\hJ{וְאֶל־הַמְּלָכִים אֲשֶׁר מִצְּפוֹן בָּהָר וּבָעֲרָבָה נֶגֶב כִּנְרוֹת וּבַשְּׁפֵלָה וּבְנָפוֹת דּוֹר מִיָּם׃}
}
{
	\eJ{
		and to the other kings in the north—in the hill country, in the
		Arabah south of Chinnereth, in the lowlands, and in the district
		of Dor on the west;
	}
}
{
}

\Verse{3}
{
	\hJ{הַכְּנַעֲנִי מִמִּזְרָח וּמִיָּם וְהָאֱמֹרִי וְהַחִתִּי וְהַפְּרִזִּי וְהַיְבוּסִי בָּהָר וְהַחִוִּי תַּחַת חֶרְמוֹן בְּאֶרֶץ הַמִּצְפָּה׃}
}
{
	\eJ{
		to the Canaanites in the east and in the west; to the Amorites,
		Hittites, Perizzites, and Jebusites in the hill country; and to
		the Hivites at the foot of Hermon, in the land of Mizpah.
	}
}
{
}

\Verse{4}
{
	\hJ{וַיֵּצְאוּ הֵם וְכל־מַחֲנֵיהֶם עִמָּם עַם־רָב כַּחוֹל אֲשֶׁר עַל־שְׂפַת־הַיָּם לָרֹב וְסוּס וָרֶכֶב רַב־מְאֹד׃}
}
{
	\eJ{
		They took the field with all their armies—an enormous host, as
		numerous as the sands on the seashore—and a vast multitude of
		horses and chariots.
	}
}
{
}

\Verse{5}
{
	\hJ{וַיִּוָּעֲדוּ כֹּל הַמְּלָכִים הָאֵלֶּה וַיָּבֹאוּ וַיַּחֲנוּ יַחְדָּו אֶל־מֵי מֵרוֹם לְהִלָּחֵם עִם־יִשְׂרָאֵל׃}
}
{
	\eJ{
		All these kings joined forces; they came and encamped together at
		the Waters of Merom to give battle to Israel.
	}
}
{
}

\Verse{6}
{
	\hJ{
		וַיֹּאמֶר יְהֹוָה אֶל־יְהוֹשֻׁעַ אַל־תִּירָא מִפְּנֵיהֶם כִּי־מָחָר כָּעֵת הַזֹּאת אָנֹכִי נֹתֵן אֶת־כֻּלָּם חֲלָלִים לִפְנֵי יִשְׂרָאֵל אֶת־סוּסֵיהֶם תְּעַקֵּר
		וְאֶת־מַרְכְּבֹתֵיהֶם תִּשְׂרֹף בָּאֵשׁ׃
	}
}
{
	\eJ{
		But YHWH said to Joshua, “Do not be afraid of them; tomorrow at
		this time I will have them all lying slain before Israel. You
		shall hamstring their horses and burn their chariots.”
	}
}
{
}

\Verse{7}
{
	\hJ{וַיָּבֹא יְהוֹשֻׁעַ וְכל־עַם הַמִּלְחָמָה עִמּוֹ עֲלֵיהֶם עַל־מֵי מֵרוֹם פִּתְאֹם וַיִּפְּלוּ בָּהֶם׃}
}
{
	\eJ{
		So Joshua, with all his fighting men, came upon them suddenly at
		the Waters of Merom, and pounced upon them.
	}
}
{
}

\Verse{8}
{
	\hJ{
		וַיִּתְּנֵם יְהֹוָה בְּיַד־יִשְׂרָאֵל וַיַּכּוּם וַיִּרְדְּפוּם עַד־צִידוֹן רַבָּה וְעַד מִשְׂרְפוֹת מַיִם וְעַד־בִּקְעַת מִצְפֶּה מִזְרָחָה וַיַּכֻּם עַד־בִּלְתִּי הִשְׁאִיר־לָהֶם
		שָׂרִיד׃
	}
}
{
	\eJ{
		YHWH delivered them into the hands of Israel, and they defeated
		them and pursued them all the way to Great Sidon and
		Misrephothmaim, and all the way to the Valley of Mizpeh on the
		east; they crushed them, letting none escape.
	}
}
{
}

\Verse{9}
{
	\hJ{וַיַּעַשׂ לָהֶם יְהוֹשֻׁעַ כַּאֲשֶׁר אָמַר־לוֹ יְהֹוָה אֶת־סוּסֵיהֶם עִקֵּר וְאֶת־מַרְכְּבֹתֵיהֶם שָׂרַף בָּאֵשׁ׃}
}
{
	\eJ{
		And Joshua dealt with them as YHWH had ordered him; he hamstrung
		their horses and burned their chariots.
	}
}
{
}

\Verse{10}
{
	\hJ{וַיָּשׁב יְהוֹשֻׁעַ בָּעֵת הַהִיא וַיִּלְכֹּד אֶת־חָצוֹר וְאֶת־מַלְכָּהּ הִכָּה בֶחָרֶב כִּי־חָצוֹר לְפָנִים הִיא רֹאשׁ כּל־הַמַּמְלָכוֹת הָאֵלֶּה׃}
}
{
	\eJ{
		Joshua then turned back and captured Hazor and put her king to the
		sword.—Hazor was formerly the head of all those kingdoms.—
	}
}
{
}

\Verse{11}
{
	\hJ{וַיַּכּוּ אֶת־כּל־הַנֶּפֶשׁ אֲשֶׁר־בָּהּ לְפִי־חֶרֶב הַחֲרֵם לֹא נוֹתַר כּל־נְשָׁמָה וְאֶת־חָצוֹר שָׂרַף בָּאֵשׁ׃}
}
{
	\eJ{
		They proscribed and put to the sword every person in it. Not a
		soul survived, and Hazor itself was burned down.
	}
}
{
}

\Verse{12}
{
	\hJ{וְאֶת־כּל־עָרֵי הַמְּלָכִים־הָאֵלֶּה וְאֶת־כּל־מַלְכֵיהֶם לָכַד יְהוֹשֻׁעַ וַיַּכֵּם לְפִי־חֶרֶב הֶחֱרִים אוֹתָם כַּאֲשֶׁר צִוָּה מֹשֶׁה עֶבֶד יְהֹוָה׃}
}
{
	\eJ{
		Joshua captured all those royal cities and their kings. He put
		them to the sword; he proscribed them in accordance with the
		charge of Moses, the servant of YHWH.
	}
}
{
}

\Verse{13}
{
	\hJ{רַק כּל־הֶעָרִים הָעֹמְדוֹת עַל־תִּלָּם לֹא שְׂרָפָם יִשְׂרָאֵל זוּלָתִי אֶת־חָצוֹר לְבַדָּהּ שָׂרַף יְהוֹשֻׁעַ׃}
}
{
	\eJ{
		However, all those towns that are still standing on their mounds
		were not burned down by Israel; it was Hazor alone that Joshua
		burned down.
	}
}
{
}

\Verse{14}
{
	\hJ{וְכֹל שְׁלַל הֶעָרִים הָאֵלֶּה וְהַבְּהֵמָה בָּזְזוּ לָהֶם בְּנֵי יִשְׂרָאֵל רַק אֶת־כּל־הָאָדָם הִכּוּ לְפִי־חֶרֶב עַד־הִשְׁמִדָם אוֹתָם לֹא הִשְׁאִירוּ כּל־נְשָׁמָה׃}
}
{
	\eJ{
		The Israelites kept all the spoil and cattle of the rest of those
		cities as booty. But they cut down their populations with the
		sword until they exterminated them; they did not spare a soul.
	}
}
{
}

\Verse{15}
{
	\hJ{כַּאֲשֶׁר צִוָּה יְהֹוָה אֶת־מֹשֶׁה עַבְדּוֹ כֵּן־צִוָּה מֹשֶׁה אֶת־יְהוֹשֻׁעַ וְכֵן עָשָׂה יְהוֹשֻׁעַ לֹא־הֵסִיר דָּבָר מִכֹּל אֲשֶׁר־צִוָּה יְהֹוָה אֶת־מֹשֶׁה׃}
}
{
	\eJ{
		Just as YHWH had commanded His servant Moses, so Moses had charged
		Joshua, and so Joshua did; he left nothing undone of all that YHWH
		had commanded Moses.
	}
}
{
}

\Verse{16}
{
	\hJ{וַיִּקַּח יְהוֹשֻׁעַ אֶת־כּל־הָאָרֶץ הַזֹּאת הָהָר וְאֶת־כּל־הַנֶּגֶב וְאֵת כּל־אֶרֶץ הַגֹּשֶׁן וְאֶת־הַשְּׁפֵלָה וְאֶת־הָעֲרָבָה וְאֶת־הַר יִשְׂרָאֵל וּשְׁפֵלָתֹה׃}
}
{
	\eJ{
		Joshua conquered the whole of this region: the hill country [of
		Judah], the Negeb, the whole land of Goshen, the Shephelah, the
		Arabah, and the hill country and coastal plain of Israel—
	}
}
{
}

\Verse{17}
{
	\hJ{מִן־הָהָר הֶחָלָק הָעוֹלֶה שֵׂעִיר וְעַד־בַּעַל גָּד בְּבִקְעַת הַלְּבָנוֹן תַּחַת הַר־חֶרְמוֹן וְאֵת כּל־מַלְכֵיהֶם לָכַד וַיַּכֵּם וַיְמִיתֵם׃}
}
{
	\eJ{
		[everything] from Mount Halak, which ascends to Seir, all the way
		to Baal-gad in the Valley of the Lebanon at the foot of Mount
		Hermon; and he captured all the kings there and executed them.
	}
}
{
}

\Verse{18}
{
	\hJ{יָמִים רַבִּים עָשָׂה יְהוֹשֻׁעַ אֶת־כּל־הַמְּלָכִים הָאֵלֶּה מִלְחָמָה׃}
}
{
	\eJ{Joshua waged war with all those kings over a long period.}
}
{
}

\Verse{19}
{
	\hJ{לֹא־הָיְתָה עִיר אֲשֶׁר הִשְׁלִימָה אֶל־בְּנֵי יִשְׂרָאֵל בִּלְתִּי הַחִוִּי יֹשְׁבֵי גִבְעוֹן אֶת־הַכֹּל לָקְחוּ בַמִּלְחָמָה׃}
}
{
	\eJ{
		Apart from the Hivites who dwelt in Gibeon, not a single city made
		terms with the Israelites; all were taken in battle.
	}
}
{
}

\Verse{20}
{
	\hJ{
		כִּי מֵאֵת יְהֹוָה הָיְתָה לְחַזֵּק אֶת־לִבָּם לִקְרַאת הַמִּלְחָמָה אֶת־יִשְׂרָאֵל לְמַעַן הַחֲרִימָם לְבִלְתִּי הֱיוֹת־לָהֶם תְּחִנָּה כִּי לְמַעַן הַשְׁמִידָם כַּאֲשֶׁר צִוָּה
		יְהֹוָה אֶת־מֹשֶׁה׃
	}
}
{
	\eJ{
		For it was YHWH’s doing to stiffen their hearts to give battle to
		Israel, in order that they might be proscribed without quarter and
		wiped out, as YHWH had commanded Moses.
	}
}
{
}

\Verse{21}
{
	\hJ{
		וַיָּבֹא יְהוֹשֻׁעַ בָּעֵת הַהִיא וַיַּכְרֵת אֶת־הָעֲנָקִים מִן־הָהָר מִן־חֶבְרוֹן מִן־דְּבִר מִן־עֲנָב וּמִכֹּל הַר יְהוּדָה וּמִכֹּל הַר יִשְׂרָאֵל עִם־עָרֵיהֶם הֶחֱרִימָם
		יְהוֹשֻׁעַ׃
	}
}
{
	\eJ{
		At that time, Joshua went and wiped out the Anakites from the hill
		country, from Hebron, Debir, and Anab, from the entire hill
		country of Judah, and from the entire hill country of Israel;
		Joshua proscribed them and their towns.
	}
}
{
}

\Verse{22}
{
	\hJ{לֹא־נוֹתַר עֲנָקִים בְּאֶרֶץ בְּנֵי יִשְׂרָאֵל רַק בְּעַזָּה בְּגַת וּבְאַשְׁדּוֹד נִשְׁאָרוּ׃}
}
{
	\eJ{
		No Anakites remained in the land of the Israelites; but some
		remained in Gaza, Gath, and Ashdod.
	}
}
{
}

\Verse{23}
{
	\hJ{
		וַיִּקַּח יְהוֹשֻׁעַ אֶת־כּל־הָאָרֶץ כְּכֹל אֲשֶׁר דִּבֶּר יְהֹוָה אֶל־מֹשֶׁה וַיִּתְּנָהּ יְהוֹשֻׁעַ לְנַחֲלָה לְיִשְׂרָאֵל כְּמַחְלְקֹתָם לְשִׁבְטֵיהֶם וְהָאָרֶץ שָׁקְטָה
		מִמִּלְחָמָה׃
	}
}
{
	\eJ{
		Thus Joshua conquered the whole country, just as YHWH had promised
		Moses; and Joshua assigned it to Israel to share according to
		their tribal divisions. And the land had rest from war.
	}
}
{
