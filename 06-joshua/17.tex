\Chapter{17}

\Verse{1}
{
	\hP{וַיְהִי הַגּוֹרָל לְמַטֵּה מְנַשֶּׁה כִּי־הוּא בְּכוֹר יוֹסֵף לְמָכִיר בְּכוֹר מְנַשֶּׁה אֲבִי הַגִּלְעָד כִּי הוּא הָיָה אִישׁ מִלְחָמָה וַיְהִי־לוֹ הַגִּלְעָד וְהַבָּשָׁן׃}
}
{
	\eP{
		There was also a lot for the tribe of Manasseh; for he was the
		firstborn of Joseph; to wit, for Machir the firstborn of
		Manasseh, the father of Gilead: because he was a man of war,
		therefore he had Gilead and Bashan.
	}
}
{
}

\Verse{2}
{
	\hP{
		וַיְהִי לִבְנֵי מְנַשֶּׁה הַנּוֹתָרִים לְמִשְׁפְּחֹתָם לִבְנֵי אֲבִיעֶזֶר וְלִבְנֵי־חֵלֶק וְלִבְנֵי אַשְׂרִיאֵל וְלִבְנֵי־שֶׁכֶם וְלִבְנֵי־חֵפֶר וְלִבְנֵי שְׁמִידָע אֵלֶּה בְּנֵי
		מְנַשֶּׁה בֶן־יוֹסֵף הַזְּכָרִים לְמִשְׁפְּחֹתָם׃
	}
}
{
	\eP{
		There was also a lot for the rest of the children of Manasseh by
		their families; for the children of Abiezer, and for the
		children of Helek, and for the children of Asriel, and for the
		children of Shechem, and for the children of Hepher, and for the
		children of Shemida: these were the male children of Manasseh
		the son of Joseph by their families.
	}
}
{
}

\Verse{3}
{
	\hP{וְלִצְלפְחָד בֶּן־חֵפֶר בֶּן־גִּלְעָד בֶּן־מָכִיר בֶּן־מְנַשֶּׁה לֹא־הָיוּ לוֹ בָּנִים כִּי אִם־בָּנוֹת וְאֵלֶּה שְׁמוֹת בְּנֹתָיו מַחְלָה וְנֹעָה חגְלָה מִלְכָּה וְתִרְצָה׃}
}
{
	\eP{
		But Zelophehad, the son of Hepher, the son of Gilead, the son of
		Machir, the son of Manasseh, had no sons, but daughters: and
		these are the names of his daughters, Mahlah, and Noah, Hoglah,
		Milcah, and Tirzah.
	}
}
{
}

\Verse{4}
{
	\hP{
		וַתִּקְרַבְנָה לִפְנֵי אֶלְעָזָר הַכֹּהֵן וְלִפְנֵי יְהוֹשֻׁעַ בִּן־נוּן וְלִפְנֵי הַנְּשִׂיאִים לֵאמֹר יְהֹוָה צִוָּה אֶת־מֹשֶׁה לָתֶת־לָנוּ נַחֲלָה בְּתוֹךְ אַחֵינוּ וַיִּתֵּן
		לָהֶם אֶל־פִּי יְהֹוָה נַחֲלָה בְּתוֹךְ אֲחֵי אֲבִיהֶן׃
	}
}
{
	\eP{
		And they came near before Eleazar the priest, and before Joshua
		the son of Nun, and before the chieftains, saying, YHWH
		commanded Moses to give us an inheritance among our brothers.
		Therefore according to the commandment of YHWH He gave them an
		inheritance among the brothers of their father.
	}
}
{
}

\Verse{5}
{
	\hP{וַיִּפְּלוּ חַבְלֵי־מְנַשֶּׁה עֲשָׂרָה לְבַד מֵאֶרֶץ הַגִּלְעָד וְהַבָּשָׁן אֲשֶׁר מֵעֵבֶר לַיַּרְדֵּן׃}
}
{
	\eP{
		And there fell ten portions to Manasseh, beside the land of
		Gilead and Bashan, that were across the Jordan;
	}
}
{
}

\Verse{6}
{
	\hP{כִּי בְּנוֹת מְנַשֶּׁה נָחֲלוּ נַחֲלָה בְּתוֹךְ בָּנָיו וְאֶרֶץ הַגִּלְעָד הָיְתָה לִבְנֵי־מְנַשֶּׁה הַנּוֹתָרִים׃}
}
{
	\eP{
		Because the daughters of Manasseh had an inheritance among his
		sons: and the rest of Manasseh’s sons had the land of Gilead.
	}
}
{
}

\Verse{7}
{
	\hP{וַיְהִי גְבוּל־מְנַשֶּׁה מֵאָשֵׁר הַמִּכְמְתָת אֲשֶׁר עַל־פְּנֵי שְׁכֶם וְהָלַךְ הַגְּבוּל אֶל־הַיָּמִין אֶל־יֹשְׁבֵי עֵין תַּפּוּחַ׃}
}
{
	\eP{
		And the border of Manasseh was from Asher to Michmethah, that
		lies before Shechem; and the border went along on the right hand
		to the inhabitants of Entappuah.
	}
}
{
}

\Verse{8}
{
	\hP{לִמְנַשֶּׁה הָיְתָה אֶרֶץ תַּפּוּחַ וְתַפּוּחַ אֶל־גְּבוּל מְנַשֶּׁה לִבְנֵי אֶפְרָיִם׃}
}
{
	\eP{
		Now Manasseh had the land of Tappuah: but Tappuah on the border
		of Manasseh belonged to the children of Ephraim;
	}
}
{
}

\Verse{9}
{
	\hP{וְיָרַד הַגְּבוּל נַחַל קָנָה נֶגְבָּה לַנַּחַל עָרִים הָאֵלֶּה לְאֶפְרַיִם בְּתוֹךְ עָרֵי מְנַשֶּׁה וּגְבוּל מְנַשֶּׁה מִצְּפוֹן לַנַּחַל וַיְהִי תֹצְאֹתָיו הַיָּמָּה׃}
}
{
	\eP{
		And the border descended to the river Kanah, southward of the
		river: these cities of Ephraim are among the cities of Manasseh:
		the border of Manasseh also was on the north side of the river,
		and the limits of it were at the sea:
	}
}
{
}

\Verse{10}
{
	\hP{נֶגְבָּה לְאֶפְרַיִם וְצָפוֹנָה לִמְנַשֶּׁה וַיְהִי הַיָּם גְּבוּלוֹ וּבְאָשֵׁר יִפְגְּעוּן מִצָּפוֹן וּבְיִשָּׂשכָר מִמִּזְרָח׃}
}
{
	\eP{
		Southward it was Ephraim’s, and northward it was Manasseh’s, and
		the sea is his border; and they met together in Asher on the
		north, and in Issachar on the east.
	}
}
{
}

\Verse{11}
{
	\hP{
		וַיְהִי לִמְנַשֶּׁה בְּיִשָּׂשכָר וּבְאָשֵׁר בֵּית־שְׁאָן וּבְנוֹתֶיהָ וְיִבְלְעָם וּבְנוֹתֶיהָ וְאֶת־יֹשְׁבֵי דֹאר וּבְנוֹתֶיהָ וְיֹשְׁבֵי עֵין־דֹּר וּבְנוֹתֶיהָ וְיֹשְׁבֵי
		תַעְנַךְ וּבְנֹתֶיהָ וְיֹשְׁבֵי מְגִדּוֹ וּבְנוֹתֶיהָ שְׁלֹשֶׁת הַנָּפֶת׃
	}
}
{
	\eP{
		And Manasseh had in Issachar and in Asher Bethshean and her
		towns, and Ibleam and her towns, and the inhabitants of Dor and
		her towns, and the inhabitants of Endor and her towns, and the
		inhabitants of Taanach and her towns, and the inhabitants of
		Megiddo and her towns, even three countries.
	}
}
{
}

\Verse{12}
{
	\hP{וְלֹא יָכְלוּ בְּנֵי מְנַשֶּׁה לְהוֹרִישׁ אֶת־הֶעָרִים הָאֵלֶּה וַיּוֹאֶל הַכְּנַעֲנִי לָשֶׁבֶת בָּאָרֶץ הַזֹּאת׃}
}
{
	\eP{
		Yet the children of Manasseh could not drive out the inhabitants
		of those cities; but the Canaanites would live in that land.
	}
}
{
}

\Verse{13}
{
	\hP{וַיְהִי כִּי חָזְקוּ בְּנֵי יִשְׂרָאֵל וַיִּתְּנוּ אֶת־הַכְּנַעֲנִי לָמַס וְהוֹרֵשׁ לֹא הוֹרִישׁוֹ׃}
}
{
	\eP{
		Yet it was, when the children of Israel were grown strong, that
		they put the Canaanites to tribute, but did not utterly drive
		them out.
	}
}
{
}

\Verse{14}
{
	\hP{וַיְדַבְּרוּ בְּנֵי יוֹסֵף אֶת־יְהוֹשֻׁעַ לֵאמֹר מַדּוּעַ נָתַתָּה לִּי נַחֲלָה גּוֹרָל אֶחָד וְחֶבֶל אֶחָד וַאֲנִי עַם־רָב עַד אֲשֶׁר־עַד־כֹּה בֵּרְכַנִי יְהֹוָה׃}
}
{
	\eP{
		And the children of Joseph spoke to Joshua, saying, Why have you
		given me but one lot and one portion to inherit, seeing I am a
		great people, forasmuch as YHWH has blessed me hitherto?
	}
}
{
}

\Verse{15}
{
	\hP{וַיֹּאמֶר אֲלֵיהֶם יְהוֹשֻׁעַ אִם־עַם־רַב אַתָּה עֲלֵה לְךָ הַיַּעְרָה וּבֵרֵאתָ לְךָ שָׁם בְּאֶרֶץ הַפְּרִזִּי וְהָרְפָאִים כִּי־אָץ לְךָ הַר־אֶפְרָיִם׃}
}
{
	\eP{
		And Joshua answered them, If you are a great people, then get
		you up to the wood country, and cut down for thyself there in
		the land of the Perizzites and of the giants, if mount Ephraim
		be too narrow for you.
	}
}
{
}

\Verse{16}
{
	\hP{
		וַיֹּאמְרוּ בְּנֵי יוֹסֵף לֹא־יִמָּצֵא לָנוּ הָהָר וְרֶכֶב בַּרְזֶל בְּכל־הַכְּנַעֲנִי הַיֹּשֵׁב בְּאֶרֶץ־הָעֵמֶק לַאֲשֶׁר בְּבֵית־שְׁאָן וּבְנוֹתֶיהָ וְלַאֲשֶׁר בְּעֵמֶק
		יִזְרְעֶאל׃
	}
}
{
	\eP{
		And the children of Joseph said, The hill is not enough for us:
		and all the Canaanites who live in the land of the valley have
		chariots of iron, both they who are of Bethshean and her towns,
		and they who are of the valley of Jezreel.
	}
}
{
}

\Verse{17}
{
	\hP{וַיֹּאמֶר יְהוֹשֻׁעַ אֶל־בֵּית יוֹסֵף לְאֶפְרַיִם וְלִמְנַשֶּׁה לֵאמֹר עַם־רַב אַתָּה וְכֹחַ גָּדוֹל לָךְ לֹא־יִהְיֶה לְךָ גּוֹרָל אֶחָד׃}
}
{
	\eP{
		And Joshua spoke to the house of Joseph, even to Ephraim and to
		Manasseh, saying, You are a great people, and have great power:
		you won't have one lot only:
	}
}
{
}

\Verse{18}
{
	\hP{כִּי הַר יִהְיֶה־לָּךְ כִּי־יַעַר הוּא וּבֵרֵאתוֹ וְהָיָה לְךָ תֹּצְאֹתָיו כִּי־תוֹרִישׁ אֶת־הַכְּנַעֲנִי כִּי רֶכֶב בַּרְזֶל לוֹ כִּי חָזָק הוּא׃}
}
{
	\eP{
		But the mountain shall be yours; for it is a wood, and you shall
		cut it down: and its limits shall be yourss: for you shall drive
		out the Canaanites, though they have iron chariots, and though
		they are strong.
	}
}
{
}
