\Chapter{16}

\Verse{1}
{
	\hP{וַיֵּצֵא הַגּוֹרָל לִבְנֵי יוֹסֵף מִיַּרְדֵּן יְרִיחוֹ לְמֵי יְרִיחוֹ מִזְרָחָה הַמִּדְבָּר עֹלֶה מִירִיחוֹ בָּהָר בֵּית־אֵל׃}
}
{
	\eP{
		And the lot of the children of Joseph fell from Jordan by
		Jericho, to the water of Jericho on the east, to the wilderness
		that goes up from Jericho throughout mount Bethel,
	}
}
{
}

\Verse{2}
{
	\hP{וְיָצָא מִבֵּית־אֵל לוּזָה וְעָבַר אֶל־גְּבוּל הָאַרְכִּי עֲטָרוֹת׃}
}
{
	\eP{
		And goes out from Bethel to Luz, and passeth along to the
		borders of Archi to Ataroth,
	}
}
{
}

\Verse{3}
{
	\hP{וְיָרַד־יָמָּה אֶל־גְּבוּל הַיַּפְלֵטִי עַד גְּבוּל בֵּית־חוֹרֹן תַּחְתּוֹן וְעַד־גָּזֶר וְהָיוּ תֹצְאֹתָו יָמָּה׃}
}
{
	\eP{
		And goes down westward to the border of Japhleti, to the border
		of Bethhoron the lower, and to Gezer; and the limits of it are
		at the sea.
	}
}
{
}

\Verse{4}
{
	\hP{וַיִּנְחֲלוּ בְנֵי־יוֹסֵף מְנַשֶּׁה וְאֶפְרָיִם׃}
}
{
	\eP{
		And the children of Joseph, Manasseh and Ephraim, took their
		inheritance.
	}
}
{
}

\Verse{5}
{
	\hP{וַיְהִי גְּבוּל בְּנֵי־אֶפְרַיִם לְמִשְׁפְּחֹתָם וַיְהִי גְּבוּל נַחֲלָתָם מִזְרָחָה עַטְרוֹת אַדָּר עַד־בֵּית חוֹרֹן עֶלְיוֹן׃}
}
{
	\eP{
		And the border of the children of Ephraim according to their
		families was thus: even the border of their inheritance on the
		east side was Atarothaddar, to Bethhoron the upper;
	}
}
{
}

\Verse{6}
{
	\hP{וְיָצָא הַגְּבוּל הַיָּמָּה הַמִּכְמְתָת מִצָּפוֹן וְנָסַב הַגְּבוּל מִזְרָחָה תַּאֲנַת שִׁלֹה וְעָבַר אוֹתוֹ מִמִּזְרַח יָנוֹחָה׃}
}
{
	\eP{
		And the border went out toward the sea to Michmethah on the
		north side; and the border went about eastward to Taanathshiloh,
		and passed by it on the east to Janohah;
	}
}
{
}

\Verse{7}
{
	\hP{וְיָרַד מִיָּנוֹחָה עֲטָרוֹת וְנַעֲרָתָה וּפָגַע בִּירִיחוֹ וְיָצָא הַיַּרְדֵּן׃}
}
{
	\eP{
		And it went down from Janohah to Ataroth, and to Naarath, and
		came to Jericho, and went out at Jordan.
	}
}
{
}

\Verse{8}
{
	\hP{מִתַּפּוּחַ יֵלֵךְ הַגְּבוּל יָמָּה נַחַל קָנָה וְהָיוּ תֹצְאֹתָיו הַיָּמָּה זֹאת נַחֲלַת מַטֵּה בְנֵי־אֶפְרַיִם לְמִשְׁפְּחֹתָם׃}
}
{
	\eP{
		The border went out from Tappuah westward to the river Kanah;
		and the limits of it were at the sea. This is the inheritance of
		the tribe of the children of Ephraim by their families.
	}
}
{
}

\Verse{9}
{
	\hP{וְהֶעָרִים הַמִּבְדָּלוֹת לִבְנֵי אֶפְרַיִם בְּתוֹךְ נַחֲלַת בְּנֵי־מְנַשֶּׁה כּל־הֶעָרִים וְחַצְרֵיהֶן׃}
}
{
	\eP{
		And the separate cities for the children of Ephraim were among
		the inheritance of the children of Manasseh, all the cities with
		their villages.
	}
}
{
}

\Verse{10}
{
	\hP{וְלֹא הוֹרִישׁוּ אֶת־הַכְּנַעֲנִי הַיּוֹשֵׁב בְּגָזֶר וַיֵּשֶׁב הַכְּנַעֲנִי בְּקֶרֶב אֶפְרַיִם עַד־הַיּוֹם הַזֶּה וַיְהִי לְמַס־עֹבֵד׃}
}
{
	\eP{
		And they drove not out the Canaanites who lived in Gezer: but
		the Canaanites live among the Ephraimites to this day, and serve
		under tribute.
	}
}
{
}
