\Chapter{14}

\Verse{1}
{
	\hP{וְאֵלֶּה אֲשֶׁר־נָחֲלוּ בְנֵי־יִשְׂרָאֵל בְּאֶרֶץ כְּנָעַן אֲשֶׁר נִחֲלוּ אוֹתָם אֶלְעָזָר הַכֹּהֵן וִיהוֹשֻׁעַ בִּן־נוּן וְרָאשֵׁי אֲבוֹת הַמַּטּוֹת לִבְנֵי יִשְׂרָאֵל׃}
}
{
	\eP{
		And these are the countries that the children of Israel
		inherited in the land of Canaan, that Eleazar the priest, and
		Joshua the son of Nun, and the heads of the fathers of the
		tribes of the children of Israel, distributed for inheritance to
		them.
	}
}
{
}

\Verse{2}
{
	\hP{בְּגוֹרַל נַחֲלָתָם כַּאֲשֶׁר צִוָּה יְהֹוָה בְּיַד־מֹשֶׁה לְתִשְׁעַת הַמַּטּוֹת וַחֲצִי הַמַּטֶּה׃}
}
{
	\eP{
		By lot was their inheritance, as YHWH commanded by the hand of
		Moses, for the nine tribes, and for the half tribe.
	}
}
{
}

\Verse{3}
{
	\hP{כִּי־נָתַן מֹשֶׁה נַחֲלַת שְׁנֵי הַמַּטּוֹת וַחֲצִי הַמַּטֶּה מֵעֵבֶר לַיַּרְדֵּן וְלַלְוִיִּם לֹא־נָתַן נַחֲלָה בְּתוֹכָם׃}
}
{
	\eP{
		For Moses had given the inheritance of two tribes and an half
		tribe across the Jordan: but to the Levites he gave none
		inheritance among them.
	}
}
{
}

\Verse{4}
{
	\hP{כִּי־הָיוּ בְנֵי־יוֹסֵף שְׁנֵי מַטּוֹת מְנַשֶּׁה וְאֶפְרָיִם וְלֹא־נָתְנוּ חֵלֶק לַלְוִיִּם בָּאָרֶץ כִּי אִם־עָרִים לָשֶׁבֶת וּמִגְרְשֵׁיהֶם לְמִקְנֵיהֶם וּלְקִנְיָנָם׃}
}
{
	\eP{
		For the children of Joseph were two tribes, Manasseh and
		Ephraim: therefore they gave no part to the Levites in the land,
		except cities to live in, with their pasture lands for their
		cattle and for their substance.
	}
}
{
}

\Verse{5}
{
	\hP{כַּאֲשֶׁר צִוָּה יְהֹוָה אֶת־מֹשֶׁה כֵּן עָשׂוּ בְּנֵי יִשְׂרָאֵל וַיַּחְלְקוּ אֶת־הָאָרֶץ׃}
}
{
	\eP{
		As YHWH commanded Moses, so the children of Israel did, and they
		divided the land.
	}
}
{
}

\Verse{6}
{
	\hX{
		וַיִּגְּשׁוּ בְנֵי־יְהוּדָה אֶל־יְהוֹשֻׁעַ בַּגִּלְגָּל וַיֹּאמֶר אֵלָיו כָּלֵב בֶּן־יְפֻנֶּה הַקְּנִזִּי אַתָּה יָדַעְתָּ אֶת־הַדָּבָר אֲשֶׁר־דִּבֶּר יְהֹוָה אֶל־מֹשֶׁה
		אִישׁ־הָאֱלֹהִים עַל אֹדוֹתַי וְעַל אֹדוֹתֶיךָ בְּקָדֵשׁ בַּרְנֵעַ׃
	}
}
{
	\eX{
		And the children of Judah came to Joshua in Gilgal: and Caleb
		the son of Jephunneh the Kenezite said to him, You knowest the
		thing that YHWH said to Moses the man of God concerning me and
		you in Kadeshbarnea.
	}
}
{
}

\Verse{7}
{
	\hX{בֶּן־אַרְבָּעִים שָׁנָה אָנֹכִי בִּשְׁלֹחַ מֹשֶׁה עֶבֶד־יְהֹוָה אֹתִי מִקָּדֵשׁ בַּרְנֵעַ לְרַגֵּל אֶת־הָאָרֶץ וָאָשֵׁב אֹתוֹ דָּבָר כַּאֲשֶׁר עִם־לְבָבִי׃}
}
{
	\eX{
		Forty years old was I when Moses the servant of YHWH sent me
		from Kadeshbarnea to espy out the land; and I brought him word
		again as it was in mine heart.
	}
}
{
}

\Verse{8}
{
	\hX{וְאַחַי אֲשֶׁר עָלוּ עִמִּי הִמְסִיו אֶת־לֵב הָעָם וְאָנֹכִי מִלֵּאתִי אַחֲרֵי יְהֹוָה אֱלֹהָי׃}
}
{
	\eX{
		Nevertheless my brothers that went up with me made the heart of
		the people melt: but I wholly followed YHWH my God.
	}
}
{
}

\Verse{9}
{
	\hX{וַיִּשָּׁבַע מֹשֶׁה בַּיּוֹם הַהוּא לֵאמֹר אִם־לֹא הָאָרֶץ אֲשֶׁר דָּרְכָה רַגְלְךָ בָּהּ לְךָ תִהְיֶה לְנַחֲלָה וּלְבָנֶיךָ עַד־עוֹלָם כִּי מִלֵּאתָ אַחֲרֵי יְהֹוָה אֱלֹהָי׃}
}
{
	\eX{
		And Moses swore on that day, saying, Surely the land on that
		your feet have trodden shall be your inheritance, and your
		children’s for ever, because you have wholly followed YHWH my
		God.
	}
}
{
}

\Verse{10}
{
	\hX{
		וְעַתָּה הִנֵּה הֶחֱיָה יְהֹוָה אוֹתִי כַּאֲשֶׁר דִּבֵּר זֶה אַרְבָּעִים וְחָמֵשׁ שָׁנָה מֵאָז דִּבֶּר יְהֹוָה אֶת־הַדָּבָר הַזֶּה אֶל־מֹשֶׁה אֲשֶׁר־הָלַךְ יִשְׂרָאֵל בַּמִּדְבָּר
		וְעַתָּה הִנֵּה אָנֹכִי הַיּוֹם בֶּן־חָמֵשׁ וּשְׁמֹנִים שָׁנָה׃
	}
}
{
	\eX{
		And now, here, YHWH has kept me alive, as he said, these forty
		and five years, even since YHWH spoke this word to Moses, while
		the children of Israel wandered in the wilderness: and now, lo,
		I am this day eighty and five years old.
	}
}
{
}

\Verse{11}
{
	\hX{עוֹדֶנִּי הַיּוֹם חָזָק כַּאֲשֶׁר בְּיוֹם שְׁלֹחַ אוֹתִי מֹשֶׁה כְּכֹחִי אָז וּכְכֹחִי עָתָּה לַמִּלְחָמָה וְלָצֵאת וְלָבוֹא׃}
}
{
	\eX{
		As yet I am as strong this day as I was in the day that Moses
		sent me: as my strength was then, even so is my strength now,
		for war, both to go out, and to come in.
	}
}
{
}

\Verse{12}
{
	\hX{
		וְעַתָּה תְּנָה־לִּי אֶת־הָהָר הַזֶּה אֲשֶׁר־דִּבֶּר יְהֹוָה בַּיּוֹם הַהוּא כִּי אַתָּה־שָׁמַעְתָּ בַיּוֹם הַהוּא כִּי־עֲנָקִים שָׁם וְעָרִים גְּדֹלוֹת בְּצֻרוֹת אוּלַי יְהֹוָה
		אוֹתִי וְהוֹרַשְׁתִּים כַּאֲשֶׁר דִּבֶּר יְהֹוָה׃
	}
}
{
	\eX{
		Now therefore give me this mountain, of that YHWH spoke in that
		day; for you heardest in that day how the Anakims were there,
		and that the cities were great and fortified: if so be YHWH will
		be with me, then I shall be able to drive them out, as YHWH
		said.
	}
}
{
}

\Verse{13}
{
	\hX{וַיְבָרְכֵהוּ יְהוֹשֻׁעַ וַיִּתֵּן אֶת־חֶבְרוֹן לְכָלֵב בֶּן־יְפֻנֶּה לְנַחֲלָה׃}
}
{
	\eX{
		And Joshua blessed him, and gave to Caleb the son of Jephunneh
		Hebron for an inheritance.
	}
}
{
}

\Verse{14}
{
	\hX{עַל־כֵּן הָיְתָה־חֶבְרוֹן לְכָלֵב בֶּן־יְפֻנֶּה הַקְּנִזִּי לְנַחֲלָה עַד הַיּוֹם הַזֶּה יַעַן אֲשֶׁר מִלֵּא אַחֲרֵי יְהֹוָה אֱלֹהֵי יִשְׂרָאֵל׃}
}
{
	\eX{
		Hebron therefore became the inheritance of Caleb the son of
		Jephunneh the Kenezite to this day, because that he wholly
		followed YHWH God of Israel.
	}
}
{
}

\Verse{15}
{
	\hX{וְשֵׁם חֶבְרוֹן לְפָנִים קִרְיַת אַרְבַּע הָאָדָם הַגָּדוֹל בָּעֲנָקִים הוּא וְהָאָרֶץ שָׁקְטָה מִמִּלְחָמָה׃}
}
{
	\eX{
		And the name of Hebron before was Kirjatharba; that Arba was a
		great man among the Anakims. And the land had rest from war.
	}
}
{
}
