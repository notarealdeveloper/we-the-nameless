\Verse{1}

	\eX{

		the hills, and in the valleys, and in all the borders of the

		the Canaanite, the Perizzite, the Hivite, and the Jebusite,
		heard of it;
	}
}
{
}

}

}
{
	\eX{
		They did work with cunning, and went and made as if they had
		been ambassadors, and took old sacks on their asses, and wine

}
{
}

\Verse{5}
{
	\hX{וּנְעָלוֹת בָּלוֹת וּמְטֻלָּאוֹת בְּרַגְלֵיהֶם וּשְׂלָמוֹת בָּלוֹת עֲלֵיהֶם וְכֹל לֶחֶם צֵידָם יָבֵשׁ הָיָה נִקֻּדִים׃}
}
{
	\eX{
		And old shoes and clouted on their feet, and old garments on
		them; and all the bread of their provision was dry and moldy.
	}
}
{
}

\Verse{6}
{
	\hX{וַיֵּלְכוּ אֶל־יְהוֹשֻׁעַ אֶל־הַמַּחֲנֶה הַגִּלְגָּל וַיֹּאמְרוּ אֵלָיו וְאֶל־אִישׁ יִשְׂרָאֵל מֵאֶרֶץ רְחוֹקָה בָּאנוּ וְעַתָּה כִּרְתוּ־לָנוּ בְרִית׃}
}
{
	\eX{
		And they went to Joshua to the camp at Gilgal, and said to him,
		and to the men of Israel, We be come from a far country: now
		therefore make you a league with us.
	}
}
{
}

\Verse{7}

	\hX{(ויאמרו) [וַיֹּאמֶר] אִישׁ־יִשְׂרָאֵל אֶל־הַחִוִּי אוּלַי בְּקִרְבִּי אַתָּה יוֹשֵׁב וְאֵיךְ (אכרות) [אֶכְרת־]לְךָ בְרִית׃}
}
{
	\eX{
		And the men of Israel said to the Hivites, Peradventure you live

	}
}
{
}

\Verse{8}
{
	\hX{וַיֹּאמְרוּ אֶל־יְהוֹשֻׁעַ עֲבָדֶיךָ אֲנָחְנוּ וַיֹּאמֶר אֲלֵיהֶם יְהוֹשֻׁעַ מִי אַתֶּם וּמֵאַיִן תָּבֹאוּ׃}
}
{
	\eX{
		And they said to Joshua, We are your servants. And Joshua said
		to them, Who are you? and from from where come you?
	}
}
{
}

\Verse{9}
{
	\hX{וַיֹּאמְרוּ אֵלָיו מֵאֶרֶץ רְחוֹקָה מְאֹד בָּאוּ עֲבָדֶיךָ לְשֵׁם יְהֹוָה אֱלֹהֶיךָ כִּי־שָׁמַעְנוּ שׁמְעוֹ וְאֵת כּל־אֲשֶׁר עָשָׂה בְּמִצְרָיִם׃}
}
{
	\eX{
		And they said to him, From a very far country your servants are
		come because of the name of YHWH your God: for we have heard the
		fame of him, and all that he did in Egypt,
	}
}
{
}

\Verse{10}
{
	\hX{וְאֵת כּל־אֲשֶׁר עָשָׂה לִשְׁנֵי מַלְכֵי הָאֱמֹרִי אֲשֶׁר בְּעֵבֶר הַיַּרְדֵּן לְסִיחוֹן מֶלֶךְ חֶשְׁבּוֹן וּלְעוֹג מֶלֶךְ־הַבָּשָׁן אֲשֶׁר בְּעַשְׁתָּרוֹת׃}
}
{
	\eX{
		And all that he did to the two kings of the Amorites, that were
		beyond Jordan, to Sihon king of Heshbon, and to Og king of
		Bashan, that was at Ashtaroth.
	}
}
{
}

\Verse{11}
{
	\hX{
		וַיֹּאמְרוּ אֵלֵינוּ זְקֵינֵינוּ וְכל־יֹשְׁבֵי אַרְצֵנוּ לֵאמֹר קְחוּ בְיֶדְכֶם צֵידָה לַדֶּרֶךְ וּלְכוּ לִקְרָאתָם וַאֲמַרְתֶּם אֲלֵיהֶם עַבְדֵיכֶם אֲנַחְנוּ וְעַתָּה
		כִּרְתוּ־לָנוּ בְרִית׃
	}
}
{
	\eX{
		Therefore our elders and all the inhabitants of our country
		spoke to us, saying, Take provisions with you for the journey,
		and go to meet them, and say to them, We are your servants:
		therefore now make you a league with us.
	}
}
{
}

\Verse{12}
{
	\hX{זֶה לַחְמֵנוּ חָם הִצְטַיַּדְנוּ אֹתוֹ מִבָּתֵּינוּ בְּיוֹם צֵאתֵנוּ לָלֶכֶת אֲלֵיכֶם וְעַתָּה הִנֵּה יָבֵשׁ וְהָיָה נִקֻּדִים׃}
}
{
	\eX{

}
{
}

\Verse{13}
{
	\hX{וְאֵלֶּה נֹאדוֹת הַיַּיִן אֲשֶׁר מִלֵּאנוּ חֲדָשִׁים וְהִנֵּה הִתְבַּקָּעוּ וְאֵלֶּה שַׂלְמוֹתֵינוּ וּנְעָלֵינוּ בָּלוּ מֵרֹב הַדֶּרֶךְ מְאֹד׃}
}
{
	\eX{
		And these bottles of wine, that we filled, were new; and, here,
		they be rent: and these our garments and our shoes are become

}
{
}

\Verse{14}
{
	\hX{וַיִּקְחוּ הָאֲנָשִׁים מִצֵּידָם וְאֶת־פִּי יְהֹוָה לֹא שָׁאָלוּ׃}
}
{
	\eX{
		And the men took of their provisions, and asked not counsel at

	}
}
{
}

\Verse{15}

	\hX{וַיַּעַשׂ לָהֶם יְהוֹשֻׁעַ שָׁלוֹם וַיִּכְרֹת לָהֶם בְּרִית לְחַיּוֹתָם וַיִּשָּׁבְעוּ לָהֶם נְשִׂיאֵי הָעֵדָה׃}
}
{
	\eX{

}

\Verse{16}
{
	\hX{וַיְהִי מִקְצֵה שְׁלֹשֶׁת יָמִים אַחֲרֵי אֲשֶׁר־כָּרְתוּ לָהֶם בְּרִית וַיִּשְׁמְעוּ כִּי־קְרֹבִים הֵם אֵלָיו וּבְקִרְבּוֹ הֵם יֹשְׁבִים׃}
}
{
	\eX{
		And it was at the end of three days after they had made a league
		with them, that they heard that they were their neighbours, and

	}
}
{
}

\Verse{17}

	\hX{וַיִּסְעוּ בְנֵי־יִשְׂרָאֵל וַיָּבֹאוּ אֶל־עָרֵיהֶם בַּיּוֹם הַשְּׁלִישִׁי וְעָרֵיהֶם גִּבְעוֹן וְהַכְּפִירָה וּבְאֵרוֹת וְקִרְיַת יְעָרִים׃}
}
{
	\eX{

\Verse{18}

	\hX{וְלֹא הִכּוּם בְּנֵי יִשְׂרָאֵל כִּי־נִשְׁבְּעוּ לָהֶם נְשִׂיאֵי הָעֵדָה בַּיהֹוָה אֱלֹהֵי יִשְׂרָאֵל וַיִּלֹּנוּ כל־הָעֵדָה עַל־הַנְּשִׂיאִים׃}
}
{
	\eX{

}
{
}

	\hX{וַיֹּאמְרוּ כל־הַנְּשִׂיאִים אֶל־כּל־הָעֵדָה אֲנַחְנוּ נִשְׁבַּעְנוּ לָהֶם בַּיהֹוָה אֱלֹהֵי יִשְׂרָאֵל וְעַתָּה לֹא נוּכַל לִנְגֹּעַ בָּהֶם׃}
}
{
	\eX{

}
{
	\eX{

	}
}
{
}

}
{
	\eX{

{
}
