\Chapter{3}

\Verse{1}
{
	\hJ{וַיַּשְׁכֵּם יְהוֹשֻׁעַ בַּבֹּקֶר וַיִּסְעוּ מֵהַשִּׁטִּים וַיָּבֹאוּ עַד־הַיַּרְדֵּן הוּא וְכל־בְּנֵי יִשְׂרָאֵל וַיָּלִנוּ שָׁם טֶרֶם יַעֲבֹרוּ׃}
}
{
	\eJ{
		And Joshua rose early in the morning; and they removed from
		Shittim, and came to Jordan, he and all the children of Israel,
		and lodged there before they passed over.
	}
}
{
}

\Verse{2}
{
	\hJ{וַיְהִי מִקְצֵה שְׁלֹשֶׁת יָמִים וַיַּעַבְרוּ הַשֹּׁטְרִים בְּקֶרֶב הַמַּחֲנֶה׃}
}
{
	\eJ{
		And it was after three days, that the officers went through the
		army;
	}
}
{
}

\Verse{3}
{
	\hJ{וַיְצַוּוּ אֶת־הָעָם לֵאמֹר כִּרְאֹתְכֶם אֵת אֲרוֹן בְּרִית־יְהֹוָה אֱלֹהֵיכֶם וְהַכֹּהֲנִים הַלְוִיִּם נֹשְׂאִים אֹתוֹ וְאַתֶּם תִּסְעוּ מִמְּקוֹמְכֶם וַהֲלַכְתֶּם אַחֲרָיו׃}
}
{
	\eJ{
		And they commanded the people, saying, When you see the ark of
		the covenant of YHWH your God, and the priests the Levites
		bearing it, then you shall remove from your place, and go after
		it.
	}
}
{
}

\Verse{4}
{
	\hJ{
		אַךְ רָחוֹק יִהְיֶה בֵּינֵיכֶם וּבֵנָיו כְּאַלְפַּיִם אַמָּה בַּמִּדָּה אַל־תִּקְרְבוּ אֵלָיו לְמַעַן אֲשֶׁר־תֵּדְעוּ אֶת־הַדֶּרֶךְ אֲשֶׁר תֵּלְכוּ־בָהּ כִּי לֹא עֲבַרְתֶּם
		בַּדֶּרֶךְ מִתְּמוֹל שִׁלְשׁוֹם׃
	}
}
{
	\eJ{
		Yet there shall be a space between you and it, about two
		thousand cubits by measure: don’t come near to it, that you may
		know the way by which you must go: for you have not passed this
		way before.
	}
}
{
}

\Verse{5}
{
	\hJ{וַיֹּאמֶר יְהוֹשֻׁעַ אֶל־הָעָם הִתְקַדָּשׁוּ כִּי מָחָר יַעֲשֶׂה יְהֹוָה בְּקִרְבְּכֶם נִפְלָאוֹת׃}
}
{
	\eJ{
		And Joshua said to the people, Sanctify yourselves: for to next
		day YHWH will do wonders among you.
	}
}
{
}

\Verse{6}
{
	\hJ{וַיֹּאמֶר יְהוֹשֻׁעַ אֶל־הַכֹּהֲנִים לֵאמֹר שְׂאוּ אֶת־אֲרוֹן הַבְּרִית וְעִבְרוּ לִפְנֵי הָעָם וַיִּשְׂאוּ אֶת־אֲרוֹן הַבְּרִית וַיֵּלְכוּ לִפְנֵי הָעָם׃}
}
{
	\eJ{
		And Joshua spoke to the priests, saying, Take up the ark of the
		covenant, and pass over before the people. And they took up the
		ark of the covenant, and went before the people.
	}
}
{
}

\Verse{7}
{
	\hJ{וַיֹּאמֶר יְהֹוָה אֶל־יְהוֹשֻׁעַ הַיּוֹם הַזֶּה אָחֵל גַּדֶּלְךָ בְּעֵינֵי כּל־יִשְׂרָאֵל אֲשֶׁר יֵדְעוּן כִּי כַּאֲשֶׁר הָיִיתִי עִם־מֹשֶׁה אֶהְיֶה עִמָּךְ׃}
}
{
	\eJ{
		And YHWH said to Joshua, This day will I begin to magnify you in
		the eyes of all Israel, that they may know that, as I was with
		Moses, so I'll be with you.
	}
}
{
}

\Verse{8}
{
	\hJ{וְאַתָּה תְּצַוֶּה אֶת־הַכֹּהֲנִים נֹשְׂאֵי אֲרוֹן־הַבְּרִית לֵאמֹר כְּבֹאֲכֶם עַד־קְצֵה מֵי הַיַּרְדֵּן בַּיַּרְדֵּן תַּעֲמֹדוּ׃}
}
{
	\eJ{
		And you shall command the priests that bear the ark of the
		covenant, saying, When you are come to the brink of the water of
		Jordan, you shall stand still in Jordan.
	}
}
{
}

\Verse{9}
{
	\hJ{וַיֹּאמֶר יְהוֹשֻׁעַ אֶל־בְּנֵי יִשְׂרָאֵל גֹּשׁוּ הֵנָּה וְשִׁמְעוּ אֶת־דִּבְרֵי יְהֹוָה אֱלֹהֵיכֶם׃}
}
{
	\eJ{
		And Joshua said to the children of Israel, Come here, and hear
		the words of YHWH your God.
	}
}
{
}

\Verse{10}
{
	\hJ{
		וַיֹּאמֶר יְהוֹשֻׁעַ בְּזֹאת תֵּדְעוּן כִּי אֵל חַי בְּקִרְבְּכֶם וְהוֹרֵשׁ יוֹרִישׁ מִפְּנֵיכֶם אֶת־הַכְּנַעֲנִי וְאֶת־הַחִתִּי וְאֶת־הַחִוִּי וְאֶת־הַפְּרִזִּי
		וְאֶת־הַגִּרְגָּשִׁי וְהָאֱמֹרִי וְהַיְבוּסִי׃
	}
}
{
	\eJ{
		And Joshua said, Hereby you shall know that the living God is
		among you, and that He will surely drive out from before you the
		Canaanites, and the Hittites, and the Hivites, and the
		Perizzites, and the Girgashites, and the Amorites, and the
		Jebusites.
	}
}
{
}

\Verse{11}
{
	\hJ{הִנֵּה אֲרוֹן הַבְּרִית אֲדוֹן כּל־הָאָרֶץ עֹבֵר לִפְנֵיכֶם בַּיַּרְדֵּן׃}
}
{
	\eJ{
		Here, the ark of the covenant of YHWH of all the earth passeth
		over before you into Jordan.
	}
}
{
}

\Verse{12}
{
	\hJ{וְעַתָּה קְחוּ לָכֶם שְׁנֵי עָשָׂר אִישׁ מִשִּׁבְטֵי יִשְׂרָאֵל אִישׁ־אֶחָד אִישׁ־אֶחָד לַשָּׁבֶט׃}
}
{
	\eJ{
		Now therefore take you twelve men out of the tribes of Israel,
		out of every tribe a man.
	}
}
{
}

\Verse{13}
{
	\hJ{
		וְהָיָה כְּנוֹחַ כַּפּוֹת רַגְלֵי הַכֹּהֲנִים נֹשְׂאֵי אֲרוֹן יְהֹוָה אֲדוֹן כּל־הָאָרֶץ בְּמֵי הַיַּרְדֵּן מֵי הַיַּרְדֵּן יִכָּרֵתוּן הַמַּיִם הַיֹּרְדִים מִלְמָעְלָה וְיַעַמְדוּ
		נֵד אֶחָד׃
	}
}
{
	\eJ{
		And it shall come to pass, as soon as the soles of the feet of
		the priests that bear the ark of YHWH, YHWH of all the earth,
		shall rest in the waters of Jordan, that the waters of Jordan
		shall be cut off from the waters that come down from above; and
		they shall stand on an heap.
	}
}
{
}

\Verse{14}
{
	\hJ{וַיְהִי בִּנְסֹעַ הָעָם מֵאהֳלֵיהֶם לַעֲבֹר אֶת־הַיַּרְדֵּן וְהַכֹּהֲנִים נֹשְׂאֵי הָאָרוֹן הַבְּרִית לִפְנֵי הָעָם׃}
}
{
	\eJ{
		And it was, when the people removed from their tents, to pass
		over Jordan, and the priests bearing the ark of the covenant
		before the people;
	}
}
{
}

\Verse{15}
{
	\hJ{וּכְבוֹא נֹשְׂאֵי הָאָרוֹן עַד־הַיַּרְדֵּן וְרַגְלֵי הַכֹּהֲנִים נֹשְׂאֵי הָאָרוֹן נִטְבְּלוּ בִּקְצֵה הַמָּיִם וְהַיַּרְדֵּן מָלֵא עַל־כּל־גְּדוֹתָיו כֹּל יְמֵי קָצִיר׃}
}
{
	\eJ{
		And as they that bare the ark were come to Jordan, and the feet
		of the priests that bare the ark were dipped in the brim of the
		water, (for Jordan overfloweth all his banks all the time of
		harvest,)
	}
}
{
}

\Verse{16}
{
	\hJ{
		וַיַּעַמְדוּ הַמַּיִם הַיֹּרְדִים מִלְמַעְלָה קָמוּ נֵד־אֶחָד הַרְחֵק מְאֹד (באדם) [מֵאָדָם] הָעִיר אֲשֶׁר מִצַּד צָרְתָן וְהַיֹּרְדִים עַל יָם הָעֲרָבָה יָם־הַמֶּלַח תַּמּוּ
		נִכְרָתוּ וְהָעָם עָבְרוּ נֶגֶד יְרִיחוֹ׃
	}
}
{
	\eJ{
		That the waters that came down from above stood and rose up on
		an heap very far from the city Adam, that is beside Zaretan: and
		those that came down toward the sea of the plain, even the Salt
		Sea, failed, and were cut off: and the people passed over right
		against Jericho.
	}
}
{
	Qere Ketiv.
}

\Verse{17}
{
	\hJ{
		וַיַּעַמְדוּ הַכֹּהֲנִים נֹשְׂאֵי הָאָרוֹן בְּרִית־יְהֹוָה בֶּחָרָבָה בְּתוֹךְ הַיַּרְדֵּן הָכֵן וְכל־יִשְׂרָאֵל עֹבְרִים בֶּחָרָבָה עַד אֲשֶׁר־תַּמּוּ כּל־הַגּוֹי לַעֲבֹר
		אֶת־הַיַּרְדֵּן׃
	}
}
{
	\eJ{
		And the priests that bare the ark of the covenant of YHWH stood
		firm on dry ground in the midst of Jordan, and all the
		Israelites passed over on dry ground, until all the people were
		passed clean over Jordan.
	}
}
{
