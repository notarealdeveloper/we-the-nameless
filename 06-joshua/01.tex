\Chapter{1}

\Verse{1}
{
	\hJ{וַיְהִי אַחֲרֵי מוֹת מֹשֶׁה עֶבֶד יְהֹוָה וַיֹּאמֶר יְהֹוָה אֶל־יְהוֹשֻׁעַ בִּן־נוּן מְשָׁרֵת מֹשֶׁה לֵאמֹר׃}
}
{
	\eJ{
		And it was after the death of Moses, YHWH’s servant, that YHWH
		spoke to Joshua the son of Nun, Moses’ attendant, saying,
	}
}
{
%	\footnote{
%		Footnote 1:1. Moses' attendant. The Hebrew calls Joshua Moses' m'sharet, the one
%		who serves or attends him. At the end of the book Joshua will be called YHWH's
%		servant. The title is not just promotion. It is the whole plot in two words.
%	}
}

\Verse{2}
{
	\hX{מֹשֶׁה עַבְדִּי מֵת וְעַתָּה קוּם עֲבֹר אֶת־הַיַּרְדֵּן הַזֶּה אַתָּה וְכל־הָעָם הַזֶּה אֶל־הָאָרֶץ אֲשֶׁר אָנֹכִי נֹתֵן לָהֶם לִבְנֵי יִשְׂרָאֵל׃}
}
{
	\eX{
		Moses my servant is dead; now therefore arise, go over this
		Jordan, you, and all this people, to the land that I do give to
		them, even to the children of Israel.
	}
}
{
}

\Verse{3}
{
	\hX{כּל־מָקוֹם אֲשֶׁר תִּדְרֹךְ כַּף־רַגְלְכֶם בּוֹ לָכֶם נְתַתִּיו כַּאֲשֶׁר דִּבַּרְתִּי אֶל־מֹשֶׁה׃}
}
{
	\eX{
		Every place that the sole of your foot shall tread on, I’ve
		given it to you, as I said to Moses.
	}
}
{
}

\Verse{4}
{
	\hX{מֵהַמִּדְבָּר וְהַלְּבָנוֹן הַזֶּה וְעַד־הַנָּהָר הַגָּדוֹל נְהַר־פְּרָת כֹּל אֶרֶץ הַחִתִּים וְעַד־הַיָּם הַגָּדוֹל מְבוֹא הַשָּׁמֶשׁ יִהְיֶה גְּבוּלְכֶם׃}
}
{
	\eX{
		From the wilderness and this Lebanon even to the great river,
		the river Euphrates, all the land of the Hittites, and to the
		great sea toward the going down of the sun, shall be your
		border.
	}
}
{
}

\Verse{5}
{
	\hX{לֹא־יִתְיַצֵּב אִישׁ לְפָנֶיךָ כֹּל יְמֵי חַיֶּיךָ כַּאֲשֶׁר הָיִיתִי עִם־מֹשֶׁה אֶהְיֶה עִמָּךְ לֹא אַרְפְּךָ וְלֹא אֶעֶזְבֶךָּ׃}
}
{
	\eX{
		No man will be able to stand before you all the days of your
		life: as I was with Moses, so I'll be with you: I won't fail
		you, nor forsake you.
	}
}
{
}

\Verse{6}
{
	\hJ{חֲזַק וֶאֱמָץ כִּי אַתָּה תַּנְחִיל אֶת־הָעָם הַזֶּה אֶת־הָאָרֶץ אֲשֶׁר־נִשְׁבַּעְתִּי לַאֲבוֹתָם לָתֵת לָהֶם׃}
}
{
	\eJ{
		Be strong and courageous: for to this people shall you divide
		for an inheritance the land, that I swore to their fathers to
		give them.
	}
}
{
}

\Verse{7}
{
	\hX{רַק חֲזַק וֶאֱמַץ מְאֹד לִשְׁמֹר לַעֲשׂוֹת כְּכל־הַתּוֹרָה אֲשֶׁר צִוְּךָ מֹשֶׁה עַבְדִּי אַל־תָּסוּר מִמֶּנּוּ יָמִין וּשְׂמֹאול לְמַעַן תַּשְׂכִּיל בְּכֹל אֲשֶׁר תֵּלֵךְ׃}
}
{
	\eX{
		Only be strong and very courageous, that you may observe to do
		according to all the law, that Moses my servant commanded you:
		turn not from it to the right hand or to the left, that you may
		prosper wherever you go.
	}
}
{
}

\Verse{8}
{
	\hX{לֹא־יָמוּשׁ סֵפֶר הַתּוֹרָה הַזֶּה מִפִּיךָ וְהָגִיתָ בּוֹ יוֹמָם וָלַיְלָה לְמַעַן תִּשְׁמֹר לַעֲשׂוֹת כְּכל־הַכָּתוּב בּוֹ כִּי־אָז תַּצְלִיחַ אֶת־דְּרָכֶךָ וְאָז תַּשְׂכִּיל׃}
}
{
	\eX{
		This book of the law won't depart out of your mouth; but you
		shall meditate in it day and night, that you may observe to do
		according to all that is written in it: for then you shall make
		your way prosperous, and then you shall have good success.
	}
}
{
}

\Verse{9}
{
	\hJ{הֲלוֹא צִוִּיתִיךָ חֲזַק וֶאֱמָץ אַל־תַּעֲרֹץ וְאַל־תֵּחָת כִּי עִמְּךָ יְהֹוָה אֱלֹהֶיךָ בְּכֹל אֲשֶׁר תֵּלֵךְ׃}
}
{
	\eJ{
		Have not I commanded you? Be strong and courageous; don’t be
		afraid, and don’t be shattered: for YHWH your God is with you
		wherever you go.
	}
}
{
}

\Verse{10}
{
	\hX{וַיְצַו יְהוֹשֻׁעַ אֶת־שֹׁטְרֵי הָעָם לֵאמֹר׃}
}
{
	\eX{And Joshua commanded the officers of the people, saying,}
}
{
}

\Verse{11}
{
	\hX{
		עִבְרוּ בְּקֶרֶב הַמַּחֲנֶה וְצַוּוּ אֶת־הָעָם לֵאמֹר הָכִינוּ לָכֶם צֵידָה כִּי בְּעוֹד שְׁלֹשֶׁת יָמִים אַתֶּם עֹבְרִים אֶת־הַיַּרְדֵּן הַזֶּה לָבוֹא לָרֶשֶׁת אֶת־הָאָרֶץ אֲשֶׁר
		יְהֹוָה אֱלֹהֵיכֶם נֹתֵן לָכֶם לְרִשְׁתָּהּ׃
	}
}
{
	\eX{
		Pass through the army, and command the people, saying, Prepare
		you provisions; for within three days you shall pass over this
		Jordan, to go in to possess the land, that YHWH your God gives
		you to possess it.
	}
}
{
}

\Verse{12}
{
	\hX{וְלָראוּבֵנִי וְלַגָּדִי וְלַחֲצִי שֵׁבֶט הַמְנַשֶּׁה אָמַר יְהוֹשֻׁעַ לֵאמֹר׃}
}
{
	\eX{
		And to the Reubenites, and to the Gadites, and to half the tribe
		of Manasseh, spoke Joshua, saying,
	}
}
{
}

\Verse{13}
{
	\hX{זָכוֹר אֶת־הַדָּבָר אֲשֶׁר צִוָּה אֶתְכֶם מֹשֶׁה עֶבֶד־יְהֹוָה לֵאמֹר יְהֹוָה אֱלֹהֵיכֶם מֵנִיחַ לָכֶם וְנָתַן לָכֶם אֶת־הָאָרֶץ הַזֹּאת׃}
}
{
	\eX{
		Remember the word that Moses the servant of YHWH commanded you,
		saying, YHWH your God has given you rest, and has given you this
		land.
	}
}
{
}

\Verse{14}
{
	\hX{
		נְשֵׁיכֶם טַפְּכֶם וּמִקְנֵיכֶם יֵשְׁבוּ בָּאָרֶץ אֲשֶׁר נָתַן לָכֶם מֹשֶׁה בְּעֵבֶר הַיַּרְדֵּן וְאַתֶּם תַּעַבְרוּ חֲמֻשִׁים לִפְנֵי אֲחֵיכֶם כֹּל גִּבּוֹרֵי הַחַיִל וַעֲזַרְתֶּם
		אוֹתָם׃
	}
}
{
	\eX{
		Your wives, your little ones, and your cattle, shall stay in the
		land that Moses gave you across the Jordan; but you shall pass
		before your brothers armed, all the strong men of force, and
		help them;
	}
}
{
}

\Verse{15}
{
	\hX{
		עַד אֲשֶׁר־יָנִיחַ יְהֹוָה לַאֲחֵיכֶם כָּכֶם וְיָרְשׁוּ גַם־הֵמָּה אֶת־הָאָרֶץ אֲשֶׁר־יְהֹוָה אֱלֹהֵיכֶם נֹתֵן לָהֶם וְשַׁבְתֶּם לְאֶרֶץ יְרֻשַּׁתְכֶם וִירִשְׁתֶּם אוֹתָהּ אֲשֶׁר
		נָתַן לָכֶם מֹשֶׁה עֶבֶד יְהֹוָה בְּעֵבֶר הַיַּרְדֵּן מִזְרַח הַשָּׁמֶשׁ׃
	}
}
{
	\eX{
		Until YHWH have given your brothers rest, as he has given you,
		and they also have possessed the land that YHWH your God gives
		them: then you shall return to the land of your possession, and
		possess it, that Moses YHWH’s servant gave you across the Jordan
		toward the rising of the sun.
	}
}
{
}

\Verse{16}
{
	\hX{וַיַּעֲנוּ אֶת־יְהוֹשֻׁעַ לֵאמֹר כֹּל אֲשֶׁר־צִוִּיתָנוּ נַעֲשֶׂה וְאֶל־כּל־אֲשֶׁר תִּשְׁלָחֵנוּ נֵלֵךְ׃}
}
{
	\eX{
		And they answered Joshua, saying, All that you command us we'll
		do, and wherever you sendest us, we'll go.
	}
}
{
}

\Verse{17}
{
	\hX{כְּכֹל אֲשֶׁר־שָׁמַעְנוּ אֶל־מֹשֶׁה כֵּן נִשְׁמַע אֵלֶיךָ רַק יִהְיֶה יְהֹוָה אֱלֹהֶיךָ עִמָּךְ כַּאֲשֶׁר הָיָה עִם־מֹשֶׁה׃}
}
{
	\eX{
		According as we listened to Moses in all things, so will we
		listen to you: only YHWH your God be with you, as he was with
		Moses.
	}
}
{
}

\Verse{18}
{
	\hX{כּל־אִישׁ אֲשֶׁר־יַמְרֶה אֶת־פִּיךָ וְלֹא־יִשְׁמַע אֶת־דְּבָרֶיךָ לְכֹל אֲשֶׁר־תְּצַוֶּנּוּ יוּמָת רַק חֲזַק וֶאֱמָץ׃}
}
{
	\eX{
		Whosoever he be that does rebel against your commandment, and
		won't listen to your words in all that you command him, he shall
		be put to death: only be strong and courageous.
	}
}
{
}
