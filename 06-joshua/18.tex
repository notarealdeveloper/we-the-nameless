\Chapter{18}

\Verse{1}
{
	\hP{וַיִּקָּהֲלוּ כּל־עֲדַת בְּנֵי־יִשְׂרָאֵל שִׁלֹה וַיַּשְׁכִּינוּ שָׁם אֶת־אֹהֶל מוֹעֵד וְהָאָרֶץ נִכְבְּשָׁה לִפְנֵיהֶם׃}
}
{
	\eP{
		And the whole congregation of the children of Israel assembled
		together at Shiloh, and set up the tabernacle of the
		congregation there. And the land was subdued before them.
	}
}
{
}

\Verse{2}
{
	\hP{וַיִּוָּתְרוּ בִּבְנֵי יִשְׂרָאֵל אֲשֶׁר לֹא־חָלְקוּ אֶת־נַחֲלָתָם שִׁבְעָה שְׁבָטִים׃}
}
{
	\eP{
		And there remained among the children of Israel seven tribes,
		that had not yet received their inheritance.
	}
}
{
}

\Verse{3}
{
	\hP{וַיֹּאמֶר יְהוֹשֻׁעַ אֶל־בְּנֵי יִשְׂרָאֵל עַד־אָנָה אַתֶּם מִתְרַפִּים לָבוֹא לָרֶשֶׁת אֶת־הָאָרֶץ אֲשֶׁר נָתַן לָכֶם יְהֹוָה אֱלֹהֵי אֲבוֹתֵיכֶם׃}
}
{
	\eP{
		And Joshua said to the children of Israel, How long are you
		slack to go to possess the land, that YHWH God of your fathers
		has given you?
	}
}
{
}

\Verse{4}
{
	\hP{הָבוּ לָכֶם שְׁלֹשָׁה אֲנָשִׁים לַשָּׁבֶט וְאֶשְׁלָחֵם וְיָקֻמוּ וְיִתְהַלְּכוּ בָאָרֶץ וְיִכְתְּבוּ אוֹתָהּ לְפִי נַחֲלָתָם וְיָבֹאוּ אֵלָי׃}
}
{
	\eP{
		Give out from among you three men for each tribe: and I'll send
		them, and they shall rise, and go through the land, and describe
		it according to the inheritance of them; and they shall come
		again to me.
	}
}
{
}

\Verse{5}
{
	\hP{וְהִתְחַלְּקוּ אֹתָהּ לְשִׁבְעָה חֲלָקִים יְהוּדָה יַעֲמֹד עַל־גְּבוּלוֹ מִנֶּגֶב וּבֵית יוֹסֵף יַעַמְדוּ עַל־גְּבוּלָם מִצָּפוֹן׃}
}
{
	\eP{
		And they shall divide it into seven parts: Judah shall stay in
		their border on the south, and the house of Joseph shall stay in
		their borders on the north.
	}
}
{
}

\Verse{6}
{
	\hP{וְאַתֶּם תִּכְתְּבוּ אֶת־הָאָרֶץ שִׁבְעָה חֲלָקִים וַהֲבֵאתֶם אֵלַי הֵנָּה וְיָרִיתִי לָכֶם גּוֹרָל פֹּה לִפְנֵי יְהֹוָה אֱלֹהֵינוּ׃}
}
{
	\eP{
		You shall therefore describe the land into seven parts, and
		bring the description here to me, that I may cast lots for you
		here before YHWH our God.
	}
}
{
}

\Verse{7}
{
	\hP{
		כִּי אֵין־חֵלֶק לַלְוִיִּם בְּקִרְבְּכֶם כִּי־כְהֻנַּת יְהֹוָה נַחֲלָתוֹ וְגָד וּרְאוּבֵן וַחֲצִי שֵׁבֶט הַמְנַשֶּׁה לָקְחוּ נַחֲלָתָם מֵעֵבֶר לַיַּרְדֵּן מִזְרָחָה אֲשֶׁר נָתַן
		לָהֶם מֹשֶׁה עֶבֶד יְהֹוָה׃
	}
}
{
	\eP{
		But the Levites have no part among you; for the priesthood of
		YHWH is their inheritance: and Gad, and Reuben, and half the
		tribe of Manasseh, have received their inheritance beyond Jordan
		on the east, that Moses the servant of YHWH gave them.
	}
}
{
}

\Verse{8}
{
	\hP{
		וַיָּקֻמוּ הָאֲנָשִׁים וַיֵּלֵכוּ וַיְצַו יְהוֹשֻׁעַ אֶת־הַהֹלְכִים לִכְתֹּב אֶת־הָאָרֶץ לֵאמֹר לְכוּ וְהִתְהַלְּכוּ בָאָרֶץ וְכִתְבוּ אוֹתָהּ וְשׁוּבוּ אֵלַי וּפֹה אַשְׁלִיךְ
		לָכֶם גּוֹרָל לִפְנֵי יְהֹוָה בְּשִׁלֹה׃
	}
}
{
	\eP{
		And the men arose, and went away: and Joshua charged them that
		went to describe the land, saying, Go and walk through the land,
		and describe it, and come again to me, that I may here cast lots
		for you before YHWH in Shiloh.
	}
}
{
}

\Verse{9}
{
	\hP{וַיֵּלְכוּ הָאֲנָשִׁים וַיַּעַבְרוּ בָאָרֶץ וַיִּכְתְּבוּהָ לֶעָרִים לְשִׁבְעָה חֲלָקִים עַל־סֵפֶר וַיָּבֹאוּ אֶל־יְהוֹשֻׁעַ אֶל־הַמַּחֲנֶה שִׁלֹה׃}
}
{
	\eP{
		And the men went and passed through the land, and described it

}
{
}

\Verse{10}
{
	\hP{וַיַּשְׁלֵךְ לָהֶם יְהוֹשֻׁעַ גּוֹרָל בְּשִׁלֹה לִפְנֵי יְהֹוָה וַיְחַלֶּק־שָׁם יְהוֹשֻׁעַ אֶת־הָאָרֶץ לִבְנֵי יִשְׂרָאֵל כְּמַחְלְקֹתָם׃}
}
{
	\eP{

		Joshua divided the land to the children of Israel according to

	}
}
{
}

\Verse{11}
{
	\hP{וַיַּעַל גּוֹרַל מַטֵּה בְנֵי־בִנְיָמִן לְמִשְׁפְּחֹתָם וַיֵּצֵא גְּבוּל גּוֹרָלָם בֵּין בְּנֵי יְהוּדָה וּבֵין בְּנֵי יוֹסֵף׃}
}

\Verse{12}

	\hP{וַיְהִי לָהֶם הַגְּבוּל לִפְאַת צָפוֹנָה מִן־הַיַּרְדֵּן וְעָלָה הַגְּבוּל אֶל־כֶּתֶף יְרִיחוֹ מִצָּפוֹן וְעָלָה בָהָר יָמָּה (והיה) [וְהָיוּ] תֹּצְאֹתָיו מִדְבַּרָה בֵּית אָוֶן׃}

	\eP{
