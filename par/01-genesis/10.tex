\Chapter{10}

\Verse{1}
{
	\hR{וְאֵלֶּה תּוֹלְדֹת בְּנֵי נֹחַ שֵׁם חָם וָיָפֶת וַיִּוָּלְדוּ לָהֶם בָּנִים אַחַר הַמַּבּוּל׃}
}
{
	\eR{
		And these are the records of Noah’s sons, Shem, Ham,
		and Yaphet: And children were born to them after the
		flood.
	}
}
{
}

\Verse{2}
{
	\hP{בְּנֵי יֶפֶת גֹּמֶר וּמָגוֹג וּמָדַי וְיָוָן וְתֻבָל וּמֶשֶׁךְ וְתִירָס׃}
}
{
	\eP{
		Yaphet’s children were Gomer and Magog and Madai and Yawan
		and Tubal and Meshech and Tiras.
	}
}
{
%	\footnote{
%		Yawan. Greece (Ionia).
%	}
}

\Verse{3}
{
	\hP{וּבְנֵי גֹּמֶר אַשְׁכְּנַז וְרִיפַת וְתֹגַרְמָה׃}
}
{
	\eP{
		And Gomer’s children were Ashkenaz and Riphath and
		Togarmah.
	}
}
{
}

\Verse{4}
{
	\hP{וּבְנֵי יָוָן אֱלִישָׁה וְתַרְשִׁישׁ כִּתִּים וְדֹדָנִים׃}
}
{
	\eP{
		And Yawan’s children were El-isha and Tarshish, Kittim and
		Dodanim.
	}
}
{
%	\footnote{
%		Tarshish. Where Jonah tries to sail from the Mediterranean port of
%		Joppa. Perhaps Gibraltar or Sardinia.
%	}
}

\Verse{5}
{
	\hP{מֵאֵלֶּה נִפְרְדוּ אִיֵּי הַגּוֹיִם בְּאַרְצֹתָם אִישׁ לִלְשֹׁנוֹ לְמִשְׁפְּחֹתָם בְּגוֹיֵהֶם׃}
}
{
	\eP{
		The islands of the nations in their lands were dispersed
		out from these, each by its language, by their families
		within their nations.
	}
}
{
%	\footnote{
%		The islands of the nations. This has been understood to mean seacoast
%		peoples.
%	}
}

\Verse{6}
{
	\hP{וּבְנֵי חָם כּוּשׁ וּמִצְרַיִם וּפוּט וּכְנָעַן׃}
}
{
	\eP{And Ham’s children were Cush and Egypt and Put and Canaan.}
}
{
}

\Verse{7}
{
	\hP{וּבְנֵי כוּשׁ סְבָא וַחֲוִילָה וְסַבְתָּה וְרַעְמָה וְסַבְתְּכָא וּבְנֵי רַעְמָה שְׁבָא וּדְדָן׃}
}
{
	\eP{
		And Cush’s children were Seba and Havilah and Sabtah and
		Raamah and Sabteca. And Raamah’s children were Sheba and
		Dedan.
	}
}
{
%	\footnote{
%		Sheba. The Sabeans (of southwest Arabia) whose queen would make a famous
%		journey to meet Israel’s King Solomon generations later. The confusing
%		thing is that Sheba is traced to both Ham (10:7) and Shem (v. 28). (And
%		this is further confused by a reference to Sheba as descended from
%		Abraham in Gen 25:3.)
%	}
}

\Verse{8}
{
	\hJ{וְכוּשׁ יָלַד אֶת נִמְרֹד הוּא הֵחֵל לִהְיוֹת גִּבֹּר בָּאָרֶץ׃}
}
{
	\eJ{
		And Cush fathered Nimrod. He began being a man of power in
		the earth.
	}
}
{
}

\Verse{9}
{
	\hJ{הוּא הָיָה גִבֹּר צַיִד לִפְנֵי יְהֹוָה עַל כֵּן יֵאָמַר כְּנִמְרֹד גִּבּוֹר צַיִד לִפְנֵי יְהֹוָה׃}
}
{
	\eJ{
		He was a powerful hunter before YHWH. On account of this
		it is said: “A powerful hunter before YHWH like Nimrod!”
	}
}
{
}

\Verse{10}
{
	\hJ{וַתְּהִי רֵאשִׁית מַמְלַכְתּוֹ בָּבֶל וְאֶרֶךְ וְאַכַּד וְכַלְנֵה בְּאֶרֶץ שִׁנְעָר׃}
}
{
	\eJ{
		And the beginning of his kingdom was Babylon and Erech and
		Akkad and Calneh in the land of Shinar.
	}
}
{
}

\Verse{11}
{
	\hJ{מִן הָאָרֶץ הַהִוא יָצָא אַשּׁוּר וַיִּבֶן אֶת נִינְוֵה וְאֶת רְחֹבֹת עִיר וְאֶת כָּלַח׃}
}
{
	\eJ{
		Asshur came out of that land and built Nineveh and
		Rehovoth-Ir and Calah,
	}
}
{
}

\Verse{12}
{
	\hJ{וְאֶת רֶסֶן בֵּין נִינְוֵה וּבֵין כָּלַח הִוא הָעִיר הַגְּדֹלָה׃}
}
{
	\eJ{and Resen between Nineveh and Calah. It is the big city.}
}
{
}

\Verse{13}
{
	\hJ{וּמִצְרַיִם יָלַד אֶת לוּדִים וְאֶת עֲנָמִים וְאֶת לְהָבִים וְאֶת נַפְתֻּחִים׃}
}
{
	\eJ{
		And Egypt fathered Ludim and Anamim and Lehabim and
		Naphtuhim
	}
}
{
}

\Verse{14}
{
	\hJ{וְאֶת פַּתְרֻסִים וְאֶת כַּסְלֻחִים אֲשֶׁר יָצְאוּ מִשָּׁם פְּלִשְׁתִּים וְאֶת כַּפְתֹּרִים׃}
}
{
	\eJ{
		and Pathrusim and Casluhim, from which the Philistines
		came out, and Caphtorim.
	}
}
{
%	\footnote{
%		Casluhim, from which the Philistines came out, and Caphtorim. But cf.
%		Amos 9:7, which says that the Philistines come from Caphtor. In any
%		case, this first reference to the Philistines in the Torah already
%		identifies them as—unlike the other residents of Canaan—coming from
%		across the Mediterranean. Still, it separates them from the Greeks.
%	}
}

\Verse{15}

}
{
	\eJ{And Canaan fathered Sidon, his firstborn, and Heth}
}
{
}

\Verse{16}
{
	\hJ{וְאֶת הַיְבוּסִי וְאֶת הָאֱמֹרִי וְאֵת הַגִּרְגָּשִׁי׃}

}

\Verse{17}

	\hJ{וְאֶת הַחִוִּי וְאֶת הַעַרְקִי וְאֶת הַסִּינִי׃}
}
{
	\eJ{and the Hivite and the Arkite and the Sinite}
}
{
}

\Verse{18}
{
	\hJ{וְאֶת הָאַרְוָדִי וְאֶת הַצְּמָרִי וְאֶת הַחֲמָתִי וְאַחַר נָפֹצוּ מִשְׁפְּחוֹת הַכְּנַעֲנִי׃}
}
{
	\eJ{
		and the Arvadite and the Zemarite and the Hamathite. And

\Verse{19}
{
	\hJ{וַיְהִי גְּבוּל הַכְּנַעֲנִי מִצִּידֹן בֹּאֲכָה גְרָרָה עַד עַזָּה בֹּאֲכָה סְדֹמָה וַעֲמֹרָה וְאַדְמָה וּצְבֹיִם עַד לָשַׁע׃}
}
{
	\eJ{
		And the Canaanite border was from Sidon, as you come to

	}
}
{
}

\Verse{20}

	\hP{אֵלֶּה בְנֵי חָם לְמִשְׁפְּחֹתָם לִלְשֹׁנֹתָם בְּאַרְצֹתָם בְּגוֹיֵהֶם׃}
