\Chapter{25}

\Verse{1}
{
	\hDtn{כִּי יִהְיֶה רִיב בֵּין אֲנָשִׁים וְנִגְּשׁוּ אֶל הַמִּשְׁפָּט וּשְׁפָטוּם וְהִצְדִּיקוּ אֶת הַצַּדִּיק וְהִרְשִׁיעוּ אֶת הָרָשָׁע׃}
}
{
	\eDtn{
		“When there will be a dispute between people, and they
		will go over to judgment, and they will judge them, then
		they shall find in favor of the one who is in the right
		and find against the one who is in the wrong.
	}
}
{
}

\Verse{2}
{
	\hDtn{וְהָיָה אִם בִּן הַכּוֹת הָרָשָׁע וְהִפִּילוֹ הַשֹּׁפֵט וְהִכָּהוּ לְפָנָיו כְּדֵי רִשְׁעָתוֹ בְּמִסְפָּר׃}
}
{
	\eDtn{
		And it will be, if the one who is in the wrong is to be
		struck, that the judge shall have him laid down and have
		him struck in front of him, according to his wrongdoing in
		number.
	}
}
{
}

\Verse{3}
{
	\hDtn{אַרְבָּעִים יַכֶּנּוּ לֹא יֹסִיף פֶּן יֹסִיף לְהַכֹּתוֹ עַל אֵלֶּה מַכָּה רַבָּה וְנִקְלָה אָחִיךָ לְעֵינֶיךָ׃}
}
{
	\eDtn{
		They shall strike him forty times. He shall not add, in
		case he would add onto these to strike him a great amount,
		and your brother would be treated as inconsequential
		before your eyes.
	}
}
{
}

\Verse{4}
{
	\hDtn{לֹא תַחְסֹם שׁוֹר בְּדִישׁוֹ׃}
}
{
	\eDtn{“You shall not muzzle an ox when it is threshing.}
}
{
}

\Verse{5}
{
	\hDtn{כִּי יֵשְׁבוּ אַחִים יַחְדָּו וּמֵת אַחַד מֵהֶם וּבֵן אֵין לוֹ לֹא תִהְיֶה אֵשֶׁת הַמֵּת הַחוּצָה לְאִישׁ זָר יְבָמָהּ יָבֹא עָלֶיהָ וּלְקָחָהּ לוֹ לְאִשָּׁה וְיִבְּמָהּ׃}
}
{
	\eDtn{
		“When brothers will live together, and one of them will
		die, and he had no son, the dead man’s wife shall not be
		an unrelated man’s, outside. Her brother-in-law shall come
		to her and take her to him for a wife and shall do the
		brother-in-law’s duty for her.
	}
}
{
%	\footnote{
%		brother-in-law. This is known as the law of levirate marriage, from the
%		Latin levir, meaning brother-in-law.
%	}
}

\Verse{6}
{
	\hDtn{וְהָיָה הַבְּכוֹר אֲשֶׁר תֵּלֵד יָקוּם עַל שֵׁם אָחִיו הַמֵּת וְלֹא יִמָּחֶה שְׁמוֹ מִיִּשְׂרָאֵל׃}
}
{
	\eDtn{
		And the firstborn to whom she will give birth shall be
		signified by the name of his brother who died, so his name
		will not be wiped out from Israel.
	}
}
{
%	\footnote{
%		by the name of his brother who died. The child is not called “son of”
%		followed by the name of his biological father, but rather “son of”
%		followed by the name of the deceased brother of his biological father.
%		In this way the deceased brother’s name is preserved after his death.
%	}
}

\Verse{7}
{
	\hDtn{וְאִם לֹא יַחְפֹּץ הָאִישׁ לָקַחַת אֶת יְבִמְתּוֹ וְעָלְתָה יְבִמְתּוֹ הַשַּׁעְרָה אֶל הַזְּקֵנִים וְאָמְרָה מֵאֵן יְבָמִי לְהָקִים לְאָחִיו שֵׁם בְּיִשְׂרָאֵל לֹא אָבָה יַבְּמִי׃}
}
{
	\eDtn{
		And if the man won’t desire to take his sister-in-law,
		then his sister-in-law shall go up at the gate to the
		elders and say, ‘My brother-in-law refuses to preserve a
		name for his brother in Israel. He was not willing to do
		the brother-in-law’s duty for me.’
	}
}
{
}

\Verse{8}
{
	\hDtn{וְקָרְאוּ לוֹ זִקְנֵי עִירוֹ וְדִבְּרוּ אֵלָיו וְעָמַד וְאָמַר לֹא חָפַצְתִּי לְקַחְתָּהּ׃}
}
{
	\eDtn{
		And his city’s elders shall call him and speak to him, and
		if he’ll stand and say, ‘I don’t desire to take her,’
	}
}
{
}

\Verse{9}
{
	\hDtn{וְנִגְּשָׁה יְבִמְתּוֹ אֵלָיו לְעֵינֵי הַזְּקֵנִים וְחָלְצָה נַעֲלוֹ מֵעַל רַגְלוֹ וְיָרְקָה בְּפָנָיו וְעָנְתָה וְאָמְרָה כָּכָה יֵעָשֶׂה לָאִישׁ אֲשֶׁר לֹא יִבְנֶה אֶת בֵּית אָחִיו׃}
}
{
	\eDtn{
		then his sister-in-law shall go over to him before the
		elders’ eyes and take off his shoe from his foot and spit
		in front of him. And she shall answer and say, ‘Thus shall
		be done to the man who will not build up his brother’s
		house.’
	}
}
{
%	\footnote{
%		spit in front of him. This is commonly understood and translated as
%		“spit in his face.” But the only other occurrence of this term ()
%		in the Torah clearly means “in front of him” (Deut 4:37), and there are
%		no linguistic or contextual grounds for taking it to mean something more
%		specific (and repugnant) than that here.
%	}
}

\Verse{10}
{
	\hDtn{וְנִקְרָא שְׁמוֹ בְּיִשְׂרָאֵל בֵּית חֲלוּץ הַנָּעַל׃}
}
{
	\eDtn{
		And his name shall be called in Israel ‘the house of the
		one whose shoe was taken off.’
	}
}
{
}

\Verse{11}
{
	\hDtn{כִּי יִנָּצוּ אֲנָשִׁים יַחְדָּו אִישׁ וְאָחִיו וְקָרְבָה אֵשֶׁת הָאֶחָד לְהַצִּיל אֶת אִישָׁהּ מִיַּד מַכֵּהוּ וְשָׁלְחָה יָדָהּ וְהֶחֱזִיקָה בִּמְבֻשָׁיו׃}
}
{
	\eDtn{
		“If people will fight together, a man and his brother, and
		the wife of one will come close to rescue her husband from
		the hand of the one striking him, and she’ll put out her
		hand and take hold of his private parts,
	}
}
{
}

\Verse{12}
{
	\hDtn{וְקַצֹּתָה אֶת כַּפָּהּ לֹא תָחוֹס עֵינֶךָ׃}
}
{
	\eDtn{then you shall cut off her hand. Your eye shall not pity.}
}
{
}

\Verse{13}
{
	\hDtn{לֹא יִהְיֶה לְךָ בְּכִיסְךָ אֶבֶן וָאָבֶן גְּדוֹלָה וּקְטַנָּה׃}
}
{
	\eDtn{
		“You shall not have in your bag multiple stones, a big and
		a small.
	}
}
{
%	\footnote{
%		multiple stones, a big and a small. Meaning: one should not have larger
%		and smaller weights so as to weigh things dishonestly.
%	}
}

\Verse{14}
{
	\hDtn{לֹא יִהְיֶה לְךָ בְּבֵיתְךָ אֵיפָה וְאֵיפָה גְּדוֹלָה וּקְטַנָּה׃}
}
{
	\eDtn{
		You shall not have in your house multiple ephah measures,
		a big and a small.
	}
}
{
}

\Verse{15}
{
	\hDtn{אֶבֶן שְׁלֵמָה וָצֶדֶק יִהְיֶה לָּךְ אֵיפָה שְׁלֵמָה וָצֶדֶק יִהְיֶה לָּךְ לְמַעַן יַאֲרִיכוּ יָמֶיךָ עַל הָאֲדָמָה אֲשֶׁר יְהֹוָה אֱלֹהֶיךָ נֹתֵן לָךְ׃}
}
{
	\eDtn{
		You shall have a whole and honest stone; you shall have a
		whole and honest ephah measure, so your days will be
		extended on the land that YHWH, your {\God}, is giving you.
	}
}
{
}

\Verse{16}
{
	\hDtn{כִּי תוֹעֲבַת יְהֹוָה אֱלֹהֶיךָ כּל עֹשֵׂה אֵלֶּה כֹּל עֹשֵׂה עָוֶל׃}
}
{
	\eDtn{
		Because everyone who does these is an offensive thing of
		YHWH, everyone who does injustice.
	}
}
{
}

\Verse{17}
{
	\hDtn{זָכוֹר אֵת אֲשֶׁר עָשָׂה לְךָ עֲמָלֵק בַּדֶּרֶךְ בְּצֵאתְכֶם מִמִּצְרָיִם׃}
}
{
	\eDtn{
		“Remember what Amalek did to you on the way when you came
		out from Egypt,
	}
}
{
}

\Verse{18}
{
	\hDtn{אֲשֶׁר קָרְךָ בַּדֶּרֶךְ וַיְזַנֵּב בְּךָ כּל הַנֶּחֱשָׁלִים אַחֲרֶיךָ וְאַתָּה עָיֵף וְיָגֵעַ וְלֹא יָרֵא אֱלֹהִים׃}
}
{
	\eDtn{
		how he fell upon you on the way and cut off all the weak
		ones at your rear, when you were exhausted and tired, and
		he didn’t fear {\God}.
	}
}
{
}

\Verse{19}
{
	\hDtn{וְהָיָה בְּהָנִיחַ יְהֹוָה אֱלֹהֶיךָ לְךָ מִכּל אֹיְבֶיךָ מִסָּבִיב בָּאָרֶץ אֲשֶׁר יְהֹוָה אֱלֹהֶיךָ נֹתֵן לְךָ נַחֲלָה לְרִשְׁתָּהּ תִּמְחֶה אֶת זֵכֶר עֲמָלֵק מִתַּחַת הַשָּׁמָיִם לֹא תִּשְׁכָּח׃}
}
{
	\eDtn{
		So it shall be, when YHWH, your {\God}, will give you rest
		from all your enemies all around in the land that YHWH,
		your {\God}, is giving you as a legacy to take possession of
		it, you shall wipe out the memory of Amalek from under the
		skies. You shall not forget.
	}
}
{
}
