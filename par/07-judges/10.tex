\Chapter{10}

\Verse{1}
{
	\hX{וַיָּקם אַחֲרֵי אֲבִימֶלֶךְ לְהוֹשִׁיעַ אֶת־יִשְׂרָאֵל תּוֹלָע בֶּן־פּוּאָה בֶּן־דּוֹדוֹ אִישׁ יִשָּׂשכָר וְהוּא־יֹשֵׁב בְּשָׁמִיר בְּהַר אֶפְרָיִם׃}
}
{
	\eX{
		After Abimelech, Tola son of Puah son of Dodo, a man of Issachar,
		arose to deliver Israel. He lived at Shamir in the hill country of
		Ephraim.
	}
}
{
}

\Verse{2}
{
	\hX{וַיִּשְׁפֹּט אֶת־יִשְׂרָאֵל עֶשְׂרִים וְשָׁלֹשׁ שָׁנָה וַיָּמת וַיִּקָּבֵר בְּשָׁמִיר׃}
}
{
	\eX{
		He led Israel for twenty-three years; then he died and was buried
		at Shamir.
	}
}
{
}

\Verse{3}
{
	\hX{וַיָּקם אַחֲרָיו יָאִיר הַגִּלְעָדִי וַיִּשְׁפֹּט אֶת־יִשְׂרָאֵל עֶשְׂרִים וּשְׁתַּיִם שָׁנָה׃}
}
{
	\eX{
		After him arose Jair the Gileadite, and he led Israel for
		twenty-two years.
	}
}
{
}

\Verse{4}
{
	\hX{וַיְהִי־לוֹ שְׁלֹשִׁים בָּנִים רֹכְבִים עַל־שְׁלֹשִׁים עֲיָרִים וּשְׁלֹשִׁים עֲיָרִים לָהֶם לָהֶם יִקְרְאוּ חַוֺּת יָאִיר עַד הַיּוֹם הַזֶּה אֲשֶׁר בְּאֶרֶץ הַגִּלְעָד׃}
}
{
	\eX{
		He had thirty sons, who rode on thirty burros and owned thirty
		boroughs in the region of Gilead; these are called Havvoth-jair to
		this day.)
	}
}
{
}

\Verse{5}
{
	\hX{וַיָּמת יָאִיר וַיִּקָּבֵר בְּקָמוֹן׃}
}
{
	\eX{Then Jair died and was buried at Kamon.}
}
{
}

\Verse{6}
{
	\hX{
		וַיֹּסִיפוּ בְּנֵי יִשְׂרָאֵל לַעֲשׂוֹת הָרַע בְּעֵינֵי יְהֹוָה וַיַּעַבְדוּ אֶת־הַבְּעָלִים וְאֶת־הָעַשְׁתָּרוֹת וְאֶת־אֱלֹהֵי אֲרָם וְאֶת־אֱלֹהֵי צִידוֹן וְאֵת אֱלֹהֵי מוֹאָב
		וְאֵת אֱלֹהֵי בְנֵי־עַמּוֹן וְאֵת אֱלֹהֵי פְלִשְׁתִּים וַיַּעַזְבוּ אֶת־יְהֹוָה וְלֹא עֲבָדוּהוּ׃
	}
}
{
	\eX{
		The Israelites again did what was offensive to YHWH. They served
		the Baalim and the Ashtaroth, and the gods of Aram, the gods of
		Sidon, the gods of Moab, the gods of the Ammonites, and the gods
		of the Philistines; they forsook YHWH and did not serve Him.
	}
}
{
}

\Verse{7}
{
	\hX{וַיִּחַר־אַף יְהֹוָה בְּיִשְׂרָאֵל וַיִּמְכְּרֵם בְּיַד־פְּלִשְׁתִּים וּבְיַד בְּנֵי עַמּוֹן׃}
}
{
	\eX{
		And YHWH, incensed with Israel, surrendered them to the
		Philistines and to the Ammonites.
	}
}
{
}

\Verse{8}
{
	\hJ{
		וַיִּרְעֲצוּ וַיְרֹצְצוּ אֶת־בְּנֵי יִשְׂרָאֵל בַּשָּׁנָה הַהִיא שְׁמֹנֶה עֶשְׂרֵה שָׁנָה אֶת־כּל־בְּנֵי יִשְׂרָאֵל אֲשֶׁר בְּעֵבֶר הַיַּרְדֵּן בְּאֶרֶץ הָאֱמֹרִי אֲשֶׁר
		בַּגִּלְעָד׃
	}
}
{
	\eJ{
		That year they battered and shattered the Israelites—for eighteen
		years—all the Israelites beyond the Jordan, in [what had been] the
		land of the Amorites in Gilead.
	}
}
{
}

\Verse{9}
{
	\hJ{וַיַּעַבְרוּ בְנֵי־עַמּוֹן אֶת־הַיַּרְדֵּן לְהִלָּחֵם גַּם־בִּיהוּדָה וּבְבִנְיָמִין וּבְבֵית אֶפְרָיִם וַתֵּצֶר לְיִשְׂרָאֵל מְאֹד׃}
}
{
	\eJ{
		The Ammonites also crossed the Jordan to make war on Judah,
		Benjamin, and the House of Ephraim. Israel was in great distress.
	}
}
{
}

\Verse{10}
{
	\hX{וַיִּזְעֲקוּ בְּנֵי יִשְׂרָאֵל אֶל־יְהֹוָה לֵאמֹר חָטָאנוּ לָךְ וְכִי עָזַבְנוּ אֶת־אֱלֹהֵינוּ וַנַּעֲבֹד אֶת־הַבְּעָלִים׃}
}
{
	\eX{
		Then the Israelites cried out to YHWH, “We stand guilty before
		You, for we have forsaken our God and served the Baalim.”
	}
}
{
}

\Verse{11}
{
	\hX{וַיֹּאמֶר יְהֹוָה אֶל־בְּנֵי יִשְׂרָאֵל הֲלֹא מִמִּצְרַיִם וּמִן־הָאֱמֹרִי וּמִן־בְּנֵי עַמּוֹן וּמִן־פְּלִשְׁתִּים׃}
}
{
	\eX{
		But YHWH said to the Israelites, “[I have rescued you] from the
		Egyptians, from the Amorites, from the Ammonites, and from the
		Philistines.
	}
}
{
}

\Verse{12}
{
	\hX{וְצִידוֹנִים וַעֲמָלֵק וּמָעוֹן לָחֲצוּ אֶתְכֶם וַתִּצְעֲקוּ אֵלַי וָאוֹשִׁיעָה אֶתְכֶם מִיָּדָם׃}
}
{
	\eX{
		The Sidonians, Amalek, and Maon also oppressed you; and when you
		cried out to Me, I saved you from them.
	}
}
{
}

\Verse{13}
{
	\hX{וְאַתֶּם עֲזַבְתֶּם אוֹתִי וַתַּעַבְדוּ אֱלֹהִים אֲחֵרִים לָכֵן לֹא־אוֹסִיף לְהוֹשִׁיעַ אֶתְכֶם׃}
}
{
	\eX{
		Yet you have forsaken Me and have served other gods. No, I will
		not deliver you again.
	}
}
{
}

\Verse{14}
{
	\hX{לְכוּ וְזַעֲקוּ אֶל־הָאֱלֹהִים אֲשֶׁר בְּחַרְתֶּם בָּם הֵמָּה יוֹשִׁיעוּ לָכֶם בְּעֵת צָרַתְכֶם׃}
}
{
	\eX{
		Go cry to the gods you have chosen; let them deliver you in your
		time of distress!”
	}
}
{
}

\Verse{15}
{
	\hX{וַיֹּאמְרוּ בְנֵי־יִשְׂרָאֵל אֶל־יְהֹוָה חָטָאנוּ עֲשֵׂה־אַתָּה לָנוּ כְּכל־הַטּוֹב בְּעֵינֶיךָ אַךְ הַצִּילֵנוּ נָא הַיּוֹם הַזֶּה׃}
}
{
	\eX{
		But the Israelites implored YHWH: “We stand guilty. Do to us as
		You see fit; only save us this day!”
	}
}
{
}

\Verse{16}
{
	\hX{וַיָּסִירוּ אֶת־אֱלֹהֵי הַנֵּכָר מִקִּרְבָּם וַיַּעַבְדוּ אֶת־יְהֹוָה וַתִּקְצַר נַפְשׁוֹ בַּעֲמַל יִשְׂרָאֵל׃}
}
{
	\eX{
		They removed the alien gods from among them and served YHWH; and
		He could not bear the miseries of Israel.
	}
}
{
}

\Verse{17}
{
	\hJ{וַיִּצָּעֲקוּ בְּנֵי עַמּוֹן וַיַּחֲנוּ בַּגִּלְעָד וַיֵּאָסְפוּ בְּנֵי יִשְׂרָאֵל וַיַּחֲנוּ בַּמִּצְפָּה׃}
}
{
	\eJ{
		The Ammonites mustered and they encamped in Gilead; and the
		Israelites massed and they encamped at Mizpah.
	}
}
{
}

\Verse{18}
{
	\hJ{וַיֹּאמְרוּ הָעָם שָׂרֵי גִלְעָד אִישׁ אֶל־רֵעֵהוּ מִי הָאִישׁ אֲשֶׁר יָחֵל לְהִלָּחֵם בִּבְנֵי עַמּוֹן יִהְיֶה לְרֹאשׁ לְכֹל יֹשְׁבֵי גִלְעָד׃}
}
{
	\eJ{
		The troops—the officers of Gilead—said to one another, “Let the
		man who is the first to fight the Ammonites be chieftain over all
		the inhabitants of Gilead.”
	}
}
{
}
