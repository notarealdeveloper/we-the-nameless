\Chapter{12}

\Verse{1}
{
	\hX{
		וַיִּצָּעֵק אִישׁ אֶפְרַיִם וַיַּעֲבֹר צָפוֹנָה וַיֹּאמְרוּ לְיִפְתָּח מַדּוּעַ עָבַרְתָּ לְהִלָּחֵם בִּבְנֵי־עַמּוֹן וְלָנוּ לֹא קָרָאתָ לָלֶכֶת עִמָּךְ בֵּיתְךָ נִשְׂרֹף עָלֶיךָ
		בָּאֵשׁ׃
	}
}
{
	\eX{
		The men of Ephraim mustered and crossed [the Jordan] to Zaphon.
		They said to Jephthah, “Why did you march to fight the Ammonites
		without calling us to go with you? We’ll burn your house down over
		you!”
	}
}
{
}

\Verse{2}
{
	\hX{וַיֹּאמֶר יִפְתָּח אֲלֵיהֶם אִישׁ רִיב הָיִיתִי אֲנִי וְעַמִּי וּבְנֵי־עַמּוֹן מְאֹד וָאֶזְעַק אֶתְכֶם וְלֹא־הוֹשַׁעְתֶּם אוֹתִי מִיָּדָם׃}
}
{
	\eX{
		Jephthah answered them, “I and my people were in a bitter conflict
		with the Ammonites; and I summoned you, but you did not save me
		from them.
	}
}
{
}

\Verse{3}
{
	\hX{וָאֶרְאֶה כִּי־אֵינְךָ מוֹשִׁיעַ וָאָשִׂימָה נַפְשִׁי בְכַפִּי וָאֶעְבְּרָה אֶל־בְּנֵי עַמּוֹן וַיִּתְּנֵם יְהֹוָה בְּיָדִי וְלָמָה עֲלִיתֶם אֵלַי הַיּוֹם הַזֶּה לְהִלָּחֶם בִּי׃}
}
{
	\eX{
		When I saw that you were no saviors, I risked my life and advanced
		against the Ammonites; and YHWH delivered them into my hands. Why
		have you come here now to fight against me?”
	}
}
{
}

\Verse{4}
{
	\hX{
		וַיִּקְבֹּץ יִפְתָּח אֶת־כּל־אַנְשֵׁי גִלְעָד וַיִּלָּחֶם אֶת־אֶפְרָיִם וַיַּכּוּ אַנְשֵׁי גִלְעָד אֶת־אֶפְרַיִם כִּי אָמְרוּ פְּלִיטֵי אֶפְרַיִם אַתֶּם גִּלְעָד בְּתוֹךְ אֶפְרַיִם
		בְּתוֹךְ מְנַשֶּׁה׃
	}
}
{
	\eX{
		And Jephthah gathered all the men of Gilead and fought the
		Ephraimites. The men of Gilead defeated the Ephraimites; for they
		had said, “You Gileadites are nothing but fugitives from
		Ephraim—being in Manasseh is like being in Ephraim.”
	}
}
{
}

\Verse{5}
{
	\hX{וַיִּלְכֹּד גִּלְעָד אֶת־מַעְבְּרוֹת הַיַּרְדֵּן לְאֶפְרָיִם וְהָיָה כִּי יֹאמְרוּ פְּלִיטֵי אֶפְרַיִם אֶעֱבֹרָה וַיֹּאמְרוּ לוֹ אַנְשֵׁי־גִלְעָד הַאֶפְרָתִי אַתָּה וַיֹּאמֶר לֹא׃}
}
{
	\eX{
		The Gileadites held the fords of the Jordan against the
		Ephraimites. And when any fugitive from Ephraim said, “Let me
		cross,” the men of Gilead would ask him, “Are you an Ephraimite?”;
		if he said “No,”
	}
}
{
}

\Verse{6}
{
	\hX{
		וַיֹּאמְרוּ לוֹ אֱמר־נָא שִׁבֹּלֶת וַיֹּאמֶר סִבֹּלֶת וְלֹא יָכִין לְדַבֵּר כֵּן וַיֹּאחֲזוּ אוֹתוֹ וַיִּשְׁחָטוּהוּ אֶל־מַעְבְּרוֹת הַיַּרְדֵּן וַיִּפֹּל בָּעֵת הַהִיא מֵאֶפְרַיִם
		אַרְבָּעִים וּשְׁנַיִם אָלֶף׃
	}
}
{
	\eX{
		they would say to him, “Then say shibboleth”; but he would say
		“sibboleth,” not being able to pronounce it correctly. Thereupon
		they would seize him and slay him by the fords of the Jordan.
		Forty-two thousand Ephraimites fell at that time.
	}
}
{
}

\Verse{7}
{
	\hX{וַיִּשְׁפֹּט יִפְתָּח אֶת־יִשְׂרָאֵל שֵׁשׁ שָׁנִים וַיָּמת יִפְתָּח הַגִּלְעָדִי וַיִּקָּבֵר בְּעָרֵי גִלְעָד׃}
}
{
	\eX{
		Jephthah led Israel six years. Then Jephthah the Gileadite died
		and he was buried in one of the towns of Gilead.
	}
}
{
}

\Verse{8}
{
	\hX{וַיִּשְׁפֹּט אַחֲרָיו אֶת־יִשְׂרָאֵל אִבְצָן מִבֵּית לָחֶם׃}
}
{
	\eX{After him, Ibzan of Bethlehem led Israel.}
}
{
}

\Verse{9}
{
	\hX{וַיְהִי־לוֹ שְׁלֹשִׁים בָּנִים וּשְׁלֹשִׁים בָּנוֹת שִׁלַּח הַחוּצָה וּשְׁלֹשִׁים בָּנוֹת הֵבִיא לְבָנָיו מִן־הַחוּץ וַיִּשְׁפֹּט אֶת־יִשְׂרָאֵל שֶׁבַע שָׁנִים׃}
}
{
	\eX{
		He had thirty sons, and he married off thirty daughters outside
		the clan and brought in thirty girls from outside the clan for his
		sons. He led Israel seven years.
	}
}
{
}

\Verse{10}
{
	\hX{וַיָּמת אִבְצָן וַיִּקָּבֵר בְּבֵית לָחֶם׃}
}
{
	\eX{Then Ibzan died and was buried in Bethlehem.}
}
{
}

\Verse{11}
{
	\hX{וַיִּשְׁפֹּט אַחֲרָיו אֶת־יִשְׂרָאֵל אֵילוֹן הַזְּבוּלֹנִי וַיִּשְׁפֹּט אֶת־יִשְׂרָאֵל עֶשֶׂר שָׁנִים׃}
}
{
	\eX{
		After him, Elon the Zebulunite led Israel; he led Israel for ten
		years.
	}
}
{
}

\Verse{12}
{
	\hX{וַיָּמת אֵילוֹן הַזְּבוּלֹנִי וַיִּקָּבֵר בְּאַיָּלוֹן בְּאֶרֶץ זְבוּלֻן׃}
}
{
	\eX{
		Then Elon the Zebulunite died and was buried in Aijalon, in the
		territory of Zebulun.
	}
}
{
}

\Verse{13}
{
	\hX{וַיִּשְׁפֹּט אַחֲרָיו אֶת־יִשְׂרָאֵל עַבְדּוֹן בֶּן־הִלֵּל הַפִּרְעָתוֹנִי׃}
}
{
	\eX{After him, Abdon son of Hillel the Pirathonite led Israel.}
}
{
}

\Verse{14}
{
	\hX{וַיְהִי־לוֹ אַרְבָּעִים בָּנִים וּשְׁלֹשִׁים בְּנֵי בָנִים רֹכְבִים עַל־שִׁבְעִים עֲיָרִם וַיִּשְׁפֹּט אֶת־יִשְׂרָאֵל שְׁמֹנֶה שָׁנִים׃}
}
{
	\eX{
		He had forty sons and thirty grandsons, who rode on seventy
		jackasses. He led Israel for eight years.
	}
}
{
}

\Verse{15}
{
	\hX{וַיָּמת עַבְדּוֹן בֶּן־הִלֵּל הַפִּרְעָתוֹנִי וַיִּקָּבֵר בְּפִרְעָתוֹן בְּאֶרֶץ אֶפְרַיִם בְּהַר הָעֲמָלֵקִי׃}
}
{
	\eX{
		Then Abdon son of Hillel the Pirathonite died. He was buried in
		Pirathon, in the territory of Ephraim, on the hill of the
		Amalekites.
	}
}
{
}
