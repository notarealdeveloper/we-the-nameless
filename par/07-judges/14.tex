\Chapter{14}

\Verse{1}
{
	\hJ{וַיֵּרֶד שִׁמְשׁוֹן תִּמְנָתָה וַיַּרְא אִשָּׁה בְּתִמְנָתָה מִבְּנוֹת פְּלִשְׁתִּים׃}
}
{
	\eJ{
		Once Samson went down to Timnah; and while in Timnah, he noticed a
		girl among the Philistine women.
	}
}
{
}

\Verse{2}
{
	\hJ{וַיַּעַל וַיַּגֵּד לְאָבִיו וּלְאִמּוֹ וַיֹּאמֶר אִשָּׁה רָאִיתִי בְתִמְנָתָה מִבְּנוֹת פְּלִשְׁתִּים וְעַתָּה קְחוּ־אוֹתָהּ לִי לְאִשָּׁה׃}
}
{
	\eJ{
		On his return, he told his father and mother, “I noticed one of
		the Philistine women in Timnah; please get her for me as a wife.”
	}
}
{
}

\Verse{3}
{
	\hJ{
		וַיֹּאמֶר לוֹ אָבִיו וְאִמּוֹ הַאֵין בִּבְנוֹת אַחֶיךָ וּבְכל־עַמִּי אִשָּׁה כִּי־אַתָּה הוֹלֵךְ לָקַחַת אִשָּׁה מִפְּלִשְׁתִּים הָעֲרֵלִים וַיֹּאמֶר שִׁמְשׁוֹן אֶל־אָבִיו אוֹתָהּ
		קַח־לִי כִּי־הִיא יָשְׁרָה בְעֵינָי׃
	}
}
{
	\eJ{
		His father and mother said to him, “Is there no one among the
		daughters of your own kinsmen and among all our people, that you
		must go and take a wife from the uncircumcised Philistines?” But
		Samson answered his father, “Get me that one, for she is the one
		that pleases me.”
	}
}
{
}

\Verse{4}
{
	\hJ{וְאָבִיו וְאִמּוֹ לֹא יָדְעוּ כִּי מֵיְהֹוָה הִיא כִּי־תֹאֲנָה הוּא־מְבַקֵּשׁ מִפְּלִשְׁתִּים וּבָעֵת הַהִיא פְּלִשְׁתִּים מֹשְׁלִים בְּיִשְׂרָאֵל׃}
}
{
	\eJ{
		His father and mother did not realize that this was YHWH’s doing:
		He was seeking a pretext against the Philistines, for the
		Philistines were ruling over Israel at that time.
	}
}
{
}

\Verse{5}
{
	\hJ{וַיֵּרֶד שִׁמְשׁוֹן וְאָבִיו וְאִמּוֹ תִּמְנָתָה וַיָּבֹאוּ עַד־כַּרְמֵי תִמְנָתָה וְהִנֵּה כְּפִיר אֲרָיוֹת שֹׁאֵג לִקְרָאתוֹ׃}
}
{
	\eJ{
		So Samson and his father and mother went down to Timnah. When he
		came to the vineyards of Timnah [for the first time], a full-grown
		lion came roaring at him.
	}
}
{
}

\Verse{6}
{
	\hJ{וַתִּצְלַח עָלָיו רוּחַ יְהֹוָה וַיְשַׁסְּעֵהוּ כְּשַׁסַּע הַגְּדִי וּמְאוּמָה אֵין בְּיָדוֹ וְלֹא הִגִּיד לְאָבִיו וּלְאִמּוֹ אֵת אֲשֶׁר עָשָׂה׃}
}
{
	\eJ{
		The spirit of YHWH gripped him, and he tore him asunder with his
		bare hands as one might tear a kid asunder; but he did not tell
		his father and mother what he had done.
	}
}
{
}

\Verse{7}
{
	\hJ{וַיֵּרֶד וַיְדַבֵּר לָאִשָּׁה וַתִּישַׁר בְּעֵינֵי שִׁמְשׁוֹן׃}
}
{
	\eJ{
		Then he went down and spoke to the woman, and she pleased Samson.
	}
}
{
}

\Verse{8}
{
	\hJ{וַיָּשׁב מִיָּמִים לְקַחְתָּהּ וַיָּסַר לִרְאוֹת אֵת מַפֶּלֶת הָאַרְיֵה וְהִנֵּה עֲדַת דְּבוֹרִים בִּגְוִיַּת הָאַרְיֵה וּדְבָשׁ׃}
}
{
	\eJ{
		Returning the following year to marry her, he turned aside to look
		at the remains of the lion; and in the lion’s skeleton he found a
		swarm of bees, and honey.
	}
}
{
}

\Verse{9}
{
	\hJ{וַיִּרְדֵּהוּ אֶל־כַּפָּיו וַיֵּלֶךְ הָלוֹךְ וְאָכֹל וַיֵּלֶךְ אֶל־אָבִיו וְאֶל־אִמּוֹ וַיִּתֵּן לָהֶם וַיֹּאכֵלוּ וְלֹא־הִגִּיד לָהֶם כִּי מִגְּוִיַּת הָאַרְיֵה רָדָה הַדְּבָשׁ׃}
}
{
	\eJ{
		He scooped it into his palms and ate it as he went along. When he
		rejoined his father and mother, he gave them some and they ate it;
		but he did not tell them that he had scooped the honey out of a
		lion’s skeleton.
	}
}
{
}

\Verse{10}
{
	\hJ{וַיֵּרֶד אָבִיהוּ אֶל־הָאִשָּׁה וַיַּעַשׂ שָׁם שִׁמְשׁוֹן מִשְׁתֶּה כִּי כֵּן יַעֲשׂוּ הַבַּחוּרִים׃}
}
{
	\eJ{
		So his father came down to the woman, and Samson made a feast
		there, as young men used to do.
	}
}
{
}

\Verse{11}
{
	\hJ{וַיְהִי כִּרְאוֹתָם אוֹתוֹ וַיִּקְחוּ שְׁלֹשִׁים מֵרֵעִים וַיִּהְיוּ אִתּוֹ׃}
}
{
	\eJ{
		When they saw him, they designated thirty companions to be with
		him.
	}
}
{
}

\Verse{12}
{
	\hJ{
		וַיֹּאמֶר לָהֶם שִׁמְשׁוֹן אָחוּדָה־נָּא לָכֶם חִידָה אִם־הַגֵּד תַּגִּידוּ אוֹתָהּ לִי שִׁבְעַת יְמֵי הַמִּשְׁתֶּה וּמְצָאתֶם וְנָתַתִּי לָכֶם שְׁלֹשִׁים סְדִינִים וּשְׁלֹשִׁים
		חֲלִפֹת בְּגָדִים׃
	}
}
{
	\eJ{
		Then Samson said to them, “Let me propound a riddle to you. If you
		can give me the right answer during the seven days of the feast, I
		shall give you thirty linen tunics and thirty sets of clothing;
	}
}
{
}

\Verse{13}
{
	\hJ{וְאִם־לֹא תוּכְלוּ לְהַגִּיד לִי וּנְתַתֶּם אַתֶּם לִי שְׁלֹשִׁים סְדִינִים וּשְׁלֹשִׁים חֲלִיפוֹת בְּגָדִים וַיֹּאמְרוּ לוֹ חוּדָה חִידָתְךָ וְנִשְׁמָעֶנָּה׃}
}
{
	\eJ{
		but if you are not able to tell it to me, you must give me thirty
		linen tunics and thirty sets of clothing.” And they said to him,
		“Ask your riddle and we will listen.”
	}
}
{
}

\Verse{14}
{
	\hJ{וַיֹּאמֶר לָהֶם מֵהָאֹכֵל יָצָא מַאֲכָל וּמֵעַז יָצָא מָתוֹק וְלֹא יָכְלוּ לְהַגִּיד הַחִידָה שְׁלֹשֶׁת יָמִים׃}
}
{
	\eJ{
		So he said to them: “Out of the eater came something to eat, Out

		answer the riddle.
	}
}

\Verse{15}
{
	\hJ{
		וַיְהִי בַּיּוֹם הַשְּׁבִיעִי וַיֹּאמְרוּ לְאֵשֶׁת־שִׁמְשׁוֹן פַּתִּי אֶת־אִישֵׁךְ וְיַגֶּד־לָנוּ אֶת־הַחִידָה פֶּן־נִשְׂרֹף אוֹתָךְ וְאֶת־בֵּית אָבִיךְ בָּאֵשׁ הַלְירְשֵׁנוּ
		קְרָאתֶם לָנוּ הֲלֹא׃
	}
}
{
	\eJ{
		On the seventh day, they said to Samson’s wife, “Coax your husband
		to provide us with the answer to the riddle; else we shall put you
		and your father’s household to the fire; have you invited us here
		in order to impoverish us?”
	}
}
{
}

\Verse{16}
{
	\hJ{
		וַתֵּבְךְּ אֵשֶׁת שִׁמְשׁוֹן עָלָיו וַתֹּאמֶר רַק־שְׂנֵאתַנִי וְלֹא אֲהַבְתָּנִי הַחִידָה חַדְתָּ לִבְנֵי עַמִּי וְלִי לֹא הִגַּדְתָּה וַיֹּאמֶר לָהּ הִנֵּה לְאָבִי וּלְאִמִּי לֹא
		הִגַּדְתִּי וְלָךְ אַגִּיד׃
	}
}
{
	\eJ{
		Then Samson’s wife harassed him with tears, and she said, “You
		really hate me, you don’t love me. You asked my countrymen a
		riddle, and you didn’t tell me the answer.” He replied, “I haven’t
		even told my father and mother; shall I tell you?”
	}
}
{
}

\Verse{17}
{
	\hJ{וַתֵּבְךְּ עָלָיו שִׁבְעַת הַיָּמִים אֲשֶׁר־הָיָה לָהֶם הַמִּשְׁתֶּה וַיְהִי בַּיּוֹם הַשְּׁבִיעִי וַיַּגֶּד־לָהּ כִּי הֱצִיקַתְהוּ וַתַּגֵּד הַחִידָה לִבְנֵי עַמָּהּ׃}
}
{
	\eJ{
		During the rest of the seven days of the feast she continued to
		harass him with her tears, and on the seventh day he told her,
		because she nagged him so. And she explained the riddle to her
		countrymen.
	}
}
{
}

\Verse{18}
{
	\hJ{
		וַיֹּאמְרוּ לוֹ אַנְשֵׁי הָעִיר בַּיּוֹם הַשְּׁבִיעִי בְּטֶרֶם יָבֹא הַחַרְסָה מַה־מָּתוֹק מִדְּבַשׁ וּמֶה עַז מֵאֲרִי וַיֹּאמֶר לָהֶם לוּלֵא חֲרַשְׁתֶּם בְּעֶגְלָתִי לֹא מְצָאתֶם
		חִידָתִי׃
	}
}
{
	\eJ{
		On the seventh day, before the sunset, the townsmen said to him:
		“What is sweeter than honey, And what is stronger than a lion?” He
		responded: “Had you not plowed with my heifer, You would not have
		guessed my riddle!”
	}
}
{
}

\Verse{19}
{
	\hJ{
		וַתִּצְלַח עָלָיו רוּחַ יְהֹוָה וַיֵּרֶד אַשְׁקְלוֹן וַיַּךְ מֵהֶם שְׁלֹשִׁים אִישׁ וַיִּקַּח אֶת־חֲלִיצוֹתָם וַיִּתֵּן הַחֲלִיפוֹת לְמַגִּידֵי הַחִידָה וַיִּחַר אַפּוֹ וַיַּעַל
		בֵּית אָבִיהוּ׃
	}
}
{
	\eJ{
		The spirit of YHWH gripped him. He went down to Ashkelon and
		killed thirty of its men. He stripped them and gave the sets of
		clothing to those who had answered the riddle. And he left in a
		rage for his father’s house.
	}
}
{
}
