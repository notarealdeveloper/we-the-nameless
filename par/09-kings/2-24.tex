\Chapter{24}

\Verse{1}
{
	\hX{בְּיָמָיו עָלָה נְבֻכַדְנֶאצַּר מֶלֶךְ בָּבֶל וַיְהִי־לוֹ יְהוֹיָקִים עֶבֶד שָׁלֹשׁ שָׁנִים וַיָּשׁב וַיִּמְרד־בּוֹ׃}
}
{
	\eX{
		In his days, King Nebuchadnezzar of Babylon came up, and Jehoiakim
		became his vassal for three years. Then he turned and rebelled
		against him.
	}
}
{
}

\Verse{2}
{
	\hX{
		וַיְשַׁלַּח יְהֹוָה בּוֹ אֶת־גְּדוּדֵי כַשְׂדִּים וְאֶת־גְּדוּדֵי אֲרָם וְאֵת גְּדוּדֵי מוֹאָב וְאֵת גְּדוּדֵי בְנֵי־עַמּוֹן וַיְשַׁלְּחֵם בִּיהוּדָה לְהַאֲבִידוֹ כִּדְבַר יְהֹוָה
		אֲשֶׁר דִּבֶּר בְּיַד עֲבָדָיו הַנְּבִיאִים׃
	}
}
{
	\eX{
		YHWH let loose against him the raiding bands of the Chaldeans,
		Arameans, Moabites, and Ammonites; He let them loose against Judah
		to destroy it, in accordance with the word that YHWH had spoken
		through His servants the prophets.
	}
}
{
}

\Verse{3}
{
	\hX{אַךְ עַל־פִּי יְהֹוָה הָיְתָה בִּיהוּדָה לְהָסִיר מֵעַל פָּנָיו בְּחַטֹּאת מְנַשֶּׁה כְּכֹל אֲשֶׁר עָשָׂה׃}
}
{
	\eX{
		All this befell Judah at the command of YHWH, who banished [them]
		from His presence because of all the sins that Manasseh had
		committed,
	}
}
{
}

\Verse{4}
{
	\hX{וְגַם דַּם־הַנָּקִי אֲשֶׁר שָׁפָךְ וַיְמַלֵּא אֶת־יְרוּשָׁלַ͏ִם דָּם נָקִי וְלֹא־אָבָה יְהֹוָה לִסְלֹחַ׃}
}
{
	\eX{
		and also because of the blood of the innocent that he shed. For he
		filled Jerusalem with the blood of the innocent, and YHWH would
		not forgive.
	}
}
{
}

\Verse{5}
{
	\hX{וְיֶתֶר דִּבְרֵי יְהוֹיָקִים וְכל־אֲשֶׁר עָשָׂה הֲלֹא־הֵם כְּתוּבִים עַל־סֵפֶר דִּבְרֵי הַיָּמִים לְמַלְכֵי יְהוּדָה׃}
}
{
	\eX{
		The other events of Jehoiakim’s reign, and all of his actions, are
		recorded in the Annals of the Kings of Judah.
	}
}
{
}

\Verse{6}
{
	\hX{וַיִּשְׁכַּב יְהוֹיָקִים עִם־אֲבֹתָיו וַיִּמְלֹךְ יְהוֹיָכִין בְּנוֹ תַּחְתָּיו׃}
}
{
	\eX{
		Jehoiakim slept with his fathers, and his son Jehoiachin succeeded
		him as king.
	}
}
{
}

\Verse{7}
{
	\hX{וְלֹא־הֹסִיף עוֹד מֶלֶךְ מִצְרַיִם לָצֵאת מֵאַרְצוֹ כִּי־לָקַח מֶלֶךְ בָּבֶל מִנַּחַל מִצְרַיִם עַד־נְהַר־פְּרָת כֹּל אֲשֶׁר הָיְתָה לְמֶלֶךְ מִצְרָיִם׃}
}
{
	\eX{
		The king of Egypt did not venture out of his country again, for
		the king of Babylon had seized all the land that had belonged to
		the king of Egypt, from the Wadi of Egypt to the River Euphrates.
	}
}
{
}

\Verse{8}
{
	\hX{בֶּן־שְׁמֹנֶה עֶשְׂרֵה שָׁנָה יְהוֹיָכִין בְּמלְכוֹ וּשְׁלֹשָׁה חֳדָשִׁים מָלַךְ בִּירוּשָׁלָ͏ִם וְשֵׁם אִמּוֹ נְחֻשְׁתָּא בַת־אֶלְנָתָן מִירוּשָׁלָ͏ִם׃}
}
{
	\eX{
		Jehoiachin was eighteen years old when he became king, and he
		reigned three months in Jerusalem; his mother’s name was Nehushta
		daughter of Elnathan of Jerusalem.
	}
}
{
}

\Verse{9}
{
	\hX{וַיַּעַשׂ הָרַע בְּעֵינֵי יְהֹוָה כְּכֹל אֲשֶׁר־עָשָׂה אָבִיו׃}
}
{
	\eX{
		He did what was displeasing to YHWH, just as his father had done.
	}
}
{
}

\Verse{10}
{
	\hX{בָּעֵת הַהִיא (עלה) [עָלוּ] עַבְדֵי נְבֻכַדְנֶאצַּר מֶלֶךְ־בָּבֶל יְרוּשָׁלָ͏ִם וַתָּבֹא הָעִיר בַּמָּצוֹר׃}
}
{
	\eX{
		At that time, the troops of King Nebuchadnezzar of Babylon marched
		against Jerusalem, and the city came under siege.
	}
}
{
	Qere Ketiv.
}

\Verse{11}
{
	\hX{וַיָּבֹא נְבֻכַדְנֶאצַּר מֶלֶךְ־בָּבֶל עַל־הָעִיר וַעֲבָדָיו צָרִים עָלֶיהָ׃}
}
{
	\eX{
		King Nebuchadnezzar of Babylon advanced against the city while his
		troops were besieging it.
	}
}
{
}

\Verse{12}
{
	\hX{וַיֵּצֵא יְהוֹיָכִין מֶלֶךְ־יְהוּדָה עַל־מֶלֶךְ בָּבֶל הוּא וְאִמּוֹ וַעֲבָדָיו וְשָׂרָיו וְסָרִיסָיו וַיִּקַּח אֹתוֹ מֶלֶךְ בָּבֶל בִּשְׁנַת שְׁמֹנֶה לְמלְכוֹ׃}
}
{
	\eX{
		Thereupon King Jehoiachin of Judah, along with his mother, and his
		courtiers, commanders, and officers, surrendered to the king of
		Babylon. The king of Babylon took him captive in the eighth year
		of his reign.
	}
}
{
}

\Verse{13}
{
	\hX{
		וַיּוֹצֵא מִשָּׁם אֶת־כּל־אוֹצְרוֹת בֵּית יְהֹוָה וְאוֹצְרוֹת בֵּית הַמֶּלֶךְ וַיְקַצֵּץ אֶת־כּל־כְּלֵי הַזָּהָב אֲשֶׁר עָשָׂה שְׁלֹמֹה מֶלֶךְ־יִשְׂרָאֵל בְּהֵיכַל יְהֹוָה
		כַּאֲשֶׁר דִּבֶּר יְהֹוָה׃
	}
}
{
	\eX{
		He carried off from Jerusalem all the treasures of the House of
		YHWH and the treasures of the royal palace; he stripped off all
		the golden decorations in the Temple of YHWH—which King Solomon of
		Israel had made—as YHWH had warned.
	}
}
{
}

\Verse{14}
{
	\hX{
		וְהִגְלָה אֶת־כּל־יְרוּשָׁלַ͏ִם וְאֶת־כּל־הַשָּׂרִים וְאֵת כּל־גִּבּוֹרֵי הַחַיִל (עשרה) [עֲשֶׂרֶת] אֲלָפִים גּוֹלֶה וְכל־הֶחָרָשׁ וְהַמַּסְגֵּר לֹא נִשְׁאַר זוּלַת דַּלַּת
		עַם־הָאָרֶץ׃
	}
}
{
	\eX{
		He exiled all of Jerusalem: all the commanders and all the
		warriors—ten thousand exiles—as well as all the craftsmen and
		smiths; only the poorest people in the land were left.
	}
}
{
	Qere Ketiv.
}

\Verse{15}
{
	\hX{וַיֶּגֶל אֶת־יְהוֹיָכִין בָּבֶלָה וְאֶת־אֵם הַמֶּלֶךְ וְאֶת־נְשֵׁי הַמֶּלֶךְ וְאֶת־סָרִיסָיו וְאֵת (אולי) [אֵילֵי] הָאָרֶץ הוֹלִיךְ גּוֹלָה מִירוּשָׁלַ͏ִם בָּבֶלָה׃}
}
{
	\eX{
		He deported Jehoiachin to Babylon; and the king’s mother and wives
		and officers and the notables of the land were brought as exiles
		from Jerusalem to Babylon.
	}
}
{
	Qere Ketiv.
}

\Verse{16}
{
	\hX{וְאֵת כּל־אַנְשֵׁי הַחַיִל שִׁבְעַת אֲלָפִים וְהֶחָרָשׁ וְהַמַּסְגֵּר אֶלֶף הַכֹּל גִּבּוֹרִים עֹשֵׂי מִלְחָמָה וַיְבִיאֵם מֶלֶךְ־בָּבֶל גּוֹלָה בָּבֶלָה׃}
}
{
	\eX{
		All the able men, to the number of seven thousand—all of them
		warriors, trained for battle—and a thousand craftsmen and smiths
		were brought to Babylon as exiles by the king of Babylon.
	}
}
{
}

\Verse{17}
{
	\hX{וַיַּמְלֵךְ מֶלֶךְ־בָּבֶל אֶת־מַתַּנְיָה דֹדוֹ תַּחְתָּיו וַיַּסֵּב אֶת־שְׁמוֹ צִדְקִיָּהוּ׃}
}
{
	\eX{
		And the king of Babylon appointed Mattaniah, Jehoiachin’s uncle,
		king in his place, changing his name to Zedekiah.
	}
}
{
}

\Verse{18}
{
	\hX{בֶּן־עֶשְׂרִים וְאַחַת שָׁנָה צִדְקִיָּהוּ בְמלְכוֹ וְאַחַת עֶשְׂרֵה שָׁנָה מָלַךְ בִּירוּשָׁלָ͏ִם וְשֵׁם אִמּוֹ (חמיטל) [חֲמוּטַל] בַּת־יִרְמְיָהוּ מִלִּבְנָה׃}
}
{
	\eX{
		Zedekiah was twenty-one years old when he became king, and he
		reigned eleven years in Jerusalem; his mother’s name was Hamutal
		daughter of Jeremiah of Libnah.
	}
}
{
	Qere Ketiv.
}

\Verse{19}
{
	\hX{וַיַּעַשׂ הָרַע בְּעֵינֵי יְהֹוָה כְּכֹל אֲשֶׁר־עָשָׂה יְהוֹיָקִים׃}
}
{
	\eX{
		He did what was displeasing to YHWH, just as Jehoiakim had done.
	}
}
{
}

\Verse{20}
{
	\hX{כִּי עַל־אַף יְהֹוָה הָיְתָה בִירוּשָׁלַ͏ִם וּבִיהוּדָה עַד־הִשְׁלִכוֹ אֹתָם מֵעַל פָּנָיו וַיִּמְרֹד צִדְקִיָּהוּ בְּמֶלֶךְ בָּבֶל׃}
}
{
	\eX{
		Indeed, Jerusalem and Judah were a cause of anger for YHWH, so
		that He cast them out of His presence. Zedekiah rebelled against
		the king of Babylon.
	}
}
{
}
