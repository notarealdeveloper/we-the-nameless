\Verse{29}
{
	\hX{וַיִּשָּׂא הַנָּבִיא אֶת־נִבְלַת אִישׁ־הָאֱלֹהִים וַיַּנִּחֵהוּ אֶל־הַחֲמוֹר וַיְשִׁיבֵהוּ וַיָּבֹא אֶל־עִיר הַנָּבִיא הַזָּקֵן לִסְפֹּד וּלְקבְרוֹ׃}
}
{
	\eX{
		The prophet lifted up the corpse of the man of God, laid it on the
		ass, and brought it back; it was brought to the town of the old
		prophet for lamentation and burial.
	}
}
{
}

\Verse{30}
{
	\hX{וַיַּנַּח אֶת־נִבְלָתוֹ בְּקִבְרוֹ וַיִּסְפְּדוּ עָלָיו הוֹי אָחִי׃}
}
{
	\eX{
		He laid the corpse in his own burial place; and they lamented over
		it, “Alas, my brother!”
	}
}
{
}

\Verse{31}
{
	\hX{וַיְהִי אַחֲרֵי קבְרוֹ אֹתוֹ וַיֹּאמֶר אֶל־בָּנָיו לֵאמֹר בְּמוֹתִי וּקְבַרְתֶּם אֹתִי בַּקֶּבֶר אֲשֶׁר אִישׁ הָאֱלֹהִים קָבוּר בּוֹ אֵצֶל עַצְמֹתָיו הַנִּיחוּ אֶת־עַצְמֹתָי׃}
}
{
	\eX{
		After burying him, he said to his sons, “When I die, bury me in
		the grave where the man of God lies buried; lay my bones beside
		his.
	}
}
{
}

\Verse{32}
{
	\hX{כִּי הָיֹה יִהְיֶה הַדָּבָר אֲשֶׁר קָרָא בִּדְבַר יְהֹוָה עַל־הַמִּזְבֵּחַ אֲשֶׁר בְּבֵית־אֵל וְעַל כּל־בָּתֵּי הַבָּמוֹת אֲשֶׁר בְּעָרֵי שֹׁמְרוֹן׃}
}
{
	\eX{
		For what he announced by the word of YHWH against the altar in
		Bethel, and against all the cult places in the towns of Samaria,
		shall surely come true.”
	}
}
{
}

\Verse{33}
{
	\hX{אַחַר הַדָּבָר הַזֶּה לֹא־שָׁב יָרבְעָם מִדַּרְכּוֹ הָרָעָה וַיָּשׁב וַיַּעַשׂ מִקְצוֹת הָעָם כֹּהֲנֵי בָמוֹת הֶחָפֵץ יְמַלֵּא אֶת־יָדוֹ וִיהִי כֹּהֲנֵי בָמוֹת׃}
}
{
	\eX{
		Even after this incident, Jeroboam did not turn back from his evil
		way, but kept on appointing priests for the shrines from the ranks
		of the people. He ordained as priests of the shrines any who so
		desired.
	}
}
{
}

\Verse{34}
{
	\hX{וַיְהִי בַּדָּבָר הַזֶּה לְחַטַּאת בֵּית יָרבְעָם וּלְהַכְחִיד וּלְהַשְׁמִיד מֵעַל פְּנֵי הָאֲדָמָה׃}
}
{
	\eX{
		Thereby the House of Jeroboam incurred guilt—to their utter
		annihilation from the face of the earth.
	}
}
{
