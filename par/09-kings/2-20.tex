\Chapter{20}

\Verse{1}
{
	\hX{בַּיָּמִים הָהֵם חָלָה חִזְקִיָּהוּ לָמוּת וַיָּבֹא אֵלָיו יְשַׁעְיָהוּ בֶן־אָמוֹץ הַנָּבִיא וַיֹּאמֶר אֵלָיו כֹּה־אָמַר יְהֹוָה צַו לְבֵיתֶךָ כִּי מֵת אַתָּה וְלֹא תִחְיֶה׃}
}
{
	\eX{
		In those days Hezekiah fell dangerously ill. The prophet Isaiah
		son of Amoz came and said to him, “Thus said YHWH: Set your
		affairs in order, for you are going to die; you will not get
		well.”
	}
}
{
}

\Verse{2}
{
	\hX{וַיַּסֵּב אֶת־פָּנָיו אֶל־הַקִּיר וַיִּתְפַּלֵּל אֶל־יְהֹוָה לֵאמֹר׃}
}
{
	\eX{
		Thereupon Hezekiah turned his face to the wall and prayed to YHWH.
		He said,
	}
}
{
}

\Verse{3}
{
	\hX{אָנָּה יְהֹוָה זְכר־נָא אֵת אֲשֶׁר הִתְהַלַּכְתִּי לְפָנֶיךָ בֶּאֱמֶת וּבְלֵבָב שָׁלֵם וְהַטּוֹב בְּעֵינֶיךָ עָשִׂיתִי וַיֵּבְךְּ חִזְקִיָּהוּ בְּכִי גָדוֹל׃}
}
{
	\eX{
		“Please, O LORD, remember how I have walked before You sincerely
		and wholeheartedly, and have done what is pleasing to You.” And
		Hezekiah wept profusely.
	}
}
{
}

\Verse{5}
{
	\hX{
		שׁוּב וְאָמַרְתָּ אֶל־חִזְקִיָּהוּ נְגִיד־עַמִּי כֹּה־אָמַר יְהֹוָה אֱלֹהֵי דָּוִד אָבִיךָ שָׁמַעְתִּי אֶת־תְּפִלָּתֶךָ רָאִיתִי אֶת־דִּמְעָתֶךָ הִנְנִי רֹפֶא לָךְ בַּיּוֹם
		הַשְּׁלִישִׁי תַּעֲלֶה בֵּית יְהֹוָה׃
	}
}
{
	\eX{
		“Go back and say to Hezekiah, the ruler of My people: Thus said
		YHWH, the God of your father David: I have heard your prayer, I
		have seen your tears. I am going to heal you; on the third day you
		shall go up to the House of YHWH.
	}
}
{
}

\Verse{6}
{
	\hX{וְהֹסַפְתִּי עַל־יָמֶיךָ חֲמֵשׁ עֶשְׂרֵה שָׁנָה וּמִכַּף מֶלֶךְ־אַשּׁוּר אַצִּילְךָ וְאֵת הָעִיר הַזֹּאת וְגַנּוֹתִי עַל־הָעִיר הַזֹּאת לְמַעֲנִי וּלְמַעַן דָּוִד עַבְדִּי׃}
}
{
	\eX{
		And I will add fifteen years to your life. I will also rescue you
		and this city from the hands of the king of Assyria. I will
		protect this city for My sake and for the sake of My servant
		David.”—
	}
}
{
}

\Verse{7}
{
	\hX{וַיֹּאמֶר יְשַׁעְיָהוּ קְחוּ דְּבֶלֶת תְּאֵנִים וַיִּקְחוּ וַיָּשִׂימוּ עַל־הַשְּׁחִין וַיֶּחִי׃}
}
{
	\eX{
		Then Isaiah said, “Get a cake of figs.” And they got one, and they
		applied it to the rash, and he recovered.—
	}
}
{
}

\Verse{8}
{
	\hX{וַיֹּאמֶר חִזְקִיָּהוּ אֶל־יְשַׁעְיָהוּ מָה אוֹת כִּי־יִרְפָּא יְהֹוָה לִי וְעָלִיתִי בַּיּוֹם הַשְּׁלִישִׁי בֵּית יְהֹוָה׃}
}
{
	\eX{
		Hezekiah asked Isaiah, “What is the sign that YHWH will heal me
		and that I shall go up to the House of YHWH on the third day?”
	}
}
{
}

\Verse{9}
{
	\hX{וַיֹּאמֶר יְשַׁעְיָהוּ זֶה־לְּךָ הָאוֹת מֵאֵת יְהֹוָה כִּי יַעֲשֶׂה יְהֹוָה אֶת־הַדָּבָר אֲשֶׁר דִּבֵּר הָלַךְ הַצֵּל עֶשֶׂר מַעֲלוֹת אִם־יָשׁוּב עֶשֶׂר מַעֲלוֹת׃}
}
{
	\eX{
		Isaiah replied, “This is the sign for you from YHWH that YHWH will
		do the thing that He has promised: Shall the shadow advance ten
		steps or recede ten steps?”
	}
}
{
}

\Verse{10}
{
	\hX{וַיֹּאמֶר יְחִזְקִיָּהוּ נָקֵל לַצֵּל לִנְטוֹת עֶשֶׂר מַעֲלוֹת לֹא כִי יָשׁוּב הַצֵּל אֲחֹרַנִּית עֶשֶׂר מַעֲלוֹת׃}
}
{
	\eX{
		Hezekiah said, “It is easy for the shadow to lengthen ten steps,
		but not for the shadow to recede ten steps.”
	}
}
{
}

\Verse{11}
{
	\hX{וַיִּקְרָא יְשַׁעְיָהוּ הַנָּבִיא אֶל־יְהֹוָה וַיָּשֶׁב אֶת־הַצֵּל בַּמַּעֲלוֹת אֲשֶׁר יָרְדָה בְּמַעֲלוֹת אָחָז אֲחֹרַנִּית עֶשֶׂר מַעֲלוֹת׃}
}
{
	\eX{
		So the prophet Isaiah called to YHWH, and He made the shadow which

}
{
}

\Verse{12}
{
	\hX{בָּעֵת הַהִיא שָׁלַח בְּרֹאדַךְ בַּלְאֲדָן בֶּן־בַּלְאֲדָן מֶלֶךְ־בָּבֶל סְפָרִים וּמִנְחָה אֶל־חִזְקִיָּהוּ כִּי שָׁמַע כִּי חָלָה חִזְקִיָּהוּ׃}

{
}

\Verse{13}
{
	\hX{
		וַיִּשְׁמַע עֲלֵיהֶם חִזְקִיָּהוּ וַיַּרְאֵם אֶת־כּל־בֵּית נְכֹתֹה אֶת־הַכֶּסֶף וְאֶת־הַזָּהָב וְאֶת־הַבְּשָׂמִים וְאֵת שֶׁמֶן הַטּוֹב וְאֵת בֵּית כֵּלָיו וְאֵת כּל־אֲשֶׁר נִמְצָא
		בְּאוֹצְרֹתָיו לֹא־הָיָה דָבָר אֲשֶׁר לֹא־הֶרְאָם חִזְקִיָּהוּ בְּבֵיתוֹ וּבְכל־מֶמְשַׁלְתּוֹ׃
	}
}
{
	\eX{
		Hezekiah heard about them and he showed them all his
		treasure-house—the silver, the gold, the spices, and the fragrant
		oil—and his armory, and everything that was to be found in his
		storehouses. There was nothing in his palace or in all his realm
		that Hezekiah did not show them.
	}
}
{
}

\Verse{14}
{
	\hX{

		בָּאוּ מִבָּבֶל׃

}

	\eX{
		Then the prophet Isaiah came to King Hezekiah. “What,” he demanded
		of him, “did those men say to you? Where have they come to you

		from Babylon.”
	}
}
{
}
