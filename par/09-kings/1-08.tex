	\hX{בָּרוּךְ יְהֹוָה אֲשֶׁר נָתַן מְנוּחָה לְעַמּוֹ יִשְׂרָאֵל כְּכֹל אֲשֶׁר דִּבֵּר לֹא־נָפַל דָּבָר אֶחָד מִכֹּל דְּבָרוֹ הַטּוֹב אֲשֶׁר דִּבֶּר בְּיַד מֹשֶׁה עַבְדּוֹ׃}
}
{
	\eX{
		“Praised be YHWH who has granted a haven to His people Israel,
		just as He promised; not a single word has failed of all the
		gracious promises that He made through His servant Moses.
	}
}
{
}

\Verse{57}
{
	\hX{יְהִי יְהֹוָה אֱלֹהֵינוּ עִמָּנוּ כַּאֲשֶׁר הָיָה עִם־אֲבֹתֵינוּ אַל־יַעַזְבֵנוּ וְאַל־יִטְּשֵׁנוּ׃}
}
{
	\eX{
		May YHWH our God be with us, as He was with our fathers. May He
		never abandon or forsake us.
	}
}
{
}

\Verse{58}
{
	\hX{לְהַטּוֹת לְבָבֵנוּ אֵלָיו לָלֶכֶת בְּכל־דְּרָכָיו וְלִשְׁמֹר מִצְוֺתָיו וְחֻקָּיו וּמִשְׁפָּטָיו אֲשֶׁר צִוָּה אֶת־אֲבֹתֵינוּ׃}
}
{
	\eX{
		May He incline our hearts to Him, that we may walk in all His ways
		and keep the commandments, the laws, and the rules, which He
		enjoined upon our fathers.
	}
}
{
}

\Verse{59}
{
	\hX{
		וְיִהְיוּ דְבָרַי אֵלֶּה אֲשֶׁר הִתְחַנַּנְתִּי לִפְנֵי יְהֹוָה קְרֹבִים אֶל־יְהֹוָה אֱלֹהֵינוּ יוֹמָם וָלָיְלָה לַעֲשׂוֹת מִשְׁפַּט עַבְדּוֹ וּמִשְׁפַּט עַמּוֹ יִשְׂרָאֵל
		דְּבַר־יוֹם בְּיוֹמוֹ׃
	}
}
{
	\eX{
		And may these words of mine, which I have offered in supplication
		before YHWH, be close to YHWH our God day and night, that He may
		provide for His servant and for His people Israel, according to
		each day’s needs—
	}
}
{
}

\Verse{60}
{
	\hX{לְמַעַן דַּעַת כּל־עַמֵּי הָאָרֶץ כִּי יְהֹוָה הוּא הָאֱלֹהִים אֵין עוֹד׃}
}
{
	\eX{
		to the end that all the peoples of the earth may know that YHWH
		alone is God, there is no other.
	}
}
{
}

\Verse{61}
{
	\hX{וְהָיָה לְבַבְכֶם שָׁלֵם עִם יְהֹוָה אֱלֹהֵינוּ לָלֶכֶת בְּחֻקָּיו וְלִשְׁמֹר מִצְוֺתָיו כַּיּוֹם הַזֶּה׃}
}
{
	\eX{
		And may you be wholehearted with YHWH our God, to walk in His ways
		and keep His commandments, even as now.”
	}
}
{
}

\Verse{62}
{
	\hX{וְהַמֶּלֶךְ וְכל־יִשְׂרָאֵל עִמּוֹ זֹבְחִים זֶבַח לִפְנֵי יְהֹוָה׃}
}
{
	\eX{
		The king and all Israel with him offered sacrifices before YHWH.
	}
}
{
}

\Verse{63}
{
	\hX{
		וַיִּזְבַּח שְׁלֹמֹה אֵת זֶבַח הַשְּׁלָמִים אֲשֶׁר זָבַח לַיהֹוָה בָּקָר עֶשְׂרִים וּשְׁנַיִם אֶלֶף וְצֹאן מֵאָה וְעֶשְׂרִים אָלֶף וַיַּחְנְכוּ אֶת־בֵּית יְהֹוָה הַמֶּלֶךְ
		וְכל־בְּנֵי יִשְׂרָאֵל׃
	}
}
{
	\eX{
		Solomon offered 22,000 oxen and 120,000 sheep as sacrifices of
		well-being to YHWH. Thus the king and all the Israelites dedicated
		the House of YHWH.
	}
}
{
}

\Verse{64}
{
	\hX{
		בַּיּוֹם הַהוּא קִדַּשׁ הַמֶּלֶךְ אֶת־תּוֹךְ הֶחָצֵר אֲשֶׁר לִפְנֵי בֵית־יְהֹוָה כִּי־עָשָׂה שָׁם אֶת־הָעֹלָה וְאֶת־הַמִּנְחָה וְאֵת חֶלְבֵי הַשְּׁלָמִים כִּי־מִזְבַּח הַנְּחֹשֶׁת
		אֲשֶׁר לִפְנֵי יְהֹוָה קָטֹן מֵהָכִיל אֶת־הָעֹלָה וְאֶת־הַמִּנְחָה וְאֵת חֶלְבֵי הַשְּׁלָמִים׃
	}
}
{
	\eX{
		That day the king consecrated the center of the court that was in
		front of the House of YHWH. For it was there that he presented the
		burnt offerings, the meal offerings, and the fat parts of the
		offerings of well-being, because the bronze altar that was before
		YHWH was too small to hold the burnt offerings, the meal
		offerings, and the fat parts of the offerings of well-being.
	}
}
{
}

\Verse{65}
{
	\hX{
		וַיַּעַשׂ שְׁלֹמֹה בָעֵת־הַהִיא אֶת־הֶחָג וְכל־יִשְׂרָאֵל עִמּוֹ קָהָל גָּדוֹל מִלְּבוֹא חֲמָת עַד־נַחַל מִצְרַיִם לִפְנֵי יְהֹוָה אֱלֹהֵינוּ שִׁבְעַת יָמִים וְשִׁבְעַת יָמִים
		אַרְבָּעָה עָשָׂר יוֹם׃
	}
}
{
	\eX{
		So Solomon and all Israel with him—a great assemblage, [coming]
		from Lebo-hamath to the Wadi of Egypt—observed the Feast at that
		time before YHWH our God, seven days and again seven days,
		fourteen days in all.
	}
}
{
}

\Verse{66}
{
	\hX{
		בַּיּוֹם הַשְּׁמִינִי שִׁלַּח אֶת־הָעָם וַיְבָרְכוּ אֶת־הַמֶּלֶךְ וַיֵּלְכוּ לְאהֳלֵיהֶם שְׂמֵחִים וְטוֹבֵי לֵב עַל כּל־הַטּוֹבָה אֲשֶׁר עָשָׂה יְהֹוָה לְדָוִד עַבְדּוֹ
		וּלְיִשְׂרָאֵל עַמּוֹ׃
	}
}
{
	\eX{
		On the eighth day he let the people go. They bade the king
		good-bye and went to their homes, joyful and glad of heart over
		all the goodness that YHWH had shown to His servant David and His
		people Israel.
	}
}
{
}
