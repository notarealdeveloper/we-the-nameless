	}
}
{
	\eX{

		of Judah and all the inhabitants of Jerusalem, and the priests and
		prophets—all the people, young and old. And he read to them the
		entire text of the covenant scroll which had been found in the
		House of YHWH.

}
{

	\hX{כִּי אִם־בִּשְׁמֹנֶה עֶשְׂרֵה שָׁנָה לַמֶּלֶךְ יֹאשִׁיָּהוּ נַעֲשָׂה הַפֶּסַח הַזֶּה לַיהֹוָה בִּירוּשָׁלָ͏ִם׃}
}
{
	\eX{
		Only in the eighteenth year of King Josiah was such a passover
		sacrifice offered in that manner to YHWH in Jerusalem.
	}
}
{
}

\Verse{24}
{
	\hX{
		וְגַם אֶת־הָאֹבוֹת וְאֶת־הַיִּדְּעֹנִים וְאֶת־הַתְּרָפִים וְאֶת־הַגִּלֻּלִים וְאֵת כּל־הַשִּׁקֻּצִים אֲשֶׁר נִרְאוּ בְּאֶרֶץ יְהוּדָה וּבִירוּשָׁלַ͏ִם בִּעֵר יֹאשִׁיָּהוּ לְמַעַן
		הָקִים אֶת־דִּבְרֵי הַתּוֹרָה הַכְּתֻבִים עַל־הַסֵּפֶר אֲשֶׁר מָצָא חִלְקִיָּהוּ הַכֹּהֵן בֵּית יְהֹוָה׃
	}
}
{
	\eX{
		Josiah also did away with the necromancers and the mediums, the
		idols and the fetishes—all the detestable things that were to be
		seen in the land of Judah and Jerusalem. Thus he fulfilled the
		terms of the Teaching recorded in the scroll that the priest
		Hilkiah had found in the House of YHWH.
	}
}
{
}

\Verse{25}
{
	\hX{וְכָמֹהוּ לֹא־הָיָה לְפָנָיו מֶלֶךְ אֲשֶׁר־שָׁב אֶל־יְהֹוָה בְּכל־לְבָבוֹ וּבְכל־נַפְשׁוֹ וּבְכל־מְאֹדוֹ כְּכֹל תּוֹרַת מֹשֶׁה וְאַחֲרָיו לֹא־קָם כָּמֹהוּ׃}
}
{
	\eX{
		There was no king like him before who turned back to YHWH with all
		his heart and soul and might, in full accord with the Teaching of
		Moses; nor did any like him arise after him.
	}
}
{
}

\Verse{26}
{
	\hX{אַךְ לֹא־שָׁב יְהֹוָה מֵחֲרוֹן אַפּוֹ הַגָּדוֹל אֲשֶׁר־חָרָה אַפּוֹ בִּיהוּדָה עַל כּל־הַכְּעָסִים אֲשֶׁר הִכְעִיסוֹ מְנַשֶּׁה׃}
}
{
	\eX{
		However, YHWH did not turn away from His awesome wrath which had
		blazed up against Judah because of all the things Manasseh did to
		vex Him.
	}
}
{
}

\Verse{27}
{
	\hX{
		וַיֹּאמֶר יְהֹוָה גַּם אֶת־יְהוּדָה אָסִיר מֵעַל פָּנַי כַּאֲשֶׁר הֲסִרֹתִי אֶת־יִשְׂרָאֵל וּמָאַסְתִּי אֶת־הָעִיר הַזֹּאת אֲשֶׁר־בָּחַרְתִּי אֶת־יְרוּשָׁלַ͏ִם וְאֶת־הַבַּיִת
		אֲשֶׁר אָמַרְתִּי יִהְיֶה שְׁמִי שָׁם׃
	}
}
{
	\eX{
		YHWH said, “I will also banish Judah from My presence as I
		banished Israel; and I will reject the city of Jerusalem which I
		chose and the House where I said My name would abide.”
	}
}
{
}

\Verse{28}
{
	\hX{וְיֶתֶר דִּבְרֵי יֹאשִׁיָּהוּ וְכל־אֲשֶׁר עָשָׂה הֲלֹא־הֵם כְּתוּבִים עַל־סֵפֶר דִּבְרֵי הַיָּמִים לְמַלְכֵי יְהוּדָה׃}
}
{
	\eX{
		The other events of Josiah’s reign, and all his actions, are
		recorded in the Annals of the Kings of Judah.
	}
}
{
}

\Verse{29}
{
	\hX{בְּיָמָיו עָלָה פַרְעֹה נְכֹה מֶלֶךְ־מִצְרַיִם עַל־מֶלֶךְ אַשּׁוּר עַל־נְהַר־פְּרָת וַיֵּלֶךְ הַמֶּלֶךְ יֹאשִׁיָּהוּ לִקְרָאתוֹ וַיְמִיתֵהוּ בִּמְגִדּוֹ כִּרְאֹתוֹ אֹתוֹ׃}
}
{
	\eX{
		In his days, Pharaoh Neco, king of Egypt, marched against the king
		of Assyria to the River Euphrates; King Josiah marched toward him,
		but when he confronted him at Megiddo, [Pharaoh Neco] slew him.
	}
}
{
}

\Verse{30}
{
	\hX{
		וַיַּרְכִּבֻהוּ עֲבָדָיו מֵת מִמְּגִדּוֹ וַיְבִאֻהוּ יְרוּשָׁלַ͏ִם וַיִּקְבְּרֻהוּ בִּקְבֻרָתוֹ וַיִּקַּח עַם־הָאָרֶץ אֶת־יְהוֹאָחָז בֶּן־יֹאשִׁיָּהוּ וַיִּמְשְׁחוּ אֹתוֹ
		וַיַּמְלִיכוּ אֹתוֹ תַּחַת אָבִיו׃
	}
}
{
	\eX{
		His servants conveyed his body in a chariot from Megiddo to
		Jerusalem, and they buried him in his tomb. Then the people of the
		land took Jehoahaz; they anointed him and made him king in place
		of his father.
	}
}
{
}

\Verse{31}
{
	\hX{בֶּן־עֶשְׂרִים וְשָׁלֹשׁ שָׁנָה יְהוֹאָחָז בְּמלְכוֹ וּשְׁלֹשָׁה חֳדָשִׁים מָלַךְ בִּירוּשָׁלָ͏ִם וְשֵׁם אִמּוֹ חֲמוּטַל בַּת־יִרְמְיָהוּ מִלִּבְנָה׃}
}
{
	\eX{
		Jehoahaz was twenty-three years old when he became king, and he
		reigned three months in Jerusalem; his mother’s name was Hamutal
		daughter of Jeremiah of Libnah.
	}
}
{
}

{
	\hX{וַיַּעַשׂ הָרַע בְּעֵינֵי יְהֹוָה כְּכֹל אֲשֶׁר־עָשׂוּ אֲבֹתָיו׃}
}

	\eX{

	}
}

}

\Verse{33}
{
	\hX{וַיַּאַסְרֵהוּ פַרְעֹה נְכֹה בְרִבְלָה בְּאֶרֶץ חֲמָת (במלך) [מִמְּלֹךְ] בִּירוּשָׁלָ͏ִם וַיִּתֶּן־עֹנֶשׁ עַל־הָאָרֶץ מֵאָה כִכַּר־כֶּסֶף וְכִכַּר זָהָב׃}
}
{
	\eX{
		Pharaoh Neco imprisoned him in Riblah in the region of Hamath, to
		keep him from reigning in Jerusalem. And he imposed on the land an
		indemnity of one hundred talents of silver and a talent of gold.
	}
}
{
	Qere Ketiv.
}

\Verse{34}
{
	\hX{וַיַּמְלֵךְ פַּרְעֹה נְכֹה אֶת־אֶלְיָקִים בֶּן־יֹאשִׁיָּהוּ תַּחַת יֹאשִׁיָּהוּ אָבִיו וַיַּסֵּב אֶת־שְׁמוֹ יְהוֹיָקִים וְאֶת־יְהוֹאָחָז לָקַח וַיָּבֹא מִצְרַיִם וַיָּמת שָׁם׃}
}
{
	\eX{
		Then Pharaoh Neco appointed Eliakim son of Josiah king in place of
		his father Josiah, changing his name to Jehoiakim. He took
		Jehoahaz and brought him to Egypt, where he died.
	}
}
{
}

\Verse{35}
{
	\hX{
		וְהַכֶּסֶף וְהַזָּהָב נָתַן יְהוֹיָקִים לְפַרְעֹה אַךְ הֶעֱרִיךְ אֶת־הָאָרֶץ לָתֵת אֶת־הַכֶּסֶף עַל־פִּי פַרְעֹה אִישׁ כְּעֶרְכּוֹ נָגַשׂ אֶת־הַכֶּסֶף וְאֶת־הַזָּהָב אֶת־עַם
		הָאָרֶץ לָתֵת לְפַרְעֹה נְכֹה׃
	}
}
{
	\eX{
		Jehoiakim gave Pharaoh the silver and the gold, and he made an
		assessment on the land to pay the money demanded by Pharaoh. He
		exacted from the people of the land the silver and gold to be paid
		Pharaoh Neco, according to each man’s assessment.
	}
}
{
}

\Verse{36}
{

}
{
	\eX{
