\Verse{30}
{
	\hX{וְיָסְפָה פְּלֵיטַת בֵּית־יְהוּדָה הַנִּשְׁאָרָה שֹׁרֶשׁ לְמָטָּה וְעָשָׂה פְרִי לְמָעְלָה׃}
}
{
	\eX{
		And the survivors of the House of Judah that have escaped shall
		regenerate its stock below and produce boughs above.
	}
}
{
}

\Verse{31}
{
	\hX{כִּי מִירוּשָׁלַ͏ִם תֵּצֵא שְׁאֵרִית וּפְלֵיטָה מֵהַר צִיּוֹן קִנְאַת יְהֹוָה [צְבָאוֹת] תַּעֲשֶׂה־זֹּאת׃}
}
{
	\eX{
		For a remnant shall come forth from Jerusalem, Survivors from
		Mount Zion. The zeal of YHWH of Hosts Shall bring this to pass.
	}
}
{
}

\Verse{32}
{
	\hX{לָכֵן כֹּה־אָמַר יְהֹוָה אֶל־מֶלֶךְ אַשּׁוּר לֹא יָבֹא אֶל־הָעִיר הַזֹּאת וְלֹא־יוֹרֶה שָׁם חֵץ וְלֹא־יְקַדְּמֶנָּה מָגֵן וְלֹא־יִשְׁפֹּךְ עָלֶיהָ סֹלְלָה׃}
}
{
	\eX{
		Assuredly, thus said YHWH concerning the king of Assyria: He shall
		not enter this city: He shall not shoot an arrow at it, Or advance
		upon it with a shield, Or pile up a siege mound against it.
	}
}
{
}

\Verse{33}
{
	\hX{בַּדֶּרֶךְ אֲשֶׁר־יָבֹא בָּהּ יָשׁוּב וְאֶל־הָעִיר הַזֹּאת לֹא יָבֹא נְאֻם־יְהֹוָה׃}
}
{
	\eX{
		He shall go back By the way he came; He shall not enter this city
		—declares YHWH.
	}
}
{
}

\Verse{34}
{
	\hX{וְגַנּוֹתִי אֶל־הָעִיר הַזֹּאת לְהוֹשִׁיעָהּ לְמַעֲנִי וּלְמַעַן דָּוִד עַבְדִּי׃}
}
{
	\eX{
		I will protect and save this city for My sake, And for the sake of
		My servant David.”
	}
}
{
}

\Verse{35}
{
	\hX{וַיְהִי בַּלַּיְלָה הַהוּא וַיֵּצֵא מַלְאַךְ יְהֹוָה וַיַּךְ בְּמַחֲנֵה אַשּׁוּר מֵאָה שְׁמוֹנִים וַחֲמִשָּׁה אָלֶף וַיַּשְׁכִּימוּ בַבֹּקֶר וְהִנֵּה כֻלָּם פְּגָרִים מֵתִים׃}
}
{
	\eX{
		That night an angel of YHWH went out and struck down one hundred
		and eighty-five thousand in the Assyrian camp, and the following
		morning they were all dead corpses.
	}
}
{
%	\footnote{
%		Footnote 19:35. One hundred eighty-five thousand is not narrated as a battle. The
%		army wakes up as corpses, which is efficient theology and terrible morning news.
%	}
}

\Verse{36}
{
	\hX{וַיִּסַּע וַיֵּלֶךְ וַיָּשׁב סַנְחֵרִיב מֶלֶךְ־אַשּׁוּר וַיֵּשֶׁב בְּנִינְוֵה׃}
}
{
	\eX{
		So King Sennacherib of Assyria broke camp and retreated, and
		stayed in Nineveh.
	}
}
{
}

\Verse{37}
{
	\hX{
		וַיְהִי הוּא מִשְׁתַּחֲוֶה בֵּית נִסְרֹךְ אֱלֹהָיו וְאַדְרַמֶּלֶךְ וְשַׂרְאֶצֶר [בָּנָיו] הִכֻּהוּ בַחֶרֶב וְהֵמָּה נִמְלְטוּ אֶרֶץ אֲרָרָט וַיִּמְלֹךְ אֵסַר־חַדֹּן בְּנוֹ
		תַּחְתָּיו׃
	}
}
{
	\eX{
		While he was worshiping in the temple of his god Nisroch, his sons
		Adrammelech and Sarezer struck him down with the sword. They fled
		to the land of Ararat, and his son Esarhaddon succeeded him as
		king.
	}
}
{
}
