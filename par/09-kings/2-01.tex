\Chapter{1}

\Verse{1}
{
	\hX{וַיִּפְשַׁע מוֹאָב בְּיִשְׂרָאֵל אַחֲרֵי מוֹת אַחְאָב׃}
}
{
	\eX{After Ahab’s death, Moab rebelled against Israel.}
}
{
}

\Verse{2}
{
	\hX{
		וַיִּפֹּל אֲחַזְיָה בְּעַד הַשְּׂבָכָה בַּעֲלִיָּתוֹ אֲשֶׁר בְּשֹׁמְרוֹן וַיָּחַל וַיִּשְׁלַח מַלְאָכִים וַיֹּאמֶר אֲלֵהֶם לְכוּ דִרְשׁוּ בְּבַעַל זְבוּב אֱלֹהֵי עֶקְרוֹן
		אִם־אֶחְיֶה מֵחֳלִי זֶה׃
	}
}
{
	\eX{
		Ahaziah fell through the lattice in his upper chamber at Samaria
		and was injured. So he sent messengers, whom he instructed: “Go
		inquire of Baal-zebub, the god of Ekron, whether I shall recover
		from this injury.”
	}
}
{
}

\Verse{3}
{
	\hX{
		וּמַלְאַךְ יְהֹוָה דִּבֶּר אֶל־אֵלִיָּה הַתִּשְׁבִּי קוּם עֲלֵה לִקְרַאת מַלְאֲכֵי מֶלֶךְ־שֹׁמְרוֹן וְדַבֵּר אֲלֵהֶם הֲמִבְּלִי אֵין־אֱלֹהִים בְּיִשְׂרָאֵל אַתֶּם הֹלְכִים לִדְרֹשׁ
		בְּבַעַל זְבוּב אֱלֹהֵי עֶקְרוֹן׃
	}
}
{
	\eX{
		But an angel of YHWH said to Elijah the Tishbite, “Go and confront
		the messengers of the king of Samaria and say to them, ‘Is there
		no God in Israel that you go to inquire of Baal-zebub, the god of
		Ekron?
	}
}
{
}

\Verse{4}
{
	\hX{וְלָכֵן כֹּה־אָמַר יְהֹוָה הַמִּטָּה אֲשֶׁר־עָלִיתָ שָּׁם לֹא־תֵרֵד מִמֶּנָּה כִּי מוֹת תָּמוּת וַיֵּלֶךְ אֵלִיָּה׃}
}
{
	\eX{
		Assuredly, thus said YHWH: You shall not rise from the bed you are
		lying on, but you shall die.’” And Elijah went.
	}
}
{
}

\Verse{5}
{
	\hX{וַיָּשׁוּבוּ הַמַּלְאָכִים אֵלָיו וַיֹּאמֶר אֲלֵיהֶם מַה־זֶּה שַׁבְתֶּם׃}
}
{
	\eX{
		The messengers returned to Ahaziah; and he asked, “Why have you
		come back?”
	}
}
{
}

\Verse{6}
{
	\hX{
		וַיֹּאמְרוּ אֵלָיו אִישׁ עָלָה לִקְרָאתֵנוּ וַיֹּאמֶר אֵלֵינוּ לְכוּ שׁוּבוּ אֶל־הַמֶּלֶךְ אֲשֶׁר־שָׁלַח אֶתְכֶם וְדִבַּרְתֶּם אֵלָיו כֹּה אָמַר יְהֹוָה הֲמִבְּלִי אֵין־אֱלֹהִים
		בְּיִשְׂרָאֵל אַתָּה שֹׁלֵחַ לִדְרֹשׁ בְּבַעַל זְבוּב אֱלֹהֵי עֶקְרוֹן לָכֵן הַמִּטָּה אֲשֶׁר־עָלִיתָ שָּׁם לֹא־תֵרֵד מִמֶּנָּה כִּי־מוֹת תָּמוּת׃
	}
}
{
	\eX{
		They answered him, “A man came toward us and said to us, ‘Go back
		to the king who sent you, and say to him: Thus said YHWH: Is there
		no God in Israel that you must send to inquire of Baal-zebub, the
		god of Ekron? Assuredly, you shall not rise from the bed you are
		lying on, but shall die.’”
	}
}
{
}

\Verse{7}
{
	\hX{וַיְדַבֵּר אֲלֵהֶם מֶה מִשְׁפַּט הָאִישׁ אֲשֶׁר עָלָה לִקְרַאתְכֶם וַיְדַבֵּר אֲלֵיכֶם אֶת־הַדְּבָרִים הָאֵלֶּה׃}
}
{
	\eX{
		“What sort of man was it,” he asked them, “who came toward you and
		said these things to you?”
	}
}
{
}

\Verse{8}
{
	\hX{וַיֹּאמְרוּ אֵלָיו אִישׁ בַּעַל שֵׂעָר וְאֵזוֹר עוֹר אָזוּר בְּמתְנָיו וַיֹּאמַר אֵלִיָּה הַתִּשְׁבִּי הוּא׃}
}
{
	\eX{
		“A hairy man,” they replied, “with a leather belt tied around his
		waist.” “That’s Elijah the Tishbite!” he said.
	}
}
{
%	\footnote{
%		Footnote 1:8. A hairy man can also be read as “a possessor of hair.” The story
%		recognizes Elijah by costume, not by résumé.
%	}
}

\Verse{9}
{
	\hX{וַיִּשְׁלַח אֵלָיו שַׂר־חֲמִשִּׁים וַחֲמִשָּׁיו וַיַּעַל אֵלָיו וְהִנֵּה יֹשֵׁב עַל־רֹאשׁ הָהָר וַיְדַבֵּר אֵלָיו אִישׁ הָאֱלֹהִים הַמֶּלֶךְ דִּבֶּר רֵדָה׃}
}
{
	\eX{
		Then he sent to him a captain of fifty with his fifty men. He
		climbed up to him, and found him sitting at the top of a hill.
		“Man of God,” he said to him, “by order of the king, come down!”
	}
}
{
}

\Verse{10}
{
	\hX{
		וַיַּעֲנֶה אֵלִיָּהוּ וַיְדַבֵּר אֶל־שַׂר הַחֲמִשִּׁים וְאִם־אִישׁ אֱלֹהִים אָנִי תֵּרֶד אֵשׁ מִן־הַשָּׁמַיִם וְתֹאכַל אֹתְךָ וְאֶת־חֲמִשֶּׁיךָ וַתֵּרֶד אֵשׁ מִן־הַשָּׁמַיִם
		וַתֹּאכַל אֹתוֹ וְאֶת־חֲמִשָּׁיו׃
	}
}
{
	\eX{
		Elijah replied to the captain of the fifty, “If I am a man of God,
		let fire come down from heaven and consume you with your fifty
		men!” And fire came down from heaven and consumed him and his
		fifty men.
	}
}
{
}

\Verse{11}
{
	\hX{וַיָּשׁב וַיִּשְׁלַח אֵלָיו שַׂר־חֲמִשִּׁים אַחֵר וַחֲמִשָּׁיו וַיַּעַן וַיְדַבֵּר אֵלָיו אִישׁ הָאֱלֹהִים כֹּה־אָמַר הַמֶּלֶךְ מְהֵרָה רֵדָה׃}
}
{
	\eX{
		The king then sent to him another captain with his fifty men; and
		he addressed him as follows: “Man of God, by order of the king,
		come down at once!”
	}
}
{
}

\Verse{12}
{
	\hX{
		וַיַּעַן אֵלִיָּה וַיְדַבֵּר אֲלֵיהֶם אִם־אִישׁ הָאֱלֹהִים אָנִי תֵּרֶד אֵשׁ מִן־הַשָּׁמַיִם וְתֹאכַל אֹתְךָ וְאֶת־חֲמִשֶּׁיךָ וַתֵּרֶד אֵשׁ־אֱלֹהִים מִן־הַשָּׁמַיִם וַתֹּאכַל
		אֹתוֹ וְאֶת־חֲמִשָּׁיו׃
	}
}
{
	\eX{
		But Elijah answered him, “If I am a man of God, let fire come down
		from heaven and consume you with your fifty men!” And fire of God
		came down from heaven and consumed him and his fifty men.
	}
}
{
}

\Verse{13}
{
	\hX{
		וַיָּשׁב וַיִּשְׁלַח שַׂר־חֲמִשִּׁים שְׁלִשִׁים וַחֲמִשָּׁיו וַיַּעַל וַיָּבֹא שַׂר־הַחֲמִשִּׁים הַשְּׁלִישִׁי וַיִּכְרַע עַל־בִּרְכָּיו לְנֶגֶד אֵלִיָּהוּ וַיִּתְחַנֵּן אֵלָיו
		וַיְדַבֵּר אֵלָיו אִישׁ הָאֱלֹהִים תִּיקַר־נָא נַפְשִׁי וְנֶפֶשׁ עֲבָדֶיךָ אֵלֶּה חֲמִשִּׁים בְּעֵינֶיךָ׃
	}
}
{
	\eX{
		Then he sent a third captain of fifty with his fifty men. The
		third captain of fifty climbed to the top, knelt before Elijah,
		and implored him, saying, “Oh, man of God, please have regard for
		my life and the lives of these fifty servants of yours!
	}
}
{
}

\Verse{14}
{
	\hX{הִנֵּה יָרְדָה אֵשׁ מִן־הַשָּׁמַיִם וַתֹּאכַל אֶת־שְׁנֵי שָׂרֵי הַחֲמִשִּׁים הָרִאשֹׁנִים וְאֶת־חֲמִשֵּׁיהֶם וְעַתָּה תִּיקַר נַפְשִׁי בְּעֵינֶיךָ׃}
}
{
	\eX{
		Already fire has come from heaven and consumed the first two
		captains of fifty and their men; I beg you, have regard for my
		life!”
	}
}
{
}

\Verse{15}
{
	\hX{וַיְדַבֵּר מַלְאַךְ יְהֹוָה אֶל־אֵלִיָּהוּ רֵד אוֹתוֹ אַל־תִּירָא מִפָּנָיו וַיָּקם וַיֵּרֶד אוֹתוֹ אֶל־הַמֶּלֶךְ׃}
}
{
	\eX{
		Then the angel of YHWH said to Elijah, “Go down with him, do not
		be afraid of him.” So he rose and went down with him to the king.
	}
}
{
}

\Verse{16}
{
	\hX{
		וַיְדַבֵּר אֵלָיו כֹּה־אָמַר יְהֹוָה יַעַן אֲשֶׁר־שָׁלַחְתָּ מַלְאָכִים לִדְרֹשׁ בְּבַעַל זְבוּב אֱלֹהֵי עֶקְרוֹן הֲמִבְּלִי אֵין־אֱלֹהִים בְּיִשְׂרָאֵל לִדְרֹשׁ בִּדְבָרוֹ לָכֵן
		הַמִּטָּה אֲשֶׁר־עָלִיתָ שָּׁם לֹא־תֵרֵד מִמֶּנָּה כִּי־מוֹת תָּמוּת׃
	}
}
{
	\eX{
		He said to him, “Thus said YHWH: Because you sent messengers to
		inquire of Baal-zebub the god of Ekron—as if there were no God in
		Israel whose word you could seek—assuredly, you shall not rise
		from the bed which you are lying on; but you shall die.”
	}
}
{
}

\Verse{17}
{
	\hX{וַיָּמת כִּדְבַר יְהֹוָה אֲשֶׁר־דִּבֶּר אֵלִיָּהוּ וַיִּמְלֹךְ יְהוֹרָם תַּחְתָּיובִּשְׁנַת שְׁתַּיִם לִיהוֹרָם בֶּן־יְהוֹשָׁפָט מֶלֶךְ יְהוּדָה כִּי לֹא־הָיָה לוֹ בֵּן׃}
}
{
	\eX{
		And [Ahaziah] died, according to the word of YHWH that Elijah had
		spoken. Jehoram succeeded him as king, in the second year of King
		Jehoram son of Jehoshaphat of Judah, for he had no son.
	}
}
{
}

\Verse{18}
{
	\hX{וְיֶתֶר דִּבְרֵי אֲחַזְיָהוּ אֲשֶׁר עָשָׂה הֲלוֹא־הֵמָּה כְתוּבִים עַל־סֵפֶר דִּבְרֵי הַיָּמִים לְמַלְכֵי יִשְׂרָאֵל׃}
}
{
	\eX{
		The other events of Ahaziah’s reign [and] his actions are recorded
		in the Annals of the Kings of Israel.
	}
}
{
}
