\Chapter{13}

\Verse{1}
{
	\hX{בֶּן־שָׁנָה שָׁאוּל בְּמלְכוֹ וּשְׁתֵּי שָׁנִים מָלַךְ עַל־יִשְׂרָאֵל׃}
}
{
	\eX{
		Saul reigned one year: and when he had reigned two years over
		Israel,
	}
}
{
}

\Verse{2}
{
	\hX{
		וַיִּבְחַר־לוֹ שָׁאוּל שְׁלֹשֶׁת אֲלָפִים מִיִּשְׂרָאֵל וַיִּהְיוּ עִם־שָׁאוּל אַלְפַּיִם בְּמִכְמָשׂ וּבְהַר בֵּית־אֵל וְאֶלֶף הָיוּ עִם־יוֹנָתָן בְּגִבְעַת בִּנְיָמִין וְיֶתֶר
		הָעָם שִׁלַּח אִישׁ לְאֹהָלָיו׃
	}
}
{
	\eX{
		Saul chose him three thousand men of Israel: whereof two
		thousand were with Saul in Michmas and in mount Bethel, and a
		thousand were with Jonathan in Gibeah of Benjamin: and the rest
		of the people he sent every man to his tent.
	}
}
{
}

\Verse{3}
{
	\hX{וַיַּךְ יוֹנָתָן אֵת נְצִיב פְּלִשְׁתִּים אֲשֶׁר בְּגֶבַע וַיִּשְׁמְעוּ פְּלִשְׁתִּים וְשָׁאוּל תָּקַע בַּשּׁוֹפָר בְּכל־הָאָרֶץ לֵאמֹר יִשְׁמְעוּ הָעִבְרִים׃}
}
{
	\eX{
		And Jonathan struck the garrison of the Philistines that was in
		Geba, and the Philistines heard of it. And Saul blew the trumpet
		throughout all the land, saying, Let the Hebrews hear.
	}
}
{
}

\Verse{4}
{
	\hX{וְכל־יִשְׂרָאֵל שָׁמְעוּ לֵאמֹר הִכָּה שָׁאוּל אֶת־נְצִיב פְּלִשְׁתִּים וְגַם־נִבְאַשׁ יִשְׂרָאֵל בַּפְּלִשְׁתִּים וַיִּצָּעֲקוּ הָעָם אַחֲרֵי שָׁאוּל הַגִּלְגָּל׃}
}
{
	\eX{
		And all Israel heard say that Saul had struck a garrison of the
		Philistines, and that Israel also was had in abomination with
		the Philistines. And the people were called together after Saul
		to Gilgal.
	}
}
{
}

\Verse{5}
{
	\hX{
		וּפְלִשְׁתִּים נֶאֶסְפוּ לְהִלָּחֵם עִם־יִשְׂרָאֵל שְׁלֹשִׁים אֶלֶף רֶכֶב וְשֵׁשֶׁת אֲלָפִים פָּרָשִׁים וְעָם כַּחוֹל אֲשֶׁר עַל־שְׂפַת־הַיָּם לָרֹב וַיַּעֲלוּ וַיַּחֲנוּ
		בְמִכְמָשׂ קִדְמַת בֵּית אָוֶן׃
	}
}
{
	\eX{
		And the Philistines gathered themselves together to fight with
		Israel, thirty thousand chariots, and six thousand horsemen, and
		people as the sand which is on the sea shore in multitude: and
		they came up, and pitched in Michmas, eastward from Bethaven.
	}
}
{
}

\Verse{6}
{
	\hX{וְאִישׁ יִשְׂרָאֵל רָאוּ כִּי צַר־לוֹ כִּי נִגַּשׂ הָעָם וַיִּתְחַבְּאוּ הָעָם בַּמְּעָרוֹת וּבַחֲוָחִים וּבַסְּלָעִים וּבַצְּרִחִים וּבַבֹּרוֹת׃}
}
{
	\eX{
		When the men of Israel saw that they were in a strait, (for the
		people were distressed,) then the people did hide themselves in
		caves, and in thickets, and in rocks, and in high places, and in
		pits.
	}
}
{
}

\Verse{7}
{
	\hX{וְעִבְרִים עָבְרוּ אֶת־הַיַּרְדֵּן אֶרֶץ גָּד וְגִלְעָד וְשָׁאוּל עוֹדֶנּוּ בַגִּלְגָּל וְכל־הָעָם חָרְדוּ אַחֲרָיו׃}
}
{
	\eX{
		And some of the Hebrews went over Jordan to the land of Gad and
		Gilead. As for Saul, he was yet in Gilgal, and all the people
		followed him trembling.
	}
}
{
}

\Verse{8}
{
	\hX{(וייחל) [וַיּוֹחֶל ] שִׁבְעַת יָמִים לַמּוֹעֵד אֲשֶׁר שְׁמוּאֵל וְלֹא־בָא שְׁמוּאֵל הַגִּלְגָּל וַיָּפֶץ הָעָם מֵעָלָיו׃}
}
{
	\eX{
		And he tarried seven days, according to the set time that Samuel
		had appointed: but Samuel came not to Gilgal: and the people
		were scattered from him.
	}
}
{
}

\Verse{9}
{
	\hX{וַיֹּאמֶר שָׁאוּל הַגִּשׁוּ אֵלַי הָעֹלָה וְהַשְּׁלָמִים וַיַּעַל הָעֹלָה׃}
}
{
	\eX{
		And Saul said, Bring here a burnt offering to me, and peace
		offerings. And he offered the burnt offering.
	}
}
{
}

\Verse{10}
{
	\hX{וַיְהִי כְּכַלֹּתוֹ לְהַעֲלוֹת הָעֹלָה וְהִנֵּה שְׁמוּאֵל בָּא וַיֵּצֵא שָׁאוּל לִקְרָאתוֹ לְבָרְכוֹ׃}
}
{
	\eX{
		And it was: that as soon as he had made an end of offering the
		burnt offering, here: Samuel came: and Saul went out to meet
		him, that he might salute him.
	}
}
{
}

\Verse{11}
{
	\hX{וַיֹּאמֶר שְׁמוּאֵל מֶה עָשִׂיתָ וַיֹּאמֶר שָׁאוּל כִּי־רָאִיתִי כִי־נָפַץ הָעָם מֵעָלַי וְאַתָּה לֹא־בָאתָ לְמוֹעֵד הַיָּמִים וּפְלִשְׁתִּים נֶאֱסָפִים מִכְמָשׂ׃}
}
{
	\eX{
		And Samuel said, What have you done? And Saul said, Because I
		saw that the people were scattered from me, and that you came
		not within the days appointed, and that the Philistines gathered
		themselves together at Michmas:
	}
}
{
}

\Verse{12}
{
	\hX{וָאֹמַר עַתָּה יֵרְדוּ פְלִשְׁתִּים אֵלַי הַגִּלְגָּל וּפְנֵי יְהֹוָה לֹא חִלִּיתִי וָאֶתְאַפַּק וָאַעֲלֶה הָעֹלָה׃}
}
{
	\eX{
		And so said I, The Philistines will come down now on me to
		Gilgal, and I've not made supplication to YHWH: I forced myself
		therefore, and offered a burnt offering.
	}
}
{
}

\Verse{13}
{
	\hX{וַיֹּאמֶר שְׁמוּאֵל אֶל־שָׁאוּל נִסְכָּלְתָּ לֹא שָׁמַרְתָּ אֶת־מִצְוַת יְהֹוָה אֱלֹהֶיךָ אֲשֶׁר צִוָּךְ כִּי עַתָּה הֵכִין יְהֹוָה אֶת־מַמְלַכְתְּךָ אֶל־יִשְׂרָאֵל עַד־עוֹלָם׃}
}
{
	\eX{
		And Samuel said to Saul, You have done foolishly: you've not
		kept the commandment of YHWH your God, which he commanded you:
		for now would YHWH have established your kingdom on Israel
		forever.
	}
}
{
}

\Verse{14}
{
	\hX{וְעַתָּה מַמְלַכְתְּךָ לֹא־תָקוּם בִּקֵּשׁ יְהֹוָה לוֹ אִישׁ כִּלְבָבוֹ וַיְצַוֵּהוּ יְהֹוָה לְנָגִיד עַל־עַמּוֹ כִּי לֹא שָׁמַרְתָּ אֵת אֲשֶׁר־צִוְּךָ יְהֹוָה׃}
}
{
	\eX{
		And now your kingdom shall not continue: YHWH has sought him a
		man after his own heart, and YHWH has commanded him to be
		captain over his people, because you've not kept that which YHWH
		commanded you.
	}
}
{
%	\footnote{
%		Footnote 13:14. a man according to His heart. The sentence is often made soft and
%		pious. Here it is a verdict in a failed dynasty trial.
%	}
}

\Verse{15}
{
	\hX{וַיָּקם שְׁמוּאֵל וַיַּעַל מִן־הַגִּלְגָּל גִּבְעַת בִּנְיָמִן וַיִּפְקֹד שָׁאוּל אֶת־הָעָם הַנִּמְצְאִים עִמּוֹ כְּשֵׁשׁ מֵאוֹת אִישׁ׃}
}
{
	\eX{
		And Samuel arose, and got him up from Gilgal to Gibeah of
		Benjamin. And Saul numbered the people that were present with
		him, about six hundred men.
	}
}
{
}

\Verse{16}
{
	\hX{וְשָׁאוּל וְיוֹנָתָן בְּנוֹ וְהָעָם הַנִּמְצָא עִמָּם יֹשְׁבִים בְּגֶבַע בִּנְיָמִן וּפְלִשְׁתִּים חָנוּ בְמִכְמָשׂ׃}
}
{
	\eX{
		And Saul, and Jonathan his son, and the people that were present
		with them, abode in Gibeah of Benjamin: but the Philistines
		encamped in Michmas.
	}
}
{
}

\Verse{17}
{
	\hX{וַיֵּצֵא הַמַּשְׁחִית מִמַּחֲנֵה פְלִשְׁתִּים שְׁלֹשָׁה רָאשִׁים הָרֹאשׁ אֶחָד יִפְנֶה אֶל־דֶּרֶךְ עפְרָה אֶל־אֶרֶץ שׁוּעָל׃}
}
{
	\eX{
		And the spoilers came out of the camp of the Philistines in
		three companies: one company turned to the way that leads to
		Ophrah, to the land of Shual:
	}
}
{
}

\Verse{18}
{
	\hX{וְהָרֹאשׁ אֶחָד יִפְנֶה דֶּרֶךְ בֵּית חֹרוֹן וְהָרֹאשׁ אֶחָד יִפְנֶה דֶּרֶךְ הַגְּבוּל הַנִּשְׁקָף עַל־גֵּי הַצְּבֹעִים הַמִּדְבָּרָה׃}
}
{
	\eX{
		And another company turned the way to Bethhoron: and another
		company turned to the way of the border that looks to the valley
		of Zeboim toward the wilderness.
	}
}
{
}

\Verse{19}
{
	\hX{וְחָרָשׁ לֹא יִמָּצֵא בְּכֹל אֶרֶץ יִשְׂרָאֵל כִּי־[אָמְרוּ] (אמר) פְלִשְׁתִּים פֶּן יַעֲשׂוּ הָעִבְרִים חֶרֶב אוֹ חֲנִית׃}
}
{
	\eX{
		And there was no smith found throughout all the land of Israel:
		for the Philistines said, Or else the Hebrews make them swords
		or spears:
	}
}
{
}

\Verse{20}
{
	\hX{וַיֵּרְדוּ כל־יִשְׂרָאֵל הַפְּלִשְׁתִּים לִלְטוֹשׁ אִישׁ אֶת־מַחֲרַשְׁתּוֹ וְאֶת־אֵתוֹ וְאֶת־קַרְדֻּמּוֹ וְאֵת מַחֲרֵשָׁתוֹ׃}
}
{
	\eX{
		And all the Israelites went down to the Philistines, to sharpen
		every man his share, and his coulter, and his axe, and his

	}
}
{
}

\Verse{21}
{
	\hX{וְהָיְתָה הַפְּצִירָה פִים לַמַּחֲרֵשֹׁת וְלָאֵתִים וְלִשְׁלֹשׁ קִלְּשׁוֹן וּלְהַקַּרְדֻּמִּים וּלְהַצִּיב הַדָּרְבָן׃}
}
{
	\eX{

		for the forks, and for the axes, and to sharpen the goads.
	}
}
{
}

\Verse{22}
{
	\hX{וְהָיָה בְּיוֹם מִלְחֶמֶת וְלֹא נִמְצָא חֶרֶב וַחֲנִית בְּיַד כּל־הָעָם אֲשֶׁר אֶת־שָׁאוּל וְאֶת־יוֹנָתָן וַתִּמָּצֵא לְשָׁאוּל וּלְיוֹנָתָן בְּנוֹ׃}
}
{
	\eX{
		And it came to pass in the day of battle, that there was neither

	}
}
{
}

\Verse{23}
{
	\hX{וַיֵּצֵא מַצַּב פְּלִשְׁתִּים אֶל־מַעֲבַר מִכְמָשׂ׃}

{
