\Chapter{4}

\Verse{1}

	\hJ{וַיְהִי דְבַר־שְׁמוּאֵל לְכל־יִשְׂרָאֵל וַיֵּצֵא יִשְׂרָאֵל לִקְרַאת פְּלִשְׁתִּים לַמִּלְחָמָה וַיַּחֲנוּ עַל־הָאֶבֶן הָעֵזֶר וּפְלִשְׁתִּים חָנוּ בַאֲפֵק׃}
}
{
	\eJ{
		And the word of Samuel came to all Israel. Now Israel went out
		against the Philistines to battle, and pitched beside Ebenezer:
		and the Philistines pitched in Aphek.

\Verse{2}
{
	\hJ{וַיַּעַרְכוּ פְלִשְׁתִּים לִקְרַאת יִשְׂרָאֵל וַתִּטֹּשׁ הַמִּלְחָמָה וַיִּנָּגֶף יִשְׂרָאֵל לִפְנֵי פְלִשְׁתִּים וַיַּכּוּ בַמַּעֲרָכָה בַּשָּׂדֶה כְּאַרְבַּעַת אֲלָפִים אִישׁ׃}
}
{
	\eJ{
		And the Philistines put themselves in array against Israel: and
		when they joined battle, Israel was struck before the
		Philistines: and they killed of the army in the field about four
		thousand men.
	}
}
{
}

\Verse{3}
{
	\hJ{
		וַיָּבֹא הָעָם אֶל־הַמַּחֲנֶה וַיֹּאמְרוּ זִקְנֵי יִשְׂרָאֵל לָמָּה נְגָפָנוּ יְהֹוָה הַיּוֹם לִפְנֵי פְלִשְׁתִּים נִקְחָה אֵלֵינוּ מִשִּׁלֹה אֶת־אֲרוֹן בְּרִית יְהֹוָה וְיָבֹא
		בְקִרְבֵּנוּ וְיֹשִׁעֵנוּ מִכַּף אֹיְבֵינוּ׃
	}
}
{
	\eJ{
		And when the people had come into the camp, the elders of Israel
		said, And so has YHWH struck us today before the Philistines?
		Let's bring the ark of the covenant of YHWH out of Shiloh to us,
		that, when it comes among us, it may save us from the hand of
		our enemies.
	}
}
{
}

\Verse{4}
{
	\hJ{וַיִּשְׁלַח הָעָם שִׁלֹה וַיִּשְׂאוּ מִשָּׁם אֵת אֲרוֹן בְּרִית־יְהֹוָה צְבָאוֹת יֹשֵׁב הַכְּרֻבִים וְשָׁם שְׁנֵי בְנֵי־עֵלִי עִם־אֲרוֹן בְּרִית הָאֱלֹהִים חפְנִי וּפִינְחָס׃}
}
{
	\eJ{
		And the people sent to Shiloh, that they might bring from from
		there the ark of the covenant of YHWH of Armies, which lives
		between the cherubs: and the two sons of Eli, Hophni and
		Phinehas, were there with the ark of the covenant of God.
	}
}
{
}

\Verse{5}
{
	\hJ{וַיְהִי כְּבוֹא אֲרוֹן בְּרִית־יְהֹוָה אֶל־הַמַּחֲנֶה וַיָּרִעוּ כל־יִשְׂרָאֵל תְּרוּעָה גְדוֹלָה וַתֵּהֹם הָאָרֶץ׃}
}
{
	\eJ{
		And when the ark of the covenant of YHWH came into the camp, all
		Israel shouted with a great shout, so that the earth rang again.
	}
}
{
}

\Verse{6}
{
	\hJ{וַיִּשְׁמְעוּ פְלִשְׁתִּים אֶת־קוֹל הַתְּרוּעָה וַיֹּאמְרוּ מֶה קוֹל הַתְּרוּעָה הַגְּדוֹלָה הַזֹּאת בְּמַחֲנֵה הָעִבְרִים וַיֵּדְעוּ כִּי אֲרוֹן יְהֹוָה בָּא אֶל־הַמַּחֲנֶה׃}
}
{
	\eJ{
		And when the Philistines heard the noise of the shout, they
		said, What means the noise of this great shout in the camp of
		the Hebrews? And they understood that the ark of YHWH had come
		into the camp.
	}
}
{
}

\Verse{7}
{
	\hJ{וַיִּרְאוּ הַפְּלִשְׁתִּים כִּי אָמְרוּ בָּא אֱלֹהִים אֶל־הַמַּחֲנֶה וַיֹּאמְרוּ אוֹי לָנוּ כִּי לֹא הָיְתָה כָּזֹאת אֶתְמוֹל שִׁלְשֹׁם׃}
}
{
	\eJ{
		And the Philistines were afraid, for they said, God has come
		into the camp. And they said, Woe to us! for there has not been
		such a thing heretofore.
	}
}
{
}

\Verse{8}
{
	\hJ{אוֹי לָנוּ מִי יַצִּילֵנוּ מִיַּד הָאֱלֹהִים הָאַדִּירִים הָאֵלֶּה אֵלֶּה הֵם הָאֱלֹהִים הַמַּכִּים אֶת־מִצְרַיִם בְּכל־מַכָּה בַּמִּדְבָּר׃}
}
{
	\eJ{
		Woe to us! who shall deliver us from the hand of these mighty

}
{
}

\Verse{9}
{
	\hJ{הִתְחַזְּקוּ וִהְיוּ לַאֲנָשִׁים פְּלִשְׁתִּים פֶּן תַּעַבְדוּ לָעִבְרִים כַּאֲשֶׁר עָבְדוּ לָכֶם וִהְיִיתֶם לַאֲנָשִׁים וְנִלְחַמְתֶּם׃}
}
{
	\eJ{
		Be strong and quit yourselves like men, O you Philistines, that

{
}
