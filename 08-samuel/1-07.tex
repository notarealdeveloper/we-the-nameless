\Chapter{7}

\Verse{1}
{
	\hJ{וַיָּבֹאוּ אַנְשֵׁי קִרְיַת יְעָרִים וַיַּעֲלוּ אֶת־אֲרוֹן יְהֹוָה וַיָּבִאוּ אֹתוֹ אֶל־בֵּית אֲבִינָדָב בַּגִּבְעָה וְאֶת־אֶלְעָזָר בְּנוֹ קִדְּשׁוּ לִשְׁמֹר אֶת־אֲרוֹן יְהֹוָה׃}
}
{
	\eJ{
		And the men of Kiriath-jearim came, and bringed up the ark of
		YHWH, and brought it into the house of Abinadab in the hill, and
		sanctified Eleazar his son to keep the ark of YHWH.
	}
}
{
}

\Verse{2}
{
	\hJ{וַיְהִי מִיּוֹם שֶׁבֶת הָאָרוֹן בְּקִרְיַת יְעָרִים וַיִּרְבּוּ הַיָּמִים וַיִּהְיוּ עֶשְׂרִים שָׁנָה וַיִּנָּהוּ כּל־בֵּית יִשְׂרָאֵל אַחֲרֵי יְהֹוָה׃}
}
{
	\eJ{
		And it was: while the ark abode in Kiriath-jearim, that the time
		was long: for it was twenty years: and all the house of Israel
		lamented after YHWH.
	}
}
{
}

\Verse{3}
{
	\hX{
		וַיֹּאמֶר שְׁמוּאֵל אֶל־כּל־בֵּית יִשְׂרָאֵל לֵאמֹר אִם־בְּכל־לְבַבְכֶם אַתֶּם שָׁבִים אֶל־יְהֹוָה הָסִירוּ אֶת־אֱלֹהֵי הַנֵּכָר מִתּוֹכְכֶם וְהָעַשְׁתָּרוֹת וְהָכִינוּ לְבַבְכֶם
		אֶל־יְהֹוָה וְעִבְדֻהוּ לְבַדּוֹ וְיַצֵּל אֶתְכֶם מִיַּד פְּלִשְׁתִּים׃
	}
}
{
	\eX{
		And Samuel spoke to all the house of Israel, saying, If you do
		return to YHWH with all your hearts, then put away the strange
		gods and Ashtaroth from among you, and prepare your hearts to
		YHWH, and serve him only: and he'll deliver you from the hand of
		the Philistines.
	}
}
{
}

\Verse{4}
{
	\hX{וַיָּסִירוּ בְּנֵי יִשְׂרָאֵל אֶת־הַבְּעָלִים וְאֶת־הָעַשְׁתָּרֹת וַיַּעַבְדוּ אֶת־יְהֹוָה לְבַדּוֹ׃}
}
{
	\eX{
		And the children of Israel did put away Baalim and Ashtaroth,

	}
}
{
}

\Verse{5}
{
	\hJ{וַיֹּאמֶר שְׁמוּאֵל קִבְצוּ אֶת־כּל־יִשְׂרָאֵל הַמִּצְפָּתָה וְאֶתְפַּלֵּל בַּעַדְכֶם אֶל־יְהֹוָה׃}
}
{
	\eJ{
		And Samuel said, Gather all Israel to Mizpah, and I'll pray for
		you to YHWH.
	}
}
{
}

\Verse{6}
{
	\hJ{
		וַיִּקָּבְצוּ הַמִּצְפָּתָה וַיִּשְׁאֲבוּ־מַיִם וַיִּשְׁפְּכוּ לִפְנֵי יְהֹוָה וַיָּצוּמוּ בַּיּוֹם הַהוּא וַיֹּאמְרוּ שָׁם חָטָאנוּ לַיהֹוָה וַיִּשְׁפֹּט שְׁמוּאֵל אֶת־בְּנֵי
		יִשְׂרָאֵל בַּמִּצְפָּה׃
	}
}
{
	\eJ{
		And they gathered together to Mizpah, and drew water, and poured
		it out before YHWH, and fasted on that day, and said there, We
		have sinned against YHWH. And Samuel judged the children of
		Israel in Mizpah.
	}
}
{
}

\Verse{7}
{
	\hJ{
		וַיִּשְׁמְעוּ פְלִשְׁתִּים כִּי־הִתְקַבְּצוּ בְנֵי־יִשְׂרָאֵל הַמִּצְפָּתָה וַיַּעֲלוּ סַרְנֵי־פְלִשְׁתִּים אֶל־יִשְׂרָאֵל וַיִּשְׁמְעוּ בְּנֵי יִשְׂרָאֵל וַיִּרְאוּ מִפְּנֵי
		פְלִשְׁתִּים׃
	}
}
{
	\eJ{
		And when the Philistines heard that the children of Israel were
		gathered together to Mizpah, the lords of the Philistines went
		up against Israel. And when the children of Israel heard it,
		they were afraid of the Philistines.
	}
}
{
}

\Verse{8}
{
	\hJ{וַיֹּאמְרוּ בְנֵי־יִשְׂרָאֵל אֶל־שְׁמוּאֵל אַל־תַּחֲרֵשׁ מִמֶּנּוּ מִזְּעֹק אֶל־יְהֹוָה אֱלֹהֵינוּ וְיֹשִׁעֵנוּ מִיַּד פְּלִשְׁתִּים׃}
}
{
	\eJ{
		And the children of Israel said to Samuel, Cease not to cry to
		YHWH our God for us, that he'll save us from the hand of the
		Philistines.
	}
}
{
}

\Verse{9}
{

}
{
	\eJ{

		offering wholly to YHWH: and Samuel cried to YHWH for Israel:

}
{
}

\Verse{10}
{
	\hJ{
		וַיְהִי שְׁמוּאֵל מַעֲלֶה הָעוֹלָה וּפְלִשְׁתִּים נִגְּשׁוּ לַמִּלְחָמָה בְּיִשְׂרָאֵל וַיַּרְעֵם יְהֹוָה בְּקוֹל־גָּדוֹל בַּיּוֹם הַהוּא עַל־פְּלִשְׁתִּים וַיְהֻמֵּם וַיִּנָּגְפוּ
		לִפְנֵי יִשְׂרָאֵל׃
	}
}
{
	\eJ{
		And as Samuel was offering up the burnt offering, the
		Philistines drew near to battle against Israel: but YHWH
		thundered with a great thunder on that day on the Philistines,
		and discomfited them: and they were struck before Israel.
	}
}
{
}

\Verse{11}
{
	\hJ{וַיֵּצְאוּ אַנְשֵׁי יִשְׂרָאֵל מִן־הַמִּצְפָּה וַיִּרְדְּפוּ אֶת־פְּלִשְׁתִּים וַיַּכּוּם עַד־מִתַּחַת לְבֵית כָּר׃}
}
{
	\eJ{

}
{
}

}

}
{
}

\Verse{13}
{
	\hJ{וַיִּכָּנְעוּ הַפְּלִשְׁתִּים וְלֹא־יָסְפוּ עוֹד לָבוֹא בִּגְבוּל יִשְׂרָאֵל וַתְּהִי יַד־יְהֹוָה בַּפְּלִשְׁתִּים כֹּל יְמֵי שְׁמוּאֵל׃}
}
{
	\eJ{

}
{
}

\Verse{14}
{
	\hJ{

		restored to Israel, from Ekron even to Gath: and the borders of

	}
}
{
}
