\Chapter{21}

\Verse{1}
{
	\hX{וַיָּקם וַיֵּלַךְ וִיהוֹנָתָן בָּא הָעִיר׃}
}
{
	\eX{And he arose and went away: and Jonathan went into the city.}
}
{
}

\Verse{2}
{
	\hX{וַיָּבֹא דָוִד נֹבֶה אֶל־אֲחִימֶלֶךְ הַכֹּהֵן וַיֶּחֱרַד אֲחִימֶלֶךְ לִקְרַאת דָּוִד וַיֹּאמֶר לוֹ מַדּוּעַ אַתָּה לְבַדֶּךָ וְאִישׁ אֵין אִתָּךְ׃}
}
{
	\eX{
		And came David to Nob to Ahimelech the priest: and Ahimelech was
		afraid at the meeting of David, and said to him, Why are you
		alone, and no man with you?
	}
}
{
}

\Verse{3}
{
	\hX{
		וַיֹּאמֶר דָּוִד לַאֲחִימֶלֶךְ הַכֹּהֵן הַמֶּלֶךְ צִוַּנִי דָבָר וַיֹּאמֶר אֵלַי אִישׁ אַל־יֵדַע מְאוּמָה אֶת־הַדָּבָר אֲשֶׁר־אָנֹכִי שֹׁלֵחֲךָ וַאֲשֶׁר צִוִּיתִךָ
		וְאֶת־הַנְּעָרִים יוֹדַעְתִּי אֶל־מְקוֹם פְּלֹנִי אַלְמוֹנִי׃
	}
}
{
	\eX{
		And David said to Ahimelech the priest, The king has commanded
		me a business, and has said to me, Let no man know anything of
		the business about which I send you, and what I've commanded
		you: and I've appointed my servants to such and such a place.
	}
}
{
}

\Verse{4}
{
	\hX{וְעַתָּה מַה־יֵּשׁ תַּחַת־יָדְךָ חֲמִשָּׁה־לֶחֶם תְּנָה בְיָדִי אוֹ הַנִּמְצָא׃}
}
{
	\eX{
		And therefore what is under your hand? give me five loaves of
		bread in my hand, or what there is present.
	}
}
{
}

\Verse{5}
{
	\hX{וַיַּעַן הַכֹּהֵן אֶת־דָּוִד וַיֹּאמֶר אֵין־לֶחֶם חֹל אֶל־תַּחַת יָדִי כִּי־אִם־לֶחֶם קֹדֶשׁ יֵשׁ אִם־נִשְׁמְרוּ הַנְּעָרִים אַךְ מֵאִשָּׁה׃}
}
{
	\eX{
		And the priest answered David, and said, There is no common
		bread under my hand, but there is holy bread: if the young men
		have kept themselves at least from women.
	}
}
{
}

\Verse{6}
{
	\hX{
		וַיַּעַן דָּוִד אֶת־הַכֹּהֵן וַיֹּאמֶר לוֹ כִּי אִם־אִשָּׁה עֲצֻרָה־לָנוּ כִּתְמוֹל שִׁלְשֹׁם בְּצֵאתִי וַיִּהְיוּ כְלֵי־הַנְּעָרִים קֹדֶשׁ וְהוּא דֶּרֶךְ חֹל וְאַף כִּי הַיּוֹם
		יִקְדַּשׁ בַּכֶּלִי׃
	}
}
{
	\eX{
		And David answered the priest, and said to him, Truly women have
		been kept from us about these three days, since I came out, and
		the vessels of the young men are holy, and the bread is in a
		manner common, yes, though it were made holy this day in the
		vessel.
	}
}
{
}

\Verse{7}
{
	\hX{וַיִּתֶּן־לוֹ הַכֹּהֵן קֹדֶשׁ כִּי לֹא־הָיָה שָׁם לֶחֶם כִּי־אִם־לֶחֶם הַפָּנִים הַמּוּסָרִים מִלִּפְנֵי יְהֹוָה לָשׂוּם לֶחֶם חֹם בְּיוֹם הִלָּקְחוֹ׃}
}
{
	\eX{
		And the priest gave him holy bread: for there was no bread there
		but the bread of the Presence, that was taken from before YHWH,
		to put hot bread in the day when it was taken away.
	}
}
{
}

\Verse{8}
{
	\hX{וְשָׁם אִישׁ מֵעַבְדֵי שָׁאוּל בַּיּוֹם הַהוּא נֶעְצָר לִפְנֵי יְהֹוָה וּשְׁמוֹ דֹּאֵג הָאֲדֹמִי אַבִּיר הָרֹעִים אֲשֶׁר לְשָׁאוּל׃}
}
{
	\eX{
		And one man of the servants of Saul was there that day, detained
		before YHWH: and his name was Doeg, an Edomite, the chief of the
		herdmen that belonged to Saul.
	}
}
{
}

\Verse{9}
{
	\hX{וַיֹּאמֶר דָּוִד לַאֲחִימֶלֶךְ וְאִין יֶשׁ־פֹּה תַחַת־יָדְךָ חֲנִית אוֹ־חָרֶב כִּי גַם־חַרְבִּי וְגַם־כֵּלַי לֹא־לָקַחְתִּי בְיָדִי כִּי־הָיָה דְבַר־הַמֶּלֶךְ נָחוּץ׃}
}
{
	\eX{
		And David said to Ahimelech, And is there not here under your
		hand spear or sword? for I've neither brought my sword nor my
		weapons with me, because the king’s business required haste.
	}
}
{
}

\Verse{10}
{
	\hX{
		וַיֹּאמֶר הַכֹּהֵן חֶרֶב גּלְיָת הַפְּלִשְׁתִּי אֲשֶׁר־הִכִּיתָ בְּעֵמֶק הָאֵלָה הִנֵּה־הִיא לוּטָה בַשִּׂמְלָה אַחֲרֵי הָאֵפוֹד אִם־אֹתָהּ תִּקַּח־לְךָ קָח כִּי אֵין אַחֶרֶת
		זוּלָתָהּ בָּזֶהוַיֹּאמֶר דָּוִד אֵין כָּמוֹהָ תְּנֶנָּה לִּי׃
	}
}
{
	\eX{
		And the priest said, The sword of Goliath the Philistine, whom
		you killed in the valley of Elah, here: it is here wrapped in a
		cloth behind the ephod: if you'll take that, take it: for there
		is no other except that here. And David said, There is none like
		that: give it me.
	}
}
{
}

\Verse{11}
{
	\hX{וַיָּקם דָּוִד וַיִּבְרַח בַּיּוֹם־הַהוּא מִפְּנֵי שָׁאוּל וַיָּבֹא אֶל־אָכִישׁ מֶלֶךְ גַּת׃}
}
{
	\eX{
		And David arose and fled that day for fear of Saul, and went to
		Achish the king of Gath.
	}
}
{
}

\Verse{12}
{
	\hX{וַיֹּאמְרוּ עַבְדֵי אָכִישׁ אֵלָיו הֲלוֹא־זֶה דָוִד מֶלֶךְ הָאָרֶץ הֲלוֹא לָזֶה יַעֲנוּ בַמְּחֹלוֹת לֵאמֹר הִכָּה שָׁאוּל בַּאֲלָפָו וְדָוִד בְּרִבְבֹתָו׃}
}
{
	\eX{
		And the servants of Achish said to him, Is not this David the
		king of the land? did they not sing one to another of him in
		dances, saying, Saul has killed his thousands, and David his ten
		thousands?
	}
}
{
}

\Verse{13}
{
	\hX{וַיָּשֶׂם דָּוִד אֶת־הַדְּבָרִים הָאֵלֶּה בִּלְבָבוֹ וַיִּרָא מְאֹד מִפְּנֵי אָכִישׁ מֶלֶךְ־גַּת׃}
}
{
	\eX{
		And David laid up these words in his heart, and was very afraid
		of Achish the king of Gath.
	}
}
{
}

\Verse{14}
{
	\hX{וַיְשַׁנּוֹ אֶת־טַעְמוֹ בְּעֵינֵיהֶם וַיִּתְהֹלֵל בְּיָדָם וַיְתָו עַל־דַּלְתוֹת הַשַּׁעַר וַיּוֹרֶד רִירוֹ אֶל־זְקָנוֹ׃}
}
{
	\eX{
		And he changed his behavior before them, and feigned himself mad
		in their hands, and scrabbled on the doors of the gate, and let
		his spittle fall down on his beard.
	}
}
{
}

\Verse{15}
{
	\hX{וַיֹּאמֶר אָכִישׁ אֶל־עֲבָדָיו הִנֵּה תִרְאוּ אִישׁ מִשְׁתַּגֵּעַ לָמָּה תָּבִיאוּ אֹתוֹ אֵלָי׃}
}
{
	\eX{
		And said Achish to his servants, Here: you see the man is mad:
		why then have you brought him to me?
	}
}
{
}

\Verse{16}
{
	\hX{חֲסַר מְשֻׁגָּעִים אָנִי כִּי־הֲבֵאתֶם אֶת־זֶה לְהִשְׁתַּגֵּעַ עָלָי הֲזֶה יָבוֹא אֶל־בֵּיתִי׃}
}
{
	\eX{
		Have I need of mad men, that you've brought this fellow to play
		the mad man in my presence? shall this fellow come into my
		house?
	}
}
{
}
