\Chapter{6}

\Verse{1}
{
	\hJ{וַיֹּסֶף עוֹד דָּוִד אֶת־כּל־בָּחוּר בְּיִשְׂרָאֵל שְׁלֹשִׁים אָלֶף׃}
}
{
	\eJ{
		David again assembled all the picked men of Israel, thirty
		thousand strong.
	}
}
{
}

\Verse{2}
{
	\hJ{וַיָּקם וַיֵּלֶךְ דָּוִד וְכל־הָעָם אֲשֶׁר אִתּוֹ מִבַּעֲלֵי יְהוּדָה לְהַעֲלוֹת מִשָּׁם אֵת אֲרוֹן הָאֱלֹהִים אֲשֶׁר־נִקְרָא שֵׁם שֵׁם יְהֹוָה צְבָאוֹת יֹשֵׁב הַכְּרֻבִים עָלָיו׃}
}
{
	\eJ{
		Then David and all the troops that were with him set out from
		Baalim of Judah to bring up from there the Ark of God to which the
		Name was attached, the name LORD of Hosts Enthroned on the
		Cherubim.
	}
}
{
}

\Verse{3}
{
	\hJ{וַיַּרְכִּבוּ אֶת־אֲרוֹן הָאֱלֹהִים אֶל־עֲגָלָה חֲדָשָׁה וַיִּשָּׂאֻהוּ מִבֵּית אֲבִינָדָב אֲשֶׁר בַּגִּבְעָה וְעֻזָּא וְאַחְיוֹ בְּנֵי אֲבִינָדָב נֹהֲגִים אֶת־הָעֲגָלָה חֲדָשָׁה׃}
}
{
	\eJ{
		They loaded the Ark of God onto a new cart and conveyed it from
		the house of Abinadab, which was on the hill; and Abinadab’s sons,
		Uzza and Ahio, guided the new cart.
	}
}
{
}

\Verse{4}
{
	\hJ{וַיִּשָּׂאֻהוּ מִבֵּית אֲבִינָדָב אֲשֶׁר בַּגִּבְעָה עִם אֲרוֹן הָאֱלֹהִים וְאַחְיוֹ הֹלֵךְ לִפְנֵי הָאָרוֹן׃}
}
{
	\eJ{
		They conveyed it from Abinadab’s house on the hill, [Uzza walking]
		alongside the Ark of God and Ahio walking in front of the Ark.
	}
}
{
}

\Verse{5}
{
	\hJ{וְדָוִד וְכל־בֵּית יִשְׂרָאֵל מְשַׂחֲקִים לִפְנֵי יְהֹוָה בְּכֹל עֲצֵי בְרוֹשִׁים וּבְכִנֹּרוֹת וּבִנְבָלִים וּבְתֻפִּים וּבִמְנַעַנְעִים וּבְצֶלְצֱלִים׃}
}
{
	\eJ{
		Meanwhile, David and all the House of Israel danced before YHWH to
		[the sound of] all kinds of cypress wood [instruments], with
		lyres, harps, timbrels, sistrums, and cymbals.
	}
}
{
}

\Verse{6}
{
	\hJ{וַיָּבֹאוּ עַד־גֹּרֶן נָכוֹן וַיִּשְׁלַח עֻזָּה אֶל־אֲרוֹן הָאֱלֹהִים וַיֹּאחֶז בּוֹ כִּי שָׁמְטוּ הַבָּקָר׃}
}
{
	\eJ{
		But when they came to the threshing floor of Nacon, Uzzah reached
		out for the Ark of God and grasped it, for the oxen had stumbled.
	}
}
{
}

\Verse{7}
{
	\hJ{וַיִּחַר־אַף יְהֹוָה בְּעֻזָּה וַיַּכֵּהוּ שָׁם הָאֱלֹהִים עַל־הַשַּׁל וַיָּמת שָׁם עִם אֲרוֹן הָאֱלֹהִים׃}
}
{
	\eJ{
		YHWH was incensed at Uzzah. And God struck him down on the spot
		for his indiscretion, and he died there beside the Ark of God.
	}
}
{
}

\Verse{8}
{
	\hJ{וַיִּחַר לְדָוִד עַל אֲשֶׁר פָּרַץ יְהֹוָה פֶּרֶץ בְּעֻזָּה וַיִּקְרָא לַמָּקוֹם הַהוּא פֶּרֶץ עֻזָּה עַד הַיּוֹם הַזֶּה׃}
}
{
	\eJ{
		David was distressed because YHWH had inflicted a breach upon
		Uzzah; and that place was named Perez-uzzah, as it is still
		called.
	}
}
{
}

\Verse{9}
{
	\hJ{וַיִּרָא דָוִד אֶת־יְהֹוָה בַּיּוֹם הַהוּא וַיֹּאמֶר אֵיךְ יָבוֹא אֵלַי אֲרוֹן יְהֹוָה׃}
}
{
	\eJ{
		David was afraid of YHWH that day; he said, “How can I let the Ark
		of YHWH come to me?”
	}
}
{
}

\Verse{10}
{
	\hJ{וְלֹא־אָבָה דָוִד לְהָסִיר אֵלָיו אֶת־אֲרוֹן יְהֹוָה עַל־עִיר דָּוִד וַיַּטֵּהוּ דָוִד בֵּית עֹבֵד־אֱדֹם הַגִּתִּי׃}
}
{
	\eJ{
		So David would not bring the Ark of YHWH to his place in the City
		of David; instead, David diverted it to the house of Obed-edom the
		Gittite.
	}
}
{
}

\Verse{11}
{
	\hJ{וַיֵּשֶׁב אֲרוֹן יְהֹוָה בֵּית עֹבֵד אֱדֹם הַגִּתִּי שְׁלֹשָׁה חֳדָשִׁים וַיְבָרֶךְ יְהֹוָה אֶת־עֹבֵד אֱדֹם וְאֶת־כּל־בֵּיתוֹ׃}
}
{
	\eJ{
		The Ark of YHWH remained in the house of Obed-edom the Gittite
		three months, and YHWH blessed Obed-edom and his whole household.
	}
}
{
}

\Verse{12}
{
	\hJ{
		וַיֻּגַּד לַמֶּלֶךְ דָּוִד לֵאמֹר בֵּרַךְ יְהֹוָה אֶת־בֵּית עֹבֵד אֱדֹם וְאֶת־כּל־אֲשֶׁר־לוֹ בַּעֲבוּר אֲרוֹן הָאֱלֹהִים וַיֵּלֶךְ דָּוִד וַיַּעַל אֶת־אֲרוֹן הָאֱלֹהִים מִבֵּית
		עֹבֵד אֱדֹם עִיר דָּוִד בְּשִׂמְחָה׃
	}
}
{
	\eJ{
		It was reported to King David: “YHWH has blessed Obed-edom’s house
		and all that belongs to him because of the Ark of God.” Thereupon
		David went and brought up the Ark of God from the house of
		Obed-edom to the City of David, amid rejoicing.
	}
}
{
}

\Verse{13}
{
	\hJ{וַיְהִי כִּי צָעֲדוּ נֹשְׂאֵי אֲרוֹן־יְהֹוָה שִׁשָּׁה צְעָדִים וַיִּזְבַּח שׁוֹר וּמְרִיא׃}
}
{
	\eJ{
		When the bearers of the Ark of YHWH had moved forward six paces,
		he sacrificed an ox and a fatling.
	}
}
{
}

\Verse{14}
{
	\hJ{וְדָוִד מְכַרְכֵּר בְּכל־עֹז לִפְנֵי יְהֹוָה וְדָוִד חָגוּר אֵפוֹד בָּד׃}
}
{
	\eJ{
		David whirled with all his might before YHWH; David was girt with
		a linen ephod.
	}
}

\Verse{15}
{
	\hJ{וְדָוִד וְכל־בֵּית יִשְׂרָאֵל מַעֲלִים אֶת־אֲרוֹן יְהֹוָה בִּתְרוּעָה וּבְקוֹל שׁוֹפָר׃}
}
{
	\eJ{
		Thus David and all the House of Israel brought up the Ark of YHWH
		with shouts and with blasts of the horn.
	}
}
{
}

\Verse{16}
{
	\hJ{
		וְהָיָה אֲרוֹן יְהֹוָה בָּא עִיר דָּוִד וּמִיכַל בַּת־שָׁאוּל נִשְׁקְפָה בְּעַד הַחַלּוֹן וַתֵּרֶא אֶת־הַמֶּלֶךְ דָּוִד מְפַזֵּז וּמְכַרְכֵּר לִפְנֵי יְהֹוָה וַתִּבֶז לוֹ
		בְּלִבָּהּ׃
	}
}
{
	\eJ{
		As the Ark of YHWH entered the City of David, Michal daughter of
		Saul looked out of the window and saw King David leaping and
		whirling before YHWH; and she despised him for it.
	}
}
{
}

\Verse{17}
{
	\hJ{וַיָּבִאוּ אֶת־אֲרוֹן יְהֹוָה וַיַּצִּגוּ אֹתוֹ בִּמְקוֹמוֹ בְּתוֹךְ הָאֹהֶל אֲשֶׁר נָטָה־לוֹ דָּוִד וַיַּעַל דָּוִד עֹלוֹת לִפְנֵי יְהֹוָה וּשְׁלָמִים׃}
}
{
	\eJ{
		They brought in the Ark of YHWH and set it up in its place inside

	}
}
{
}

\Verse{18}
{
	\hJ{וַיְכַל דָּוִד מֵהַעֲלוֹת הָעוֹלָה וְהַשְּׁלָמִים וַיְבָרֶךְ אֶת־הָעָם בְּשֵׁם יְהֹוָה צְבָאוֹת׃}
}
{
	\eJ{
		When David finished sacrificing the burnt offerings and the
		offerings of well-being, he blessed the people in the name of YHWH

	}
}
{
}

\Verse{19}
{
	\hJ{וַיְחַלֵּק לְכל־הָעָם לְכל־הֲמוֹן יִשְׂרָאֵל לְמֵאִישׁ וְעַד־אִשָּׁה לְאִישׁ חַלַּת לֶחֶם אַחַת וְאֶשְׁפָּר אֶחָד וַאֲשִׁישָׁה אֶחָת וַיֵּלֶךְ כּל־הָעָם אִישׁ לְבֵיתוֹ׃}
}
{
	\eJ{
		And he distributed among all the people—the entire multitude of
		Israel, man and woman alike—to each a loaf of bread, a cake made
		in a pan, and a raisin cake. Then all the people left for their
		homes.
	}
}
{
}

\Verse{20}
{
	\hJ{
		וַיָּשׁב דָּוִד לְבָרֵךְ אֶת־בֵּיתוֹוַתֵּצֵא מִיכַל בַּת־שָׁאוּל לִקְרַאת דָּוִד וַתֹּאמֶר מַה־נִּכְבַּד הַיּוֹם מֶלֶךְ יִשְׂרָאֵל אֲשֶׁר נִגְלָה הַיּוֹם לְעֵינֵי אַמְהוֹת עֲבָדָיו

	}
}
{
	\eJ{
		David went home to greet his household. And Michal daughter of
		Saul came out to meet David and said, “Didn’t the king of Israel
		do himself honor today—exposing himself today in the sight of the
		slavegirls of his subjects, as one of the riffraff might expose
		himself!”
	}
}
{
}

\Verse{21}
{
	\hJ{וַיֹּאמֶר דָּוִד אֶל־מִיכַל לִפְנֵי יְהֹוָה אֲשֶׁר בָּחַר־בִּי מֵאָבִיךְ וּמִכּל־בֵּיתוֹ לְצַוֺּת אֹתִי נָגִיד עַל־עַם יְהֹוָה עַל־יִשְׂרָאֵל וְשִׂחַקְתִּי לִפְנֵי יְהֹוָה׃}
}
{

	}
}
{
}
