\Chapter{6}

\Verse{1}
{
	\hJ{וַיֹּסֶף עוֹד דָּוִד אֶת־כּל־בָּחוּר בְּיִשְׂרָאֵל שְׁלֹשִׁים אָלֶף׃}
}
{
	\eJ{
		Again, David gathered together all the chosen men of Israel,
		thirty thousand.
	}
}
{
}

\Verse{2}
{
	\hJ{וַיָּקם וַיֵּלֶךְ דָּוִד וְכל־הָעָם אֲשֶׁר אִתּוֹ מִבַּעֲלֵי יְהוּדָה לְהַעֲלוֹת מִשָּׁם אֵת אֲרוֹן הָאֱלֹהִים אֲשֶׁר־נִקְרָא שֵׁם שֵׁם יְהֹוָה צְבָאוֹת יֹשֵׁב הַכְּרֻבִים עָלָיו׃}
}
{
	\eJ{
		And David arose, and went with all the people that were with him
		from Baale of Judah, to bring up from from there the ark of God,
		whose name is called by the name of YHWH of Armies that lives
		between the cherubims.
	}
}
{
}

\Verse{3}
{
	\hJ{וַיַּרְכִּבוּ אֶת־אֲרוֹן הָאֱלֹהִים אֶל־עֲגָלָה חֲדָשָׁה וַיִּשָּׂאֻהוּ מִבֵּית אֲבִינָדָב אֲשֶׁר בַּגִּבְעָה וְעֻזָּא וְאַחְיוֹ בְּנֵי אֲבִינָדָב נֹהֲגִים אֶת־הָעֲגָלָה חֲדָשָׁה׃}
}
{
	\eJ{
		And they set the ark of God on a new cart, and brought it from
		the house of Abinadab that was in Gibeah: and Uzzah and Ahio,
		the sons of Abinadab, drave the new cart.
	}
}
{
}

\Verse{4}
{
	\hJ{וַיִּשָּׂאֻהוּ מִבֵּית אֲבִינָדָב אֲשֶׁר בַּגִּבְעָה עִם אֲרוֹן הָאֱלֹהִים וְאַחְיוֹ הֹלֵךְ לִפְנֵי הָאָרוֹן׃}
}
{
	\eJ{
		And they brought it from the house of Abinadab that was at
		Gibeah, accompanying the ark of God: and Ahio went before the
		ark.
	}
}
{
}

\Verse{5}
{
	\hJ{וְדָוִד וְכל־בֵּית יִשְׂרָאֵל מְשַׂחֲקִים לִפְנֵי יְהֹוָה בְּכֹל עֲצֵי בְרוֹשִׁים וּבְכִנֹּרוֹת וּבִנְבָלִים וּבְתֻפִּים וּבִמְנַעַנְעִים וּבְצֶלְצֱלִים׃}
}
{
	\eJ{
		And David and all the house of Israel played before YHWH on all
		manner of instruments made of fir wood, even on harps, and on
		psalteries, and on timbrels, and on cornets, and on cymbals.
	}
}
{
}

\Verse{6}
{
	\hJ{וַיָּבֹאוּ עַד־גֹּרֶן נָכוֹן וַיִּשְׁלַח עֻזָּה אֶל־אֲרוֹן הָאֱלֹהִים וַיֹּאחֶז בּוֹ כִּי שָׁמְטוּ הַבָּקָר׃}
}
{
	\eJ{
		And when they came to Nachon’s threshing floor, Uzzah put out
		his hand to the ark of God, and took hold of it; for the oxen
		shook it.
	}
}
{
}

\Verse{7}
{
	\hJ{וַיִּחַר־אַף יְהֹוָה בְּעֻזָּה וַיַּכֵּהוּ שָׁם הָאֱלֹהִים עַל־הַשַּׁל וַיָּמת שָׁם עִם אֲרוֹן הָאֱלֹהִים׃}
}
{
	\eJ{
		And the anger of YHWH was kindled against Uzzah; and God struck
		him there for his error; and there he died by the ark of God.
	}
}
{
}

\Verse{8}
{
	\hJ{וַיִּחַר לְדָוִד עַל אֲשֶׁר פָּרַץ יְהֹוָה פֶּרֶץ בְּעֻזָּה וַיִּקְרָא לַמָּקוֹם הַהוּא פֶּרֶץ עֻזָּה עַד הַיּוֹם הַזֶּה׃}
}
{
	\eJ{
		And David was displeased, because YHWH had made a breach on
		Uzzah: and he called the name of the place Perezuzzah to this
		day.
	}
}
{
}

\Verse{9}
{
	\hJ{וַיִּרָא דָוִד אֶת־יְהֹוָה בַּיּוֹם הַהוּא וַיֹּאמֶר אֵיךְ יָבוֹא אֵלַי אֲרוֹן יְהֹוָה׃}
}
{
	\eJ{
		And David was afraid of YHWH that day, and said, How shall the
		ark of YHWH come to me?
	}
}
{
}

\Verse{10}
{
	\hJ{וְלֹא־אָבָה דָוִד לְהָסִיר אֵלָיו אֶת־אֲרוֹן יְהֹוָה עַל־עִיר דָּוִד וַיַּטֵּהוּ דָוִד בֵּית עֹבֵד־אֱדֹם הַגִּתִּי׃}
}
{
	\eJ{
		So David wouldn't remove the ark of YHWH to him into the city of
		David: but David carried it aside into the house of Obededom the
		Gittite.
	}
}
{
}

\Verse{11}
{
	\hJ{וַיֵּשֶׁב אֲרוֹן יְהֹוָה בֵּית עֹבֵד אֱדֹם הַגִּתִּי שְׁלֹשָׁה חֳדָשִׁים וַיְבָרֶךְ יְהֹוָה אֶת־עֹבֵד אֱדֹם וְאֶת־כּל־בֵּיתוֹ׃}
}
{
	\eJ{
		And the ark of YHWH continued in the house of Obededom the
		Gittite three months: and YHWH blessed Obededom, and all his
		household.
	}
}
{
}

\Verse{12}
{
	\hJ{
		וַיֻּגַּד לַמֶּלֶךְ דָּוִד לֵאמֹר בֵּרַךְ יְהֹוָה אֶת־בֵּית עֹבֵד אֱדֹם וְאֶת־כּל־אֲשֶׁר־לוֹ בַּעֲבוּר אֲרוֹן הָאֱלֹהִים וַיֵּלֶךְ דָּוִד וַיַּעַל אֶת־אֲרוֹן הָאֱלֹהִים מִבֵּית
		עֹבֵד אֱדֹם עִיר דָּוִד בְּשִׂמְחָה׃
	}
}
{
	\eJ{
		And it was told king David, saying, YHWH has blessed the house
		of Obededom, and all that belongs to him, because of the ark of
		God. So David went and brought up the ark of God from the house
		of Obededom into the city of David with gladness.
	}
}
{
}

\Verse{13}
{
	\hJ{וַיְהִי כִּי צָעֲדוּ נֹשְׂאֵי אֲרוֹן־יְהֹוָה שִׁשָּׁה צְעָדִים וַיִּזְבַּח שׁוֹר וּמְרִיא׃}
}
{
	\eJ{
		And it was so, that when they that bare the ark of YHWH had gone
		six paces, he sacrificed oxen and fatlings.
	}
}
{
}

\Verse{14}
{
	\hJ{וְדָוִד מְכַרְכֵּר בְּכל־עֹז לִפְנֵי יְהֹוָה וְדָוִד חָגוּר אֵפוֹד בָּד׃}
}
{
	\eJ{
		And David danced before YHWH with all his might; and David was
		belted with a linen ephod.
	}
}

\Verse{15}
{
	\hJ{וְדָוִד וְכל־בֵּית יִשְׂרָאֵל מַעֲלִים אֶת־אֲרוֹן יְהֹוָה בִּתְרוּעָה וּבְקוֹל שׁוֹפָר׃}
}
{
	\eJ{
		So David and all the house of Israel brought up the ark of YHWH
		with shouting, and with the sound of the trumpet.
	}
}
{
}

\Verse{16}
{
	\hJ{
		וְהָיָה אֲרוֹן יְהֹוָה בָּא עִיר דָּוִד וּמִיכַל בַּת־שָׁאוּל נִשְׁקְפָה בְּעַד הַחַלּוֹן וַתֵּרֶא אֶת־הַמֶּלֶךְ דָּוִד מְפַזֵּז וּמְכַרְכֵּר לִפְנֵי יְהֹוָה וַתִּבֶז לוֹ
		בְּלִבָּהּ׃
	}
}
{
	\eJ{
		And as the ark of YHWH came into the city of David, Michal
		Saul’s daughter looked through a window, and saw king David
		leaping and dancing before YHWH; and she despised him in her
		heart.
	}
}
{
}

\Verse{17}
{
	\hJ{וַיָּבִאוּ אֶת־אֲרוֹן יְהֹוָה וַיַּצִּגוּ אֹתוֹ בִּמְקוֹמוֹ בְּתוֹךְ הָאֹהֶל אֲשֶׁר נָטָה־לוֹ דָּוִד וַיַּעַל דָּוִד עֹלוֹת לִפְנֵי יְהֹוָה וּשְׁלָמִים׃}
}
{
	\eJ{
		And they brought in the ark of YHWH, and set it in his place, in
		the midst of the tabernacle that David had pitched for it: and
		David offered burnt offerings and peace offerings before YHWH.
	}
}
{
}

\Verse{18}
{
	\hJ{וַיְכַל דָּוִד מֵהַעֲלוֹת הָעוֹלָה וְהַשְּׁלָמִים וַיְבָרֶךְ אֶת־הָעָם בְּשֵׁם יְהֹוָה צְבָאוֹת׃}
}
{
	\eJ{
		And as soon as David had made an end of offering burnt offerings

	}
}
{
}

\Verse{19}
{
	\hJ{וַיְחַלֵּק לְכל־הָעָם לְכל־הֲמוֹן יִשְׂרָאֵל לְמֵאִישׁ וְעַד־אִשָּׁה לְאִישׁ חַלַּת לֶחֶם אַחַת וְאֶשְׁפָּר אֶחָד וַאֲשִׁישָׁה אֶחָת וַיֵּלֶךְ כּל־הָעָם אִישׁ לְבֵיתוֹ׃}
}
{
	\eJ{
		And he dealt among all the people, even among the whole
		multitude of Israel, as well to the women as men, to every one a
		cake of bread, and a good piece of flesh, and a flagon of wine.
		So all the people departed every one to his house.
	}
}
{
}

\Verse{20}
{
	\hJ{
		וַיָּשׁב דָּוִד לְבָרֵךְ אֶת־בֵּיתוֹוַתֵּצֵא מִיכַל בַּת־שָׁאוּל לִקְרַאת דָּוִד וַתֹּאמֶר מַה־נִּכְבַּד הַיּוֹם מֶלֶךְ יִשְׂרָאֵל אֲשֶׁר נִגְלָה הַיּוֹם לְעֵינֵי אַמְהוֹת עֲבָדָיו
		כְּהִגָּלוֹת נִגְלוֹת אַחַד הָרֵקִים׃
	}
}
{
	\eJ{
		And David returned to bless his household. And Michal the
		daughter of Saul came out to meet David, and said, How glorious
		was the king of Israel today, who uncovered himself today in the
		eyes of the handmaids of his servants, as one of the vain
		fellows shamelessly uncovers himself!
	}
}
{
}

\Verse{21}
{
	\hJ{וַיֹּאמֶר דָּוִד אֶל־מִיכַל לִפְנֵי יְהֹוָה אֲשֶׁר בָּחַר־בִּי מֵאָבִיךְ וּמִכּל־בֵּיתוֹ לְצַוֺּת אֹתִי נָגִיד עַל־עַם יְהֹוָה עַל־יִשְׂרָאֵל וְשִׂחַקְתִּי לִפְנֵי יְהֹוָה׃}
}
{
	\eJ{

		before YHWH.
	}
}
{
}
