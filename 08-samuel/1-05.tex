\Chapter{5}

\Verse{1}
{
	\hJ{וּפְלִשְׁתִּים לָקְחוּ אֵת אֲרוֹן הָאֱלֹהִים וַיְבִאֻהוּ מֵאֶבֶן הָעֵזֶר אַשְׁדּוֹדָה׃}
}
{
	\eJ{
		When the Philistines captured the Ark of God, they brought it from
		Eben-ezer to Ashdod.
	}
}
{
}

\Verse{2}
{
	\hJ{וַיִּקְחוּ פְלִשְׁתִּים אֶת־אֲרוֹן הָאֱלֹהִים וַיָּבִאוּ אֹתוֹ בֵּית דָּגוֹן וַיַּצִּיגוּ אֹתוֹ אֵצֶל דָּגוֹן׃}
}
{
	\eJ{
		The Philistines took the Ark of God and brought it into the temple
		of Dagon and they set it up beside Dagon.
	}
}
{
}

\Verse{3}
{
	\hJ{וַיַּשְׁכִּמוּ אַשְׁדּוֹדִים מִמּחֳרָת וְהִנֵּה דָגוֹן נֹפֵל לְפָנָיו אַרְצָה לִפְנֵי אֲרוֹן יְהֹוָה וַיִּקְחוּ אֶת־דָּגוֹן וַיָּשִׁבוּ אֹתוֹ לִמְקוֹמוֹ׃}
}
{
	\eJ{
		Early the next day, the Ashdodites found Dagon lying face down on
		the ground in front of the Ark of YHWH. They picked Dagon up and
		put him back in his place;
	}
}
{
}

\Verse{4}
{
	\hJ{
		וַיַּשְׁכִּמוּ בַבֹּקֶר מִמּחֳרָת וְהִנֵּה דָגוֹן נֹפֵל לְפָנָיו אַרְצָה לִפְנֵי אֲרוֹן יְהֹוָה וְרֹאשׁ דָּגוֹן וּשְׁתֵּי כַּפּוֹת יָדָיו כְּרֻתוֹת אֶל־הַמִּפְתָּן רַק דָּגוֹן
		נִשְׁאַר עָלָיו׃
	}
}
{
	\eJ{
		but early the next morning, Dagon was again lying prone on the
		ground in front of the Ark of YHWH. The head and both hands of
		Dagon were cut off, lying on the threshold; only Dagon’s trunk was
		left intact.
	}
}
{
}

\Verse{5}
{
	\hJ{עַל־כֵּן לֹא־יִדְרְכוּ כֹהֲנֵי דָגוֹן וְכל־הַבָּאִים בֵּית־דָּגוֹן עַל־מִפְתַּן דָּגוֹן בְּאַשְׁדּוֹד עַד הַיּוֹם הַזֶּה׃}
}
{
	\eJ{
		That is why, to this day, the priests of Dagon and all who enter
		the temple of Dagon do not tread on the threshold of Dagon in
		Ashdod.
	}
}
{
}

\Verse{6}
{
	\hJ{וַתִּכְבַּד יַד־יְהֹוָה אֶל־הָאַשְׁדּוֹדִים וַיְשִׁמֵּם וַיַּךְ אֹתָם (בעפלים) [בַּטְּחֹרִים] אֶת־אַשְׁדּוֹד וְאֶת־גְּבוּלֶיהָ׃}
}
{
	\eJ{
		The hand of YHWH lay heavy upon the Ashdodites, and He wrought
		havoc among them: He struck Ashdod and its territory with
		hemorrhoids.
	}
}
{
	Qere Ketiv.
}

\Verse{7}
{
	\hJ{וַיִּרְאוּ אַנְשֵׁי־אַשְׁדּוֹד כִּי־כֵן וְאָמְרוּ לֹא־יֵשֵׁב אֲרוֹן אֱלֹהֵי יִשְׂרָאֵל עִמָּנוּ כִּי־קָשְׁתָה יָדוֹ עָלֵינוּ וְעַל דָּגוֹן אֱלֹהֵינוּ׃}
}
{
	\eJ{
		When the men of Ashdod saw how matters stood, they said, “The Ark
		of the God of Israel must not remain with us, for His hand has
		dealt harshly with us and with our god Dagon.”
	}
}
{
}

\Verse{8}
{
	\hJ{
		וַיִּשְׁלְחוּ וַיַּאַסְפוּ אֶת־כּל־סַרְנֵי פְלִשְׁתִּים אֲלֵיהֶם וַיֹּאמְרוּ מַה־נַּעֲשֶׂה לַאֲרוֹן אֱלֹהֵי יִשְׂרָאֵל וַיֹּאמְרוּ גַּת יִסֹּב אֲרוֹן אֱלֹהֵי יִשְׂרָאֵל
		וַיַּסֵּבּוּ אֶת־אֲרוֹן אֱלֹהֵי יִשְׂרָאֵל׃
	}
}
{
	\eJ{
		They sent messengers and assembled all the lords of the
		Philistines and asked, “What shall we do with the Ark of the God
		of Israel?” They answered, “Let the Ark of the God of Israel be
		removed to Gath.” So they moved the Ark of the God of Israel [to
		Gath].
	}
}
{
}

\Verse{9}
{
	\hJ{וַיְהִי אַחֲרֵי הֵסַבּוּ אֹתוֹ וַתְּהִי יַד־יְהֹוָה בָּעִיר מְהוּמָה גְּדוֹלָה מְאֹד וַיַּךְ אֶת־אַנְשֵׁי הָעִיר מִקָּטֹן וְעַד־גָּדוֹל וַיִּשָּׂתְרוּ לָהֶם (עפלים) [טְחֹרִים]׃}
}
{
	\eJ{
		And after they had moved it, the hand of YHWH came against the
		city, causing great panic; He struck the people of the city, young
		and old, so that hemorrhoids broke out among them.
	}
}
{
	Qere Ketiv.
}

\Verse{10}
{
	\hJ{
		וַיְשַׁלְּחוּ אֶת־אֲרוֹן הָאֱלֹהִים עֶקְרוֹן וַיְהִי כְּבוֹא אֲרוֹן הָאֱלֹהִים עֶקְרוֹן וַיִּזְעֲקוּ הָעֶקְרֹנִים לֵאמֹר הֵסַבּוּ אֵלַי אֶת־אֲרוֹן אֱלֹהֵי יִשְׂרָאֵל לַהֲמִיתֵנִי
		וְאֶת־עַמִּי׃
	}
}
{
	\eJ{
		Then they sent the Ark of God to Ekron. But when the Ark of God
		came to Ekron, the Ekronites cried out, “They have moved the Ark
		of the God of Israel to us to slay us and our kindred.”
	}
}
{
}

\Verse{11}
{
	\hJ{
		וַיִּשְׁלְחוּ וַיַּאַסְפוּ אֶת־כּל־סַרְנֵי פְלִשְׁתִּים וַיֹּאמְרוּ שַׁלְּחוּ אֶת־אֲרוֹן אֱלֹהֵי יִשְׂרָאֵל וְיָשֹׁב לִמְקוֹמוֹ וְלֹא־יָמִית אֹתִי וְאֶת־עַמִּי כִּי־הָיְתָה
		מְהוּמַת־מָוֶת בְּכל־הָעִיר כָּבְדָה מְאֹד יַד הָאֱלֹהִים שָׁם׃
	}
}
{
	\eJ{
		They too sent messengers and assembled all the lords of the
		Philistines and said, “Send the Ark of the God of Israel away, and
		let it return to its own place, that it may not slay us and our
		kindred.” For the panic of death pervaded the whole city, so
		heavily had the hand of God fallen there;
	}
}
{
}

\Verse{12}
{
	\hJ{וְהָאֲנָשִׁים אֲשֶׁר לֹא־מֵתוּ הֻכּוּ (בעפלים) [בַּטְּחֹרִים] וַתַּעַל שַׁוְעַת הָעִיר הַשָּׁמָיִם׃}
}
{
	\eJ{
		and the men who did not die were stricken with hemorrhoids. The
		outcry of the city went up to heaven.
	}
}
{
	Qere Ketiv.
}
