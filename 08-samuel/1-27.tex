\Chapter{27}

\Verse{1}
{
	\hJ{
		וַיֹּאמֶר דָּוִד אֶל־לִבּוֹ עַתָּה אֶסָּפֶה יוֹם־אֶחָד בְּיַד־שָׁאוּל אֵין־לִי טוֹב כִּי הִמָּלֵט אִמָּלֵט אֶל־אֶרֶץ פְּלִשְׁתִּים וְנוֹאַשׁ מִמֶּנִּי שָׁאוּל לְבַקְשֵׁנִי עוֹד
		בְּכל־גְּבוּל יִשְׂרָאֵל וְנִמְלַטְתִּי מִיָּדוֹ׃
	}
}
{
	\eJ{
		And David said in his heart, I shall now perish one day by the
		hand of Saul: there is nothing better for me than that I should
		speedily escape into the land of the Philistines: and Saul shall
		despair of me, to seek me any more in any border of Israel: so
		shall I escape out of his hand.
	}
}
{
}

\Verse{2}
{
	\hJ{וַיָּקם דָּוִד וַיַּעֲבֹר הוּא וְשֵׁשׁ־מֵאוֹת אִישׁ אֲשֶׁר עִמּוֹ אֶל־אָכִישׁ בֶּן־מָעוֹךְ מֶלֶךְ גַּת׃}
}
{
	\eJ{
		And David arose, and he passed over with the six hundred men
		that were with him to Achish, the son of Maoch, king of Gath.
	}
}
{
}

\Verse{3}
{
	\hJ{וַיֵּשֶׁב דָּוִד עִם־אָכִישׁ בְּגַת הוּא וַאֲנָשָׁיו אִישׁ וּבֵיתוֹ דָּוִד וּשְׁתֵּי נָשָׁיו אֲחִינֹעַם הַיִּזְרְעֵאלִת וַאֲבִיגַיִל אֵשֶׁת־נָבָל הַכַּרְמְלִית׃}
}
{
	\eJ{
		And David lived with Achish at Gath, he and his men, every man
		with his household, even David with his two wives, Ahinoam the
		Jezreelitess, and Abigail the Carmelitess, Nabal’s wife.
	}
}
{
}

\Verse{4}
{
	\hJ{וַיֻּגַּד לְשָׁאוּל כִּי־בָרַח דָּוִד גַּת וְלֹא־[יָסַף] (יוסף) עוֹד לְבַקְשׁוֹ׃}
}
{
	\eJ{
		And it was told Saul that David was fled to Gath: and he sought
		no more again for him.
	}
}
{
	Qere Ketiv.
}

\Verse{5}
{
	\hJ{וַיֹּאמֶר דָּוִד אֶל־אָכִישׁ אִם־נָא מָצָאתִי חֵן בְּעֵינֶיךָ יִתְּנוּ־לִי מָקוֹם בְּאַחַת עָרֵי הַשָּׂדֶה וְאֵשְׁבָה שָּׁם וְלָמָּה יֵשֵׁב עַבְדְּךָ בְּעִיר הַמַּמְלָכָה עִמָּךְ׃}
}
{
	\eJ{
		And David said to Achish, If I've now found favor in your eyes,
		let them give me a place in some town in the country, that I may
		live there: for why should your servant live in the royal city
		with you?
	}
}
{
}

\Verse{6}
{
	\hJ{וַיִּתֶּן־לוֹ אָכִישׁ בַּיּוֹם הַהוּא אֶת־צִקְלָג לָכֵן הָיְתָה צִקְלַג לְמַלְכֵי יְהוּדָה עַד הַיּוֹם הַזֶּה׃}
}
{
	\eJ{
		And Achish gave him Ziklag that day: why Ziklag belongs to the
		kings of Judah to this day.
	}
}
{
}

\Verse{7}
{
	\hJ{וַיְהִי מִסְפַּר הַיָּמִים אֲשֶׁר־יָשַׁב דָּוִד בִּשְׂדֵה פְלִשְׁתִּים יָמִים וְאַרְבָּעָה חֳדָשִׁים׃}
}
{
	\eJ{
		And the time that David lived in the country of the Philistines
		was a full year and four months.
	}
}
{
}

\Verse{8}
{
	\hJ{
		וַיַּעַל דָּוִד וַאֲנָשָׁיו וַיִּפְשְׁטוּ אֶל־הַגְּשׁוּרִי (והגרזי) [וְהַגִּזְרִי] וְהָעֲמָלֵקִי כִּי הֵנָּה יֹשְׁבוֹת הָאָרֶץ אֲשֶׁר מֵעוֹלָם בּוֹאֲךָ שׁוּרָה וְעַד־אֶרֶץ
		מִצְרָיִם׃
	}
}
{
	\eJ{
		And David and his men went up, and invaded the Geshurites, and
		the Gezrites, and the Amalekites: for those nations were of old
		the inhabitants of the land, as you go to Shur, even to the land
		of Egypt.
	}
}
{
	Qere Ketiv.
}

\Verse{9}
{
	\hJ{וְהִכָּה דָוִד אֶת־הָאָרֶץ וְלֹא יְחַיֶּה אִישׁ וְאִשָּׁה וְלָקַח צֹאן וּבָקָר וַחֲמֹרִים וּגְמַלִּים וּבְגָדִים וַיָּשׁב וַיָּבֹא אֶל־אָכִישׁ׃}
}
{
	\eJ{
		And David struck the land, and left neither man nor woman alive,
		and took away the sheep, and the cattle, and the asses, and the
		camels, and the apparel, and returned, and came to Achish.
	}
}
{
}

\Verse{10}
{
	\hJ{וַיֹּאמֶר אָכִישׁ אַל־פְּשַׁטְתֶּם הַיּוֹם וַיֹּאמֶר דָּוִד עַל־נֶגֶב יְהוּדָה וְעַל־נֶגֶב הַיְּרַחְמְאֵלִי וְאֶל־נֶגֶב הַקֵּינִי׃}
}
{
	\eJ{
		And Achish said, Where have you made a road today? And David
		said, Against the south of Judah, and against the south of the
		Jerahmeelites, and against the south of the Kenites.
	}
}
{
}

\Verse{11}
{
	\hJ{וְאִישׁ וְאִשָּׁה לֹא־יְחַיֶּה דָוִד לְהָבִיא גַת לֵאמֹר פֶּן־יַגִּדוּ עָלֵינוּ לֵאמֹר כֹּה־עָשָׂה דָוִד וְכֹה מִשְׁפָּטוֹ כּל־הַיָּמִים אֲשֶׁר יָשַׁב בִּשְׂדֵה פְלִשְׁתִּים׃}
}
{
	\eJ{
		And David saved neither man nor woman alive, to bring news to
		Gath, saying, Or else they should tell on us, saying, So did
		David, and so will be his manner all the while he lives in the
		country of the Philistines.
	}
}
{
}

\Verse{12}
{
	\hJ{וַיַּאֲמֵן אָכִישׁ בְּדָוִד לֵאמֹר הַבְאֵשׁ הִבְאִישׁ בְּעַמּוֹ בְיִשְׂרָאֵל וְהָיָה לִי לְעֶבֶד עוֹלָם׃}
}
{
	\eJ{
		And Achish believed David, saying, He has made his people Israel
		utterly to abhor him: therefore he shall be my servant forever.
	}
}
{
}
