	\hX{וְדָוִד עֹלֶה בְמַעֲלֵה הַזֵּיתִים עֹלֶה וּבוֹכֶה וְרֹאשׁ לוֹ חָפוּי וְהוּא הֹלֵךְ יָחֵף וְכל־הָעָם אֲשֶׁר־אִתּוֹ חָפוּ אִישׁ רֹאשׁוֹ וְעָלוּ עָלֹה וּבָכֹה׃}
}
{
	\eX{
		And David went up by the ascent of mount Olivet, and wept as he
		went up, and had his head covered, and he went barefoot: and all
		the people that was with him covered every man his head, and
		they went up, weeping as they went up.
	}
}
{
}

\Verse{31}
{
	\hX{וְדָוִד הִגִּיד לֵאמֹר אֲחִיתֹפֶל בַּקֹּשְׁרִים עִם־אַבְשָׁלוֹם וַיֹּאמֶר דָּוִד סַכֶּל־נָא אֶת־עֲצַת אֲחִיתֹפֶל יְהֹוָה׃}
}
{
	\eX{
		And one told David, saying, Ahithophel is among the conspirators
		with Absalom. And David said, O YHWH, please, turn the counsel
		of Ahithophel into foolishness.
	}
}
{
}

\Verse{32}
{
	\hX{וַיְהִי דָוִד בָּא עַד־הָרֹאשׁ אֲשֶׁר־יִשְׁתַּחֲוֶה שָׁם לֵאלֹהִים וְהִנֵּה לִקְרָאתוֹ חוּשַׁי הָאַרְכִּי קָרוּעַ כֻּתּנְתּוֹ וַאֲדָמָה עַל־רֹאשׁוֹ׃}
}
{
	\eX{
		And it was, that when David came to the top of the mount, where
		he worshipped God, here: Hushai the Archite came to meet him
		with his coat torn, and earth on his head:
	}
}
{
}

\Verse{33}
{
	\hX{וַיֹּאמֶר לוֹ דָּוִד אִם עָבַרְתָּ אִתִּי וְהָיִתָ עָלַי לְמַשָּׂא׃}
}
{
	\eX{
		To whom David said, If you pass on with me, then you shall be a
		burden to me:
	}
}
{
}

\Verse{34}
{
	\hX{וְאִם־הָעִיר תָּשׁוּב וְאָמַרְתָּ לְאַבְשָׁלוֹם עַבְדְּךָ אֲנִי הַמֶּלֶךְ אֶהְיֶה עֶבֶד אָבִיךָ וַאֲנִי מֵאָז וְעַתָּה וַאֲנִי עַבְדֶּךָ וְהֵפַרְתָּה לִי אֵת עֲצַת אֲחִיתֹפֶל׃}
}
{
	\eX{
		But if you return to the city, and say to Absalom, I'll be your
		servant, O king; as I've been your father’s servant here, so
		will I now also be your servant: then may you for me defeat the
		counsel of Ahithophel.
	}
}
{
}

\Verse{35}
{
	\hX{וַהֲלוֹא עִמְּךָ שָׁם צָדוֹק וְאֶבְיָתָר הַכֹּהֲנִים וְהָיָה כּל־הַדָּבָר אֲשֶׁר תִּשְׁמַע מִבֵּית הַמֶּלֶךְ תַּגִּיד לְצָדוֹק וּלְאֶבְיָתָר הַכֹּהֲנִים׃}
}
{
	\eX{
		And have you not there with you Zadok and Abiathar the priests?
		so it shall be, that whatever thing you shall hear from the
		king’s house, you shall tell it to Zadok and Abiathar the
		priests.
	}
}
{
}

\Verse{36}
{
	\hX{הִנֵּה־שָׁם עִמָּם שְׁנֵי בְנֵיהֶם אֲחִימַעַץ לְצָדוֹק וִיהוֹנָתָן לְאֶבְיָתָר וּשְׁלַחְתֶּם בְּיָדָם אֵלַי כּל־דָּבָר אֲשֶׁר תִּשְׁמָעוּ׃}
}
{
	\eX{
		Here: they've there with them their two sons, Ahimaaz Zadok’s
		son, and Jonathan Abiathar’s son; and by them you shall send to
		me every thing that you can hear.
	}
}
{
}
