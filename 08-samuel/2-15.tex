}
{
	\eJ{
		David meanwhile went up the slope of the [Mount of] Olives,
		weeping as he went; his head was covered and he walked barefoot.
		And all the people who were with him covered their heads and wept
		as they went up.
	}
}

}
{
	\eJ{

}

}

}

\Verse{34}
{
	\hJ{וְאִם־הָעִיר תָּשׁוּב וְאָמַרְתָּ לְאַבְשָׁלוֹם עַבְדְּךָ אֲנִי הַמֶּלֶךְ אֶהְיֶה עֶבֶד אָבִיךָ וַאֲנִי מֵאָז וְעַתָּה וַאֲנִי עַבְדֶּךָ וְהֵפַרְתָּה לִי אֵת עֲצַת אֲחִיתֹפֶל׃}
}
{
	\eJ{
		But if you go back to the city and say to Absalom, ‘I will be your
		servant, O king; I was your father’s servant formerly, and now I
		will be yours,’ then you can nullify Ahithophel’s counsel for me.
	}
}
{
}

}
{
	\eJ{
		You will have the priests Zadok and Abiathar there, and you can

}
{
}
