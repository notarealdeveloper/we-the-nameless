\Chapter{16}

\Verse{1}
{
	\hX{וְדָוִד עָבַר מְעַט מֵהָרֹאשׁ וְהִנֵּה צִיבָא נַעַר מְפִיבֹשֶׁת לִקְרָאתוֹ וְצֶמֶד חֲמֹרִים חֲבֻשִׁים וַעֲלֵיהֶם מָאתַיִם לֶחֶם וּמֵאָה צִמּוּקִים וּמֵאָה קַיִץ וְנֵבֶל יָיִן׃}
}
{
	\eX{
		And when David was a little past the top of the hill, here: Ziba
		the servant of Mephibosheth met him, with a couple of asses
		saddled, and on them two hundred loaves of bread, and a hundred
		bunches of raisins, and a hundred summer fruits, and a bottle of
		wine.
	}
}
{
}

\Verse{2}
{
	\hX{
		וַיֹּאמֶר הַמֶּלֶךְ אֶל־צִיבָא מָה־אֵלֶּה לָּךְ וַיֹּאמֶר צִיבָא הַחֲמוֹרִים לְבֵית־הַמֶּלֶךְ לִרְכֹּב (ולהלחם) [וְהַלֶּחֶם] וְהַקַּיִץ לֶאֱכוֹל הַנְּעָרִים וְהַיַּיִן לִשְׁתּוֹת
		הַיָּעֵף בַּמִּדְבָּר׃
	}
}
{
	\eX{
		And the king said to Ziba, What are these to you? And Ziba said,
		The asses be for the king’s household to ride on; and the bread
		and summer fruit for the young men to eat; and the wine, that
		such as be faint in the wilderness may drink.
	}
}
{
}

\Verse{3}
{
	\hX{וַיֹּאמֶר הַמֶּלֶךְ וְאַיֵּה בֶּן־אֲדֹנֶיךָ וַיֹּאמֶר צִיבָא אֶל־הַמֶּלֶךְ הִנֵּה יוֹשֵׁב בִּירוּשָׁלַ͏ִם כִּי אָמַר הַיּוֹם יָשִׁיבוּ לִי בֵּית יִשְׂרָאֵל אֵת מַמְלְכוּת אָבִי׃}
}
{
	\eX{
		And the king said, And where is your master’s son? And Ziba said
		to the king, Here: he stays at Jerusalem: for he said, Today
		shall the house of Israel restore me the kingdom of my father.
	}
}
{
}

\Verse{4}
{
	\hX{וַיֹּאמֶר הַמֶּלֶךְ לְצִבָא הִנֵּה לְךָ כֹּל אֲשֶׁר לִמְפִיבֹשֶׁת וַיֹּאמֶר צִיבָא הִשְׁתַּחֲוֵיתִי אֶמְצָא־חֵן בְּעֵינֶיךָ אֲדֹנִי הַמֶּלֶךְ׃}
}
{
	\eX{
		And the king said to Ziba, Here: all that belonged to
		Mephibosheth is yours. And Ziba said, Please let me find favor
		in your eyes, my lord, O king.
	}
}
{
}

\Verse{5}
{
	\hX{וּבָא הַמֶּלֶךְ דָּוִד עַד־בַּחוּרִים וְהִנֵּה מִשָּׁם אִישׁ יוֹצֵא מִמִּשְׁפַּחַת בֵּית־שָׁאוּל וּשְׁמוֹ שִׁמְעִי בֶן־גֵּרָא יֹצֵא יָצוֹא וּמְקַלֵּל׃}
}
{
	\eX{
		And when king David came to Bahurim, here: from there came out a
		man of the family of the house of Saul, whose name was Shimei,
		the son of Gera: he came forth, and cursed still as he came.
	}
}
{
}

\Verse{6}
{
	\hX{וַיְסַקֵּל בָּאֲבָנִים אֶת־דָּוִד וְאֶת־כּל־עַבְדֵי הַמֶּלֶךְ דָּוִד וְכל־הָעָם וְכל־הַגִּבֹּרִים מִימִינוֹ וּמִשְּׂמֹאלוֹ׃}
}
{
	\eX{
		And he cast stones at David, and at all the servants of king
		David: and all the people and all the heroes were on his right
		hand and on his left.
	}
}
{
}

\Verse{7}
{
	\hX{וְכֹה־אָמַר שִׁמְעִי בְּקַלְלוֹ צֵא צֵא אִישׁ הַדָּמִים וְאִישׁ הַבְּלִיָּעַל׃}
}
{
	\eX{
		And thus said Shimei when he cursed, Come out, come out, you
		bloody man, and you man of Belial:
	}
}
{
}

\Verse{8}
{
	\hX{
		הֵשִׁיב עָלֶיךָ יְהֹוָה כֹּל דְּמֵי בֵית־שָׁאוּל אֲשֶׁר מָלַכְתָּ תַּחְתָּו וַיִּתֵּן יְהֹוָה אֶת־הַמְּלוּכָה בְּיַד אַבְשָׁלוֹם בְּנֶךָ וְהִנְּךָ בְּרָעָתֶךָ כִּי אִישׁ דָּמִים
		אָתָּה׃
	}
}
{
	\eX{
		YHWH has returned on you all the blood of the house of Saul, in
		whose stead you have reigned; and YHWH has delivered the kingdom
		into the hand of Absalom your son: and, here: you are taken in
		your mischief, because you are a bloody man.
	}
}
{
}

\Verse{9}
{
	\hX{וַיֹּאמֶר אֲבִישַׁי בֶּן־צְרוּיָה אֶל־הַמֶּלֶךְ לָמָּה יְקַלֵּל הַכֶּלֶב הַמֵּת הַזֶּה אֶת־אֲדֹנִי הַמֶּלֶךְ אֶעְבְּרָה־נָּא וְאָסִירָה אֶת־רֹאשׁוֹ׃}
}
{
	\eX{
		And Abishai said the son of Zeruiah to the king, Why should this
		dead dog curse my lord the king? let me go over, please, and
		take off his head.
	}
}
{
}

\Verse{10}
{
	\hX{וַיֹּאמֶר הַמֶּלֶךְ מַה־לִּי וְלָכֶם בְּנֵי צְרֻיָה (כי) [כֹּה] יְקַלֵּל (וכי) [כִּי] יְהֹוָה אָמַר לוֹ קַלֵּל אֶת־דָּוִד וּמִי יֹאמַר מַדּוּעַ עָשִׂיתָה כֵּן׃}
}
{
	\eX{
		And the king said, What have I to do with you, you sons of
		Zeruiah? so let him curse, because YHWH has said to him, Curse
		David. Who shall then say, Why have you done so?
	}
}
{
}

\Verse{11}
{
	\hX{
		וַיֹּאמֶר דָּוִד אֶל־אֲבִישַׁי וְאֶל־כּל־עֲבָדָיו הִנֵּה בְנִי אֲשֶׁר־יָצָא מִמֵּעַי מְבַקֵּשׁ אֶת־נַפְשִׁי וְאַף כִּי־עַתָּה בֶּן־הַיְמִינִי הַנִּחוּ לוֹ וִיקַלֵּל כִּי אָמַר־לוֹ
		יְהֹוָה׃
	}
}
{
	\eX{
		And David said to Abishai, and to all his servants, Here: my
		son, that came out from my body, seeks my life: how much more
		now may this Benjamite do it? let him alone, and let him curse;
		for YHWH has bidden him.
	}
}
{
}

\Verse{12}
{
	\hX{אוּלַי יִרְאֶה יְהֹוָה (בעוני) [בְּעֵינִי] וְהֵשִׁיב יְהֹוָה לִי טוֹבָה תַּחַת קִלְלָתוֹ הַיּוֹם הַזֶּה׃}
}
{
	\eX{
		It may be that YHWH will look on mine affliction, and that YHWH
		will requite me good for his cursing this day.
	}
}
{
}

\Verse{13}
{
	\hX{וַיֵּלֶךְ דָּוִד וַאֲנָשָׁיו בַּדָּרֶךְוְשִׁמְעִי הֹלֵךְ בְּצֵלַע הָהָר לְעֻמָּתוֹ הָלוֹךְ וַיְקַלֵּל וַיְסַקֵּל בָּאֲבָנִים לְעֻמָּתוֹ וְעִפַּר בֶּעָפָר׃}
}
{
	\eX{
		And as David and his men went by the way, Shimei went along on
		the hill’s side over against him, and cursed as he went, and
		threw stones at him, and cast dust.
	}
}
{
}

\Verse{14}
{
	\hX{וַיָּבֹא הַמֶּלֶךְ וְכל־הָעָם אֲשֶׁר־אִתּוֹ עֲיֵפִים וַיִּנָּפֵשׁ שָׁם׃}
}
{
	\eX{
		And the king, and all the people that were with him, came weary,
		and refreshed themselves there.
	}
}
{
}

\Verse{15}
{
	\hX{וְאַבְשָׁלוֹם וְכל־הָעָם אִישׁ יִשְׂרָאֵל בָּאוּ יְרוּשָׁלָ͏ִם וַאֲחִיתֹפֶל אִתּוֹ׃}
}
{
	\eX{
		And Absalom, and all the people the men of Israel, came to
		Jerusalem, and Ahithophel with him.
	}
}
{
}

\Verse{16}
{
	\hX{וַיְהִי כַּאֲשֶׁר־בָּא חוּשַׁי הָאַרְכִּי רֵעֶה דָוִד אֶל־אַבְשָׁלוֹם וַיֹּאמֶר חוּשַׁי אֶל־אַבְשָׁלוֹם יְחִי הַמֶּלֶךְ יְחִי הַמֶּלֶךְ׃}
}
{
	\eX{
		And it was, when Hushai the Archite, David’s friend, came to
		Absalom, that Hushai said to Absalom, God except the king, God
		except the king.
	}
}
{
}

\Verse{17}
{
	\hX{וַיֹּאמֶר אַבְשָׁלוֹם אֶל־חוּשַׁי זֶה חַסְדְּךָ אֶת־רֵעֶךָ לָמָּה לֹא־הָלַכְתָּ אֶת־רֵעֶךָ׃}
}
{
	\eX{
		And Absalom said to Hushai, Is this your kindness to your
		friend? why did you go not with your friend?
	}
}
{
}

\Verse{18}
{
	\hX{וַיֹּאמֶר חוּשַׁי אֶל־אַבְשָׁלֹם לֹא כִּי אֲשֶׁר בָּחַר יְהֹוָה וְהָעָם הַזֶּה וְכל־אִישׁ יִשְׂרָאֵל (לא) [לוֹ] אֶהְיֶה וְאִתּוֹ אֵשֵׁב׃}
}
{
	\eX{
		And Hushai said to Absalom, No; but whom YHWH, and this people,
		and all the men of Israel, choose, his will I be, and with him
		will I abide.
	}
}
{
}

\Verse{19}
{
	\hX{וְהַשֵּׁנִית לְמִי אֲנִי אֶעֱבֹד הֲלוֹא לִפְנֵי בְנוֹ כַּאֲשֶׁר עָבַדְתִּי לִפְנֵי אָבִיךָ כֵּן אֶהְיֶה לְפָנֶיךָ׃}
}
{
	\eX{
		And again, whom should I serve? should I not serve in the
		presence of his son? as I've served in your father’s presence,
		so will I be in your presence.
	}
}
{
}

\Verse{20}
{
	\hX{וַיֹּאמֶר אַבְשָׁלוֹם אֶל־אֲחִיתֹפֶל הָבוּ לָכֶם עֵצָה מַה־נַּעֲשֶׂה׃}
}
{
	\eX{
		And Absalom said to Ahithophel, Give counsel among you what we
		shall do.
	}
}
{
}

\Verse{21}
{
	\hX{
		וַיֹּאמֶר אֲחִיתֹפֶל אֶל־אַבְשָׁלֹם בּוֹא אֶל־פִּלַגְשֵׁי אָבִיךָ אֲשֶׁר הִנִּיחַ לִשְׁמוֹר הַבָּיִת וְשָׁמַע כּל־יִשְׂרָאֵל כִּי־נִבְאַשְׁתָּ אֶת־אָבִיךָ וְחָזְקוּ יְדֵי
		כּל־אֲשֶׁר אִתָּךְ׃
	}
}
{
	\eX{
		And Ahithophel said to Absalom, Go in to your father’s
		concubines, that he has left to keep the house; and all Israel
		shall hear that you are abhorred of your father: then shall the
		hands of all that are with you be strong.
	}
}
{
}

\Verse{22}
{
	\hX{וַיַּטּוּ לְאַבְשָׁלוֹם הָאֹהֶל עַל־הַגָּג וַיָּבֹא אַבְשָׁלוֹם אֶל־פִּלַגְשֵׁי אָבִיו לְעֵינֵי כּל־יִשְׂרָאֵל׃}
}
{
	\eX{
		So they spread Absalom a tent on the top of the house; and
		Absalom went in to his father’s concubines in the eyes of all
		Israel.
	}
}
{
}

\Verse{23}
{
	\hX{וַעֲצַת אֲחִיתֹפֶל אֲשֶׁר יָעַץ בַּיָּמִים הָהֵם כַּאֲשֶׁר יִשְׁאַל־[אִישׁ] בִּדְבַר הָאֱלֹהִים כֵּן כּל־עֲצַת אֲחִיתֹפֶל גַּם־לְדָוִד גַּם לְאַבְשָׁלֹם׃}
}
{
	\eX{
		And the counsel of Ahithophel, that he counselled in those days,
		was as if a man had enquired at the oracle of God: so was all
		the counsel of Ahithophel both with David and with Absalom.
	}
}
{
}
