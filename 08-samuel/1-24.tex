\Chapter{24}

\Verse{1}
{
	\hX{וַיַּעַל דָּוִד מִשָּׁם וַיֵּשֶׁב בִּמְצָדוֹת עֵין־גֶּדִי׃}
}
{
	\eX{
		And David went up from from there, and lived in strong holds at
		Engedi.
	}
}
{
}

\Verse{2}
{
	\hX{וַיְהִי כַּאֲשֶׁר שָׁב שָׁאוּל מֵאַחֲרֵי פְּלִשְׁתִּים וַיַּגִּדוּ לוֹ לֵאמֹר הִנֵּה דָוִד בְּמִדְבַּר עֵין גֶּדִי׃}
}
{
	\eX{
		And it was when Saul was returned from following the
		Philistines, that it was told him, saying, Here: David is in the
		wilderness of Engedi.
	}
}
{
}

\Verse{3}
{
	\hX{וַיִּקַּח שָׁאוּל שְׁלֹשֶׁת אֲלָפִים אִישׁ בָּחוּר מִכּל־יִשְׂרָאֵל וַיֵּלֶךְ לְבַקֵּשׁ אֶת־דָּוִד וַאֲנָשָׁיו עַל־פְּנֵי צוּרֵי הַיְּעֵלִים׃}
}
{
	\eX{
		And Saul took three thousand chosen men out of all Israel, and
		went to seek David and his men on the rocks of the wild goats.
	}
}
{
}

\Verse{4}
{
	\hX{וַיָּבֹא אֶל־גִּדְרוֹת הַצֹּאן עַל־הַדֶּרֶךְ וְשָׁם מְעָרָה וַיָּבֹא שָׁאוּל לְהָסֵךְ אֶת־רַגְלָיו וְדָוִד וַאֲנָשָׁיו בְּיַרְכְּתֵי הַמְּעָרָה יֹשְׁבִים׃}
}
{
	\eX{
		And he came to the sheepcotes by the way, where was a cave: and
		Saul went in to cover his feet: and David and his men remained
		in the sides of the cave.
	}
}
{
}

\Verse{5}
{
	\hX{
		וַיֹּאמְרוּ אַנְשֵׁי דָוִד אֵלָיו הִנֵּה הַיּוֹם אֲשֶׁר־אָמַר יְהֹוָה אֵלֶיךָ הִנֵּה אָנֹכִי נֹתֵן אֶת־[אֹיִבְךָ] (איביך) בְּיָדֶךָ וְעָשִׂיתָ לּוֹ כַּאֲשֶׁר יִטַב בְּעֵינֶיךָ
		וַיָּקם דָּוִד וַיִּכְרֹת אֶת־כְּנַף־הַמְּעִיל אֲשֶׁר־לְשָׁאוּל בַּלָּט׃
	}
}
{
	\eX{
		And the men of David said to him, Here: the day of which YHWH
		said to you, Here: I'll deliver your enemy into your hand, that
		you may do to him as it shall seem good to you. Then David
		arose, and cut off the skirt of Saul’s robe quietly.
	}
}
{
	Qere Ketiv.
}

\Verse{6}
{
	\hX{וַיְהִי אַחֲרֵי־כֵן וַיַּךְ לֵב־דָּוִד אֹתוֹ עַל אֲשֶׁר כָּרַת אֶת־כָּנָף אֲשֶׁר לְשָׁאוּל׃}
}
{
	\eX{
		And it came to pass afterward, that David’s heart struck him,
		because he had cut off Saul’s skirt.
	}
}
{
%	\footnote{
%		Footnote 24:6. YHWH's anointed. David has Saul in his hand and refuses the hand.
%		The phrase protects a king who has become dangerous, which is why the story is
%		more interesting than revenge.
%	}
}

\Verse{7}
{
	\hX{וַיֹּאמֶר לַאֲנָשָׁיו חָלִילָה לִּי מֵיְהֹוָה אִם־אֶעֱשֶׂה אֶת־הַדָּבָר הַזֶּה לַאדֹנִי לִמְשִׁיחַ יְהֹוָה לִשְׁלֹחַ יָדִי בּוֹ כִּי־מְשִׁיחַ יְהֹוָה הוּא׃}
}
{
	\eX{
		And he said to his men, YHWH forbid that I should do this thing
		to my master, YHWH’s anointed, to stretch forth my hand against
		him, seeing he is the anointed of YHWH.
	}
}
{
}

\Verse{8}
{
	\hX{וַיְשַׁסַּע דָּוִד אֶת־אֲנָשָׁיו בַּדְּבָרִים וְלֹא נְתָנָם לָקוּם אֶל־שָׁאוּל וְשָׁאוּל קָם מֵהַמְּעָרָה וַיֵּלֶךְ בַּדָּרֶךְ׃}
}
{
	\eX{
		And David stayed his servants with these words, and suffered
		them not to rise against Saul. But Saul rose up out of the cave,
		and went on his way.
	}
}
{
}

\Verse{9}
{
	\hX{
		וַיָּקם דָּוִד אַחֲרֵי־כֵן וַיֵּצֵא (מן המערה) [מֵהַמְּעָרָה] וַיִּקְרָא אַחֲרֵי־שָׁאוּל לֵאמֹר אֲדֹנִי הַמֶּלֶךְ וַיַּבֵּט שָׁאוּל אַחֲרָיו וַיִּקֹּד דָּוִד אַפַּיִם אַרְצָה
		וַיִּשְׁתָּחוּ׃
	}
}
{
	\eX{
		David also arose afterward, and went out of the cave, and cried
		after Saul, saying, My lord the king. And when Saul looked
		behind him, David stooped with his face to the earth, and bowed
		himself.
	}
}
{
	Qere Ketiv.
}

\Verse{10}
{
	\hX{וַיֹּאמֶר דָּוִד לְשָׁאוּל לָמָּה תִשְׁמַע אֶת־דִּבְרֵי אָדָם לֵאמֹר הִנֵּה דָוִד מְבַקֵּשׁ רָעָתֶךָ׃}
}
{
	\eX{
		And David said to Saul, And so do you hear men’s words, saying,
		Here: David seeks your hurt?
	}
}
{
}

\Verse{11}
{
	\hX{
		הִנֵּה הַיּוֹם הַזֶּה רָאוּ עֵינֶיךָ אֵת אֲשֶׁר־נְתָנְךָ יְהֹוָה הַיּוֹם בְּיָדִי בַּמְּעָרָה וְאָמַר לַהֲרָגְךָ וַתָּחס עָלֶיךָ וָאֹמַר לֹא־אֶשְׁלַח יָדִי בַּאדֹנִי כִּי־מְשִׁיחַ
		יְהֹוָה הוּא׃
	}
}
{
	\eX{
		Here: this day your eyes have seen how that YHWH had delivered
		you today into my hand in the cave: and some bade me kill you:
		but my eye spared you: and I said, I'll not put forth my hand
		against my lord: for he is YHWH’s anointed.
	}
}
{
}

\Verse{12}
{
	\hX{
		וְאָבִי רְאֵה גַּם רְאֵה אֶת־כְּנַף מְעִילְךָ בְּיָדִי כִּי בְּכרְתִי אֶת־כְּנַף מְעִילְךָ וְלֹא הֲרַגְתִּיךָ דַּע וּרְאֵה כִּי אֵין בְּיָדִי רָעָה וָפֶשַׁע וְלֹא־חָטָאתִי לָךְ
		וְאַתָּה צֹדֶה אֶת־נַפְשִׁי לְקַחְתָּהּ׃
	}
}
{
	\eX{
		Moreover, my father, see, yes, see the skirt of your robe in my
		hand: for in that I cut off the skirt of your robe, and killed
		you not, know you and see that there is neither bad nor
		transgression in my hand, and I've not sinned against you: yet
		you hunt my life to take it.
	}
}
{
}

\Verse{13}
{
	\hX{יִשְׁפֹּט יְהֹוָה בֵּינִי וּבֵינֶךָ וּנְקָמַנִי יְהֹוָה מִמֶּךָּ וְיָדִי לֹא תִהְיֶה־בָּךְ׃}
}
{
	\eX{
		YHWH judge between me and you, and YHWH avenge me of you: but my
		hand shall not be on you.
	}
}
{
}

\Verse{14}
{
	\hX{כַּאֲשֶׁר יֹאמַר מְשַׁל הַקַּדְמֹנִי מֵרְשָׁעִים יֵצֵא רֶשַׁע וְיָדִי לֹא תִהְיֶה־בָּךְ׃}
}
{
	\eX{
		As says the proverb of the ancients, Wickedness proceeds from
		the wicked: but my hand shall not be on you.
	}
}
{
}

\Verse{15}
{
	\hX{אַחֲרֵי מִי יָצָא מֶלֶךְ יִשְׂרָאֵל אַחֲרֵי מִי אַתָּה רֹדֵף אַחֲרֵי כֶּלֶב מֵת אַחֲרֵי פַּרְעֹשׁ אֶחָד׃}
}
{
	\eX{
		After whom is the king of Israel come out? after whom do you
		pursue? after a dead dog, after a flea.
	}
}
{
}

\Verse{16}
{
	\hX{וְהָיָה יְהֹוָה לְדַיָּן וְשָׁפַט בֵּינִי וּבֵינֶךָ וְיֵרֶא וְיָרֵב אֶת־רִיבִי וְיִשְׁפְּטֵנִי מִיָּדֶךָ׃}
}
{
	\eX{
		YHWH therefore be judge, and judge between me and you, and see,
		and plead my cause, and deliver me out of your hand.
	}
}
{
}

\Verse{17}
{
	\hX{וַיְהִי כְּכַלּוֹת דָּוִד לְדַבֵּר אֶת־הַדְּבָרִים הָאֵלֶּה אֶל־שָׁאוּל וַיֹּאמֶר שָׁאוּל הֲקֹלְךָ זֶה בְּנִי דָוִד וַיִּשָּׂא שָׁאוּל קֹלוֹ וַיֵּבְךְּ׃}
}
{
	\eX{
		And it was when David had made an end of speaking these words to
		Saul, that Saul said, Is this your voice, my son David? And Saul
		lifted up his voice, and wept.
	}
}
{
}

\Verse{18}
{
	\hX{וַיֹּאמֶר אֶל־דָּוִד צַדִּיק אַתָּה מִמֶּנִּי כִּי אַתָּה גְּמַלְתַּנִי הַטּוֹבָה וַאֲנִי גְּמַלְתִּיךָ הָרָעָה׃}
}
{
	\eX{
		And he said to David, You are more righteous than I: for you've
		rewarded me good, whereas I've rewarded you bad.
	}
}
{
}

\Verse{19}
{
	\hX{(ואת) [וְאַתָּה] הִגַּדְתָּ הַיּוֹם אֵת אֲשֶׁר־עָשִׂיתָה אִתִּי טוֹבָה אֵת אֲשֶׁר סִגְּרַנִי יְהֹוָה בְּיָדְךָ וְלֹא הֲרַגְתָּנִי׃}
}
{
	\eX{
		And you've showed this day how that you've dealt well with me:
		because when YHWH had delivered me into your hand, you didn't
		kill me.
	}
}
{
	Qere Ketiv.
}

\Verse{20}
{
	\hX{וְכִי־יִמְצָא אִישׁ אֶת־אֹיְבוֹ וְשִׁלְּחוֹ בְּדֶרֶךְ טוֹבָה וַיהֹוָה יְשַׁלֶּמְךָ טוֹבָה תַּחַת הַיּוֹם הַזֶּה אֲשֶׁר עָשִׂיתָה לִי׃}
}
{
	\eX{
		For if a man find his enemy, will he let him go well away? why
		YHWH reward you good for that you've done to me this day.
	}
}
{
}

\Verse{21}
{
	\hX{וְעַתָּה הִנֵּה יָדַעְתִּי כִּי מָלֹךְ תִּמְלוֹךְ וְקָמָה בְּיָדְךָ מַמְלֶכֶת יִשְׂרָאֵל׃}
}
{
	\eX{
		And now, here: I know well that you shall surely be king, and
		that the kingdom of Israel shall be established in your hand.
	}
}
{
}

\Verse{22}
{
	\hX{וְעַתָּה הִשָּׁבְעָה לִּי בַּיהֹוָה אִם־תַּכְרִית אֶת־זַרְעִי אַחֲרָי וְאִם־תַּשְׁמִיד אֶת־שְׁמִי מִבֵּית אָבִי׃}
}
{
	\eX{
		Swear now therefore to me by YHWH, that you'll not cut off my
		seed after me, and that you'll not destroy my name out of my
		father’s house.
	}
}
{
}

\Verse{23}
{
	\hX{וַיִּשָּׁבַע דָּוִד לְשָׁאוּל וַיֵּלֶךְ שָׁאוּל אֶל־בֵּיתוֹ וְדָוִד וַאֲנָשָׁיו עָלוּ עַל־הַמְּצוּדָה׃}
}
{
	\eX{
		And David swore to Saul. And Saul went home: but David and his
		men got them up to the hold.
	}
}
{
}
