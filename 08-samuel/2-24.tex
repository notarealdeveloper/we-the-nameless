{
	\eX{

		even to Beersheba, and count the people, that I may know the
		number of the people.

		הַזֶּה׃
	}
}
{
	\eX{
		And Joab said to the king, And YHWH your God add to the people,
		how many ever they are, a hundred times, and that the eyes of my
		lord the king may see it: but why does my lord the king delight
		in this thing?
	}
}
{
}

}
{
	\eX{
		But the king’s word prevailed against Joab, and against the

}
{

}
{
	\eX{

{
	\eX{

		years of famine come to you in your land? or will you flee three

		answer I shall return to him that sent me.
	}
}
{

}

}

{
