\Chapter{4}

\Verse{1}
{
	\hX{וַיִּשְׁמַע בֶּן־שָׁאוּל כִּי מֵת אַבְנֵר בְּחֶבְרוֹן וַיִּרְפּוּ יָדָיו וְכל־יִשְׂרָאֵל נִבְהָלוּ׃}
}
{
	\eX{
		And when Saul’s son heard that Abner was dead in Hebron, his
		hands were feeble, and all the Israelites were troubled.
	}
}
{
}

\Verse{2}
{
	\hX{
		וּשְׁנֵי אֲנָשִׁים שָׂרֵי־גְדוּדִים הָיוּ בֶן־שָׁאוּל שֵׁם הָאֶחָד בַּעֲנָה וְשֵׁם הַשֵּׁנִי רֵכָב בְּנֵי רִמּוֹן הַבְּאֵרֹתִי מִבְּנֵי בִנְיָמִן כִּי גַּם־בְּאֵרוֹת תֵּחָשֵׁב
		עַל־בִּנְיָמִן׃
	}
}
{
	\eX{
		And Saul’s son had two men that were commanders of bands: the
		name of the one was Baanah, and the name of the other Rechab,
		the sons of Rimmon a Beerothite, of the children of Benjamin:
		(for Beeroth also was reckoned to Benjamin.
	}
}
{
}

\Verse{3}
{
	\hX{וַיִּבְרְחוּ הַבְּאֵרֹתִים גִּתָּיְמָה וַיִּהְיוּ־שָׁם גָּרִים עַד הַיּוֹם הַזֶּה׃}
}
{
	\eX{
		And the Beerothites fled to Gittaim, and were sojourners there
		until this day.)
	}
}
{
}

\Verse{4}
{
	\hX{
		וְלִיהוֹנָתָן בֶּן־שָׁאוּל בֵּן נְכֵה רַגְלָיִם בֶּן־חָמֵשׁ שָׁנִים הָיָה בְּבֹא שְׁמֻעַת שָׁאוּל וִיהוֹנָתָן מִיִּזְרְעֶאל וַתִּשָּׂאֵהוּ אֹמַנְתּוֹ וַתָּנֹס וַיְהִי בְּחפְזָהּ
		לָנוּס וַיִּפֹּל וַיִּפָּסֵחַ וּשְׁמוֹ מְפִיבֹשֶׁת׃
	}
}
{
	\eX{
		And Jonathan, Saul’s son, had a son that was lame of his feet.
		He was five years old when the news came of Saul and Jonathan
		from Jezreel, and his nurse took him up, and fled: and it was,
		as she made haste to flee, that he fell, and became lame. And
		his name was Mephibosheth.
	}
}
{
}

\Verse{5}
{
	\hX{וַיֵּלְכוּ בְּנֵי־רִמּוֹן הַבְּאֵרֹתִי רֵכָב וּבַעֲנָה וַיָּבֹאוּ כְּחֹם הַיּוֹם אֶל־בֵּית אִישׁ בֹּשֶׁת וְהוּא שֹׁכֵב אֵת מִשְׁכַּב הַצּהֳרָיִם׃}
}
{
	\eX{
		And the sons of Rimmon the Beerothite, Rechab and Baanah, went,
		and came about the heat of the day to the house of Ishbosheth,
		who lay on a bed at noon.
	}
}
{
}

\Verse{6}
{
	\hX{וְהֵנָּה בָּאוּ עַד־תּוֹךְ הַבַּיִת לֹקְחֵי חִטִּים וַיַּכֻּהוּ אֶל־הַחֹמֶשׁ וְרֵכָב וּבַעֲנָה אָחִיו נִמְלָטוּ׃}
}
{
	\eX{
		And they came there into the midst of the house, as if they
		would have got wheat; and they struck him under the belly: and
		Rechab and Baanah his brother escaped.
	}
}
{
}

\Verse{7}
{
	\hX{
		וַיָּבֹאוּ הַבַּיִת וְהוּא־שֹׁכֵב עַל־מִטָּתוֹ בַּחֲדַר מִשְׁכָּבוֹ וַיַּכֻּהוּ וַיְמִתֻהוּ וַיָּסִירוּ אֶת־רֹאשׁוֹ וַיִּקְחוּ אֶת־רֹאשׁוֹ וַיֵּלְכוּ דֶּרֶךְ הָעֲרָבָה
		כּל־הַלָּיְלָה׃
	}
}
{
	\eX{
		Because when they came into the house, he lay on his bed in his
		bedchamber, and they struck him, and killed him, and beheaded
		him, and took his head, and got them away through the plain all
		night.
	}
}
{
}

\Verse{8}
{
	\hX{
		וַיָּבִאוּ אֶת־רֹאשׁ אִישׁ־בֹּשֶׁת אֶל־דָּוִד חֶבְרוֹן וַיֹּאמְרוּ אֶל־הַמֶּלֶךְ הִנֵּה־רֹאשׁ אִישׁ־בֹּשֶׁת בֶּן־שָׁאוּל אֹיִבְךָ אֲשֶׁר בִּקֵּשׁ אֶת־נַפְשֶׁךָ וַיִּתֵּן יְהֹוָה
		לַאדֹנִי הַמֶּלֶךְ נְקָמוֹת הַיּוֹם הַזֶּה מִשָּׁאוּל וּמִזַּרְעוֹ׃
	}
}
{
	\eX{
		And they brought the head of Ishbosheth to David to Hebron, and
		said to the king, Here: the head of Ishbosheth the son of Saul
		your enemy, that sought your life; and YHWH has avenged my lord
		the king this day of Saul, and of his seed.
	}
}
{
}

\Verse{9}
{
	\hX{וַיַּעַן דָּוִד אֶת־רֵכָב וְאֶת־בַּעֲנָה אָחִיו בְּנֵי רִמּוֹן הַבְּאֵרֹתִי וַיֹּאמֶר לָהֶם חַי־יְהֹוָה אֲשֶׁר־פָּדָה אֶת־נַפְשִׁי מִכּל־צָרָה׃}
}
{
	\eX{
		And David answered Rechab and Baanah his brother, the sons of
		Rimmon the Beerothite, and said to them, As YHWH lives, who has
		redeemed my soul from all adversity,
	}
}
{
}

\Verse{10}
{
	\hX{כִּי הַמַּגִּיד לִי לֵאמֹר הִנֵּה־מֵת שָׁאוּל וְהוּא־הָיָה כִמְבַשֵּׂר בְּעֵינָיו וָאֹחֲזָה בוֹ וָאֶהְרְגֵהוּ בְּצִקְלָג אֲשֶׁר לְתִתִּי־לוֹ בְּשֹׂרָה׃}
}
{
	\eX{
		When one told me, saying, Here: Saul is dead, thinking to have
		brought good news, I took hold of him, and killed him in Ziklag,
		who thought that I would have given him a reward for his news:
	}
}
{
}

\Verse{11}
{
	\hX{אַף כִּי־אֲנָשִׁים רְשָׁעִים הָרְגוּ אֶת־אִישׁ־צַדִּיק בְּבֵיתוֹ עַל־מִשְׁכָּבוֹ וְעַתָּה הֲלוֹא אֲבַקֵּשׁ אֶת־דָּמוֹ מִיֶּדְכֶם וּבִעַרְתִּי אֶתְכֶם מִן־הָאָרֶץ׃}
}
{
	\eX{
		How much more, when wicked men have killed a righteous person in
		his own house on his bed? shall I not so now require his blood
		of your hand, and take you away from the earth?
	}
}
{
}

\Verse{12}
{
	\hX{
		וַיְצַו דָּוִד אֶת־הַנְּעָרִים וַיַּהַרְגוּם וַיְקַצְּצוּ אֶת־יְדֵיהֶם וְאֶת־רַגְלֵיהֶם וַיִּתְלוּ עַל־הַבְּרֵכָה בְּחֶבְרוֹן וְאֵת רֹאשׁ אִישׁ־בֹּשֶׁת לָקָחוּ וַיִּקְבְּרוּ
		בְקֶבֶר־אַבְנֵר בְּחֶבְרוֹן׃
	}
}
{
	\eX{
		And David commanded his young men, and they killed them, and cut
		off their hands and their feet, and hanged them up over the pool
		in Hebron. But they took the head of Ishbosheth, and buried it
		in the grave of Abner in Hebron.
	}
}
{
}
