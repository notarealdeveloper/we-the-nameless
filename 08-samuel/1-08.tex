\Chapter{8}

\Verse{1}
{
	\hJ{וַיְהִי כַּאֲשֶׁר זָקֵן שְׁמוּאֵל וַיָּשֶׂם אֶת־בָּנָיו שֹׁפְטִים לְיִשְׂרָאֵל׃}
}
{
	\eJ{
		When Samuel grew old, he appointed his sons judges over Israel.
	}
}
{
}

\Verse{2}
{
	\hJ{וַיְהִי שֶׁם־בְּנוֹ הַבְּכוֹר יוֹאֵל וְשֵׁם מִשְׁנֵהוּ אֲבִיָּה שֹׁפְטִים בִּבְאֵר שָׁבַע׃}
}
{
	\eJ{
		The name of his first-born son was Joel, and his second son’s name
		was Abijah; they sat as judges in Beer-sheba.
	}
}
{
}

\Verse{3}
{
	\hJ{וְלֹא־הָלְכוּ בָנָיו בִּדְרָכָו וַיִּטּוּ אַחֲרֵי הַבָּצַע וַיִּקְחוּ־שֹׁחַד וַיַּטּוּ מִשְׁפָּט׃}
}
{
	\eJ{
		But his sons did not follow in his ways; they were bent on gain,
		they accepted bribes, and they subverted justice.
	}
}
{
}

\Verse{4}
{
	\hJ{וַיִּתְקַבְּצוּ כֹּל זִקְנֵי יִשְׂרָאֵל וַיָּבֹאוּ אֶל־שְׁמוּאֵל הָרָמָתָה׃}
}
{
	\eJ{
		All the elders of Israel assembled and came to Samuel at Ramah,
	}
}
{
}

\Verse{5}
{
	\hJ{וַיֹּאמְרוּ אֵלָיו הִנֵּה אַתָּה זָקַנְתָּ וּבָנֶיךָ לֹא הָלְכוּ בִּדְרָכֶיךָ עַתָּה שִׂימָה־לָּנוּ מֶלֶךְ לְשׁפְטֵנוּ כְּכל־הַגּוֹיִם׃}
}
{
	\eJ{
		and they said to him, “You have grown old, and your sons have not
		followed your ways. Therefore appoint a king for us, to govern us
		like all other nations.”
	}
}
{
}

\Verse{6}
{
	\hJ{וַיֵּרַע הַדָּבָר בְּעֵינֵי שְׁמוּאֵל כַּאֲשֶׁר אָמְרוּ תְּנָה־לָּנוּ מֶלֶךְ לְשׁפְטֵנוּ וַיִּתְפַּלֵּל שְׁמוּאֵל אֶל־יְהֹוָה׃}
}
{
	\eJ{
		Samuel was displeased that they said “Give us a king to govern
		us.” Samuel prayed to YHWH,
	}
}
{
}

\Verse{7}
{
	\hJ{וַיֹּאמֶר יְהֹוָה אֶל־שְׁמוּאֵל שְׁמַע בְּקוֹל הָעָם לְכֹל אֲשֶׁר־יֹאמְרוּ אֵלֶיךָ כִּי לֹא אֹתְךָ מָאָסוּ כִּי־אֹתִי מָאֲסוּ מִמְּלֹךְ עֲלֵיהֶם׃}
}
{
	\eJ{
		and YHWH replied to Samuel, “Heed the demand of the people in
		everything they say to you. For it is not you that they have
		rejected; it is Me they have rejected as their king.
	}
}
{
%	\footnote{
%		Footnote 8:7. They have not rejected you, but they have rejected me. The demand
%		for a king is not merely a bad political idea. It is a theological vote of no
%		confidence.
%	}
}

\Verse{8}
{
	\hX{כְּכל־הַמַּעֲשִׂים אֲשֶׁר־עָשׂוּ מִיּוֹם הַעֲלֹתִי אוֹתָם מִמִּצְרַיִם וְעַד־הַיּוֹם הַזֶּה וַיַּעַזְבֻנִי וַיַּעַבְדוּ אֱלֹהִים אֲחֵרִים כֵּן הֵמָּה עֹשִׂים גַּם־לָךְ׃}
}
{
	\eX{
		Like everything else they have done ever since I brought them out
		of Egypt to this day—forsaking Me and worshiping other gods—so
		they are doing to you.
	}
}
{
}

\Verse{9}
{
	\hJ{וְעַתָּה שְׁמַע בְּקוֹלָם אַךְ כִּי־הָעֵד תָּעִיד בָּהֶם וְהִגַּדְתָּ לָהֶם מִשְׁפַּט הַמֶּלֶךְ אֲשֶׁר יִמְלֹךְ עֲלֵיהֶם׃}
}
{
	\eJ{
		Heed their demand; but warn them solemnly, and tell them about the
		practices of any king who will rule over them.”
	}
}
{
}

\Verse{10}
{
	\hJ{וַיֹּאמֶר שְׁמוּאֵל אֵת כּל־דִּבְרֵי יְהֹוָה אֶל־הָעָם הַשֹּׁאֲלִים מֵאִתּוֹ מֶלֶךְ׃}
}
{
	\eJ{
		Samuel reported all the words of YHWH to the people, who were
		asking him for a king.
	}
}
{
}

\Verse{11}
{
	\hJ{וַיֹּאמֶר זֶה יִהְיֶה מִשְׁפַּט הַמֶּלֶךְ אֲשֶׁר יִמְלֹךְ עֲלֵיכֶם אֶת־בְּנֵיכֶם יִקָּח וְשָׂם לוֹ בְּמֶרְכַּבְתּוֹ וּבְפָרָשָׁיו וְרָצוּ לִפְנֵי מֶרְכַּבְתּוֹ׃}
}
{
	\eJ{
		He said, “This will be the practice of the king who will rule over
		you: He will take your sons and appoint them as his charioteers
		and horsemen, and they will serve as outrunners for his chariots.
	}
}
{
}

\Verse{12}
{
	\hJ{וְלָשׂוּם לוֹ שָׂרֵי אֲלָפִים וְשָׂרֵי חֲמִשִּׁים וְלַחֲרֹשׁ חֲרִישׁוֹ וְלִקְצֹר קְצִירוֹ וְלַעֲשׂוֹת כְּלֵי־מִלְחַמְתּוֹ וּכְלֵי רִכְבּוֹ׃}
}
{
	\eJ{
		He will appoint them as his chiefs of thousands and of fifties; or
		they will have to plow his fields, reap his harvest, and make his
		weapons and the equipment for his chariots.
	}
}
{
}

\Verse{13}
{
	\hJ{וְאֶת־בְּנוֹתֵיכֶם יִקָּח לְרַקָּחוֹת וּלְטַבָּחוֹת וּלְאֹפוֹת׃}
}
{
	\eJ{
		He will take your daughters as perfumers, cooks, and bakers.
	}
}
{
}

\Verse{14}

	\hJ{וְאֶת־שְׂדוֹתֵיכֶם וְאֶת־כַּרְמֵיכֶם וְזֵיתֵיכֶם הַטּוֹבִים יִקָּח וְנָתַן לַעֲבָדָיו׃}
}
{
	\eJ{

}

}

}

\Verse{16}

	\hJ{וְאֶת־עַבְדֵיכֶם וְאֶת־שִׁפְחוֹתֵיכֶם וְאֶת־בַּחוּרֵיכֶם הַטּוֹבִים וְאֶת־חֲמוֹרֵיכֶם יִקָּח וְעָשָׂה לִמְלַאכְתּוֹ׃}

{
}

}

	}
}
{
}

}

	}

}

\Verse{20}

	\hJ{וְהָיִינוּ גַם־אֲנַחְנוּ כְּכל־הַגּוֹיִם וּשְׁפָטָנוּ מַלְכֵּנוּ וְיָצָא לְפָנֵינוּ וְנִלְחַם אֶת־מִלְחֲמֹתֵנוּ׃}
