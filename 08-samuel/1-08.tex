\Chapter{8}

\Verse{1}
{
	\hJ{וַיְהִי כַּאֲשֶׁר זָקֵן שְׁמוּאֵל וַיָּשֶׂם אֶת־בָּנָיו שֹׁפְטִים לְיִשְׂרָאֵל׃}
}
{
	\eJ{
		And it was when Samuel was old, that he made his sons judges
		over Israel.
	}
}
{
}

\Verse{2}
{
	\hJ{וַיְהִי שֶׁם־בְּנוֹ הַבְּכוֹר יוֹאֵל וְשֵׁם מִשְׁנֵהוּ אֲבִיָּה שֹׁפְטִים בִּבְאֵר שָׁבַע׃}
}
{
	\eJ{
		And the name of his firstborn was Joel: and the name of his
		second, Abiah: they were judges in Beersheba.
	}
}
{
}

\Verse{3}
{
	\hJ{וְלֹא־הָלְכוּ בָנָיו בִּדְרָכָו וַיִּטּוּ אַחֲרֵי הַבָּצַע וַיִּקְחוּ־שֹׁחַד וַיַּטּוּ מִשְׁפָּט׃}
}
{
	\eJ{
		And his sons walked not in his ways, but turned aside after
		lucre, and took bribes, and perverted judgment.
	}
}
{
}

\Verse{4}
{
	\hJ{וַיִּתְקַבְּצוּ כֹּל זִקְנֵי יִשְׂרָאֵל וַיָּבֹאוּ אֶל־שְׁמוּאֵל הָרָמָתָה׃}
}
{
	\eJ{
		And all the elders of Israel gathered themselves together, and
		came to Samuel to Ramah,
	}
}
{
}

\Verse{5}
{
	\hJ{וַיֹּאמְרוּ אֵלָיו הִנֵּה אַתָּה זָקַנְתָּ וּבָנֶיךָ לֹא הָלְכוּ בִּדְרָכֶיךָ עַתָּה שִׂימָה־לָּנוּ מֶלֶךְ לְשׁפְטֵנוּ כְּכל־הַגּוֹיִם׃}
}
{
	\eJ{
		And said to him, Here: you're old, and your sons walk not in
		your ways: now make us a king to judge us like all the nations.
	}
}
{
}

\Verse{6}
{
	\hJ{וַיֵּרַע הַדָּבָר בְּעֵינֵי שְׁמוּאֵל כַּאֲשֶׁר אָמְרוּ תְּנָה־לָּנוּ מֶלֶךְ לְשׁפְטֵנוּ וַיִּתְפַּלֵּל שְׁמוּאֵל אֶל־יְהֹוָה׃}
}
{
	\eJ{
		And the thing displeased Samuel, when they said, Give us a king
		to judge us. And Samuel prayed to YHWH.
	}
}
{
}

\Verse{7}
{
	\hJ{וַיֹּאמֶר יְהֹוָה אֶל־שְׁמוּאֵל שְׁמַע בְּקוֹל הָעָם לְכֹל אֲשֶׁר־יֹאמְרוּ אֵלֶיךָ כִּי לֹא אֹתְךָ מָאָסוּ כִּי־אֹתִי מָאֲסוּ מִמְּלֹךְ עֲלֵיהֶם׃}
}
{
	\eJ{
		And YHWH said to Samuel, Hearken to the voice of the people in
		all that they say to you: for they've not rejected you, but
		they've rejected me, that I should not reign over them.
	}
}
{
%	\footnote{
%		Footnote 8:7. They have not rejected you, but they have rejected me. The demand
%		for a king is not merely a bad political idea. It is a theological vote of no
%		confidence.
%	}
}

\Verse{8}
{
	\hX{כְּכל־הַמַּעֲשִׂים אֲשֶׁר־עָשׂוּ מִיּוֹם הַעֲלֹתִי אוֹתָם מִמִּצְרַיִם וְעַד־הַיּוֹם הַזֶּה וַיַּעַזְבֻנִי וַיַּעַבְדוּ אֱלֹהִים אֲחֵרִים כֵּן הֵמָּה עֹשִׂים גַּם־לָךְ׃}
}
{
	\eX{
		According to all the works which they've done since the day that
		I brought them up out of Egypt even to this day, wherewith
		they've forsaken me, and served other gods, so do they also to
		you.
	}
}
{
}

\Verse{9}
{
	\hJ{וְעַתָּה שְׁמַע בְּקוֹלָם אַךְ כִּי־הָעֵד תָּעִיד בָּהֶם וְהִגַּדְתָּ לָהֶם מִשְׁפַּט הַמֶּלֶךְ אֲשֶׁר יִמְלֹךְ עֲלֵיהֶם׃}
}
{
	\eJ{
		And therefore listen to their voice: but yet protest solemnly to
		them, and show them the manner of the king that shall reign over
		them.
	}
}
{
}

\Verse{10}
{
	\hJ{וַיֹּאמֶר שְׁמוּאֵל אֵת כּל־דִּבְרֵי יְהֹוָה אֶל־הָעָם הַשֹּׁאֲלִים מֵאִתּוֹ מֶלֶךְ׃}
}
{
	\eJ{
		And Samuel told all the words of YHWH to the people that asked
		of him a king.
	}
}
{
}

\Verse{11}
{
	\hJ{וַיֹּאמֶר זֶה יִהְיֶה מִשְׁפַּט הַמֶּלֶךְ אֲשֶׁר יִמְלֹךְ עֲלֵיכֶם אֶת־בְּנֵיכֶם יִקָּח וְשָׂם לוֹ בְּמֶרְכַּבְתּוֹ וּבְפָרָשָׁיו וְרָצוּ לִפְנֵי מֶרְכַּבְתּוֹ׃}
}
{
	\eJ{
		And he said, This will be the manner of the king that shall
		reign over you: He will take your sons, and appoint them for
		himself, for his chariots, and to be his horsemen: and some
		shall run before his chariots.
	}
}
{
}

\Verse{12}
{
	\hJ{וְלָשׂוּם לוֹ שָׂרֵי אֲלָפִים וְשָׂרֵי חֲמִשִּׁים וְלַחֲרֹשׁ חֲרִישׁוֹ וְלִקְצֹר קְצִירוֹ וְלַעֲשׂוֹת כְּלֵי־מִלְחַמְתּוֹ וּכְלֵי רִכְבּוֹ׃}
}
{
	\eJ{
		And he'll appoint him captains over thousands, and captains over
		fifties: and will set them to plow his ground, and to reap his
		harvest, and to make his instruments of war, and instruments of
		his chariots.
	}
}
{
}

\Verse{13}
{
	\hJ{וְאֶת־בְּנוֹתֵיכֶם יִקָּח לְרַקָּחוֹת וּלְטַבָּחוֹת וּלְאֹפוֹת׃}
}
{
	\eJ{
		And he'll take your danythingers to be confectionaries, and to
		be cooks, and to be bakers.
	}
}
{
}

\Verse{14}
{
	\hJ{וְאֶת־שְׂדוֹתֵיכֶם וְאֶת־כַּרְמֵיכֶם וְזֵיתֵיכֶם הַטּוֹבִים יִקָּח וְנָתַן לַעֲבָדָיו׃}
}
{
	\eJ{
		And he'll take your fields, and your vineyards, and your olive
		groves, even the best of them, and give them to his servants.
	}
}
{
}

\Verse{15}
{
	\hJ{וְזַרְעֵיכֶם וְכַרְמֵיכֶם יַעְשֹׂר וְנָתַן לְסָרִיסָיו וְלַעֲבָדָיו׃}
}
{
	\eJ{
		And he'll take the tenth of your seed, and of your vineyards,
		and give to his officers, and to his servants.
	}
}
{
}

\Verse{16}
{
	\hJ{וְאֶת־עַבְדֵיכֶם וְאֶת־שִׁפְחוֹתֵיכֶם וְאֶת־בַּחוּרֵיכֶם הַטּוֹבִים וְאֶת־חֲמוֹרֵיכֶם יִקָּח וְעָשָׂה לִמְלַאכְתּוֹ׃}
}
{
	\eJ{
		And he'll take your male servants, and your maidservants, and
		your best young men, and your asses, and put them to his work.
	}
}
{
}

\Verse{17}
{
	\hJ{צֹאנְכֶם יַעְשֹׂר וְאַתֶּם תִּהְיוּ־לוֹ לַעֲבָדִים׃}
}
{
	\eJ{
		He will take the tenth of your sheep: and you shall be his
		servants.
	}
}
{
}

\Verse{18}
{
	\hJ{וּזְעַקְתֶּם בַּיּוֹם הַהוּא מִלִּפְנֵי מַלְכְּכֶם אֲשֶׁר בְּחַרְתֶּם לָכֶם וְלֹא־יַעֲנֶה יְהֹוָה אֶתְכֶם בַּיּוֹם הַהוּא׃}
}
{
	\eJ{
		And you shall cry out in that day because of your king which you
		shall have chosen you: and YHWH won't hear you in that day.
	}
}
{
}

\Verse{19}
{
	\hJ{וַיְמָאֲנוּ הָעָם לִשְׁמֹעַ בְּקוֹל שְׁמוּאֵל וַיֹּאמְרוּ לֹּא כִּי אִם־מֶלֶךְ יִהְיֶה עָלֵינוּ׃}
}
{
	\eJ{
		Nevertheless the people refused to obey the voice of Samuel: and
		they said, No: but we'll have a king over us:
	}
}
{
}

\Verse{20}
{
	\hJ{וְהָיִינוּ גַם־אֲנַחְנוּ כְּכל־הַגּוֹיִם וּשְׁפָטָנוּ מַלְכֵּנוּ וְיָצָא לְפָנֵינוּ וְנִלְחַם אֶת־מִלְחֲמֹתֵנוּ׃}
}
{
	\eJ{
		That we also may be like all the nations: and that our king may
		judge us, and go out before us, and fight our battles.
	}
}
{
}

\Verse{21}
{
	\hJ{וַיִּשְׁמַע שְׁמוּאֵל אֵת כּל־דִּבְרֵי הָעָם וַיְדַבְּרֵם בְּאזְנֵי יְהֹוָה׃}
}
{
	\eJ{
		And Samuel heard all the words of the people, and he rehearsed
		them in the ears of YHWH.
	}
}
{
}

\Verse{22}
{
	\hJ{וַיֹּאמֶר יְהֹוָה אֶל־שְׁמוּאֵל שְׁמַע בְּקוֹלָם וְהִמְלַכְתָּ לָהֶם מֶלֶךְ וַיֹּאמֶר שְׁמוּאֵל אֶל־אַנְשֵׁי יִשְׂרָאֵל לְכוּ אִישׁ לְעִירוֹ׃}
}
{
	\eJ{
		And YHWH said to Samuel, Hearken to their voice, and make them a
		king. And Samuel said to the men of Israel, Go you every man to
		his city.
	}
}
