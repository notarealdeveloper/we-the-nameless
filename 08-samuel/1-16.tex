\Chapter{16}

\Verse{1}
{
	\hX{
		וַיֹּאמֶר יְהֹוָה אֶל־שְׁמוּאֵל עַד־מָתַי אַתָּה מִתְאַבֵּל אֶל־שָׁאוּל וַאֲנִי מְאַסְתִּיו מִמְּלֹךְ עַל־יִשְׂרָאֵל מַלֵּא קַרְנְךָ שֶׁמֶן וְלֵךְ אֶשְׁלָחֲךָ אֶל־יִשַׁי
		בֵּית־הַלַּחְמִי כִּי־רָאִיתִי בְּבָנָיו לִי מֶלֶךְ׃
	}
}
{
	\eX{
		And YHWH said to Samuel, How long will you mourn for Saul,
		seeing I've rejected him from reigning over Israel? fill your
		horn with oil, and go, I'll send you to Jesse the Bethlehemite:
		for I've provided me a king among his sons.
	}
}
{
}

\Verse{2}
{
	\hX{וַיֹּאמֶר שְׁמוּאֵל אֵיךְ אֵלֵךְ וְשָׁמַע שָׁאוּל וַהֲרָגָנִי וַיֹּאמֶר יְהֹוָה עֶגְלַת בָּקָר תִּקַּח בְּיָדֶךָ וְאָמַרְתָּ לִזְבֹּחַ לַיהֹוָה בָּאתִי׃}
}
{
	\eX{
		And Samuel said, How can I go? if Saul hear it, he'll kill me.
		And YHWH said, Take an heifer with you, and say, I'm come to
		sacrifice to YHWH.
	}
}
{
}

\Verse{3}
{
	\hX{וְקָרָאתָ לְיִשַׁי בַּזָּבַח וְאָנֹכִי אוֹדִיעֲךָ אֵת אֲשֶׁר־תַּעֲשֶׂה וּמָשַׁחְתָּ לִי אֵת אֲשֶׁר־אֹמַר אֵלֶיךָ׃}
}
{
	\eX{
		And call Jesse to the sacrifice, and I'll show you what you
		shall do: and you shall anoint to me him whom I name to you.
	}
}
{
}

\Verse{4}
{
	\hX{וַיַּעַשׂ שְׁמוּאֵל אֵת אֲשֶׁר דִּבֶּר יְהֹוָה וַיָּבֹא בֵּית לָחֶם וַיֶּחֶרְדוּ זִקְנֵי הָעִיר לִקְרָאתוֹ וַיֹּאמֶר שָׁלֹם בּוֹאֶךָ׃}
}
{
	\eX{
		And Samuel did that which YHWH spoke, and came to Bethlehem. And
		the elders of the town trembled at his coming, and said, Do you
		come in peace?
	}
}
{
}

\Verse{5}
{
	\hX{וַיֹּאמֶר שָׁלוֹם לִזְבֹּחַ לַיהֹוָה בָּאתִי הִתְקַדְּשׁוּ וּבָאתֶם אִתִּי בַּזָּבַח וַיְקַדֵּשׁ אֶת־יִשַׁי וְאֶת־בָּנָיו וַיִּקְרָא לָהֶם לַזָּבַח׃}
}
{
	\eX{
		And he said, Peaceably: I'm come to sacrifice to YHWH: sanctify
		yourselves, and come with me to the sacrifice. And he sanctified
		Jesse and his sons, and called them to the sacrifice.
	}
}
{
}

\Verse{6}
{
	\hX{וַיְהִי בְּבוֹאָם וַיַּרְא אֶת־אֱלִיאָב וַיֹּאמֶר אַךְ נֶגֶד יְהֹוָה מְשִׁיחוֹ׃}
}
{
	\eX{

}
{
}

\Verse{7}
{
	\hX{
		וַיֹּאמֶר יְהֹוָה אֶל־שְׁמוּאֵל אַל־תַּבֵּט אֶל־מַרְאֵהוּ וְאֶל־גְּבֹהַּ קוֹמָתוֹ כִּי מְאַסְתִּיהוּ כִּי לֹא אֲשֶׁר יִרְאֶה הָאָדָם כִּי הָאָדָם יִרְאֶה לַעֵינַיִם וַיהֹוָה
		יִרְאֶה לַלֵּבָב׃
	}
}
{
	\eX{
		And YHWH said to Samuel, Look not on his face, or on the height
		of his stature: because I've refused him: for YHWH sees not as
		man sees: for man looks on the outward appearance, but YHWH
		looks on the heart.
	}
}
{
%	\footnote{
%		Footnote 16:7. The human sees by the eyes, and YHWH sees by the heart. The verse
%		makes election a problem of vision before it makes it a problem of kingship.
%	}
}
