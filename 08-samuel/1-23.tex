}
{
	\eX{

	}

{

}
{
	\eX{
		But David’s men said to him, “Look, we are afraid here in Judah,
		how much more if we go to Keilah against the forces of the
		Philistines!”

}
{
}

\Verse{4}
{
	\hX{וַיּוֹסֶף עוֹד דָּוִד לִשְׁאוֹל בַּיהֹוָה וַיַּעֲנֵהוּ יְהֹוָה וַיֹּאמֶר קוּם רֵד קְעִילָה כִּי־אֲנִי נֹתֵן אֶת־פְּלִשְׁתִּים בְּיָדֶךָ׃}
}
{
	\eX{

}
{
	\eX{
