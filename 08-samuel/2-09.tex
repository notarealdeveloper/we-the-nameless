\Chapter{9}

\Verse{1}
{
	\hJ{וַיֹּאמֶר דָּוִד הֲכִי יֶשׁ־עוֹד אֲשֶׁר נוֹתַר לְבֵית שָׁאוּל וְאֶעֱשֶׂה עִמּוֹ חֶסֶד בַּעֲבוּר יְהוֹנָתָן׃}
}
{
	\eJ{
		And David said, Is there yet any that is left of the house of
		Saul, that I may show him kindness for Jonathan’s sake?
	}
}
{
}

\Verse{2}
{
	\hJ{וּלְבֵית שָׁאוּל עֶבֶד וּשְׁמוֹ צִיבָא וַיִּקְרְאוּ־לוֹ אֶל־דָּוִד וַיֹּאמֶר הַמֶּלֶךְ אֵלָיו הַאַתָּה צִיבָא וַיֹּאמֶר עַבְדֶּךָ׃}
}
{
	\eJ{
		And there was of the house of Saul a servant whose name was
		Ziba. And when they had called him to David, the king said to
		him, Are you Ziba? And he said, Your servant is he.
	}
}
{
}

\Verse{3}
{
	\hJ{וַיֹּאמֶר הַמֶּלֶךְ הַאֶפֶס עוֹד אִישׁ לְבֵית שָׁאוּל וְאֶעֱשֶׂה עִמּוֹ חֶסֶד אֱלֹהִים וַיֹּאמֶר צִיבָא אֶל־הַמֶּלֶךְ עוֹד בֵּן לִיהוֹנָתָן נְכֵה רַגְלָיִם׃}
}
{
	\eJ{
		And the king said, Is there not yet any of the house of Saul,
		that I may show the kindness of God to him? And Ziba said to the
		king, Jonathan has yet a son, that is lame on his feet.
	}
}
{
}

\Verse{4}
{
	\hJ{וַיֹּאמֶר־לוֹ הַמֶּלֶךְ אֵיפֹה הוּא וַיֹּאמֶר צִיבָא אֶל־הַמֶּלֶךְ הִנֵּה־הוּא בֵּית מָכִיר בֶּן־עַמִּיאֵל בְּלוֹ דְבָר׃}
}
{
	\eJ{
		And the king said to him, Where is he? And Ziba said to the
		king, Here: he is in the house of Machir, the son of Ammiel, in
		Lodebar.
	}
}
{
}

\Verse{5}
{
	\hJ{וַיִּשְׁלַח הַמֶּלֶךְ דָּוִד וַיִּקָּחֵהוּ מִבֵּית מָכִיר בֶּן־עַמִּיאֵל מִלּוֹ דְבָר׃}
}
{
	\eJ{
		And king David sent, and got him from the house of Machir, the
		son of Ammiel, from Lodebar.
	}
}
{
}

\Verse{6}
{
	\hJ{וַיָּבֹא מְפִיבֹשֶׁת בֶּן־יְהוֹנָתָן בֶּן־שָׁאוּל אֶל־דָּוִד וַיִּפֹּל עַל־פָּנָיו וַיִּשְׁתָּחוּ וַיֹּאמֶר דָּוִד מְפִיבֹשֶׁת וַיֹּאמֶר הִנֵּה עַבְדֶּךָ׃}
}
{
	\eJ{
		And when Mephibosheth, the son of Jonathan, the son of Saul,
		came to David, he fell on his face, and bowed. And David said,
		Mephibosheth. And he answered, Here: your servant!
	}
}
{
}

\Verse{7}
{
	\hJ{
		וַיֹּאמֶר לוֹ דָוִד אַל־תִּירָא כִּי עָשֹׂה אֶעֱשֶׂה עִמְּךָ חֶסֶד בַּעֲבוּר יְהוֹנָתָן אָבִיךָ וַהֲשִׁבֹתִי לְךָ אֶת־כּל־שְׂדֵה שָׁאוּל אָבִיךָ וְאַתָּה תֹּאכַל לֶחֶם
		עַל־שֻׁלְחָנִי תָּמִיד׃
	}
}
{
	\eJ{
		And David said to him, Fear not: for I'll surely show you
		kindness for Jonathan your father’s sake, and will restore you
		all the land of Saul your father; and you shall eat bread at my
		table continually.
	}
}
{
}

\Verse{8}
{
	\hJ{וַיִּשְׁתַּחוּ וַיֹּאמֶר מֶה עַבְדֶּךָ כִּי פָנִיתָ אֶל־הַכֶּלֶב הַמֵּת אֲשֶׁר כָּמוֹנִי׃}
}
{
	\eJ{
		And he bowed, and said, What is your servant, that you should
		look on such a dead dog as I am?
	}
}
{
}

\Verse{9}
{
	\hJ{וַיִּקְרָא הַמֶּלֶךְ אֶל־צִיבָא נַעַר שָׁאוּל וַיֹּאמֶר אֵלָיו כֹּל אֲשֶׁר הָיָה לְשָׁאוּל וּלְכל־בֵּיתוֹ נָתַתִּי לְבֶן־אֲדֹנֶיךָ׃}
}
{
	\eJ{
		And the king called to Ziba, Saul’s servant, and said to him,
		I've given to your master’s son all who belonged to Saul and to
		all his house.
	}
}
{
}

\Verse{10}
{
	\hJ{
		וְעָבַדְתָּ לּוֹ אֶת־הָאֲדָמָה אַתָּה וּבָנֶיךָ וַעֲבָדֶיךָ וְהֵבֵאתָ וְהָיָה לְבֶן־אֲדֹנֶיךָ לֶּחֶם וַאֲכָלוֹ וּמְפִיבֹשֶׁת בֶּן־אֲדֹנֶיךָ יֹאכַל תָּמִיד לֶחֶם עַל־שֻׁלְחָנִי
		וּלְצִיבָא חֲמִשָּׁה עָשָׂר בָּנִים וְעֶשְׂרִים עֲבָדִים׃
	}
}
{
	\eJ{
		And you, and your sons, and your servants, shall till the land
		for him, and you shall bring in produce, that your master’s son
		may have food to eat: but Mephibosheth your master’s son shall
		eat bread always at my table. And Ziba had fifteen sons and
		twenty servants.
	}
}
{
}

\Verse{11}
{
	\hJ{וַיֹּאמֶר צִיבָא אֶל־הַמֶּלֶךְ כְּכֹל אֲשֶׁר יְצַוֶּה אֲדֹנִי הַמֶּלֶךְ אֶת־עַבְדּוֹ כֵּן יַעֲשֶׂה עַבְדֶּךָ וּמְפִיבֹשֶׁת אֹכֵל עַל־שֻׁלְחָנִי כְּאַחַד מִבְּנֵי הַמֶּלֶךְ׃}
}
{
	\eJ{
		And Ziba said to the king, According to all that my lord the
		king has commanded his servant, so shall your servant do. And
		the king said, As for Mephibosheth, he shall eat at my table, as
		one of the king’s sons.
	}
}
{
}

\Verse{12}
{
	\hJ{וְלִמְפִיבֹשֶׁת בֵּן־קָטָן וּשְׁמוֹ מִיכָא וְכֹל מוֹשַׁב בֵּית־צִיבָא עֲבָדִים לִמְפִיבֹשֶׁת׃}
}
{
	\eJ{
		And Mephibosheth had a young son, whose name was Micha. And all
		that lived in the house of Ziba were servants to Mephibosheth.
	}
}
{
}

\Verse{13}
{
	\hJ{וּמְפִיבֹשֶׁת יֹשֵׁב בִּירוּשָׁלַ͏ִם כִּי עַל־שֻׁלְחַן הַמֶּלֶךְ תָּמִיד הוּא אֹכֵל וְהוּא פִסֵּחַ שְׁתֵּי רַגְלָיו׃}
}
{
	\eJ{
		So Mephibosheth lived in Jerusalem: for he ate always at the
		king’s table; and was lame on both his feet.
	}
}
{
}
