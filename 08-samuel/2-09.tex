\Chapter{9}

\Verse{1}
{
	\hJ{וַיֹּאמֶר דָּוִד הֲכִי יֶשׁ־עוֹד אֲשֶׁר נוֹתַר לְבֵית שָׁאוּל וְאֶעֱשֶׂה עִמּוֹ חֶסֶד בַּעֲבוּר יְהוֹנָתָן׃}
}
{
	\eJ{
		David inquired, “Is there anyone still left of the House of Saul
		with whom I can keep faith for the sake of Jonathan?”
	}
}
{
}

\Verse{2}
{
	\hJ{וּלְבֵית שָׁאוּל עֶבֶד וּשְׁמוֹ צִיבָא וַיִּקְרְאוּ־לוֹ אֶל־דָּוִד וַיֹּאמֶר הַמֶּלֶךְ אֵלָיו הַאַתָּה צִיבָא וַיֹּאמֶר עַבְדֶּךָ׃}
}
{
	\eJ{
		There was a servant of the House of Saul named Ziba, and they
		summoned him to David. “Are you Ziba?” the king asked him. “Yes,
		sir,” he replied.
	}
}
{
}

\Verse{3}
{
	\hJ{וַיֹּאמֶר הַמֶּלֶךְ הַאֶפֶס עוֹד אִישׁ לְבֵית שָׁאוּל וְאֶעֱשֶׂה עִמּוֹ חֶסֶד אֱלֹהִים וַיֹּאמֶר צִיבָא אֶל־הַמֶּלֶךְ עוֹד בֵּן לִיהוֹנָתָן נְכֵה רַגְלָיִם׃}
}
{
	\eJ{
		The king continued, “Is there anyone at all left of the House of
		Saul with whom I can keep faith as pledged before God?” Ziba
		answered the king, “Yes, there is still a son of Jonathan whose
		feet are crippled.”
	}
}
{
}

\Verse{4}
{
	\hJ{וַיֹּאמֶר־לוֹ הַמֶּלֶךְ אֵיפֹה הוּא וַיֹּאמֶר צִיבָא אֶל־הַמֶּלֶךְ הִנֵּה־הוּא בֵּית מָכִיר בֶּן־עַמִּיאֵל בְּלוֹ דְבָר׃}
}
{
	\eJ{
		“Where is he?” the king asked, and Ziba said to the king, “He is
		in the house of Machir son of Ammiel, in Lo-debar.”
	}
}
{
}

\Verse{5}
{
	\hJ{וַיִּשְׁלַח הַמֶּלֶךְ דָּוִד וַיִּקָּחֵהוּ מִבֵּית מָכִיר בֶּן־עַמִּיאֵל מִלּוֹ דְבָר׃}
}
{
	\eJ{
		King David had him brought from the house of Machir son of Ammiel,
		at Lo-debar;
	}
}
{
}

\Verse{6}
{
	\hJ{וַיָּבֹא מְפִיבֹשֶׁת בֶּן־יְהוֹנָתָן בֶּן־שָׁאוּל אֶל־דָּוִד וַיִּפֹּל עַל־פָּנָיו וַיִּשְׁתָּחוּ וַיֹּאמֶר דָּוִד מְפִיבֹשֶׁת וַיֹּאמֶר הִנֵּה עַבְדֶּךָ׃}
}
{
	\eJ{
		and when Mephibosheth son of Jonathan son of Saul came to David,
		he flung himself on his face and prostrated himself. David said,
		“Mephibosheth!” and he replied, “At your service, sir.”
	}
}
{
}

\Verse{7}
{
	\hJ{
		וַיֹּאמֶר לוֹ דָוִד אַל־תִּירָא כִּי עָשֹׂה אֶעֱשֶׂה עִמְּךָ חֶסֶד בַּעֲבוּר יְהוֹנָתָן אָבִיךָ וַהֲשִׁבֹתִי לְךָ אֶת־כּל־שְׂדֵה שָׁאוּל אָבִיךָ וְאַתָּה תֹּאכַל לֶחֶם
		עַל־שֻׁלְחָנִי תָּמִיד׃
	}
}
{
	\eJ{
		David said to him, “Don’t be afraid, for I will keep faith with
		you for the sake of your father Jonathan. I will give you back all
		the land of your grandfather Saul; moreover, you shall always eat
		at my table.”
	}
}
{
}

\Verse{8}
{
	\hJ{וַיִּשְׁתַּחוּ וַיֹּאמֶר מֶה עַבְדֶּךָ כִּי פָנִיתָ אֶל־הַכֶּלֶב הַמֵּת אֲשֶׁר כָּמוֹנִי׃}
}
{
	\eJ{
		[Mephibosheth] prostrated himself again, and said, “What is your
		servant, that you should show regard for a dead dog like me?”
	}
}
{
}

\Verse{9}
{
	\hJ{וַיִּקְרָא הַמֶּלֶךְ אֶל־צִיבָא נַעַר שָׁאוּל וַיֹּאמֶר אֵלָיו כֹּל אֲשֶׁר הָיָה לְשָׁאוּל וּלְכל־בֵּיתוֹ נָתַתִּי לְבֶן־אֲדֹנֶיךָ׃}
}
{
	\eJ{
		The king summoned Ziba, Saul’s steward, and said to him, “I give
		to your master’s grandson everything that belonged to Saul and to
		his entire family.
	}
}
{
}

\Verse{10}
{
	\hJ{
		וְעָבַדְתָּ לּוֹ אֶת־הָאֲדָמָה אַתָּה וּבָנֶיךָ וַעֲבָדֶיךָ וְהֵבֵאתָ וְהָיָה לְבֶן־אֲדֹנֶיךָ לֶּחֶם וַאֲכָלוֹ וּמְפִיבֹשֶׁת בֶּן־אֲדֹנֶיךָ יֹאכַל תָּמִיד לֶחֶם עַל־שֻׁלְחָנִי
		וּלְצִיבָא חֲמִשָּׁה עָשָׂר בָּנִים וְעֶשְׂרִים עֲבָדִים׃
	}
}
{
	\eJ{
		You and your sons and your slaves shall farm the land for him and
		shall bring in [its yield] to provide food for your master’s
		grandson to live on; but Mephibosheth, your master’s grandson,
		shall always eat at my table.”—Ziba had fifteen sons and twenty
		slaves.—
	}
}
{
}

\Verse{11}
{
	\hJ{וַיֹּאמֶר צִיבָא אֶל־הַמֶּלֶךְ כְּכֹל אֲשֶׁר יְצַוֶּה אֲדֹנִי הַמֶּלֶךְ אֶת־עַבְדּוֹ כֵּן יַעֲשֶׂה עַבְדֶּךָ וּמְפִיבֹשֶׁת אֹכֵל עַל־שֻׁלְחָנִי כְּאַחַד מִבְּנֵי הַמֶּלֶךְ׃}
}
{
	\eJ{
		Ziba said to the king, “Your servant will do just as my lord the
		king has commanded him.” “Mephibosheth shall eat at my table like
		one of the king’s sons.”
	}
}
{
}

\Verse{12}
{
	\hJ{וְלִמְפִיבֹשֶׁת בֵּן־קָטָן וּשְׁמוֹ מִיכָא וְכֹל מוֹשַׁב בֵּית־צִיבָא עֲבָדִים לִמְפִיבֹשֶׁת׃}
}
{
	\eJ{
		Mephibosheth had a young son named Mica; and all the members of
		Ziba’s household worked for Mephibosheth.
	}
}
{
}

\Verse{13}
{
	\hJ{וּמְפִיבֹשֶׁת יֹשֵׁב בִּירוּשָׁלַ͏ִם כִּי עַל־שֻׁלְחַן הַמֶּלֶךְ תָּמִיד הוּא אֹכֵל וְהוּא פִסֵּחַ שְׁתֵּי רַגְלָיו׃}
}
{
	\eJ{
		Mephibosheth lived in Jerusalem, for he ate regularly at the
		king’s table. He was lame in both feet.
	}
}
{
}
