\Chapter{5}

\Verse{1}
{
	\hJ{וַיָּבֹאוּ כּל־שִׁבְטֵי יִשְׂרָאֵל אֶל־דָּוִד חֶבְרוֹנָה וַיֹּאמְרוּ לֵאמֹר הִנְנוּ עַצְמְךָ וּבְשָׂרְךָ אֲנָחְנוּ׃}
}
{
	\eJ{
		And came all the tribes of Israel to David to Hebron, and spoke,
		saying, Here: we are your bone and your flesh.
	}
}
{
}

\Verse{2}
{
	\hJ{
		גַּם־אֶתְמוֹל גַּם־שִׁלְשׁוֹם בִּהְיוֹת שָׁאוּל מֶלֶךְ עָלֵינוּ אַתָּה (הייתה מוציא) [הָיִיתָ הַמּוֹצִיא] וְהַמֵּבִי אֶת־יִשְׂרָאֵל וַיֹּאמֶר יְהֹוָה לְךָ אַתָּה תִרְעֶה אֶת־עַמִּי
		אֶת־יִשְׂרָאֵל וְאַתָּה תִּהְיֶה לְנָגִיד עַל־יִשְׂרָאֵל׃
	}
}
{
	\eJ{
		Also in time past, when Saul was king over us, you were he that
		led out and brought in Israel: and YHWH said to you, You shall
		feed my people Israel, and you shall be a commander over Israel.
	}
}
{
}

\Verse{3}
{
	\hJ{וַיָּבֹאוּ כּל־זִקְנֵי יִשְׂרָאֵל אֶל־הַמֶּלֶךְ חֶבְרוֹנָה וַיִּכְרֹת לָהֶם הַמֶּלֶךְ דָּוִד בְּרִית בְּחֶבְרוֹן לִפְנֵי יְהֹוָה וַיִּמְשְׁחוּ אֶת־דָּוִד לְמֶלֶךְ עַל־יִשְׂרָאֵל׃}
}
{
	\eJ{
		So all the elders of Israel came to the king to Hebron; and king
		David made a covenant with them in Hebron before YHWH: and they
		anointed David king over Israel.
	}
}
{
}

\Verse{4}
{
	\hJ{בֶּן־שְׁלֹשִׁים שָׁנָה דָּוִד בְּמלְכוֹ אַרְבָּעִים שָׁנָה מָלָךְ׃}
}
{
	\eJ{
		David was thirty years old when he began to reign, and he
		reigned forty years.
	}
}
{
}

\Verse{5}
{
	\hJ{בְּחֶבְרוֹן מָלַךְ עַל־יְהוּדָה שֶׁבַע שָׁנִים וְשִׁשָּׁה חֳדָשִׁים וּבִירוּשָׁלַ͏ִם מָלַךְ שְׁלֹשִׁים וְשָׁלֹשׁ שָׁנָה עַל כּל־יִשְׂרָאֵל וִיהוּדָה׃}
}
{
	\eJ{
		In Hebron he reigned over Judah seven years and six months: and
		in Jerusalem he reigned thirty and three years over all Israel
		and Judah.
	}
}
{
}

\Verse{6}
{
	\hJ{
		וַיֵּלֶךְ הַמֶּלֶךְ וַאֲנָשָׁיו יְרוּשָׁלַ͏ִם אֶל־הַיְבֻסִי יוֹשֵׁב הָאָרֶץ וַיֹּאמֶר לְדָוִד לֵאמֹר לֹא־תָבוֹא הֵנָּה כִּי אִם־הֱסִירְךָ הַעִוְרִים וְהַפִּסְחִים לֵאמֹר לֹא־יָבוֹא
		דָוִד הֵנָּה׃
	}
}
{
	\eJ{
		And the king and his men went to Jerusalem to the Jebusites, the
		inhabitants of the land: that spoke to David, saying, Except you
		take away the blind and the lame, you shall not come in here:
		thinking, David cannot come in here.
	}
}
{
}

\Verse{7}
{
	\hJ{וַיִּלְכֹּד דָּוִד אֵת מְצֻדַת צִיּוֹן הִיא עִיר דָּוִד׃}
}
{
	\eJ{
		Nevertheless David took the strong hold of Zion: the same is the
		city of David.
	}
}
{
%	\footnote{
%		Footnote 5:7. Zion becomes the City of David here. The place-name is doing
%		politics, not only geography.
%	}
}

\Verse{8}
{
	\hJ{
		וַיֹּאמֶר דָּוִד בַּיּוֹם הַהוּא כּל־מַכֵּה יְבֻסִי וְיִגַּע בַּצִּנּוֹר וְאֶת־הַפִּסְחִים וְאֶת־הַעִוְרִים (שנאו) [שְׂנוּאֵי] נֶפֶשׁ דָּוִד עַל־כֵּן יֹאמְרוּ עִוֵּר וּפִסֵּחַ לֹא
		יָבוֹא אֶל־הַבָּיִת׃
	}
}
{
	\eJ{
		And David said on that day, Whoever gets up to the gutter, and
		strikes the Jebusites, and the lame and the blind that are hated
		of David’s soul, he shall be chief and commander. Therefore they
		said, The blind and the lame shall not come into the house.
	}
}
{
}

\Verse{9}
{
	\hJ{וַיֵּשֶׁב דָּוִד בַּמְּצֻדָה וַיִּקְרָא־לָהּ עִיר דָּוִד וַיִּבֶן דָּוִד סָבִיב מִן־הַמִּלּוֹא וָבָיְתָה׃}
}
{
	\eJ{

		David built round about from Millo and inward.

}
{
}

\Verse{10}
{
	\hJ{וַיֵּלֶךְ דָּוִד הָלוֹךְ וְגָדוֹל וַיהֹוָה אֱלֹהֵי צְבָאוֹת עִמּוֹ׃}
}
{
	\eJ{

}

	\hJ{וַיֵּדַע דָּוִד כִּי־הֱכִינוֹ יְהֹוָה לְמֶלֶךְ עַל־יִשְׂרָאֵל וְכִי נִשֵּׂא מַמְלַכְתּוֹ בַּעֲבוּר עַמּוֹ יִשְׂרָאֵל׃}

\Verse{13}

	\eJ{

}

}
{
	\eJ{
		And David enquired of YHWH, saying, Shall I go up to the

		your hand.
	}
}
{
}

}
{
	\eJ{
		And David came to Baalperazim, and David struck them there, and
		said, YHWH has broken forth on mine enemies before me, as the
		breach of waters. So he called the name of that place
		Baalperazim.
	}
}
{
}

	}
}
{
}
