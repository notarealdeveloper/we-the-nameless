\Chapter{5}

\Verse{1}
{
	\hJ{וַיָּבֹאוּ כּל־שִׁבְטֵי יִשְׂרָאֵל אֶל־דָּוִד חֶבְרוֹנָה וַיֹּאמְרוּ לֵאמֹר הִנְנוּ עַצְמְךָ וּבְשָׂרְךָ אֲנָחְנוּ׃}
}
{
	\eJ{
		All the tribes of Israel came to David at Hebron and said, “We are
		your own flesh and blood.
	}
}
{
}

\Verse{2}
{
	\hJ{
		גַּם־אֶתְמוֹל גַּם־שִׁלְשׁוֹם בִּהְיוֹת שָׁאוּל מֶלֶךְ עָלֵינוּ אַתָּה (הייתה מוציא) [הָיִיתָ הַמּוֹצִיא] וְהַמֵּבִי אֶת־יִשְׂרָאֵל וַיֹּאמֶר יְהֹוָה לְךָ אַתָּה תִרְעֶה אֶת־עַמִּי
		אֶת־יִשְׂרָאֵל וְאַתָּה תִּהְיֶה לְנָגִיד עַל־יִשְׂרָאֵל׃
	}
}
{
	\eJ{
		Long before now, when Saul was king over us, it was you who led
		Israel in war; and YHWH said to you: You shall shepherd My people
		Israel; you shall be ruler of Israel.”
	}
}
{
	Qere Ketiv.
}

\Verse{3}
{
	\hJ{וַיָּבֹאוּ כּל־זִקְנֵי יִשְׂרָאֵל אֶל־הַמֶּלֶךְ חֶבְרוֹנָה וַיִּכְרֹת לָהֶם הַמֶּלֶךְ דָּוִד בְּרִית בְּחֶבְרוֹן לִפְנֵי יְהֹוָה וַיִּמְשְׁחוּ אֶת־דָּוִד לְמֶלֶךְ עַל־יִשְׂרָאֵל׃}
}
{
	\eJ{
		All the elders of Israel came to the king at Hebron, and King
		David made a pact with them in Hebron before YHWH. And they
		anointed David king over Israel.
	}
}
{
}

\Verse{4}
{
	\hJ{בֶּן־שְׁלֹשִׁים שָׁנָה דָּוִד בְּמלְכוֹ אַרְבָּעִים שָׁנָה מָלָךְ׃}
}
{
	\eJ{
		David was thirty years old when he became king, and he reigned
		forty years.
	}
}
{
}

\Verse{5}
{
	\hJ{בְּחֶבְרוֹן מָלַךְ עַל־יְהוּדָה שֶׁבַע שָׁנִים וְשִׁשָּׁה חֳדָשִׁים וּבִירוּשָׁלַ͏ִם מָלַךְ שְׁלֹשִׁים וְשָׁלֹשׁ שָׁנָה עַל כּל־יִשְׂרָאֵל וִיהוּדָה׃}
}
{
	\eJ{
		In Hebron he reigned over Judah seven years and six months, and in
		Jerusalem he reigned over all Israel and Judah thirty-three years.
	}
}
{
}

\Verse{6}
{
	\hJ{
		וַיֵּלֶךְ הַמֶּלֶךְ וַאֲנָשָׁיו יְרוּשָׁלַ͏ִם אֶל־הַיְבֻסִי יוֹשֵׁב הָאָרֶץ וַיֹּאמֶר לְדָוִד לֵאמֹר לֹא־תָבוֹא הֵנָּה כִּי אִם־הֱסִירְךָ הַעִוְרִים וְהַפִּסְחִים לֵאמֹר לֹא־יָבוֹא
		דָוִד הֵנָּה׃
	}
}
{
	\eJ{
		The king and his men set out for Jerusalem against the Jebusites
		who inhabited the region. David was told, “You will never get in
		here! Even the blind and the lame will turn you back.” (They
		meant: David will never enter here.)
	}
}
{
}

\Verse{7}
{
	\hJ{וַיִּלְכֹּד דָּוִד אֵת מְצֻדַת צִיּוֹן הִיא עִיר דָּוִד׃}
}
{
	\eJ{
		But David captured the stronghold of Zion; it is now the City of
		David.
	}
}
{
%	\footnote{
%		Footnote 5:7. Zion becomes the City of David here. The place-name is doing
%		politics, not only geography.
%	}
}

\Verse{8}
{
	\hJ{
		וַיֹּאמֶר דָּוִד בַּיּוֹם הַהוּא כּל־מַכֵּה יְבֻסִי וְיִגַּע בַּצִּנּוֹר וְאֶת־הַפִּסְחִים וְאֶת־הַעִוְרִים (שנאו) [שְׂנוּאֵי] נֶפֶשׁ דָּוִד עַל־כֵּן יֹאמְרוּ עִוֵּר וּפִסֵּחַ לֹא
		יָבוֹא אֶל־הַבָּיִת׃
	}
}
{
	\eJ{
		On that occasion David said, “Those who attack the Jebusites shall
		reach the water channel and [strike down] the lame and the blind,
		who are hateful to David.” That is why they say: “No one who is
		blind or lame may enter the House.”
	}
}
{
	Qere Ketiv.
}

\Verse{9}
{
	\hJ{וַיֵּשֶׁב דָּוִד בַּמְּצֻדָה וַיִּקְרָא־לָהּ עִיר דָּוִד וַיִּבֶן דָּוִד סָבִיב מִן־הַמִּלּוֹא וָבָיְתָה׃}
}
{
	\eJ{
		David occupied the stronghold and renamed it the City of David;

{
}

\Verse{10}
{
	\hJ{וַיֵּלֶךְ דָּוִד הָלוֹךְ וְגָדוֹל וַיהֹוָה אֱלֹהֵי צְבָאוֹת עִמּוֹ׃}
}
{
	\eJ{
		David kept growing stronger, for YHWH, the God of Hosts, was with

	}

}

\Verse{11}

}
{

}

\Verse{12}

	\hJ{וַיֵּדַע דָּוִד כִּי־הֱכִינוֹ יְהֹוָה לְמֶלֶךְ עַל־יִשְׂרָאֵל וְכִי נִשֵּׂא מַמְלַכְתּוֹ בַּעֲבוּר עַמּוֹ יִשְׂרָאֵל׃}

\Verse{13}

	\hJ{וַיִּקַּח דָּוִד עוֹד פִּלַגְשִׁים וְנָשִׁים מִירוּשָׁלַ͏ִם אַחֲרֵי בֹּאוֹ מֵחֶבְרוֹן וַיִּוָּלְדוּ עוֹד לְדָוִד בָּנִים וּבָנוֹת׃}

\Verse{17}

	\hJ{וַיִּשְׁמְעוּ פְלִשְׁתִּים כִּי־מָשְׁחוּ אֶת־דָּוִד לְמֶלֶךְ עַל־יִשְׂרָאֵל וַיַּעֲלוּ כל־פְּלִשְׁתִּים לְבַקֵּשׁ אֶת־דָּוִד וַיִּשְׁמַע דָּוִד וַיֵּרֶד אֶל־הַמְּצוּדָה׃}
}
{
	\eJ{
		When the Philistines heard that David had been anointed king over
		Israel, the Philistines marched up in search of David; but David

	}
}
{
}

\Verse{18}

}
{
	\eJ{

	}
}
{
}

\Verse{19}
{
	\hJ{וַיִּשְׁאַל דָּוִד בַּיהֹוָה לֵאמֹר הַאֶעֱלֶה אֶל־פְּלִשְׁתִּים הֲתִתְּנֵם בְּיָדִיוַיֹּאמֶר יְהֹוָה אֶל־דָּוִד עֲלֵה כִּי־נָתֹן אֶתֵּן אֶת־הַפְּלִשְׁתִּים בְּיָדֶךָ׃}
}
{
	\eJ{
		David inquired of YHWH, “Shall I go up against the Philistines?
		Will You deliver them into my hands?” And YHWH answered David, “Go
		up, and I will deliver the Philistines into your hands.”
	}
}
{
}

\Verse{20}
{
	\hJ{וַיָּבֹא דָוִד בְּבַעַל־פְּרָצִים וַיַּכֵּם שָׁם דָּוִד וַיֹּאמֶר פָּרַץ יְהֹוָה אֶת־אֹיְבַי לְפָנַי כְּפֶרֶץ מָיִם עַל־כֵּן קָרָא שֵׁם־הַמָּקוֹם הַהוּא בַּעַל פְּרָצִים׃}
}
{
	\eJ{
		Thereupon David marched to Baal-perazim, and David defeated them
		there. And he said, “YHWH has broken through my enemies before me
		as waters break through [a dam].” That is why that place was named
		Baal-perazim.
	}
}
{
}

{
	\hJ{וַיַּעַזְבוּ שָׁם אֶת־עֲצַבֵּיהֶם וַיִּשָּׂאֵם דָּוִד וַאֲנָשָׁיו׃}
}

}

\Verse{23}
{
	\hJ{וַיִּשְׁאַל דָּוִד בַּיהֹוָה וַיֹּאמֶר לֹא תַעֲלֶה הָסֵב אֶל־אַחֲרֵיהֶם וּבָאתָ לָהֶם מִמּוּל בְּכָאִים׃}

}
{

}
{
	Qere Ketiv.
}
