\Chapter{8}

\Verse{1}
{
	\hJ{וַיְהִי אַחֲרֵי־כֵן וַיַּךְ דָּוִד אֶת־פְּלִשְׁתִּים וַיַּכְנִיעֵם וַיִּקַּח דָּוִד אֶת־מֶתֶג הָאַמָּה מִיַּד פְּלִשְׁתִּים׃}
}
{
	\eJ{
		And after this it was that David struck the Philistines, and
		subdued them: and David took Methegammah from the hand of the
		Philistines.
	}
}
{
}

\Verse{2}
{
	\hJ{
		וַיַּךְ אֶת־מוֹאָב וַיְמַדְּדֵם בַּחֶבֶל הַשְׁכֵּב אוֹתָם אַרְצָה וַיְמַדֵּד שְׁנֵי־חֲבָלִים לְהָמִית וּמְלֹא הַחֶבֶל לְהַחֲיוֹת וַתְּהִי מוֹאָב לְדָוִד לַעֲבָדִים נֹשְׂאֵי
		מִנְחָה׃
	}
}
{
	\eJ{
		And he struck Moab, and measured them with a line, casting them
		down to the ground; even with two lines measured he to put to
		death, and with one full line to keep alive. And the Moabites
		became David’s servants, and brought gifts.
	}
}
{
}

\Verse{3}
{
	\hJ{וַיַּךְ דָּוִד אֶת־הֲדַדְעֶזֶר בֶּן־רְחֹב מֶלֶךְ צוֹבָה בְּלֶכְתּוֹ לְהָשִׁיב יָדוֹ (בנהר) [בִּנְהַר־פְּרָת]׃}
}
{
	\eJ{
		David struck also Hadadezer, the son of Rehob, king of Zobah, as
		he went to recover his border at the river Euphrates.
	}
}
{
}

\Verse{4}
{
	\hJ{וַיִּלְכֹּד דָּוִד מִמֶּנּוּ אֶלֶף וּשְׁבַע־מֵאוֹת פָּרָשִׁים וְעֶשְׂרִים אֶלֶף אִישׁ רַגְלִי וַיְעַקֵּר דָּוִד אֶת־כּל־הָרֶכֶב וַיּוֹתֵר מִמֶּנּוּ מֵאָה רָכֶב׃}
}
{
	\eJ{
		And David took from him a thousand chariots, and seven hundred
		horsemen, and twenty thousand footmen: and David hamstrung all
		the chariot horses, but reserved of them for a hundred chariots.
	}
}
{
}

\Verse{5}
{
	\hJ{וַתָּבֹא אֲרַם דַּמֶּשֶׂק לַעְזֹר לַהֲדַדְעֶזֶר מֶלֶךְ צוֹבָה וַיַּךְ דָּוִד בַּאֲרָם עֶשְׂרִים־וּשְׁנַיִם אֶלֶף אִישׁ׃}
}
{
	\eJ{
		And when the Syrians of Damascus came to help Hadadezer king of
		Zobah, David killed of the Syrians twenty-two thousand men.
	}
}
{
}

\Verse{6}
{
	\hJ{וַיָּשֶׂם דָּוִד נְצִבִים בַּאֲרַם דַּמֶּשֶׂק וַתְּהִי אֲרָם לְדָוִד לַעֲבָדִים נוֹשְׂאֵי מִנְחָה וַיֹּשַׁע יְהֹוָה אֶת־דָּוִד בְּכֹל אֲשֶׁר הָלָךְ׃}
}
{
	\eJ{
		And David put garrisons in Syria of Damascus: and the Syrians
		became servants to David, and brought gifts. And YHWH preserved
		David wherever he went.
	}
}
{
}

\Verse{7}
{
	\hJ{וַיִּקַּח דָּוִד אֵת שִׁלְטֵי הַזָּהָב אֲשֶׁר הָיוּ אֶל עַבְדֵי הֲדַדְעָזֶר וַיְבִיאֵם יְרוּשָׁלָ͏ִם׃}
}
{
	\eJ{
		And David took the shields of gold that were on the servants of
		Hadadezer, and brought them to Jerusalem.
	}
}
{
}

\Verse{8}
{
	\hJ{וּמִבֶּטַח וּמִבֵּרֹתַי עָרֵי הֲדַדְעָזֶר לָקַח הַמֶּלֶךְ דָּוִד נְחֹשֶׁת הַרְבֵּה מְאֹד׃}
}
{
	\eJ{
		And from Betah, and from Berothai, cities of Hadadezer, king
		David took very much bronze.
	}
}
{
}

\Verse{9}
{
	\hJ{וַיִּשְׁמַע תֹּעִי מֶלֶךְ חֲמָת כִּי הִכָּה דָוִד אֵת כּל־חֵיל הֲדַדְעָזֶר׃}
}
{
	\eJ{
		When Toi king of Hamath heard that David had struck all the army
		of Hadadezer,
	}
}
{
}

\Verse{10}
{
	\hJ{
		וַיִּשְׁלַח תֹּעִי אֶת־יוֹרָם־בְּנוֹ אֶל־הַמֶּלֶךְ־דָּוִד לִשְׁאל־לוֹ לְשָׁלוֹם וּלְבָרְכוֹ עַל אֲשֶׁר נִלְחַם בַּהֲדַדְעֶזֶר וַיַּכֵּהוּ כִּי־אִישׁ מִלְחֲמוֹת תֹּעִי הָיָה
		הֲדַדְעָזֶר וּבְיָדוֹ הָיוּ כְּלֵי־כֶסֶף וּכְלֵי־זָהָב וּכְלֵי נְחֹשֶׁת׃
	}
}
{
	\eJ{
		And Toi sent Joram his son to king David, to salute him, and to
		bless him, because he had fought against Hadadezer, and struck
		him: for Hadadezer had wars with Toi. And Joram brought with him
		vessels of silver, and vessels of gold, and vessels of bronze:
	}
}
{
}

\Verse{11}
{
	\hJ{גַּם־אֹתָם הִקְדִּישׁ הַמֶּלֶךְ דָּוִד לַיהֹוָה עִם־הַכֶּסֶף וְהַזָּהָב אֲשֶׁר הִקְדִּישׁ מִכּל־הַגּוֹיִם אֲשֶׁר כִּבֵּשׁ׃}
}
{
	\eJ{
		That also king David did dedicate to YHWH, with the silver and
		gold that he had dedicated of all nations that he subdued;
	}
}
{
}

\Verse{12}
{
	\hJ{מֵאֲרָם וּמִמּוֹאָב וּמִבְּנֵי עַמּוֹן וּמִפְּלִשְׁתִּים וּמֵעֲמָלֵק וּמִשְּׁלַל הֲדַדְעֶזֶר בֶּן־רְחֹב מֶלֶךְ צוֹבָה׃}
}
{
	\eJ{
		Of Syria, and of Moab, and of the children of Ammon, and of the
		Philistines, and of Amalek, and of the spoil of Hadadezer, son
		of Rehob, king of Zobah.
	}
}
{
}

\Verse{13}
{
	\hJ{וַיַּעַשׂ דָּוִד שֵׁם בְּשֻׁבוֹ מֵהַכּוֹתוֹ אֶת־אֲרָם בְּגֵיא־מֶלַח שְׁמוֹנָה עָשָׂר אָלֶף׃}
}
{
	\eJ{
		And David got him a name when he returned from smiting of the
		Syrians in the valley of salt, being eighteen thousand men.
	}
}
{
}

\Verse{14}
{
	\hJ{וַיָּשֶׂם בֶּאֱדוֹם נְצִבִים בְּכל־אֱדוֹם שָׂם נְצִבִים וַיְהִי כל־אֱדוֹם עֲבָדִים לְדָוִד וַיּוֹשַׁע יְהֹוָה אֶת־דָּוִד בְּכֹל אֲשֶׁר הָלָךְ׃}
}
{
	\eJ{
		And he put garrisons in Edom; throughout all Edom put he
		garrisons, and all they of Edom became David’s servants. And
		YHWH preserved David wherever he went.
	}
}
{
}

\Verse{15}
{
	\hJ{וַיִּמְלֹךְ דָּוִד עַל־כּל־יִשְׂרָאֵל וַיְהִי דָוִד עֹשֶׂה מִשְׁפָּט וּצְדָקָה לְכל־עַמּוֹ׃}
}
{
	\eJ{

}

}
{
	\eJ{

}

}

}
