\Chapter{31}

\Verse{1}
{
	\hJ{וּפְלִשְׁתִּים נִלְחָמִים בְּיִשְׂרָאֵל וַיָּנֻסוּ אַנְשֵׁי יִשְׂרָאֵל מִפְּנֵי פְלִשְׁתִּים וַיִּפְּלוּ חֲלָלִים בְּהַר הַגִּלְבֹּעַ׃}
}
{
	\eJ{
		The Philistines attacked Israel, and the men of Israel fled before
		the Philistines and [many] fell on Mount Gilboa.
	}
}
{
}

\Verse{2}
{
	\hX{וַיַּדְבְּקוּ פְלִשְׁתִּים אֶת־שָׁאוּל וְאֶת־בָּנָיו וַיַּכּוּ פְלִשְׁתִּים אֶת־יְהוֹנָתָן וְאֶת־אֲבִינָדָב וְאֶת־מַלְכִּישׁוּעַ בְּנֵי שָׁאוּל׃}
}
{
	\eX{
		The Philistines pursued Saul and his sons, and the Philistines
		struck down Jonathan, Abinadab, and Malchi-shua, sons of Saul.
	}
}
{
}

\Verse{3}
{
	\hX{וַתִּכְבַּד הַמִּלְחָמָה אֶל־שָׁאוּל וַיִּמְצָאֻהוּ הַמּוֹרִים אֲנָשִׁים בַּקָּשֶׁת וַיָּחֶל מְאֹד מֵהַמּוֹרִים׃}
}
{
	\eX{
		The battle raged around Saul, and some of the archers hit him, and
		he was severely wounded by the archers.
	}
}
{
}

\Verse{4}
{
	\hX{
		וַיֹּאמֶר שָׁאוּל לְנֹשֵׂא כֵלָיו שְׁלֹף חַרְבְּךָ וְדקְרֵנִי בָהּ פֶּן־יָבוֹאוּ הָעֲרֵלִים הָאֵלֶּה וּדְקָרֻנִי וְהִתְעַלְּלוּ־בִי וְלֹא אָבָה נֹשֵׂא כֵלָיו כִּי יָרֵא מְאֹד
		וַיִּקַּח שָׁאוּל אֶת־הַחֶרֶב וַיִּפֹּל עָלֶיהָ׃
	}
}
{
	\eX{
		Saul said to his arms-bearer, “Draw your sword and run me through,
		so that the uncircumcised may not run me through and make sport of
		me.” But his arms-bearer, in his great awe, refused; whereupon
		Saul grasped the sword and fell upon it.
	}
}
{
%	\footnote{
%		Footnote 31:4. Saul falls on his own sword after fearing what the uncircumcised
%		will do to him. The first royal story ends with Israel's king becoming his own
%		executioner.
%	}
}

\Verse{5}
{
	\hX{וַיַּרְא נֹשֵׂא־כֵלָיו כִּי מֵת שָׁאוּל וַיִּפֹּל גַּם־הוּא עַל־חַרְבּוֹ וַיָּמת עִמּוֹ׃}
}
{
	\eX{
		When his arms-bearer saw that Saul was dead, he too fell on his
		sword and died with him.
	}
}
{
}

\Verse{6}
{
	\hX{וַיָּמת שָׁאוּל וּשְׁלֹשֶׁת בָּנָיו וְנֹשֵׂא כֵלָיו גַּם כּל־אֲנָשָׁיו בַּיּוֹם הַהוּא יַחְדָּו׃}
}
{
	\eX{
		Thus Saul and his three sons and his arms-bearer, as well as all
		his men, died together on that day.
	}
}
{
}

\Verse{7}
{
	\hX{
		וַיִּרְאוּ אַנְשֵׁי־יִשְׂרָאֵל אֲשֶׁר־בְּעֵבֶר הָעֵמֶק וַאֲשֶׁר בְּעֵבֶר הַיַּרְדֵּן כִּי־נָסוּ אַנְשֵׁי יִשְׂרָאֵל וְכִי־מֵתוּ שָׁאוּל וּבָנָיו וַיַּעַזְבוּ אֶת־הֶעָרִים
		וַיָּנֻסוּ וַיָּבֹאוּ פְלִשְׁתִּים וַיֵּשְׁבוּ בָּהֶן׃
	}
}
{
	\eX{
		And when the men of Israel on the other side of the valley and on
		the other side of the Jordan saw that the men of Israel had fled
		and that Saul and his sons were dead, they abandoned the towns and
		fled; the Philistines then came and occupied them.
	}
}
{
}

\Verse{8}
{
	\hJ{וַיְהִי מִמּחֳרָת וַיָּבֹאוּ פְלִשְׁתִּים לְפַשֵּׁט אֶת־הַחֲלָלִים וַיִּמְצְאוּ אֶת־שָׁאוּל וְאֶת־שְׁלֹשֶׁת בָּנָיו נֹפְלִים בְּהַר הַגִּלְבֹּעַ׃}
}
{
	\eJ{
		The next day the Philistines came to strip the slain, and they
		found Saul and his three sons lying on Mount Gilboa.
	}
}
{
}

\Verse{9}
{
	\hJ{וַיִּכְרְתוּ אֶת־רֹאשׁוֹ וַיַּפְשִׁטוּ אֶת־כֵּלָיו וַיְשַׁלְּחוּ בְאֶרֶץ־פְּלִשְׁתִּים סָבִיב לְבַשֵּׂר בֵּית עֲצַבֵּיהֶם וְאֶת־הָעָם׃}
}
{
	\eJ{
		They cut off his head and stripped him of his armor, and they sent
		them throughout the land of the Philistines, to spread the news in
		the temples of their idols and among the people.
	}
}
{
}

\Verse{10}
{
	\hJ{וַיָּשִׂימוּ אֶת־כֵּלָיו בֵּית עַשְׁתָּרוֹת וְאֶת־גְּוִיָּתוֹ תָּקְעוּ בְּחוֹמַת בֵּית שָׁן׃}
}
{
	\eJ{
		They placed his armor in the temple of Ashtaroth, and they impaled
		his body on the wall of Beth-shan.
	}
}
{
}

\Verse{11}
{
	\hJ{וַיִּשְׁמְעוּ אֵלָיו יֹשְׁבֵי יָבֵישׁ גִּלְעָד אֵת אֲשֶׁר־עָשׂוּ פְלִשְׁתִּים לְשָׁאוּל׃}
}
{
	\eJ{
		When the inhabitants of Jabesh-gilead heard about it—what the
		Philistines had done to Saul—
	}
}
{
}

\Verse{12}
{
	\hJ{וַיָּקוּמוּ כּל־אִישׁ חַיִל וַיֵּלְכוּ כל־הַלַּיְלָה וַיִּקְחוּ אֶת־גְּוִיַּת שָׁאוּל וְאֵת גְּוִיֹּת בָּנָיו מֵחוֹמַת בֵּית שָׁן וַיָּבֹאוּ יָבֵשָׁה וַיִּשְׂרְפוּ אֹתָם שָׁם׃}
}
{
	\eJ{
		all their stalwart men set out and marched all night; they removed
		the bodies of Saul and his sons from the wall of Beth-shan and
		came to Jabesh and burned them there.
	}
}
{
}

\Verse{13}
{
	\hJ{וַיִּקְחוּ אֶת־עַצְמֹתֵיהֶם וַיִּקְבְּרוּ תַחַת־הָאֶשֶׁל בְּיָבֵשָׁה וַיָּצֻמוּ שִׁבְעַת יָמִים׃}
}
{
	\eJ{
		Then they took the bones and buried them under the tamarisk tree
		in Jabesh, and they fasted for seven days.
	}
}
{
}
