\Chapter{29}

\Verse{1}
{
	\hJ{וַיִּקְבְּצוּ פְלִשְׁתִּים אֶת־כּל־מַחֲנֵיהֶם אֲפֵקָה וְיִשְׂרָאֵל חֹנִים בַּעַיִן אֲשֶׁר בְּיִזְרְעֶאל׃}
}
{
	\eJ{
		And the Philistines gathered together all their armies to Aphek:
		and the Israelites pitched by a fountain which is in Jezreel.
	}
}
{
}

\Verse{2}
{
	\hJ{וְסַרְנֵי פְלִשְׁתִּים עֹבְרִים לְמֵאוֹת וְלַאֲלָפִים וְדָוִד וַאֲנָשָׁיו עֹבְרִים בָּאַחֲרֹנָה עִם־אָכִישׁ׃}
}
{
	\eJ{
		And the lords of the Philistines passed on by hundreds, and by
		thousands: but David and his men passed on in the rereward with
		Achish.
	}
}
{
}

\Verse{3}
{
	\hJ{
		וַיֹּאמְרוּ שָׂרֵי פְלִשְׁתִּים מָה הָעִבְרִים הָאֵלֶּה וַיֹּאמֶר אָכִישׁ אֶל־שָׂרֵי פְלִשְׁתִּים הֲלוֹא־זֶה דָוִד עֶבֶד שָׁאוּל מֶלֶךְ־יִשְׂרָאֵל אֲשֶׁר הָיָה אִתִּי זֶה יָמִים
		אוֹ־זֶה שָׁנִים וְלֹא־מָצָאתִי בוֹ מְאוּמָה מִיּוֹם נפְלוֹ עַד־הַיּוֹם הַזֶּה׃
	}
}
{
	\eJ{
		And said the princes of the Philistines, What do these Hebrews
		here? And Achish said to the princes of the Philistines, Is not
		this David, the servant of Saul the king of Israel, which has
		been with me these days, or these years, and I've found no fault
		in him since he fell to me to this day?
	}
}
{
}

\Verse{4}
{
	\hJ{
		וַיִּקְצְפוּ עָלָיו שָׂרֵי פְלִשְׁתִּים וַיֹּאמְרוּ לוֹ שָׂרֵי פְלִשְׁתִּים הָשֵׁב אֶת־הָאִישׁ וְיָשֹׁב אֶל־מְקוֹמוֹ אֲשֶׁר הִפְקַדְתּוֹ שָׁם וְלֹא־יֵרֵד עִמָּנוּ בַּמִּלְחָמָה
		וְלֹא־יִהְיֶה־לָּנוּ לְשָׂטָן בַּמִּלְחָמָה וּבַמֶּה יִתְרַצֶּה זֶה אֶל־אֲדֹנָיו הֲלוֹא בְּרָאשֵׁי הָאֲנָשִׁים הָהֵם׃
	}
}
{
	\eJ{
		And the princes of the Philistines were wroth with him: and the
		princes of the Philistines said to him, Make this fellow return,
		that he may go again to his place which you've appointed him,
		and let him not go down with us to battle, or else in the battle
		he be an adversary to us: for wherewith should he reconcile
		himself to his master? should it not be with the heads of these
		men?
	}
}
{
}

\Verse{5}
{
	\hJ{הֲלוֹא־זֶה דָוִד אֲשֶׁר יַעֲנוּ־לוֹ בַּמְּחֹלוֹת לֵאמֹר הִכָּה שָׁאוּל בַּאֲלָפָיו וְדָוִד בְּרִבְבֹתָו׃}
}
{
	\eJ{
		Is not this David, of whom they sang one to another in dances,
		saying, Saul killed his thousands, and David his ten thousands?
	}
}
{
}

\Verse{6}
{
	\hJ{
		וַיִּקְרָא אָכִישׁ אֶל־דָּוִד וַיֹּאמֶר אֵלָיו חַי־יְהֹוָה כִּי־יָשָׁר אַתָּה וְטוֹב בְּעֵינַי צֵאתְךָ וּבֹאֲךָ אִתִּי בַּמַּחֲנֶה כִּי לֹא־מָצָאתִי בְךָ רָעָה מִיּוֹם בֹּאֲךָ
		אֵלַי עַד־הַיּוֹם הַזֶּה וּבְעֵינֵי הַסְּרָנִים לֹא־טוֹב אָתָּה׃
	}
}
{
	\eJ{
		And Achish called David, and said to him, Surely, as YHWH lives,
		you've been upright, and your going out and your coming in with
		me in the army is good in my sight: for I've not found bad in
		you since the day of your coming to me to this day: nevertheless
		the lords favor you not.
	}
}
{
}

\Verse{7}
{
	\hJ{וְעַתָּה שׁוּב וְלֵךְ בְּשָׁלוֹם וְלֹא־תַעֲשֶׂה רָע בְּעֵינֵי סַרְנֵי פְלִשְׁתִּים׃}
}
{
	\eJ{
		And so now return, and go in peace, that you displease not the
		lords of the Philistines.
	}
}
{
}

\Verse{8}
{
	\hJ{
		וַיֹּאמֶר דָּוִד אֶל־אָכִישׁ כִּי מֶה עָשִׂיתִי וּמַה־מָּצָאתָ בְעַבְדְּךָ מִיּוֹם אֲשֶׁר הָיִיתִי לְפָנֶיךָ עַד הַיּוֹם הַזֶּה כִּי לֹא אָבוֹא וְנִלְחַמְתִּי בְּאֹיְבֵי אֲדֹנִי
		הַמֶּלֶךְ׃
	}
}
{
	\eJ{
		And David said to Achish, But what have I done? and what have
		you found in your servant so long as I've been with you to this
		day, that I may not go fight against the enemies of my lord the
		king?
	}
}
{
}

\Verse{9}
{
	\hJ{וַיַּעַן אָכִישׁ וַיֹּאמֶר אֶל־דָּוִד יָדַעְתִּי כִּי טוֹב אַתָּה בְּעֵינַי כְּמַלְאַךְ אֱלֹהִים אַךְ שָׂרֵי פְלִשְׁתִּים אָמְרוּ לֹא־יַעֲלֶה עִמָּנוּ בַּמִּלְחָמָה׃}
}
{
	\eJ{
		And Achish answered and said to David, I know that you're good
		in my sight, as an angel of God: but the princes of the
		Philistines have said, He shall not go up with us to the battle.
	}
}
{
}

\Verse{10}
{
	\hJ{וְעַתָּה הַשְׁכֵּם בַּבֹּקֶר וְעַבְדֵי אֲדֹנֶיךָ אֲשֶׁר־בָּאוּ אִתָּךְ וְהִשְׁכַּמְתֶּם בַּבֹּקֶר וְאוֹר לָכֶם וָלֵכוּ׃}
}
{
	\eJ{
		And so now rise up early in the morning with your master’s
		servants that have come with you: and as soon as you be up early
		in the morning, and have light, go away.
	}
}
{
}

\Verse{11}
{
	\hJ{וַיַּשְׁכֵּם דָּוִד הוּא וַאֲנָשָׁיו לָלֶכֶת בַּבֹּקֶר לָשׁוּב אֶל־אֶרֶץ פְּלִשְׁתִּים וּפְלִשְׁתִּים עָלוּ יִזְרְעֶאל׃}
}
{
	\eJ{
		And David and his men rose up early to go away in the morning,
		to return into the land of the Philistines. And the Philistines
		went up to Jezreel.
	}
}
{
}
