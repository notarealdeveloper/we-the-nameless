\Chapter{26}

\Verse{1}
{
	\hJ{וַיָּבֹאוּ הַזִּפִים אֶל־שָׁאוּל הַגִּבְעָתָה לֵאמֹר הֲלוֹא דָוִד מִסְתַּתֵּר בְּגִבְעַת הַחֲכִילָה עַל פְּנֵי הַיְשִׁימֹן׃}
}
{
	\eJ{
		And the Ziphites came to Saul to Gibeah, saying, Does not David
		hide himself in the hill of Hachilah, which is before Jeshimon?
	}
}
{
}

\Verse{2}
{
	\hJ{וַיָּקם שָׁאוּל וַיֵּרֶד אֶל־מִדְבַּר־זִיף וְאִתּוֹ שְׁלֹשֶׁת־אֲלָפִים אִישׁ בְּחוּרֵי יִשְׂרָאֵל לְבַקֵּשׁ אֶת־דָּוִד בְּמִדְבַּר־זִיף׃}
}
{
	\eJ{
		And Saul arose, and went down to the wilderness of Ziph, having
		three thousand chosen men of Israel with him, to seek David in
		the wilderness of Ziph.
	}
}
{
}

\Verse{3}
{
	\hJ{וַיִּחַן שָׁאוּל בְּגִבְעַת הַחֲכִילָה אֲשֶׁר עַל־פְּנֵי הַיְשִׁימֹן עַל־הַדָּרֶךְ וְדָוִד יֹשֵׁב בַּמִּדְבָּר וַיַּרְא כִּי בָא שָׁאוּל אַחֲרָיו הַמִּדְבָּרָה׃}
}
{
	\eJ{
		And Saul pitched in the hill of Hachilah, which is before
		Jeshimon, by the way. But David abode in the wilderness, and he
		saw that Saul came after him into the wilderness.
	}
}
{
}

\Verse{4}
{
	\hJ{וַיִּשְׁלַח דָּוִד מְרַגְּלִים וַיֵּדַע כִּי־בָא שָׁאוּל אֶל־נָכוֹן׃}
}
{
	\eJ{
		David therefore sent out spies, and understood that Saul had
		come in very deed.
	}
}
{
}

\Verse{5}
{
	\hJ{
		וַיָּקם דָּוִד וַיָּבֹא אֶל־הַמָּקוֹם אֲשֶׁר חָנָה־שָׁם שָׁאוּל וַיַּרְא דָּוִד אֶת־הַמָּקוֹם אֲשֶׁר שָׁכַב־שָׁם שָׁאוּל וְאַבְנֵר בֶּן־נֵר שַׂר־צְבָאוֹ וְשָׁאוּל שֹׁכֵב
		בַּמַּעְגָּל וְהָעָם חֹנִים סְבִיבֹתָו׃
	}
}
{
	\eJ{
		And David arose, and came to the place where Saul had pitched:
		and David beheld the place where Saul lay, and Abner the son of
		Ner, the captain of his army: and Saul lay in the trench, and
		the people pitched round about him.
	}
}
{
}

\Verse{6}
{
	\hJ{
		וַיַּעַן דָּוִד וַיֹּאמֶר אֶל־אֲחִימֶלֶךְ הַחִתִּי וְאֶל־אֲבִישַׁי בֶּן־צְרוּיָה אֲחִי יוֹאָב לֵאמֹר מִי־יֵרֵד אִתִּי אֶל־שָׁאוּל אֶל־הַמַּחֲנֶה וַיֹּאמֶר אֲבִישַׁי אֲנִי אֵרֵד
		עִמָּךְ׃
	}
}
{
	\eJ{
		And answered David and said to Ahimelech the Hittite, and to
		Abishai the son of Zeruiah, brother to Joab, saying, Who will go
		down with me to Saul to the camp? And Abishai said, I'll go down
		with you.
	}
}
{
}

\Verse{7}
{
	\hJ{וַיָּבֹא דָוִד וַאֲבִישַׁי אֶל־הָעָם לַיְלָה וְהִנֵּה שָׁאוּל שֹׁכֵב יָשֵׁן בַּמַּעְגָּל וַחֲנִיתוֹ מְעוּכָה־בָאָרֶץ מְרַאֲשֹׁתָו וְאַבְנֵר וְהָעָם שֹׁכְבִים סְבִיבֹתָו׃}
}
{
	\eJ{
		And David and Abishai came to the people by night: and, here:
		Saul lay sleeping within the trench, and his spear stuck in the
		ground at his bolster: but Abner and the people lay round about
		him.
	}
}
{
}

\Verse{8}
{
	\hJ{וַיֹּאמֶר אֲבִישַׁי אֶל־דָּוִד סִגַּר אֱלֹהִים הַיּוֹם אֶת־אוֹיִבְךָ בְּיָדֶךָ וְעַתָּה אַכֶּנּוּ נָא בַּחֲנִית וּבָאָרֶץ פַּעַם אַחַת וְלֹא אֶשְׁנֶה לוֹ׃}
}
{
	\eJ{
		And said Abishai to David, God has delivered your enemy into
		your hand this day: now therefore let me strike him, please,
		with the spear even to the earth at once, and I'll not strike
		him the second time.
	}
}
{
}

\Verse{9}
{
	\hJ{וַיֹּאמֶר דָּוִד אֶל־אֲבִישַׁי אַל־תַּשְׁחִיתֵהוּ כִּי מִי שָׁלַח יָדוֹ בִּמְשִׁיחַ יְהֹוָה וְנִקָּה׃}
}
{
	\eJ{
		And David said to Abishai, Destroy him not: for who can stretch
		forth his hand against YHWH’s anointed, and be guiltless?
	}
}
{
}

\Verse{10}
{
	\hJ{וַיֹּאמֶר דָּוִד חַי־יְהֹוָה כִּי אִם־יְהֹוָה יִגֳּפֶנּוּ אוֹ־יוֹמוֹ יָבוֹא וָמֵת אוֹ בַמִּלְחָמָה יֵרֵד וְנִסְפָּה׃}
}
{
	\eJ{
		David said furthermore, As YHWH lives, YHWH shall strike him: or
		his day shall come to die: or he shall descend into battle, and
		perish.
	}
}
{
}

\Verse{11}
{
	\hJ{חָלִילָה לִּי מֵיְהֹוָה מִשְּׁלֹחַ יָדִי בִּמְשִׁיחַ יְהֹוָה וְעַתָּה קַח־נָא אֶת־הַחֲנִית אֲשֶׁר מְרַאֲשֹׁתָו וְאֶת־צַפַּחַת הַמַּיִם וְנֵלְכָה־לָּנוּ׃}
}
{
	\eJ{
		YHWH forbid that I should stretch forth my hand against YHWH’s
		anointed: but, please, take you now the spear that is at his
		bolster, and the cruse of water, and let us go.
	}
}
{
}

\Verse{12}
{
	\hJ{
		וַיִּקַּח דָּוִד אֶת־הַחֲנִית וְאֶת־צַפַּחַת הַמַּיִם מֵרַאֲשֹׁתֵי שָׁאוּל וַיֵּלְכוּ לָהֶם וְאֵין רֹאֶה וְאֵין יוֹדֵעַ וְאֵין מֵקִיץ כִּי כֻלָּם יְשֵׁנִים כִּי תַּרְדֵּמַת יְהֹוָה
		נָפְלָה עֲלֵיהֶם׃
	}
}
{
	\eJ{
		And David took the spear and the cruse of water from Saul’s
		bolster: and they got them away, and no man saw it, nor knew it,
		neither awaked: for they were all asleep: because a deep sleep
		from YHWH was fallen on them.
	}
}
{
}

\Verse{13}
{
	\hJ{וַיַּעֲבֹר דָּוִד הָעֵבֶר וַיַּעֲמֹד עַל־רֹאשׁ־הָהָר מֵרָחֹק רַב הַמָּקוֹם בֵּינֵיהֶם׃}
}
{
	\eJ{
		And David went over to the other side, and stood on the top of
		an hill afar off: a great space being between them:
	}
}
{
}

\Verse{14}
{
	\hJ{וַיִּקְרָא דָוִד אֶל־הָעָם וְאֶל־אַבְנֵר בֶּן־נֵר לֵאמֹר הֲלוֹא תַעֲנֶה אַבְנֵר וַיַּעַן אַבְנֵר וַיֹּאמֶר מִי אַתָּה קָרָאתָ אֶל־הַמֶּלֶךְ׃}
}
{
	\eJ{
		And David cried to the people, and to Abner the son of Ner,
		saying, Do you answer you not, Abner? Then Abner answered and
		said, Who are you that cry to the king?
	}
}
{
}

\Verse{15}
{
	\hJ{
		וַיֹּאמֶר דָּוִד אֶל־אַבְנֵר הֲלוֹא־אִישׁ אַתָּה וּמִי כָמוֹךָ בְּיִשְׂרָאֵל וְלָמָּה לֹא שָׁמַרְתָּ אֶל־אֲדֹנֶיךָ הַמֶּלֶךְ כִּי־בָא אַחַד הָעָם לְהַשְׁחִית אֶת־הַמֶּלֶךְ
		אֲדֹנֶיךָ׃
	}
}
{
	\eJ{
		And David said to Abner, Are not you a valiant man? and who is
		like to you in Israel? why then have you not kept your lord the
		king? for there came one of the people in to destroy the king
		your lord.
	}
}
{
}

\Verse{16}
{
	\hJ{
		לֹא־טוֹב הַדָּבָר הַזֶּה אֲשֶׁר עָשִׂיתָ חַי־יְהֹוָה כִּי בְנֵי־מָוֶת אַתֶּם אֲשֶׁר לֹא־שְׁמַרְתֶּם עַל־אֲדֹנֵיכֶם עַל־מְשִׁיחַ יְהֹוָה וְעַתָּה רְאֵה אֵי־חֲנִית הַמֶּלֶךְ
		וְאֶת־צַפַּחַת הַמַּיִם אֲשֶׁר מְרַאֲשֹׁתָו׃
	}
}
{
	\eJ{
		This thing is not good that you've done. As YHWH lives, you're
		worthy to die, because you've not kept your master, YHWH’s
		anointed.
	}
}
{
}

\Verse{17}
{
	\hJ{וַיַּכֵּר שָׁאוּל אֶת־קוֹל דָּוִד וַיֹּאמֶר הֲקוֹלְךָ זֶה בְּנִי דָוִד וַיֹּאמֶר דָּוִד קוֹלִי אֲדֹנִי הַמֶּלֶךְ׃}
}
{
	\eJ{
		And Saul knew David’s voice, and said, Is this your voice, my
		son David? And David said, It is my voice, my lord, O king.
	}
}
{
}

\Verse{18}
{
	\hJ{וַיֹּאמֶר לָמָּה זֶּה אֲדֹנִי רֹדֵף אַחֲרֵי עַבְדּוֹ כִּי מֶה עָשִׂיתִי וּמַה־בְּיָדִי רָעָה׃}
}
{
	\eJ{
		And he said, And so does my lord thus pursue after his servant?
		for what have I done? or what bad is in my hand?
	}
}
{
}

\Verse{19}
{
	\hJ{
		וְעַתָּה יִשְׁמַע־נָא אֲדֹנִי הַמֶּלֶךְ אֵת דִּבְרֵי עַבְדּוֹ אִם־יְהֹוָה הֱסִיתְךָ בִי יָרַח מִנְחָה וְאִם בְּנֵי הָאָדָם אֲרוּרִים הֵם לִפְנֵי יְהֹוָה כִּי־גֵרְשׁוּנִי הַיּוֹם
		מֵהִסְתַּפֵּחַ בְּנַחֲלַת יְהֹוָה לֵאמֹר לֵךְ עֲבֹד אֱלֹהִים אֲחֵרִים׃
	}
}
{
	\eJ{
		And therefore, please, let my lord the king hear the words of
		his servant. If YHWH have stirred you up against me, let him
		accept an offering: but if they be the children of men, cursed
		be they before YHWH: for they've driven me out this day from
		abiding in the legacy of YHWH, saying, Go, serve other gods.
	}
}
{
}

\Verse{20}
{
	\hJ{וְעַתָּה אַל־יִפֹּל דָּמִי אַרְצָה מִנֶּגֶד פְּנֵי יְהֹוָה כִּי־יָצָא מֶלֶךְ יִשְׂרָאֵל לְבַקֵּשׁ אֶת־פַּרְעֹשׁ אֶחָד כַּאֲשֶׁר יִרְדֹּף הַקֹּרֵא בֶּהָרִים׃}
}
{
	\eJ{
		And therefore, let not my blood fall to the earth before the
		face of YHWH: for the king of Israel has come out to seek a
		flea, as when one does hunt a partridge in the mountains.
	}
}
{
}

\Verse{21}
{
	\hJ{וַיֹּאמֶר שָׁאוּל חָטָאתִי שׁוּב בְּנִי־דָוִד כִּי לֹא־אָרַע לְךָ עוֹד תַּחַת אֲשֶׁר יָקְרָה נַפְשִׁי בְּעֵינֶיךָ הַיּוֹם הַזֶּה הִנֵּה הִסְכַּלְתִּי וָאֶשְׁגֶּה הַרְבֵּה מְאֹד׃}
}
{
	\eJ{
		And said Saul, I've sinned: return, my son David: for I'll no
		more do you harm, because my life was precious in your eyes this
		day: here: I've played the fool, and have erred exceedingly.
	}
}
{
}

\Verse{22}

{
}

\Verse{23}
{
	\hJ{וַיהֹוָה יָשִׁיב לָאִישׁ אֶת־צִדְקָתוֹ וְאֶת־אֱמֻנָתוֹ אֲשֶׁר נְתָנְךָ יְהֹוָה הַיּוֹם בְּיָד וְלֹא אָבִיתִי לִשְׁלֹחַ יָדִי בִּמְשִׁיחַ יְהֹוָה׃}

	}
}
{
}

\Verse{24}

}
{
	\eJ{

		let my life be much set by in the eyes of YHWH, and let him
		deliver me out of all tribulation.
	}
}
{
}

\Verse{25}
{

}
{
	\eJ{

		both do great things, and also shall still prevail. So David
		went on his way, and Saul returned to his place.
	}
}
{
}
