\Chapter{11}

\Verse{1}
{
	\hJ{וַיַּעַל נָחָשׁ הָעַמּוֹנִי וַיִּחַן עַל־יָבֵישׁ גִּלְעָד וַיֹּאמְרוּ כּל־אַנְשֵׁי יָבֵישׁ אֶל־נָחָשׁ כְּרת־לָנוּ בְרִית וְנַעַבְדֶךָּ׃}
}
{
	\eJ{
		And Nahash the Ammonite came up, and encamped against
		Jabesh-gilead: and all the men of Jabesh said to Nahash, Make a
		covenant with us, and we'll serve you.
	}
}
{
}

\Verse{2}
{
	\hJ{וַיֹּאמֶר אֲלֵיהֶם נָחָשׁ הָעַמּוֹנִי בְּזֹאת אֶכְרֹת לָכֶם בִּנְקוֹר לָכֶם כּל־עֵין יָמִין וְשַׂמְתִּיהָ חֶרְפָּה עַל־כּל־יִשְׂרָאֵל׃}
}
{
	\eJ{
		And Nahash the Ammonite answered them, On this condition will I
		make a covenant with you, that I may thrust out all your right
		eyes, and lay it for a reproach on all Israel.
	}
}
{
}

\Verse{3}
{
	\hJ{וַיֹּאמְרוּ אֵלָיו זִקְנֵי יָבֵישׁ הֶרֶף לָנוּ שִׁבְעַת יָמִים וְנִשְׁלְחָה מַלְאָכִים בְּכֹל גְּבוּל יִשְׂרָאֵל וְאִם־אֵין מוֹשִׁיעַ אֹתָנוּ וְיָצָאנוּ אֵלֶיךָ׃}
}
{
	\eJ{
		And the elders of Jabesh said to him, Give us seven days’
		respite, that we may send messengers to all the borders of
		Israel: and then, if there be no man to save us, we'll come out
		to you.
	}
}
{
}

\Verse{4}
{
	\hJ{וַיָּבֹאוּ הַמַּלְאָכִים גִּבְעַת שָׁאוּל וַיְדַבְּרוּ הַדְּבָרִים בְּאזְנֵי הָעָם וַיִּשְׂאוּ כל־הָעָם אֶת־קוֹלָם וַיִּבְכּוּ׃}
}
{
	\eJ{
		And came the messengers to Gibeah of Saul, and told the news in
		the ears of the people: and all the people lifted up their
		voices, and wept.
	}
}
{
}

\Verse{5}
{
	\hJ{וְהִנֵּה שָׁאוּל בָּא אַחֲרֵי הַבָּקָר מִן־הַשָּׂדֶה וַיֹּאמֶר שָׁאוּל מַה־לָּעָם כִּי יִבְכּוּ וַיְסַפְּרוּ־לוֹ אֶת־דִּבְרֵי אַנְשֵׁי יָבֵישׁ׃}
}
{
	\eJ{
		And, here: Saul came after the herd out of the field: and Saul
		said, What ails the people that they weep? And they told him the
		news of the men of Jabesh.
	}
}
{
}

{
	\hJ{וַתִּצְלַח רוּחַ־אֱלֹהִים עַל־שָׁאוּל (בשמעו) [כְּשׁמְעוֹ] אֶת־הַדְּבָרִים הָאֵלֶּה וַיִּחַר אַפּוֹ מְאֹד׃}
}

\Verse{7}
{
	\hJ{
		וַיִּקַּח צֶמֶד בָּקָר וַיְנַתְּחֵהוּ וַיְשַׁלַּח בְּכל־גְּבוּל יִשְׂרָאֵל בְּיַד הַמַּלְאָכִים לֵאמֹר אֲשֶׁר אֵינֶנּוּ יֹצֵא אַחֲרֵי שָׁאוּל וְאַחַר שְׁמוּאֵל כֹּה יֵעָשֶׂה
		לִבְקָרוֹ וַיִּפֹּל פַּחַד־יְהֹוָה עַל־הָעָם וַיֵּצְאוּ כְּאִישׁ אֶחָד׃
	}
}
{
	\eJ{
		And he took a yoke of cattle, and hewed them in pieces, and sent
		them throughout all the borders of Israel by the hands of
		messengers, saying, Whosoever comes not forth after Saul and
		after Samuel, so shall it be done to his cattle. And the fear of
		YHWH fell on the people, and they came out with one consent.
	}
}
{
}

}

\Verse{11}
{
	\hJ{
		וַיְהִי מִמּחֳרָת וַיָּשֶׂם שָׁאוּל אֶת־הָעָם שְׁלֹשָׁה רָאשִׁים וַיָּבֹאוּ בְתוֹךְ־הַמַּחֲנֶה בְּאַשְׁמֹרֶת הַבֹּקֶר וַיַּכּוּ אֶת־עַמּוֹן עַד־חֹם הַיּוֹם וַיְהִי הַנִּשְׁאָרִים
		וַיָּפֻצוּ וְלֹא נִשְׁאֲרוּ־בָם שְׁנַיִם יָחַד׃
	}
}
{
	\eJ{
		And it was so on the next day, that Saul put the people in three
		companies: and they came into the midst of the army in the
		morning watch, and killed the Ammonites until the heat of the
		day: and it came to pass, that they which remained were
		scattered, so that two of them were not left together.
	}
}
{
}

\Verse{15}
