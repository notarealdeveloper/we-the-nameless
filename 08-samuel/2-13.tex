	\hJ{וַיַּעֲשׂוּ נַעֲרֵי אַבְשָׁלוֹם לְאַמְנוֹן כַּאֲשֶׁר צִוָּה אַבְשָׁלוֹם וַיָּקֻמוּ כּל־בְּנֵי הַמֶּלֶךְ וַיִּרְכְּבוּ אִישׁ עַל־פִּרְדּוֹ וַיָּנֻסוּ׃}
}
{
	\eJ{
		And the servants of Absalom did to Amnon as Absalom had
		commanded.
	}
}
{
}

\Verse{30}
{
	\hJ{וַיְהִי הֵמָּה בַדֶּרֶךְ וְהַשְּׁמֻעָה בָאָה אֶל־דָּוִד לֵאמֹר הִכָּה אַבְשָׁלוֹם אֶת־כּל־בְּנֵי הַמֶּלֶךְ וְלֹא־נוֹתַר מֵהֶם אֶחָד׃}
}
{
	\eJ{
		And it was, while they were in the way, that news came to David,
		saying, Absalom has killed all the king’s sons, and there is not
		one of them left.
	}
}
{
}

\Verse{31}
{

}
{
	\eJ{
		And the king arose, and tare his garments, and lay on the earth;
		and all his servants stood by with their clothes torn.
	}
}
{
}

\Verse{32}
{
	\hJ{
		וַיַּעַן יוֹנָדָב בֶּן־שִׁמְעָה אֲחִי־דָוִד וַיֹּאמֶר אַל־יֹאמַר אֲדֹנִי אֵת כּל־הַנְּעָרִים בְּנֵי־הַמֶּלֶךְ הֵמִיתוּ כִּי־אַמְנוֹן לְבַדּוֹ מֵת כִּי־עַל־פִּי אַבְשָׁלוֹם הָיְתָה
		שׂוּמָה מִיּוֹם עַנֹּתוֹ אֵת תָּמָר אֲחֹתוֹ׃
	}
}
{
	\eJ{
		And Jonadab, the son of Shimeah David’s brother, answered and
		said, Let not my lord suppose that they've killed all the young
		men the king’s sons; for Amnon only is dead: for by the
		appointment of Absalom this has been determined from the day
		that he forced his sister Tamar.
	}
}
{
}

\Verse{33}
{
	\hJ{וְעַתָּה אַל־יָשֵׂם אֲדֹנִי הַמֶּלֶךְ אֶל־לִבּוֹ דָּבָר לֵאמֹר כּל־בְּנֵי הַמֶּלֶךְ מֵתוּ כִּי־(אם)־אַמְנוֹן לְבַדּוֹ מֵת׃}
}
{
	\eJ{
		And now let not my lord the king take the thing to his heart, to
		think that all the king’s sons are dead: for Amnon only is dead.
	}
}
{
}

\Verse{34}
{
	\hJ{וַיִּבְרַח אַבְשָׁלוֹם וַיִּשָּׂא הַנַּעַר הַצֹּפֶה אֶת־עֵינָו וַיַּרְא וְהִנֵּה עַם־רַב הֹלְכִים מִדֶּרֶךְ אַחֲרָיו מִצַּד הָהָר׃}
}
{
	\eJ{
		But Absalom fled. And the young man that kept the watch lifted
		his eyes, and looked, and, here: there came much people by the
		way of the hill side behind him.
	}
}
{
}

\Verse{35}
{
	\hJ{וַיֹּאמֶר יוֹנָדָב אֶל־הַמֶּלֶךְ הִנֵּה בְנֵי־הַמֶּלֶךְ בָּאוּ כִּדְבַר עַבְדְּךָ כֵּן הָיָה׃}
}
{
	\eJ{
		And Jonadab said to the king, Here: the king’s sons come: as
		your servant said, so it is.
	}
}
{
}

\Verse{36}
{
	\hJ{וַיְהִי כְּכַלֹּתוֹ לְדַבֵּר וְהִנֵּה בְנֵי־הַמֶּלֶךְ בָּאוּ וַיִּשְׂאוּ קוֹלָם וַיִּבְכּוּ וְגַם־הַמֶּלֶךְ וְכל־עֲבָדָיו בָּכוּ בְּכִי גָּדוֹל מְאֹד׃}
}
{
	\eJ{
		And it was, as soon as he had made an end of speaking, that,
		here: the king’s sons came, and lifted up their voice and wept:
		and the king also and all his servants wept very sore.
	}
}
{
}

\Verse{37}
{
	\hJ{וְאַבְשָׁלוֹם בָּרַח וַיֵּלֶךְ אֶל־תַּלְמַי בֶּן־[עַמִּיהוּד] (עמיחור) מֶלֶךְ גְּשׁוּר וַיִּתְאַבֵּל עַל־בְּנוֹ כּל־הַיָּמִים׃}
}
{
	\eJ{
		But Absalom fled, and went to Talmai, the son of Ammihud, king

{
}

{
	\hJ{וְאַבְשָׁלוֹם בָּרַח וַיֵּלֶךְ גְּשׁוּר וַיְהִי־שָׁם שָׁלֹשׁ שָׁנִים׃}
}
{
	\eJ{So Absalom fled, and went to Geshur, and was there three years.}

}

\Verse{39}
