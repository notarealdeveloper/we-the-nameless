\Verse{1}

	\eJ{

	}
}
{
}

\Verse{2}
{
	\hJ{וְלוֹ שְׁתֵּי נָשִׁים שֵׁם אַחַת חַנָּה וְשֵׁם הַשֵּׁנִית פְּנִנָּה וַיְהִי לִפְנִנָּה יְלָדִים וּלְחַנָּה אֵין יְלָדִים׃}
}
{
	\eJ{
		And he had two wives: the name of the one was Hannah, and the
		name of the other Peninnah: and Peninnah had children, but
		Hannah had no children.
	}
}
{
}

\Verse{3}

	\hJ{וְעָלָה הָאִישׁ הַהוּא מֵעִירוֹ מִיָּמִים יָמִימָה לְהִשְׁתַּחֲוֺת וְלִזְבֹּחַ לַיהֹוָה צְבָאוֹת בְּשִׁלֹה וְשָׁם שְׁנֵי בְנֵי־עֵלִי חפְנִי וּפִנְחָס כֹּהֲנִים לַיהֹוָה׃}
}
{
	\eJ{
		And this man went up out of his city yearly to bow down and to
		sacrifice to YHWH of Armies in Shiloh. And the two sons of Eli,
		Hophni and Phinehas, the priests of YHWH, were there.
	}
}
{
}

\Verse{4}
{
	\hJ{וַיְהִי הַיּוֹם וַיִּזְבַּח אֶלְקָנָה וְנָתַן לִפְנִנָּה אִשְׁתּוֹ וּלְכל־בָּנֶיהָ וּבְנוֹתֶיהָ מָנוֹת׃}
}
{
	\eJ{
		And when the time was that Elkanah offered, he gave to Peninnah

	}
}
{
}

\Verse{5}
{
	\hJ{וּלְחַנָּה יִתֵּן מָנָה אַחַת אַפָּיִם כִּי אֶת־חַנָּה אָהֵב וַיהֹוָה סָגַר רַחְמָהּ׃}
}
{
	\eJ{
		And to Hannah he gave a worthy portion: for he loved Hannah: but

	}
}
{
}

\Verse{6}

	\hJ{וְכִעֲסַתָּה צָרָתָהּ גַּם־כַּעַס בַּעֲבוּר הַרְּעִמָהּ כִּי־סָגַר יְהֹוָה בְּעַד רַחְמָהּ׃}
}
{
	\eJ{
		And her adversary also provoked her bitterly, for to make her
		fret, because YHWH had closed her womb.
	}
}
{
}

\Verse{7}
{
	\hJ{וְכֵן יַעֲשֶׂה שָׁנָה בְשָׁנָה מִדֵּי עֲלֹתָהּ בְּבֵית יְהֹוָה כֵּן תַּכְעִסֶנָּה וַתִּבְכֶּה וְלֹא תֹאכַל׃}
}
{
	\eJ{
		And as he did so year by year, when she went up to the house of
		YHWH, so she provoked her: therefore she wept, and didn't eat.
	}
}
{
}

\Verse{8}
{
	\hJ{וַיֹּאמֶר לָהּ אֶלְקָנָה אִישָׁהּ חַנָּה לָמֶה תִבְכִּי וְלָמֶה לֹא תֹאכְלִי וְלָמֶה יֵרַע לְבָבֵךְ הֲלוֹא אָנֹכִי טוֹב לָךְ מֵעֲשָׂרָה בָּנִים׃}
}
{
	\eJ{
		And said Elkanah her husband to her, Hannah, why do you weep?
		and why don't you eat? and why is your heart grieved? am not I
		better to you than ten sons?
	}
}
{
}

\Verse{9}
{

}
{
	\eJ{
		And Hannah rose up after they had eaten in Shiloh, and after
		they had drunk. Now Eli the priest sat on a seat by a post of
		the palace of YHWH.
	}
}
{
}

\Verse{10}
{
	\hJ{וְהִיא מָרַת נָפֶשׁ וַתִּתְפַּלֵּל עַל־יְהֹוָה וּבָכֹה תִבְכֶּה׃}
}
{

	}
}
{
}

\Verse{11}
{
	\hJ{
		וַתִּדֹּר נֶדֶר וַתֹּאמַר יְהֹוָה צְבָאוֹת אִם־רָאֹה תִרְאֶה בּעֳנִי אֲמָתֶךָ וּזְכַרְתַּנִי וְלֹא־תִשְׁכַּח אֶת־אֲמָתֶךָ וְנָתַתָּה לַאֲמָתְךָ זֶרַע אֲנָשִׁים וּנְתַתִּיו לַיהֹוָה
		כּל־יְמֵי חַיָּיו וּמוֹרָה לֹא־יַעֲלֶה עַל־רֹאשׁוֹ׃
	}
}
{
	\eJ{

		indeed look on the affliction of your maidservant, and remember

		maidservant a man child, then I'll give him to YHWH all the days
		of his life, and there shall no razor come on his head.
	}
}
{
}

\Verse{12}

	\hJ{וְהָיָה כִּי הִרְבְּתָה לְהִתְפַּלֵּל לִפְנֵי יְהֹוָה וְעֵלִי שֹׁמֵר אֶת־פִּיהָ׃}

\Verse{13}

\Verse{15}

}
{
	\eJ{
		And Hannah answered and said, No, my lord, I'm a woman of a

\Verse{16}

{
}
