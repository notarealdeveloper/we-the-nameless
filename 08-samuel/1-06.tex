\Chapter{6}

\Verse{1}
{
	\hJ{וַיְהִי אֲרוֹן־יְהֹוָה בִּשְׂדֵה פְלִשְׁתִּים שִׁבְעָה חֳדָשִׁים׃}
}
{
	\eJ{
		And the ark of YHWH was in the country of the Philistines seven
		months.
	}
}
{
}

\Verse{2}
{
	\hJ{וַיִּקְרְאוּ פְלִשְׁתִּים לַכֹּהֲנִים וְלַקֹּסְמִים לֵאמֹר מַה־נַּעֲשֶׂה לַאֲרוֹן יְהֹוָה הוֹדִעֻנוּ בַּמֶּה נְשַׁלְּחֶנּוּ לִמְקוֹמוֹ׃}
}
{
	\eJ{
		And the Philistines called for the priests and the diviners,
		saying, What shall we do to the ark of YHWH? tell us wherewith
		we shall send it to his place.
	}
}
{
}

\Verse{3}
{
	\hJ{
		וַיֹּאמְרוּ אִם־מְשַׁלְּחִים אֶת־אֲרוֹן אֱלֹהֵי יִשְׂרָאֵל אַל־תְּשַׁלְּחוּ אֹתוֹ רֵיקָם כִּי־הָשֵׁב תָּשִׁיבוּ לוֹ אָשָׁם אָז תֵּרָפְאוּ וְנוֹדַע לָכֶם לָמָּה לֹא־תָסוּר יָדוֹ
		מִכֶּם׃
	}
}
{
	\eJ{
		And they said, If you send away the ark of the God of Israel,
		send it not empty: but surely return him a trespass offering:
		then you shall be healed, and it shall be known to you why his
		hand is not removed from you.
	}
}
{
}

\Verse{4}
{
	\hJ{
		וַיֹּאמְרוּ מָה הָאָשָׁם אֲשֶׁר נָשִׁיב לוֹ וַיֹּאמְרוּ מִסְפַּר סַרְנֵי פְלִשְׁתִּים חֲמִשָּׁה (עפלי) [טְחֹרֵי] זָהָב וַחֲמִשָּׁה עַכְבְּרֵי זָהָב כִּי־מַגֵּפָה אַחַת לְכֻלָּם
		וּלְסַרְנֵיכֶם׃
	}
}
{
	\eJ{
		And said they, What shall be the trespass offering which we
		shall return to him? They answered, Five golden tumors, and five
		golden mice, according to the number of the lords of the
		Philistines: for one plague was on you all, and on your lords.
	}
}
{
	Qere Ketiv.
}

\Verse{5}
{
	\hJ{
		וַעֲשִׂיתֶם צַלְמֵי (עפליכם) [טְחֹרֵיכֶם] וְצַלְמֵי עַכְבְּרֵיכֶם הַמַּשְׁחִיתִם אֶת־הָאָרֶץ וּנְתַתֶּם לֵאלֹהֵי יִשְׂרָאֵל כָּבוֹד אוּלַי יָקֵל אֶת־יָדוֹ מֵעֲלֵיכֶם וּמֵעַל
		אֱלֹהֵיכֶם וּמֵעַל אַרְצְכֶם׃
	}
}
{
	\eJ{
		And so you shall make images of your tumors, and images of your
		mice that mar the land: and you shall give glory to the God of
		Israel: perhaps he'll lighten his hand from you, and from your
		gods, and from your land.
	}
}
{
	Qere Ketiv.
}

\Verse{6}
{
	\hJ{וְלָמָּה תְכַבְּדוּ אֶת־לְבַבְכֶם כַּאֲשֶׁר כִּבְּדוּ מִצְרַיִם וּפַרְעֹה אֶת־לִבָּם הֲלוֹא כַּאֲשֶׁר הִתְעַלֵּל בָּהֶם וַיְשַׁלְּחוּם וַיֵּלֵכוּ׃}
}
{
	\eJ{
		And so then do you harden your hearts, as the Egyptians and
		Pharaoh hardened their hearts? when he had wrought wonderfully
		among them, did they not let the people go, and they went away?
	}
}
{
}

\Verse{7}
{
	\hJ{
		וְעַתָּה קְחוּ וַעֲשׂוּ עֲגָלָה חֲדָשָׁה אֶחָת וּשְׁתֵּי פָרוֹת עָלוֹת אֲשֶׁר לֹא־עָלָה עֲלֵיהֶם עֹל וַאֲסַרְתֶּם אֶת־הַפָּרוֹת בָּעֲגָלָה וַהֲשֵׁיבֹתֶם בְּנֵיהֶם מֵאַחֲרֵיהֶם
		הַבָּיְתָה׃
	}
}
{
	\eJ{
		And therefore make a new cart, and take two milch cows, on which
		there has come no yoke, and tie the cows to the cart, and bring
		their calves home from them:
	}
}
{
}

\Verse{8}
{
	\hJ{וּלְקַחְתֶּם אֶת־אֲרוֹן יְהֹוָה וּנְתַתֶּם אֹתוֹ אֶל־הָעֲגָלָה וְאֵת כְּלֵי הַזָּהָב אֲשֶׁר הֲשֵׁבֹתֶם לוֹ אָשָׁם תָּשִׂימוּ בָאַרְגַּז מִצִּדּוֹ וְשִׁלַּחְתֶּם אֹתוֹ וְהָלָךְ׃}
}
{
	\eJ{
		And take the ark of YHWH, and lay it on the cart: and put the
		gold objects, which you return him for a trespass offering, in a
		box by the side of it: and send it away, that it may go.
	}
}
{
}

\Verse{9}
{
	\hJ{
		וּרְאִיתֶם אִם־דֶּרֶךְ גְּבוּלוֹ יַעֲלֶה בֵּית שֶׁמֶשׁ הוּא עָשָׂה לָנוּ אֶת־הָרָעָה הַגְּדוֹלָה הַזֹּאת וְאִם־לֹא וְיָדַעְנוּ כִּי לֹא יָדוֹ נָגְעָה בָּנוּ מִקְרֶה הוּא הָיָה
		לָנוּ׃
	}
}
{
	\eJ{
		And see, if it goes up by the way of his own border to
		Beth-shemesh, then he has done us this great bad: but if not,
		then we shall know that it is not his hand that struck us: it
		was a chance that happened to us.
	}
}
{
}

\Verse{10}
{
	\hJ{וַיַּעֲשׂוּ הָאֲנָשִׁים כֵּן וַיִּקְחוּ שְׁתֵּי פָרוֹת עָלוֹת וַיַּאַסְרוּם בָּעֲגָלָה וְאֶת־בְּנֵיהֶם כָּלוּ בַבָּיִת׃}
}
{
	\eJ{
		And the men did so: and took two milch cows, and tied them to
		the cart, and closed their calves at home:
	}
}
{
}

\Verse{11}
{
	\hJ{וַיָּשִׂמוּ אֶת־אֲרוֹן יְהֹוָה אֶל־הָעֲגָלָה וְאֵת הָאַרְגַּז וְאֵת עַכְבְּרֵי הַזָּהָב וְאֵת צַלְמֵי טְחֹרֵיהֶם׃}
}
{
	\eJ{
		And they laid the ark of YHWH on the cart, and the box with the
		mice of gold and the images of their tumors.
	}
}
{
}

\Verse{12}
{
	\hJ{
		וַיִּשַּׁרְנָה הַפָּרוֹת בַּדֶּרֶךְ עַל־דֶּרֶךְ בֵּית שֶׁמֶשׁ בִּמְסִלָּה אַחַת הָלְכוּ הָלֹךְ וְגָעוֹ וְלֹא־סָרוּ יָמִין וּשְׂמֹאול וְסַרְנֵי פְלִשְׁתִּים הֹלְכִים אַחֲרֵיהֶם
		עַד־גְּבוּל בֵּית שָׁמֶשׁ׃
	}
}
{
	\eJ{
		And the cows took the straight way to the way of Beth-shemesh,
		and went along the highway, lowing as they went, and turned not
		aside to the right hand or to the left: and the lords of the
		Philistines went after them to the border of Beth-shemesh.
	}
}
{
}

\Verse{13}
{
	\hJ{וּבֵית שֶׁמֶשׁ קֹצְרִים קְצִיר־חִטִּים בָּעֵמֶק וַיִּשְׂאוּ אֶת־עֵינֵיהֶם וַיִּרְאוּ אֶת־הָאָרוֹן וַיִּשְׂמְחוּ לִרְאוֹת׃}
}
{
	\eJ{
		And they of Beth-shemesh were reaping their wheat harvest in the
		valley: and they lifted up their eyes, and saw the ark, and
		rejoiced to see it.
	}
}
{
}

\Verse{14}
{
	\hJ{וְהָעֲגָלָה בָּאָה אֶל־שְׂדֵה יְהוֹשֻׁעַ בֵּית־הַשִּׁמְשִׁי וַתַּעֲמֹד שָׁם וְשָׁם אֶבֶן גְּדוֹלָה וַיְבַקְּעוּ אֶת־עֲצֵי הָעֲגָלָה וְאֶת־הַפָּרוֹת הֶעֱלוּ עֹלָה לַיהֹוָה׃}
}
{
	\eJ{
		And the cart came into the field of Joshua, a Bethshemite, and
		stood there, where there was a great stone: and they clung the
		wood of the cart, and offered the cows a burnt offering to YHWH.
	}
}
{
}

\Verse{15}
{
	\hJ{
		וְהַלְוִיִּם הוֹרִידוּ אֶת־אֲרוֹן יְהֹוָה וְאֶת־הָאַרְגַּז אֲשֶׁר־אִתּוֹ אֲשֶׁר־בּוֹ כְלֵי־זָהָב וַיָּשִׂמוּ אֶל־הָאֶבֶן הַגְּדוֹלָה וְאַנְשֵׁי בֵית־שֶׁמֶשׁ הֶעֱלוּ עֹלוֹת
		וַיִּזְבְּחוּ זְבָחִים בַּיּוֹם הַהוּא לַיהֹוָה׃
	}
}
{
	\eJ{
		And the Levites took down the ark of YHWH, and the box that was
		with it, in which the gold objects were, and put them on the
		great stone: and the men of Beth-shemesh offered burnt offerings
		and sacrificed sacrifices the same day to YHWH.
	}
}
{
}

\Verse{16}
{
	\hJ{וַחֲמִשָּׁה סַרְנֵי־פְלִשְׁתִּים רָאוּ וַיָּשֻׁבוּ עֶקְרוֹן בַּיּוֹם הַהוּא׃}
}
{
	\eJ{
		And when the five lords of the Philistines had seen it, they
		returned to Ekron the same day.
	}
}
{
}

\Verse{17}
{
	\hJ{וְאֵלֶּה טְחֹרֵי הַזָּהָב אֲשֶׁר הֵשִׁיבוּ פְלִשְׁתִּים אָשָׁם לַיהֹוָהלְאַשְׁדּוֹד אֶחָדלְעַזָּה אֶחָדלְאַשְׁקְלוֹן אֶחָדלְגַת אֶחָדלְעֶקְרוֹן אֶחָד׃}
}
{
	\eJ{
		And these are the golden tumors which the Philistines returned
		for a trespass offering to YHWH: for Ashdod one, for Gaza one,
		for Askelon one, for Gath one, for Ekron one:
	}
}
{
}

\Verse{18}
{
	\hJ{
		וְעַכְבְּרֵי הַזָּהָב מִסְפַּר כּל־עָרֵי פְלִשְׁתִּים לַחֲמֵשֶׁת הַסְּרָנִים מֵעִיר מִבְצָר וְעַד כֹּפֶר הַפְּרָזִי וְעַד אָבֵל הַגְּדוֹלָה אֲשֶׁר הִנִּיחוּ עָלֶיהָ אֵת אֲרוֹן
		יְהֹוָה עַד הַיּוֹם הַזֶּה בִּשְׂדֵה יְהוֹשֻׁעַ בֵּית הַשִּׁמְשִׁי׃
	}
}
{
	\eJ{
		And the golden mice, according to the number of all the cities
		of the Philistines belonging to the five lords, both of fenced
		cities, and of country villages, even to the great stone of
		Abel, where they set down the ark of YHWH: which stone remains
		to this day in the field of Joshua, the Bethshemite.
	}
}
{
}

\Verse{19}
{
	\hJ{
		וַיַּךְ בְּאַנְשֵׁי בֵית־שֶׁמֶשׁ כִּי רָאוּ בַּאֲרוֹן יְהֹוָה וַיַּךְ בָּעָם שִׁבְעִים אִישׁ חֲמִשִּׁים אֶלֶף אִישׁ וַיִּתְאַבְּלוּ הָעָם כִּי־הִכָּה יְהֹוָה בָּעָם מַכָּה
		גְדוֹלָה׃
	}
}
{
	\eJ{

		into the ark of YHWH, even he struck of the people fifty

		had struck many of the people with a great slaughter.
	}
}
{
}

	}
}
