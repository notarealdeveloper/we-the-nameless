\Chapter{10}

\Verse{1}
{
	\hJ{וַיְהִי אַחֲרֵי־כֵן וַיָּמת מֶלֶךְ בְּנֵי עַמּוֹן וַיִּמְלֹךְ חָנוּן בְּנוֹ תַּחְתָּיו׃}
}
{
	\eJ{
		And it was after this, that the king of the children of Ammon
		died, and Hanun his son reigned in his stead.
	}
}
{
}

\Verse{2}
{
	\hJ{
		וַיֹּאמֶר דָּוִד אֶעֱשֶׂה־חֶסֶד עִם־חָנוּן בֶּן־נָחָשׁ כַּאֲשֶׁר עָשָׂה אָבִיו עִמָּדִי חֶסֶד וַיִּשְׁלַח דָּוִד לְנַחֲמוֹ בְּיַד־עֲבָדָיו אֶל־אָבִיו וַיָּבֹאוּ עַבְדֵי דָוִד אֶרֶץ
		בְּנֵי עַמּוֹן׃
	}
}
{
	\eJ{
		And David said, I'll show kindness to Hanun the son of Nahash,
		as his father showed kindness to me. And David sent to comfort
		him by the hand of his servants for his father. And David’s
		servants came into the land of the children of Ammon.
	}
}
{
}

\Verse{3}
{
	\hJ{
		וַיֹּאמְרוּ שָׂרֵי בְנֵי־עַמּוֹן אֶל־חָנוּן אֲדֹנֵיהֶם הַמְכַבֵּד דָּוִד אֶת־אָבִיךָ בְּעֵינֶיךָ כִּי־שָׁלַח לְךָ מְנַחֲמִים הֲלוֹא בַּעֲבוּר חֲקֹר אֶת־הָעִיר וּלְרַגְּלָהּ
		וּלְהפְכָהּ שָׁלַח דָּוִד אֶת־עֲבָדָיו אֵלֶיךָ׃
	}
}
{
	\eJ{
		And the chieftains of the children of Ammon said to Hanun their
		lord, Do you think that David is honoring your father, that he
		has sent comforters to you? has not David rather sent his
		servants to you, to search the city, and to spy it out, and to
		overthrow it?
	}
}
{
}

\Verse{4}
{
	\hJ{וַיִּקַּח חָנוּן אֶת־עַבְדֵי דָוִד וַיְגַלַּח אֶת־חֲצִי זְקָנָם וַיִּכְרֹת אֶת־מַדְוֵיהֶם בַּחֵצִי עַד שְׁתוֹתֵיהֶם וַיְשַׁלְּחֵם׃}
}
{
	\eJ{
		Why Hanun took David’s servants, and shaved off the one half of
		their beards, and cut off their garments in the middle, even to
		their buttocks, and sent them away.
	}
}
{
}

\Verse{5}
{
	\hJ{וַיַּגִּדוּ לְדָוִד וַיִּשְׁלַח לִקְרָאתָם כִּי־הָיוּ הָאֲנָשִׁים נִכְלָמִים מְאֹד וַיֹּאמֶר הַמֶּלֶךְ שְׁבוּ בִירֵחוֹ עַד־יְצַמַּח זְקַנְכֶם וְשַׁבְתֶּם׃}
}
{
	\eJ{
		When they told it to David, he sent to meet them, because the
		men were greatly ashamed: and the king said, Stay at Jericho
		until your beards be grown, and then return.
	}
}
{
}

\Verse{6}
{
	\hJ{
		וַיִּרְאוּ בְּנֵי עַמּוֹן כִּי נִבְאֲשׁוּ בְּדָוִד וַיִּשְׁלְחוּ בְנֵי־עַמּוֹן וַיִּשְׂכְּרוּ אֶת־אֲרַם בֵּית־רְחוֹב וְאֶת־אֲרַם צוֹבָא עֶשְׂרִים אֶלֶף רַגְלִי וְאֶת־מֶלֶךְ מַעֲכָה
		אֶלֶף אִישׁ וְאִישׁ טוֹב שְׁנֵים־עָשָׂר אֶלֶף אִישׁ׃
	}
}
{
	\eJ{
		And when the children of Ammon saw that they stank before David,
		the children of Ammon sent and hired the Syrians of Bethrehob
		and the Syrians of Zoba, twenty thousand footmen, and of king
		Maacah a thousand men, and of Ishtob twelve thousand men.
	}
}
{
}

\Verse{7}
{
	\hJ{וַיִּשְׁמַע דָּוִד וַיִּשְׁלַח אֶת־יוֹאָב וְאֵת כּל־הַצָּבָא הַגִּבֹּרִים׃}
}
{
	\eJ{
		And when David heard of it, he sent Joab, and all the army of
		the heroes.
	}
}
{
}

\Verse{8}
{
	\hJ{וַיֵּצְאוּ בְּנֵי עַמּוֹן וַיַּעַרְכוּ מִלְחָמָה פֶּתַח הַשָּׁעַר וַאֲרַם צוֹבָא וּרְחוֹב וְאִישׁ־טוֹב וּמַעֲכָה לְבַדָּם בַּשָּׂדֶה׃}
}
{
	\eJ{
		And the children of Ammon came out, and put the battle in array
		at the entering in of the gate: and the Syrians of Zoba, and of
		Rehob, and Ishtob, and Maacah, were by themselves in the field.
	}
}
{
}

\Verse{9}
{
	\hJ{וַיַּרְא יוֹאָב כִּי־הָיְתָה אֵלָיו פְּנֵי הַמִּלְחָמָה מִפָּנִים וּמֵאָחוֹר וַיִּבְחַר מִכֹּל בְּחוּרֵי (בישראל) [יִשְׂרָאֵל] וַיַּעֲרֹךְ לִקְרַאת אֲרָם׃}
}
{
	\eJ{
		When Joab saw that the front of the battle was against him
		before and behind, he chose of all the choice men of Israel, and
		arrange them against the Syrians:
	}
}
{
	Qere Ketiv.
}

\Verse{10}
{
	\hJ{וְאֵת יֶתֶר הָעָם נָתַן בְּיַד אַבְשַׁי אָחִיו וַיַּעֲרֹךְ לִקְרַאת בְּנֵי עַמּוֹן׃}
}
{
	\eJ{
		And the rest of the people he delivered into the hand of Abishai
		his brother, that he might arrange them against the children of
		Ammon.
	}
}
{
}

\Verse{11}
{
	\hJ{וַיֹּאמֶר אִם־תֶּחֱזַק אֲרָם מִמֶּנִּי וְהָיִתָה לִּי לִישׁוּעָה וְאִם־בְּנֵי עַמּוֹן יֶחֶזְקוּ מִמְּךָ וְהָלַכְתִּי לְהוֹשִׁיעַ לָךְ׃}
}
{
	\eJ{
		And he said, If the Syrians be too strong for me, then you shall
		help me: but if the children of Ammon be too strong for you,
		then I'll come and help you.
	}
}
{
}

\Verse{12}
{
	\hJ{חֲזַק וְנִתְחַזַּק בְּעַד־עַמֵּנוּ וּבְעַד עָרֵי אֱלֹהֵינוּ וַיהֹוָה יַעֲשֶׂה הַטּוֹב בְּעֵינָיו׃}
}
{
	\eJ{
		Be of good courage, and let us play the men for our people, and
		for the cities of our God: and YHWH do that that seems him good.
	}
}
{
}

\Verse{13}
{
	\hJ{וַיִּגַּשׁ יוֹאָב וְהָעָם אֲשֶׁר עִמּוֹ לַמִּלְחָמָה בַּאֲרָם וַיָּנֻסוּ מִפָּנָיו׃}
}
{
	\eJ{
		And Joab drew near, and the people that were with him, to the
		battle against the Syrians: and they fled before him.
	}
}
{
}

\Verse{14}
{
	\hJ{וּבְנֵי עַמּוֹן רָאוּ כִּי־נָס אֲרָם וַיָּנֻסוּ מִפְּנֵי אֲבִישַׁי וַיָּבֹאוּ הָעִיר וַיָּשׁב יוֹאָב מֵעַל בְּנֵי עַמּוֹן וַיָּבֹא יְרוּשָׁלָ͏ִם׃}
}
{
	\eJ{
		And when the children of Ammon saw that the Syrians were fled,
		then fled they also before Abishai, and entered into the city.
		So Joab returned from the children of Ammon, and came to
		Jerusalem.
	}
}
{
}

\Verse{15}
{
	\hJ{וַיַּרְא אֲרָם כִּי נִגַּף לִפְנֵי יִשְׂרָאֵל וַיֵּאָסְפוּ יָחַד׃}
}
{
	\eJ{
		And when the Syrians saw that they were struck before Israel,

	}
}
{
}

\Verse{16}

}
{
	\eJ{
		And Hadarezer sent, and brought out the Syrians that were beyond
		the river: and they came to Helam; and Shobach the commander of
		the army of Hadarezer went before them.
	}
}
{
}

\Verse{17}
{
	\hJ{וַיֻּגַּד לְדָוִד וַיֶּאֱסֹף אֶת־כּל־יִשְׂרָאֵל וַיַּעֲבֹר אֶת־הַיַּרְדֵּן וַיָּבֹא חֵלָאמָה וַיַּעַרְכוּ אֲרָם לִקְרַאת דָּוִד וַיִּלָּחֲמוּ עִמּוֹ׃}
}
{
	\eJ{
		And when it was told David, he gathered all Israel together, and
		passed over Jordan, and came to Helam. And the Syrians set
		themselves in array against David, and fought with him.
	}
}
{
}

\Verse{18}
{
	\hJ{וַיָּנס אֲרָם מִפְּנֵי יִשְׂרָאֵל וַיַּהֲרֹג דָּוִד מֵאֲרָם שְׁבַע מֵאוֹת רֶכֶב וְאַרְבָּעִים אֶלֶף פָּרָשִׁים וְאֵת שׁוֹבַךְ שַׂר־צְבָאוֹ הִכָּה וַיָּמת שָׁם׃}
}
{
	\eJ{
		And the Syrians fled before Israel; and David killed the men of
		seven hundred chariots of the Syrians, and forty thousand
		horsemen, and struck Shobach the commander of their army, who
		died there.
	}
}
{
}

\Verse{19}
{
	\hJ{וַיִּרְאוּ כל־הַמְּלָכִים עַבְדֵי הֲדַדְעֶזֶר כִּי נִגְּפוּ לִפְנֵי יִשְׂרָאֵל וַיַּשְׁלִמוּ אֶת־יִשְׂרָאֵל וַיַּעַבְדוּם וַיִּרְאוּ אֲרָם לְהוֹשִׁיעַ עוֹד אֶת־בְּנֵי עַמּוֹן׃}
}
{
	\eJ{
		And when all the kings that were servants to Hadarezer saw that
		they were struck before Israel, they made peace with Israel, and
		served them. So the Syrians feared to help the children of Ammon
		any more.
	}
}
