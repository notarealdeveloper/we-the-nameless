\Chapter{3}

\Verse{1}
{
	\hJ{וְהַנַּעַר שְׁמוּאֵל מְשָׁרֵת אֶת־יְהֹוָה לִפְנֵי עֵלִי וּדְבַר־יְהֹוָה הָיָה יָקָר בַּיָּמִים הָהֵם אֵין חָזוֹן נִפְרָץ׃}
}
{
	\eJ{
		And the child Samuel ministered to YHWH before Eli. And the word
		of YHWH was precious in those days: there was no open vision.
	}
}
{
}

\Verse{2}
{
	\hJ{וַיְהִי בַּיּוֹם הַהוּא וְעֵלִי שֹׁכֵב בִּמְקוֹמוֹ וְעֵינָו הֵחֵלּוּ כֵהוֹת לֹא יוּכַל לִרְאוֹת׃}
}
{
	\eJ{
		And it came to pass at that time, when Eli was laid down in his
		place, and his eyes began to wax dim, that he could not see:
	}
}
{
}

\Verse{3}
{
	\hJ{וְנֵר אֱלֹהִים טֶרֶם יִכְבֶּה וּשְׁמוּאֵל שֹׁכֵב בְּהֵיכַל יְהֹוָה אֲשֶׁר־שָׁם אֲרוֹן אֱלֹהִים׃}
}
{
	\eJ{
		And before the lamp of God went out in the palace of YHWH, where
		the ark of God was, and Samuel was laid down to sleep:
	}
}
{
}

\Verse{4}
{
	\hJ{וַיִּקְרָא יְהֹוָה אֶל־שְׁמוּאֵל וַיֹּאמֶר הִנֵּנִי׃}
}
{
	\eJ{That YHWH called Samuel: and he answered, Here am I.}
}
{
}

\Verse{5}
{
	\hJ{וַיָּרץ אֶל־עֵלִי וַיֹּאמֶר הִנְנִי כִּי־קָרָאתָ לִּי וַיֹּאמֶר לֹא־קָרָאתִי שׁוּב שְׁכָב וַיֵּלֶךְ וַיִּשְׁכָּב׃}
}
{
	\eJ{
		And he ran to Eli, and said, Here am I: for you calledst me. And
		he said, I called not: lie down again. And he went and lay down.
	}
}
{
}

\Verse{6}
{
	\hJ{וַיֹּסֶף יְהֹוָה קְרֹא עוֹד שְׁמוּאֵל וַיָּקם שְׁמוּאֵל וַיֵּלֶךְ אֶל־עֵלִי וַיֹּאמֶר הִנְנִי כִּי קָרָאתָ לִי וַיֹּאמֶר לֹא־קָרָאתִי בְנִי שׁוּב שְׁכָב׃}
}
{
	\eJ{
		And YHWH called yet again, Samuel. And Samuel arose and went to
		Eli, and said, Here am I: for you called me. And he answered, I
		called not, my son: lie down again.
	}
}
{
}

\Verse{7}
{
	\hJ{וּשְׁמוּאֵל טֶרֶם יָדַע אֶת־יְהֹוָה וְטֶרֶם יִגָּלֶה אֵלָיו דְּבַר־יְהֹוָה׃}
}
{
	\eJ{
		And Samuel didn't yet know YHWH, neither was the word of YHWH
		yet revealed to him.
	}
}
{
}

\Verse{8}
{
	\hJ{וַיֹּסֶף יְהֹוָה קְרֹא־שְׁמוּאֵל בַּשְּׁלִישִׁת וַיָּקם וַיֵּלֶךְ אֶל־עֵלִי וַיֹּאמֶר הִנְנִי כִּי קָרָאתָ לִי וַיָּבֶן עֵלִי כִּי יְהֹוָה קֹרֵא לַנָּעַר׃}
}
{
	\eJ{
		And YHWH called Samuel again the third time. And he arose and
		went to Eli, and said, Here am I: for you called me. And Eli saw
		that YHWH had called the child.
	}
}
{
}

\Verse{9}
{
	\hJ{וַיֹּאמֶר עֵלִי לִשְׁמוּאֵל לֵךְ שְׁכָב וְהָיָה אִם־יִקְרָא אֵלֶיךָ וְאָמַרְתָּ דַּבֵּר יְהֹוָה כִּי שֹׁמֵעַ עַבְדֶּךָ וַיֵּלֶךְ שְׁמוּאֵל וַיִּשְׁכַּב בִּמְקוֹמוֹ׃}
}
{
	\eJ{
		And so Eli said to Samuel, Go, lie down: and it shall be, if he
		call you, that you shall say, Speak, YHWH: for your servant
		hears. So Samuel went and lay down in his place.
	}
}
{
}

\Verse{10}
{
	\hJ{וַיָּבֹא יְהֹוָה וַיִּתְיַצַּב וַיִּקְרָא כְפַעַם־בְּפַעַם שְׁמוּאֵל שְׁמוּאֵל וַיֹּאמֶר שְׁמוּאֵל דַּבֵּר כִּי שֹׁמֵעַ עַבְדֶּךָ׃}
}
{
	\eJ{
		And YHWH came, and stood, and called as at other times, Samuel,
		Samuel. Then Samuel answered, Speak: for your servant hears.
	}
}
{
%	\footnote{
%		Footnote 3:10. Samuel, Samuel. The doubled name is intimate and dangerous:
%		Abraham, Abraham; Jacob, Jacob; Moses, Moses. When God says a name twice, history
%		is about to move furniture.
%	}
}

\Verse{11}
{
	\hJ{וַיֹּאמֶר יְהֹוָה אֶל־שְׁמוּאֵל הִנֵּה אָנֹכִי עֹשֶׂה דָבָר בְּיִשְׂרָאֵל אֲשֶׁר כּל־שֹׁמְעוֹ תְּצִלֶּינָה שְׁתֵּי אזְנָיו׃}
}
{
	\eJ{
		And YHWH said to Samuel, Here: I'll do a thing in Israel, at
		which both the ears of every one that hears it shall tingle.
	}
}
{
}

\Verse{12}
{
	\hJ{בַּיּוֹם הַהוּא אָקִים אֶל־עֵלִי אֵת כּל־אֲשֶׁר דִּבַּרְתִּי אֶל־בֵּיתוֹ הָחֵל וְכַלֵּה׃}
}
{
	\eJ{
		In that day I'll perform against Eli all things which I've
		spoken concerning his house: when I begin, I'll also make an
		end.
	}
}
{
}

\Verse{13}
{
	\hJ{וְהִגַּדְתִּי לוֹ כִּי־שֹׁפֵט אֲנִי אֶת־בֵּיתוֹ עַד־עוֹלָם בַּעֲוֺן אֲשֶׁר־יָדַע כִּי־מְקַלְלִים לָהֶם בָּנָיו וְלֹא כִהָה בָּם׃}
}
{
	\eJ{
		For I've told him that I'll judge his house forever for the
		guilt which he knows: because his sons made themselves vile, and
		he restrained them not.
	}
}
{
}

\Verse{14}
{
	\hJ{וְלָכֵן נִשְׁבַּעְתִּי לְבֵית עֵלִי אִם־יִתְכַּפֵּר עֲוֺן בֵּית־עֵלִי בְּזֶבַח וּבְמִנְחָה עַד־עוֹלָם׃}
}
{
	\eJ{
		And therefore I've sworn to the house of Eli, that the guilt of
		Eli’s house shall not be purged with sacrifice nor offering
		forever.
	}
}
{
}

\Verse{15}
{
	\hJ{וַיִּשְׁכַּב שְׁמוּאֵל עַד־הַבֹּקֶר וַיִּפְתַּח אֶת־דַּלְתוֹת בֵּית־יְהֹוָה וּשְׁמוּאֵל יָרֵא מֵהַגִּיד אֶת־הַמַּרְאָה אֶל־עֵלִי׃}
}
{
	\eJ{
		And Samuel lay until the morning, and opened the doors of the
		house of YHWH. And Samuel feared to show Eli the vision.
	}
}
{
}

\Verse{16}
{
	\hJ{וַיִּקְרָא עֵלִי אֶת־שְׁמוּאֵל וַיֹּאמֶר שְׁמוּאֵל בְּנִי וַיֹּאמֶר הִנֵּנִי׃}
}
{
	\eJ{
		And Eli called Samuel, and said, Samuel, my son. And he
		answered, Here am I.
	}
}
{
}

\Verse{17}
{
	\hJ{
		וַיֹּאמֶר מָה הַדָּבָר אֲשֶׁר דִּבֶּר אֵלֶיךָ אַל־נָא תְכַחֵד מִמֶּנִּי כֹּה יַעֲשֶׂה־לְּךָ אֱלֹהִים וְכֹה יוֹסִיף אִם־תְּכַחֵד מִמֶּנִּי דָּבָר מִכּל־הַדָּבָר אֲשֶׁר־דִּבֶּר
		אֵלֶיךָ׃
	}
}
{
	\eJ{
		And he said, What is the thing that YHWH has said to you? please
		hide it not from me: God do so to you, and more also, if you
		hide anything from me of all the things that he said to you.
	}
}
{
}

\Verse{18}
{
	\hJ{וַיַּגֶּד־לוֹ שְׁמוּאֵל אֶת־כּל־הַדְּבָרִים וְלֹא כִחֵד מִמֶּנּוּ וַיֹּאמַר יְהֹוָה הוּא הַטּוֹב בְּעֵינָו יַעֲשֶׂה׃}
}
{
	\eJ{
		And Samuel told him everything, and hid nothing from him. And he
		said, It is YHWH: let him do what seems him good.
	}
}
{
}

\Verse{19}
{
	\hJ{וַיִּגְדַּל שְׁמוּאֵל וַיהֹוָה הָיָה עִמּוֹ וְלֹא־הִפִּיל מִכּל־דְּבָרָיו אָרְצָה׃}
}
{
	\eJ{
		And Samuel grew, and YHWH was with him, and did let none of his
		words fall to the ground.
	}
}
{
}

\Verse{20}
{
	\hJ{וַיֵּדַע כּל־יִשְׂרָאֵל מִדָּן וְעַד־בְּאֵר שָׁבַע כִּי נֶאֱמָן שְׁמוּאֵל לְנָבִיא לַיהֹוָה׃}
}
{
	\eJ{
		And all Israel from Dan even to Beersheba knew that Samuel was
		established to be a prophet of YHWH.
	}
}
{
}

\Verse{21}
{
	\hJ{וַיֹּסֶף יְהֹוָה לְהֵרָאֹה בְשִׁלֹה כִּי־נִגְלָה יְהֹוָה אֶל־שְׁמוּאֵל בְּשִׁלוֹ בִּדְבַר יְהֹוָה׃}
}
