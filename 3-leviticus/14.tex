{
}

\Verse{3}
{
	\hOther{וְיָצָא הַכֹּהֵן אֶל מִחוּץ לַמַּחֲנֶה וְרָאָה הַכֹּהֵן וְהִנֵּה נִרְפָּא נֶגַע הַצָּרַעַת מִן הַצָּרוּעַ׃}
}
{
	\eOther{
		and the priest shall go outside the camp, and the priest
		shall see, and if, here, the affliction of leprosy has
		been healed from the leper,
	}
}
{
%	\footnote{
%		the priest shall see. Again, the priest is not a physician. The priest
%		has identified the condition (in the preceding chapter) and now sees
%		that the condition is healed. So what follows is not a ritual of
%		healing. The person is already healed. It is a ritual of purification.
%	}
}

\Verse{4}
{
	\hOther{וְצִוָּה הַכֹּהֵן וְלָקַח לַמִּטַּהֵר שְׁתֵּי צִפֳּרִים חַיּוֹת טְהֹרוֹת וְעֵץ אֶרֶז וּשְׁנִי תוֹלַעַת וְאֵזֹב׃}
}
{
	\eOther{
		then the priest shall command, and one shall take two
		live, pure birds and cedarwood and scarlet and hyssop for
		the one being purified.
	}
}
{
}

\Verse{5}
{
	\hOther{וְצִוָּה הַכֹּהֵן וְשָׁחַט אֶת הַצִּפּוֹר הָאֶחָת אֶל כְּלִי חֶרֶשׂ עַל מַיִם חַיִּים׃}
}
{
	\eOther{
		And the priest shall command, and he shall slaughter one
		of the birds in a clay container over living water.
	}
}
{
%	\footnote{
%		living water. On the meaning of (mayim ayyîm): this seems to be
%		indicated by Gen 26:19 and Song of Songs 4:15 to be freshwater flowing
%		from a well or other natural source, as opposed to stagnant or stored
%		water. I have heard it compared to a mikveh by Rabbi Martin Lawson. That
%		is especially interesting in the light of Jer 17:13, where God is
%		referred to first as “Israel’s hope” (—miqwh yir’l) and then in the same
%		verse as “source of living water” (—mqôr mayim ayyîm).
%	}
}

\Verse{6}
{
	\hOther{אֶת הַצִּפֹּר הַחַיָּה יִקַּח אֹתָהּ וְאֶת עֵץ הָאֶרֶז וְאֶת שְׁנִי הַתּוֹלַעַת וְאֶת הָאֵזֹב וְטָבַל אוֹתָם וְאֵת הַצִּפֹּר הַחַיָּה בְּדַם הַצִּפֹּר הַשְּׁחֻטָה עַל הַמַּיִם הַחַיִּים׃}
}
{
	\eOther{
		The live bird: he shall take it and the cedarwood and the
		scarlet and the hyssop, and he shall dip them and the live
		bird in the slaughtered bird’s blood over the living
		water.
	}
}
{
}

\Verse{7}
{
	\hOther{וְהִזָּה עַל הַמִּטַּהֵר מִן הַצָּרַעַת שֶׁבַע פְּעָמִים וְטִהֲרוֹ וְשִׁלַּח אֶת הַצִּפֹּר הַחַיָּה עַל פְּנֵי הַשָּׂדֶה׃}
}
{
	\eOther{
		And he shall sprinkle it on the one being purified from
		the leprosy seven times. And he shall identify him as
		pure. And he shall let the live bird go at the open field.
	}
}
{
}

\Verse{8}
{
	\hOther{וְכִבֶּס הַמִּטַּהֵר אֶת בְּגָדָיו וְגִלַּח אֶת כּל שְׂעָרוֹ וְרָחַץ בַּמַּיִם וְטָהֵר וְאַחַר יָבוֹא אֶל הַמַּחֲנֶה וְיָשַׁב מִחוּץ לְאהֳלוֹ שִׁבְעַת יָמִים׃}
}
{
	\eOther{
		And the one being purified shall wash his clothes and
		shave all his hair and wash in water, and he will be pure,
		and after that he shall come to the camp. And he shall
		live outside his tent seven days.
	}
}
{
}

\Verse{9}
{
	\hOther{וְהָיָה בַיּוֹם הַשְּׁבִיעִי יְגַלַּח אֶת כּל שְׂעָרוֹ אֶת רֹאשׁוֹ וְאֶת זְקָנוֹ וְאֵת גַּבֹּת עֵינָיו וְאֶת כּל שְׂעָרוֹ יְגַלֵּחַ וְכִבֶּס אֶת בְּגָדָיו וְרָחַץ אֶת בְּשָׂרוֹ בַּמַּיִם וְטָהֵר׃}
}
{
	\eOther{
		And it will be, on the seventh day: he shall shave all his
		hair—he shall shave his head and his beard and his
		eyebrows and all his hair—and he shall wash his clothes
		and wash his flesh in water, and he will be pure.
	}
}
{
}

\Verse{10}
{
	\hOther{וּבַיּוֹם הַשְּׁמִינִי יִקַּח שְׁנֵי כְבָשִׂים תְּמִימִם וְכַבְשָׂה אַחַת בַּת שְׁנָתָהּ תְּמִימָה וּשְׁלֹשָׁה עֶשְׂרֹנִים סֹלֶת מִנְחָה בְּלוּלָה בַשֶּׁמֶן וְלֹג אֶחָד שָׁמֶן׃}
}
{
	\eOther{
		And on the eighth day he shall take two unblemished
		he-lambs and one unblemished ewe-lamb in its first year
		and three-tenths of a measure of fine flour as a grain
		offering mixed with oil and one log of oil.
	}
}
{
%	\footnote{
%		log. A liquid measure (thought to be about one-half liter).
%	}
}

\Verse{11}
{
	\hOther{וְהֶעֱמִיד הַכֹּהֵן הַמְטַהֵר אֵת הָאִישׁ הַמִּטַּהֵר וְאֹתָם לִפְנֵי יְהֹוָה פֶּתַח אֹהֶל מוֹעֵד׃}
}
{
	\eOther{

\Verse{12}
{
	\hOther{וְלָקַח הַכֹּהֵן אֶת הַכֶּבֶשׂ הָאֶחָד וְהִקְרִיב אֹתוֹ לְאָשָׁם וְאֶת לֹג הַשָּׁמֶן וְהֵנִיף אֹתָם תְּנוּפָה לִפְנֵי יְהֹוָה׃}

}

\Verse{13}
{
	\hOther{וְשָׁחַט אֶת הַכֶּבֶשׂ בִּמְקוֹם אֲשֶׁר יִשְׁחַט אֶת הַחַטָּאת וְאֶת הָעֹלָה בִּמְקוֹם הַקֹּדֶשׁ כִּי כַּחַטָּאת הָאָשָׁם הוּא לַכֹּהֵן קֹדֶשׁ קדָשִׁים הוּא׃}
}
{
	\eOther{
		And he shall slaughter the lamb in the place where he
		slaughters the sin offering and the burnt offering, in the
		place of the Holy, because, like the sin offering, the
		guilt offering is the priest’s. It is the holy of holies.
	}
}
{
}

\Verse{14}
{
	\hOther{וְלָקַח הַכֹּהֵן מִדַּם הָאָשָׁם וְנָתַן הַכֹּהֵן עַל תְּנוּךְ אֹזֶן הַמִּטַּהֵר הַיְמָנִית וְעַל בֹּהֶן יָדוֹ הַיְמָנִית וְעַל בֹּהֶן רַגְלוֹ הַיְמָנִית׃}
}
{
	\eOther{
		And the priest shall take some of the blood of the guilt
		offering, and the priest shall put it on the right earlobe
		of the one being purified and on the thumb of his right
		hand and on the big toe of his right foot.
	}
}
{
%	\footnote{
%		blood on the right earlobe, thumb, and big toe. This is the same as the
%		ceremony for ordaining Aaron and his sons as priests (Lev 8:23–24). In
%		both cases, there is a transition. Here it is from impure to pure. In
%		the priestly case it is from secular to holy. Both apparently call for
%		placing blood on the body’s three extremities (ear, thumb, toe) to
%		convey that the entire body is thus covered by this purification.
%	}
}

%		Parashat Meora that it is about bringing people who are infirm back into
