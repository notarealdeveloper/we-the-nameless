\Chapter{22}

\Verse{1}
{
	\hP{וַיְדַבֵּר יְהֹוָה אֶל מֹשֶׁה לֵּאמֹר׃}
}
{
	\eP{22 And YHWH spoke to Moses, saying,}
}
{
}

\Verse{2}
{
	\hP{דַּבֵּר אֶל אַהֲרֹן וְאֶל בָּנָיו וְיִנָּזְרוּ מִקּדְשֵׁי בְנֵי יִשְׂרָאֵל וְלֹא יְחַלְּלוּ אֶת שֵׁם קדְשִׁי אֲשֶׁר הֵם מַקְדִּשִׁים לִי אֲנִי יְהֹוָה׃}
}
{
	\eP{
		“Speak to Aaron and to his sons that they be alerted
		regarding the holy things of the children of Israel that
		they consecrate to me, so they will not desecrate my holy
		name. I am YHWH.
	}
}
{
}

\Verse{3}
{
	\hP{אֱמֹר אֲלֵהֶם לְדֹרֹתֵיכֶם כּל אִישׁ אֲשֶׁר יִקְרַב מִכּל זַרְעֲכֶם אֶל הַקֳּדָשִׁים אֲשֶׁר יַקְדִּישׁוּ בְנֵי יִשְׂרָאֵל לַיהֹוָה וְטֻמְאָתוֹ עָלָיו וְנִכְרְתָה הַנֶּפֶשׁ הַהִוא מִלְּפָנַי אֲנִי יְהֹוָה׃}
}
{
	\eP{
		Say to them: Through your generations, any man who will
		come close, from all of your seed, to the holy things that
		the children of Israel will consecrate to YHWH, while his
		impurity is on him: that person will be cut off from in
		front of me. I am YHWH.
	}
}
{
}

\Verse{4}
{
	\hP{אִישׁ אִישׁ מִזֶּרַע אַהֲרֹן וְהוּא צָרוּעַ אוֹ זָב בַּקֳּדָשִׁים לֹא יֹאכַל עַד אֲשֶׁר יִטְהָר וְהַנֹּגֵעַ בְּכל טְמֵא נֶפֶשׁ אוֹ אִישׁ אֲשֶׁר תֵּצֵא מִמֶּנּוּ שִׁכְבַת זָרַע׃}
}
{
	\eP{
		“Any man from Aaron’s seed and who is a leper or has an
		emission shall not eat any of the holy things until he
		becomes pure. And one who touches anything that is impure
		by a person, or a man from whom intercourse seed will come
		out,
	}
}
{
%	\footnote{
%		impure by a person. Meaning: something that has become impure because of
%		contact with the dead body of a person.
%	}
}

\Verse{5}
{
	\hP{אוֹ אִישׁ אֲשֶׁר יִגַּע בְּכל שֶׁרֶץ אֲשֶׁר יִטְמָא לוֹ אוֹ בְאָדָם אֲשֶׁר יִטְמָא לוֹ לְכֹל טֻמְאָתוֹ׃}
}
{
	\eP{
		or a man who will touch any swarming creature by which he
		will become impure or a human by whom he will become
		impure, whatever his impurity:
	}
}
{
}

\Verse{6}
{
	\hP{נֶפֶשׁ אֲשֶׁר תִּגַּע בּוֹ וְטָמְאָה עַד הָעָרֶב וְלֹא יֹאכַל מִן הַקֳּדָשִׁים כִּי אִם רָחַץ בְּשָׂרוֹ בַּמָּיִם׃}
}
{
	\eP{
		a person who will touch him will be impure until evening;
		and he shall not eat from the holy things unless he has
		washed his flesh in water.
	}
}
{
}

\Verse{7}
{
	\hP{וּבָא הַשֶּׁמֶשׁ וְטָהֵר וְאַחַר יֹאכַל מִן הַקֳּדָשִׁים כִּי לַחְמוֹ הוּא׃}
}
{
	\eP{
		And when the sun has set, he shall be pure, and after that
		he shall eat from the holy things, because it is his food.
	}
}
{
}

\Verse{8}
{
	\hP{נְבֵלָה וּטְרֵפָה לֹא יֹאכַל לְטמְאָה בָהּ אֲנִי יְהֹוָה׃}
}
{
	\eP{
		He shall not eat a carcass or a torn animal, to become
		impure by it. I am YHWH.
	}
}
{
}

\Verse{9}
{
	\hP{וְשָׁמְרוּ אֶת מִשְׁמַרְתִּי וְלֹא יִשְׂאוּ עָלָיו חֵטְא וּמֵתוּ בוֹ כִּי יְחַלְּלֻהוּ אֲנִי יְהֹוָה מְקַדְּשָׁם׃}
}
{
	\eP{
		“And they shall keep my charge so they will not bear sin
		over it and die through it when they desecrate it. I,
		YHWH, make them holy.
	}
}
{
}

\Verse{10}
{
	\hP{וְכל זָר לֹא יֹאכַל קֹדֶשׁ תּוֹשַׁב כֹּהֵן וְשָׂכִיר לֹא יֹאכַל קֹדֶשׁ׃}
}
{
	\eP{
		“And any outsider shall not eat what is holy: a priest’s
		visitor and an employee shall not eat what is holy.
	}
}
{
%	\footnote{
%		outsider. See comment on Exod 29:33.
%	}
}

\Verse{11}
{
	\hP{וְכֹהֵן כִּי יִקְנֶה נֶפֶשׁ קִנְיַן כַּסְפּוֹ הוּא יֹאכַל בּוֹ וִילִיד בֵּיתוֹ הֵם יֹאכְלוּ בְלַחְמוֹ׃}
}
{
	\eP{
		But when a priest buys a person as a possession by his
		money, he may eat it; and one who is born in his
		household: they may eat his bread.
	}
}
{
}

\Verse{12}
{
	\hP{וּבַת כֹּהֵן כִּי תִהְיֶה לְאִישׁ זָר הִוא בִּתְרוּמַת הַקֳּדָשִׁים לֹא תֹאכֵל׃}
}
{
	\eP{
		And a priest’s daughter who will become an outsider’s: she
		shall not eat the donated holy things;
	}
}
{
}

\Verse{13}
{
	\hP{וּבַת כֹּהֵן כִּי תִהְיֶה אַלְמָנָה וּגְרוּשָׁה וְזֶרַע אֵין לָהּ וְשָׁבָה אֶל בֵּית אָבִיהָ כִּנְעוּרֶיהָ מִלֶּחֶם אָבִיהָ תֹּאכֵל וְכל זָר לֹא יֹאכַל בּוֹ׃}
}
{
	\eP{
		but a priest’s daughter who will be a widow or a divorcée
		and has no seed and returns to her father’s house as in
		her youth, she may eat from her father’s bread. But any
		outsider shall not eat it.
	}
}
{
}

\Verse{14}
{
	\hP{וְאִישׁ כִּי יֹאכַל קֹדֶשׁ בִּשְׁגָגָה וְיָסַף חֲמִשִׁיתוֹ עָלָיו וְנָתַן לַכֹּהֵן אֶת הַקֹּדֶשׁ׃}
}
{
	\eP{
		And a man who eats what is holy by mistake shall add to it
		a fifth of it and shall give the holy thing to the priest.
	}
}
{
}

\Verse{15}
{
	\hP{וְלֹא יְחַלְּלוּ אֶת קדְשֵׁי בְּנֵי יִשְׂרָאֵל אֵת אֲשֶׁר יָרִימוּ לַיהֹוָה׃}
}
{
	\eP{
		And they shall not desecrate the holy things of the
		children of Israel that they will donate to YHWH
	}
}
{
}

\Verse{16}
{
	\hP{וְהִשִּׂיאוּ אוֹתָם עֲוֺן אַשְׁמָה בְּאכְלָם אֶת קדְשֵׁיהֶם כִּי אֲנִי יְהֹוָה מְקַדְּשָׁם׃}
}
{
	\eP{
		so that they would make them bear a crime requiring a
		guilt offering by their eating their holy things, because
		I, YHWH, make them holy.”
	}
}
{
}

\Verse{18}
{
	\hP{דַּבֵּר אֶל אַהֲרֹן וְאֶל בָּנָיו וְאֶל כּל בְּנֵי יִשְׂרָאֵל וְאָמַרְתָּ אֲלֵהֶם אִישׁ אִישׁ מִבֵּית יִשְׂרָאֵל וּמִן הַגֵּר בְּיִשְׂרָאֵל אֲשֶׁר יַקְרִיב קרְבָּנוֹ לְכל נִדְרֵיהֶם וּלְכל נִדְבוֹתָם אֲשֶׁר יַקְרִיבוּ לַיהֹוָה לְעֹלָה׃}
}
{
	\eP{
		“Speak to Aaron and to his sons and to all the children of
		Israel, and you shall say to them: Any man from the house
		of Israel or from the aliens in Israel who will make his
		offering—for all their vows and all their contributions
		that they bring forward to YHWH as a burnt offering—
	}
}
{
}

\Verse{19}
{
	\hP{לִרְצֹנְכֶם תָּמִים זָכָר בַּבָּקָר בַּכְּשָׂבִים וּבָעִזִּים׃}
}
{
	\eP{
		for acceptance for you it is to be unblemished, male of
		the cattle, of the sheep, or of the goats.
	}
}
{
}

\Verse{20}
{
	\hP{כֹּל אֲשֶׁר בּוֹ מוּם לֹא תַקְרִיבוּ כִּי לֹא לְרָצוֹן יִהְיֶה לָכֶם׃}
}
{
	\eP{
		You shall not bring forward any that has an injury in it,
		because it will not be acceptable for you.
	}
}
{
}

\Verse{21}
{
	\hP{וְאִישׁ כִּי יַקְרִיב זֶבַח שְׁלָמִים לַיהֹוָה לְפַלֵּא נֶדֶר אוֹ לִנְדָבָה בַּבָּקָר אוֹ בַצֹּאן תָּמִים יִהְיֶה לְרָצוֹן כּל מוּם לֹא יִהְיֶה בּוֹ׃}
}
{
	\eP{
		And a man who will bring forward a peace-offering
		sacrifice to YHWH to express a vow or as a contribution of
		the cattle or of the flock: it shall be unblemished for
		acceptance; there shall not be any injury in it.
	}
}
{
}

\Verse{22}
{
	\hP{עַוֶּרֶת אוֹ שָׁבוּר אוֹ חָרוּץ אוֹ יַבֶּלֶת אוֹ גָרָב אוֹ יַלֶּפֶת לֹא תַקְרִיבוּ אֵלֶּה לַיהֹוָה וְאִשֶּׁה לֹא תִתְּנוּ מֵהֶם עַל הַמִּזְבֵּחַ לַיהֹוָה׃}
}
{
	\eP{
		Blind or broken or slashed or sore or scabbed or scurvied:
		you shall not bring these forward to YHWH, and you shall
		not give an offering by fire of them on the altar to YHWH.
	}
}
{
}

\Verse{23}
{
	\hP{וְשׁוֹר וָשֶׂה שָׂרוּעַ וְקָלוּט נְדָבָה תַּעֲשֶׂה אֹתוֹ וּלְנֵדֶר לֹא יֵרָצֶה׃}
}
{
	\eP{
		An ox or a sheep that has an elongated limb or a short
		limb: you may make it a contribution, but it shall not be
		accepted for a vow.
	}
}
{
}

\Verse{24}
{
	\hP{וּמָעוּךְ וְכָתוּת וְנָתוּק וְכָרוּת לֹא תַקְרִיבוּ לַיהֹוָה וּבְאַרְצְכֶם לֹא תַעֲשׂוּ׃}
}
{
	\eP{
		And you shall not bring forward to YHWH one that is
		bruised, crushed, torn, or cut. And you shall not do it in
		your land,
	}
}
{
}

\Verse{25}
{
	\hP{וּמִיַּד בֶּן נֵכָר לֹא תַקְרִיבוּ אֶת לֶחֶם אֱלֹהֵיכֶם מִכּל אֵלֶּה כִּי משְׁחָתָם בָּהֶם מוּם בָּם לֹא יֵרָצוּ לָכֶם׃}
}
{
	\eP{
		and you shall not bring forward your God’s bread from any
		of these from a foreigner’s hand, because their flaw is in
		them, an injury is in them; they shall not be accepted for
		you.”
	}
}
{
}

\Verse{26}
{

	\eP{And YHWH spoke to Moses, saying,}

\Verse{27}
{
	\hP{שׁוֹר אוֹ כֶשֶׂב אוֹ עֵז כִּי יִוָּלֵד וְהָיָה שִׁבְעַת יָמִים תַּחַת אִמּוֹ וּמִיּוֹם הַשְּׁמִינִי וָהָלְאָה יֵרָצֶה לְקרְבַּן אִשֶּׁה לַיהֹוָה׃}
}
{
	\eP{
		“When an ox or a sheep or a goat will be born, it will be
		under its mother seven days, and from the eighth day on it
		will be accepted as an offering, an offering by fire to
		YHWH.
	}
}
{
}

\Verse{28}
{
	\hP{וְשׁוֹר אוֹ שֶׂה אֹתוֹ וְאֶת בְּנוֹ לֹא תִשְׁחֲטוּ בְּיוֹם אֶחָד׃}
}
{
	\eP{
		And an ox or a sheep: you shall not slaughter it and its
		child on one day.
	}
}
{
%	\footnote{
%		it and its child on one day. It is possible that this is a parallel to
%		the commandment against cooking a kid in its mother’s milk. This case is
%		more commonly understood to be a moral matter—a respect for the animals,
%		accepting that although we eat animals we must appreciate that they are
%		living beings—whereas the case of the kid also has a ritual dimension,
%		reflected in a Ugaritic text. See comment on Exod Footnote 23:19.
%	}
}

\Verse{29}
{

}
{
	\eP{

	}

}

\Verse{30}
