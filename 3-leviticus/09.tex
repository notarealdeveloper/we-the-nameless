\Chapter{9}

\Verse{1}
{
	\hOther{וַיְהִי בַּיּוֹם הַשְּׁמִינִי קָרָא מֹשֶׁה לְאַהֲרֹן וּלְבָנָיו וּלְזִקְנֵי יִשְׂרָאֵל׃}
}
{
	\eOther{
		And it was, on the eighth day, Moses called to Aaron and
		to his sons and to Israel’s elders.
	}
}
{
}

\Verse{2}
{
	\hOther{וַיֹּאמֶר אֶל אַהֲרֹן קַח לְךָ עֵגֶל בֶּן בָּקָר לְחַטָּאת וְאַיִל לְעֹלָה תְּמִימִם וְהַקְרֵב לִפְנֵי יְהֹוָה׃}
}
{
	\eOther{
		And he said to Aaron, “Take a calf of the cattle for a sin
		offering and a ram for a burnt offering—unblemished—and
		bring them forward in front of YHWH.
	}
}
{
}

\Verse{3}
{
	\hOther{וְאֶל בְּנֵי יִשְׂרָאֵל תְּדַבֵּר לֵאמֹר קְחוּ שְׂעִיר עִזִּים לְחַטָּאת וְעֵגֶל וָכֶבֶשׂ בְּנֵי שָׁנָה תְּמִימִם לְעֹלָה׃}
}
{
	\eOther{
		And you shall speak to the children of Israel, saying,
		‘Take a goat for a sin offering and a calf and a lamb,
		unblemished one-year-olds, for a burnt offering
	}
}
{
}

\Verse{4}
{
	\hOther{וְשׁוֹר וָאַיִל לִשְׁלָמִים לִזְבֹּחַ לִפְנֵי יְהֹוָה וּמִנְחָה בְּלוּלָה בַשָּׁמֶן כִּי הַיּוֹם יְהֹוָה נִרְאָה אֲלֵיכֶם׃}
}
{
	\eOther{
		and an ox and a ram for peace offerings to sacrifice in
		front of YHWH, and a grain offering mixed with oil,
		because today YHWH is appearing to you.’”
	}
}
{
}

\Verse{5}
{
	\hOther{וַיִּקְחוּ אֵת אֲשֶׁר צִוָּה מֹשֶׁה אֶל פְּנֵי אֹהֶל מוֹעֵד וַיִּקְרְבוּ כּל הָעֵדָה וַיַּעַמְדוּ לִפְנֵי יְהֹוָה׃}
}
{
	\eOther{
		And they took what Moses had commanded to the front of the
		Tent of Meeting, and they brought forward all of the
		congregation, and they stood in front of YHWH.
	}
}
{
}

\Verse{6}
{
	\hOther{וַיֹּאמֶר מֹשֶׁה זֶה הַדָּבָר אֲשֶׁר צִוָּה יְהֹוָה תַּעֲשׂוּ וְיֵרָא אֲלֵיכֶם כְּבוֹד יְהֹוָה׃}
}
{
	\eOther{
		And Moses said, “This is the thing that YHWH has commanded
		that you shall do, and YHWH’s glory will appear to you.”
	}
}
{
}

\Verse{7}
{
	\hOther{וַיֹּאמֶר מֹשֶׁה אֶל אַהֲרֹן קְרַב אֶל הַמִּזְבֵּחַ וַעֲשֵׂה אֶת חַטָּאתְךָ וְאֶת עֹלָתֶךָ וְכַפֵּר בַּעַדְךָ וּבְעַד הָעָם וַעֲשֵׂה אֶת קרְבַּן הָעָם וְכַפֵּר בַּעֲדָם כַּאֲשֶׁר צִוָּה יְהֹוָה׃}
}
{
	\eOther{
		And Moses said to Aaron, “Come forward to the altar and
		make your sin offering and your burnt offering and make
		atonement for yourself and for the people, and make the
		people’s offering and make atonement for them as YHWH
		commanded.”
	}
}
{
}

\Verse{8}
{
	\hOther{וַיִּקְרַב אַהֲרֹן אֶל הַמִּזְבֵּחַ וַיִּשְׁחַט אֶת עֵגֶל הַחַטָּאת אֲשֶׁר לוֹ׃}
}
{
	\eOther{
		And Aaron came forward to the altar and slaughtered the
		calf for the sin offering that he had.
	}
}
{
}

\Verse{9}
{
	\hOther{וַיַּקְרִבוּ בְּנֵי אַהֲרֹן אֶת הַדָּם אֵלָיו וַיִּטְבֹּל אֶצְבָּעוֹ בַּדָּם וַיִּתֵּן עַל קַרְנוֹת הַמִּזְבֵּחַ וְאֶת הַדָּם יָצַק אֶל יְסוֹד הַמִּזְבֵּחַ׃}
}
{
	\eOther{
		And Aaron’s sons brought forward the blood to him, and he
		dipped his finger in the blood and put it on the altar’s
		horns, and he poured the blood to the base of the altar.
	}
}
{
}

\Verse{10}
{
	\hOther{וְאֶת הַחֵלֶב וְאֶת הַכְּלָיֹת וְאֶת הַיֹּתֶרֶת מִן הַכָּבֵד מִן הַחַטָּאת הִקְטִיר הַמִּזְבֵּחָה כַּאֲשֶׁר צִוָּה יְהֹוָה אֶת מֹשֶׁה׃}
}
{
	\eOther{
		And he burned the fat and the kidneys and the lobe from
		the liver from the sin offering to smoke at the altar, as
		YHWH had commanded Moses.
	}
}
{
}

\Verse{11}
{
	\hOther{וְאֶת הַבָּשָׂר וְאֶת הָעוֹר שָׂרַף בָּאֵשׁ מִחוּץ לַמַּחֲנֶה׃}
}
{
	\eOther{
		And he burned the meat and the skin in fire outside the
		camp.
	}
}
{
}

\Verse{12}
{
	\hOther{וַיִּשְׁחַט אֶת הָעֹלָה וַיַּמְצִאוּ בְּנֵי אַהֲרֹן אֵלָיו אֶת הַדָּם וַיִּזְרְקֵהוּ עַל הַמִּזְבֵּחַ סָבִיב׃}
}
{
	\eOther{
		And he slaughtered the burnt offering. And Aaron’s sons
		presented the blood to him, and he flung it on the altar
		all around.
	}
}
{
}

\Verse{13}
{
	\hOther{וְאֶת הָעֹלָה הִמְצִיאוּ אֵלָיו לִנְתָחֶיהָ וְאֶת הָרֹאשׁ וַיַּקְטֵר עַל הַמִּזְבֵּחַ׃}
}
{
	\eOther{
		And they presented the burnt offering to him in its parts
		and the head, and he burned it to smoke on the altar.
	}
}
{
}

\Verse{14}
{
	\hOther{וַיִּרְחַץ אֶת הַקֶּרֶב וְאֶת הַכְּרָעָיִם וַיַּקְטֵר עַל הָעֹלָה הַמִּזְבֵּחָה׃}
}
{
	\eOther{
		And he washed the innards and the legs and burned them to
		smoke with the burnt offering at the altar.
	}
}
{
}

\Verse{15}
{
	\hOther{וַיַּקְרֵב אֵת קרְבַּן הָעָם וַיִּקַּח אֶת שְׂעִיר הַחַטָּאת אֲשֶׁר לָעָם וַיִּשְׁחָטֵהוּ וַיְחַטְּאֵהוּ כָּרִאשׁוֹן׃}
}
{
	\eOther{
		And he made the people’s offering: and he took the goat
		for the sin offering that was the people’s, and he
		slaughtered it and made a sin offering with it like the
		first one.
	}
}
{
%	\footnote{
%		like the first one. That is, he prepares the sin offering for the people
%		in the same place as the burnt offering that immediately preceded it
%		(9:12–14). This is in fulfillment of the commandment in 6:18.
%	}
}

\Verse{16}
{
	\hOther{וַיַּקְרֵב אֶת הָעֹלָה וַיַּעֲשֶׂהָ כַּמִּשְׁפָּט׃}
}
{
	\eOther{
		And he brought forward the burnt offering and made it
		according to the required manner.
	}
}
{
}

\Verse{17}
{
	\hOther{וַיַּקְרֵב אֶת הַמִּנְחָה וַיְמַלֵּא כַפּוֹ מִמֶּנָּה וַיַּקְטֵר עַל הַמִּזְבֵּחַ מִלְּבַד עֹלַת הַבֹּקֶר׃}
}
{
	\eOther{
		And he brought forward the grain offering and filled his
		hand from it and burned it to smoke on the altar—apart
		from the morning’s burnt offering.
	}
}
{
}

\Verse{18}
{
	\hOther{וַיִּשְׁחַט אֶת הַשּׁוֹר וְאֶת הָאַיִל זֶבַח הַשְּׁלָמִים אֲשֶׁר לָעָם וַיַּמְצִאוּ בְּנֵי אַהֲרֹן אֶת הַדָּם אֵלָיו וַיִּזְרְקֵהוּ עַל הַמִּזְבֵּחַ סָבִיב׃}
}
{
	\eOther{
		And he slaughtered the ox and the ram, the peace-offering
		sacrifice that was the people’s. And Aaron’s sons
		presented the blood to him, and he flung it on the altar
		all around,
	}
}
{
}

\Verse{19}
{
	\hOther{וְאֶת הַחֲלָבִים מִן הַשּׁוֹר וּמִן הָאַיִל הָאַלְיָה וְהַמְכַסֶּה וְהַכְּלָיֹת וְיֹתֶרֶת הַכָּבֵד׃}
}
{
	\eOther{
		and the fats from the ox and from the ram, the fat tail
		and the covering and the kidneys and the lobe of the
		liver.
	}
}
{
}

\Verse{20}
{
	\hOther{וַיָּשִׂימוּ אֶת הַחֲלָבִים עַל הֶחָזוֹת וַיַּקְטֵר הַחֲלָבִים הַמִּזְבֵּחָה׃}
}
{
	\eOther{
		And they set the fats on the breasts, and he burned the
		fats to smoke at the altar.
	}
}
{
}

\Verse{21}
{
	\hOther{וְאֵת הֶחָזוֹת וְאֵת שׁוֹק הַיָּמִין הֵנִיף אַהֲרֹן תְּנוּפָה לִפְנֵי יְהֹוָה כַּאֲשֶׁר צִוָּה מֹשֶׁה׃}
}
{
	\eOther{
		And Aaron elevated the breasts and the right thigh, an
		elevation offering in front of YHWH, as Moses had
		commanded.
	}
}
{
%	\footnote{
%		as Moses had commanded. It is unusual (though certainly not unknown) for
%		Moses to give commands. The Septuagint and Samaritan texts read “as YHWH
%		had commanded Moses,” which is likely (though not certain) to be the
%		original reading. See the comment on Lev 8:31.
%	}
}

\Verse{22}
{
	\hOther{וַיִּשָּׂא אַהֲרֹן אֶת יָדָו אֶל הָעָם וַיְבָרְכֵם וַיֵּרֶד מֵעֲשֹׂת הַחַטָּאת וְהָעֹלָה וְהַשְּׁלָמִים׃}
}
{
	\eOther{
		And Aaron raised his hands to the people and blessed them.
		And he went down from making the sin offering and the
		burnt offering and the peace offering.
	}
}
{
}

\Verse{23}
{
	\hOther{וַיָּבֹא מֹשֶׁה וְאַהֲרֹן אֶל אֹהֶל מוֹעֵד וַיֵּצְאוּ וַיְבָרְכוּ אֶת הָעָם וַיֵּרָא כְבוֹד יְהֹוָה אֶל כּל הָעָם׃}
}
{
	\eOther{
		And Moses and Aaron came to the Tent of Meeting, and they
		went out and blessed the people. And YHWH’s glory appeared
		to all the people.
	}
}
{
}

\Verse{24}
{
	\hOther{וַתֵּצֵא אֵשׁ מִלִּפְנֵי יְהֹוָה וַתֹּאכַל עַל הַמִּזְבֵּחַ אֶת הָעֹלָה וְאֶת הַחֲלָבִים וַיַּרְא כּל הָעָם וַיָּרֹנּוּ וַיִּפְּלוּ עַל פְּנֵיהֶם׃}
}
{
	\eOther{
		And fire came out from in front of YHWH and consumed the
		burnt offering and the fats on the altar! And all the
		people saw, and they shouted, and they fell on their
		faces!
	}
}
{
%	\footnote{
%		fire came out from in front of YHWH and consumed. The sacrifice that
%		inaugurates Israel’s priesthood is ignited by a miraculous fire that
%		comes from God, not humans. This is the first of several stories in
%		which miracles occur to confirm that Aaron and his descendants are the
%		only true priests.
%	}
}
