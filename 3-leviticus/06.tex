\Verse{2}
{
	\hOther{צַו אֶת אַהֲרֹן וְאֶת בָּנָיו לֵאמֹר זֹאת תּוֹרַת הָעֹלָה הִוא הָעֹלָה עַל מוֹקְדָה עַל הַמִּזְבֵּחַ כּל הַלַּיְלָה עַד הַבֹּקֶר וְאֵשׁ הַמִּזְבֵּחַ תּוּקַד בּוֹ׃}
}
{
	\eOther{
		“Command Aaron and his sons, saying: This is the\\
		instruction for the burnt offering. It is the one that\\
		goes up on its place of burning on the altar all night\\
		until morning, and the altar’s fire shall be kept burning\\
		through it.\\
	}
}
{
%	\footnote{
%		the one that goes up on its place of burning. Unlike the sacrifices that
%		are eaten, the “burnt offering”—literally “the one that goes up”—is
%		completely burned.
%	}
}

\Verse{3}
{
	\hOther{וְלָבַשׁ הַכֹּהֵן מִדּוֹ בַד וּמִכְנְסֵי בַד יִלְבַּשׁ עַל בְּשָׂרוֹ וְהֵרִים אֶת הַדֶּשֶׁן אֲשֶׁר תֹּאכַל הָאֵשׁ אֶת הָעֹלָה עַל הַמִּזְבֵּחַ וְשָׂמוֹ אֵצֶל הַמִּזְבֵּחַ׃}
}

	\eOther{
		And the priest shall wear his linen garment and shall wear\\
		linen drawers on his flesh. And he shall lift the ashes to\\

		altar, and he shall set them beside the altar.\\
	}
}
{

\Verse{4}
{
	\hOther{וּפָשַׁט אֶת בְּגָדָיו וְלָבַשׁ בְּגָדִים אֲחֵרִים וְהוֹצִיא אֶת הַדֶּשֶׁן אֶל מִחוּץ לַמַּחֲנֶה אֶל מָקוֹם טָהוֹר׃}
}
{
	\eOther{
		And he shall take off his clothes and wear other clothes,\\
		and he shall take the ashes outside the camp, to a pure\\
		place.\\
	}
}
{
%	\footnote{
%		he shall take off his clothes and wear other clothes. The priest wears
%		the special priestly garments when he gathers the ashes in the
%		Tabernacle courtyard, but he changes to other clothes when he carries
%		the ashes out of the camp. Why? Because the sacred garments can be worn
%		only in the sacred place. This is another case of zones of holiness.
%	}
}

\Verse{5}
{
	\hOther{וְהָאֵשׁ עַל הַמִּזְבֵּחַ תּוּקַד בּוֹ לֹא תִכְבֶּה וּבִעֵר עָלֶיהָ הַכֹּהֵן עֵצִים בַּבֹּקֶר בַּבֹּקֶר וְעָרַךְ עָלֶיהָ הָעֹלָה וְהִקְטִיר עָלֶיהָ חֶלְבֵי הַשְּׁלָמִים׃}
}
{
	\eOther{
		And the fire on the altar shall be kept burning through\\
		it. It shall not go out. And the priest shall burn wood on\\
		it morning by morning, and he shall arrange the burnt\\
		offering on it, and he shall burn the fat of the peace\\
		offerings to smoke on it.\\
	}
}
{
}

\Verse{6}
{
	\hOther{אֵשׁ תָּמִיד תּוּקַד עַל הַמִּזְבֵּחַ לֹא תִכְבֶּה׃}
}
{
	\eOther{
		Fire always shall be kept burning on the altar. It shall\\
		not go out.\\
	}
}
{
%	\footnote{
%		Fire always shall be kept burning on the altar. It shall not go out. If
%		it will always be kept burning, of course it will not go out. This is
%		redundant, and this makes it emphatic: this ritual law has special
%		significance because it brings together space and time. YHWH tells Moses
%		to command Aaron and his sons to keep an eternal fire burning at the
%		altar. This law thus provides for a visual expression of the idea that
%		the ritual structure that is starting here is to prevail for all time to
%		come. This fire that is not to be quenched is also reminiscent of the
%		account in Exodus of Moses’ encounter with YHWH at a bush that burns
%		without being consumed. Like the laws of distinction that are
%		reminiscent of the creation in Genesis 1 (see the comment on Lev 10:10),
%		this passage serves to connect the law and the Torah’s story. In both
%		cases, the priests are required by the law to perform an act that is
%		imitative of something that God has done in the narrative—which further
%		points to the bond between law and history in the Torah.
%	}
}

\Verse{7}

\Verse{8}
{
	\hOther{וְהֵרִים מִמֶּנּוּ בְּקֻמְצוֹ מִסֹּלֶת הַמִּנְחָה וּמִשַּׁמְנָהּ וְאֵת כּל הַלְּבֹנָה אֲשֶׁר עַל הַמִּנְחָה וְהִקְטִיר הַמִּזְבֵּחַ רֵיחַ נִיחֹחַ אַזְכָּרָתָהּ לַיהֹוָה׃}
}
{
	\eOther{
		And he shall lift some of it in his fist, some of the fine\\
		flour of the grain offering and some of its oil and all of\\
		the frankincense that is on the grain offering, and he\\
		shall burn a representative portion of it to smoke at the\\
		altar as a pleasant smell to YHWH.\\
	}
}
{
}

\Verse{9}
{
	\hOther{וְהַנּוֹתֶרֶת מִמֶּנָּה יֹאכְלוּ אַהֲרֹן וּבָנָיו מַצּוֹת תֵּאָכֵל בְּמָקוֹם קָדֹשׁ בַּחֲצַר אֹהֶל מוֹעֵד יֹאכְלוּהָ׃}
}
{
	\eOther{
		And Aaron and his sons shall eat the remainder of it. It\\
		shall be eaten as unleavened bread, in a holy place. They\\
		shall eat it in the courtyard of the Tent of Meeting.\\
	}
}
{
}

\Verse{10}
{
	\hOther{לֹא תֵאָפֶה חָמֵץ חֶלְקָם נָתַתִּי אֹתָהּ מֵאִשָּׁי קֹדֶשׁ קדָשִׁים הִוא כַּחַטָּאת וְכָאָשָׁם׃}

{
	\eOther{

	}
}
{
}

\Verse{11}
