\Chapter{24}

\Verse{1}
{
	\hX{בְּיָמָיו עָלָה נְבֻכַדְנֶאצַּר מֶלֶךְ בָּבֶל וַיְהִי־לוֹ יְהוֹיָקִים עֶבֶד שָׁלֹשׁ שָׁנִים וַיָּשׁב וַיִּמְרד־בּוֹ׃}
}
{
	\eX{
		In his days Nebuchadnezzar king of Babylon came up, and
		Jehoiakim became his servant three years: then he turned and
		rebelled against him.
	}
}
{
}

\Verse{2}
{
	\hX{
		וַיְשַׁלַּח יְהֹוָה בּוֹ אֶת־גְּדוּדֵי כַשְׂדִּים וְאֶת־גְּדוּדֵי אֲרָם וְאֵת גְּדוּדֵי מוֹאָב וְאֵת גְּדוּדֵי בְנֵי־עַמּוֹן וַיְשַׁלְּחֵם בִּיהוּדָה לְהַאֲבִידוֹ כִּדְבַר יְהֹוָה
		אֲשֶׁר דִּבֶּר בְּיַד עֲבָדָיו הַנְּבִיאִים׃
	}
}
{
	\eX{
		And YHWH sent against him bands of the Chaldees, and bands of
		the Arameans, and bands of the Moabites, and bands of the
		children of Ammon, and sent them against Judah to destroy it,
		according to the word of YHWH, that he spoke by his servants the
		prophets.
	}
}
{
}

\Verse{3}
{
	\hX{אַךְ עַל־פִּי יְהֹוָה הָיְתָה בִּיהוּדָה לְהָסִיר מֵעַל פָּנָיו בְּחַטֹּאת מְנַשֶּׁה כְּכֹל אֲשֶׁר עָשָׂה׃}
}
{
	\eX{
		Surely at the commandment of YHWH came this on Judah, to remove
		them out of his sight, for the sins of Manasseh, according to
		all that he did:
	}
}
{
}

\Verse{4}
{
	\hX{וְגַם דַּם־הַנָּקִי אֲשֶׁר שָׁפָךְ וַיְמַלֵּא אֶת־יְרוּשָׁלַ͏ִם דָּם נָקִי וְלֹא־אָבָה יְהֹוָה לִסְלֹחַ׃}
}
{
	\eX{
		And also for the innocent blood that he shed: for he filled
		Jerusalem with innocent blood: that YHWH would not pardon.
	}
}
{
}

\Verse{5}
{
	\hX{וְיֶתֶר דִּבְרֵי יְהוֹיָקִים וְכל־אֲשֶׁר עָשָׂה הֲלֹא־הֵם כְּתוּבִים עַל־סֵפֶר דִּבְרֵי הַיָּמִים לְמַלְכֵי יְהוּדָה׃}
}
{
	\eX{
		And the rest of the acts of Jehoiakim, and all that he did, are
		they not written in the book of the chronicles of the kings of
		Judah?
	}
}
{
}

\Verse{6}
{
	\hX{וַיִּשְׁכַּב יְהוֹיָקִים עִם־אֲבֹתָיו וַיִּמְלֹךְ יְהוֹיָכִין בְּנוֹ תַּחְתָּיו׃}
}
{
	\eX{
		So Jehoiakim slept with his fathers: and Jehoiachin his son
		reigned in his place.
	}
}
{
}

\Verse{7}
{
	\hX{וְלֹא־הֹסִיף עוֹד מֶלֶךְ מִצְרַיִם לָצֵאת מֵאַרְצוֹ כִּי־לָקַח מֶלֶךְ בָּבֶל מִנַּחַל מִצְרַיִם עַד־נְהַר־פְּרָת כֹּל אֲשֶׁר הָיְתָה לְמֶלֶךְ מִצְרָיִם׃}
}
{
	\eX{
		And the king of Egypt didn't come again any more out of his
		land: for the king of Babylon had taken from the river of Egypt
		to the river Euphrates all that pertained to the king of Egypt.
	}
}
{
}

\Verse{8}
{
	\hX{בֶּן־שְׁמֹנֶה עֶשְׂרֵה שָׁנָה יְהוֹיָכִין בְּמלְכוֹ וּשְׁלֹשָׁה חֳדָשִׁים מָלַךְ בִּירוּשָׁלָ͏ִם וְשֵׁם אִמּוֹ נְחֻשְׁתָּא בַת־אֶלְנָתָן מִירוּשָׁלָ͏ִם׃}
}
{
	\eX{
		Jehoiachin was eighteen years old when he began to reign, and he
		reigned in Jerusalem three months. And his mother's name was
		Nehushta, the daughter of Elnathan of Jerusalem.
	}
}
{
}

\Verse{9}
{
	\hX{וַיַּעַשׂ הָרַע בְּעֵינֵי יְהֹוָה כְּכֹל אֲשֶׁר־עָשָׂה אָבִיו׃}
}
{
	\eX{
		And he did that that was bad in the eyes of YHWH, according to
		all that his father had done.
	}
}
{
}

\Verse{10}
{
	\hX{בָּעֵת הַהִיא (עלה) [עָלוּ] עַבְדֵי נְבֻכַדְנֶאצַּר מֶלֶךְ־בָּבֶל יְרוּשָׁלָ͏ִם וַתָּבֹא הָעִיר בַּמָּצוֹר׃}
}
{
	\eX{
		At that time the servants of Nebuchadnezzar king of Babylon came
		up against Jerusalem, and the city was laid siege to.
	}
}
{
	Qere Ketiv.
}

\Verse{11}
{
	\hX{וַיָּבֹא נְבֻכַדְנֶאצַּר מֶלֶךְ־בָּבֶל עַל־הָעִיר וַעֲבָדָיו צָרִים עָלֶיהָ׃}
}
{
	\eX{
		And Nebuchadnezzar king of Babylon came against the city, and
		his servants did besiege it.
	}
}
{
}

\Verse{12}
{
	\hX{וַיֵּצֵא יְהוֹיָכִין מֶלֶךְ־יְהוּדָה עַל־מֶלֶךְ בָּבֶל הוּא וְאִמּוֹ וַעֲבָדָיו וְשָׂרָיו וְסָרִיסָיו וַיִּקַּח אֹתוֹ מֶלֶךְ בָּבֶל בִּשְׁנַת שְׁמֹנֶה לְמלְכוֹ׃}
}
{
	\eX{
		And Jehoiachin the king of Judah went out to the king of
		Babylon, he, and his mother, and his servants, and his princes,
		and his officers: and the king of Babylon took him in the eighth
		year of his reign.
	}
}
{
}

\Verse{13}
{
	\hX{
		וַיּוֹצֵא מִשָּׁם אֶת־כּל־אוֹצְרוֹת בֵּית יְהֹוָה וְאוֹצְרוֹת בֵּית הַמֶּלֶךְ וַיְקַצֵּץ אֶת־כּל־כְּלֵי הַזָּהָב אֲשֶׁר עָשָׂה שְׁלֹמֹה מֶלֶךְ־יִשְׂרָאֵל בְּהֵיכַל יְהֹוָה
		כַּאֲשֶׁר דִּבֶּר יְהֹוָה׃
	}
}
{
	\eX{
		And he carried out from there all the treasures of the house of
		YHWH, and the treasures of the king's house, and cut in pieces
		all the vessels of gold that Solomon king of Israel had made in
		the temple of YHWH, as YHWH had said.
	}
}
{
}

\Verse{14}
{
	\hX{
		וְהִגְלָה אֶת־כּל־יְרוּשָׁלַ͏ִם וְאֶת־כּל־הַשָּׂרִים וְאֵת כּל־גִּבּוֹרֵי הַחַיִל (עשרה) [עֲשֶׂרֶת] אֲלָפִים גּוֹלֶה וְכל־הֶחָרָשׁ וְהַמַּסְגֵּר לֹא נִשְׁאַר זוּלַת דַּלַּת
		עַם־הָאָרֶץ׃
	}
}
{
	\eX{
		And he carried away all Jerusalem, and all the princes, and all
		the mighty men of strength, even ten thousand captives, and all
		the craftsmen and smiths: none remained, save the poorest sort
		of the people of the land.
	}
}
{
	Qere Ketiv.
}

\Verse{15}
{
	\hX{וַיֶּגֶל אֶת־יְהוֹיָכִין בָּבֶלָה וְאֶת־אֵם הַמֶּלֶךְ וְאֶת־נְשֵׁי הַמֶּלֶךְ וְאֶת־סָרִיסָיו וְאֵת (אולי) [אֵילֵי] הָאָרֶץ הוֹלִיךְ גּוֹלָה מִירוּשָׁלַ͏ִם בָּבֶלָה׃}
}
{
	\eX{
		And he carried away Jehoiachin to Babylon, and the king's
		mother, and the king's wives, and his officers, and the mighty
		of the land, those carried he into captivity from Jerusalem to
		Babylon.
	}
}
{
	Qere Ketiv.
}

\Verse{16}
{
	\hX{וְאֵת כּל־אַנְשֵׁי הַחַיִל שִׁבְעַת אֲלָפִים וְהֶחָרָשׁ וְהַמַּסְגֵּר אֶלֶף הַכֹּל גִּבּוֹרִים עֹשֵׂי מִלְחָמָה וַיְבִיאֵם מֶלֶךְ־בָּבֶל גּוֹלָה בָּבֶלָה׃}
}
{
	\eX{
		And all the men of might, even seven thousand, and craftsmen and
		smiths a thousand, all that were strong and apt for war, even
		them the king of Babylon brought captive to Babylon.
	}
}
{
}

\Verse{17}
{
	\hX{וַיַּמְלֵךְ מֶלֶךְ־בָּבֶל אֶת־מַתַּנְיָה דֹדוֹ תַּחְתָּיו וַיַּסֵּב אֶת־שְׁמוֹ צִדְקִיָּהוּ׃}
}
{
	\eX{
		And the king of Babylon made Mattaniah his father's brother king
		in his place, and changed his name to Zedekiah.
	}
}
{
}

\Verse{18}
{
	\hX{בֶּן־עֶשְׂרִים וְאַחַת שָׁנָה צִדְקִיָּהוּ בְמלְכוֹ וְאַחַת עֶשְׂרֵה שָׁנָה מָלַךְ בִּירוּשָׁלָ͏ִם וְשֵׁם אִמּוֹ (חמיטל) [חֲמוּטַל] בַּת־יִרְמְיָהוּ מִלִּבְנָה׃}
}
{
	\eX{
		Zedekiah was twenty-one years old when he began to reign, and he
		reigned eleven years in Jerusalem. And his mother's name was
		Hamutal, the daughter of Jeremiah of Libnah.
	}
}
{
	Qere Ketiv.
}

\Verse{19}
{
	\hX{וַיַּעַשׂ הָרַע בְּעֵינֵי יְהֹוָה כְּכֹל אֲשֶׁר־עָשָׂה יְהוֹיָקִים׃}
}
{
	\eX{
		And he did that that was bad in the eyes of YHWH, according to
		all that Jehoiakim had done.
	}
}
{
}

\Verse{20}
{
	\hX{כִּי עַל־אַף יְהֹוָה הָיְתָה בִירוּשָׁלַ͏ִם וּבִיהוּדָה עַד־הִשְׁלִכוֹ אֹתָם מֵעַל פָּנָיו וַיִּמְרֹד צִדְקִיָּהוּ בְּמֶלֶךְ בָּבֶל׃}
}
{
	\eX{
		For through the anger of YHWH it was in Jerusalem and Judah,
		until he had cast them out from his presence, that Zedekiah
		rebelled against the king of Babylon.
	}
}
{
}
