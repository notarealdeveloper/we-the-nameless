\Chapter{10}

\Verse{1}
{
	\hX{וּמַלְכַּת־שְׁבָא שֹׁמַעַת אֶת־שֵׁמַע שְׁלֹמֹה לְשֵׁם יְהֹוָה וַתָּבֹא לְנַסֹּתוֹ בְּחִידוֹת׃}
}
{
	\eX{
		And when the queen of Sheba heard of the name of Solomon
		concerning the name of YHWH, she came to prove him with hard
		questions.
	}
}
{
}

\Verse{2}
{
	\hX{
		וַתָּבֹא יְרוּשָׁלַ͏ְמָה בְּחַיִל כָּבֵד מְאֹד גְּמַלִּים נֹשְׂאִים בְּשָׂמִים וְזָהָב רַב־מְאֹד וְאֶבֶן יְקָרָה וַתָּבֹא אֶל־שְׁלֹמֹה וַתְּדַבֵּר אֵלָיו אֵת כּל־אֲשֶׁר הָיָה
		עִם־לְבָבָהּ׃
	}
}
{
	\eX{
		And she came to Jerusalem with a very great train, with camels
		that bore spices, and very much gold, and precious stones: and
		when she was come to Solomon, she communed with him of all that
		was in her heart.
	}
}
{
}

\Verse{3}
{
	\hX{וַיַּגֶּד־לָהּ שְׁלֹמֹה אֶת־כּל־דְּבָרֶיהָ לֹא־הָיָה דָבָר נֶעְלָם מִן־הַמֶּלֶךְ אֲשֶׁר לֹא הִגִּיד לָהּ׃}
}
{
	\eX{
		And Solomon told her all her questions: there was not any thing
		hid from the king, that he told her not.
	}
}
{
}

\Verse{4}
{
	\hX{וַתֵּרֶא מַלְכַּת־שְׁבָא אֵת כּל־חכְמַת שְׁלֹמֹה וְהַבַּיִת אֲשֶׁר בָּנָה׃}
}
{
	\eX{
		And when the queen of Sheba had seen all Solomon's wisdom, and
		the house that he had built,
	}
}
{
}

\Verse{5}
{
	\hX{וּמַאֲכַל שֻׁלְחָנוֹ וּמוֹשַׁב עֲבָדָיו וּמַעֲמַד מְשָׁרְתָו וּמַלְבֻּשֵׁיהֶם וּמַשְׁקָיו וְעֹלָתוֹ אֲשֶׁר יַעֲלֶה בֵּית יְהֹוָה וְלֹא־הָיָה בָהּ עוֹד רוּחַ׃}
}
{
	\eX{
		And the meat of his table, and the sitting of his servants, and
		the attendance of his ministers, and their apparel, and his
		cupbearers, and his ascent by that he went up to the house of
		YHWH: there was no more spirit in her.
	}
}
{
}

\Verse{6}
{
	\hX{וַתֹּאמֶר אֶל־הַמֶּלֶךְ אֱמֶת הָיָה הַדָּבָר אֲשֶׁר שָׁמַעְתִּי בְּאַרְצִי עַל־דְּבָרֶיךָ וְעַל־חכְמָתֶךָ׃}
}
{
	\eX{
		And she said to the king, It was a true report that I heard in
		my own land of your acts and of your wisdom.
	}
}
{
}

\Verse{7}
{
	\hX{וְלֹא־הֶאֱמַנְתִּי לַדְּבָרִים עַד אֲשֶׁר־בָּאתִי וַתִּרְאֶינָה עֵינַי וְהִנֵּה לֹא־הֻגַּד־לִי הַחֵצִי הוֹסַפְתָּ חכְמָה וָטוֹב אֶל־הַשְּׁמוּעָה אֲשֶׁר שָׁמָעְתִּי׃}
}
{
	\eX{
		But I believed not the words, until I came, and my eyes had seen
		it: and, here: the half was not told me: your wisdom and
		prosperity exceeds the name that I heard.
	}
}
{
}

\Verse{8}
{
	\hX{אַשְׁרֵי אֲנָשֶׁיךָ אַשְׁרֵי עֲבָדֶיךָ אֵלֶּה הָעֹמְדִים לְפָנֶיךָ תָּמִיד הַשֹּׁמְעִים אֶת־חכְמָתֶךָ׃}
}
{
	\eX{
		Happy are your men, happy are these your servants, which stand
		continually before you, and that hear your wisdom.
	}
}
{
}

\Verse{9}
{
	\hX{יְהִי יְהֹוָה אֱלֹהֶיךָ בָּרוּךְ אֲשֶׁר חָפֵץ בְּךָ לְתִתְּךָ עַל־כִּסֵּא יִשְׂרָאֵל בְּאַהֲבַת יְהֹוָה אֶת־יִשְׂרָאֵל לְעֹלָם וַיְשִׂימְךָ לְמֶלֶךְ לַעֲשׂוֹת מִשְׁפָּט וּצְדָקָה׃}
}
{
	\eX{
		Blessed be YHWH your God, which delighted in you, to set you on
		the throne of Israel: because YHWH loved Israel for ever,
		therefore made he you king, to do judgment and justice.
	}
}
{
}

\Verse{10}
{
	\hX{
		וַתִּתֵּן לַמֶּלֶךְ מֵאָה וְעֶשְׂרִים כִּכַּר זָהָב וּבְשָׂמִים הַרְבֵּה מְאֹד וְאֶבֶן יְקָרָה לֹא בָא כַבֹּשֶׂם הַהוּא עוֹד לָרֹב אֲשֶׁר־נָתְנָה מַלְכַּת־שְׁבָא לַמֶּלֶךְ
		שְׁלֹמֹה׃
	}
}
{
	\eX{
		And she gave the king a hundred and twenty talents of gold, and
		of spices very great store, and precious stones: there came no
		more such abundance of spices as these which the queen of Sheba
		gave to king Solomon.
	}
}
{
}

\Verse{11}
{
	\hX{וְגַם אֳנִי חִירָם אֲשֶׁר־נָשָׂא זָהָב מֵאוֹפִיר הֵבִיא מֵאֹפִיר עֲצֵי אַלְמֻגִּים הַרְבֵּה מְאֹד וְאֶבֶן יְקָרָה׃}
}
{
	\eX{
		And the navy also of Hiram, that brought gold from Ophir,
		brought in from Ophir great plenty of almug trees, and precious
		stones.
	}
}
{
}

\Verse{12}
{
	\hX{
		וַיַּעַשׂ הַמֶּלֶךְ אֶת־עֲצֵי הָאַלְמֻגִּים מִסְעָד לְבֵית־יְהֹוָה וּלְבֵית הַמֶּלֶךְ וְכִנֹּרוֹת וּנְבָלִים לַשָּׁרִים לֹא בָא־כֵן עֲצֵי אַלְמֻגִּים וְלֹא נִרְאָה עַד הַיּוֹם
		הַזֶּה׃
	}
}
{
	\eX{
		And the king made of the almug trees pillars for the house of
		YHWH, and for the king's house, harps also and psalteries for
		singers: there came no such almug trees, nor were seen to this
		day.
	}
}
{
}

\Verse{13}
{
	\hX{וְהַמֶּלֶךְ שְׁלֹמֹה נָתַן לְמַלְכַּת־שְׁבָא אֶת־כּל־חֶפְצָהּ אֲשֶׁר שָׁאָלָה מִלְּבַד אֲשֶׁר נָתַן־לָהּ כְּיַד הַמֶּלֶךְ שְׁלֹמֹה וַתֵּפֶן וַתֵּלֶךְ לְאַרְצָהּ הִיא וַעֲבָדֶיהָ׃}
}
{
	\eX{
		And king Solomon gave to the queen of Sheba all her desire,
		whatsoever she asked, beside that which Solomon gave her of his
		royal bounty.
	}
}
{
}

\Verse{14}
{
	\hX{וַיְהִי מִשְׁקַל הַזָּהָב אֲשֶׁר־בָּא לִשְׁלֹמֹה בְּשָׁנָה אֶחָת שֵׁשׁ מֵאוֹת שִׁשִּׁים וָשֵׁשׁ כִּכַּר זָהָב׃}
}

{
}

\Verse{15}

}
{
	\eX{

}
{
}

\Verse{16}

	\hX{וַיַּעַשׂ הַמֶּלֶךְ שְׁלֹמֹה מָאתַיִם צִנָּה זָהָב שָׁחוּט שֵׁשׁ־מֵאוֹת זָהָב יַעֲלֶה עַל־הַצִּנָּה הָאֶחָת׃}
}
{
	\eX{

}
{
}

}
{
	\eX{

		gold went to one shield: and the king put them in the house of
		the forest of Lebanon.

}
{
}

\Verse{18}
{
	\hX{וַיַּעַשׂ הַמֶּלֶךְ כִּסֵּא־שֵׁן גָּדוֹל וַיְצַפֵּהוּ זָהָב מוּפָז׃}

}

{
}

\Verse{20}

}

{

\Verse{21}

	\hX{וְכֹל כְּלֵי מַשְׁקֵה הַמֶּלֶךְ שְׁלֹמֹה זָהָב וְכֹל כְּלֵי בֵּית־יַעַר הַלְּבָנוֹן זָהָב סָגוּר אֵין כֶּסֶף לֹא נֶחְשָׁב בִּימֵי שְׁלֹמֹה לִמְאוּמָה׃}

	\eX{

}
{
}
