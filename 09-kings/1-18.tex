\Chapter{18}

\Verse{1}
{
	\hX{וַיְהִי יָמִים רַבִּים וּדְבַר־יְהֹוָה הָיָה אֶל־אֵלִיָּהוּ בַּשָּׁנָה הַשְּׁלִישִׁית לֵאמֹר לֵךְ הֵרָאֵה אֶל־אַחְאָב וְאֶתְּנָה מָטָר עַל־פְּנֵי הָאֲדָמָה׃}
}
{
	\eX{
		And it was after many days, that the word of YHWH came to Elijah
		in the third year, saying, Go, show yourself to Ahab: and I'll
		send rain on the earth.
	}
}
{
}

\Verse{2}
{
	\hX{וַיֵּלֶךְ אֵלִיָּהוּ לְהֵרָאוֹת אֶל־אַחְאָב וְהָרָעָב חָזָק בְּשֹׁמְרוֹן׃}
}
{
	\eX{
		And Elijah went to show himself to Ahab. And there was a heavy
		famine in Samaria.
	}
}
{
}

\Verse{3}
{
	\hX{וַיִּקְרָא אַחְאָב אֶל־עֹבַדְיָהוּ אֲשֶׁר עַל־הַבָּיִת וְעֹבַדְיָהוּ הָיָה יָרֵא אֶת־יְהֹוָה מְאֹד׃}
}
{
	\eX{
		And Ahab called Obadiah, that was the governor of his house.
		(And Obadiah feared YHWH greatly:
	}
}
{
}

\Verse{4}
{
	\hX{וַיְהִי בְּהַכְרִית אִיזֶבֶל אֵת נְבִיאֵי יְהֹוָה וַיִּקַּח עֹבַדְיָהוּ מֵאָה נְבִיאִים וַיַּחְבִּיאֵם חֲמִשִּׁים אִישׁ בַּמְּעָרָה וְכִלְכְּלָם לֶחֶם וָמָיִם׃}
}
{
	\eX{
		For it was so, when Jezebel cut off the prophets of YHWH, that
		Obadiah took a hundred prophets, and hid them by fifty in a
		cave, and fed them with bread and water.)
	}
}
{
}

\Verse{5}
{
	\hX{וַיֹּאמֶר אַחְאָב אֶל־עֹבַדְיָהוּ לֵךְ בָּאָרֶץ אֶל־כּל־מַעְיְנֵי הַמַּיִם וְאֶל כּל־הַנְּחָלִים אוּלַי נִמְצָא חָצִיר וּנְחַיֶּה סוּס וָפֶרֶד וְלוֹא נַכְרִית מֵהַבְּהֵמָה׃}
}
{
	\eX{
		And Ahab said to Obadiah, Go into the land, to all fountains of
		water, and to all brooks: perhaps we may find grass to save the
		horses and mules alive, that we lose not all the animals.
	}
}
{
}

\Verse{6}
{
	\hX{וַיְחַלְּקוּ לָהֶם אֶת־הָאָרֶץ לַעֲבר־בָּהּ אַחְאָב הָלַךְ בְּדֶרֶךְ אֶחָד לְבַדּוֹ וְעֹבַדְיָהוּ הָלַךְ בְּדֶרֶךְ־אֶחָד לְבַדּוֹ׃}
}
{
	\eX{
		And they divided the land between them to pass throughout it:
		Ahab went one way by himself, and Obadiah went another way by
		himself.
	}
}
{
}

\Verse{7}
{
	\hX{וַיְהִי עֹבַדְיָהוּ בַּדֶּרֶךְ וְהִנֵּה אֵלִיָּהוּ לִקְרָאתוֹ וַיַּכִּרֵהוּ וַיִּפֹּל עַל־פָּנָיו וַיֹּאמֶר הַאַתָּה זֶה אֲדֹנִי אֵלִיָּהוּ׃}
}
{
	\eX{
		And as Obadiah was in the way, here: Elijah met him: and he knew
		him, and fell on his face, and said, Are you that my lord
		Elijah?
	}
}
{
}

\Verse{8}
{
	\hX{וַיֹּאמֶר לוֹ אָנִי לֵךְ אֱמֹר לַאדֹנֶיךָ הִנֵּה אֵלִיָּהוּ׃}
}
{
	\eX{

\Verse{9}

}
{
	\eX{

{

\Verse{10}
{
	\hX{חַי יְהֹוָה אֱלֹהֶיךָ אִם־יֶשׁ־גּוֹי וּמַמְלָכָה אֲשֶׁר לֹא־שָׁלַח אֲדֹנִי שָׁם לְבַקֶּשְׁךָ וְאָמְרוּ אָיִן וְהִשְׁבִּיעַ אֶת־הַמַּמְלָכָה וְאֶת־הַגּוֹי כִּי לֹא יִמְצָאֶכָּה׃}
}
{
	\eX{
		As YHWH your God lives, there is no nation or kingdom, where my
		lord has not sent to seek you: and when they said, He is not
		there: he took an oath of the kingdom and nation, that they
		found you not.
	}
}
{
}

\Verse{11}
{
	\hX{וְעַתָּה אַתָּה אֹמֵר לֵךְ אֱמֹר לַאדֹנֶיךָ הִנֵּה אֵלִיָּהוּ׃}
}
{
	\eX{And now you say, Go, tell your lord, Here: Elijah is here.}

{
}

\Verse{12}
{
	\hX{וְהָיָה אֲנִי אֵלֵךְ מֵאִתָּךְ וְרוּחַ יְהֹוָה יִשָּׂאֲךָ עַל אֲשֶׁר לֹא־אֵדָע וּבָאתִי לְהַגִּיד לְאַחְאָב וְלֹא יִמְצָאֲךָ וַהֲרָגָנִי וְעַבְדְּךָ יָרֵא אֶת־יְהֹוָה מִנְּעֻרָי׃}
}
{
	\eX{
		And it will be, as soon as I am gone from you, that the Spirit
		of YHWH shall carry you where I know not: and so when I come and
		tell Ahab, and he can't find you, he shall kill me: but I your
		servant fear YHWH from my youth.
	}
}
{
}

\Verse{13}
{
	\hX{
		הֲלֹא־הֻגַּד לַאדֹנִי אֵת אֲשֶׁר־עָשִׂיתִי בַּהֲרֹג אִיזֶבֶל אֵת נְבִיאֵי יְהֹוָה וָאַחְבִּא מִנְּבִיאֵי יְהֹוָה מֵאָה אִישׁ חֲמִשִּׁים חֲמִשִּׁים אִישׁ בַּמְּעָרָה וָאֲכַלְכְּלֵם
		לֶחֶם וָמָיִם׃
	}
}
{
	\eX{
		Was it not told my lord what I did when Jezebel slaughtered the
		prophets of YHWH, how I hid a hundred men of YHWH's prophets by
		fifty in a cave, and fed them with bread and water?
	}
}
{
}

{
	\hX{וְעַתָּה אַתָּה אֹמֵר לֵךְ אֱמֹר לַאדֹנֶיךָ הִנֵּה אֵלִיָּהוּ וַהֲרָגָנִי׃}

\Verse{17}

}

\Verse{18}

	\hX{וַיֹּאמֶר לֹא עָכַרְתִּי אֶת־יִשְׂרָאֵל כִּי אִם־אַתָּה וּבֵית אָבִיךָ בַּעֲזבְכֶם אֶת־מִצְוֺת יְהֹוָה וַתֵּלֶךְ אַחֲרֵי הַבְּעָלִים׃}
}
{
	\eX{

	}
}
{
}

\Verse{19}
{
	\hX{
		וְעַתָּה שְׁלַח קְבֹץ אֵלַי אֶת־כּל־יִשְׂרָאֵל אֶל־הַר הַכַּרְמֶל וְאֶת־נְבִיאֵי הַבַּעַל אַרְבַּע מֵאוֹת וַחֲמִשִּׁים וּנְבִיאֵי הָאֲשֵׁרָה אַרְבַּע מֵאוֹת אֹכְלֵי שֻׁלְחַן
		אִיזָבֶל׃
	}
}
{
	\eX{
		And now send, and gather to me all Israel to mount Carmel, and
		the prophets of Baal four hundred and fifty, and the prophets of
		the Asherahs four hundred, which eat at Jezebel's table.
	}
}
{
}

\Verse{20}
{
	\hX{וַיִּשְׁלַח אַחְאָב בְּכל־בְּנֵי יִשְׂרָאֵל וַיִּקְבֹּץ אֶת־הַנְּבִיאִים אֶל־הַר הַכַּרְמֶל׃}
}
{
	\eX{

		prophets together to mount Carmel.
	}
}
{
}

\Verse{21}
{
	\hX{
		וַיִּגַּשׁ אֵלִיָּהוּ אֶל־כּל־הָעָם וַיֹּאמֶר עַד־מָתַי אַתֶּם פֹּסְחִים עַל־שְׁתֵּי הַסְּעִפִּים אִם־יְהֹוָה הָאֱלֹהִים לְכוּ אַחֲרָיו וְאִם־הַבַּעַל לְכוּ אַחֲרָיו וְלֹא־עָנוּ
		הָעָם אֹתוֹ דָּבָר׃
	}
}
{
	\eX{

		you limping on two branches? If YHWH is God, go after Him; and
		if Baal, go after him. And the people did not answer him a word.
	}
}
{
%	\footnote{
%		Footnote 18:21. Limping on two branches is the image. Elijah turns indecision into
%		a body moving badly.
%	}
}

{

}
{
	\eX{

}
{
}

\Verse{23}
{
	\hX{

		it on wood, and put no fire under:
	}
}
{
}

\Verse{24}
{
	\hX{וּקְרָאתֶם בְּשֵׁם אֱלֹהֵיכֶם וַאֲנִי אֶקְרָא בְשֵׁם־יְהֹוָה וְהָיָה הָאֱלֹהִים אֲשֶׁר־יַעֲנֶה בָאֵשׁ הוּא הָאֱלֹהִים וַיַּעַן כּל־הָעָם וַיֹּאמְרוּ טוֹב הַדָּבָר׃}
}
{
	\eX{

}
{
}

\Verse{25}
{
	\hX{וַיֹּאמֶר אֵלִיָּהוּ לִנְבִיאֵי הַבַּעַל בַּחֲרוּ לָכֶם הַפָּר הָאֶחָד וַעֲשׂוּ רִאשֹׁנָה כִּי אַתֶּם הָרַבִּים וְקִרְאוּ בְּשֵׁם אֱלֹהֵיכֶם וְאֵשׁ לֹא תָשִׂימוּ׃}
}
{
	\eX{

		yourselves, and prepare it first: for you are many: and call on
		the name of your gods, but put no fire under.
	}
}
{
}

\Verse{26}
{
	\hX{
		וַיִּקְחוּ אֶת־הַפָּר אֲשֶׁר־נָתַן לָהֶם וַיַּעֲשׂוּ וַיִּקְרְאוּ בְשֵׁם־הַבַּעַל מֵהַבֹּקֶר וְעַד־הַצּהֳרַיִם לֵאמֹר הַבַּעַל עֲנֵנוּ וְאֵין קוֹל וְאֵין עֹנֶה וַיְפַסְּחוּ
		עַל־הַמִּזְבֵּחַ אֲשֶׁר עָשָׂה׃
	}
}
{
	\eX{
		And they took the bull that was given them, and they dressed it,
		and called on the name of Baal from morning even until noon,
		saying, O Baal, hear us. But there was no voice, nor any that
		answered. And they leaped on the altar that was made.
	}
}
{
}

\Verse{27}
{
	\hX{וַיְהִי בַצּהֳרַיִם וַיְהַתֵּל בָּהֶם אֵלִיָּהוּ וַיֹּאמֶר קִרְאוּ בְקוֹל־גָּדוֹל כִּי־אֱלֹהִים הוּא כִּי שִׂיחַ וְכִי־שִׂיג לוֹ וְכִי־דֶרֶךְ לוֹ אוּלַי יָשֵׁן הוּא וְיִקָץ׃}
}
{
	\eX{
		And it was at noon, that Elijah mocked them, and said, Cry
		aloud: for he is a god: either he is talking, or he is pursuing,
		or he is in a journey, or perhaps he sleeps, and must be awaked.
	}
}
{
}

\Verse{28}
{
	\hX{וַיִּקְרְאוּ בְּקוֹל גָּדוֹל וַיִּתְגֹּדְדוּ כְּמִשְׁפָּטָם בַּחֲרָבוֹת וּבָרְמָחִים עַד־שְׁפךְ־דָּם עֲלֵיהֶם׃}

}
{

}
