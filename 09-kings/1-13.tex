\Chapter{13}

\Verse{1}
{
	\hX{וְהִנֵּה אִישׁ אֱלֹהִים בָּא מִיהוּדָה בִּדְבַר יְהֹוָה אֶל־בֵּית־אֵל וְיָרבְעָם עֹמֵד עַל־הַמִּזְבֵּחַ לְהַקְטִיר׃}
}
{
	\eX{
		And here: there came a man of God out of Judah by the word of
		YHWH to Bethel: and Jeroboam stood by the altar to burn incense.
	}
}
{
}

\Verse{2}
{
	\hX{
		וַיִּקְרָא עַל־הַמִּזְבֵּחַ בִּדְבַר יְהֹוָה וַיֹּאמֶר מִזְבֵּחַ מִזְבֵּחַ כֹּה אָמַר יְהֹוָה הִנֵּה־בֵן נוֹלָד לְבֵית־דָּוִד יֹאשִׁיָּהוּ שְׁמוֹ וְזָבַח עָלֶיךָ אֶת־כֹּהֲנֵי
		הַבָּמוֹת הַמַּקְטִרִים עָלֶיךָ וְעַצְמוֹת אָדָם יִשְׂרְפוּ עָלֶיךָ׃
	}
}
{
	\eX{
		And he cried against the altar in the word of YHWH, and said, O
		altar, altar, thus says YHWH: Here: a child shall be born to the
		house of David, Josiah by name: and on you shall he offer the
		priests of the high places that burn incense on you, and men's
		bones shall be burnt on you.
	}
}
{
}

\Verse{3}
{
	\hX{וְנָתַן בַּיּוֹם הַהוּא מוֹפֵת לֵאמֹר זֶה הַמּוֹפֵת אֲשֶׁר דִּבֶּר יְהֹוָה הִנֵּה הַמִּזְבֵּחַ נִקְרָע וְנִשְׁפַּךְ הַדֶּשֶׁן אֲשֶׁר־עָלָיו׃}
}
{
	\eX{
		And he gave a sign the same day, saying, This is the sign which
		YHWH has spoken: Here: the altar shall be tore, and the ashes
		that are on it shall be poured out.
	}
}
{
}

\Verse{4}
{
	\hX{
		וַיְהִי כִשְׁמֹעַ הַמֶּלֶךְ אֶת־דְּבַר אִישׁ־הָאֱלֹהִים אֲשֶׁר קָרָא עַל־הַמִּזְבֵּחַ בְּבֵית־אֵל וַיִּשְׁלַח יָרבְעָם אֶת־יָדוֹ מֵעַל הַמִּזְבֵּחַ לֵאמֹר תִּפְשֻׂהוּ וַתִּיבַשׁ
		יָדוֹ אֲשֶׁר שָׁלַח עָלָיו וְלֹא יָכֹל לַהֲשִׁיבָהּ אֵלָיו׃
	}
}
{
	\eX{
		And it was when king Jeroboam heard the saying of the man of
		God, which had cried against the altar in Bethel, that he put
		forth his hand from the altar, saying, Lay hold on him. And his
		hand, that he put forth against him, dried up, so that he could
		not pull it in again to him.
	}
}
{
}

\Verse{5}
{
	\hX{וְהַמִּזְבֵּחַ נִקְרָע וַיִּשָּׁפֵךְ הַדֶּשֶׁן מִן־הַמִּזְבֵּחַ כַּמּוֹפֵת אֲשֶׁר נָתַן אִישׁ הָאֱלֹהִים בִּדְבַר יְהֹוָה׃}
}
{
	\eX{
		The altar also was tore, and the ashes poured out from the
		altar, according to the sign which the man of God had given by
		the word of YHWH.
	}
}
{
}

\Verse{6}
{
	\hX{

		וַתָּשׁב יַד־הַמֶּלֶךְ אֵלָיו וַתְּהִי כְּבָרִאשֹׁנָה׃
	}
}
{
	\eX{
		And the king answered and said to the man of God, Intreat now
		the face of YHWH your God, and pray for me, that my hand may be
		restored me again. And the man of God besought YHWH, and the
		king's hand was restored him again, and became as it was before.
	}
}
{
}

\Verse{7}
{
	\hX{וַיְדַבֵּר הַמֶּלֶךְ אֶל־אִישׁ הָאֱלֹהִים בֹּאָה־אִתִּי הַבַּיְתָה וּסְעָדָה וְאֶתְּנָה לְךָ מַתָּת׃}
}
{
	\eX{
		And the king said to the man of God, Come home with me, and

{

\Verse{8}
{
	\hX{וַיֹּאמֶר אִישׁ־הָאֱלֹהִים אֶל־הַמֶּלֶךְ אִם־תִּתֶּן־לִי אֶת־חֲצִי בֵיתֶךָ לֹא אָבֹא עִמָּךְ וְלֹא־אֹכַל לֶחֶם וְלֹא אֶשְׁתֶּה־מַּיִם בַּמָּקוֹם הַזֶּה׃}
}
{
	\eX{
		And the man of God said to the king, If you'll give me half your

}
{
}

\Verse{9}

	\hX{כִּי־כֵן צִוָּה אֹתִי בִּדְבַר יְהֹוָה לֵאמֹר לֹא־תֹאכַל לֶחֶם וְלֹא תִשְׁתֶּה־מָּיִם וְלֹא תָשׁוּב בַּדֶּרֶךְ אֲשֶׁר הָלָכְתָּ׃}
}
{
	\eX{

	\hX{וַיֵּלֶךְ בְּדֶרֶךְ אַחֵר וְלֹא־שָׁב בַּדֶּרֶךְ אֲשֶׁר בָּא בָהּ אֶל־בֵּית־אֵל׃}
}

\Verse{11}

	\eX{

	}
}
{
}

}

	\eX{

{

\Verse{28}
{
	\hX{וַיֵּלֶךְ וַיִּמְצָא אֶת־נִבְלָתוֹ מֻשְׁלֶכֶת בַּדֶּרֶךְ וַחֲמוֹר וְהָאַרְיֵה עֹמְדִים אֵצֶל הַנְּבֵלָה לֹא־אָכַל הָאַרְיֵה אֶת־הַנְּבֵלָה וְלֹא שָׁבַר אֶת־הַחֲמוֹר׃}
}
{
	\eX{
		And he went and found his carcass cast in the way, and the
		donkey and the lion standing by the carcass: the lion had not
		eaten the carcass, nor torn the donkey.
	}
}
{
}

\Verse{29}
{
	\hX{וַיִּשָּׂא הַנָּבִיא אֶת־נִבְלַת אִישׁ־הָאֱלֹהִים וַיַּנִּחֵהוּ אֶל־הַחֲמוֹר וַיְשִׁיבֵהוּ וַיָּבֹא אֶל־עִיר הַנָּבִיא הַזָּקֵן לִסְפֹּד וּלְקבְרוֹ׃}
}
{
	\eX{
		And the prophet took up the carcass of the man of God, and laid
		it on the donkey, and brought it back: and the old prophet came
		to the city, to mourn and to bury him.
	}
}
{
}

\Verse{30}
{
	\hX{וַיַּנַּח אֶת־נִבְלָתוֹ בְּקִבְרוֹ וַיִּסְפְּדוּ עָלָיו הוֹי אָחִי׃}
}
{
	\eX{
		And he laid his carcass in his own grave: and they mourned over
		him, saying, Alas, my brother!
	}
}
{
}

\Verse{31}
{
	\hX{וַיְהִי אַחֲרֵי קבְרוֹ אֹתוֹ וַיֹּאמֶר אֶל־בָּנָיו לֵאמֹר בְּמוֹתִי וּקְבַרְתֶּם אֹתִי בַּקֶּבֶר אֲשֶׁר אִישׁ הָאֱלֹהִים קָבוּר בּוֹ אֵצֶל עַצְמֹתָיו הַנִּיחוּ אֶת־עַצְמֹתָי׃}
}
{
	\eX{
		And it was, after he had buried him, that he spoke to his sons,
		saying, When I am dead, then bury me in the grave in which the
		man of God is buried: lay my bones beside his bones:
	}
}
{
}

\Verse{32}
{
	\hX{כִּי הָיֹה יִהְיֶה הַדָּבָר אֲשֶׁר קָרָא בִּדְבַר יְהֹוָה עַל־הַמִּזְבֵּחַ אֲשֶׁר בְּבֵית־אֵל וְעַל כּל־בָּתֵּי הַבָּמוֹת אֲשֶׁר בְּעָרֵי שֹׁמְרוֹן׃}
}
{
	\eX{
		For the saying that he cried by the word of YHWH against the
		altar in Bethel, and against all the houses of the high places
		which are in the cities of Samaria, shall surely come to pass.
	}
}
{
}

\Verse{33}
{
	\hX{אַחַר הַדָּבָר הַזֶּה לֹא־שָׁב יָרבְעָם מִדַּרְכּוֹ הָרָעָה וַיָּשׁב וַיַּעַשׂ מִקְצוֹת הָעָם כֹּהֲנֵי בָמוֹת הֶחָפֵץ יְמַלֵּא אֶת־יָדוֹ וִיהִי כֹּהֲנֵי בָמוֹת׃}
}
{
	\eX{
		After this thing Jeroboam returned not from his bad way, but
		made again of the lowest of the people priests of the high
		places: whoever would, he consecrated him, and he became one of
		the priests of the high places.
	}
}
{
}

\Verse{34}
{
	\hX{וַיְהִי בַּדָּבָר הַזֶּה לְחַטַּאת בֵּית יָרבְעָם וּלְהַכְחִיד וּלְהַשְׁמִיד מֵעַל פְּנֵי הָאֲדָמָה׃}
}
{
	\eX{
		And this thing became sin to the house of Jeroboam, even to cut
		it off, and to destroy it from off the face of the earth.
	}
}
{
}
