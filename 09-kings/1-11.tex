}
{
	\eX{

	\hX{וַיֹּאמֶר לְיָרבְעָם קַח־לְךָ עֲשָׂרָה קְרָעִים כִּי כֹה אָמַר יְהֹוָה אֱלֹהֵי יִשְׂרָאֵל הִנְנִי קֹרֵעַ אֶת־הַמַּמְלָכָה מִיַּד שְׁלֹמֹה וְנָתַתִּי לְךָ אֵת עֲשָׂרָה הַשְּׁבָטִים׃}
}
{
	\eX{
		And he said to Jeroboam, Take you ten pieces: for thus says
		YHWH, the God of Israel, Here: I'll rend the kingdom out of the
		hand of Solomon, and will give ten tribes to you:
	}
}
{
}

\Verse{32}
{
	\hX{וְהַשֵּׁבֶט הָאֶחָד יִהְיֶה־לּוֹ לְמַעַן עַבְדִּי דָוִד וּלְמַעַן יְרוּשָׁלַ͏ִם הָעִיר אֲשֶׁר בָּחַרְתִּי בָהּ מִכֹּל שִׁבְטֵי יִשְׂרָאֵל׃}
}
{
	\eX{
		(But he shall have one tribe for my servant David's sake, and
		for Jerusalem's sake, the city that I have chosen out of all the
		tribes of Israel:)
	}
}
{
}

\Verse{33}
{
	\hX{
		יַעַן אֲשֶׁר עֲזָבוּנִי וַיִּשְׁתַּחֲווּ לְעַשְׁתֹּרֶת אֱלֹהֵי צִדֹנִין לִכְמוֹשׁ אֱלֹהֵי מוֹאָב וּלְמִלְכֹּם אֱלֹהֵי בְנֵי־עַמּוֹן וְלֹא־הָלְכוּ בִדְרָכַי לַעֲשׂוֹת הַיָּשָׁר
		בְּעֵינַי וְחֻקֹּתַי וּמִשְׁפָּטַי כְּדָוִד אָבִיו׃
	}
}
{
	\eX{
		Because that they have forsaken me, and have worshipped
		Ashtoreth the goddess of the Zidonians, Chemosh the god of the
		Moabites, and Milcom the god of the children of Ammon, and have
		not walked in my ways, to do that which is right in my eyes, and
		to keep my statutes and my judgments, as did David his father.
	}
}
{
}

\Verse{34}
{
	\hX{וְלֹא־אֶקַּח אֶת־כּל־הַמַּמְלָכָה מִיָּדוֹ כִּי נָשִׂיא אֲשִׁתֶנּוּ כֹּל יְמֵי חַיָּיו לְמַעַן דָּוִד עַבְדִּי אֲשֶׁר בָּחַרְתִּי אֹתוֹ אֲשֶׁר שָׁמַר מִצְוֺתַי וְחֻקֹּתָי׃}
}
{
	\eX{
		But I'll not take the whole kingdom out of his hand: but I'll
		make him prince all the days of his life for David my servant's
		sake, whom I chose, because he kept my commandments and my
		statutes:
	}
}
{
}

\Verse{35}

}
{
	\eX{

	}
}
{
}

\Verse{36}
{
	\hX{וְלִבְנוֹ אֶתֵּן שֵׁבֶט־אֶחָד לְמַעַן הֱיוֹת־נִיר לְדָוִיד־עַבְדִּי כּל־הַיָּמִים לְפָנַי בִּירוּשָׁלַ͏ִם הָעִיר אֲשֶׁר בָּחַרְתִּי לִי לָשׂוּם שְׁמִי שָׁם׃}
}
{
	\eX{
		And to his son will I give one tribe, that David my servant may
		have a light alway before me in Jerusalem, the city that I have
		chosen me to put my name there.
	}
}
{
}

\Verse{37}
{
	\hX{וְאֹתְךָ אֶקַּח וּמָלַכְתָּ בְּכֹל אֲשֶׁר־תְּאַוֶּה נַפְשֶׁךָ וְהָיִיתָ מֶּלֶךְ עַל־יִשְׂרָאֵל׃}
}
{
	\eX{
		And I'll take you, and you shall reign according to all that

	}
}
{
}

\Verse{38}
{
	\hX{
		וְהָיָה אִם־תִּשְׁמַע אֶת־כּל־אֲשֶׁר אֲצַוֶּךָ וְהָלַכְתָּ בִדְרָכַי וְעָשִׂיתָ הַיָּשָׁר בְּעֵינַי לִשְׁמוֹר חֻקּוֹתַי וּמִצְוֺתַי כַּאֲשֶׁר עָשָׂה דָּוִד עַבְדִּי וְהָיִיתִי
		עִמָּךְ וּבָנִיתִי לְךָ בַיִת־נֶאֱמָן כַּאֲשֶׁר בָּנִיתִי לְדָוִד וְנָתַתִּי לְךָ אֶת־יִשְׂרָאֵל׃
	}
}
{
	\eX{
		And it shall be, if you'll listen to all that I command, and
		will walk in my ways, and do that is right in my sight, to keep
		my statutes and my commandments, as David my servant did: that
		I'll be with you, and build you a sure house, as I built for
		David, and will give Israel to you.
	}
}
{
}
