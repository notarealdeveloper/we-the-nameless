\Chapter{12}

\Verse{1}
{
	\hX{בִּשְׁנַת־שֶׁבַע לְיֵהוּא מָלַךְ יְהוֹאָשׁ וְאַרְבָּעִים שָׁנָה מָלַךְ בִּירוּשָׁלָ͏ִם וְשֵׁם אִמּוֹ צִבְיָה מִבְּאֵר שָׁבַע׃}
}
{
	\eX{
		In the seventh year of Jehu Jehoash began to reign: and forty
		years reigned he in Jerusalem. And his mother's name was Zibiah
		of Beersheba.
	}
}
{
}

\Verse{2}
{
	\hX{וַיַּעַשׂ יְהוֹאָשׁ הַיָּשָׁר בְּעֵינֵי יְהֹוָה כּל־יָמָיו אֲשֶׁר הוֹרָהוּ יְהוֹיָדָע הַכֹּהֵן׃}
}
{
	\eX{
		And Jehoash did that that was right in the eyes of YHWH all his
		days wherein Jehoiada the priest instructed him.
	}
}
{
}

\Verse{3}
{
	\hX{רַק הַבָּמוֹת לֹא־סָרוּ עוֹד הָעָם מְזַבְּחִים וּמְקַטְּרִים בַּבָּמוֹת׃}
}
{
	\eX{
		But the high places were not taken away: the people still
		sacrificed and burned incense in the high places.
	}
}
{
}

\Verse{4}
{
	\hX{
		וַיֹּאמֶר יְהוֹאָשׁ אֶל־הַכֹּהֲנִים כֹּל כֶּסֶף הַקֳּדָשִׁים אֲשֶׁר־יוּבָא בֵית־יְהֹוָה כֶּסֶף עוֹבֵר אִישׁ כֶּסֶף נַפְשׁוֹת עֶרְכּוֹ כּל־כֶּסֶף אֲשֶׁר יַעֲלֶה עַל לֶב־אִישׁ
		לְהָבִיא בֵּית יְהֹוָה׃
	}
}
{
	\eX{
		And Jehoash said to the priests, All the money of the dedicated
		things that is brought into the house of YHWH, even the money of
		every one that passes the account, the money that every man is
		set at, and all the money that comes into any man's heart to
		bring into the house of YHWH,
	}
}
{
}

\Verse{5}
{
	\hX{יִקְחוּ לָהֶם הַכֹּהֲנִים אִישׁ מֵאֵת מַכָּרוֹ וְהֵם יְחַזְּקוּ אֶת־בֶּדֶק הַבַּיִת לְכֹל אֲשֶׁר־יִמָּצֵא שָׁם בָּדֶק׃}
}
{
	\eX{
		Let the priests take it to them, every man of his acquaintance:
		and let them repair the breaches of the house, wheresoever any
		breach shall be found.
	}
}
{
}

\Verse{6}
{
	\hX{וַיְהִי בִּשְׁנַת עֶשְׂרִים וְשָׁלֹשׁ שָׁנָה לַמֶּלֶךְ יְהוֹאָשׁ לֹא־חִזְּקוּ הַכֹּהֲנִים אֶת־בֶּדֶק הַבָּיִת׃}
}
{
	\eX{
		But it was so, that in the three and twentieth year of king
		Jehoash the priests had not repaired the breaches of the house.
	}
}
{
}

\Verse{7}
{
	\hX{
		וַיִּקְרָא הַמֶּלֶךְ יְהוֹאָשׁ לִיהוֹיָדָע הַכֹּהֵן וְלַכֹּהֲנִים וַיֹּאמֶר אֲלֵהֶם מַדּוּעַ אֵינְכֶם מְחַזְּקִים אֶת־בֶּדֶק הַבָּיִת וְעַתָּה אַל־תִּקְחוּ־כֶסֶף מֵאֵת מַכָּרֵיכֶם
		כִּי־לְבֶדֶק הַבַּיִת תִּתְּנֻהוּ׃
	}
}
{
	\eX{
		And king Jehoash called for Jehoiada the priest, and the other
		priests, and said to them, Why repair you not the breaches of
		the house? now therefore receive no more money of your
		acquaintance, but deliver it for the breaches of the house.
	}
}
{
}

\Verse{8}
{
	\hX{וַיֵּאֹתוּ הַכֹּהֲנִים לְבִלְתִּי קְחַת־כֶּסֶף מֵאֵת הָעָם וּלְבִלְתִּי חַזֵּק אֶת־בֶּדֶק הַבָּיִת׃}
}
{
	\eX{
		And the priests consented to receive no more money of the
		people, neither to repair the breaches of the house.
	}
}
{
}

\Verse{9}
{
	\hX{
		וַיִּקַּח יְהוֹיָדָע הַכֹּהֵן אֲרוֹן אֶחָד וַיִּקֹּב חֹר בְּדַלְתּוֹ וַיִּתֵּן אֹתוֹ אֵצֶל הַמִּזְבֵּחַ (בימין) [מִיָּמִין] בְּבוֹא־אִישׁ בֵּית יְהֹוָה וְנָתְנוּ־שָׁמָּה
		הַכֹּהֲנִים שֹׁמְרֵי הַסַּף אֶת־כּל־הַכֶּסֶף הַמּוּבָא בֵית־יְהֹוָה׃
	}
}
{
	\eX{
		But Jehoiada the priest took a chest, and bored a hole in the
		lid of it, and set it beside the altar, on the right side as one
		comes into the house of YHWH: and the priests that kept the door
		put in it all the money that was brought into the house of YHWH.
	}
}
{
}

\Verse{10}
{
	\hX{וַיְהִי כִּרְאוֹתָם כִּי־רַב הַכֶּסֶף בָּאָרוֹן וַיַּעַל סֹפֵר הַמֶּלֶךְ וְהַכֹּהֵן הַגָּדוֹל וַיָּצֻרוּ וַיִּמְנוּ אֶת־הַכֶּסֶף הַנִּמְצָא בֵית־יְהֹוָה׃}
}
{
	\eX{
		And it was so, when they saw that there was much money in the
		chest, that the king's scribe and the high priest came up, and
		they put up in bags, and told the money that was found in the
		house of YHWH.
	}
}
{
}

\Verse{11}
{
	\hX{וְנָתְנוּ אֶת־הַכֶּסֶף הַמְתֻכָּן עַל־[יְדֵי] (יד) עֹשֵׂי הַמְּלָאכָה (הפקדים) [הַמֻּפְקָדִים] בֵּית יְהֹוָה וַיּוֹצִיאֻהוּ לְחָרָשֵׁי הָעֵץ וְלַבֹּנִים הָעֹשִׂים בֵּית יְהֹוָה׃}
}
{
	\eX{
		And they gave the money, being told, into the hands of them that
		did the work, that had the oversight of the house of YHWH: and
		they laid it out to the carpenters and builders, who worked on
		the house of YHWH,
	}
}
{
}

\Verse{12}
{
	\hX{וְלַגֹּדְרִים וּלְחֹצְבֵי הָאֶבֶן וְלִקְנוֹת עֵצִים וְאַבְנֵי מַחְצֵב לְחַזֵּק אֶת־בֶּדֶק בֵּית־יְהֹוָה וּלְכֹל אֲשֶׁר־יֵצֵא עַל־הַבַּיִת לְחזְקָה׃}
}
{
	\eX{
		And to masons, and hewers of stone, and to buy timber and hewed
		stone to repair the breaches of the house of YHWH, and for all
		that was laid out for the house to repair it.
	}
}
{
}

\Verse{13}
{
	\hX{אַךְ לֹא יֵעָשֶׂה בֵּית יְהֹוָה סִפּוֹת כֶּסֶף מְזַמְּרוֹת מִזְרָקוֹת חֲצֹצְרוֹת כּל־כְּלִי זָהָב וּכְלִי־כָסֶף מִן־הַכֶּסֶף הַמּוּבָא בֵית־יְהֹוָה׃}
}
{
	\eX{
		Only there were not made for the house of YHWH bowls of silver,
		snuffers, basons, trumpets, any vessels of gold, or vessels of
		silver, of the money that was brought into the house of YHWH:
	}
}
{
}

\Verse{14}
{
	\hX{כִּי־לְעֹשֵׂי הַמְּלָאכָה יִתְּנֻהוּ וְחִזְּקוּ־בוֹ אֶת־בֵּית יְהֹוָה׃}
}
{
	\eX{
		But they gave that to the workmen, and repaired with it the
		house of YHWH.
	}
}
{
}

\Verse{15}
{
	\hX{וְלֹא יְחַשְּׁבוּ אֶת־הָאֲנָשִׁים אֲשֶׁר יִתְּנוּ אֶת־הַכֶּסֶף עַל־יָדָם לָתֵת לְעֹשֵׂי הַמְּלָאכָה כִּי בֶאֱמֻנָה הֵם עֹשִׂים׃}
}
{
	\eX{
		And they reckoned not with the men, into whose hand they
		delivered the money to be bestowed on workmen: for they dealt
		faithfully.
	}
}
{
}

\Verse{16}
{
	\hX{כֶּסֶף אָשָׁם וְכֶסֶף חַטָּאוֹת לֹא יוּבָא בֵּית יְהֹוָה לַכֹּהֲנִים יִהְיוּ׃}
}
{
	\eX{
		The trespass money and sin money was not brought into the house
		of YHWH: it was the priests'.
	}
}
{
}

\Verse{17}
{
	\hX{אָז יַעֲלֶה חֲזָאֵל מֶלֶךְ אֲרָם וַיִּלָּחֶם עַל־גַּת וַיִּלְכְּדָהּ וַיָּשֶׂם חֲזָאֵל פָּנָיו לַעֲלוֹת עַל־יְרוּשָׁלָ͏ִם׃}
}
{
	\eX{
		And Hazael king of Aram went up, and fought against Gath, and
		took it: and Hazael set his face to go up to Jerusalem.
	}
}
{
}

\Verse{18}
{
	\hX{
		וַיִּקַּח יְהוֹאָשׁ מֶלֶךְ־יְהוּדָה אֵת כּל־הַקֳּדָשִׁים אֲשֶׁר־הִקְדִּישׁוּ יְהוֹשָׁפָט וִיהוֹרָם וַאֲחַזְיָהוּ אֲבֹתָיו מַלְכֵי יְהוּדָה וְאֶת־קֳדָשָׁיו וְאֵת כּל־הַזָּהָב
		הַנִּמְצָא בְּאֹצְרוֹת בֵּית־יְהֹוָה וּבֵית הַמֶּלֶךְ וַיִּשְׁלַח לַחֲזָאֵל מֶלֶךְ אֲרָם וַיַּעַל מֵעַל יְרוּשָׁלָ͏ִם׃
	}
}
{
	\eX{
		And Jehoash king of Judah took all the hallowed things that
		Jehoshaphat, and Jehoram, and Ahaziah, his fathers, kings of
		Judah, had dedicated, and his own hallowed things, and all the
		gold that was found in the treasures of the house of YHWH, and
		in the king's house, and sent it to Hazael king of Aram: and he
		went away from Jerusalem.
	}
}
{
}

\Verse{19}
{
	\hX{וְיֶתֶר דִּבְרֵי יוֹאָשׁ וְכל־אֲשֶׁר עָשָׂה הֲלוֹא־הֵם כְּתוּבִים עַל־סֵפֶר דִּבְרֵי הַיָּמִים לְמַלְכֵי יְהוּדָה׃}
}
{
	\eX{
		And the rest of the acts of Joash, and all that he did, are they
		not written in the book of the chronicles of the kings of Judah?
	}
}
{
}

\Verse{20}
{
	\hX{וַיָּקֻמוּ עֲבָדָיו וַיִּקְשְׁרוּ־קָשֶׁר וַיַּכּוּ אֶת־יוֹאָשׁ בֵּית מִלֹּא הַיֹּרֵד סִלָּא׃}
}
{
	\eX{
		And his servants arose, and made a conspiracy, and killed Joash
		in the house of Millo, that goes down to Silla.
	}
}
{
}

\Verse{21}
{
	\hX{וְיוֹזָכָר בֶּן־שִׁמְעָת וִיהוֹזָבָד בֶּן־שֹׁמֵר עֲבָדָיו הִכֻּהוּ וַיָּמֹת וַיִּקְבְּרוּ אֹתוֹ עִם־אֲבֹתָיו בְּעִיר דָּוִד וַיִּמְלֹךְ אֲמַצְיָה בְנוֹ תַּחְתָּיו׃}
}
{
	\eX{
		For Jozachar the son of Shimeath, and Jehozabad the son of
		Shomer, his servants, struck him, and he died: and they buried
		him with his fathers in the city of David: and Amaziah his son
		reigned in his place.
	}
}
{
}
