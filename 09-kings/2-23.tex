	\hX{כִּי לֹא נַעֲשָׂה כַּפֶּסַח הַזֶּה מִימֵי הַשֹּׁפְטִים אֲשֶׁר שָׁפְטוּ אֶת־יִשְׂרָאֵל וְכֹל יְמֵי מַלְכֵי יִשְׂרָאֵל וּמַלְכֵי יְהוּדָה׃}
}
{
	\eX{
		Surely there was not held such a passover from the days of the
		judges that judged Israel, nor in all the days of the kings of
		Israel, nor of the kings of Judah:
	}
}
{
}

\Verse{23}
{
	\hX{כִּי אִם־בִּשְׁמֹנֶה עֶשְׂרֵה שָׁנָה לַמֶּלֶךְ יֹאשִׁיָּהוּ נַעֲשָׂה הַפֶּסַח הַזֶּה לַיהֹוָה בִּירוּשָׁלָ͏ִם׃}
}
{
	\eX{
		But in the eighteenth year of king Josiah, wherein this passover
		was held to YHWH in Jerusalem.
	}
}
{
}

\Verse{24}
{
	\hX{
		וְגַם אֶת־הָאֹבוֹת וְאֶת־הַיִּדְּעֹנִים וְאֶת־הַתְּרָפִים וְאֶת־הַגִּלֻּלִים וְאֵת כּל־הַשִּׁקֻּצִים אֲשֶׁר נִרְאוּ בְּאֶרֶץ יְהוּדָה וּבִירוּשָׁלַ͏ִם בִּעֵר יֹאשִׁיָּהוּ לְמַעַן
		הָקִים אֶת־דִּבְרֵי הַתּוֹרָה הַכְּתֻבִים עַל־הַסֵּפֶר אֲשֶׁר מָצָא חִלְקִיָּהוּ הַכֹּהֵן בֵּית יְהֹוָה׃
	}
}
{
	\eX{
		And the workers with ghosts, and the mediums, and the images,
		and the idols, and all the abominations that were saw in the
		land of Judah and in Jerusalem, did Josiah put away, that he
		might perform the words of the law that were written in the book
		that Hilkiah the priest found in the house of YHWH.
	}
}
{
}

\Verse{25}
{
	\hX{וְכָמֹהוּ לֹא־הָיָה לְפָנָיו מֶלֶךְ אֲשֶׁר־שָׁב אֶל־יְהֹוָה בְּכל־לְבָבוֹ וּבְכל־נַפְשׁוֹ וּבְכל־מְאֹדוֹ כְּכֹל תּוֹרַת מֹשֶׁה וְאַחֲרָיו לֹא־קָם כָּמֹהוּ׃}
}
{
	\eX{
		And like to him was there no king in front of him, that turned
		to YHWH with all his heart, and with all his soul, and with all
		his might, according to all the law of Moses: neither after him
		arose there any like him.
	}
}
{
}

\Verse{26}
{
	\hX{אַךְ לֹא־שָׁב יְהֹוָה מֵחֲרוֹן אַפּוֹ הַגָּדוֹל אֲשֶׁר־חָרָה אַפּוֹ בִּיהוּדָה עַל כּל־הַכְּעָסִים אֲשֶׁר הִכְעִיסוֹ מְנַשֶּׁה׃}
}
{
	\eX{
		Still YHWH didn't turn from the fierceness of his great wrath,
		with which his anger was kindled against Judah, because of all
		the provocations that Manasseh had provoked him with it.
	}
}
{
}

\Verse{27}
{
	\hX{
		וַיֹּאמֶר יְהֹוָה גַּם אֶת־יְהוּדָה אָסִיר מֵעַל פָּנַי כַּאֲשֶׁר הֲסִרֹתִי אֶת־יִשְׂרָאֵל וּמָאַסְתִּי אֶת־הָעִיר הַזֹּאת אֲשֶׁר־בָּחַרְתִּי אֶת־יְרוּשָׁלַ͏ִם וְאֶת־הַבַּיִת
		אֲשֶׁר אָמַרְתִּי יִהְיֶה שְׁמִי שָׁם׃
	}
}
{
	\eX{
		And YHWH said, I'll remove Judah also out of my sight, as I have
		removed Israel, and will cast off this city Jerusalem that I
		have chosen, and the house of that I said, My name shall be
		there.
	}
}
{
}

\Verse{29}
{
	\hX{בְּיָמָיו עָלָה פַרְעֹה נְכֹה מֶלֶךְ־מִצְרַיִם עַל־מֶלֶךְ אַשּׁוּר עַל־נְהַר־פְּרָת וַיֵּלֶךְ הַמֶּלֶךְ יֹאשִׁיָּהוּ לִקְרָאתוֹ וַיְמִיתֵהוּ בִּמְגִדּוֹ כִּרְאֹתוֹ אֹתוֹ׃}
}
{
	\eX{
		In his days Pharaohnechoh king of Egypt went up against the king

	}
}
{
}

\Verse{30}
{
	\hX{
		וַיַּרְכִּבֻהוּ עֲבָדָיו מֵת מִמְּגִדּוֹ וַיְבִאֻהוּ יְרוּשָׁלַ͏ִם וַיִּקְבְּרֻהוּ בִּקְבֻרָתוֹ וַיִּקַּח עַם־הָאָרֶץ אֶת־יְהוֹאָחָז בֶּן־יֹאשִׁיָּהוּ וַיִּמְשְׁחוּ אֹתוֹ

	}
}
{
	\eX{
		And his servants carried him in a chariot dead from Megiddo, and
		brought him to Jerusalem, and buried him in his own grave. And
		the people of the land took Jehoahaz the son of Josiah, and
		anointed him, and made him king in his father's place.
	}
}
{
}
