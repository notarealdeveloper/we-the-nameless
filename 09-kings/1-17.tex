\Chapter{17}

\Verse{1}

	\hX{
		וַיֹּאמֶר אֵלִיָּהוּ הַתִּשְׁבִּי מִתֹּשָׁבֵי גִלְעָד אֶל־אַחְאָב חַי־יְהֹוָה אֱלֹהֵי יִשְׂרָאֵל אֲשֶׁר עָמַדְתִּי לְפָנָיו אִם־יִהְיֶה הַשָּׁנִים הָאֵלֶּה טַל וּמָטָר כִּי
		אִם־לְפִי דְבָרִי׃
	}
}
{
	\eX{
		Elijah the Tishbite, an inhabitant of Gilead, said to Ahab, “As
		YHWH lives, the God of Israel whom I serve, there will be no dew
		or rain except at my bidding.”
	}
}
{
}

}
{
	\eX{
		He proceeded to do as YHWH had bidden: he went, and he stayed by

\Verse{7}

	\hX{וַיְהִי מִקֵּץ יָמִים וַיִּיבַשׁ הַנָּחַל כִּי לֹא־הָיָה גֶשֶׁם בָּאָרֶץ׃}
}

	\eX{

		the land.
	}
}
{
}

\Verse{8}
{
	\hX{וַיְהִי דְבַר־יְהֹוָה אֵלָיו לֵאמֹר׃}

}

\Verse{9}

	\hX{קוּם לֵךְ צָרְפַתָה אֲשֶׁר לְצִידוֹן וְיָשַׁבְתָּ שָׁם הִנֵּה צִוִּיתִי שָׁם אִשָּׁה אַלְמָנָה לְכַלְכְּלֶךָ׃}
}
{
	\eX{

	}
}
{
}

\Verse{10}
{
	\hX{
		וַיָּקם וַיֵּלֶךְ צָרְפַתָה וַיָּבֹא אֶל־פֶּתַח הָעִיר וְהִנֵּה־שָׁם אִשָּׁה אַלְמָנָה מְקֹשֶׁשֶׁת עֵצִים וַיִּקְרָא אֵלֶיהָ וַיֹּאמַר קְחִי־נָא לִי מְעַט־מַיִם בַּכְּלִי
		וְאֶשְׁתֶּה׃
	}
}
{
	\eX{
		So he went at once to Zarephath. When he came to the entrance of
		the town, a widow was there gathering wood. He called out to her,
		“Please bring me a little water in your pitcher, and let me
		drink.”
	}
}
{
}

\Verse{11}
{
	\hX{וַתֵּלֶךְ לָקַחַת וַיִּקְרָא אֵלֶיהָ וַיֹּאמַר לִקְחִי־נָא לִי פַּת־לֶחֶם בְּיָדֵךְ׃}
}
{
	\eX{

		a piece of bread for me.”
	}
}
{
}

\Verse{12}

	\hX{
		וַתֹּאמֶר חַי־יְהֹוָה אֱלֹהֶיךָ אִם־יֶשׁ־לִי מָעוֹג כִּי אִם־מְלֹא כַף־קֶמַח בַּכַּד וּמְעַט־שֶׁמֶן בַּצַּפָּחַת וְהִנְנִי מְקֹשֶׁשֶׁת שְׁנַיִם עֵצִים וּבָאתִי וַעֲשִׂיתִיהוּ לִי
		וְלִבְנִי וַאֲכַלְנֻהוּ וָמָתְנוּ׃
	}
}
{
	\eX{
		“As YHWH your God lives,” she replied, “I have nothing baked,
		nothing but a handful of flour in a jar and a little oil in a jug.
		I am just gathering a couple of sticks, so that I can go home and
		prepare it for me and my son; we shall eat it and then we shall
		die.”
	}
}
{
}

\Verse{13}
{
	\hX{וַיֹּאמֶר אֵלֶיהָ אֵלִיָּהוּ אַל־תִּירְאִי בֹּאִי עֲשִׂי כִדְבָרֵךְ אַךְ עֲשִׂי־לִי־מִשָּׁם עֻגָה קְטַנָּה בָרִאשֹׁנָה וְהוֹצֵאת לִי וְלָךְ וְלִבְנֵךְ תַּעֲשִׂי בָּאַחֲרֹנָה׃}
}
{
	\eX{
		“Don’t be afraid,” said Elijah to her. “Go and do as you have
		said; but first make me a small cake from what you have there, and
		bring it out to me; then make some for yourself and your son.
	}
}
{
}

\Verse{14}
{
	\hX{כִּי כֹה אָמַר יְהֹוָה אֱלֹהֵי יִשְׂרָאֵל כַּד הַקֶּמַח לֹא תִכְלָה וְצַפַּחַת הַשֶּׁמֶן לֹא תֶחְסָר עַד יוֹם (תתן) [תֵּת־]יְהֹוָה גֶּשֶׁם עַל־פְּנֵי הָאֲדָמָה׃}
}
{
	\eX{
