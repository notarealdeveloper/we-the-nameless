\Chapter{21}

\Verse{1}
{
	\hX{בֶּן־שְׁתֵּים עֶשְׂרֵה שָׁנָה מְנַשֶּׁה בְמלְכוֹ וַחֲמִשִּׁים וְחָמֵשׁ שָׁנָה מָלַךְ בִּירוּשָׁלָ͏ִם וְשֵׁם אִמּוֹ חֶפְצִי־בָהּ׃}
}
{
	\eX{
		Manasseh was twelve years old when he became king, and he reigned
		fifty-five years in Jerusalem; his mother’s name was Hephzibah.
	}
}
{
}

\Verse{2}
{
	\hX{וַיַּעַשׂ הָרַע בְּעֵינֵי יְהֹוָה כְּתוֹעֲבֹת הַגּוֹיִם אֲשֶׁר הוֹרִישׁ יְהֹוָה מִפְּנֵי בְּנֵי יִשְׂרָאֵל׃}
}
{
	\eX{
		He did what was displeasing to YHWH, following the abhorrent
		practices of the nations that YHWH had dispossessed before the
		Israelites.
	}
}
{
}

\Verse{3}
{
	\hX{
		וַיָּשׁב וַיִּבֶן אֶת־הַבָּמוֹת אֲשֶׁר אִבַּד חִזְקִיָּהוּ אָבִיו וַיָּקֶם מִזְבְּחֹת לַבַּעַל וַיַּעַשׂ אֲשֵׁרָה כַּאֲשֶׁר עָשָׂה אַחְאָב מֶלֶךְ יִשְׂרָאֵל וַיִּשְׁתַּחוּ
		לְכל־צְבָא הַשָּׁמַיִם וַיַּעֲבֹד אֹתָם׃
	}
}
{
	\eX{
		He rebuilt the shrines that his father Hezekiah had destroyed; he
		erected altars for Baal and made a sacred post, as King Ahab of
		Israel had done. He bowed down to all the host of heaven and
		worshiped them,
	}
}
{
}

\Verse{4}
{
	\hX{וּבָנָה מִזְבְּחֹת בְּבֵית יְהֹוָה אֲשֶׁר אָמַר יְהֹוָה בִּירוּשָׁלַ͏ִם אָשִׂים אֶת־שְׁמִי׃}
}
{
	\eX{
		and he built altars for them in the House of YHWH, of which YHWH
		had said, “I will establish My name in Jerusalem.”
	}
}
{
}

\Verse{5}
{
	\hX{וַיִּבֶן מִזְבְּחוֹת לְכל־צְבָא הַשָּׁמָיִם בִּשְׁתֵּי חַצְרוֹת בֵּית־יְהֹוָה׃}
}
{
	\eX{
		He built altars for all the hosts of heaven in the two courts of
		the House of YHWH.
	}
}
{
}

\Verse{6}
{
	\hX{וְהֶעֱבִיר אֶת־בְּנוֹ בָּאֵשׁ וְעוֹנֵן וְנִחֵשׁ וְעָשָׂה אוֹב וְיִדְּעֹנִים הִרְבָּה לַעֲשׂוֹת הָרַע בְּעֵינֵי יְהֹוָה לְהַכְעִיס׃}
}
{
	\eX{
		He consigned his son to the fire; he practiced soothsaying and
		divination, and consulted ghosts and familiar spirits; he did much
		that was displeasing to YHWH, to vex Him.
	}
}
{
}

\Verse{7}
{
	\hX{
		וַיָּשֶׂם אֶת־פֶּסֶל הָאֲשֵׁרָה אֲשֶׁר עָשָׂה בַּבַּיִת אֲשֶׁר אָמַר יְהֹוָה אֶל־דָּוִד וְאֶל־שְׁלֹמֹה בְנוֹ בַּבַּיִת הַזֶּה וּבִירוּשָׁלַ͏ִם אֲשֶׁר בָּחַרְתִּי מִכֹּל שִׁבְטֵי
		יִשְׂרָאֵל אָשִׂים אֶת־שְׁמִי לְעוֹלָם׃
	}
}
{
	\eX{
		The sculptured image of Asherah that he made he placed in the
		House concerning which YHWH had said to David and to his son
		Solomon, “In this House and in Jerusalem, which I chose out of all
		the tribes of Israel, I will establish My name forever.
	}
}
{
}

\Verse{8}
{
	\hX{
		וְלֹא אֹסִיף לְהָנִיד רֶגֶל יִשְׂרָאֵל מִן־הָאֲדָמָה אֲשֶׁר נָתַתִּי לַאֲבוֹתָם רַק אִם־יִשְׁמְרוּ לַעֲשׂוֹת כְּכֹל אֲשֶׁר צִוִּיתִים וּלְכל־הַתּוֹרָה אֲשֶׁר־צִוָּה אֹתָם עַבְדִּי
		מֹשֶׁה׃
	}
}
{
	\eX{
		And I will not again cause the feet of Israel to wander from the
		land that I gave to their fathers, if they will but faithfully
		observe all that I have commanded them—all the Teachings with
		which My servant Moses charged them.”
	}
}
{
}

\Verse{9}
{
	\hX{וְלֹא שָׁמֵעוּ וַיַּתְעֵם מְנַשֶּׁה לַעֲשׂוֹת אֶת־הָרָע מִן־הַגּוֹיִם אֲשֶׁר הִשְׁמִיד יְהֹוָה מִפְּנֵי בְּנֵי יִשְׂרָאֵל׃}
}
{
	\eX{
		But they did not obey, and Manasseh led them astray to do greater
		evil than the nations that YHWH had destroyed before the
		Israelites.
	}
}
{
}

\Verse{10}
{
	\hX{וַיְדַבֵּר יְהֹוָה בְּיַד־עֲבָדָיו הַנְּבִיאִים לֵאמֹר׃}
}
{
	\eX{Therefore YHWH spoke through His servants the prophets:}
}
{
}

\Verse{11}
{
	\hX{יַעַן אֲשֶׁר עָשָׂה מְנַשֶּׁה מֶלֶךְ־יְהוּדָה הַתֹּעֵבוֹת הָאֵלֶּה הֵרַע מִכֹּל אֲשֶׁר־עָשׂוּ הָאֱמֹרִי אֲשֶׁר לְפָנָיו וַיַּחֲטִא גַם־אֶת־יְהוּדָה בְּגִלּוּלָיו׃}
}
{
	\eX{
		“Because King Manasseh of Judah has done these abhorrent things—he
		has outdone in wickedness all that the Amorites did before his
		time—and because he led Judah to sin with his fetishes,
	}
}
{
}

\Verse{12}
{
	\hX{לָכֵן כֹּה־אָמַר יְהֹוָה אֱלֹהֵי יִשְׂרָאֵל הִנְנִי מֵבִיא רָעָה עַל־יְרוּשָׁלַ͏ִם וִיהוּדָה אֲשֶׁר כּל־[שֹׁמְעָהּ] (שמעיו) תִּצַּלְנָה שְׁתֵּי אזְנָיו׃}
}
{
	\eX{
		assuredly, thus said YHWH, the God of Israel: I am going to bring
		such a disaster on Jerusalem and Judah that both ears of everyone
		who hears about it will tingle.
	}
}
{
	Qere Ketiv.
}

\Verse{13}
{
	\hX{וְנָטִיתִי עַל־יְרוּשָׁלַ͏ִם אֵת קָו שֹׁמְרוֹן וְאֶת־מִשְׁקֹלֶת בֵּית אַחְאָב וּמָחִיתִי אֶת־יְרוּשָׁלַ͏ִם כַּאֲשֶׁר־יִמְחֶה אֶת־הַצַּלַּחַת מָחָה וְהָפַךְ עַל־פָּנֶיהָ׃}
}
{
	\eX{
		I will apply to Jerusalem the measuring line of Samaria and the
		weights of the House of Ahab; I will wipe Jerusalem clean as one
		wipes a dish and turns it upside down.
	}
}
{
}

\Verse{14}
{
	\hX{וְנָטַשְׁתִּי אֵת שְׁאֵרִית נַחֲלָתִי וּנְתַתִּים בְּיַד אֹיְבֵיהֶם וְהָיוּ לְבַז וְלִמְשִׁסָּה לְכל־אֹיְבֵיהֶם׃}
}
{
	\eX{
		And I will cast off the remnant of My own people and deliver them
		into the hands of their enemies. They shall be plunder and prey to
		all their enemies
	}
}
{
}

\Verse{15}
{
	\hX{יַעַן אֲשֶׁר עָשׂוּ אֶת־הָרַע בְּעֵינַי וַיִּהְיוּ מַכְעִסִים אֹתִי מִן־הַיּוֹם אֲשֶׁר יָצְאוּ אֲבוֹתָם מִמִּצְרַיִם וְעַד הַיּוֹם הַזֶּה׃}
}
{
	\eX{
		because they have done what is displeasing to Me and have been
		vexing Me from the day that their fathers came out of Egypt to
		this day.”
	}
}
{
}

\Verse{16}
{
	\hX{וְגַם דָּם נָקִי שָׁפַךְ מְנַשֶּׁה הַרְבֵּה מְאֹד עַד אֲשֶׁר־מִלֵּא אֶת־יְרוּשָׁלַ͏ִם פֶּה לָפֶה לְבַד מֵחַטָּאתוֹ אֲשֶׁר הֶחֱטִיא אֶת־יְהוּדָה לַעֲשׂוֹת הָרַע בְּעֵינֵי יְהֹוָה׃}
}
{
	\eX{
		Moreover, Manasseh put so many innocent persons to death that he
		filled Jerusalem [with blood] from end to end—besides the sin he
		committed in causing Judah to do what was displeasing to YHWH.
	}
}
{
}

\Verse{17}
{
	\hX{וְיֶתֶר דִּבְרֵי מְנַשֶּׁה וְכל־אֲשֶׁר עָשָׂה וְחַטָּאתוֹ אֲשֶׁר חָטָא הֲלֹא־הֵם כְּתוּבִים עַל־סֵפֶר דִּבְרֵי הַיָּמִים לְמַלְכֵי יְהוּדָה׃}
}

	\eX{

{
}

}
{
	\eX{

}
{
}

\Verse{19}
{
	\hX{בֶּן־עֶשְׂרִים וּשְׁתַּיִם שָׁנָה אָמוֹן בְּמלְכוֹ וּשְׁתַּיִם שָׁנִים מָלַךְ בִּירוּשָׁלָ͏ִם וְשֵׁם אִמּוֹ מְשֻׁלֶּמֶת בַּת־חָרוּץ מִן־יטְבָה׃}
}
{
	\eX{

	}
}
{
}

\Verse{20}
{
