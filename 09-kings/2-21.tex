\Chapter{21}

\Verse{1}
{
	\hX{בֶּן־שְׁתֵּים עֶשְׂרֵה שָׁנָה מְנַשֶּׁה בְמלְכוֹ וַחֲמִשִּׁים וְחָמֵשׁ שָׁנָה מָלַךְ בִּירוּשָׁלָ͏ִם וְשֵׁם אִמּוֹ חֶפְצִי־בָהּ׃}
}
{
	\eX{

}
{
	\eX{
		And he did that that was bad in the eyes of YHWH, after the

		children of Israel.
	}
}
{

\Verse{3}
{
	\hX{
		וַיָּשׁב וַיִּבֶן אֶת־הַבָּמוֹת אֲשֶׁר אִבַּד חִזְקִיָּהוּ אָבִיו וַיָּקֶם מִזְבְּחֹת לַבַּעַל וַיַּעַשׂ אֲשֵׁרָה כַּאֲשֶׁר עָשָׂה אַחְאָב מֶלֶךְ יִשְׂרָאֵל וַיִּשְׁתַּחוּ

	\eX{
		For he built up again the high places that Hezekiah his father
		had destroyed: and he reared up altars for Baal, and made a

		of skies, and served them.

}
{

	\eX{

\Verse{5}
{
	\hX{וַיִּבֶן מִזְבְּחוֹת לְכל־צְבָא הַשָּׁמָיִם בִּשְׁתֵּי חַצְרוֹת בֵּית־יְהֹוָה׃}

}
{
	\eX{

	}
}
{
}

\Verse{7}
{
	\hX{
		וַיָּשֶׂם אֶת־פֶּסֶל הָאֲשֵׁרָה אֲשֶׁר עָשָׂה בַּבַּיִת אֲשֶׁר אָמַר יְהֹוָה אֶל־דָּוִד וְאֶל־שְׁלֹמֹה בְנוֹ בַּבַּיִת הַזֶּה וּבִירוּשָׁלַ͏ִם אֲשֶׁר בָּחַרְתִּי מִכֹּל שִׁבְטֵי
		יִשְׂרָאֵל אָשִׂים אֶת־שְׁמִי לְעוֹלָם׃
	}
}
{
	\eX{
		And he set a carved image of the grove that he had made in the
		house, of that YHWH said to David, and to Solomon his son, In
		this house, and in Jerusalem, that I have chosen out of all
		tribes of Israel, will I put my name forever:
	}
}
{
}

\Verse{8}
{
	\hX{

		מֹשֶׁה׃
	}
}
{
	\eX{
		Neither will I make the feet of Israel move any more out of the
		land that I gave their fathers: only if they will observe to do

		all the law that my servant Moses commanded them.
	}
}
{
}

	\hX{וְלֹא שָׁמֵעוּ וַיַּתְעֵם מְנַשֶּׁה לַעֲשׂוֹת אֶת־הָרָע מִן־הַגּוֹיִם אֲשֶׁר הִשְׁמִיד יְהֹוָה מִפְּנֵי בְּנֵי יִשְׂרָאֵל׃}

{

}
{
	\eX{
		Therefore thus says YHWH God of Israel, Here: I am bringing such

}

	\eX{
