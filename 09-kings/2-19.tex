\Chapter{19}

\Verse{1}

}
{
	\eX{
		And it was, when king Hezekiah heard it, that he tore his
		clothes, and covered himself with sackcloth, and went into the
		house of YHWH.
	}
}
{
}

\Verse{2}
{
	\hX{וַיִּשְׁלַח אֶת־אֶלְיָקִים אֲשֶׁר־עַל־הַבַּיִת וְשֶׁבְנָא הַסֹּפֵר וְאֵת זִקְנֵי הַכֹּהֲנִים מִתְכַּסִּים בַּשַּׂקִּים אֶל־יְשַׁעְיָהוּ הַנָּבִיא בֶּן־אָמוֹץ׃}
}
{
	\eX{
		And he sent Eliakim, that was over the household, and Shebna the
		scribe, and the elders of the priests, covered with sackcloth,
		to Isaiah the prophet the son of Amoz.
	}
}
{
}

\Verse{3}
{
	\hX{וַיֹּאמְרוּ אֵלָיו כֹּה אָמַר חִזְקִיָּהוּ יוֹם־צָרָה וְתוֹכֵחָה וּנְאָצָה הַיּוֹם הַזֶּה כִּי בָאוּ בָנִים עַד־מַשְׁבֵּר וְכֹחַ אַיִן לְלֵדָה׃}
}
{
	\eX{
		And they said to him, Thus says Hezekiah, This day is a day of

	}
}
{
}

\Verse{4}
{
	\hX{
		אוּלַי יִשְׁמַע יְהֹוָה אֱלֹהֶיךָ אֵת כּל־דִּבְרֵי רַבְשָׁקֵה אֲשֶׁר שְׁלָחוֹ מֶלֶךְ־אַשּׁוּר אֲדֹנָיו לְחָרֵף אֱלֹהִים חַי וְהוֹכִיחַ בַּדְּבָרִים אֲשֶׁר שָׁמַע יְהֹוָה אֱלֹהֶיךָ
		וְנָשָׂאתָ תְפִלָּה בְּעַד הַשְּׁאֵרִית הַנִּמְצָאָה׃
	}
}
{
	\eX{
		It may be YHWH your God will hear all the words of Rabshakeh,
		whom the king of Assyria his master has sent to reproach the
		living God: and will reprove the words that YHWH your God has
		heard: why lift up your prayer for the remnant that are left.
	}
}
{
}

	\hX{וַיָּבֹאוּ עַבְדֵי הַמֶּלֶךְ חִזְקִיָּהוּ אֶל־יְשַׁעְיָהוּ׃}
}

\Verse{6}

}
{
}

}

}
{
	\eX{

}

}

	\eX{

{

\Verse{15}

	\hX{
		וַיִּתְפַּלֵּל חִזְקִיָּהוּ לִפְנֵי יְהֹוָה וַיֹּאמַר יְהֹוָה אֱלֹהֵי יִשְׂרָאֵל יֹשֵׁב הַכְּרֻבִים אַתָּה־הוּא הָאֱלֹהִים לְבַדְּךָ לְכֹל מַמְלְכוֹת הָאָרֶץ אַתָּה עָשִׂיתָ

}
{
}

{
}

{
}
