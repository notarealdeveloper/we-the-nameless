\Chapter{16}

\Verse{1}
{
	\hX{וַיְהִי דְבַר־יְהֹוָה אֶל־יֵהוּא בֶן־חֲנָנִי עַל־בַּעְשָׁא לֵאמֹר׃}
}
{
	\eX{
		And the word of YHWH came to Jehu the son of Hanani against
		Baasha, saying,
	}
}
{
}

\Verse{2}
{
	\hX{יַעַן אֲשֶׁר הֲרִימֹתִיךָ מִן־הֶעָפָר וָאֶתֶּנְךָ נָגִיד עַל עַמִּי יִשְׂרָאֵל וַתֵּלֶךְ בְּדֶרֶךְ יָרבְעָם וַתַּחֲטִא אֶת־עַמִּי יִשְׂרָאֵל לְהַכְעִיסֵנִי בְּחַטֹּאתָם׃}
}
{
	\eX{
		Because as I exalted you out of the dust, and made you prince
		over my people Israel: and you have walked in the way of
		Jeroboam, and have made my people Israel to sin, to provoke me
		to anger with their sins:
	}
}
{
}

\Verse{3}
{
	\hX{הִנְנִי מַבְעִיר אַחֲרֵי בַעְשָׁא וְאַחֲרֵי בֵיתוֹ וְנָתַתִּי אֶת־בֵּיתְךָ כְּבֵית יָרבְעָם בֶּן־נְבָט׃}
}
{
	\eX{
		Here: I'll take away the posterity of Baasha, and the posterity
		of his house: and will make your house like the house of
		Jeroboam the son of Nebat.
	}
}
{
}

\Verse{4}
{
	\hX{הַמֵּת לְבַעְשָׁא בָּעִיר יֹאכְלוּ הַכְּלָבִים וְהַמֵּת לוֹ בַּשָּׂדֶה יֹאכְלוּ עוֹף הַשָּׁמָיִם׃}
}
{
	\eX{
		Him that dies of Baasha in the city shall the dogs eat: and him
		that dies of his in the fields shall the birds of the air eat.
	}
}
{
}

\Verse{5}
{
	\hX{וְיֶתֶר דִּבְרֵי בַעְשָׁא וַאֲשֶׁר עָשָׂה וּגְבוּרָתוֹ הֲלֹא־הֵם כְּתוּבִים עַל־סֵפֶר דִּבְרֵי הַיָּמִים לְמַלְכֵי יִשְׂרָאֵל׃}
}
{
	\eX{
		And the rest of the acts of Baasha, and what he did, and his
		might, are they not written in the book of the chronicles of the
		kings of Israel?
	}
}
{
}

\Verse{6}
{
	\hX{וַיִּשְׁכַּב בַּעְשָׁא עִם־אֲבֹתָיו וַיִּקָּבֵר בְּתִרְצָה וַיִּמְלֹךְ אֵלָה בְנוֹ תַּחְתָּיו׃}
}
{
	\eX{
		And Baasha lay down with his fathers, and was buried in Tirzah:
		and Elah his son reigned in his place.
	}
}
{
}

\Verse{7}
{
	\hX{
		וְגַם בְּיַד־יֵהוּא בֶן־חֲנָנִי הַנָּבִיא דְּבַר־יְהֹוָה הָיָה אֶל־בַּעְשָׁא וְאֶל־בֵּיתוֹ וְעַל כּל־הָרָעָה אֲשֶׁר־עָשָׂה בְּעֵינֵי יְהֹוָה לְהַכְעִיסוֹ בְּמַעֲשֵׂה יָדָיו
		לִהְיוֹת כְּבֵית יָרבְעָם וְעַל אֲשֶׁר־הִכָּה אֹתוֹ׃
	}
}
{
	\eX{
		And also by the hand of the prophet Jehu the son of Hanani came
		the word of YHWH against Baasha, and against his house, even for
		all the bad that he did in YHWH's eyes, in provoking him to
		anger with the work of his hands, in being like the house of
		Jeroboam: and because he killed him.
	}
}
{
}

\Verse{8}
{
	\hX{בִּשְׁנַת עֶשְׂרִים וָשֵׁשׁ שָׁנָה לְאָסָא מֶלֶךְ יְהוּדָה מָלַךְ אֵלָה בֶן־בַּעְשָׁא עַל־יִשְׂרָאֵל בְּתִרְצָה שְׁנָתָיִם׃}
}
{
	\eX{
		In the twenty and sixth year of Asa king of Judah began Elah the
		son of Baasha to reign over Israel in Tirzah, two years.
	}
}
{
}

\Verse{9}
{
	\hX{וַיִּקְשֹׁר עָלָיו עַבְדּוֹ זִמְרִי שַׂר מַחֲצִית הָרָכֶב וְהוּא בְתִרְצָה שֹׁתֶה שִׁכּוֹר בֵּית אַרְצָא אֲשֶׁר עַל־הַבַּיִת בְּתִרְצָה׃}
}
{
	\eX{
		And his servant Zimri, commander of half his chariots, conspired
		against him, as he was in Tirzah, drinking himself drunk in the
		house of Arza steward of his house in Tirzah.
	}
}
{
}

\Verse{10}
{
	\hX{וַיָּבֹא זִמְרִי וַיַּכֵּהוּ וַיְמִיתֵהוּ בִּשְׁנַת עֶשְׂרִים וָשֶׁבַע לְאָסָא מֶלֶךְ יְהוּדָה וַיִּמְלֹךְ תַּחְתָּיו׃}
}
{
	\eX{
		And Zimri went in and struck him, and killed him, in the twenty
		and seventh year of Asa king of Judah, and reigned in his place.
	}
}
{
}

\Verse{11}
{
	\hX{וַיְהִי בְמלְכוֹ כְּשִׁבְתּוֹ עַל־כִּסְאוֹ הִכָּה אֶת־כּל־בֵּית בַּעְשָׁא לֹא־הִשְׁאִיר לוֹ מַשְׁתִּין בְּקִיר וְגֹאֲלָיו וְרֵעֵהוּ׃}
}
{
	\eX{
		And it was when he began to reign, as soon as he sat on his
		throne, that he slaughtered all the house of Baasha: he left him
		not one that pisses against a wall, neither of his kinsfolks,
		nor of his friends.
	}
}
{
}

\Verse{12}
{
	\hX{וַיַּשְׁמֵד זִמְרִי אֵת כּל־בֵּית בַּעְשָׁא כִּדְבַר יְהֹוָה אֲשֶׁר דִּבֶּר אֶל־בַּעְשָׁא בְּיַד יֵהוּא הַנָּבִיא׃}
}
{
	\eX{
		Thus did Zimri destroy all the house of Baasha, according to the
		word of YHWH, that he spoke against Baasha by Jehu the prophet.
	}
}
{
}

\Verse{13}
{
	\hX{אֶל כּל־חַטֹּאות בַּעְשָׁא וְחַטֹּאות אֵלָה בְנוֹ אֲשֶׁר חָטְאוּ וַאֲשֶׁר הֶחֱטִיאוּ אֶת־יִשְׂרָאֵל לְהַכְעִיס אֶת־יְהֹוָה אֱלֹהֵי יִשְׂרָאֵל בְּהַבְלֵיהֶם׃}
}
{
	\eX{
		For all the sins of Baasha, and the sins of Elah his son, by
		that they sinned, and by that they made Israel to sin, in
		provoking YHWH God of Israel to anger with their empty things.
	}
}
{
}

\Verse{14}
{
	\hX{וְיֶתֶר דִּבְרֵי אֵלָה וְכל־אֲשֶׁר עָשָׂה הֲלוֹא־הֵם כְּתוּבִים עַל־סֵפֶר דִּבְרֵי הַיָּמִים לְמַלְכֵי יִשְׂרָאֵל׃}
}
{
	\eX{
		And the rest of the acts of Elah, and all that he did, are they
		not written in the book of the chronicles of the kings of
		Israel?
	}
}
{
}

\Verse{15}
{
	\hX{בִּשְׁנַת עֶשְׂרִים וָשֶׁבַע שָׁנָה לְאָסָא מֶלֶךְ יְהוּדָה מָלַךְ זִמְרִי שִׁבְעַת יָמִים בְּתִרְצָה וְהָעָם חֹנִים עַל־גִּבְּתוֹן אֲשֶׁר לַפְּלִשְׁתִּים׃}
}
{
	\eX{
		In the twenty and seventh year of Asa king of Judah did Zimri
		reign seven days in Tirzah. And the people were encamped against
		Gibbethon, who belonged to the Philistines.
	}
}
{
}

\Verse{16}
{
	\hX{וַיִּשְׁמַע הָעָם הַחֹנִים לֵאמֹר קָשַׁר זִמְרִי וְגַם הִכָּה אֶת־הַמֶּלֶךְ וַיַּמְלִכוּ כל־יִשְׂרָאֵל אֶת־עמְרִי שַׂר־צָבָא עַל־יִשְׂרָאֵל בַּיּוֹם הַהוּא בַּמַּחֲנֶה׃}
}
{
	\eX{
		And the people that were encamped heard say, Zimri has
		conspired, and has also killed the king: why all Israel made
		Omri, the commander of the army, king over Israel that day in
		the camp.
	}
}
{
}

\Verse{17}
{
	\hX{וַיַּעֲלֶה עמְרִי וְכל־יִשְׂרָאֵל עִמּוֹ מִגִּבְּתוֹן וַיָּצֻרוּ עַל־תִּרְצָה׃}
}
{
	\eX{
		And Omri went up from Gibbethon, and all Israel with him, and
		they besieged Tirzah.
	}
}
{
}

\Verse{18}
{
	\hX{וַיְהִי כִּרְאוֹת זִמְרִי כִּי־נִלְכְּדָה הָעִיר וַיָּבֹא אֶל־אַרְמוֹן בֵּית־הַמֶּלֶךְ וַיִּשְׂרֹף עָלָיו אֶת־בֵּית־מֶלֶךְ בָּאֵשׁ וַיָּמֹת׃}
}
{
	\eX{
		And it was when Zimri saw that the city was taken, that he went
		into the palace of the king's house, and burnt the king's house
		over him with fire, and died.
	}
}
{
}

\Verse{19}
{
	\hX{עַל־חַטֹּאתָיו אֲשֶׁר חָטָא לַעֲשׂוֹת הָרַע בְּעֵינֵי יְהֹוָה לָלֶכֶת בְּדֶרֶךְ יָרבְעָם וּבְחַטָּאתוֹ אֲשֶׁר עָשָׂה לְהַחֲטִיא אֶת־יִשְׂרָאֵל׃}
}
{
	\eX{
		For his sins that he sinned in doing bad in YHWH's eyes, in
		walking in the way of Jeroboam, and in his sin that he did, to
		make Israel to sin.
	}
}
{
}

\Verse{20}
{
	\hX{וְיֶתֶר דִּבְרֵי זִמְרִי וְקִשְׁרוֹ אֲשֶׁר קָשָׁר הֲלֹא־הֵם כְּתוּבִים עַל־סֵפֶר דִּבְרֵי הַיָּמִים לְמַלְכֵי יִשְׂרָאֵל׃}
}
{
	\eX{
		And the rest of the acts of Zimri, and his treason that he
		worked, are they not written in the book of the chronicles of
		the kings of Israel?
	}
}
{
}

\Verse{21}
{
	\hX{אָז יֵחָלֵק הָעָם יִשְׂרָאֵל לַחֵצִי חֲצִי הָעָם הָיָה אַחֲרֵי תִבְנִי בֶן־גִּינַת לְהַמְלִיכוֹ וְהַחֲצִי אַחֲרֵי עמְרִי׃}
}
{
	\eX{
		And were the people of Israel divided into two parts: half of
		the people followed Tibni the son of Ginath, to make him king:
		and half followed Omri.
	}
}
{
}

\Verse{22}
{
	\hX{וַיֶּחֱזַק הָעָם אֲשֶׁר אַחֲרֵי עמְרִי אֶת־הָעָם אֲשֶׁר אַחֲרֵי תִּבְנִי בֶן־גִּינַת וַיָּמת תִּבְנִי וַיִּמְלֹךְ עמְרִי׃}
}
{
	\eX{
		But the people that followed Omri prevailed against the people
		that followed Tibni the son of Ginath: so Tibni died, and Omri
		reigned.
	}
}
{
}

\Verse{23}
{
	\hX{בִּשְׁנַת שְׁלֹשִׁים וְאַחַת שָׁנָה לְאָסָא מֶלֶךְ יְהוּדָה מָלַךְ עמְרִי עַל־יִשְׂרָאֵל שְׁתֵּים עֶשְׂרֵה שָׁנָה בְּתִרְצָה מָלַךְ שֵׁשׁ־שָׁנִים׃}
}
{
	\eX{
		In the thirty and first year of Asa king of Judah began Omri to
		reign over Israel, twelve years: six years reigned he in Tirzah.
	}
}
{
}

\Verse{24}
{
	\hX{וַיִּקֶן אֶת־הָהָר שֹׁמְרוֹן מֵאֶת שֶׁמֶר בְּכִכְּרַיִם כָּסֶף וַיִּבֶן אֶת־הָהָר וַיִּקְרָא אֶת־שֵׁם הָעִיר אֲשֶׁר בָּנָה עַל שֶׁם־שֶׁמֶר אֲדֹנֵי הָהָר שֹׁמְרוֹן׃}
}
{
	\eX{
		And he bought the hill Samaria of Shemer for two talents of
		silver, and built on the hill, and called the name of the city
		that he built, after the name of Shemer, owner of the hill,
		Samaria.
	}
}
{
}

\Verse{25}
{
	\hX{וַיַּעֲשֶׂה עמְרִי הָרַע בְּעֵינֵי יְהֹוָה וַיָּרַע מִכֹּל אֲשֶׁר לְפָנָיו׃}
}
{
	\eX{
		But Omri worked bad in the eyes of YHWH, and did worse than all

	}
}
{
}

\Verse{26}
{
	\hX{וַיֵּלֶךְ בְּכל־דֶּרֶךְ יָרבְעָם בֶּן־נְבָט (ובחטאתיו) [וּבְחַטָּאתוֹ] אֲשֶׁר הֶחֱטִיא אֶת־יִשְׂרָאֵל לְהַכְעִיס אֶת־יְהֹוָה אֱלֹהֵי יִשְׂרָאֵל בְּהַבְלֵיהֶם׃}
}
{
	\eX{
		For he walked in all the way of Jeroboam the son of Nebat, and
		in his sin with what he made Israel to sin, to provoke YHWH God
		of Israel to anger with their empty things.
	}
}
{
}

\Verse{27}
{
	\hX{וְיֶתֶר דִּבְרֵי עמְרִי אֲשֶׁר עָשָׂה וּגְבוּרָתוֹ אֲשֶׁר עָשָׂה הֲלֹא־הֵם כְּתוּבִים עַל־סֵפֶר דִּבְרֵי הַיָּמִים לְמַלְכֵי יִשְׂרָאֵל׃}
}
{
	\eX{
		And the rest of the acts of Omri that he did, and his might that
		he showed, are they not written in the book of the chronicles of
		the kings of Israel?
	}
}
{
}

\Verse{28}
{
	\hX{וַיִּשְׁכַּב עמְרִי עִם־אֲבֹתָיו וַיִּקָּבֵר בְּשֹׁמְרוֹן וַיִּמְלֹךְ אַחְאָב בְּנוֹ תַּחְתָּיו׃}
}
{
	\eX{
		And Omri lay down with his fathers, and was buried in Samaria:

	}
}
{
}

\Verse{29}
{
	\hX{
		וְאַחְאָב בֶּן־עמְרִי מָלַךְ עַל־יִשְׂרָאֵל בִּשְׁנַת שְׁלֹשִׁים וּשְׁמֹנֶה שָׁנָה לְאָסָא מֶלֶךְ יְהוּדָה וַיִּמְלֹךְ אַחְאָב בֶּן־עמְרִי עַל־יִשְׂרָאֵל בְּשֹׁמְרוֹן עֶשְׂרִים
		וּשְׁתַּיִם שָׁנָה׃
	}
}
{
	\eX{
		And in the thirty and eighth year of Asa king of Judah began
		Ahab the son of Omri to reign over Israel: and Ahab the son of
		Omri reigned over Israel in Samaria twenty and two years.
	}
}
{
}

\Verse{30}
{
	\hX{וַיַּעַשׂ אַחְאָב בֶּן־עמְרִי הָרַע בְּעֵינֵי יְהֹוָה מִכֹּל אֲשֶׁר לְפָנָיו׃}
}
