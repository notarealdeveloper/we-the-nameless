\Chapter{20}

\Verse{1}
{
	\hX{וּבֶן־הֲדַד מֶלֶךְ־אֲרָם קָבַץ אֶת־כּל־חֵילוֹ וּשְׁלֹשִׁים וּשְׁנַיִם מֶלֶךְ אִתּוֹ וְסוּס וָרָכֶב וַיַּעַל וַיָּצַר עַל־שֹׁמְרוֹן וַיִּלָּחֶם בָּהּ׃}
}
{
	\eX{
		And Benhadad the king of Syria gathered all his army together:
		and there were thirty and two kings with him, and horses, and
		chariots: and he went up and besieged Samaria, and warred
		against it.
	}
}
{
}

\Verse{2}
{
	\hX{וַיִּשְׁלַח מַלְאָכִים אֶל־אַחְאָב מֶלֶךְ־יִשְׂרָאֵל הָעִירָה׃}
}
{
	\eX{
		And he sent messengers to Ahab king of Israel into the city, and
		said to him, Thus says Benhadad,
	}
}
{
}

\Verse{3}
{
	\hX{וַיֹּאמֶר לוֹ כֹּה אָמַר בֶּן־הֲדַד כַּסְפְּךָ וּזְהָבְךָ לִי־הוּא וְנָשֶׁיךָ וּבָנֶיךָ הַטּוֹבִים לִי־הֵם׃}
}
{
	\eX{
		Your silver and your gold is my: your wives also and your
		children, even the goodliest, are mine.
	}
}
{
}

\Verse{4}
{
	\hX{וַיַּעַן מֶלֶךְ־יִשְׂרָאֵל וַיֹּאמֶר כִּדְבָרְךָ אֲדֹנִי הַמֶּלֶךְ לְךָ אֲנִי וְכל־אֲשֶׁר־לִי׃}
}
{
	\eX{
		And the king of Israel answered and said, My lord, king,
		according to your saying, I am yours, and all that I have.
	}
}
{
}

\Verse{5}
{
	\hX{וַיָּשֻׁבוּ הַמַּלְאָכִים וַיֹּאמְרוּ כֹּה־אָמַר בֶּן־הֲדַד לֵאמֹר כִּי־שָׁלַחְתִּי אֵלֶיךָ לֵאמֹר כַּסְפְּךָ וּזְהָבְךָ וְנָשֶׁיךָ וּבָנֶיךָ לִי תִתֵּן׃}
}
{
	\eX{
		And the messengers came again, and said, Thus speaks Benhadad,
		saying, Although I have sent to you, saying, You shall deliver
		me your silver, and your gold, and your wives, and your
		children:
	}
}
{
}

\Verse{6}
{
	\hX{כִּי אִם־כָּעֵת מָחָר אֶשְׁלַח אֶת־עֲבָדַי אֵלֶיךָ וְחִפְּשׂוּ אֶת־בֵּיתְךָ וְאֵת בָּתֵּי עֲבָדֶיךָ וְהָיָה כּל־מַחְמַד עֵינֶיךָ יָשִׂימוּ בְיָדָם וְלָקָחוּ׃}
}
{
	\eX{
		Yet I'll send my servants to you tomorrow about this time, and
		they shall search your house, and the houses of your servants:
		and it shall be, that whatsoever is pleasant in your eyes, they
		shall put it in their hand, and take it away.
	}
}
{
}

\Verse{7}
{
	\hX{
		וַיִּקְרָא מֶלֶךְ־יִשְׂרָאֵל לְכל־זִקְנֵי הָאָרֶץ וַיֹּאמֶר דְּעוּ־נָא וּרְאוּ כִּי רָעָה זֶה מְבַקֵּשׁ כִּי־שָׁלַח אֵלַי לְנָשַׁי וּלְבָנַי וּלְכַסְפִּי וְלִזְהָבִי וְלֹא
		מָנַעְתִּי מִמֶּנּוּ׃
	}
}
{
	\eX{
		And the king of Israel called all the elders of the land, and
		said, Mark, please, and see how this man seeks bad: for he sent
		to me for my wives, and for my children, and for my silver, and
		for my gold: and I denied him not.
	}
}
{
}

\Verse{8}
{
	\hX{וַיֹּאמְרוּ אֵלָיו כּל־הַזְּקֵנִים וְכל־הָעָם אַל־תִּשְׁמַע וְלוֹא תֹאבֶה׃}
}
{
	\eX{
		And all the elders and all the people said to him, Listen not to
		him, nor consent.
	}
}
{
}

\Verse{9}
{
	\hX{
		וַיֹּאמֶר לְמַלְאֲכֵי בֶן־הֲדַד אִמְרוּ לַאדֹנִי הַמֶּלֶךְ כֹּל אֲשֶׁר־שָׁלַחְתָּ אֶל־עַבְדְּךָ בָרִאשֹׁנָה אֶעֱשֶׂה וְהַדָּבָר הַזֶּה לֹא אוּכַל לַעֲשׂוֹת וַיֵּלְכוּ הַמַּלְאָכִים
		וַיְשִׁבֻהוּ דָּבָר׃
	}
}
{
	\eX{
		Why he said to the messengers of Benhadad, Tell my lord the
		king, All that you did send for to your servant at the first
		I'll do: but this thing I may not do. And the messengers
		departed, and brought him word again.
	}
}
{
}

\Verse{10}
{
	\hX{וַיִּשְׁלַח אֵלָיו בֶּן־הֲדַד וַיֹּאמֶר כֹּה־יַעֲשׂוּן לִי אֱלֹהִים וְכֹה יוֹסִפוּ אִם־יִשְׂפֹּק עֲפַר שֹׁמְרוֹן לִשְׁעָלִים לְכל־הָעָם אֲשֶׁר בְּרַגְלָי׃}
}
{
	\eX{
		And Benhadad sent to him, and said, The gods do so to me, and
		more also, if the dust of Samaria shall suffice for handfuls for
		all the people that follow me.
	}
}
{
}

\Verse{11}
{
	\hX{וַיַּעַן מֶלֶךְ־יִשְׂרָאֵל וַיֹּאמֶר דַּבְּרוּ אַל־יִתְהַלֵּל חֹגֵר כִּמְפַתֵּחַ׃}
}
{
	\eX{
		And the king of Israel answered and said, Tell him, Let not him
		that girds on his armor boast himself as he that puts it off.
	}
}
{
}

\Verse{12}
{
	\hX{וַיְהִי כִּשְׁמֹעַ אֶת־הַדָּבָר הַזֶּה וְהוּא שֹׁתֶה הוּא וְהַמְּלָכִים בַּסֻּכּוֹת וַיֹּאמֶר אֶל־עֲבָדָיו שִׂימוּ וַיָּשִׂימוּ עַל־הָעִיר׃}
}
{
	\eX{
		And it was when Benhadad heard this message, as he was drinking,
		he and the kings in the pavilions, that he said to his servants,
		Set yourselves in array. And they set themselves in array
		against the city.
	}
}
{
}

\Verse{13}
{
	\hX{
		וְהִנֵּה נָבִיא אֶחָד נִגַּשׁ אֶל־אַחְאָב מֶלֶךְ־יִשְׂרָאֵל וַיֹּאמֶר כֹּה אָמַר יְהֹוָה הֲרָאִיתָ אֵת כּל־הֶהָמוֹן הַגָּדוֹל הַזֶּה הִנְנִי נֹתְנוֹ בְיָדְךָ הַיּוֹם וְיָדַעְתָּ
		כִּי־אֲנִי יְהֹוָה׃
	}
}
{
	\eX{
		And here: there came a prophet to Ahab king of Israel, saying,
		Thus says YHWH, Have you seen all this great multitude? here:,
		I'll deliver it into your hand this day: and you shall know that
		I am YHWH.
	}
}
{
}

\Verse{14}
{
	\hX{וַיֹּאמֶר אַחְאָב בְּמִי וַיֹּאמֶר כֹּה־אָמַר יְהֹוָה בְּנַעֲרֵי שָׂרֵי הַמְּדִינוֹת וַיֹּאמֶר מִי־יֶאְסֹר הַמִּלְחָמָה וַיֹּאמֶר אָתָּה׃}
}
{
	\eX{
		And Ahab said, By whom? And he said, Thus says YHWH, Even by the
		young men of the princes of the provinces. And he said, Who
		shall order the battle? And he answered, You.
	}
}
{
}

\Verse{15}
{
	\hX{וַיִּפְקֹד אֶת־נַעֲרֵי שָׂרֵי הַמְּדִינוֹת וַיִּהְיוּ מָאתַיִם שְׁנַיִם וּשְׁלֹשִׁים וְאַחֲרֵיהֶם פָּקַד אֶת־כּל־הָעָם כּל־בְּנֵי יִשְׂרָאֵל שִׁבְעַת אֲלָפִים׃}
}
{
	\eX{
		And he numbered the young men of the princes of the provinces,
		and they were two hundred and thirty two: and after them he
		numbered all the people, even all the children of Israel, being
		seven thousand.
	}
}
{
}

\Verse{16}
{
	\hX{וַיֵּצְאוּ בַּצּהֳרָיִם וּבֶן־הֲדַד שֹׁתֶה שִׁכּוֹר בַּסֻּכּוֹת הוּא וְהַמְּלָכִים שְׁלֹשִׁים־וּשְׁנַיִם מֶלֶךְ עֹזֵר אֹתוֹ׃}
}
{
	\eX{
		And they went out at noon. But Benhadad was drinking himself
		drunk in the pavilions, he and the kings, the thirty and two
		kings that helped him.
	}
}
{
}

\Verse{17}
{
	\hX{וַיֵּצְאוּ נַעֲרֵי שָׂרֵי הַמְּדִינוֹת בָּרִאשֹׁנָה וַיִּשְׁלַח בֶּן־הֲדַד וַיַּגִּידוּ לוֹ לֵאמֹר אֲנָשִׁים יָצְאוּ מִשֹּׁמְרוֹן׃}
}
{
	\eX{
		And the young men of the princes of the provinces went out
		first: and Benhadad sent out, and they told him, saying, There
		are men come out of Samaria.
	}
}
{
}

\Verse{18}
{
	\hX{וַיֹּאמֶר אִם־לְשָׁלוֹם יָצָאוּ תִּפְשׂוּם חַיִּים וְאִם לְמִלְחָמָה יָצָאוּ חַיִּים תִּפְשׂוּם׃}
}
{
	\eX{
		And he said, Whether they be come out for peace, take them
		alive: or whether they be come out for war, take them alive.
	}
}
{
}

\Verse{19}
{
	\hX{וְאֵלֶּה יָצְאוּ מִן־הָעִיר נַעֲרֵי שָׂרֵי הַמְּדִינוֹת וְהַחַיִל אֲשֶׁר אַחֲרֵיהֶם׃}
}
{
	\eX{
		And these young men of the princes of the provinces came out of
		the city, and the army which followed them.
	}
}
{
}

\Verse{20}
{
	\hX{וַיַּכּוּ אִישׁ אִישׁוֹ וַיָּנֻסוּ אֲרָם וַיִּרְדְּפֵם יִשְׂרָאֵל וַיִּמָּלֵט בֶּן־הֲדַד מֶלֶךְ אֲרָם עַל־סוּס וּפָרָשִׁים׃}
}
{
	\eX{
		And they slaughtered every one his man: and the Syrians fled:
		and Israel pursued them: and Benhadad the king of Syria escaped
		on an horse with the horsemen.
	}
}
{
}

\Verse{21}
{
	\hX{וַיֵּצֵא מֶלֶךְ יִשְׂרָאֵל וַיַּךְ אֶת־הַסּוּס וְאֶת־הָרָכֶב וְהִכָּה בַאֲרָם מַכָּה גְדוֹלָה׃}
}
{
	\eX{
		And the king of Israel went out, and struck the horses and
		chariots, and slaughtered the Syrians with a great slaughter.
	}
}
{
}

\Verse{22}
{
	\hX{וַיִּגַּשׁ הַנָּבִיא אֶל־מֶלֶךְ יִשְׂרָאֵל וַיֹּאמֶר לוֹ לֵךְ הִתְחַזַּק וְדַע וּרְאֵה אֵת אֲשֶׁר־תַּעֲשֶׂה כִּי לִתְשׁוּבַת הַשָּׁנָה מֶלֶךְ אֲרָם עֹלֶה עָלֶיךָ׃}
}
{
	\eX{
		And the prophet came to the king of Israel, and said to him, Go,
		strengthen yourself, and mark, and see what you do: for at the
		return of the year the king of Syria will come up against you.
	}
}
{
}

\Verse{23}
{
	\hX{וְעַבְדֵי מֶלֶךְ־אֲרָם אָמְרוּ אֵלָיו אֱלֹהֵי הָרִים אֱלֹהֵיהֶם עַל־כֵּן חָזְקוּ מִמֶּנּוּ וְאוּלָם נִלָּחֵם אִתָּם בַּמִּישׁוֹר אִם־לֹא נֶחֱזַק מֵהֶם׃}
}
{
	\eX{
		And the servants of the king of Syria said to him, Their gods
		are gods of the hills: therefore they were stronger than we: but
		let us fight against them in the plain, and surely we shall be
		stronger than they.
	}
}
{
}

\Verse{24}
{
	\hX{וְאֶת־הַדָּבָר הַזֶּה עֲשֵׂה הָסֵר הַמְּלָכִים אִישׁ מִמְּקֹמוֹ וְשִׂים פַּחוֹת תַּחְתֵּיהֶם׃}
}
{
	\eX{
		And do this thing, Take the kings away, every man out of his
		place, and put commanders in their rooms:
	}
}
{
}

\Verse{25}
{
	\hX{וְאַתָּה תִמְנֶה־לְךָ חַיִל כַּחַיִל הַנֹּפֵל מֵאוֹתָךְ וְסוּס כַּסּוּס וְרֶכֶב כָּרֶכֶב וְנִלָּחֲמָה אוֹתָם בַּמִּישׁוֹר אִם־לֹא נֶחֱזַק מֵהֶם וַיִּשְׁמַע לְקֹלָם וַיַּעַשׂ כֵּן׃}
}
{
	\eX{
		And number you an army, like the army that you have lost, horse
		for horse, and chariot for chariot: and we'll fight against them
		in the plain, and surely we shall be stronger than they. And he
		listened to their voice, and did so.
	}
}
{
}

\Verse{26}
{
	\hX{וַיְהִי לִתְשׁוּבַת הַשָּׁנָה וַיִּפְקֹד בֶּן־הֲדַד אֶת־אֲרָם וַיַּעַל אֲפֵקָה לַמִּלְחָמָה עִם־יִשְׂרָאֵל׃}
}
{
	\eX{
		And it was at the return of the year, that Benhadad numbered the
		Syrians, and went up to Aphek, to fight against Israel.
	}
}
{
}

\Verse{27}
{
	\hX{וּבְנֵי יִשְׂרָאֵל התְפָּקְדוּ וְכלְכְּלוּ וַיֵּלְכוּ לִקְרָאתָם וַיַּחֲנוּ בְנֵי־יִשְׂרָאֵל נֶגְדָּם כִּשְׁנֵי חֲשִׂפֵי עִזִּים וַאֲרָם מִלְאוּ אֶת־הָאָרֶץ׃}
}
{
	\eX{
		And the children of Israel were numbered, and were all present,
		and went against them: and the children of Israel pitched before
		them like two little flocks of kids: but the Syrians filled the
		country.
	}
}
{
}

\Verse{28}
{
	\hX{
		וַיִּגַּשׁ אִישׁ הָאֱלֹהִים וַיֹּאמֶר אֶל־מֶלֶךְ יִשְׂרָאֵל וַיֹּאמֶר כֹּה־אָמַר יְהֹוָה יַעַן אֲשֶׁר אָמְרוּ אֲרָם אֱלֹהֵי הָרִים יְהֹוָה וְלֹא־אֱלֹהֵי עֲמָקִים הוּא וְנָתַתִּי
		אֶת־כּל־הֶהָמוֹן הַגָּדוֹל הַזֶּה בְּיָדֶךָ וִידַעְתֶּם כִּי־אֲנִי יְהֹוָה׃
	}
}
{
	\eX{
		And there came a man of God, and spoke to the king of Israel,
		and said, Thus says YHWH, Because the Syrians have said, The
		YHWH is God of the hills, but he is not God of the valleys,
		therefore will I deliver all this great multitude into your
		hand, and you shall know that I am YHWH.
	}
}
{
}

\Verse{29}
{
