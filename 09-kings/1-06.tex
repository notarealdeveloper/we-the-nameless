	\hX{וְכֵן עָשָׂה לְפֶתַח הַהֵיכָל מְזוּזוֹת עֲצֵי־שָׁמֶן מֵאֵת רְבִעִית׃}
}
{
	\eX{
		And also made he for the door of the temple posts of olive tree,
		a fourth part of the wall.
	}
}
{
}

\Verse{34}
{
	\hX{וּשְׁתֵּי דַלְתוֹת עֲצֵי בְרוֹשִׁים שְׁנֵי צְלָעִים הַדֶּלֶת הָאַחַת גְּלִילִים וּשְׁנֵי קְלָעִים הַדֶּלֶת הַשֵּׁנִית גְּלִילִים׃}
}
{
	\eX{
		And the two doors were of cypress tree: the two leaves of the
		one door were folding, and the two leaves of the other door were
		folding.
	}
}
{
}

\Verse{35}
{
	\hX{וְקָלַע כְּרוּבִים וְתִמֹרוֹת וּפְטֻרֵי צִצִּים וְצִפָּה זָהָב מְיֻשָּׁר עַל־הַמְּחֻקֶּה׃}
}
{
	\eX{
		And he carved thereon cherubims and palm trees and open flowers:
		and covered them with gold fitted on the carved work.
	}
}
{
}

\Verse{36}
{
	\hX{וַיִּבֶן אֶת־הֶחָצֵר הַפְּנִימִית שְׁלֹשָׁה טוּרֵי גָזִית וְטוּר כְּרֻתֹת אֲרָזִים׃}
}
{
	\eX{
		And he built the inner court with three rows of cuted stone, and
		a row of cedar beams.
	}
}
{
}

\Verse{37}
{
	\hX{בַּשָּׁנָה הָרְבִיעִית יֻסַּד בֵּית יְהֹוָה בְּיֶרַח זִו׃}
}
{
	\eX{
		In the fourth year was the foundation of the house of YHWH laid,
		in the month Zif:
	}
}
{
}

\Verse{38}
{
	\hX{וּבַשָּׁנָה הָאַחַת עֶשְׂרֵה בְּיֶרַח בּוּל הוּא הַחֹדֶשׁ הַשְּׁמִינִי כָּלָה הַבַּיִת לְכל־דְּבָרָיו וּלְכל־מִשְׁפָּטָו וַיִּבְנֵהוּ שֶׁבַע שָׁנִים׃}
}
{
	\eX{
		And in the eleventh year, in the month Bul, which is the eighth
		month, was the house finished throughout all the parts of it,
		and according to all the fashion of it. And was he seven years
		in building it.
	}
}
{
