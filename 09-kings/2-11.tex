\Chapter{11}

\Verse{1}
{
	\hX{וַעֲתַלְיָה אֵם אֲחַזְיָהוּ (וראתה) [רָאֲתָה] כִּי מֵת בְּנָהּ וַתָּקם וַתְּאַבֵּד אֵת כּל־זֶרַע הַמַּמְלָכָה׃}
}
{
	\eX{
		And when Athaliah the mother of Ahaziah saw that her son was
		dead, she arose and destroyed all the seed royal.
	}
}

	Qere Ketiv.
}

\Verse{2}
{
	\hX{
		וַתִּקַּח יְהוֹשֶׁבַע בַּת־הַמֶּלֶךְ־יוֹרָם אֲחוֹת אֲחַזְיָהוּ אֶת־יוֹאָשׁ בֶּן־אֲחַזְיָה וַתִּגְנֹב אֹתוֹ מִתּוֹךְ בְּנֵי־הַמֶּלֶךְ (הממותתים) [הַמּוּמָתִים] אֹתוֹ
		וְאֶת־מֵינִקְתּוֹ בַּחֲדַר הַמִּטּוֹת וַיַּסְתִּרוּ אֹתוֹ מִפְּנֵי עֲתַלְיָהוּ וְלֹא הוּמָת׃
	}
}
{
	\eX{
		But Jehosheba, the daughter of king Joram, sister of Ahaziah,
		took Joash the son of Ahaziah, and stole him from among the
		king's sons that were killed: and they hid him, even him and his
		nurse, in the bedchamber from Athaliah, so that he was not
		killed.
	}
}
{
	Qere Ketiv.
}

\Verse{3}
{
	\hX{וַיְהִי אִתָּהּ בֵּית יְהֹוָה מִתְחַבֵּא שֵׁשׁ שָׁנִים וַעֲתַלְיָה מֹלֶכֶת עַל־הָאָרֶץ׃}
}
{
	\eX{
		And he was with her hid in the house of YHWH six years. And
		Athaliah did reign over the land.
	}
}
{
}

\Verse{4}
{
	\hX{
		וּבַשָּׁנָה הַשְּׁבִיעִית שָׁלַח יְהוֹיָדָע וַיִּקַּח אֶת־שָׂרֵי (המאיות) [הַמֵּאוֹת] לַכָּרִי וְלָרָצִים וַיָּבֵא אֹתָם אֵלָיו בֵּית יְהֹוָה וַיִּכְרֹת לָהֶם בְּרִית וַיַּשְׁבַּע
		אֹתָם בְּבֵית יְהֹוָה וַיַּרְא אֹתָם אֶת־בֶּן־הַמֶּלֶךְ׃
	}
}
{
	\eX{
		And the seventh year Jehoiada sent and fetched the rulers over
		hundreds, with the commanders and the guard, and brought them to
		him into the house of YHWH, and made a covenant with them, and
		took an oath of them in the house of YHWH, and showed them the
		king's son.
	}
}
{
	Qere Ketiv.
}

\Verse{5}
{
	\hX{וַיְצַוֵּם לֵאמֹר זֶה הַדָּבָר אֲשֶׁר תַּעֲשׂוּן הַשְּׁלִשִׁית מִכֶּם בָּאֵי הַשַּׁבָּת וְשֹׁמְרֵי מִשְׁמֶרֶת בֵּית הַמֶּלֶךְ׃}
}
{
	\eX{
		And he commanded them, saying, This is the thing that you shall
		do: A third part of you that enter in on the sabbath shall even
		be keepers of the watch of the king's house:
	}
}
{
}

\Verse{6}
{
	\hX{וְהַשְּׁלִשִׁית בְּשַׁעַר סוּר וְהַשְּׁלִשִׁית בַּשַּׁעַר אַחַר הָרָצִים וּשְׁמַרְתֶּם אֶת־מִשְׁמֶרֶת הַבַּיִת מַסָּח׃}
}
{
	\eX{
		And a third part shall be at the gate of Sur: and a third part
		at the gate behind the guard: so shall you keep the watch of the
		house, that it be not broken down.
	}
}
{
}

\Verse{7}
{
	\hX{וּשְׁתֵּי הַיָּדוֹת בָּכֶם כֹּל יֹצְאֵי הַשַּׁבָּת וְשָׁמְרוּ אֶת־מִשְׁמֶרֶת בֵּית־יְהֹוָה אֶל־הַמֶּלֶךְ׃}
}
{
	\eX{
		And two parts of all you that go forth on the sabbath, even they
		shall keep the watch of the house of YHWH about the king.
	}
}
{
}

\Verse{8}
{
	\hX{וְהִקַּפְתֶּם עַל־הַמֶּלֶךְ סָבִיב אִישׁ וְכֵלָיו בְּיָדוֹ וְהַבָּא אֶל־הַשְּׂדֵרוֹת יוּמָת וִהְיוּ אֶת־הַמֶּלֶךְ בְּצֵאתוֹ וּבְבֹאוֹ׃}
}
{
	\eX{
		And you shall compass the king round about, every man with his
		weapons in his hand: and he that comes within the ranges, let
		him be killed: and be you with the king as he goes out and as he
		comes in.
	}
}
{
}

\Verse{9}
{
	\hX{
		וַיַּעֲשׂוּ שָׂרֵי (המאיות) [הַמֵּאוֹת] כְּכֹל אֲשֶׁר־צִוָּה יְהוֹיָדָע הַכֹּהֵן וַיִּקְחוּ אִישׁ אֶת־אֲנָשָׁיו בָּאֵי הַשַּׁבָּת עִם יֹצְאֵי הַשַּׁבָּת וַיָּבֹאוּ אֶל־יְהוֹיָדָע
		הַכֹּהֵן׃
	}
}
{
	\eX{
		And the commanders over the hundreds did according to all things
		that Jehoiada the priest commanded: and they took every man his
		men that were to come in on the sabbath, with them that should
		go out on the sabbath, and came to Jehoiada the priest.
	}
}
{
	Qere Ketiv.
}

\Verse{10}
{
	\hX{וַיִּתֵּן הַכֹּהֵן לְשָׂרֵי (המאיות) [הַמֵּאוֹת] אֶת־הַחֲנִית וְאֶת־הַשְּׁלָטִים אֲשֶׁר לַמֶּלֶךְ דָּוִד אֲשֶׁר בְּבֵית יְהֹוָה׃}
}
{
	\eX{
		And to the commanders over hundreds did the priest give king
		David's spears and shields, that were in the temple of YHWH.

}
{
	Qere Ketiv.
}

\Verse{11}
{
	\hX{וַיַּעַמְדוּ הָרָצִים אִישׁ וְכֵלָיו בְּיָדוֹ מִכֶּתֶף הַבַּיִת הַיְמָנִית עַד־כֶּתֶף הַבַּיִת הַשְּׂמָאלִית לַמִּזְבֵּחַ וְלַבָּיִת עַל־הַמֶּלֶךְ סָבִיב׃}
}
{
	\eX{
		And the guard stood, every man with his weapons in his hand,
		round about the king, from the right corner of the temple to the
		left corner of the temple, along by the altar and the temple.
	}
}
{
}

\Verse{12}
{
	\hX{וַיּוֹצִא אֶת־בֶּן־הַמֶּלֶךְ וַיִּתֵּן עָלָיו אֶת־הַנֵּזֶר וְאֶת־הָעֵדוּת וַיַּמְלִכוּ אֹתוֹ וַיִּמְשָׁחֻהוּ וַיַּכּוּ־כָף וַיֹּאמְרוּ יְחִי הַמֶּלֶךְ׃}
}
{
	\eX{
		And he brought out the king's son, and put the crown on him, and
		gave him the testimony: and they made him king, and anointed
		him: and they clapped their hands, and said, God save the king.
	}
}
{
}

\Verse{13}

	\hX{וַתִּשְׁמַע עֲתַלְיָה אֶת־קוֹל הָרָצִין הָעָם וַתָּבֹא אֶל־הָעָם בֵּית יְהֹוָה׃}
}

	\eX{

\Verse{14}
{
	\hX{
		וַתֵּרֶא וְהִנֵּה הַמֶּלֶךְ עֹמֵד עַל־הָעַמּוּד כַּמִּשְׁפָּט וְהַשָּׂרִים וְהַחֲצֹצְרוֹת אֶל־הַמֶּלֶךְ וְכל־עַם הָאָרֶץ שָׂמֵחַ וְתֹקֵעַ בַּחֲצֹצְרוֹת וַתִּקְרַע עֲתַלְיָה
		אֶת־בְּגָדֶיהָ וַתִּקְרָא קֶשֶׁר קָשֶׁר׃
	}
}
{
	\eX{
		And when she looked, here: the king stood by a column, as the
		manner was, and the princes and the trumpeters by the king, and
		all the people of the land rejoiced, and blew with trumpets: and
		Athaliah tore her clothes, and cried, Treason, Treason.
	}
}
{
}

\Verse{15}
{
	\hX{
		וַיְצַו יְהוֹיָדָע הַכֹּהֵן אֶת־שָׂרֵי (המאיות) [הַמֵּאוֹת ] פְּקֻדֵי הַחַיִל וַיֹּאמֶר אֲלֵיהֶם הוֹצִיאוּ אֹתָהּ אֶל־מִבֵּית לַשְּׂדֵרֹת וְהַבָּא אַחֲרֶיהָ הָמֵת בֶּחָרֶב כִּי

	}
}
{
	\eX{
		But Jehoiada the priest commanded the commanders of the
		hundreds, the officers of the army, and said to them, Have her
		forth without the ranges: and him that follows her kill with the
		sword. For the priest had said, Let her not be killed in the
		house of YHWH.
	}
}
{
	Qere Ketiv.
}

}

{

\Verse{18}

	\eX{

		broke it down: his altars and his images broke they in pieces

		YHWH.
	}
}
{
}

\Verse{19}
{
	\hX{

{
