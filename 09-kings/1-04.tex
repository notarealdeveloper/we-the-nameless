\Chapter{4}

\Verse{1}
{
	\hX{וַיְהִי הַמֶּלֶךְ שְׁלֹמֹה מֶלֶךְ עַל־כּל־יִשְׂרָאֵל׃}
}
{
	\eX{And king Solomon was king over all Israel.}
}
{
}

\Verse{2}
{
	\hX{וְאֵלֶּה הַשָּׂרִים אֲשֶׁר־לוֹ עֲזַרְיָהוּ בֶן־צָדוֹק הַכֹּהֵן׃}
}
{
	\eX{
		And these were the princes that he had: Azariah the son of Zadok
		the priest,
	}
}
{
}

\Verse{3}
{
	\hX{אֱלִיחֹרֶף וַאֲחִיָּה בְּנֵי שִׁישָׁא סֹפְרִיםיְהוֹשָׁפָט בֶּן־אֲחִילוּד הַמַּזְכִּיר׃}
}
{
	\eX{
		Elihoreph and Ahiah, the sons of Shisha, scribes: Jehoshaphat
		the son of Ahilud, the recorder.
	}
}
{
}

\Verse{4}
{
	\hX{וּבְנָיָהוּ בֶן־יְהוֹיָדָע עַל־הַצָּבָאוְצָדוֹק וְאֶבְיָתָר כֹּהֲנִים׃}
}
{
	\eX{
		And Benaiah the son of Jehoiada was over the army: and Zadok and
		Abiathar were the priests:
	}
}
{
}

\Verse{5}
{
	\hX{וַעֲזַרְיָהוּ בֶן־נָתָן עַל־הַנִּצָּבִיםוְזָבוּד בֶּן־נָתָן כֹּהֵן רֵעֶה הַמֶּלֶךְ׃}
}
{
	\eX{
		And Azariah the son of Nathan was over the officers: and Zabud
		the son of Nathan was principal officer, and the king's friend:
	}
}
{
}

\Verse{6}
{
	\hX{וַאֲחִישָׁר עַל־הַבָּיִתוַאֲדֹנִירָם בֶּן־עַבְדָּא עַל־הַמַּס׃}
}
{
	\eX{
		And Ahishar was over the household: and Adoniram the son of Abda
		was over the tribute.
	}
}
{
}

\Verse{7}
{
	\hX{וְלִשְׁלֹמֹה שְׁנֵים־עָשָׂר נִצָּבִים עַל־כּל־יִשְׂרָאֵל וְכִלְכְּלוּ אֶת־הַמֶּלֶךְ וְאֶת־בֵּיתוֹ חֹדֶשׁ בַּשָּׁנָה יִהְיֶה עַל־[הָאֶחָד] (אחד) לְכַלְכֵּל׃}
}
{
	\eX{
		And Solomon had twelve officers over all Israel, which provided
		food for the king and his household: each man his month in a
		year made provision.
	}
}
{
}

\Verse{8}
{
	\hX{וְאֵלֶּה שְׁמוֹתָם בֶּן־חוּר בְּהַר אֶפְרָיִם׃}
}
{
	\eX{And these are their names: The son of Hur, in mount Ephraim:}
}
{
}

\Verse{9}
{
	\hX{בֶּן־דֶּקֶר בְּמָקַץ וּבְשַׁעַלְבִים וּבֵית שָׁמֶשׁ וְאֵילוֹן בֵּית חָנָן׃}
}
{
	\eX{
		The son of Dekar, in Makaz, and in Shaalbim, and Bethshemesh,
		and Elonbethhanan:
	}
}
{
}

\Verse{10}
{
	\hX{בֶּן־חֶסֶד בָּאֲרֻבּוֹת לוֹ שֹׂכֹה וְכל־אֶרֶץ חֵפֶר׃}
}
{
	\eX{
		The son of Hesed, in Aruboth: to him pertained Sochoh, and all
		the land of Hepher:
	}
}
{
}

\Verse{11}
{
	\hX{בֶּן־אֲבִינָדָב כּל־נָפַת דֹּאר טָפַת בַּת־שְׁלֹמֹה הָיְתָה לּוֹ לְאִשָּׁה׃}
}
{
	\eX{
		The son of Abinadab, in all the region of Dor: which had Taphath
		the daughter of Solomon to wife:
	}
}
{
}

\Verse{12}
{
	\hX{בַּעֲנָא בֶּן־אֲחִילוּד תַּעְנַךְ וּמְגִדּוֹ וְכל־בֵּית שְׁאָן אֲשֶׁר אֵצֶל צָרְתַנָה מִתַּחַת לְיִזְרְעֶאל מִבֵּית שְׁאָן עַד אָבֵל מְחוֹלָה עַד מֵעֵבֶר לְיקְמְעָם׃}
}
{
	\eX{
		Baana the son of Ahilud: to him pertained Taanach and Megiddo,
		and all Bethshean, which is by Zartanah beneath Jezreel, from
		Bethshean to Abelmeholah, even to the place that is beyond
		Jokneam:
	}
}
{
}

\Verse{13}
{
	\hX{בֶּן־גֶּבֶר בְּרָמֹת גִּלְעָד לוֹ חַוֺּת יָאִיר בֶּן־מְנַשֶּׁה אֲשֶׁר בַּגִּלְעָד לוֹ חֶבֶל אַרְגֹּב אֲשֶׁר בַּבָּשָׁן שִׁשִּׁים עָרִים גְּדֹלוֹת חוֹמָה וּבְרִיחַ נְחֹשֶׁת׃}
}
{
	\eX{
		The son of Geber, in Ramothgilead: to him pertained the towns of
		Jair the son of Manasseh, which are in Gilead: to him also
		pertained the region of Argob, which is in Bashan, sixty great
		cities with walls and bronze bars:
	}
}
{
}

\Verse{14}
{
	\hX{אֲחִינָדָב בֶּן־עִדֹּא מַחֲנָיְמָה׃}
}
{
	\eX{Ahinadab the son of Iddo had Mahanaim:}
}
{
}

\Verse{15}
{
	\hX{אֲחִימַעַץ בְּנַפְתָּלִי גַּם־הוּא לָקַח אֶת־בָּשְׂמַת בַּת־שְׁלֹמֹה לְאִשָּׁה׃}
}
{
	\eX{
		Ahimaaz was in Naphtali: he also took Basmath the daughter of
		Solomon to wife:
	}
}
{
}

\Verse{16}
{
	\hX{בַּעֲנָא בֶּן־חוּשָׁי בְּאָשֵׁר וּבְעָלוֹת׃}
}
{
	\eX{Baanah the son of Hushai was in Asher and in Aloth:}
}
{
}

\Verse{17}
{
	\hX{יְהוֹשָׁפָט בֶּן־פָּרוּחַ בְּיִשָּׂשכָר׃}
}
{
	\eX{Jehoshaphat the son of Paruah, in Issachar:}
}
{
}

\Verse{18}
{
	\hX{שִׁמְעִי בֶן־אֵלָא בְּבִנְיָמִן׃}
}
{
	\eX{Shimei the son of Elah, in Benjamin:}
}
{
}

\Verse{19}
{
	\hX{גֶּבֶר בֶּן־אֻרִי בְּאֶרֶץ גִּלְעָד אֶרֶץ סִיחוֹן מֶלֶךְ הָאֱמֹרִי וְעֹג מֶלֶךְ הַבָּשָׁן וּנְצִיב אֶחָד אֲשֶׁר בָּאָרֶץ׃}
}
{
	\eX{
		Geber the son of Uri was in the country of Gilead, in the
		country of Sihon king of the Amorites, and of Og king of Bashan:
		and he was the only officer that was in the land.
	}
}
{
}

\Verse{20}
{
	\hX{יְהוּדָה וְיִשְׂרָאֵל רַבִּים כַּחוֹל אֲשֶׁר־עַל־הַיָּם לָרֹב אֹכְלִים וְשֹׁתִים וּשְׂמֵחִים׃}
}
{
	\eX{
		Judah and Israel were many, as the sand which is by the sea in
		multitude, eating and drinking, and making merry.
	}
}
{
}
