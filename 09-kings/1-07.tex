	\hX{וְאַרְבָּעָה אוֹפַנֵּי נְחֹשֶׁת לַמְּכוֹנָה הָאַחַת וְסַרְנֵי נְחֹשֶׁת וְאַרְבָּעָה פַעֲמֹתָיו כְּתֵפֹת לָהֶם מִתַּחַת לַכִּיֹּר הַכְּתֵפוֹת יְצֻקוֹת מֵעֵבֶר אִישׁ לֹיוֹת׃}
}
{
	\eX{
		And every base had four bronze wheels, and plates of brass: and
		the four corners of it had undersetters: under the laver were
		undersetters molten, at the side of every addition.
	}
}
{
}

\Verse{31}
{
	\hX{וּפִיהוּ מִבֵּית לַכֹּתֶרֶת וָמַעְלָה בָּאַמָּה וּפִיהָ עָגֹל מַעֲשֵׂה־כֵן אַמָּה וַחֲצִי הָאַמָּה וְגַם־עַל־פִּיהָ מִקְלָעוֹת וּמִסְגְּרֹתֵיהֶם מְרֻבָּעוֹת לֹא עֲגֻלּוֹת׃}
}
{
	\eX{
		And the mouth of it within the chapiter and above was a cubit:
		but the mouth of it was round after the work of the base, a
		cubit and an half: and also on the mouth of it were gravings
		with their borders, foursquare, not round.
	}
}
{
}

\Verse{32}
{
	\hX{וְאַרְבַּעַת הָאוֹפַנִּים לְמִתַּחַת לַמִּסְגְּרוֹת וִידוֹת הָאוֹפַנִּים בַּמְּכוֹנָה וְקוֹמַת הָאוֹפַן הָאֶחָד אַמָּה וַחֲצִי הָאַמָּה׃}
}
{
	\eX{
		And under the borders were four wheels: and the axletrees of the
		wheels were joined to the base: and the height of a wheel was a
		cubit and half a cubit.
	}
}
{
}

\Verse{33}
{
	\hX{וּמַעֲשֵׂה הָאוֹפַנִּים כְּמַעֲשֵׂה אוֹפַן הַמֶּרְכָּבָה יְדוֹתָם וְגַבֵּיהֶם וְחִשֻּׁקֵיהֶם וְחִשֻּׁרֵיהֶם הַכֹּל מוּצָק׃}
}
{
	\eX{
		And the work of the wheels was like the work of a chariot wheel:
		their axletrees, and their naves, and their felloes, and their
		spokes, were all molten.
	}
}
{
}

\Verse{34}
{
	\hX{וְאַרְבַּע כְּתֵפוֹת אֶל אַרְבַּע פִּנּוֹת הַמְּכֹנָה הָאֶחָת מִן־הַמְּכֹנָה כְּתֵפֶיהָ׃}
}
{
	\eX{
		And there were four undersetters to the four corners of one
		base: and the undersetters were of the very base itself.
	}
}
{
}

\Verse{35}
{
	\hX{וּבְרֹאשׁ הַמְּכוֹנָה חֲצִי הָאַמָּה קוֹמָה עָגֹל סָבִיב וְעַל רֹאשׁ הַמְּכֹנָה יְדֹתֶיהָ וּמִסְגְּרֹתֶיהָ מִמֶּנָּה׃}
}
{
	\eX{
		And in the top of the base was there a round compass of half a
		cubit high: and on the top of the base the ledges of it and the
		borders of it were of the same.
	}
}
{
}

\Verse{36}
{
	\hX{וַיְפַתַּח עַל־הַלֻּחֹת יְדֹתֶיהָ וְעַל (ומסגרתיה) [מִסְגְּרֹתֶיהָ] כְּרוּבִים אֲרָיוֹת וְתִמֹרֹת כְּמַעַר־אִישׁ וְלֹיוֹת סָבִיב׃}
}
{
	\eX{
		For on the plates of the ledges of it, and on the borders of it,
		he graved cherubims, lions, and palm trees, according to the

	}
}

	Qere Ketiv.

\Verse{38}
{
	\hX{וַיַּעַשׂ עֲשָׂרָה כִיֹּרוֹת נְחֹשֶׁת אַרְבָּעִים בַּת יָכִיל הַכִּיּוֹר הָאֶחָד אַרְבַּע בָּאַמָּה הַכִּיּוֹר הָאֶחָד כִּיּוֹר אֶחָד עַל־הַמְּכוֹנָה הָאַחַת לְעֶשֶׂר הַמְּכֹנוֹת׃}
}
{
	\eX{

{
}

\Verse{39}
{
	\hX{וַיִּתֵּן אֶת־הַמְּכֹנוֹת חָמֵשׁ עַל־כֶּתֶף הַבַּיִת מִיָּמִין וְחָמֵשׁ עַל־כֶּתֶף הַבַּיִת מִשְּׂמֹאלוֹ וְאֶת־הַיָּם נָתַן מִכֶּתֶף הַבַּיִת הַיְמָנִית קֵדְמָה מִמּוּל נֶגֶב׃}
}
{
	\eX{

}
{
}

\Verse{40}
