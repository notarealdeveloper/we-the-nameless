\Chapter{13}

\Verse{1}
{
	\hX{בִּשְׁנַת עֶשְׂרִים וְשָׁלֹשׁ שָׁנָה לְיוֹאָשׁ בֶּן־אֲחַזְיָהוּ מֶלֶךְ יְהוּדָה מָלַךְ יְהוֹאָחָז בֶּן־יֵהוּא עַל־יִשְׂרָאֵל בְּשֹׁמְרוֹן שְׁבַע עֶשְׂרֵה שָׁנָה׃}
}
{
	\eX{
		In the three and twentieth year of Joash the son of Ahaziah king
		of Judah Jehoahaz the son of Jehu began to reign over Israel in
		Samaria, and reigned seventeen years.
	}
}
{
}

\Verse{2}
{
	\hX{וַיַּעַשׂ הָרַע בְּעֵינֵי יְהֹוָה וַיֵּלֶךְ אַחַר חַטֹּאת יָרבְעָם בֶּן־נְבָט אֲשֶׁר־הֶחֱטִיא אֶת־יִשְׂרָאֵל לֹא־סָר מִמֶּנָּה׃}
}
{
	\eX{
		And he did that that was bad in the eyes of YHWH, and followed
		the sins of Jeroboam the son of Nebat, that made Israel to sin:
		he didn't depart therefrom.
	}
}
{
}

\Verse{3}
{
	\hX{וַיִּחַר־אַף יְהֹוָה בְּיִשְׂרָאֵל וַיִּתְּנֵם בְּיַד חֲזָאֵל מֶלֶךְ־אֲרָם וּבְיַד בֶּן־הֲדַד בֶּן־חֲזָאֵל כּל־הַיָּמִים׃}
}
{
	\eX{
		And the anger of YHWH was kindled against Israel, and he
		delivered them into the hand of Hazael king of Aram, and into
		the hand of Benhadad the son of Hazael, all their days.
	}
}
{
}

\Verse{4}
{
	\hX{וַיְחַל יְהוֹאָחָז אֶת־פְּנֵי יְהֹוָה וַיִּשְׁמַע אֵלָיו יְהֹוָה כִּי רָאָה אֶת־לַחַץ יִשְׂרָאֵל כִּי־לָחַץ אֹתָם מֶלֶךְ אֲרָם׃}
}
{
	\eX{
		And Jehoahaz pleaded with YHWH, and YHWH hearkened to him: for
		he saw the oppression of Israel, because the king of Aram
		oppressed them.
	}
}
{
}

\Verse{5}
{
	\hX{וַיִּתֵּן יְהֹוָה לְיִשְׂרָאֵל מוֹשִׁיעַ וַיֵּצְאוּ מִתַּחַת יַד־אֲרָם וַיֵּשְׁבוּ בְנֵי־יִשְׂרָאֵל בְּאהֳלֵיהֶם כִּתְמוֹל שִׁלְשׁוֹם׃}
}
{
	\eX{
		(And YHWH gave Israel a saviour, so that they went out from
		under the hand of the Arameans: and the children of Israel lived
		in their tents, as beforetime.
	}
}
{
}

\Verse{6}
{
	\hX{אַךְ לֹא־סָרוּ מֵחַטֹּאת בֵּית־יָרבְעָם אֲשֶׁר־הֶחֱטִי אֶת־יִשְׂרָאֵל בָּהּ הָלָךְ וְגַם הָאֲשֵׁרָה עָמְדָה בְּשֹׁמְרוֹן׃}
}
{
	\eX{
		But they didn't depart from the sins of the house of Jeroboam,
		who made Israel sin, but walked in it: and there remained the
		grove also in Samaria.)
	}
}
{
}

\Verse{7}
{
	\hX{כִּי לֹא הִשְׁאִיר לִיהוֹאָחָז עָם כִּי אִם־חֲמִשִּׁים פָּרָשִׁים וַעֲשָׂרָה רֶכֶב וַעֲשֶׂרֶת אֲלָפִים רַגְלִי כִּי אִבְּדָם מֶלֶךְ אֲרָם וַיְשִׂמֵם כֶּעָפָר לָדֻשׁ׃}
}
{
	\eX{
		Neither did he leave of the people to Jehoahaz but fifty
		horsemen, and ten chariots, and ten thousand footmen: for the
		king of Aram had destroyed them, and had made them like the dust
		by threshing.
	}
}
{
}

\Verse{8}
{
	\hX{וְיֶתֶר דִּבְרֵי יְהוֹאָחָז וְכל־אֲשֶׁר עָשָׂה וּגְבוּרָתוֹ הֲלוֹא־הֵם כְּתוּבִים עַל־סֵפֶר דִּבְרֵי הַיָּמִים לְמַלְכֵי יִשְׂרָאֵל׃}
}
{
	\eX{
		And the rest of the acts of Jehoahaz, and all that he did, and
		his might, are they not written in the book of the chronicles of
		the kings of Israel?
	}
}
{
}

\Verse{9}
{
	\hX{וַיִּשְׁכַּב יְהוֹאָחָז עִם־אֲבֹתָיו וַיִּקְבְּרֻהוּ בְּשֹׁמְרוֹן וַיִּמְלֹךְ יוֹאָשׁ בְּנוֹ תַּחְתָּיו׃}
}
{
	\eX{
		And Jehoahaz slept with his fathers: and they buried him in
		Samaria: and Joash his son reigned in his place.
	}
}
{
}

\Verse{10}
{
	\hX{בִּשְׁנַת שְׁלֹשִׁים וָשֶׁבַע שָׁנָה לְיוֹאָשׁ מֶלֶךְ יְהוּדָה מָלַךְ יְהוֹאָשׁ בֶּן־יְהוֹאָחָז עַל־יִשְׂרָאֵל בְּשֹׁמְרוֹן שֵׁשׁ עֶשְׂרֵה שָׁנָה׃}
}
{
	\eX{
		In the thirty and seventh year of Joash king of Judah began
		Jehoash the son of Jehoahaz to reign over Israel in Samaria, and
		reigned sixteen years.
	}
}
{
}

\Verse{11}
{
	\hX{וַיַּעֲשֶׂה הָרַע בְּעֵינֵי יְהֹוָה לֹא סָר מִכּל־חַטֹּאות יָרבְעָם בֶּן־נְבָט אֲשֶׁר־הֶחֱטִיא אֶת־יִשְׂרָאֵל בָּהּ הָלָךְ׃}
}
{
	\eX{
		And he did that that was bad in the eyes of YHWH: he didn't
		depart from all the sins of Jeroboam the son of Nebat, who made
		Israel sin: but he walked in it.
	}
}
{
}

\Verse{12}
{
	\hX{וְיֶתֶר דִּבְרֵי יוֹאָשׁ וְכל־אֲשֶׁר עָשָׂה וּגְבוּרָתוֹ אֲשֶׁר נִלְחַם עִם אֲמַצְיָה מֶלֶךְ־יְהוּדָה הֲלֹא־הֵם כְּתוּבִים עַל־סֵפֶר דִּבְרֵי הַיָּמִים לְמַלְכֵי יִשְׂרָאֵל׃}
}
{
	\eX{
		And the rest of the acts of Joash, and all that he did, and his
		might with which he fought against Amaziah king of Judah, are
		they not written in the book of the chronicles of the kings of
		Israel?
	}
}
{
}

\Verse{13}
{
	\hX{וַיִּשְׁכַּב יוֹאָשׁ עִם־אֲבֹתָיו וְיָרבְעָם יָשַׁב עַל־כִּסְאוֹ וַיִּקָּבֵר יוֹאָשׁ בְּשֹׁמְרוֹן עִם מַלְכֵי יִשְׂרָאֵל׃}
}
{
	\eX{
		And Joash slept with his fathers: and Jeroboam sat on his
		throne: and Joash was buried in Samaria with the kings of
		Israel.
	}
}
{
}

\Verse{14}
{
	\hX{וֶאֱלִישָׁע חָלָה אֶת־חלְיוֹ אֲשֶׁר יָמוּת בּוֹ וַיֵּרֶד אֵלָיו יוֹאָשׁ מֶלֶךְ־יִשְׂרָאֵל וַיֵּבְךְּ עַל־פָּנָיו וַיֹּאמַר אָבִי אָבִי רֶכֶב יִשְׂרָאֵל וּפָרָשָׁיו׃}
}
{
	\eX{
		And Elisha was fallen sick of his sickness of which he died. And
		Joash the king of Israel came down to him, and wept over his
		face, and said, O my father, my father, the chariot of Israel,
		and the horsemen.
	}
}
{
}

\Verse{15}
{
	\hX{וַיֹּאמֶר לוֹ אֱלִישָׁע קַח קֶשֶׁת וְחִצִּים וַיִּקַּח אֵלָיו קֶשֶׁת וְחִצִּים׃}
}
{
	\eX{
		And Elisha said to him, Take bow and arrows. And he took to him
		bow and arrows.
	}
}
{
}

\Verse{16}
{
	\hX{וַיֹּאמֶר לְמֶלֶךְ יִשְׂרָאֵל הַרְכֵּב יָדְךָ עַל־הַקֶּשֶׁת וַיַּרְכֵּב יָדוֹ וַיָּשֶׂם אֱלִישָׁע יָדָיו עַל־יְדֵי הַמֶּלֶךְ׃}
}
{
	\eX{
		And he said to the king of Israel, Put yours hand on the bow.
		And he put his hand on it: and Elisha put his hands on the
		king's hands.
	}
}
{
}

\Verse{17}
{
	\hX{
		וַיֹּאמֶר פְּתַח הַחַלּוֹן קֵדְמָה וַיִּפְתָּח וַיֹּאמֶר אֱלִישָׁע יְרֵה וַיּוֹר וַיֹּאמֶר חֵץ־תְּשׁוּעָה לַיהֹוָה וְחֵץ תְּשׁוּעָה בַאֲרָם וְהִכִּיתָ אֶת־אֲרָם בַּאֲפֵק
		עַד־כַּלֵּה׃
	}
}
{
	\eX{
		And he said, Open the window eastward. And he opened it. And
		Elisha said, Shoot. And he shot. And he said, The arrow of
		YHWH's deliverance, and the arrow of deliverance from Aram: for
		you shall smite the Arameans in Aphek, till you have consumed
		them.
	}
}
{
}

\Verse{18}
{
	\hX{וַיֹּאמֶר קַח הַחִצִּים וַיִּקָּח וַיֹּאמֶר לְמֶלֶךְ־יִשְׂרָאֵל הַךְ־אַרְצָה וַיַּךְ שָׁלֹשׁ־פְּעָמִים וַיַּעֲמֹד׃}
}
{
	\eX{
		And he said, Take the arrows. And he took them. And he said to
		the king of Israel, Smite on the ground. And he struck thrice,
		and stayed.
	}
}
{
}

\Verse{19}
{
	\hX{וַיִּקְצֹף עָלָיו אִישׁ הָאֱלֹהִים וַיֹּאמֶר לְהַכּוֹת חָמֵשׁ אוֹ־שֵׁשׁ פְּעָמִים אָז הִכִּיתָ אֶת־אֲרָם עַד־כַּלֵּה וְעַתָּה שָׁלֹשׁ פְּעָמִים תַּכֶּה אֶת־אֲרָם׃}
}
{
	\eX{
		And the man of God was angry with him, and said, You should have
		struck five or six times: then hadst you struck Aram till you
		hadst consumed it: whereas now you shall smite Aram but thrice.
	}
}
{
}

\Verse{20}
{
	\hX{וַיָּמת אֱלִישָׁע וַיִּקְבְּרֻהוּ וּגְדוּדֵי מוֹאָב יָבֹאוּ בָאָרֶץ בָּא שָׁנָה׃}
}

\Verse{21}
{
	\hX{
		וַיְהִי הֵם קֹבְרִים אִישׁ וְהִנֵּה רָאוּ אֶת־הַגְּדוּד וַיַּשְׁלִיכוּ אֶת־הָאִישׁ בְּקֶבֶר אֱלִישָׁע וַיֵּלֶךְ וַיִּגַּע הָאִישׁ בְּעַצְמוֹת אֱלִישָׁע וַיְחִי וַיָּקם
		עַל־רַגְלָיו׃

}

	\eX{

		when the man was let down, and touched the bones of Elisha, he
		revived, and stood up on his feet.
	}
}
{
}

{
	\hX{וַחֲזָאֵל מֶלֶךְ אֲרָם לָחַץ אֶת־יִשְׂרָאֵל כֹּל יְמֵי יְהוֹאָחָז׃}

\Verse{23}

	}
}
{
}

\Verse{25}

	}
}
{
