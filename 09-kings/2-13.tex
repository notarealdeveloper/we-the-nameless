\Chapter{13}

\Verse{1}
{
	\hX{בִּשְׁנַת עֶשְׂרִים וְשָׁלֹשׁ שָׁנָה לְיוֹאָשׁ בֶּן־אֲחַזְיָהוּ מֶלֶךְ יְהוּדָה מָלַךְ יְהוֹאָחָז בֶּן־יֵהוּא עַל־יִשְׂרָאֵל בְּשֹׁמְרוֹן שְׁבַע עֶשְׂרֵה שָׁנָה׃}
}
{
	\eX{
		In the twenty-third year of King Joash son of Ahaziah of Judah,
		Jehoahaz son of Jehu became king over Israel in Samaria—for
		seventeen years.
	}
}
{
}

\Verse{2}
{
	\hX{וַיַּעַשׂ הָרַע בְּעֵינֵי יְהֹוָה וַיֵּלֶךְ אַחַר חַטֹּאת יָרבְעָם בֶּן־נְבָט אֲשֶׁר־הֶחֱטִיא אֶת־יִשְׂרָאֵל לֹא־סָר מִמֶּנָּה׃}
}
{
	\eX{
		He did what was displeasing to YHWH. He persisted in the sins
		which Jeroboam son of Nebat had caused Israel to commit; he did
		not depart from them.
	}
}
{
}

\Verse{3}
{
	\hX{וַיִּחַר־אַף יְהֹוָה בְּיִשְׂרָאֵל וַיִּתְּנֵם בְּיַד חֲזָאֵל מֶלֶךְ־אֲרָם וּבְיַד בֶּן־הֲדַד בֶּן־חֲזָאֵל כּל־הַיָּמִים׃}
}
{
	\eX{
		YHWH was angry with Israel and He repeatedly delivered them into
		the hands of King Hazael of Aram and into the hands of Ben-hadad
		son of Hazael.
	}
}
{
}

\Verse{4}
{
	\hX{וַיְחַל יְהוֹאָחָז אֶת־פְּנֵי יְהֹוָה וַיִּשְׁמַע אֵלָיו יְהֹוָה כִּי רָאָה אֶת־לַחַץ יִשְׂרָאֵל כִּי־לָחַץ אֹתָם מֶלֶךְ אֲרָם׃}
}
{
	\eX{
		But Jehoahaz pleaded with YHWH; and YHWH listened to him, for He
		saw the suffering that the king of Aram inflicted upon Israel.
	}
}
{
}

\Verse{5}
{
	\hX{וַיִּתֵּן יְהֹוָה לְיִשְׂרָאֵל מוֹשִׁיעַ וַיֵּצְאוּ מִתַּחַת יַד־אֲרָם וַיֵּשְׁבוּ בְנֵי־יִשְׂרָאֵל בְּאהֳלֵיהֶם כִּתְמוֹל שִׁלְשׁוֹם׃}
}
{
	\eX{
		So YHWH granted Israel a deliverer, and they gained their freedom
		from Aram; and Israel dwelt in its homes as before.
	}
}
{
}

\Verse{6}
{
	\hX{אַךְ לֹא־סָרוּ מֵחַטֹּאת בֵּית־יָרבְעָם אֲשֶׁר־הֶחֱטִי אֶת־יִשְׂרָאֵל בָּהּ הָלָךְ וְגַם הָאֲשֵׁרָה עָמְדָה בְּשֹׁמְרוֹן׃}
}
{
	\eX{
		However, they did not depart from the sins which the House of
		Jeroboam had caused Israel to commit; they persisted in them. Even
		the sacred post stood in Samaria.
	}
}
{
}

\Verse{7}
{
	\hX{כִּי לֹא הִשְׁאִיר לִיהוֹאָחָז עָם כִּי אִם־חֲמִשִּׁים פָּרָשִׁים וַעֲשָׂרָה רֶכֶב וַעֲשֶׂרֶת אֲלָפִים רַגְלִי כִּי אִבְּדָם מֶלֶךְ אֲרָם וַיְשִׂמֵם כֶּעָפָר לָדֻשׁ׃}
}
{
	\eX{
		In fact, Jehoahaz was left with a force of only fifty horsemen,
		ten chariots, and ten thousand foot soldiers; for the king of Aram
		had decimated them and trampled them like the dust under his feet.
	}
}
{
}

\Verse{8}
{
	\hX{וְיֶתֶר דִּבְרֵי יְהוֹאָחָז וְכל־אֲשֶׁר עָשָׂה וּגְבוּרָתוֹ הֲלוֹא־הֵם כְּתוּבִים עַל־סֵפֶר דִּבְרֵי הַיָּמִים לְמַלְכֵי יִשְׂרָאֵל׃}
}
{
	\eX{
		The other events of Jehoahaz’s reign, and all his actions and his
		exploits, are recorded in the Annals of the Kings of Israel.
	}
}
{
}

\Verse{9}
{
	\hX{וַיִּשְׁכַּב יְהוֹאָחָז עִם־אֲבֹתָיו וַיִּקְבְּרֻהוּ בְּשֹׁמְרוֹן וַיִּמְלֹךְ יוֹאָשׁ בְּנוֹ תַּחְתָּיו׃}
}
{
	\eX{
		Jehoahaz slept with his fathers and he was buried in Samaria; his
		son Joash succeeded him as king.
	}
}
{
}

\Verse{10}
{
	\hX{בִּשְׁנַת שְׁלֹשִׁים וָשֶׁבַע שָׁנָה לְיוֹאָשׁ מֶלֶךְ יְהוּדָה מָלַךְ יְהוֹאָשׁ בֶּן־יְהוֹאָחָז עַל־יִשְׂרָאֵל בְּשֹׁמְרוֹן שֵׁשׁ עֶשְׂרֵה שָׁנָה׃}
}
{
	\eX{
		In the thirty-seventh year of King Joash of Judah, Jehoash son of
		Jehoahaz became king of Israel in Samaria—for sixteen years.
	}
}
{
}

\Verse{11}
{
	\hX{וַיַּעֲשֶׂה הָרַע בְּעֵינֵי יְהֹוָה לֹא סָר מִכּל־חַטֹּאות יָרבְעָם בֶּן־נְבָט אֲשֶׁר־הֶחֱטִיא אֶת־יִשְׂרָאֵל בָּהּ הָלָךְ׃}
}
{
	\eX{
		He did what was displeasing to YHWH; he did not depart from any of
		the sins which Jeroboam son of Nebat had caused Israel to commit;
		he persisted in them.
	}
}
{
}

\Verse{12}
{
	\hX{וְיֶתֶר דִּבְרֵי יוֹאָשׁ וְכל־אֲשֶׁר עָשָׂה וּגְבוּרָתוֹ אֲשֶׁר נִלְחַם עִם אֲמַצְיָה מֶלֶךְ־יְהוּדָה הֲלֹא־הֵם כְּתוּבִים עַל־סֵפֶר דִּבְרֵי הַיָּמִים לְמַלְכֵי יִשְׂרָאֵל׃}
}
{
	\eX{
		The other events of Joash’s reign, and all his actions, and his
		exploits in his war with King Amaziah of Judah, are recorded in
		the Annals of the Kings of Israel.
	}
}
{
}

\Verse{13}
{
	\hX{וַיִּשְׁכַּב יוֹאָשׁ עִם־אֲבֹתָיו וְיָרבְעָם יָשַׁב עַל־כִּסְאוֹ וַיִּקָּבֵר יוֹאָשׁ בְּשֹׁמְרוֹן עִם מַלְכֵי יִשְׂרָאֵל׃}
}
{
	\eX{
		Joash slept with his fathers and Jeroboam occupied his throne;
		Joash was buried in Samaria with the kings of Israel.
	}
}
{
}

\Verse{14}
{
	\hX{וֶאֱלִישָׁע חָלָה אֶת־חלְיוֹ אֲשֶׁר יָמוּת בּוֹ וַיֵּרֶד אֵלָיו יוֹאָשׁ מֶלֶךְ־יִשְׂרָאֵל וַיֵּבְךְּ עַל־פָּנָיו וַיֹּאמַר אָבִי אָבִי רֶכֶב יִשְׂרָאֵל וּפָרָשָׁיו׃}
}
{
	\eX{
		Elisha had been stricken with the illness of which he was to die,
		and King Joash of Israel went down to see him. He wept over him
		and cried, “Father, father! Israel’s chariots and horsemen!”
	}
}
{
}

\Verse{15}
{
	\hX{וַיֹּאמֶר לוֹ אֱלִישָׁע קַח קֶשֶׁת וְחִצִּים וַיִּקַּח אֵלָיו קֶשֶׁת וְחִצִּים׃}
}
{
	\eX{
		Elisha said to him, “Get a bow and arrows”; and he brought him a
		bow and arrows.
	}
}
{
}

\Verse{16}
{
	\hX{וַיֹּאמֶר לְמֶלֶךְ יִשְׂרָאֵל הַרְכֵּב יָדְךָ עַל־הַקֶּשֶׁת וַיַּרְכֵּב יָדוֹ וַיָּשֶׂם אֱלִישָׁע יָדָיו עַל־יְדֵי הַמֶּלֶךְ׃}
}
{
	\eX{
		Then he said to the king of Israel, “Grasp the bow!” And when he
		had grasped it, Elisha put his hands over the king’s hands.
	}
}
{
}

\Verse{17}
{
	\hX{
		וַיֹּאמֶר פְּתַח הַחַלּוֹן קֵדְמָה וַיִּפְתָּח וַיֹּאמֶר אֱלִישָׁע יְרֵה וַיּוֹר וַיֹּאמֶר חֵץ־תְּשׁוּעָה לַיהֹוָה וְחֵץ תְּשׁוּעָה בַאֲרָם וְהִכִּיתָ אֶת־אֲרָם בַּאֲפֵק
		עַד־כַּלֵּה׃
	}
}
{
	\eX{
		“Open the window toward the east,” he said; and he opened it.
		Elisha said, “Shoot!” and he shot. Then he said, “An arrow of
		victory for YHWH! An arrow of victory over Aram! You shall rout
		Aram completely at Aphek.”
	}
}
{
}

\Verse{18}
{
	\hX{וַיֹּאמֶר קַח הַחִצִּים וַיִּקָּח וַיֹּאמֶר לְמֶלֶךְ־יִשְׂרָאֵל הַךְ־אַרְצָה וַיַּךְ שָׁלֹשׁ־פְּעָמִים וַיַּעֲמֹד׃}
}
{
	\eX{
		He said, “Now pick up the arrows.” And he picked them up. “Strike
		the ground!” he said to the king of Israel; and he struck three
		times and stopped.
	}
}
{
}

\Verse{19}
{
	\hX{וַיִּקְצֹף עָלָיו אִישׁ הָאֱלֹהִים וַיֹּאמֶר לְהַכּוֹת חָמֵשׁ אוֹ־שֵׁשׁ פְּעָמִים אָז הִכִּיתָ אֶת־אֲרָם עַד־כַּלֵּה וְעַתָּה שָׁלֹשׁ פְּעָמִים תַּכֶּה אֶת־אֲרָם׃}
}
{
	\eX{
		The man of God was angry with him and said to him, “If only you
		had struck five or six times! Then you would have annihilated
		Aram; as it is, you shall defeat Aram only three times.”
	}
}
{
}

\Verse{20}
{
	\hX{וַיָּמת אֱלִישָׁע וַיִּקְבְּרֻהוּ וּגְדוּדֵי מוֹאָב יָבֹאוּ בָאָרֶץ בָּא שָׁנָה׃}
}
{
	\eX{
		Elisha died and he was buried. Now bands of Moabites used to
		invade the land at the coming of every year.
	}
}
{
}

\Verse{21}
{
	\hX{
		וַיְהִי הֵם קֹבְרִים אִישׁ וְהִנֵּה רָאוּ אֶת־הַגְּדוּד וַיַּשְׁלִיכוּ אֶת־הָאִישׁ בְּקֶבֶר אֱלִישָׁע וַיֵּלֶךְ וַיִּגַּע הָאִישׁ בְּעַצְמוֹת אֱלִישָׁע וַיְחִי וַיָּקם
		עַל־רַגְלָיו׃
	}
}
{
	\eX{
		Once a man was being buried, when the people caught sight of such
		a band; so they threw the corpse into Elisha’s grave and made off.
		When the [dead] man came in contact with Elisha’s bones, he came
		to life and stood up.
	}
}
{
}

\Verse{22}
{
	\hX{וַחֲזָאֵל מֶלֶךְ אֲרָם לָחַץ אֶת־יִשְׂרָאֵל כֹּל יְמֵי יְהוֹאָחָז׃}
}
{
	\eX{
		King Hazael of Aram had oppressed the Israelites throughout the
		reign of Jehoahaz.
	}
}
{
}

\Verse{23}
{
	\hX{וַיָּחן יְהֹוָה אֹתָם וַיְרַחֲמֵם וַיִּפֶן אֲלֵיהֶם לְמַעַן בְּרִיתוֹ אֶת־אַבְרָהָם יִצְחָק וְיַעֲקֹב וְלֹא אָבָה הַשְׁחִיתָם וְלֹא־הִשְׁלִיכָם מֵעַל־פָּנָיו עַד־עָתָּה׃}
}
{
	\eX{
		But YHWH was gracious and merciful to them, and He turned back to
		them for the sake of His covenant with Abraham, Isaac, and Jacob.
		He refrained from destroying them, and He still did not cast them
		out from His presence.
	}
}
{
}

\Verse{24}
{
	\hX{וַיָּמת חֲזָאֵל מֶלֶךְ־אֲרָם וַיִּמְלֹךְ בֶּן־הֲדַד בְּנוֹ תַּחְתָּיו׃}
}
{
	\eX{
		When King Hazael of Aram died, his son Ben-hadad succeeded him as
		king;
	}
}
{
}

\Verse{25}
{
	\hX{
		וַיָּשׁב יְהוֹאָשׁ בֶּן־יְהוֹאָחָז וַיִּקַּח אֶת־הֶעָרִים מִיַּד בֶּן־הֲדַד בֶּן־חֲזָאֵל אֲשֶׁר לָקַח מִיַּד יְהוֹאָחָז אָבִיו בַּמִּלְחָמָה שָׁלֹשׁ פְּעָמִים הִכָּהוּ יוֹאָשׁ
		וַיָּשֶׁב אֶת־עָרֵי יִשְׂרָאֵל׃
	}
}
{
	\eX{
		and then Jehoash son of Jehoahaz recovered from Ben-hadad son of
		Hazael the towns which had been taken from his father Jehoahaz in
		war. Three times Joash defeated him, and he recovered the towns of
		Israel.
	}
}
{
}
