{

{
	\eX{

{

}
{
	\eX{

{
	\eX{

		the elders also, and the bringers up of the children, sent to
		Jehu, saying, We are your servants, and will do all that you
		shall told us: we won't make any king: do you that that is good
		in your eyes.
	}
}
{
}

\Verse{6}
{
	\hX{

	}
}
{
	\eX{
		And he wrote a letter the second time to them, saying, If you be
		mine, and if you will hearken to my voice, take you the heads of
		the men your master's sons, and come to me to Jezreel by
		tomorrow this time. And the king's sons, being seventy persons,
		were with the great men of the city, that brought them up.

}
{
}

}
{
	\eX{

{

}
{
	\eX{

{
}

\Verse{9}

	\hX{וַיְהִי בַבֹּקֶר וַיֵּצֵא וַיַּעֲמֹד וַיֹּאמֶר אֶל־כּל־הָעָם צַדִּקִים אַתֶּם הִנֵּה אֲנִי קָשַׁרְתִּי עַל־אֲדֹנִי וָאֶהְרְגֵהוּ וּמִי הִכָּה אֶת־כּל־אֵלֶּה׃}
}
{
	\eX{
		And it was in the morning, that he went out, and stood, and said
		to all the people, You be righteous: here: I conspired against
		my master, and killed him: but who killed all these?
	}
}
{
}

	\eX{

{
}

	\eX{

{
}

{

\Verse{29}

{
	\eX{

\Verse{30}
{
	\hX{
		וַיֹּאמֶר יְהֹוָה אֶל־יֵהוּא יַעַן אֲשֶׁר־הֱטִיבֹתָ לַעֲשׂוֹת הַיָּשָׁר בְּעֵינַי כְּכֹל אֲשֶׁר בִּלְבָבִי עָשִׂיתָ לְבֵית אַחְאָב בְּנֵי רְבִעִים יֵשְׁבוּ לְךָ עַל־כִּסֵּא
		יִשְׂרָאֵל׃
	}
}
{
	\eX{
		And YHWH said to Jehu, Because you have done well in executing
		that that is right in my eyes, and have done to the house of
		Ahab according to all that was in my heart, your children of the
		fourth generation shall sit on the throne of Israel.
	}
}
{
}

}
{
	\eX{
		But Jehu took no heed to walk in the law of YHWH God of Israel

		Jeroboam, that made Israel to sin.
	}
}
{
