}
{
	\eX{
		And it was in the third year, that Jehoshaphat the king of Judah
		came down to the king of Israel.
	}
}
{
}

\Verse{3}

	\hX{וַיֹּאמֶר מֶלֶךְ־יִשְׂרָאֵל אֶל־עֲבָדָיו הַיְדַעְתֶּם כִּי־לָנוּ רָמֹת גִּלְעָד וַאֲנַחְנוּ מַחְשִׁים מִקַּחַת אֹתָהּ מִיַּד מֶלֶךְ אֲרָם׃}
}
{
	\eX{
		And the king of Israel said to his servants, Know you that
		Ramoth in Gilead is ours, and we be still, and take it not out
		of the hand of the king of Syria?
	}
}
{
}

\Verse{4}

}
{
	\eX{
		And he said to Jehoshaphat, Will you go with me to battle to
		Ramothgilead? And Jehoshaphat said to the king of Israel, I am

	}
}
{
}

}

	\eX{

	}

{
}

\Verse{6}

	\hX{

		בְּיַד הַמֶּלֶךְ׃

	\eX{

		Ramothgilead to battle, or shall I hold back? And they said, Go
		up: for YHWH shall deliver it into the hand of the king.
	}
}
{
}
