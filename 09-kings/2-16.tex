\Chapter{16}

\Verse{1}
{
	\hX{בִּשְׁנַת שְׁבַע־עֶשְׂרֵה שָׁנָה לְפֶקַח בֶּן־רְמַלְיָהוּ מָלַךְ אָחָז בֶּן־יוֹתָם מֶלֶךְ יְהוּדָה׃}
}
{
	\eX{
		In the seventeenth year of Pekah the son of Remaliah Ahaz the
		son of Jotham king of Judah began to reign.
	}
}
{
}

\Verse{2}
{
	\hX{בֶּן־עֶשְׂרִים שָׁנָה אָחָז בְּמלְכוֹ וְשֵׁשׁ־עֶשְׂרֵה שָׁנָה מָלַךְ בִּירוּשָׁלָ͏ִם וְלֹא־עָשָׂה הַיָּשָׁר בְּעֵינֵי יְהֹוָה אֱלֹהָיו כְּדָוִד אָבִיו׃}
}
{
	\eX{
		Twenty years old was Ahaz when he began to reign, and reigned
		sixteen years in Jerusalem, and didn't that that was right in
		the eyes of YHWH his God, like David his father.
	}
}
{
}

\Verse{3}
{
	\hX{וַיֵּלֶךְ בְּדֶרֶךְ מַלְכֵי יִשְׂרָאֵל וְגַם אֶת־בְּנוֹ הֶעֱבִיר בָּאֵשׁ כְּתֹעֲבוֹת הַגּוֹיִם אֲשֶׁר הוֹרִישׁ יְהֹוָה אֹתָם מִפְּנֵי בְּנֵי יִשְׂרָאֵל׃}
}
{
	\eX{
		But he walked in the way of the kings of Israel, yes, and made
		his son to pass through the fire, according to the abominations
		of the nations, whom YHWH cast out from before the children of
		Israel.
	}
}
{
}

\Verse{4}
{
	\hX{וַיְזַבֵּחַ וַיְקַטֵּר בַּבָּמוֹת וְעַל־הַגְּבָעוֹת וְתַחַת כּל־עֵץ רַעֲנָן׃}
}
{
	\eX{
		And he sacrificed and burned incense in the high places, and on
		the hills, and under every green tree.
	}
}
{
}

\Verse{5}
{
	\hX{אָז יַעֲלֶה רְצִין מֶלֶךְ־אֲרָם וּפֶקַח בֶּן־רְמַלְיָהוּ מֶלֶךְ־יִשְׂרָאֵל יְרוּשָׁלַ͏ִם לַמִּלְחָמָה וַיָּצֻרוּ עַל־אָחָז וְלֹא יָכְלוּ לְהִלָּחֵם׃}
}
{
	\eX{
		And Rezin king of Aram and Pekah son of Remaliah king of Israel
		came up to Jerusalem to war: and they laid siege to Ahaz, but
		could not overcome him.
	}
}
{
}

\Verse{6}
{
	\hX{בָּעֵת הַהִיא הֵשִׁיב רְצִין מֶלֶךְ־אֲרָם אֶת־אֵילַת לַאֲרָם וַיְנַשֵּׁל אֶת־הַיְּהוּדִים מֵאֵילוֹת (וארמים) [וַאֲדֹמִים] בָּאוּ אֵילַת וַיֵּשְׁבוּ שָׁם עַד הַיּוֹם הַזֶּה׃}
}
{
	\eX{
		At that time Rezin king of Aram recovered Elath to Aram, and
		drove the Jews from Elath: and the Arameans came to Elath, and
		lived there to this day.
	}
}
{
}

\Verse{7}
{
	\hX{
		וַיִּשְׁלַח אָחָז מַלְאָכִים אֶל־תִּגְלַת פְּלֶסֶר מֶלֶךְ־אַשּׁוּר לֵאמֹר עַבְדְּךָ וּבִנְךָ אָנִי עֲלֵה וְהוֹשִׁעֵנִי מִכַּף מֶלֶךְ־אֲרָם וּמִכַּף מֶלֶךְ יִשְׂרָאֵל הַקּוֹמִים
		עָלָי׃
	}
}
{
	\eX{
		So Ahaz sent messengers to Tiglathpileser king of Assyria,
		saying, I am your servant and your son: come up, and save me
		from the hand of the king of Aram, and from the hand of the king
		of Israel, that rise up against me.
	}
}
{
}

\Verse{8}
{
	\hX{וַיִּקַּח אָחָז אֶת־הַכֶּסֶף וְאֶת־הַזָּהָב הַנִּמְצָא בֵּית יְהֹוָה וּבְאֹצְרוֹת בֵּית הַמֶּלֶךְ וַיִּשְׁלַח לְמֶלֶךְ־אַשּׁוּר שֹׁחַד׃}
}
{
	\eX{
		And Ahaz took the silver and gold that was found in the house of
		YHWH, and in the treasures of the king's house, and sent it for
		a present to the king of Assyria.
	}
}
{
}

\Verse{9}
{
	\hX{וַיִּשְׁמַע אֵלָיו מֶלֶךְ אַשּׁוּר וַיַּעַל מֶלֶךְ אַשּׁוּר אֶל־דַּמֶּשֶׂק וַיִּתְפְּשֶׂהָ וַיַּגְלֶהָ קִירָה וְאֶת־רְצִין הֵמִית׃}
}
{
	\eX{
		And the king of Assyria hearkened to him: for the king of
		Assyria went up against Damascus, and took it, and carried the
		people of it captive to Kir, and killed Rezin.
	}
}
{
}

\Verse{10}
{
	\hX{
		וַיֵּלֶךְ הַמֶּלֶךְ אָחָז לִקְרַאת תִּגְלַת פִּלְאֶסֶר מֶלֶךְ־אַשּׁוּר דּוּמֶּשֶׂק וַיַּרְא אֶת־הַמִּזְבֵּחַ אֲשֶׁר בְּדַמָּשֶׂק וַיִּשְׁלַח הַמֶּלֶךְ אָחָז אֶל־אוּרִיָּה הַכֹּהֵן
		אֶת־דְּמוּת הַמִּזְבֵּחַ וְאֶת־תַּבְנִיתוֹ לְכל־מַעֲשֵׂהוּ׃
	}
}
{
	\eX{
		And king Ahaz went to Damascus to meet Tiglathpileser king of
		Assyria, and saw an altar that was at Damascus: and king Ahaz
		sent to Urijah the priest the fashion of the altar, and the
		pattern of it, according to all the workmanship of it.
	}
}
{
}

\Verse{11}
{
	\hX{וַיִּבֶן אוּרִיָּה הַכֹּהֵן אֶת־הַמִּזְבֵּחַ כְּכֹל אֲשֶׁר־שָׁלַח הַמֶּלֶךְ אָחָז מִדַּמֶּשֶׂק כֵּן עָשָׂה אוּרִיָּה הַכֹּהֵן עַד־בּוֹא הַמֶּלֶךְ־אָחָז מִדַּמָּשֶׂק׃}
}
{
	\eX{
		And Urijah the priest built an altar according to all that king
		Ahaz had sent from Damascus: so Urijah the priest made it
		against king Ahaz came from Damascus.
	}
}
{
}

\Verse{12}
{
	\hX{וַיָּבֹא הַמֶּלֶךְ מִדַּמֶּשֶׂק וַיַּרְא הַמֶּלֶךְ אֶת־הַמִּזְבֵּחַ וַיִּקְרַב הַמֶּלֶךְ עַל־הַמִּזְבֵּחַ וַיַּעַל עָלָיו׃}
}
{
	\eX{
		And when the king was come from Damascus, the king saw the
		altar: and the king approached to the altar, and offered
		thereon.
	}
}
{
}

\Verse{13}
{
	\hX{וַיַּקְטֵר אֶת־עֹלָתוֹ וְאֶת־מִנְחָתוֹ וַיַּסֵּךְ אֶת־נִסְכּוֹ וַיִּזְרֹק אֶת־דַּם־הַשְּׁלָמִים אֲשֶׁר־לוֹ עַל־הַמִּזְבֵּחַ׃}
}
{
	\eX{
		And he burned his burned offering and his food offering, and
		poured his drink offering, and sprinkled the blood of his peace
		offerings, on the altar.
	}
}
{
}

\Verse{14}
{
	\hX{וְאֵת הַמִּזְבַּח הַנְּחֹשֶׁת אֲשֶׁר לִפְנֵי יְהֹוָה וַיַּקְרֵב מֵאֵת פְּנֵי הַבַּיִת מִבֵּין הַמִּזְבֵּחַ וּמִבֵּין בֵּית יְהֹוָה וַיִּתֵּן אֹתוֹ עַל־יֶרֶךְ הַמִּזְבֵּחַ צָפוֹנָה׃}
}
{
	\eX{
		And he brought also the bronze altar, that was in front of YHWH,
		from the forefront of the house, from between the altar and the
		house of YHWH, and put it on the north side of the altar.
	}
}
{
}

\Verse{15}
{
	\hX{
		(ויצוהו) [וַיְצַוֶּה] הַמֶּלֶךְ־אָחָז אֶת־אוּרִיָּה הַכֹּהֵן לֵאמֹר עַל הַמִּזְבֵּחַ הַגָּדוֹל הַקְטֵר אֶת־עֹלַת־הַבֹּקֶר וְאֶת־מִנְחַת הָעֶרֶב וְאֶת־עֹלַת הַמֶּלֶךְ
		וְאֶת־מִנְחָתוֹ וְאֵת עֹלַת כּל־עַם הָאָרֶץ וּמִנְחָתָם וְנִסְכֵּיהֶם וְכל־דַּם עֹלָה וְכל־דַּם־זֶבַח עָלָיו תִּזְרֹק וּמִזְבַּח הַנְּחֹשֶׁת יִהְיֶה־לִּי לְבַקֵּר׃
	}
}
{
	\eX{
		And king Ahaz commanded Urijah the priest, saying, On the great
		altar burn the morning burned offering, and the evening food
		offering, and the king's burned sacrifice, and his food
		offering, with the burned offering of all the people of the
		land, and their food offering, and their drink offerings: and
		sprinkle on it all the blood of the burned offering, and all the
		blood of the sacrifice: and the bronze altar shall be for me to
		inquire by.
	}
}
{
}

\Verse{16}
{
	\hX{וַיַּעַשׂ אוּרִיָּה הַכֹּהֵן כְּכֹל אֲשֶׁר־צִוָּה הַמֶּלֶךְ אָחָז׃}
}
{
	\eX{
		Thus did Urijah the priest, according to all that king Ahaz
		commanded.
	}
}
{
}

\Verse{17}
{
	\hX{
		וַיְקַצֵּץ הַמֶּלֶךְ אָחָז אֶת־הַמִּסְגְּרוֹת הַמְּכוֹנֹת וַיָּסַר מֵעֲלֵיהֶם (ואת) [אֶת־]הַכִּיֹּר וְאֶת־הַיָּם הוֹרִד מֵעַל הַבָּקָר הַנְּחֹשֶׁת אֲשֶׁר תַּחְתֶּיהָ וַיִּתֵּן
		אֹתוֹ עַל מַרְצֶפֶת אֲבָנִים׃
	}
}
{
	\eX{
		And king Ahaz cut off the borders of the bases, and removed the
		laver from off them: and took down the sea from off the bronze
		oxen that were under it, and put it on the pavement of stones.
	}
}
{
}

\Verse{18}
{
	\hX{וְאֶת־[מוּסַךְ] (מיסך) הַשַּׁבָּת אֲשֶׁר־בָּנוּ בַבַּיִת וְאֶת־מְבוֹא הַמֶּלֶךְ הַחִיצוֹנָה הֵסֵב בֵּית יְהֹוָה מִפְּנֵי מֶלֶךְ אַשּׁוּר׃}
}
{
	\eX{
		And the covert for the sabbath that they had built in the house,
		and the king's entry without, turned he from the house of YHWH
		for the king of Assyria.
	}
}
{
}

\Verse{19}
{
	\hX{וְיֶתֶר דִּבְרֵי אָחָז אֲשֶׁר עָשָׂה הֲלֹא־הֵם כְּתוּבִים עַל־סֵפֶר דִּבְרֵי הַיָּמִים לְמַלְכֵי יְהוּדָה׃}
}
{
	\eX{
		And the rest of the acts of Ahaz that he did, are they not
		written in the book of the chronicles of the kings of Judah?
	}
}
{
}

\Verse{20}
{
	\hX{וַיִּשְׁכַּב אָחָז עִם־אֲבֹתָיו וַיִּקָּבֵר עִם־אֲבֹתָיו בְּעִיר דָּוִד וַיִּמְלֹךְ חִזְקִיָּהוּ בְנוֹ תַּחְתָּיו׃}
}
{
	\eX{
		And Ahaz slept with his fathers, and was buried with his fathers
		in the city of David: and Hezekiah his son reigned in his place.
	}
}
{
}
