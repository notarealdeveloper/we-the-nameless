\Chapter{7}

\Verse{1}
{
	\hX{וַיֹּאמֶר אֱלִישָׁע שִׁמְעוּ דְּבַר־יְהֹוָה כֹּה אָמַר יְהֹוָה כָּעֵת מָחָר סְאָה־סֹלֶת בְּשֶׁקֶל וְסָאתַיִם שְׂעֹרִים בְּשֶׁקֶל בְּשַׁעַר שֹׁמְרוֹן׃}
}
{
	\eX{
		And Elisha said, Hear you the word of YHWH: Thus says YHWH, To
		morrow about this time shall a measure of fine flour be sold for
		a shekel, and two measures of barley for a shekel, in the gate
		of Samaria.
	}
}
{
}

\Verse{2}
{
	\hX{
		וַיַּעַן הַשָּׁלִישׁ אֲשֶׁר־לַמֶּלֶךְ נִשְׁעָן עַל־יָדוֹ אֶת־אִישׁ הָאֱלֹהִים וַיֹּאמַר הִנֵּה יְהֹוָה עֹשֶׂה אֲרֻבּוֹת בַּשָּׁמַיִם הֲיִהְיֶה הַדָּבָר הַזֶּה וַיֹּאמֶר הִנְּכָה
		רֹאֶה בְּעֵינֶיךָ וּמִשָּׁם לֹא תֹאכֵל׃
	}
}
{
	\eX{
		And a lord on whose hand the king leaned answered the man of
		God, and said, Here: if YHWH would make windows in the skies,
		might this thing be? And he said, Here: you shall see it with
		your eyes, but shall not eat of it.
	}
}
{
}

\Verse{3}
{
	\hX{וְאַרְבָּעָה אֲנָשִׁים הָיוּ מְצֹרָעִים פֶּתַח הַשָּׁעַר וַיֹּאמְרוּ אִישׁ אֶל־רֵעֵהוּ מָה אֲנַחְנוּ יֹשְׁבִים פֹּה עַד־מָתְנוּ׃}
}
{
	\eX{
		And there were four leprous men at the entering in of the gate:
		and they said one to another, Why sit we here until we die?
	}
}
{
}

\Verse{4}
{
	\hX{
		אִם־אָמַרְנוּ נָבוֹא הָעִיר וְהָרָעָב בָּעִיר וָמַתְנוּ שָׁם וְאִם־יָשַׁבְנוּ פֹה וָמָתְנוּ וְעַתָּה לְכוּ וְנִפְּלָה אֶל־מַחֲנֵה אֲרָם אִם־יְחַיֻּנוּ נִחְיֶה וְאִם־יְמִיתֻנוּ
		וָמָתְנוּ׃
	}
}
{
	\eX{
		If we say, We will enter into the city, then the famine is in
		the city, and we shall die there: and if we sit still here, we
		die also. And therefore come, and let us fall to the army of the
		Arameans: if they keep us alive, we shall live: and if they kill
		us, we shall die.
	}
}
{
}

\Verse{5}
{
	\hX{וַיָּקֻמוּ בַנֶּשֶׁף לָבוֹא אֶל־מַחֲנֵה אֲרָם וַיָּבֹאוּ עַד־קְצֵה מַחֲנֵה אֲרָם וְהִנֵּה אֵין־שָׁם אִישׁ׃}
}
{
	\eX{
		And they rose up in the twilight, to go to the camp of the
		Arameans: and when they were come to the edge of the camp of
		Aram, here: there was no man there.
	}
}
{
}

\Verse{6}
{
	\hX{
		וַאדֹנָי הִשְׁמִיעַ אֶת־מַחֲנֵה אֲרָם קוֹל רֶכֶב קוֹל סוּס קוֹל חַיִל גָּדוֹל וַיֹּאמְרוּ אִישׁ אֶל־אָחִיו הִנֵּה שָׂכַר־עָלֵינוּ מֶלֶךְ יִשְׂרָאֵל אֶת־מַלְכֵי הַחִתִּים
		וְאֶת־מַלְכֵי מִצְרַיִם לָבוֹא עָלֵינוּ׃
	}
}
{
	\eX{
		For YHWH had made the army of the Arameans to hear a noise of
		chariots, and a noise of horses, even the noise of a great army:
		and they said one to another, Lo, the king of Israel has hired
		against us the kings of the Hittites, and the kings of the
		Egyptians, to come on us.
	}
}
{
}

\Verse{7}
{
	\hX{וַיָּקוּמוּ וַיָּנוּסוּ בַנֶּשֶׁף וַיַּעַזְבוּ אֶת־אהֳלֵיהֶם וְאֶת־סוּסֵיהֶם וְאֶת־חֲמֹרֵיהֶם הַמַּחֲנֶה כַּאֲשֶׁר־הִיא וַיָּנֻסוּ אֶל־נַפְשָׁם׃}
}
{
	\eX{
		Why they arose and fled in the twilight, and left their tents,
		and their horses, and their asses, even the camp as it was, and
		fled for their life.
	}
}
{
}

\Verse{8}
{
	\hX{
		וַיָּבֹאוּ הַמְצֹרָעִים הָאֵלֶּה עַד־קְצֵה הַמַּחֲנֶה וַיָּבֹאוּ אֶל־אֹהֶל אֶחָד וַיֹּאכְלוּ וַיִּשְׁתּוּ וַיִּשְׂאוּ מִשָּׁם כֶּסֶף וְזָהָב וּבְגָדִים וַיֵּלְכוּ וַיַּטְמִנוּ
		וַיָּשֻׁבוּ וַיָּבֹאוּ אֶל־אֹהֶל אַחֵר וַיִּשְׂאוּ מִשָּׁם וַיֵּלְכוּ וַיַּטְמִנוּ׃
	}
}
{
	\eX{
		And when these those with skin disease came to the edge of the
		camp, they went into one tent, and ate and drink, and carried
		from there silver, and gold, and clothes, and went and hid it:
		and came again, and entered into another tent, and carried from
		there also, and went and hid it.
	}
}
{
}

\Verse{9}
{
	\hX{
		וַיֹּאמְרוּ אִישׁ אֶל־רֵעֵהוּ לֹא־כֵן אֲנַחְנוּ עֹשִׂים הַיּוֹם הַזֶּה יוֹם־בְּשֹׂרָה הוּא וַאֲנַחְנוּ מַחְשִׁים וְחִכִּינוּ עַד־אוֹר הַבֹּקֶר וּמְצָאָנוּ עָווֹן וְעַתָּה לְכוּ

	}
}
{
	\eX{
		And they said one to another, We don't well: this day is a day
		of good tidings, and we keep quiet: if we stay till the morning
		light, some mischief will come on us: now therefore come, that
		we may go and tell the king's household.
	}
}
{
}

\Verse{10}
{
	\hX{
		וַיָּבֹאוּ וַיִּקְרְאוּ אֶל־שֹׁעֵר הָעִיר וַיַּגִּידוּ לָהֶם לֵאמֹר בָּאנוּ אֶל־מַחֲנֵה אֲרָם וְהִנֵּה אֵין־שָׁם אִישׁ וְקוֹל אָדָם כִּי אִם־הַסּוּס אָסוּר וְהַחֲמוֹר אָסוּר

}
{
	\eX{

		them, saying, We came to the camp of the Arameans, and, here:

		and asses tied, and the tents as they were.
	}
}
{
}

		[בַשָּׂדֶה] לֵאמֹר כִּי־יֵצְאוּ מִן־הָעִיר וְנִתְפְּשֵׂם חַיִּים וְאֶל־הָעִיר נָבֹא׃
	}
}
{
	\eX{
		And the king arose in the night, and said to his servants, I'll
		now show you what the Arameans have done to us. They know that
		we are hungry: therefore are they gone out of the camp to hide
		themselves in the field, saying, When they come out of the city,
		we shall catch them alive, and get into the city.
