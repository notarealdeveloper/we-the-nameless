\Chapter{19}

\Verse{1}
{
	\hX{וַיַּגֵּד אַחְאָב לְאִיזֶבֶל אֵת כּל־אֲשֶׁר עָשָׂה אֵלִיָּהוּ וְאֵת כּל־אֲשֶׁר הָרַג אֶת־כּל־הַנְּבִיאִים בֶּחָרֶב׃}
}
{
	\eX{
		And Ahab told Jezebel all that Elijah had done, and with it how
		he had killed all the prophets with the sword.
	}
}
{
}

\Verse{2}
{
	\hX{וַתִּשְׁלַח אִיזֶבֶל מַלְאָךְ אֶל־אֵלִיָּהוּ לֵאמֹר כֹּה־יַעֲשׂוּן אֱלֹהִים וְכֹה יוֹסִפוּן כִּי־כָעֵת מָחָר אָשִׂים אֶת־נַפְשְׁךָ כְּנֶפֶשׁ אַחַד מֵהֶם׃}
}
{
	\eX{
		And Jezebel sent a messenger to Elijah, saying, And let the gods
		do to me, and more also, if I make not your life as the life of
		one of them by tomorrow about this time.
	}
}
{
}

\Verse{3}
{
	\hX{וַיַּרְא וַיָּקם וַיֵּלֶךְ אֶל־נַפְשׁוֹ וַיָּבֹא בְּאֵר שֶׁבַע אֲשֶׁר לִיהוּדָה וַיַּנַּח אֶת־נַעֲרוֹ שָׁם׃}
}
{
	\eX{
		And when he saw that, he arose, and went for his life, and came
		to Beersheba, which belongs to Judah, and left his servant
		there.
	}
}
{
}

\Verse{4}
{
	\hX{
		וְהוּא־הָלַךְ בַּמִּדְבָּר דֶּרֶךְ יוֹם וַיָּבֹא וַיֵּשֶׁב תַּחַת רֹתֶם (אחת) [אֶחָד] וַיִּשְׁאַל אֶת־נַפְשׁוֹ לָמוּת וַיֹּאמֶר רַב עַתָּה יְהֹוָה קַח נַפְשִׁי כִּי־לֹא־טוֹב
		אָנֹכִי מֵאֲבֹתָי׃
	}
}
{
	\eX{
		But he himself went a day's journey into the wilderness, and
		came and sat down under a juniper tree: and he requested for
		himself that he might die: and said, It is enough: now, YHWH,
		take away my life: for I am not better than my fathers.
	}
}
{
}

\Verse{5}
{
	\hX{וַיִּשְׁכַּב וַיִּישַׁן תַּחַת רֹתֶם אֶחָד וְהִנֵּה־זֶה מַלְאָךְ נֹגֵעַ בּוֹ וַיֹּאמֶר לוֹ קוּם אֱכוֹל׃}
}
{
	\eX{
		And as he lay and slept under a juniper tree, here: then an
		angel touched him, and said to him, Arise and eat.
	}
}
{
}

\Verse{6}
{
	\hX{וַיַּבֵּט וְהִנֵּה מְרַאֲשֹׁתָיו עֻגַת רְצָפִים וְצַפַּחַת מָיִם וַיֹּאכַל וַיֵּשְׁתְּ וַיָּשׁב וַיִּשְׁכָּב׃}
}
{
	\eX{
		And he looked, and, here: there was a cake baken on the coals,
		and a cruse of water at his head. And he did eat and drink, and
		laid him down again.
	}
}
{
}

\Verse{7}
{
	\hX{וַיָּשׁב מַלְאַךְ יְהֹוָה שֵׁנִית וַיִּגַּע־בּוֹ וַיֹּאמֶר קוּם אֱכֹל כִּי רַב מִמְּךָ הַדָּרֶךְ׃}
}
{
	\eX{
		And the angel of YHWH came again the second time, and touched
		him, and said, Arise and eat: because the journey is too great
		for you.
	}
}
{
}

\Verse{8}
{
	\hX{וַיָּקם וַיֹּאכַל וַיִּשְׁתֶּה וַיֵּלֶךְ בְּכֹחַ הָאֲכִילָה הַהִיא אַרְבָּעִים יוֹם וְאַרְבָּעִים לַיְלָה עַד הַר הָאֱלֹהִים חֹרֵב׃}
}
{
	\eX{
		And he arose, and did eat and drink, and went in the strength of
		that meat forty days and forty nights to Horeb the mount of God.
	}
}
{
}

\Verse{9}
{
	\hX{וַיָּבֹא־שָׁם אֶל־הַמְּעָרָה וַיָּלֶן שָׁם וְהִנֵּה דְבַר־יְהֹוָה אֵלָיו וַיֹּאמֶר לוֹ מַה־לְּךָ פֹה אֵלִיָּהוּ׃}
}
{
	\eX{
		And he came there to a cave, and lodged there: and, here: the
		word of YHWH came to him, and he said to him, What are you doing
		here, Elijah?
	}
}
{
}

\Verse{10}
{
	\hX{
		וַיֹּאמֶר קַנֹּא קִנֵּאתִי לַיהֹוָה אֱלֹהֵי צְבָאוֹת כִּי־עָזְבוּ בְרִיתְךָ בְּנֵי יִשְׂרָאֵל אֶת־מִזְבְּחֹתֶיךָ הָרָסוּ וְאֶת־נְבִיאֶיךָ הָרְגוּ בֶחָרֶב וָאִוָּתֵר אֲנִי לְבַדִּי
		וַיְבַקְשׁוּ אֶת־נַפְשִׁי לְקַחְתָּהּ׃
	}
}
{
	\eX{
		And he said, I have been very jealous for YHWH God of armies:
		for the children of Israel have forsaken your covenant, thrown
		down your altars, and killed your prophets with the sword: and
		I, even I only, am left: and they seek my life, to take it away.
	}
}
{
}

\Verse{11}
{
	\hX{
		וַיֹּאמֶר צֵא וְעָמַדְתָּ בָהָר לִפְנֵי יְהֹוָה וְהִנֵּה יְהֹוָה עֹבֵר וְרוּחַ גְּדוֹלָה וְחָזָק מְפָרֵק הָרִים וּמְשַׁבֵּר סְלָעִים לִפְנֵי יְהֹוָה לֹא בָרוּחַ יְהֹוָה וְאַחַר
		הָרוּחַ רַעַשׁ לֹא בָרַעַשׁ יְהֹוָה׃
	}
}
{
	\eX{And he said, Go forth, and stand on the mount before YHWH.}
}
{
}

\Verse{12}
{
	\hX{וְאַחַר הָרַעַשׁ אֵשׁ לֹא בָאֵשׁ יְהֹוָה וְאַחַר הָאֵשׁ קוֹל דְּמָמָה דַקָּה׃}
}
{
	\eX{
		And after the earthquake, fire; YHWH was not in the fire. And
		after the fire, a thin sound of silence.
	}
}
{
%	\footnote{
%		Footnote 19:12. A thin sound of silence is famously hard to carry over. The Hebrew
%		is not a thunderclap. It is the thing after all the thunderclaps have failed.
%	}
}

\Verse{13}
{
	\hX{וַיְהִי כִּשְׁמֹעַ אֵלִיָּהוּ וַיָּלֶט פָּנָיו בְּאַדַּרְתּוֹ וַיֵּצֵא וַיַּעֲמֹד פֶּתַח הַמְּעָרָה וְהִנֵּה אֵלָיו קוֹל וַיֹּאמֶר מַה־לְּךָ פֹה אֵלִיָּהוּ׃}
}
{
	\eX{
		And it was so, when Elijah heard it, that he wrapped his face in
		his cloak, and went out, and stood in the entering in of the
		cave. And here: there came a voice to him, and said, What are
		you doing here, Elijah?
	}
}
{
}

\Verse{14}
{
	\hX{

		take it away.
	}
}
{
}

\Verse{15}
{
	\hX{וַיֹּאמֶר יְהֹוָה אֵלָיו לֵךְ שׁוּב לְדַרְכְּךָ מִדְבַּרָה דַמָּשֶׂק וּבָאתָ וּמָשַׁחְתָּ אֶת־חֲזָאֵל לְמֶלֶךְ עַל־אֲרָם׃}
}
{
	\eX{
		And YHWH said to him, Go, return on your way to the wilderness
		of Damascus: and when you come, anoint Hazael to be king over
		Syria:
	}
}
{
}

\Verse{16}
{
	\hX{וְאֵת יֵהוּא בֶן־נִמְשִׁי תִּמְשַׁח לְמֶלֶךְ עַל־יִשְׂרָאֵל וְאֶת־אֱלִישָׁע בֶּן־שָׁפָט מֵאָבֵל מְחוֹלָה תִּמְשַׁח לְנָבִיא תַּחְתֶּיךָ׃}
}
{
	\eX{
		And Jehu the son of Nimshi shall you anoint to be king over
		Israel: and Elisha the son of Shaphat of Abelmeholah shall you
		anoint to be prophet in your place.
	}
}
{
}

\Verse{17}
{
	\hX{וְהָיָה הַנִּמְלָט מֵחֶרֶב חֲזָאֵל יָמִית יֵהוּא וְהַנִּמְלָט מֵחֶרֶב יֵהוּא יָמִית אֱלִישָׁע׃}
}
{
	\eX{
		And it will be, that him that escapes the sword of Hazael shall
		Jehu kill: and him that escapes from the sword of Jehu shall
		Elisha kill.
	}
}
{
}

\Verse{18}
{
	\hX{וְהִשְׁאַרְתִּי בְיִשְׂרָאֵל שִׁבְעַת אֲלָפִים כּל־הַבִּרְכַּיִם אֲשֶׁר לֹא־כָרְעוּ לַבַּעַל וְכל־הַפֶּה אֲשֶׁר לֹא־נָשַׁק לוֹ׃}
}
{
	\eX{
		Yet I have left me seven thousand in Israel, all the knees which
		have not bowed to Baal, and every mouth which has not kissed
		him.
	}
}
{
}

\Verse{19}
{
	\hX{
		וַיֵּלֶךְ מִשָּׁם וַיִּמְצָא אֶת־אֱלִישָׁע בֶּן־שָׁפָט וְהוּא חֹרֵשׁ שְׁנֵים־עָשָׂר צְמָדִים לְפָנָיו וְהוּא בִּשְׁנֵים הֶעָשָׂר וַיַּעֲבֹר אֵלִיָּהוּ אֵלָיו וַיַּשְׁלֵךְ
		אַדַּרְתּוֹ אֵלָיו׃
	}
}
{
	\eX{
		And he departed thence, and found Elisha the son of Shaphat, who
		was plowing with twelve yoke of oxen before him, and he with the
		twelfth: and Elijah passed by him, and cast his cloak on him.
	}
}
{
}

\Verse{20}
{
	\hX{וַיַּעֲזֹב אֶת־הַבָּקָר וַיָּרץ אַחֲרֵי אֵלִיָּהוּ וַיֹּאמֶר אֶשְּׁקָה־נָּא לְאָבִי וּלְאִמִּי וְאֵלְכָה אַחֲרֶיךָ וַיֹּאמֶר לוֹ לֵךְ שׁוּב כִּי מֶה־עָשִׂיתִי לָךְ׃}
}
{
	\eX{

		And he said to him, Go back again: for what have I done to you?
	}
}
{
}

\Verse{21}
{
	\hX{
		וַיָּשׁב מֵאַחֲרָיו וַיִּקַּח אֶת־צֶמֶד הַבָּקָר וַיִּזְבָּחֵהוּ וּבִכְלִי הַבָּקָר בִּשְּׁלָם הַבָּשָׂר וַיִּתֵּן לָעָם וַיֹּאכֵלוּ וַיָּקם וַיֵּלֶךְ אַחֲרֵי אֵלִיָּהוּ
