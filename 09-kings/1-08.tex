	\hX{בָּרוּךְ יְהֹוָה אֲשֶׁר נָתַן מְנוּחָה לְעַמּוֹ יִשְׂרָאֵל כְּכֹל אֲשֶׁר דִּבֵּר לֹא־נָפַל דָּבָר אֶחָד מִכֹּל דְּבָרוֹ הַטּוֹב אֲשֶׁר דִּבֶּר בְּיַד מֹשֶׁה עַבְדּוֹ׃}
}
{
	\eX{
		Blessed be YHWH, that has given rest to his people Israel,
		according to all that he promised: there has not failed one word
		of all his good promise, that he promised by the hand of Moses
		his servant.
	}
}
{
}

\Verse{57}
{
	\hX{יְהִי יְהֹוָה אֱלֹהֵינוּ עִמָּנוּ כַּאֲשֶׁר הָיָה עִם־אֲבֹתֵינוּ אַל־יַעַזְבֵנוּ וְאַל־יִטְּשֵׁנוּ׃}
}
{
	\eX{
		The YHWH our God be with us, as he was with our fathers: let him
		not leave us, nor forsake us:
	}
}
{
}

\Verse{58}
{
	\hX{לְהַטּוֹת לְבָבֵנוּ אֵלָיו לָלֶכֶת בְּכל־דְּרָכָיו וְלִשְׁמֹר מִצְוֺתָיו וְחֻקָּיו וּמִשְׁפָּטָיו אֲשֶׁר צִוָּה אֶת־אֲבֹתֵינוּ׃}
}
{
	\eX{
		That he may incline our hearts to him, to walk in all his ways,
		and to keep his commandments, and his statutes, and his
		judgments, that he commanded our fathers.
	}
}
{
}

\Verse{59}
{
	\hX{
		וְיִהְיוּ דְבָרַי אֵלֶּה אֲשֶׁר הִתְחַנַּנְתִּי לִפְנֵי יְהֹוָה קְרֹבִים אֶל־יְהֹוָה אֱלֹהֵינוּ יוֹמָם וָלָיְלָה לַעֲשׂוֹת מִשְׁפַּט עַבְדּוֹ וּמִשְׁפַּט עַמּוֹ יִשְׂרָאֵל
		דְּבַר־יוֹם בְּיוֹמוֹ׃
	}
}
{
	\eX{
		And let these my words, with what I have made supplication
		before YHWH, be nigh to YHWH our God day and night, that he
		maintain the cause of his servant, and the cause of his people
		Israel at all times, as the matter shall require:
	}
}
{
}

\Verse{60}
{
	\hX{לְמַעַן דַּעַת כּל־עַמֵּי הָאָרֶץ כִּי יְהֹוָה הוּא הָאֱלֹהִים אֵין עוֹד׃}
}
{
	\eX{
		That all the people of the earth may know that YHWH is God, and
		that there is none else.
	}
}
{
}

\Verse{61}
{
	\hX{וְהָיָה לְבַבְכֶם שָׁלֵם עִם יְהֹוָה אֱלֹהֵינוּ לָלֶכֶת בְּחֻקָּיו וְלִשְׁמֹר מִצְוֺתָיו כַּיּוֹם הַזֶּה׃}
}
{
	\eX{
		Let your heart therefore be perfect with YHWH our God, to walk
		in his statutes, and to keep his commandments, as at this day.
	}
}
{
}

\Verse{62}
{
	\hX{וְהַמֶּלֶךְ וְכל־יִשְׂרָאֵל עִמּוֹ זֹבְחִים זֶבַח לִפְנֵי יְהֹוָה׃}
}
{
	\eX{
		And the king, and all Israel with him, offered sacrifice before
		YHWH.
	}
}
{
}

\Verse{63}
{
	\hX{
		וַיִּזְבַּח שְׁלֹמֹה אֵת זֶבַח הַשְּׁלָמִים אֲשֶׁר זָבַח לַיהֹוָה בָּקָר עֶשְׂרִים וּשְׁנַיִם אֶלֶף וְצֹאן מֵאָה וְעֶשְׂרִים אָלֶף וַיַּחְנְכוּ אֶת־בֵּית יְהֹוָה הַמֶּלֶךְ
		וְכל־בְּנֵי יִשְׂרָאֵל׃
	}
}
{
	\eX{
		And Solomon offered a sacrifice of peace offerings, that he
		offered to YHWH, two and twenty thousand oxen, and a hundred and
		twenty thousand sheep. And the king and all the children of
		Israel dedicated the house of YHWH.
	}
}
{
}

\Verse{64}
{
	\hX{
		בַּיּוֹם הַהוּא קִדַּשׁ הַמֶּלֶךְ אֶת־תּוֹךְ הֶחָצֵר אֲשֶׁר לִפְנֵי בֵית־יְהֹוָה כִּי־עָשָׂה שָׁם אֶת־הָעֹלָה וְאֶת־הַמִּנְחָה וְאֵת חֶלְבֵי הַשְּׁלָמִים כִּי־מִזְבַּח הַנְּחֹשֶׁת
		אֲשֶׁר לִפְנֵי יְהֹוָה קָטֹן מֵהָכִיל אֶת־הָעֹלָה וְאֶת־הַמִּנְחָה וְאֵת חֶלְבֵי הַשְּׁלָמִים׃
	}
}
{
	\eX{
		The same day did the king hallow the middle of the court that
		was before the house of YHWH: for there he offered burnt
		offerings, and grain offerings, and the fat of the peace
		offerings: because the bronze altar that was before YHWH was too
		little to receive the burnt offerings, and grain offerings, and
		the fat of the peace offerings.
	}
}
{
}

\Verse{65}
{
	\hX{
		וַיַּעַשׂ שְׁלֹמֹה בָעֵת־הַהִיא אֶת־הֶחָג וְכל־יִשְׂרָאֵל עִמּוֹ קָהָל גָּדוֹל מִלְּבוֹא חֲמָת עַד־נַחַל מִצְרַיִם לִפְנֵי יְהֹוָה אֱלֹהֵינוּ שִׁבְעַת יָמִים וְשִׁבְעַת יָמִים
		אַרְבָּעָה עָשָׂר יוֹם׃
	}
}
{
	\eX{
		And at that time Solomon held a feast, and all Israel with him,
		a great congregation, from the entering in of Hamath to the
		river of Egypt, before YHWH our God, seven days and seven days,
		even fourteen days.
	}
}
{
}

\Verse{66}
{
	\hX{
		בַּיּוֹם הַשְּׁמִינִי שִׁלַּח אֶת־הָעָם וַיְבָרְכוּ אֶת־הַמֶּלֶךְ וַיֵּלְכוּ לְאהֳלֵיהֶם שְׂמֵחִים וְטוֹבֵי לֵב עַל כּל־הַטּוֹבָה אֲשֶׁר עָשָׂה יְהֹוָה לְדָוִד עַבְדּוֹ
		וּלְיִשְׂרָאֵל עַמּוֹ׃
	}
}
{
	\eX{
		On the eighth day he sent the people away: and they blessed the
		king, and went to their tents joyful and glad of heart for all
		the goodness that YHWH had done for David his servant, and for
		Israel his people.
	}
}
{
