\Chapter{20}

\Verse{1}
{
	\hX{בַּיָּמִים הָהֵם חָלָה חִזְקִיָּהוּ לָמוּת וַיָּבֹא אֵלָיו יְשַׁעְיָהוּ בֶן־אָמוֹץ הַנָּבִיא וַיֹּאמֶר אֵלָיו כֹּה־אָמַר יְהֹוָה צַו לְבֵיתֶךָ כִּי מֵת אַתָּה וְלֹא תִחְיֶה׃}
}
{
	\eX{
		In those days was Hezekiah sick to death. And the prophet Isaiah
		the son of Amoz came to him, and said to him, Thus says YHWH,
		Set yours house in order: for you shall die, and not live.
	}
}
{
}

\Verse{2}
{
	\hX{וַיַּסֵּב אֶת־פָּנָיו אֶל־הַקִּיר וַיִּתְפַּלֵּל אֶל־יְהֹוָה לֵאמֹר׃}
}
{
	\eX{And he turned his face to the wall, and prayed to YHWH, saying,}
}
{
}

\Verse{3}
{
	\hX{אָנָּה יְהֹוָה זְכר־נָא אֵת אֲשֶׁר הִתְהַלַּכְתִּי לְפָנֶיךָ בֶּאֱמֶת וּבְלֵבָב שָׁלֵם וְהַטּוֹב בְּעֵינֶיךָ עָשִׂיתִי וַיֵּבְךְּ חִזְקִיָּהוּ בְּכִי גָדוֹל׃}
}
{
	\eX{
		I please you, O YHWH, remember now how I have walked before you
		in truth and with a perfect heart, and have done that that is
		good in your sight. And Hezekiah wept much.
	}
}
{
}

\Verse{4}
{
	\hX{וַיְהִי יְשַׁעְיָהוּ לֹא יָצָא (העיר) [חָצֵר] הַתִּיכֹנָה וּדְבַר־יְהֹוָה הָיָה אֵלָיו לֵאמֹר׃}
}
{
	\eX{
		And it was, afore Isaiah was gone out into the middle court,
		that the word of YHWH came to him, saying,
	}
}
{
	Qere Ketiv.
}

\Verse{5}
{
	\hX{
		שׁוּב וְאָמַרְתָּ אֶל־חִזְקִיָּהוּ נְגִיד־עַמִּי כֹּה־אָמַר יְהֹוָה אֱלֹהֵי דָּוִד אָבִיךָ שָׁמַעְתִּי אֶת־תְּפִלָּתֶךָ רָאִיתִי אֶת־דִּמְעָתֶךָ הִנְנִי רֹפֶא לָךְ בַּיּוֹם
		הַשְּׁלִישִׁי תַּעֲלֶה בֵּית יְהֹוָה׃
	}
}
{
	\eX{
		Turn again, and tell Hezekiah the commander of my people, Thus
		says YHWH, the God of David your father, I have heard your
		prayer, I have seen your tears: here: I'll heal you: on the
		third day you shall go up to the house of YHWH.
	}
}
{
}

\Verse{6}
{
	\hX{וְהֹסַפְתִּי עַל־יָמֶיךָ חֲמֵשׁ עֶשְׂרֵה שָׁנָה וּמִכַּף מֶלֶךְ־אַשּׁוּר אַצִּילְךָ וְאֵת הָעִיר הַזֹּאת וְגַנּוֹתִי עַל־הָעִיר הַזֹּאת לְמַעֲנִי וּלְמַעַן דָּוִד עַבְדִּי׃}
}
{
	\eX{
		And I'll add to your days fifteen years: and I'll deliver you
		and this city from the hand of the king of Assyria: and I'll
		defend this city for mine own sake, and for my servant David's
		sake.
	}
}
{
}

\Verse{7}
{
	\hX{וַיֹּאמֶר יְשַׁעְיָהוּ קְחוּ דְּבֶלֶת תְּאֵנִים וַיִּקְחוּ וַיָּשִׂימוּ עַל־הַשְּׁחִין וַיֶּחִי׃}
}
{
	\eX{
		And Isaiah said, Take a lump of figs. And they took and laid it
		on the boil, and he recovered.
	}
}
{
}

\Verse{8}
{
	\hX{וַיֹּאמֶר חִזְקִיָּהוּ אֶל־יְשַׁעְיָהוּ מָה אוֹת כִּי־יִרְפָּא יְהֹוָה לִי וְעָלִיתִי בַּיּוֹם הַשְּׁלִישִׁי בֵּית יְהֹוָה׃}
}
{
	\eX{
		And Hezekiah said to Isaiah, What shall be the sign that YHWH
		will heal me, and that I'll go up into the house of YHWH the
		third day?
	}
}
{
}

\Verse{9}
{
	\hX{וַיֹּאמֶר יְשַׁעְיָהוּ זֶה־לְּךָ הָאוֹת מֵאֵת יְהֹוָה כִּי יַעֲשֶׂה יְהֹוָה אֶת־הַדָּבָר אֲשֶׁר דִּבֵּר הָלַךְ הַצֵּל עֶשֶׂר מַעֲלוֹת אִם־יָשׁוּב עֶשֶׂר מַעֲלוֹת׃}
}
{
	\eX{
		And Isaiah said, This sign shall you have of YHWH, that YHWH
		will do the thing that he has spoken: shall the shadow go
		forward ten degrees, or go back ten degrees?
	}
}
{
}

\Verse{10}
{
	\hX{וַיֹּאמֶר יְחִזְקִיָּהוּ נָקֵל לַצֵּל לִנְטוֹת עֶשֶׂר מַעֲלוֹת לֹא כִי יָשׁוּב הַצֵּל אֲחֹרַנִּית עֶשֶׂר מַעֲלוֹת׃}
}
{
	\eX{
		And Hezekiah answered, It is a light thing for the shadow to go
		down ten degrees: no, but let the shadow return backward ten
		degrees.
	}
}
{
}

\Verse{11}
{
	\hX{וַיִּקְרָא יְשַׁעְיָהוּ הַנָּבִיא אֶל־יְהֹוָה וַיָּשֶׁב אֶת־הַצֵּל בַּמַּעֲלוֹת אֲשֶׁר יָרְדָה בְּמַעֲלוֹת אָחָז אֲחֹרַנִּית עֶשֶׂר מַעֲלוֹת׃}
}
{
	\eX{
		And Isaiah the prophet cried to YHWH: and he brought the shadow
		ten degrees backward, by that it had gone down in the dial of
		Ahaz.
	}
}
{
}

\Verse{12}
{
	\hX{בָּעֵת הַהִיא שָׁלַח בְּרֹאדַךְ בַּלְאֲדָן בֶּן־בַּלְאֲדָן מֶלֶךְ־בָּבֶל סְפָרִים וּמִנְחָה אֶל־חִזְקִיָּהוּ כִּי שָׁמַע כִּי חָלָה חִזְקִיָּהוּ׃}
}
{
	\eX{
		At that time Berodachbaladan, the son of Baladan, king of
		Babylon, sent letters and a present to Hezekiah: for he had
		heard that Hezekiah had been sick.
	}
}
{
}

\Verse{13}
{
	\hX{
		וַיִּשְׁמַע עֲלֵיהֶם חִזְקִיָּהוּ וַיַּרְאֵם אֶת־כּל־בֵּית נְכֹתֹה אֶת־הַכֶּסֶף וְאֶת־הַזָּהָב וְאֶת־הַבְּשָׂמִים וְאֵת שֶׁמֶן הַטּוֹב וְאֵת בֵּית כֵּלָיו וְאֵת כּל־אֲשֶׁר נִמְצָא
		בְּאוֹצְרֹתָיו לֹא־הָיָה דָבָר אֲשֶׁר לֹא־הֶרְאָם חִזְקִיָּהוּ בְּבֵיתוֹ וּבְכל־מֶמְשַׁלְתּוֹ׃
	}
}
{
	\eX{
		And Hezekiah hearkened to them, and showed them all the house of
		his precious things, the silver, and the gold, and the spices,
		and the precious ointment, and all the house of his armor, and
		all that was found in his treasures: there was nothing in his
		house, nor in all his dominion, that Hezekiah didn't show them.
	}
}
{
}

\Verse{14}
{
	\hX{
		וַיָּבֹא יְשַׁעְיָהוּ הַנָּבִיא אֶל־הַמֶּלֶךְ חִזְקִיָּהוּ וַיֹּאמֶר אֵלָיו מָה אָמְרוּ הָאֲנָשִׁים הָאֵלֶּה וּמֵאַיִן יָבֹאוּ אֵלֶיךָ וַיֹּאמֶר חִזְקִיָּהוּ מֵאֶרֶץ רְחוֹקָה
		בָּאוּ מִבָּבֶל׃
	}
}
{
	\eX{
		And came Isaiah the prophet to king Hezekiah, and said to him,
		What said these men? and from from where came they to you? And
		Hezekiah said, They are come from a far country, even from
		Babylon.
	}
}
{
}

\Verse{15}
{
	\hX{וַיֹּאמֶר מָה רָאוּ בְּבֵיתֶךָ וַיֹּאמֶר חִזְקִיָּהוּ אֵת כּל־אֲשֶׁר בְּבֵיתִי רָאוּ לֹא־הָיָה דָבָר אֲשֶׁר לֹא־הִרְאִיתִם בְּאֹצְרֹתָי׃}
}
{
	\eX{
		And he said, What have they seen in yours house? And Hezekiah
		answered, All the things that are in my house have they seen:
		there is nothing among my treasures that I have not showed them.
	}
}
{
}

\Verse{16}
{
	\hX{וַיֹּאמֶר יְשַׁעְיָהוּ אֶל־חִזְקִיָּהוּ שְׁמַע דְּבַר־יְהֹוָה׃}
}

	\eX{And Isaiah said to Hezekiah, Hear the word of YHWH.}

{
}

\Verse{17}
{
	\hX{הִנֵּה יָמִים בָּאִים וְנִשָּׂא כּל־אֲשֶׁר בְּבֵיתֶךָ וַאֲשֶׁר אָצְרוּ אֲבֹתֶיךָ עַד־הַיּוֹם הַזֶּה בָּבֶלָה לֹא־יִוָּתֵר דָּבָר אָמַר יְהֹוָה׃}
}
{
	\eX{

	}
}
{
}

}

	}
}

}

\Verse{19}
{
	\hX{וַיֹּאמֶר חִזְקִיָּהוּ אֶל־יְשַׁעְיָהוּ טוֹב דְּבַר־יְהֹוָה אֲשֶׁר דִּבַּרְתָּ וַיֹּאמֶר הֲלוֹא אִם־שָׁלוֹם וֶאֱמֶת יִהְיֶה בְיָמָי׃}
}
{
	\eX{
		And said Hezekiah to Isaiah, Good is the word of YHWH that you
		have spoken. And he said, Is it not good, if peace and truth be

	}
}
{
}

\Verse{20}
{
	\hX{
		וְיֶתֶר דִּבְרֵי חִזְקִיָּהוּ וְכל־גְּבוּרָתוֹ וַאֲשֶׁר עָשָׂה אֶת־הַבְּרֵכָה וְאֶת־הַתְּעָלָה וַיָּבֵא אֶת־הַמַּיִם הָעִירָה הֲלֹא־הֵם כְּתוּבִים עַל־סֵפֶר דִּבְרֵי הַיָּמִים
		לְמַלְכֵי יְהוּדָה׃
	}
}
{
	\eX{
		And the rest of the acts of Hezekiah, and all his might, and how
		he made a pool, and a conduit, and brought water into the city,
		are they not written in the book of the chronicles of the kings
		of Judah?
	}
}
{
}
