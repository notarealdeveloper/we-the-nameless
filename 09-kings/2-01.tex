\Chapter{1}

\Verse{1}
{
	\hX{וַיִּפְשַׁע מוֹאָב בְּיִשְׂרָאֵל אַחֲרֵי מוֹת אַחְאָב׃}
}
{
	\eX{And Moab rebelled against Israel after the death of Ahab.}
}
{
}

\Verse{2}
{
	\hX{
		וַיִּפֹּל אֲחַזְיָה בְּעַד הַשְּׂבָכָה בַּעֲלִיָּתוֹ אֲשֶׁר בְּשֹׁמְרוֹן וַיָּחַל וַיִּשְׁלַח מַלְאָכִים וַיֹּאמֶר אֲלֵהֶם לְכוּ דִרְשׁוּ בְּבַעַל זְבוּב אֱלֹהֵי עֶקְרוֹן
		אִם־אֶחְיֶה מֵחֳלִי זֶה׃
	}
}
{
	\eX{
		And Ahaziah fell down through a lattice in his upper chamber
		that was in Samaria, and was sick: and he sent messengers, and
		said to them, Go, inquire of Baalzebub the god of Ekron whether
		I'll recover of this disease.
	}
}
{
}

\Verse{3}
{
	\hX{
		וּמַלְאַךְ יְהֹוָה דִּבֶּר אֶל־אֵלִיָּה הַתִּשְׁבִּי קוּם עֲלֵה לִקְרַאת מַלְאֲכֵי מֶלֶךְ־שֹׁמְרוֹן וְדַבֵּר אֲלֵהֶם הֲמִבְּלִי אֵין־אֱלֹהִים בְּיִשְׂרָאֵל אַתֶּם הֹלְכִים לִדְרֹשׁ
		בְּבַעַל זְבוּב אֱלֹהֵי עֶקְרוֹן׃
	}
}
{
	\eX{
		But the angel of YHWH said to Elijah the Tishbite, Arise, go up
		to meet the messengers of the king of Samaria, and say to them,
		Is it not because there is no God in Israel, that you go to
		inquire of Baalzebub the god of Ekron?
	}
}
{
}

\Verse{4}
{
	\hX{וְלָכֵן כֹּה־אָמַר יְהֹוָה הַמִּטָּה אֲשֶׁר־עָלִיתָ שָּׁם לֹא־תֵרֵד מִמֶּנָּה כִּי מוֹת תָּמוּת וַיֵּלֶךְ אֵלִיָּה׃}
}
{
	\eX{
		And therefore thus says YHWH, You shall not come down from that
		bed on which you went up, because you shall die, yes, die. And
		Elijah departed.
	}
}
{
}

\Verse{5}
{
	\hX{וַיָּשׁוּבוּ הַמַּלְאָכִים אֵלָיו וַיֹּאמֶר אֲלֵיהֶם מַה־זֶּה שַׁבְתֶּם׃}
}
{
	\eX{
		And when the messengers turned back to him, he said to them, Why
		are you now turned back?
	}
}
{
}

\Verse{6}
{
	\hX{
		וַיֹּאמְרוּ אֵלָיו אִישׁ עָלָה לִקְרָאתֵנוּ וַיֹּאמֶר אֵלֵינוּ לְכוּ שׁוּבוּ אֶל־הַמֶּלֶךְ אֲשֶׁר־שָׁלַח אֶתְכֶם וְדִבַּרְתֶּם אֵלָיו כֹּה אָמַר יְהֹוָה הֲמִבְּלִי אֵין־אֱלֹהִים
		בְּיִשְׂרָאֵל אַתָּה שֹׁלֵחַ לִדְרֹשׁ בְּבַעַל זְבוּב אֱלֹהֵי עֶקְרוֹן לָכֵן הַמִּטָּה אֲשֶׁר־עָלִיתָ שָּׁם לֹא־תֵרֵד מִמֶּנָּה כִּי־מוֹת תָּמוּת׃
	}
}
{
	\eX{
		And they said to him, A man came up to meet us, and said to us,
		Go, turn again to the king that sent you, and say to him, Thus
		says YHWH, Is it not because there is no God in Israel, that you
		send to inquire of Baalzebub the god of Ekron? therefore you
		shall not come down from that bed on which you went up, because
		you shall die, yes, die.
	}
}
{
}

\Verse{7}
{
	\hX{וַיְדַבֵּר אֲלֵהֶם מֶה מִשְׁפַּט הָאִישׁ אֲשֶׁר עָלָה לִקְרַאתְכֶם וַיְדַבֵּר אֲלֵיכֶם אֶת־הַדְּבָרִים הָאֵלֶּה׃}
}
{
	\eX{
		And he said to them, What kind of man was he that came up to
		meet you, and told you these words?
	}
}
{
}

\Verse{8}
{
	\hX{וַיֹּאמְרוּ אֵלָיו אִישׁ בַּעַל שֵׂעָר וְאֵזוֹר עוֹר אָזוּר בְּמתְנָיו וַיֹּאמַר אֵלִיָּה הַתִּשְׁבִּי הוּא׃}
}
{
	\eX{
		And they answered him, He was a hairy man, and belted with a
		belt of leather about his loins. And he said, It is Elijah the
		Tishbite.
	}
}
{
%	\footnote{
%		Footnote 1:8. A hairy man can also be read as “a possessor of hair.” The story
%		recognizes Elijah by costume, not by résumé.
%	}
}

\Verse{9}
{
	\hX{וַיִּשְׁלַח אֵלָיו שַׂר־חֲמִשִּׁים וַחֲמִשָּׁיו וַיַּעַל אֵלָיו וְהִנֵּה יֹשֵׁב עַל־רֹאשׁ הָהָר וַיְדַבֵּר אֵלָיו אִישׁ הָאֱלֹהִים הַמֶּלֶךְ דִּבֶּר רֵדָה׃}
}
{
	\eX{
		And the king sent to him a commander of fifty with his fifty.
		And he went up to him: and, here: he sat on the top of a hill.
		And he spoke to him, Man of God, the king has said, Come down.
	}
}
{
}

\Verse{10}
{
	\hX{
		וַיַּעֲנֶה אֵלִיָּהוּ וַיְדַבֵּר אֶל־שַׂר הַחֲמִשִּׁים וְאִם־אִישׁ אֱלֹהִים אָנִי תֵּרֶד אֵשׁ מִן־הַשָּׁמַיִם וְתֹאכַל אֹתְךָ וְאֶת־חֲמִשֶּׁיךָ וַתֵּרֶד אֵשׁ מִן־הַשָּׁמַיִם
		וַתֹּאכַל אֹתוֹ וְאֶת־חֲמִשָּׁיו׃
	}
}
{
	\eX{
		And Elijah answered and said to the commander of fifty, If I am
		a man of God, then let fire come down from the skies, and
		consume you and your fifty. And fire came down from the skies
		and consumed him and his fifty.
	}
}
{
}

\Verse{11}
{
	\hX{וַיָּשׁב וַיִּשְׁלַח אֵלָיו שַׂר־חֲמִשִּׁים אַחֵר וַחֲמִשָּׁיו וַיַּעַן וַיְדַבֵּר אֵלָיו אִישׁ הָאֱלֹהִים כֹּה־אָמַר הַמֶּלֶךְ מְהֵרָה רֵדָה׃}
}
{
	\eX{
		And he again sent to him another commander of fifty with his
		fifty. And he answered and spoke to him, Man of God, thus says
		the king: Come down quickly.
	}
}
{
}

\Verse{12}
{
	\hX{
		וַיַּעַן אֵלִיָּה וַיְדַבֵּר אֲלֵיהֶם אִם־אִישׁ הָאֱלֹהִים אָנִי תֵּרֶד אֵשׁ מִן־הַשָּׁמַיִם וְתֹאכַל אֹתְךָ וְאֶת־חֲמִשֶּׁיךָ וַתֵּרֶד אֵשׁ־אֱלֹהִים מִן־הַשָּׁמַיִם וַתֹּאכַל
		אֹתוֹ וְאֶת־חֲמִשָּׁיו׃
	}
}
{
	\eX{
		And Elijah answered and said to them, If I am a man of God, let
		fire come down from the skies, and consume you and your fifty.
		And the fire of God came down from the skies, and consumed him
		and his fifty.
	}
}
{
}

\Verse{13}
{
	\hX{
		וַיָּשׁב וַיִּשְׁלַח שַׂר־חֲמִשִּׁים שְׁלִשִׁים וַחֲמִשָּׁיו וַיַּעַל וַיָּבֹא שַׂר־הַחֲמִשִּׁים הַשְּׁלִישִׁי וַיִּכְרַע עַל־בִּרְכָּיו לְנֶגֶד אֵלִיָּהוּ וַיִּתְחַנֵּן אֵלָיו
		וַיְדַבֵּר אֵלָיו אִישׁ הָאֱלֹהִים תִּיקַר־נָא נַפְשִׁי וְנֶפֶשׁ עֲבָדֶיךָ אֵלֶּה חֲמִשִּׁים בְּעֵינֶיךָ׃
	}
}
{
	\eX{
		And he sent again a commander of the third fifty with his fifty.
		And the third commander of fifty went up, and came and fell on
		his knees before Elijah, and pleaded with him, and said to him,
		Man of God, please, let my life, and the life of these fifty
		your servants, be precious in your eyes.
	}
}
{
}

\Verse{14}
{
	\hX{הִנֵּה יָרְדָה אֵשׁ מִן־הַשָּׁמַיִם וַתֹּאכַל אֶת־שְׁנֵי שָׂרֵי הַחֲמִשִּׁים הָרִאשֹׁנִים וְאֶת־חֲמִשֵּׁיהֶם וְעַתָּה תִּיקַר נַפְשִׁי בְּעֵינֶיךָ׃}
}
{
	\eX{
		Here: there came fire down from the skies, and burned up the two
		commanders of the former fifties with their fifties: therefore
		let my life now be precious in your eyes.
	}
}
{
}

\Verse{15}
{
	\hX{וַיְדַבֵּר מַלְאַךְ יְהֹוָה אֶל־אֵלִיָּהוּ רֵד אוֹתוֹ אַל־תִּירָא מִפָּנָיו וַיָּקם וַיֵּרֶד אוֹתוֹ אֶל־הַמֶּלֶךְ׃}
}
{
	\eX{
		And the angel of YHWH said to Elijah, Go down with him: don't be
		afraid of him. And he arose, and went down with him to the king.
	}
}
{
}

\Verse{16}
{
	\hX{
		וַיְדַבֵּר אֵלָיו כֹּה־אָמַר יְהֹוָה יַעַן אֲשֶׁר־שָׁלַחְתָּ מַלְאָכִים לִדְרֹשׁ בְּבַעַל זְבוּב אֱלֹהֵי עֶקְרוֹן הֲמִבְּלִי אֵין־אֱלֹהִים בְּיִשְׂרָאֵל לִדְרֹשׁ בִּדְבָרוֹ לָכֵן
		הַמִּטָּה אֲשֶׁר־עָלִיתָ שָּׁם לֹא־תֵרֵד מִמֶּנָּה כִּי־מוֹת תָּמוּת׃
	}
}
{
	\eX{
		And he said to him, Thus says YHWH, Because you have sent
		messengers to inquire of Baalzebub the god of Ekron, is it not
		because there is no God in Israel to inquire of his word?
		therefore you shall not come down from the bed on which you went
		up, because you shall die, yes, die.
	}
}
{
}

\Verse{17}

{
}

\Verse{18}
{
	\hX{וְיֶתֶר דִּבְרֵי אֲחַזְיָהוּ אֲשֶׁר עָשָׂה הֲלוֹא־הֵמָּה כְתוּבִים עַל־סֵפֶר דִּבְרֵי הַיָּמִים לְמַלְכֵי יִשְׂרָאֵל׃}
