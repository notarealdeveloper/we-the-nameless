	\hX{וְגֵחֲזִי עָבַר לִפְנֵיהֶם וַיָּשֶׂם אֶת־הַמִּשְׁעֶנֶת עַל־פְּנֵי הַנַּעַר וְאֵין קוֹל וְאֵין קָשֶׁב וַיָּשׁב לִקְרָאתוֹ וַיַּגֶּד־לוֹ לֵאמֹר לֹא הֵקִיץ הַנָּעַר׃}
}
{
	\eX{
		And Gehazi passed on in front of them, and laid the staff on the
		face of the child: but there was neither voice, nor hearing. Why
		he went again to meet him, and told him, saying, The child is
		not awaked.
	}
}
{
}

\Verse{32}
{
	\hX{וַיָּבֹא אֱלִישָׁע הַבָּיְתָה וְהִנֵּה הַנַּעַר מֵת מֻשְׁכָּב עַל־מִטָּתוֹ׃}
}
{
	\eX{
		And when Elisha was come into the house, here: the child was
		dead, and laid on his bed.
	}
}
{
}

\Verse{33}
{
	\hX{וַיָּבֹא וַיִּסְגֹּר הַדֶּלֶת בְּעַד שְׁנֵיהֶם וַיִּתְפַּלֵּל אֶל־יְהֹוָה׃}
}
{
	\eX{
		He went in therefore, and shut the door on them two, and prayed
		to YHWH.
	}
}
{
}

\Verse{34}
{
	\hX{וַיַּעַל וַיִּשְׁכַּב עַל־הַיֶּלֶד וַיָּשֶׂם פִּיו עַל־פִּיו וְעֵינָיו עַל־עֵינָיו וְכַפָּיו עַל־כַּפָּו וַיִּגְהַר עָלָיו וַיָּחם בְּשַׂר הַיָּלֶד׃}
}
{
	\eX{
		And he went up, and lay on the child, and put his mouth on his
		mouth, and his eyes on his eyes, and his hands on his hands: and
		stretched himself on the child: and the flesh of the child waxed
		warm.
	}
}
{
}

\Verse{35}
{
	\hX{וַיָּשׁב וַיֵּלֶךְ בַּבַּיִת אַחַת הֵנָּה וְאַחַת הֵנָּה וַיַּעַל וַיִּגְהַר עָלָיו וַיְזוֹרֵר הַנַּעַר עַד־שֶׁבַע פְּעָמִים וַיִּפְקַח הַנַּעַר אֶת־עֵינָיו׃}
}
{
	\eX{
		And he returned, and walked in the house to and fro: and went
		up, and stretched himself on him: and the child sneezed seven
		times, and the child opened his eyes.
	}
}
{
}

\Verse{36}
{
	\hX{וַיִּקְרָא אֶל־גֵּיחֲזִי וַיֹּאמֶר קְרָא אֶל־הַשֻּׁנַמִּית הַזֹּאת וַיִּקְרָאֶהָ וַתָּבֹא אֵלָיו וַיֹּאמֶר שְׂאִי בְנֵךְ׃}
}
{
	\eX{

}
{
}

\Verse{37}
{
	\hX{וַתָּבֹא וַתִּפֹּל עַל־רַגְלָיו וַתִּשְׁתַּחוּ אָרְצָה וַתִּשָּׂא אֶת־בְּנָהּ וַתֵּצֵא׃}

}
{
}

\Verse{38}
{
	\hX{וֶאֱלִישָׁע שָׁב הַגִּלְגָּלָה וְהָרָעָב בָּאָרֶץ וּבְנֵי הַנְּבִיאִים יֹשְׁבִים לְפָנָיו וַיֹּאמֶר לְנַעֲרוֹ שְׁפֹת הַסִּיר הַגְּדוֹלָה וּבַשֵּׁל נָזִיד לִבְנֵי הַנְּבִיאִים׃}
}
{
	\eX{
		And Elisha came again to Gilgal: and there was a famine in the
		land: and the sons of the prophets were sitting in front of him:
		and he said to his servant, Set on the great pot, and cook stew
		for the sons of the prophets.
	}
}
{
}

\Verse{39}
{
	\hX{וַיֵּצֵא אֶחָד אֶל־הַשָּׂדֶה לְלַקֵּט אֹרֹת וַיִּמְצָא גֶּפֶן שָׂדֶה וַיְלַקֵּט מִמֶּנּוּ פַּקֻּעֹת שָׂדֶה מְלֹא בִגְדוֹ וַיָּבֹא וַיְפַלַּח אֶל־סִיר הַנָּזִיד כִּי־לֹא יָדָעוּ׃}
}
{
	\eX{
		And one went out into the field to gather herbs, and found a
		wild vine, and gathered of it wild gourds his lap full, and came
		and cut them into the pot of stew: for they didn't know them.
	}
}
{
}

\Verse{40}
{
	\hX{וַיִּצְקוּ לַאֲנָשִׁים לֶאֱכוֹל וַיְהִי כְּאכְלָם מֵהַנָּזִיד וְהֵמָּה צָעָקוּ וַיֹּאמְרוּ מָוֶת בַּסִּיר אִישׁ הָאֱלֹהִים וְלֹא יָכְלוּ לֶאֱכֹל׃}
}
{
	\eX{
		So they poured out for the men to eat. And it was, as they were
		eating of the stew, that they cried out, and said, O you man of
		God, there is death in the pot. And they could not eat of it.
	}
}
{
}

\Verse{41}
{
	\hX{וַיֹּאמֶר וּקְחוּ־קֶמַח וַיַּשְׁלֵךְ אֶל־הַסִּיר וַיֹּאמֶר צַק לָעָם וְיֹאכֵלוּ וְלֹא הָיָה דָּבָר רָע בַּסִּיר׃}
}
{
	\eX{
		But he said, And bring meal. And he cast it into the pot: and he

		no harm in the pot.
	}
}
{
}

\Verse{42}
{
	\hX{וְאִישׁ בָּא מִבַּעַל שָׁלִשָׁה וַיָּבֵא לְאִישׁ הָאֱלֹהִים לֶחֶם בִּכּוּרִים עֶשְׂרִים־לֶחֶם שְׂעֹרִים וְכַרְמֶל בְּצִקְלֹנוֹ וַיֹּאמֶר תֵּן לָעָם וְיֹאכֵלוּ׃}
}
{
	\eX{

		people, that they may eat.
	}
}
{
}

\Verse{43}
{
	\hX{וַיֹּאמֶר מְשָׁרְתוֹ מָה אֶתֵּן זֶה לִפְנֵי מֵאָה אִישׁ וַיֹּאמֶר תֵּן לָעָם וְיֹאכֵלוּ כִּי כֹה אָמַר יְהֹוָה אָכֹל וְהוֹתֵר׃}
}
{
	\eX{

	}
}
{
}
