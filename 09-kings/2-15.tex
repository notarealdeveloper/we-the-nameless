	\hX{וַיִּקְשׁר־קֶשֶׁר הוֹשֵׁעַ בֶּן־אֵלָה עַל־פֶּקַח בֶּן־רְמַלְיָהוּ וַיַּכֵּהוּ וַיְמִיתֵהוּ וַיִּמְלֹךְ תַּחְתָּיו בִּשְׁנַת עֶשְׂרִים לְיוֹתָם בֶּן־עֻזִּיָּה׃}
}
{
	\eX{
		And Hoshea the son of Elah made a conspiracy against Pekah the
		son of Remaliah, and struck him, and killed him, and reigned in
		his place, in the twentieth year of Jotham the son of Uzziah.
	}
}
{
}

\Verse{31}
{
	\hX{וְיֶתֶר דִּבְרֵי־פֶקַח וְכל־אֲשֶׁר עָשָׂה הִנָּם כְּתוּבִים עַל־סֵפֶר דִּבְרֵי הַיָּמִים לְמַלְכֵי יִשְׂרָאֵל׃}
}
{
	\eX{
		And the rest of the acts of Pekah, and all that he did, here:
		they are written in the book of the chronicles of the kings of
		Israel.
	}
}
{
}

\Verse{32}
{
	\hX{בִּשְׁנַת שְׁתַּיִם לְפֶקַח בֶּן־רְמַלְיָהוּ מֶלֶךְ יִשְׂרָאֵל מָלַךְ יוֹתָם בֶּן־עֻזִּיָּהוּ מֶלֶךְ יְהוּדָה׃}
}
{
	\eX{
		In the second year of Pekah the son of Remaliah king of Israel
		began Jotham the son of Uzziah king of Judah to reign.
	}
}
{
}

\Verse{33}
{
	\hX{בֶּן־עֶשְׂרִים וְחָמֵשׁ שָׁנָה הָיָה בְמלְכוֹ וְשֵׁשׁ־עֶשְׂרֵה שָׁנָה מָלַךְ בִּירוּשָׁלָ͏ִם וְשֵׁם אִמּוֹ יְרוּשָׁא בַּת־צָדוֹק׃}
}
{
	\eX{
		Five and twenty years old was he when he began to reign, and he
		reigned sixteen years in Jerusalem. And his mother's name was
		Jerusha, the daughter of Zadok.
	}
}
{
}

\Verse{34}
{
	\hX{וַיַּעַשׂ הַיָּשָׁר בְּעֵינֵי יְהֹוָה כְּכֹל אֲשֶׁר־עָשָׂה עֻזִּיָּהוּ אָבִיו עָשָׂה׃}
}
{
	\eX{
		And he did that that was right in the eyes of YHWH: he did
		according to all that his father Uzziah had done.
	}
}
{
}

\Verse{35}
{
	\hX{רַק הַבָּמוֹת לֹא סָרוּ עוֹד הָעָם מְזַבְּחִים וּמְקַטְּרִים בַּבָּמוֹת הוּא בָּנָה אֶת־שַׁעַר בֵּית־יְהֹוָה הָעֶלְיוֹן׃}
}
{
	\eX{
		Only the high places were not removed: the people sacrificed and
		burned incense still in the high places. He built the higher
		gate of the house of YHWH.
	}
}
{
}

\Verse{36}
{
	\hX{וְיֶתֶר דִּבְרֵי יוֹתָם אֲשֶׁר עָשָׂה הֲלֹא־הֵם כְּתוּבִים עַל־סֵפֶר דִּבְרֵי הַיָּמִים לְמַלְכֵי יְהוּדָה׃}
}
{
	\eX{
		And the rest of the acts of Jotham, and all that he did, are
		they not written in the book of the chronicles of the kings of
		Judah?
	}
}
{
}

\Verse{37}
{
	\hX{בַּיָּמִים הָהֵם הֵחֵל יְהֹוָה לְהַשְׁלִיחַ בִּיהוּדָה רְצִין מֶלֶךְ אֲרָם וְאֵת פֶּקַח בֶּן־רְמַלְיָהוּ׃}
}
{
	\eX{

}
{
}

\Verse{38}
{
	\hX{וַיִּשְׁכַּב יוֹתָם עִם־אֲבֹתָיו וַיִּקָּבֵר עִם־אֲבֹתָיו בְּעִיר דָּוִד אָבִיו וַיִּמְלֹךְ אָחָז בְּנוֹ תַּחְתָּיו׃}
}
{
	\eX{

		reigned in his place.
	}
}
