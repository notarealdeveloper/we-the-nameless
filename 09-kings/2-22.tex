\Chapter{22}

\Verse{1}
{
	\hX{בֶּן־שְׁמֹנֶה שָׁנָה יֹאשִׁיָּהוּ בְמלְכוֹ וּשְׁלֹשִׁים וְאַחַת שָׁנָה מָלַךְ בִּירוּשָׁלָ͏ִם וְשֵׁם אִמּוֹ יְדִידָה בַת־עֲדָיָה מִבָּצְקַת׃}
}
{
	\eX{
		Josiah was eight years old when he began to reign, and he
		reigned thirty-one years in Jerusalem. And his mother's name was
		Jedidah, the daughter of Adaiah of Boscath.
	}
}
{
}

\Verse{2}
{
	\hX{וַיַּעַשׂ הַיָּשָׁר בְּעֵינֵי יְהֹוָה וַיֵּלֶךְ בְּכל־דֶּרֶךְ דָּוִד אָבִיו וְלֹא־סָר יָמִין וּשְׂמֹאול׃}
}
{
	\eX{
		And he did that that was right in the eyes of YHWH, and walked
		in all the way of David his father, and didn't turn aside to the
		right hand or to the left.
	}
}
{
}

\Verse{3}
{
	\hX{וַיְהִי בִּשְׁמֹנֶה עֶשְׂרֵה שָׁנָה לַמֶּלֶךְ יֹאשִׁיָּהוּ שָׁלַח הַמֶּלֶךְ אֶת־שָׁפָן בֶּן־אֲצַלְיָהוּ בֶן־מְשֻׁלָּם הַסֹּפֵר בֵּית יְהֹוָה לֵאמֹר׃}
}
{
	\eX{
		And it was in the eighteenth year of king Josiah, that the king
		sent Shaphan the son of Azaliah, the son of Meshullam, the
		scribe, to the house of YHWH, saying,
	}
}
{
}

\Verse{4}
{
	\hX{עֲלֵה אֶל־חִלְקִיָּהוּ הַכֹּהֵן הַגָּדוֹל וְיַתֵּם אֶת־הַכֶּסֶף הַמּוּבָא בֵּית יְהֹוָה אֲשֶׁר אָסְפוּ שֹׁמְרֵי הַסַּף מֵאֵת הָעָם׃}
}
{
	\eX{
		Go up to Hilkiah the high priest, that he may sum the silver
		that is brought into the house of YHWH, that the keepers of the
		door have gathered of the people:
	}
}
{
}

\Verse{5}
{
	\hX{(ויתנה) [וְיִתְּנוּהוּ] עַל־יַד עֹשֵׂי הַמְּלָאכָה הַמֻּפְקָדִים (בבית) [בֵּית] יְהֹוָה וְיִתְּנוּ אֹתוֹ לְעֹשֵׂי הַמְּלָאכָה אֲשֶׁר בְּבֵית יְהֹוָה לְחַזֵּק בֶּדֶק הַבָּיִת׃}
}
{
	\eX{
		And let them deliver it into the hand of the doers of the work,
		that have the oversight of the house of YHWH: and let them give
		it to the doers of the work that is in the house of YHWH, to
		repair the breaches of the house,
	}
}
{
}

\Verse{6}
{
	\hX{לֶחָרָשִׁים וְלַבֹּנִים וְלַגֹּדְרִים וְלִקְנוֹת עֵצִים וְאַבְנֵי מַחְצֵב לְחַזֵּק אֶת־הַבָּיִת׃}
}
{
	\eX{
		To carpenters, and builders, and masons, and to buy timber and
		hewn stone to repair the house.
	}
}
{
}

\Verse{7}
{
	\hX{אַךְ לֹא־יֵחָשֵׁב אִתָּם הַכֶּסֶף הַנִּתָּן עַל־יָדָם כִּי בֶאֱמוּנָה הֵם עֹשִׂים׃}
}
{
	\eX{
		Only there was no reckoning made with them of the money that was
		delivered into their hand, because they dealt faithfully.
	}
}
{
}

\Verse{8}
{
	\hX{וַיֹּאמֶר חִלְקִיָּהוּ הַכֹּהֵן הַגָּדוֹל עַל־שָׁפָן הַסֹּפֵר סֵפֶר הַתּוֹרָה מָצָאתִי בְּבֵית יְהֹוָה וַיִּתֵּן חִלְקִיָּה אֶת־הַסֵּפֶר אֶל־שָׁפָן וַיִּקְרָאֵהוּ׃}
}
{
	\eX{
		And Hilkiah the high priest said to Shaphan the scribe, I have
		found the book of the law in the house of YHWH. And Hilkiah gave
		the book to Shaphan, and he read it.
	}
}
{
%	\footnote{
%		Footnote 22:8. Finding the scroll is either reform, rediscovery, or a controlled
%		explosion in the archive. The text lets the book do what kings could not.
%	}
}

\Verse{9}
{
	\hX{
		וַיָּבֹא שָׁפָן הַסֹּפֵר אֶל־הַמֶּלֶךְ וַיָּשֶׁב אֶת־הַמֶּלֶךְ דָּבָר וַיֹּאמֶר הִתִּיכוּ עֲבָדֶיךָ אֶת־הַכֶּסֶף הַנִּמְצָא בַבַּיִת וַיִּתְּנֻהוּ עַל־יַד עֹשֵׂי הַמְּלָאכָה
		הַמֻּפְקָדִים בֵּית יְהֹוָה׃
	}
}
{
	\eX{
		And Shaphan the scribe came to the king, and brought the king
		word again, and said, Your servants have gathered the money that
		was found in the house, and have delivered it into the hand of
		them that do the work, that have the oversight of the house of
		YHWH.
	}
}
{
}

\Verse{10}
{
	\hX{וַיַּגֵּד שָׁפָן הַסֹּפֵר לַמֶּלֶךְ לֵאמֹר סֵפֶר נָתַן לִי חִלְקִיָּה הַכֹּהֵן וַיִּקְרָאֵהוּ שָׁפָן לִפְנֵי הַמֶּלֶךְ׃}
}
{
	\eX{
		And Shaphan the scribe showed the king, saying, Hilkiah the
		priest has delivered me a book. And Shaphan read it before the
		king.
	}
}
{
}

\Verse{11}
{
	\hX{וַיְהִי כִּשְׁמֹעַ הַמֶּלֶךְ אֶת־דִּבְרֵי סֵפֶר הַתּוֹרָה וַיִּקְרַע אֶת־בְּגָדָיו׃}
}
{
	\eX{
		And it was, when the king had heard the words of the book of the
		law, that he tore his clothes.
	}
}
{
}

\Verse{12}
{
	\hX{וַיְצַו הַמֶּלֶךְ אֶת־חִלְקִיָּה הַכֹּהֵן וְאֶת־אֲחִיקָם בֶּן־שָׁפָן וְאֶת־עַכְבּוֹר בֶּן־מִיכָיָה וְאֵת שָׁפָן הַסֹּפֵר וְאֵת עֲשָׂיָה עֶבֶד־הַמֶּלֶךְ לֵאמֹר׃}
}
{
	\eX{
		And the king commanded Hilkiah the priest, and Ahikam the son of
		Shaphan, and Achbor the son of Michaiah, and Shaphan the scribe,
		and Asahiah a servant of the king's, saying,
	}
}
{
}

\Verse{13}
{
	\hX{
		לְכוּ דִרְשׁוּ אֶת־יְהֹוָה בַּעֲדִי וּבְעַד־הָעָם וּבְעַד כּל־יְהוּדָה עַל־דִּבְרֵי הַסֵּפֶר הַנִּמְצָא הַזֶּה כִּי־גְדוֹלָה חֲמַת יְהֹוָה אֲשֶׁר־הִיא נִצְּתָה בָנוּ עַל אֲשֶׁר
		לֹא־שָׁמְעוּ אֲבֹתֵינוּ עַל־דִּבְרֵי הַסֵּפֶר הַזֶּה לַעֲשׂוֹת כְּכל־הַכָּתוּב עָלֵינוּ׃
	}
}
{
	\eX{
		Go you, inquire of YHWH for me, and for the people, and for all
		Judah, concerning the words of this book that is found: for
		great is the wrath of YHWH that is kindled against us, because
		our fathers have not hearkened to the words of this book, to do
		according to all that that is written concerning us.
	}
}
{
}

\Verse{14}
{
	\hX{
		וַיֵּלֶךְ חִלְקִיָּהוּ הַכֹּהֵן וַאֲחִיקָם וְעַכְבּוֹר וְשָׁפָן וַעֲשָׂיָה אֶל־חֻלְדָּה הַנְּבִיאָה אֵשֶׁת שַׁלֻּם בֶּן־תִּקְוָה בֶּן־חַרְחַס שֹׁמֵר הַבְּגָדִים וְהִיא יֹשֶׁבֶת
		בִּירוּשָׁלַ͏ִם בַּמִּשְׁנֶה וַיְדַבְּרוּ אֵלֶיהָ׃
	}
}
{
	\eX{
		So Hilkiah the priest, and Ahikam, and Achbor, and Shaphan, and
		Asahiah, went to Huldah the prophetess, the wife of Shallum the
		son of Tikvah, the son of Harhas, keeper of the wardrobe: (now
		she lived in Jerusalem in the college:) and they communed with
		her.
	}
}
{
}

\Verse{15}
{
	\hX{וַתֹּאמֶר אֲלֵיהֶם כֹּה־אָמַר יְהֹוָה אֱלֹהֵי יִשְׂרָאֵל אִמְרוּ לָאִישׁ אֲשֶׁר־שָׁלַח אֶתְכֶם אֵלָי׃}
}
{
	\eX{
		And she said to them, Thus says YHWH God of Israel, Tell the man
		that sent you to me,
	}
}
{
}

\Verse{16}
{
	\hX{כֹּה אָמַר יְהֹוָה הִנְנִי מֵבִיא רָעָה אֶל־הַמָּקוֹם הַזֶּה וְעַל־יֹשְׁבָיו אֵת כּל־דִּבְרֵי הַסֵּפֶר אֲשֶׁר קָרָא מֶלֶךְ יְהוּדָה׃}
}
{
	\eX{
		Thus says YHWH, Here: I'll bring bad on this place, and on the
		inhabitants of it, even all the words of the book that the king
		of Judah has read:
	}
}
{
}

\Verse{17}
{
	\hX{תַּחַת אֲשֶׁר עֲזָבוּנִי וַיְקַטְּרוּ לֵאלֹהִים אֲחֵרִים לְמַעַן הַכְעִיסֵנִי בְּכֹל מַעֲשֵׂה יְדֵיהֶם וְנִצְּתָה חֲמָתִי בַּמָּקוֹם הַזֶּה וְלֹא תִכְבֶּה׃}
}
{
	\eX{
		Because they have forsaken me, and have burned incense to other
		gods, that they might provoke me to anger with all the works of
		their hands: therefore my wrath shall be kindled against this
		place, and won't be quenched.
	}
}
{
}

\Verse{18}
{
	\hX{וְאֶל־מֶלֶךְ יְהוּדָה הַשֹּׁלֵחַ אֶתְכֶם לִדְרֹשׁ אֶת־יְהֹוָה כֹּה תֹאמְרוּ אֵלָיו כֹּה־אָמַר יְהֹוָה אֱלֹהֵי יִשְׂרָאֵל הַדְּבָרִים אֲשֶׁר שָׁמָעְתָּ׃}
}
{
	\eX{
		But to the king of Judah that sent you to inquire of YHWH, thus
		shall you say to him, Thus says YHWH God of Israel, As touching
		the words that you have heard:
	}
}
{
}

\Verse{19}
{
	\hX{
		יַעַן רַךְ־לְבָבְךָ וַתִּכָּנַע מִפְּנֵי יְהֹוָה בְּשׁמְעֲךָ אֲשֶׁר דִּבַּרְתִּי עַל־הַמָּקוֹם הַזֶּה וְעַל־יֹשְׁבָיו לִהְיוֹת לְשַׁמָּה וְלִקְלָלָה וַתִּקְרַע אֶת־בְּגָדֶיךָ
		וַתִּבְכֶּה לְפָנָי וְגַם אָנֹכִי שָׁמַעְתִּי נְאֻם־יְהֹוָה׃
	}
}
{
	\eX{
		Because your heart was tender, and you have humbled yourself in
		front of YHWH, when you heard what I spoke against this place,
		and against the inhabitants of it, that they should become a
		desolation and a curse, and have torn your clothes, and wept in
		front of me: I also have heard you, says YHWH.
	}
}
{
}

\Verse{20}
{
	\hX{
		לָכֵן הִנְנִי אֹסִפְךָ עַל־אֲבֹתֶיךָ וְנֶאֱסַפְתָּ אֶל־קִבְרֹתֶיךָ בְּשָׁלוֹם וְלֹא־תִרְאֶינָה עֵינֶיךָ בְּכֹל הָרָעָה אֲשֶׁר־אֲנִי מֵבִיא עַל־הַמָּקוֹם הַזֶּה וַיָּשִׁבוּ
		אֶת־הַמֶּלֶךְ דָּבָר׃
	}
}
{
	\eX{
		Here therefore, I'll gather you to your fathers, and you shall
		be gathered into your grave in peace: and your eyes won't see
		all the bad that I'll bring on this place. And they brought the
		king word again.
	}
}
{
}
