{
	\eX{
		And it was in the thirty-seventh year of the captivity of
		Jehoiachin king of Judah, in the twelfth month, on the
		twenty-seventh day of the month, that Evilmerodach king of
		Babylon in the year that he began to reign lifted the head of
		Jehoiachin king of Judah out of prison:
	}
}
{
}

\Verse{28}
{
	\hX{וַיְדַבֵּר אִתּוֹ טֹבוֹת וַיִּתֵּן אֶת־כִּסְאוֹ מֵעַל כִּסֵּא הַמְּלָכִים אֲשֶׁר אִתּוֹ בְּבָבֶל׃}
}
{
	\eX{
		And he spoke kindly to him, and set his throne above the throne
		of the kings that were with him in Babylon:
	}
}
{
}

\Verse{29}
{
	\hX{וְשִׁנָּא אֵת בִּגְדֵי כִלְאוֹ וְאָכַל לֶחֶם תָּמִיד לְפָנָיו כּל־יְמֵי חַיָּיו׃}
}
{
	\eX{
		And changed his prison garments: and he ate bread continually in
		front of him all the days of his life.
	}
}
{
}

\Verse{30}
{
	\hX{וַאֲרֻחָתוֹ אֲרֻחַת תָּמִיד נִתְּנָה־לּוֹ מֵאֵת הַמֶּלֶךְ דְּבַר־יוֹם בְּיוֹמוֹ כֹּל יְמֵי חַיָּו׃}
}
{
	\eX{
		And his allowance was a continual allowance given him of the
		king, a daily rate for every day, all the days of his life.
	}
}
