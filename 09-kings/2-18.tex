\Chapter{18}

\Verse{1}
{
	\hX{וַיְהִי בִּשְׁנַת שָׁלֹשׁ לְהוֹשֵׁעַ בֶּן־אֵלָה מֶלֶךְ יִשְׂרָאֵל מָלַךְ חִזְקִיָּה בֶן־אָחָז מֶלֶךְ יְהוּדָה׃}
}
{
	\eX{
		And it was in the third year of Hoshea son of Elah king of
		Israel, that Hezekiah the son of Ahaz king of Judah began to
		reign.
	}
}
{
}

\Verse{2}
{
	\hX{בֶּן־עֶשְׂרִים וְחָמֵשׁ שָׁנָה הָיָה בְמלְכוֹ וְעֶשְׂרִים וָתֵשַׁע שָׁנָה מָלַךְ בִּירוּשָׁלָ͏ִם וְשֵׁם אִמּוֹ אֲבִי בַּת־זְכַרְיָה׃}
}
{
	\eX{
		Twenty and five years old was he when he began to reign: and he
		reigned twenty and nine years in Jerusalem. His mother's name
		also was Abi, the daughter of Zachariah.
	}
}
{
}

\Verse{3}
{
	\hX{וַיַּעַשׂ הַיָּשָׁר בְּעֵינֵי יְהֹוָה כְּכֹל אֲשֶׁר־עָשָׂה דָּוִד אָבִיו׃}
}
{
	\eX{
		And he did that that was right in the eyes of YHWH, according to
		all that David his father did.
	}
}
{
}

\Verse{4}
{
	\hX{
		הוּא הֵסִיר אֶת־הַבָּמוֹת וְשִׁבַּר אֶת־הַמַּצֵּבֹת וְכָרַת אֶת־הָאֲשֵׁרָה וְכִתַּת נְחַשׁ הַנְּחֹשֶׁת אֲשֶׁר־עָשָׂה מֹשֶׁה כִּי עַד־הַיָּמִים הָהֵמָּה הָיוּ בְנֵי־יִשְׂרָאֵל
		מְקַטְּרִים לוֹ וַיִּקְרָא־לוֹ נְחֻשְׁתָּן׃
	}
}
{
	\eX{
		He removed the high places, and broke the images, and cut down
		the groves, and broke in pieces the bronze serpent that Moses
		had made: for to those days the children of Israel did burn
		incense to it: and he called it Nehushtan.
	}
}
{
}

\Verse{5}
{
	\hX{בַּיהֹוָה אֱלֹהֵי־יִשְׂרָאֵל בָּטָח וְאַחֲרָיו לֹא־הָיָה כָמֹהוּ בְּכֹל מַלְכֵי יְהוּדָה וַאֲשֶׁר הָיוּ לְפָנָיו׃}
}
{
	\eX{
		He trusted in YHWH God of Israel: so that after him was none
		like him among all the kings of Judah, nor any that were in
		front of him.
	}
}
{
}

\Verse{6}
{
	\hX{וַיִּדְבַּק בַּיהֹוָה לֹא־סָר מֵאַחֲרָיו וַיִּשְׁמֹר מִצְוֺתָיו אֲשֶׁר־צִוָּה יְהֹוָה אֶת־מֹשֶׁה׃}
}
{
	\eX{
		For he clung to YHWH, and didn't depart from following him, but
		kept his commandments, that YHWH commanded Moses.
	}
}
{
}

\Verse{7}
{
	\hX{וְהָיָה יְהֹוָה עִמּוֹ בְּכֹל אֲשֶׁר־יֵצֵא יַשְׂכִּיל וַיִּמְרֹד בְּמֶלֶךְ־אַשּׁוּר וְלֹא עֲבָדוֹ׃}
}
{
	\eX{
		And YHWH was with him: and he prospered whithersoever he went
		out: and he rebelled against the king of Assyria, and served him
		not.
	}
}
{
}

\Verse{8}
{
	\hX{הוּא־הִכָּה אֶת־פְּלִשְׁתִּים עַד־עַזָּה וְאֶת־גְּבוּלֶיהָ מִמִּגְדַּל נוֹצְרִים עַד־עִיר מִבְצָר׃}
}
{
	\eX{
		He struck the Philistines, even to Gaza, and the borders of it,
		from the tower of the watchmen to the fortified city.
	}
}
{
}

\Verse{9}
{
	\hX{
		וַיְהִי בַּשָּׁנָה הָרְבִיעִית לַמֶּלֶךְ חִזְקִיָּהוּ הִיא הַשָּׁנָה הַשְּׁבִיעִית לְהוֹשֵׁעַ בֶּן־אֵלָה מֶלֶךְ יִשְׂרָאֵל עָלָה שַׁלְמַנְאֶסֶר מֶלֶךְ־אַשּׁוּר עַל־שֹׁמְרוֹן
		וַיָּצַר עָלֶיהָ׃
	}
}
{
	\eX{
		And it was in the fourth year of king Hezekiah, that was the
		seventh year of Hoshea son of Elah king of Israel, that
		Shalmaneser king of Assyria came up against Samaria, and laid
		siege to it.
	}
}
{
}

\Verse{10}
{
	\hX{וַיִּלְכְּדֻהָ מִקְצֵה שָׁלֹשׁ שָׁנִים בִּשְׁנַת־שֵׁשׁ לְחִזְקִיָּה הִיא שְׁנַת־תֵּשַׁע לְהוֹשֵׁעַ מֶלֶךְ יִשְׂרָאֵל נִלְכְּדָה שֹׁמְרוֹן׃}
}
{
	\eX{
		And at the end of three years they took it: even in the sixth
		year of Hezekiah, that is in the ninth year of Hoshea king of
		Israel, Samaria was taken.
	}
}
{
}

\Verse{11}
{
	\hX{וַיֶּגֶל מֶלֶךְ־אַשּׁוּר אֶת־יִשְׂרָאֵל אַשּׁוּרָה וַיַּנְחֵם בַּחְלַח וּבְחָבוֹר נְהַר גּוֹזָן וְעָרֵי מָדָי׃}
}
{
	\eX{
		And the king of Assyria did carry away Israel to Assyria, and
		put them in Halah and in Habor by the river of Gozan, and in the
		cities of the Medes:
	}
}
{
}

\Verse{12}
{
	\hX{עַל אֲשֶׁר לֹא־שָׁמְעוּ בְּקוֹל יְהֹוָה אֱלֹהֵיהֶם וַיַּעַבְרוּ אֶת־בְּרִיתוֹ אֵת כּל־אֲשֶׁר צִוָּה מֹשֶׁה עֶבֶד יְהֹוָה וְלֹא שָׁמְעוּ וְלֹא עָשׂוּ׃}
}
{
	\eX{
		Because they obeyed not the voice of YHWH their God, but
		transgressed his covenant, and all that Moses the servant of
		YHWH commanded, and would not hear them, nor do them.
	}
}
{
}

\Verse{13}
{
	\hX{וּבְאַרְבַּע עֶשְׂרֵה שָׁנָה לַמֶּלֶךְ חִזְקִיָּה עָלָה סַנְחֵרִיב מֶלֶךְ־אַשּׁוּר עַל כּל־עָרֵי יְהוּדָה הַבְּצֻרוֹת וַיִּתְפְּשֵׂם׃}
}
{
	\eX{
		And in the fourteenth year of king Hezekiah did Sennacherib king
		of Assyria come up against all the fenced cities of Judah, and
		took them.
	}
}
{
}

\Verse{14}
{
	\hX{
		וַיִּשְׁלַח חִזְקִיָּה מֶלֶךְ־יְהוּדָה אֶל־מֶלֶךְ־אַשּׁוּר לָכִישָׁה לֵאמֹר חָטָאתִי שׁוּב מֵעָלַי אֵת אֲשֶׁר־תִּתֵּן עָלַי אֶשָּׂא וַיָּשֶׂם מֶלֶךְ־אַשּׁוּר עַל־חִזְקִיָּה
		מֶלֶךְ־יְהוּדָה שְׁלֹשׁ מֵאוֹת כִּכַּר־כֶּסֶף וּשְׁלֹשִׁים כִּכַּר זָהָב׃
	}
}
{
	\eX{
		And Hezekiah king of Judah sent to the king of Assyria to
		Lachish, saying, I have offended: return from me: that that you
		puttest on me will I bear. And the king of Assyria appointed to
		Hezekiah king of Judah three hundred talents of silver and
		thirty talents of gold.
	}
}
{
}

\Verse{15}
{
	\hX{וַיִּתֵּן חִזְקִיָּה אֶת־כּל־הַכֶּסֶף הַנִּמְצָא בֵית־יְהֹוָה וּבְאֹצְרוֹת בֵּית הַמֶּלֶךְ׃}
}
{
	\eX{
		And Hezekiah gave him all the silver that was found in the house
		of YHWH, and in the treasures of the king's house.
	}
}
{
}

\Verse{16}
{
	\hX{בָּעֵת הַהִיא קִצַּץ חִזְקִיָּה אֶת־דַּלְתוֹת הֵיכַל יְהֹוָה וְאֶת־הָאֹמְנוֹת אֲשֶׁר צִפָּה חִזְקִיָּה מֶלֶךְ יְהוּדָה וַיִּתְּנֵם לְמֶלֶךְ אַשּׁוּר׃}
}
{
	\eX{

	}
}
{
}

\Verse{17}
{
	\hX{
		וַיִּשְׁלַח מֶלֶךְ־אַשּׁוּר אֶת־תַּרְתָּן וְאֶת־רַב־סָרִיס וְאֶת־רַבְשָׁקֵה מִן־לָכִישׁ אֶל־הַמֶּלֶךְ חִזְקִיָּהוּ בְּחֵיל כָּבֵד יְרוּשָׁלָ͏ִם וַיַּעֲלוּ וַיָּבֹאוּ יְרוּשָׁלַ͏ִם
		וַיַּעֲלוּ וַיָּבֹאוּ וַיַּעַמְדוּ בִּתְעָלַת הַבְּרֵכָה הָעֶלְיוֹנָה אֲשֶׁר בִּמְסִלַּת שְׂדֵה כֹבֵס׃
	}
}
{
	\eX{
		And the king of Assyria sent Tartan and Rabsaris and Rabshakeh
		from Lachish to king Hezekiah with a great army against
		Jerusalem. And they went up and came to Jerusalem. And when they
		were come up, they came and stood by the conduit of the upper
		pool, that is in the highway of the fuller's field.
	}
}
{
}

\Verse{18}
{
	\hX{וַיִּקְרְאוּ אֶל־הַמֶּלֶךְ וַיֵּצֵא אֲלֵהֶם אֶלְיָקִים בֶּן־חִלְקִיָּהוּ אֲשֶׁר עַל־הַבָּיִת וְשֶׁבְנָה הַסֹּפֵר וְיוֹאָח בֶּן־אָסָף הַמַּזְכִּיר׃}
}
{
	\eX{
		And when they had called to the king, there came out to them
		Eliakim the son of Hilkiah, that was over the household, and

	}
}
{
}

\Verse{19}
{
	\hX{וַיֹּאמֶר אֲלֵיהֶם רַבְשָׁקֵה אִמְרוּ־נָא אֶל־חִזְקִיָּהוּ כֹּה־אָמַר הַמֶּלֶךְ הַגָּדוֹל מֶלֶךְ אַשּׁוּר מָה הַבִּטָּחוֹן הַזֶּה אֲשֶׁר בָּטָחְתָּ׃}

}
{
}

{

\Verse{21}
{
	\hX{

	}
}
{
}

{

	}
}
{
}

{
}

\Verse{24}

}

	}
}
{
}
