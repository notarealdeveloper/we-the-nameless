\Verse{9}

}
{
	\eP{
		“When Pharaoh will speak to you, saying, ‘Produce a
		wonder!’ then say to Aaron, ‘Take your staff and throw it
		in front of Pharaoh. Let it become a serpent.’”
	}
}
{
%	\footnote{
%		a serpent. Not a snake. This is different from the snake (Hebrew nh)
%		that Moses’ staff became in Exod 4:3. Moses performed that miracle for
%		the Israelite elders (4:30). Now, in front of Pharaoh, Aaron’s staff
%		becomes a tannîn. This is the term that is used for the big sea serpents
%		that God makes on the fifth day of creation (Gen 1:21). They are not
%		merely snakes, as people have often pictured them. They are
%		extraordinary creatures from a seemingly unearthly realm.
%	}
}

	\eE{
		YHWH said this: “By this you’ll know that I am YHWH.”
		Here, I’m striking with the staff that’s in my hand on the

		blood.
	}
}
{
%	\footnote{
%		By this you’ll know that I am YHWH. This is the story of the
%		introduction of the deity by name to the world, so this statement can be
%		understood not only as establishing the existence of the named deity to
%		Pharaoh, but also as establishing what the name conveys. Thus: By this
%		(a miracle involving a change in nature) you’ll know that I am the one
%		who causes being.
%	}
