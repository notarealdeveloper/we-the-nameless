\Chapter{15}

\Verse{1}

	\hJ{אַחַר הַדְּבָרִים הָאֵלֶּה הָיָה דְבַר יְהֹוָה אֶל אַבְרָם בַּמַּחֲזֶה לֵאמֹר אַל תִּירָא אַבְרָם אָנֹכִי מָגֵן לָךְ שְׂכָרְךָ הַרְבֵּה מְאֹד}
}
{
	\eJ{
		After these things YHWH’s word came to Abram in a vision, saying,\\
		“Don’t fear, Abram. I’m a shield for you. Your reward is very much.”\\

}
{
}

\Verse{2}
{
	\hJ{וַיֹּאמֶר אַבְרָם אֲדֹנָי יֱהֹוִה מַה תִּתֶּן לִי וְאָנֹכִי הוֹלֵךְ עֲרִירִי וּבֶן מֶשֶׁק בֵּיתִי הוּא דַּמֶּשֶׂק אֱלִיעֶזֶר}
}
{
	\eJ{
		And Abram said, “My Lord, YHWH, what would you give me when I go
		childless and my household is an acquired person!” (That is Damascus
		Eliezer.)\\
	}
}
{
}

\Verse{3}
{
	\hJ{וַיֹּאמֶר אַבְרָם הֵן לִי לֹא נָתַתָּה זָרַע וְהִנֵּה בֶן בֵּיתִי יוֹרֵשׁ אֹתִי}
}
{
	\eJ{
		And Abram said, “Here, you haven’t given me seed. And, here, a member

	}
}
{
}

\Verse{4}
{
	\hJ{וְהִנֵּה דְבַר יְהֹוָה אֵלָיו לֵאמֹר לֹא יִירָשְׁךָ זֶה כִּי אִם אֲשֶׁר יֵצֵא מִמֵּעֶיךָ הוּא יִירָשֶׁךָ}
}
{
	\eJ{
		And, here, YHWH’s word came to him, saying, “This one won’t take
		possession from you, but rather one who will come out of your in-sides:
		he will take possession from you.”\\
	}
}
{
}

\Verse{5}
{
	\hJ{וַיּוֹצֵא אֹתוֹ הַחוּצָה וַיֹּאמֶר הַבֶּט נָא הַשָּׁמַיְמָה וּסְפֹר הַכּוֹכָבִים אִם תּוּכַל לִסְפֹּר אֹתָם וַיֹּאמֶר לוֹ כֹּה יִהְיֶה זַרְעֶךָ}
}
{
	\eJ{
		And He brought him outside and said, “Look at the skies and count the

}
{
}

}
{
	\eJ{

}
{

}

	\eJ{

	\eJ{
