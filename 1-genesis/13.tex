\Chapter{13}

\Verse{1}
{
	\hJ{וַיַּעַל אַבְרָם מִמִּצְרַיִם הוּא וְאִשְׁתּוֹ וְכל אֲשֶׁר לוֹ וְלוֹט עִמּוֹ הַנֶּגְבָּה}
}
{
	\eJ{
		And Abram went up from Egypt,\\
		he and his wife and all he had\\
		and Lot with him,\\
		to the Negeb.\\
	}
}
{
}

\Verse{2}
{
	\hJ{וְאַבְרָם כָּבֵד מְאֹד בַּמִּקְנֶה בַּכֶּסֶף וּבַזָּהָב}
}
{
	\eJ{
		And Abram was very heavy\\
		with livestock and silver and gold.\\
	}
}
{
}

\Verse{3}
{
	\hJ{וַיֵּלֶךְ לְמַסָּעָיו מִנֶּגֶב וְעַד בֵּית אֵל עַד הַמָּקוֹם אֲשֶׁר הָיָה שָׁם אהֳלֹה בַּתְּחִלָּה בֵּין בֵּית אֵל וּבֵין הָעָי}
}
{
	\eJ{
		And he went on his travels\\
		from the Negeb as far as Beth-El,\\
		as far as the place where his tent was at the start,\\
		between Beth-El and Ai,\\
	}
}
{
}

\Verse{4}
{
	\hJ{אֶל מְקוֹם הַמִּזְבֵּחַ אֲשֶׁר עָשָׂה שָׁם בָּרִאשֹׁנָה וַיִּקְרָא שָׁם אַבְרָם בְּשֵׁם יְהֹוָה}
}
{
	\eJ{
		to the place of the altar that he had made there at the beginning.\\
		And Abram invoked the name YHWH there.\\
	}
}
{
}

\Verse{5}
{
	\hJ{וְגַם לְלוֹט הַהֹלֵךְ אֶת אַבְרָם הָיָה צֹאן וּבָקָר וְאֹהָלִים}
}
{
	\eJ{
		And Lot, who was going with Abram,\\
		also had a flock and oxen and tents.\\
	}
}
{
}

\Verse{6}
{
	\hP{וְלֹא נָשָׂא אֹתָם הָאָרֶץ לָשֶׁבֶת יַחְדָּו כִּי הָיָה רְכוּשָׁם רָב}
	\hP{וְלֹא יָכְלוּ לָשֶׁבֶת יַחְדָּו}
}
{
	\eP{
		And the land did not suffice them to live together,
		because their property was great,
	}
	\eP{
		and they were not able to live together.\\
	}
}
{
}


\Verse{7}
{
	\hJ{וַיְהִי רִיב בֵּין רֹעֵי מִקְנֵה אַבְרָם וּבֵין רֹעֵי מִקְנֵה לוֹט וְהַכְּנַעֲנִי וְהַפְּרִזִּי אָז יֹשֵׁב בָּאָרֶץ}
}
{
	\eJ{
		And there was a quarrel
		between those who herded Abram’s livestock
		and those who herded Lot’s livestock.
		And the Canaanite and the Perizzite
		lived in the land then.
	}
}
{
}

\Verse{8}
{
	\hJ{וַיֹּאמֶר אַבְרָם אֶל לוֹט אַל נָא תְהִי מְרִיבָה בֵּינִי וּבֵינֶיךָ וּבֵין רֹעַי וּבֵין רֹעֶיךָ כִּי אֲנָשִׁים אַחִים אֲנָחְנוּ}
}
{
	\eJ{
		And Abram said to Lot,\\
		“Let there be no quarreling between me and you
		and between my herders and your herders,
		because we’re brothers.
	}
}
{
}

\Verse{9}
{
	\hJ{הֲלֹוא כל הָאָרֶץ לְפָנֶיךָ הִפָּרֶד נָא מֵעָלָי אִם הַשְּׂמֹאל וְאֵימִנָה וְאִם הַיָּמִין וְאַשְׂמְאִילָה}
}
{
	\eJ{
		Isn’t the whole land before you?
		Separate from me: if left then I’ll go right,
		and if right then I’ll go left.”
	}
}
{
}

\Verse{10}
{
	\hJ{וַיִּשָּׂא לוֹט אֶת עֵינָיו וַיַּרְא אֶת כּל כִּכַּר הַיַּרְדֵּן כִּי כֻלָּהּ מַשְׁקֶה לִפְנֵי שַׁחֵת יְהֹוָה אֶת סְדֹם וְאֶת עֲמֹרָה כְּגַן יְהֹוָה כְּאֶרֶץ מִצְרַיִם בֹּאֲכָה צֹעַר}
}
{
	\eJ{
		And Lot raised his eyes\\
		and saw all the plain of the Jordan,\\
		that all of it was well watered\\
		(before YHWH’s destroying Sodom and Gomorrah),\\
		like YHWH’s garden,\\
		like the land of Egypt,\\
		as you come to Zoar.\\
	}
}
{
}

\Verse{11}
{
	\hP{וַיִּבְחַר לוֹ לוֹט אֵת כּל כִּכַּר הַיַּרְדֵּן וַיִּסַּע לוֹט מִקֶּדֶם}
	\hJ{וַיִּפָּרְדוּ אִישׁ מֵעַל אָחִיו}
}
{
	\eP{
		And Lot chose all the plain of the Jordan for himself,
		and Lot traveled east.\\
	}
	\eJ{
		And they separated, each from his brother.\\
	}
}
{
}

\Verse{12}
{
	\hP{אַבְרָם יָשַׁב בְּאֶרֶץ כְּנָעַן וְלוֹט יָשַׁב בְּעָרֵי הַכִּכָּר}
	\hJ{וַיֶּאֱהַל עַד סְדֹם}
}
{
	\eP{
		Abram lived in the land of Canaan,\\
		and Lot lived in the cities of the plain.\\
	}
	\eJ{
		And he tented as far as Sodom.\\
	}
}
{
}


\Verse{13}
{
	\hJ{וְאַנְשֵׁי סְדֹם רָעִים וְחַטָּאִים לַיהֹוָה מְאֹד}
}
{
	\eJ{
		And the people of Sodom\\
		were very bad and sinful to YHWH.\\
	}
}
{
}

\Verse{14}
{
	\hJ{וַיהֹוָה אָמַר אֶל אַבְרָם אַחֲרֵי הִפָּרֶד לוֹט מֵעִמּוֹ שָׂא נָא עֵינֶיךָ וּרְאֵה מִן הַמָּקוֹם אֲשֶׁר אַתָּה שָׁם צָפֹנָה וָנֶגְבָּה וָקֵדְמָה וָיָמָּה}
}
{
	\eJ{
		And YHWH said to Abram\\
		after Lot’s separation from him,\\
		“Lift your eyes and see from the place where you are\\
		to the north and south and east and west.\\
	}
}
{
}

\Verse{15}
{
	\hJ{כִּי אֶת כּל הָאָרֶץ אֲשֶׁר אַתָּה רֹאֶה לְךָ אֶתְּנֶנָּה וּלְזַרְעֲךָ עַד עוֹלָם}
}
{
	\eJ{
		For all the land that you see,\\
		I’ll give it to you and to your seed forever.\\
	}
}
{
}

\Verse{16}
{
	\hJ{וְשַׂמְתִּי אֶת זַרְעֲךָ כַּעֲפַר הָאָרֶץ אֲשֶׁר אִם יוּכַל אִישׁ לִמְנוֹת אֶת עֲפַר הָאָרֶץ גַּם זַרְעֲךָ יִמָּנֶה}
}
{
	\eJ{
		And I’ll make your seed like the dust of the earth,\\
		so that if a man could count the dust of the earth\\
		then your seed also could be counted.\\
	}
}
{
}

\Verse{17}
{
	\hJ{קוּם הִתְהַלֵּךְ בָּאָרֶץ לְארְכָּהּ וּלְרחְבָּהּ כִּי לְךָ אֶתְּנֶנָּה}
}
{
	\eJ{
		Get up, go around in the land\\
		to its length and its width,\\
		because I’m giving it to you.”\\
	}
}
{
}

\Verse{18}
{
	\hJ{וַיֶּאֱהַל אַבְרָם וַיָּבֹא וַיֵּשֶׁב בְּאֵלֹנֵי מַמְרֵא אֲשֶׁר בְּחֶבְרוֹן וַיִּבֶן שָׁם מִזְבֵּחַ לַיהֹוָה}
}
{
	\eJ{
		And Abram took up his tent\\
		and came and lived among the oaks of Mamre\\
		which are in Hebron,\\
		and he built an altar to YHWH there.\\
	}
}
{
}
