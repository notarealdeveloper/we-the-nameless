	\hX{(אחרי) [אַחֲרָיו] הֶחֱזִיק מַלְכִּיָּה בֶּן־הַצֹּרְפִי עַד־בֵּית הַנְּתִינִים וְהָרֹכְלִים נֶגֶד שַׁעַר הַמִּפְקָד וְעַד עֲלִיַּת הַפִּנָּה׃}
}
{
	\eX{
		After him, Malchijah of the smiths repaired as far as the house of
		the temple servants and the merchants, [from] in front of the
		Muster Gate to the corner loft.
	}
}
{
	Qere Ketiv.
}

\Verse{32}
{
	\hX{וּבֵין עֲלִיַּת הַפִּנָּה לְשַׁעַר הַצֹּאן הֶחֱזִיקוּ הַצֹּרְפִים וְהָרֹכְלִים׃}
}
{
	\eX{
		And between the corner loft to the Sheep Gate the smiths and the
		merchants repaired.
	}
}
{
}

\Verse{33}
{
	\hX{וַיְהִי כַּאֲשֶׁר שָׁמַע סַנְבַלַּט כִּי־אֲנַחְנוּ בוֹנִים אֶת־הַחוֹמָה וַיִּחַר לוֹ וַיִּכְעַס הַרְבֵּה וַיַּלְעֵג עַל־הַיְּהוּדִים׃}
}
{
	\eX{
		When Sanballat heard that we were rebuilding the wall, it angered
		him, and he was extremely vexed. He mocked the Jews,
	}
}
{
}

\Verse{34}
{
	\hX{
		וַיֹּאמֶר לִפְנֵי אֶחָיו וְחֵיל שֹׁמְרוֹן וַיֹּאמֶר מָה הַיְּהוּדִים הָאֲמֵלָלִים עֹשִׂים הֲיַעַזְבוּ לָהֶם הֲיִזְבָּחוּ הַיְכַלּוּ בַיּוֹם הַיְחַיּוּ אֶת־הָאֲבָנִים מֵעֲרֵמוֹת
		הֶעָפָר וְהֵמָּה שְׂרוּפוֹת׃
	}
}
{
	\eX{
		saying in the presence of his brothers and the Samarian force,
		“What are the miserable Jews doing? Will they restore, offer
		sacrifice, and finish one day? Can they revive those stones out of
		the dust heaps, burned as they are?”
	}
}
{
}

\Verse{35}
{
	\hX{וְטוֹבִיָּה הָעַמֹּנִי אֶצְלוֹ וַיֹּאמֶר גַּם אֲשֶׁר־הֵם בּוֹנִים אִם־יַעֲלֶה שׁוּעָל וּפָרַץ חוֹמַת אַבְנֵיהֶם׃}
}
{
	\eX{
		Tobiah the Ammonite, alongside him, said, “That stone wall they
		are building—if a fox climbed it he would breach it!”
	}
}
{
}

\Verse{36}
{
	\hX{שְׁמַע אֱלֹהֵינוּ כִּי־הָיִינוּ בוּזָה וְהָשֵׁב חֶרְפָּתָם אֶל־רֹאשָׁם וּתְנֵם לְבִזָּה בְּאֶרֶץ שִׁבְיָה׃}
}
{
	\eX{
		Hear, our God, how we have become a mockery, and return their
		taunts upon their heads! Let them be taken as spoil to a land of
		captivity!
	}
}
{
}

\Verse{37}
{
	\hX{וְאַל־תְּכַס עַל־עֲוֺנָם וְחַטָּאתָם מִלְּפָנֶיךָ אַל־תִּמָּחֶה כִּי הִכְעִיסוּ לְנֶגֶד הַבּוֹנִים׃}
}
{
	\eX{
		Do not cover up their iniquity or let their sin be blotted out
		before You, for they hurled provocations at the builders.
	}
}
{
}

\Verse{38}
{
	\hX{וַנִּבְנֶה אֶת־הַחוֹמָה וַתִּקָּשֵׁר כּל־הַחוֹמָה עַד־חֶצְיָהּ וַיְהִי לֵב לָעָם לַעֲשׂוֹת׃}
}
{
	\eX{
		We rebuilt the wall till it was continuous all around to half its
		height; for the people’s heart was in the work.
	}
}
{
}
