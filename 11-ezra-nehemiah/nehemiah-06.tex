\Chapter{6}

\Verse{1}
{
	\hX{
		וַיְהִי כַאֲשֶׁר נִשְׁמַע לְסַנְבַלַּט וְטוֹבִיָּה וּלְגֶשֶׁם הָעַרְבִי וּלְיֶתֶר אֹיְבֵינוּ כִּי בָנִיתִי אֶת־הַחוֹמָה וְלֹא־נוֹתַר בָּהּ פָּרֶץ גַּם עַד־הָעֵת הַהִיא דְּלָתוֹת
		לֹא־הֶעֱמַדְתִּי בַשְּׁעָרִים׃
	}
}
{
	\eX{
		When word reached Sanballat, Tobiah, Geshem the Arab, and the rest
		of our enemies that I had rebuilt the wall and not a breach
		remained in it—though at that time I had not yet set up doors in
		the gateways—
	}
}
{
}

\Verse{2}
{
	\hX{וַיִּשְׁלַח סַנְבַלַּט וְגֶשֶׁם אֵלַי לֵאמֹר לְכָה וְנִוָּעֲדָה יַחְדָּו בַּכְּפִירִים בְּבִקְעַת אוֹנוֹ וְהֵמָּה חֹשְׁבִים לַעֲשׂוֹת לִי רָעָה׃}
}
{
	\eX{
		Sanballat and Geshem sent a message to me, saying, “Come, let us
		get together in Kephirim in the Ono valley”; they planned to do me
		harm.
	}
}
{
}

\Verse{3}
{
	\hX{וָאֶשְׁלְחָה עֲלֵיהֶם מַלְאָכִים לֵאמֹר מְלָאכָה גְדוֹלָה אֲנִי עֹשֶׂה וְלֹא אוּכַל לָרֶדֶת לָמָּה תִשְׁבַּת הַמְּלָאכָה כַּאֲשֶׁר אַרְפֶּהָ וְיָרַדְתִּי אֲלֵיכֶם׃}
}
{
	\eX{
		I sent them messengers, saying, “I am engaged in a great work and
		cannot come down, for the work will stop if I leave it in order to
		come down to you.”
	}
}
{
}

\Verse{4}
{
	\hX{וַיִּשְׁלְחוּ אֵלַי כַּדָּבָר הַזֶּה אַרְבַּע פְּעָמִים וָאָשִׁיב אוֹתָם כַּדָּבָר הַזֶּה׃}
}
{
	\eX{
		They sent me the same message four times, and I gave them the same
		answer.
	}
}
{
}

\Verse{5}
{
	\hX{וַיִּשְׁלַח אֵלַי סַנְבַלַּט כַּדָּבָר הַזֶּה פַּעַם חֲמִישִׁית אֶת־נַעֲרוֹ וְאִגֶּרֶת פְּתוּחָה בְּיָדוֹ׃}
}
{
	\eX{
		Sanballat sent me the same message a fifth time by his servant,
		who had an open letter with him.
	}
}
{
}

\Verse{6}
{
	\hX{כָּתוּב בָּהּ בַּגּוֹיִם נִשְׁמָע וְגַשְׁמוּ אֹמֵר אַתָּה וְהַיְּהוּדִים חֹשְׁבִים לִמְרוֹד עַל־כֵּן אַתָּה בוֹנֶה הַחוֹמָה וְאַתָּה הֹוֶה לָהֶם לְמֶלֶךְ כַּדְּבָרִים הָאֵלֶּה׃}
}
{
	\eX{
		Its text was: “Word has reached the nations, and Geshem too says
		that you and the Jews are planning to rebel—for which reason you
		are building the wall—and that you are to be their king. Such is
		the word.
	}
}
{
}

\Verse{7}
{
	\hX{וְגַם־נְבִיאִים הֶעֱמַדְתָּ לִקְרֹא עָלֶיךָ בִירוּשָׁלַ͏ִם לֵאמֹר מֶלֶךְ בִּיהוּדָה וְעַתָּה יִשָּׁמַע לַמֶּלֶךְ כַּדְּבָרִים הָאֵלֶּה וְעַתָּה לְכָה וְנִוָּעֲצָה יַחְדָּו׃}
}
{
	\eX{
		You have also set up prophets in Jerusalem to proclaim about you,
		‘There is a king in Judah!’ Word of these things will surely reach
		the king; so come, let us confer together.”
	}
}
{
}

\Verse{8}
{
	\hX{וָאֶשְׁלְחָה אֵלָיו לֵאמֹר לֹא נִהְיָה כַּדְּבָרִים הָאֵלֶּה אֲשֶׁר אַתָּה אוֹמֵר כִּי מִלִּבְּךָ אַתָּה בוֹדָאם׃}
}
{
	\eX{
		I sent back a message to him, saying, “None of these things you
		mention has occurred; they are figments of your imagination”—
	}
}
{
}

\Verse{9}
{
	\hX{כִּי כֻלָּם מְיָרְאִים אוֹתָנוּ לֵאמֹר יִרְפּוּ יְדֵיהֶם מִן־הַמְּלָאכָה וְלֹא תֵעָשֶׂה וְעַתָּה חַזֵּק אֶת־יָדָי׃}
}
{
	\eX{
		for they all wished to intimidate us, thinking, “They will desist
		from the work, and it will not get done.” Now strengthen my hands!
	}
}
{
}

\Verse{10}
{
	\hX{
		וַאֲנִי־בָאתִי בֵּית שְׁמַעְיָה בֶן־דְּלָיָה בֶּן־מְהֵיטַבְאֵל וְהוּא עָצוּר וַיֹּאמֶר נִוָּעֵד אֶל־בֵּית הָאֱלֹהִים אֶל־תּוֹךְ הַהֵיכָל וְנִסְגְּרָה דַּלְתוֹת הַהֵיכָל כִּי
		בָּאִים לְהרְגֶךָ וְלַיְלָה בָּאִים לְהרְגֶךָ׃
	}
}
{
	\eX{
		Then I visited Shemaiah son of Delaiah son of Mehetabel when he
		was housebound, and he said, “Let us meet in the House of God,
		inside the sanctuary, And let us shut the doors of the sanctuary,
		for they are coming to kill you, By night they are coming to kill
		you.”
	}
}
{
}

\Verse{11}
{
	\hX{וָאֹמְרָה הַאִישׁ כָּמוֹנִי יִבְרָח וּמִי כָמוֹנִי אֲשֶׁר־יָבֹא אֶל־הַהֵיכָל וָחָי לֹא אָבוֹא׃}
}
{
	\eX{
		I replied, “Will a man like me take flight? Besides, who such as I
		can go into the sanctuary and live? I will not go in.”
	}
}
{
}

\Verse{12}
{
	\hX{וָאַכִּירָה וְהִנֵּה לֹא־אֱלֹהִים שְׁלָחוֹ כִּי הַנְּבוּאָה דִּבֶּר עָלַי וְטוֹבִיָּה וְסַנְבַלַּט שְׂכָרוֹ׃}
}
{
	\eX{
		Then I realized that it was not God who sent him, but that he
		uttered that prophecy about me—Tobiah and Sanballat having hired
		him—
	}
}
{
}

\Verse{13}
{
	\hX{לְמַעַן שָׂכוּר הוּא לְמַעַן־אִירָא וְאֶעֱשֶׂה־כֵּן וְחָטָאתִי וְהָיָה לָהֶם לְשֵׁם רָע לְמַעַן יְחָרְפוּנִי׃}
}
{
	\eX{
		because he was a hireling, that I might be intimidated and act
		thus and commit a sin, and so provide them a scandal with which to
		reproach me.
	}
}
{
}

\Verse{14}
{
	\hX{זכְרָה אֱלֹהַי לְטוֹבִיָּה וּלְסַנְבַלַּט כְּמַעֲשָׂיו אֵלֶּה וְגַם לְנוֹעַדְיָה הַנְּבִיאָה וּלְיֶתֶר הַנְּבִיאִים אֲשֶׁר הָיוּ מְיָרְאִים אוֹתִי׃}
}
{
	\eX{
		“O my God, remember against Tobiah and Sanballat these deeds of
		theirs, and against Noadiah the prophetess, and against the other
		prophets that they wished to intimidate me!”
	}
}
{
}

\Verse{15}
{
	\hX{וַתִּשְׁלַם הַחוֹמָה בְּעֶשְׂרִים וַחֲמִשָּׁה לֶאֱלוּל לַחֲמִשִּׁים וּשְׁנַיִם יוֹם׃}
}
{
	\eX{
		The wall was finished on the twenty-fifth of Elul, after fifty-two
		days.
	}
}
{
}

\Verse{16}
{
	\hX{
		וַיְהִי כַּאֲשֶׁר שָׁמְעוּ כּל־אוֹיְבֵינוּ וַיִּרְאוּ כּל־הַגּוֹיִם אֲשֶׁר סְבִיבֹתֵינוּ וַיִּפְּלוּ מְאֹד בְּעֵינֵיהֶם וַיֵּדְעוּ כִּי מֵאֵת אֱלֹהֵינוּ נֶעֶשְׂתָה הַמְּלָאכָה
		הַזֹּאת׃
	}
}
{
	\eX{
		When all our enemies heard it, all the nations round about us were
		intimidated, and fell very low in their own estimation; they
		realized that this work had been accomplished by the help of our
		God.
	}
}
{
}

\Verse{17}
{
	\hX{גַּם בַּיָּמִים הָהֵם מַרְבִּים חֹרֵי יְהוּדָה אִגְּרֹתֵיהֶם הוֹלְכוֹת עַל־טוֹבִיָּה וַאֲשֶׁר לְטוֹבִיָּה בָּאוֹת אֲלֵיהֶם׃}
}
{
	\eX{
		Also in those days, the nobles of Judah kept up a brisk
		correspondence with Tobiah, and Tobiah with them.
	}
}
{
}

\Verse{18}
{
	\hX{כִּי־רַבִּים בִּיהוּדָה בַּעֲלֵי שְׁבוּעָה לוֹ כִּי־חָתָן הוּא לִשְׁכַנְיָה בֶן־אָרַח וִיהוֹחָנָן בְּנוֹ לָקַח אֶת־בַּת־מְשֻׁלָּם בֶּן בֶּרֶכְיָה׃}
}
{
	\eX{
		Many in Judah were his confederates, for he was a son-in-law of
		Shecaniah son of Arah, and his son Jehohanan had married the
		daughter of Meshullam son of Berechiah.
	}
}
{
}

\Verse{19}
{
	\hX{גַּם טוֹבֹתָיו הָיוּ אֹמְרִים לְפָנַי וּדְבָרַי הָיוּ מוֹצִיאִים לוֹ אִגְּרוֹת שָׁלַח טוֹבִיָּה לְיָרְאֵנִי׃}
}
{
	\eX{
		They would also speak well of him to me, and would divulge my
		affairs to him. Tobiah sent letters to intimidate me.
	}
}
{
}
