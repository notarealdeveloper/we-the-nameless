}

	\eX{
		In the first year of King Cyrus, King Cyrus issued an order
		concerning the House of God in Jerusalem: ‘Let the house be
		rebuilt, a place for offering sacrifices, with a base built up
		high. Let it be sixty cubits high and sixty cubits wide,
	}
}
{
}

\Verse{4}

}
{
	\eX{

		stone. The expenses shall be paid by the palace.
	}
}
{
}

\Verse{5}
{
	\hX{
		וְאַף מָאנֵי בֵית־אֱלָהָא דִּי דַהֲבָה וְכַסְפָּא דִּי נְבוּכַדְנֶצַּר הַנְפֵּק מִן־הֵיכְלָא דִי־בִירוּשְׁלֶם וְהֵיבֵל לְבָבֶל יַהֲתִיבוּן וִיהָךְ לְהֵיכְלָא דִי־בִירוּשְׁלֶם
		לְאַתְרֵהּ וְתַחֵת בְּבֵית אֱלָהָא׃
	}
}
{
	\eX{
		And the gold and silver vessels of the House of God which
		Nebuchadnezzar had taken away from the temple in Jerusalem and
		transported to Babylon shall be returned, and let each go back to
		the temple in Jerusalem where it belongs; you shall deposit it in
		the House of God.’
	}
}
{
}

\Verse{6}
{
	\hX{כְּעַן תַּתְּנַי פַּחַת עֲבַר־נַהֲרָה שְׁתַר בּוֹזְנַי וּכְנָוָתְהוֹן אֲפַרְסְכָיֵא דִּי בַּעֲבַר נַהֲרָה רַחִיקִין הֲווֹ מִן־תַּמָּה׃}
}
{
	\eX{
		“Now you, Tattenai, governor of the province of Beyond the River,
		Shethar-bozenai and colleagues, the officials of the province of
		Beyond the River, stay away from that place.
	}
}
{
}

\Verse{7}
{
	\hX{שְׁבֻקוּ לַעֲבִידַת בֵּית־אֱלָהָא דֵךְ פַּחַת יְהוּדָיֵא וּלְשָׂבֵי יְהוּדָיֵא בֵּית־אֱלָהָא דֵךְ יִבְנוֹן עַל־אַתְרֵהּ׃}
}
{
	\eX{
		Allow the work of this House of God to go on; let the governor of
		the Jews and the elders of the Jews rebuild this House of God on
		its site.
	}
}
{
}

\Verse{8}
{
	\hX{
		וּמִנִּי שִׂים טְעֵם לְמָא דִי־תַעַבְדוּן עִם־שָׂבֵי יְהוּדָיֵא אִלֵּךְ לְמִבְנֵא בֵּית־אֱלָהָא דֵךְ וּמִנִּכְסֵי מַלְכָּא דִּי מִדַּת עֲבַר נַהֲרָה אסְפַּרְנָא נִפְקְתָא תֶּהֱוֵא
		מִתְיַהֲבָא לְגֻבְרַיָּא אִלֵּךְ דִּי־לָא לְבַטָּלָא׃
	}
}
{
	\eX{
		And I hereby issue an order concerning what you must do to help
		these elders of the Jews rebuild this House of God: the expenses
		are to be paid to these men with dispatch out of the resources of
		the king, derived from the taxes of the province of Beyond the
		River, so that the work not be stopped.
	}
}
{
}

\Verse{9}
{
	\hX{
		וּמָה חַשְׁחָן וּבְנֵי תוֹרִין וְדִכְרִין וְאִמְּרִין לַעֲלָוָן לֶאֱלָהּ שְׁמַיָּא חִנְטִין מְלַח חֲמַר וּמְשַׁח כְּמֵאמַר כָּהֲנַיָּא דִי־בִירוּשְׁלֶם לֶהֱוֵא מִתְיְהֵב לְהֹם יוֹם
		בְּיוֹם דִּי־לָא שָׁלוּ׃
	}
}
{
	\eX{
		They are to be given daily, without fail, whatever they need of
		young bulls, rams, or lambs as burnt offerings for the God of
		Heaven, and wheat, salt, wine, and oil, at the order of the
		priests in Jerusalem,
	}
}
{
}

\Verse{10}
{
	\hX{דִּי־לֶהֱוֺן מְהַקְרְבִין נִיחוֹחִין לֶאֱלָהּ שְׁמַיָּא וּמְצַלַּיִן לְחַיֵּי מַלְכָּא וּבְנוֹהִי׃}
}

	\eX{

		and pray for the life of the king and his sons.
	}
}
{
}

\Verse{11}
{
	\hX{וּמִנִּי שִׂים טְעֵם דִּי כל־אֱנָשׁ דִּי יְהַשְׁנֵא פִּתְגָמָא דְנָה יִתְנְסַח אָע מִן־בַּיְתֵהּ וּזְקִיף יִתְמְחֵא עֲלֹהִי וּבַיְתֵהּ נְוָלוּ יִתְעֲבֵד עַל־דְּנָה׃}
}
{
	\eX{

	}
}
{
}

\Verse{12}
{
	\hX{
		וֵאלָהָא דִּי שַׁכִּן שְׁמֵהּ תַּמָּה יְמַגַּר כּל־מֶלֶךְ וְעַם דִּי יִשְׁלַח יְדֵהּ לְהַשְׁנָיָה לְחַבָּלָה בֵּית־אֱלָהָא דֵךְ דִּי בִירוּשְׁלֶם אֲנָה דָרְיָוֶשׁ שָׂמֶת טְעֵם
		אסְפַּרְנָא יִתְעֲבִד׃
	}
}
{
	\eX{
		And may the God who established His name there cause the downfall
		of any king or nation that undertakes to alter or damage that
		House of God in Jerusalem. I, Darius, have issued the decree; let
		it be carried out with dispatch.”
	}
}
{
}

\Verse{13}

	\eX{

		וְדָרְיָוֶשׁ וְאַרְתַּחְשַׁשְׂתְּא מֶלֶךְ פָּרָס׃

		Artaxerxes of Persia.
