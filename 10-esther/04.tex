\Chapter{4}

\Verse{1}
{
	\hX{וּמרְדֳּכַי יָדַע אֶת־כּל־אֲשֶׁר נַעֲשָׂה וַיִּקְרַע מרְדֳּכַי אֶת־בְּגָדָיו וַיִּלְבַּשׁ שַׂק וָאֵפֶר וַיֵּצֵא בְּתוֹךְ הָעִיר וַיִּזְעַק זְעָקָה גְדוֹלָה וּמָרָה׃}
}
{
	\eX{
		When Mordecai learned all that had happened, Mordecai tore his
		clothes and put on sackcloth and ashes. He went through the city,
		crying out loudly and bitterly,
	}
}
{
}

\Verse{2}
{
	\hX{וַיָּבוֹא עַד לִפְנֵי שַׁעַר־הַמֶּלֶךְ כִּי אֵין לָבוֹא אֶל־שַׁעַר הַמֶּלֶךְ בִּלְבוּשׁ שָׂק׃}
}
{
	\eX{
		until he came in front of the palace gate; for one could not enter
		the palace gate wearing sackcloth.—
	}
}
{
}

\Verse{3}
{
	\hX{וּבְכל־מְדִינָה וּמְדִינָה מְקוֹם אֲשֶׁר דְּבַר־הַמֶּלֶךְ וְדָתוֹ מַגִּיעַ אֵבֶל גָּדוֹל לַיְּהוּדִים וְצוֹם וּבְכִי וּמִסְפֵּד שַׂק וָאֵפֶר יֻצַּע לָרַבִּים׃}
}
{
	\eX{
		Also, in every province that the king’s command and decree
		reached, there was great mourning among the Jews, with fasting,
		weeping, and wailing, and everybody lay in sackcloth and ashes.—
	}
}
{
}

\Verse{4}
{
	\hX{
		(ותבואינה) [וַתָּבוֹאנָה] נַעֲרוֹת אֶסְתֵּר וְסָרִיסֶיהָ וַיַּגִּידוּ לָהּ וַתִּתְחַלְחַל הַמַּלְכָּה מְאֹד וַתִּשְׁלַח בְּגָדִים לְהַלְבִּישׁ אֶת־מרְדֳּכַי וּלְהָסִיר שַׂקּוֹ
		מֵעָלָיו וְלֹא קִבֵּל׃
	}
}
{
	\eX{
		When Esther’s maidens and eunuchs came and informed her, the queen
		was greatly agitated. She sent clothing for Mordecai to wear, so
		that he might take off his sackcloth; but he refused.
	}
}
{
	Qere Ketiv.
}

\Verse{5}
{
	\hX{וַתִּקְרָא אֶסְתֵּר לַהֲתָךְ מִסָּרִיסֵי הַמֶּלֶךְ אֲשֶׁר הֶעֱמִיד לְפָנֶיהָ וַתְּצַוֵּהוּ עַל־מרְדֳּכָי לָדַעַת מַה־זֶּה וְעַל־מַה־זֶּה׃}
}
{
	\eX{
		Thereupon Esther summoned Hathach, one of the eunuchs whom the
		king had appointed to serve her, and sent him to Mordecai to learn
		the why and wherefore of it all.
	}
}
{
}

\Verse{6}
{
	\hX{וַיֵּצֵא הֲתָךְ אֶל־מרְדֳּכָי אֶל־רְחוֹב הָעִיר אֲשֶׁר לִפְנֵי שַׁעַר־הַמֶּלֶךְ׃}
}
{
	\eX{
		Hathach went out to Mordecai in the city square in front of the
		palace gate;
	}
}
{
}

\Verse{7}
{
	\hX{וַיַּגֶּד־לוֹ מרְדֳּכַי אֵת כּל־אֲשֶׁר קָרָהוּ וְאֵת פָּרָשַׁת הַכֶּסֶף אֲשֶׁר אָמַר הָמָן לִשְׁקוֹל עַל־גִּנְזֵי הַמֶּלֶךְ (ביהודיים) [בַּיְּהוּדִים] לְאַבְּדָם׃}
}
{
	\eX{
		and Mordecai told him all that had happened to him, and all about
		the money that Haman had offered to pay into the royal treasury
		for the destruction of the Jews.
	}
}
{
	Qere Ketiv.
}

\Verse{8}
{
	\hX{
		וְאֶת־פַּתְשֶׁגֶן כְּתָב־הַדָּת אֲשֶׁר־נִתַּן בְּשׁוּשָׁן לְהַשְׁמִידָם נָתַן לוֹ לְהַרְאוֹת אֶת־אֶסְתֵּר וּלְהַגִּיד לָהּ וּלְצַוּוֹת עָלֶיהָ לָבוֹא אֶל־הַמֶּלֶךְ לְהִתְחַנֶּן־לוֹ
		וּלְבַקֵּשׁ מִלְּפָנָיו עַל־עַמָּהּ׃
	}
}
{
	\eX{
		He also gave him the written text of the law that had been
		proclaimed in Shushan for their destruction. [He bade him] show it
		to Esther and inform her, and charge her to go to the king and to
		appeal to him and to plead with him for her people.
	}
}
{
}

}

}
{
	\eX{

	}

\Verse{11}
{
	\hX{
		כּל־עַבְדֵי הַמֶּלֶךְ וְעַם־מְדִינוֹת הַמֶּלֶךְ יֹדְעִים אֲשֶׁר כּל־אִישׁ וְאִשָּׁה אֲשֶׁר יָבוֹא־אֶל־הַמֶּלֶךְ אֶל־הֶחָצֵר הַפְּנִימִית אֲשֶׁר לֹא־יִקָּרֵא אַחַת דָּתוֹ לְהָמִית
		לְבַד מֵאֲשֶׁר יוֹשִׁיט־לוֹ הַמֶּלֶךְ אֶת־שַׁרְבִיט הַזָּהָב וְחָיָה וַאֲנִי לֹא נִקְרֵאתִי לָבוֹא אֶל־הַמֶּלֶךְ זֶה שְׁלוֹשִׁים יוֹם׃
	}
}
{
	\eX{
		“All the king’s courtiers and the people of the king’s provinces
		know that if any person, man or woman, enters the king’s presence
		in the inner court without having been summoned, there is but one
		law for him—that he be put to death. Only if the king extends the
		golden scepter to him may he live. Now I have not been summoned to
		visit the king for the last thirty days.”
	}
}
{
}

\Verse{12}
{
	\hX{וַיַּגִּידוּ לְמרְדֳּכָי אֵת דִּבְרֵי אֶסְתֵּר׃}
}
{
	\eX{When Mordecai was told what Esther had said,}
}
{
}

\Verse{13}
{
	\hX{וַיֹּאמֶר מרְדֳּכַי לְהָשִׁיב אֶל־אֶסְתֵּר אַל־תְּדַמִּי בְנַפְשֵׁךְ לְהִמָּלֵט בֵּית־הַמֶּלֶךְ מִכּל־הַיְּהוּדִים׃}
}
{
	\eX{
		Mordecai had this message delivered to Esther: “Do not imagine
		that you, of all the Jews, will escape with your life by being in
		the king’s palace.
	}
}
{
}

\Verse{14}
{
	\hX{
		כִּי אִם־הַחֲרֵשׁ תַּחֲרִישִׁי בָּעֵת הַזֹּאת רֶוַח וְהַצָּלָה יַעֲמוֹד לַיְּהוּדִים מִמָּקוֹם אַחֵר וְאַתְּ וּבֵית־אָבִיךְ תֹּאבֵדוּ וּמִי יוֹדֵעַ אִם־לְעֵת כָּזֹאת הִגַּעַתְּ
		לַמַּלְכוּת׃
	}
}
{
	\eX{
		On the contrary, if you keep silent in this crisis, relief and
		deliverance will come to the Jews from another quarter, while you
		and your father’s house will perish. And who knows, perhaps you
		have attained to royal position for just such a crisis.”
	}
}
{
}

}
{
	\eX{Then Esther sent back this answer to Mordecai:}
}
{
}

\Verse{16}
{
	\hX{
		לֵךְ כְּנוֹס אֶת־כּל־הַיְּהוּדִים הַנִּמְצְאִים בְּשׁוּשָׁן וְצוּמוּ עָלַי וְאַל־תֹּאכְלוּ וְאַל־תִּשְׁתּוּ שְׁלֹשֶׁת יָמִים לַיְלָה וָיוֹם גַּם־אֲנִי וְנַעֲרֹתַי אָצוּם כֵּן
		וּבְכֵן אָבוֹא אֶל־הַמֶּלֶךְ אֲשֶׁר לֹא־כַדָּת וְכַאֲשֶׁר אָבַדְתִּי אָבָדְתִּי׃
	}
}
{
	\eX{
		“Go, assemble all the Jews who live in Shushan, and fast in my
		behalf; do not eat or drink for three days, night or day. I and my
		maidens will observe the same fast. Then I shall go to the king,
		though it is contrary to the law; and if I am to perish, I shall
		perish!”
	}
}
{
}
