\Chapter{3}

\Verse{1}
{
	\hX{אַחַר הַדְּבָרִים הָאֵלֶּה גִּדַּל הַמֶּלֶךְ אֲחַשְׁוֵרוֹשׁ אֶת־הָמָן בֶּן־הַמְּדָתָא הָאֲגָגִי וַיְנַשְּׂאֵהוּ וַיָּשֶׂם אֶת־כִּסְאוֹ מֵעַל כּל־הַשָּׂרִים אֲשֶׁר אִתּוֹ׃}
}
{
	\eX{
		After these things did king Ahasuerus promote Haman the son of
		Hammedatha the Agagite, and advanced him, and set his seat above
		all the princes that were with him.
	}
}
{
}

\Verse{2}
{
	\hX{וְכל־עַבְדֵי הַמֶּלֶךְ אֲשֶׁר־בְּשַׁעַר הַמֶּלֶךְ כֹּרְעִים וּמִשְׁתַּחֲוִים לְהָמָן כִּי־כֵן צִוָּה־לוֹ הַמֶּלֶךְ וּמרְדֳּכַי לֹא יִכְרַע וְלֹא יִשְׁתַּחֲוֶה׃}
}
{
	\eX{
		And all the king’s servants, that were in the king’s gate,
		bowed, and reverenced Haman: for the king had so commanded
		concerning him. But Mordecai bowed not, nor did him reverence.
	}
}
{
}

\Verse{3}
{
	\hX{וַיֹּאמְרוּ עַבְדֵי הַמֶּלֶךְ אֲשֶׁר־בְּשַׁעַר הַמֶּלֶךְ לְמרְדֳּכָי מַדּוּעַ אַתָּה עוֹבֵר אֵת מִצְוַת הַמֶּלֶךְ׃}
}
{
	\eX{
		Then the king’s servants, which were in the king’s gate, said
		unto Mordecai, Why transgressest thou the king’s commandment?
	}
}
{
}

\Verse{4}
{
	\hX{וַיְהִי (באמרם) [כְּאמְרָם] אֵלָיו יוֹם וָיוֹם וְלֹא שָׁמַע אֲלֵיהֶם וַיַּגִּידוּ לְהָמָן לִרְאוֹת הֲיַעַמְדוּ דִּבְרֵי מרְדֳּכַי כִּי־הִגִּיד לָהֶם אֲשֶׁר־הוּא יְהוּדִי׃}
}
{
	\eX{
		Now it came to pass, when they spake daily unto him, and he
		hearkened not unto them, that they told Haman, to see whether
		Mordecai’s matters would stand: for he had told them that he was
		a Jew.
	}
}
{
}

\Verse{5}
{
	\hX{וַיַּרְא הָמָן כִּי־אֵין מרְדֳּכַי כֹּרֵעַ וּמִשְׁתַּחֲוֶה לוֹ וַיִּמָּלֵא הָמָן חֵמָה׃}
}
{
	\eX{
		And when Haman saw that Mordecai bowed not, nor did him
		reverence, then was Haman full of wrath.
	}
}
{
}

\Verse{6}
{
	\hX{
		וַיִּבֶז בְּעֵינָיו לִשְׁלֹחַ יָד בְּמרְדֳּכַי לְבַדּוֹ כִּי־הִגִּידוּ לוֹ אֶת־עַם מרְדֳּכָי וַיְבַקֵּשׁ הָמָן לְהַשְׁמִיד אֶת־כּל־הַיְּהוּדִים אֲשֶׁר בְּכל־מַלְכוּת אֲחַשְׁוֵרוֹשׁ
		עַם מרְדֳּכָי׃
	}
}
{
	\eX{
		And he thought scorn to lay hands on Mordecai alone; for they
		had shewed him the people of Mordecai: wherefore Haman sought to
		destroy all the Jews that were throughout the whole kingdom of
		Ahasuerus, even the people of Mordecai.
	}
}
{
}

\Verse{7}
{
	\hX{
		בַּחֹדֶשׁ הָרִאשׁוֹן הוּא־חֹדֶשׁ נִיסָן בִּשְׁנַת שְׁתֵּים עֶשְׂרֵה לַמֶּלֶךְ אֲחַשְׁוֵרוֹשׁ הִפִּיל פּוּר הוּא הַגּוֹרָל לִפְנֵי הָמָן מִיּוֹם לְיוֹם וּמֵחֹדֶשׁ לְחֹדֶשׁ
		שְׁנֵים־עָשָׂר הוּא־חֹדֶשׁ אֲדָר׃
	}
}
{
	\eX{
		In the first month, that is, the month Nisan, in the twelfth
		year of king Ahasuerus, they cast Pur, that is, the lot, before
		Haman from day to day, and from month to month, to the twelfth
		month, that is, the month Adar.
	}
}
{
}

\Verse{8}
{
	\hX{
		וַיֹּאמֶר הָמָן לַמֶּלֶךְ אֲחַשְׁוֵרוֹשׁ יֶשְׁנוֹ עַם־אֶחָד מְפֻזָּר וּמְפֹרָד בֵּין הָעַמִּים בְּכֹל מְדִינוֹת מַלְכוּתֶךָ וְדָתֵיהֶם שֹׁנוֹת מִכּל־עָם וְאֶת־דָּתֵי הַמֶּלֶךְ
		אֵינָם עֹשִׂים וְלַמֶּלֶךְ אֵין־שֹׁוֶה לְהַנִּיחָם׃
	}
}
{
	\eX{
		And Haman said unto king Ahasuerus, There is a certain people
		scattered abroad and dispersed among the people in all the
		provinces of thy kingdom; and their laws are diverse from all
		people; neither keep they the king’s laws: therefore it is not
		for the king’s profit to suffer them.
	}
}
{
}

\Verse{9}
{
	\hX{אִם־עַל־הַמֶּלֶךְ טוֹב יִכָּתֵב לְאַבְּדָם וַעֲשֶׂרֶת אֲלָפִים כִּכַּר־כֶּסֶף אֶשְׁקוֹל עַל־יְדֵי עֹשֵׂי הַמְּלָאכָה לְהָבִיא אֶל־גִּנְזֵי הַמֶּלֶךְ׃}
}
{
	\eX{
		If it please the king, let it be written that they may be
		destroyed: and I will pay ten thousand talents of silver to the
		hands of those that have the charge of the business, to bring it
		into the king’s treasuries.
	}
}
{
}

\Verse{10}
{
	\hX{וַיָּסַר הַמֶּלֶךְ אֶת־טַבַּעְתּוֹ מֵעַל יָדוֹ וַיִּתְּנָהּ לְהָמָן בֶּן־הַמְּדָתָא הָאֲגָגִי צֹרֵר הַיְּהוּדִים׃}
}
{
	\eX{
		And the king took his ring from his hand, and gave it unto Haman
		the son of Hammedatha the Agagite, the Jews’ enemy.
	}
}
{
}

\Verse{11}
{
	\hX{וַיֹּאמֶר הַמֶּלֶךְ לְהָמָן הַכֶּסֶף נָתוּן לָךְ וְהָעָם לַעֲשׂוֹת בּוֹ כַּטּוֹב בְּעֵינֶיךָ׃}
}
{
	\eX{
		And the king said unto Haman, The silver is given to thee, the
		people also, to do with them as it seemeth good to thee.
	}
}
{
}

\Verse{12}
{
	\hX{
		וַיִּקָּרְאוּ סֹפְרֵי הַמֶּלֶךְ בַּחֹדֶשׁ הָרִאשׁוֹן בִּשְׁלוֹשָׁה עָשָׂר יוֹם בּוֹ וַיִּכָּתֵב כְּכל־אֲשֶׁר־צִוָּה הָמָן אֶל אֲחַשְׁדַּרְפְּנֵי־הַמֶּלֶךְ וְאֶל־הַפַּחוֹת אֲשֶׁר
		עַל־מְדִינָה וּמְדִינָה וְאֶל־שָׂרֵי עַם וָעָם מְדִינָה וּמְדִינָה כִּכְתָבָהּ וְעַם וָעָם כִּלְשׁוֹנוֹ בְּשֵׁם הַמֶּלֶךְ אֲחַשְׁוֵרֹשׁ נִכְתָּב וְנֶחְתָּם בְּטַבַּעַת הַמֶּלֶךְ׃
	}
}
{
	\eX{
		Then were the king’s scribes called on the thirteenth day of the
		first month, and there was written according to all that Haman
		had commanded unto the king’s lieutenants, and to the governors
		that were over every province, and to the rulers of every people
		of every province according to the writing thereof, and to every
		people after their language; in the name of king Ahasuerus was
		it written, and sealed with the king’s ring.
	}
}
{
}

\Verse{13}
{
	\hX{
		וְנִשְׁלוֹחַ סְפָרִים בְּיַד הָרָצִים אֶל־כּל־מְדִינוֹת הַמֶּלֶךְ לְהַשְׁמִיד לַהֲרֹג וּלְאַבֵּד אֶת־כּל־הַיְּהוּדִים מִנַּעַר וְעַד־זָקֵן טַף וְנָשִׁים בְּיוֹם אֶחָד בִּשְׁלוֹשָׁה
		עָשָׂר לְחֹדֶשׁ שְׁנֵים־עָשָׂר הוּא־חֹדֶשׁ אֲדָר וּשְׁלָלָם לָבוֹז׃
	}
}
{
	\eX{
		And the letters were sent by posts into all the king’s
		provinces, to destroy, to kill, and to cause to perish, all
		Jews, both young and old, little children and women, in one day,
		even upon the thirteenth day of the twelfth month, which is the
		month Adar, and to take the spoil of them for a prey.
	}
}
{
}

\Verse{14}
{
	\hX{פַּתְשֶׁגֶן הַכְּתָב לְהִנָּתֵן דָּת בְּכל־מְדִינָה וּמְדִינָה גָּלוּי לְכל־הָעַמִּים לִהְיוֹת עֲתִדִים לַיּוֹם הַזֶּה׃}
}
{
	\eX{
		The copy of the writing for a commandment to be given in every
		province was published unto all people, that they should be
		ready against that day.
	}
}
{
}

\Verse{15}
{
	\hX{הָרָצִים יָצְאוּ דְחוּפִים בִּדְבַר הַמֶּלֶךְ וְהַדָּת נִתְּנָה בְּשׁוּשַׁן הַבִּירָה וְהַמֶּלֶךְ וְהָמָן יָשְׁבוּ לִשְׁתּוֹת וְהָעִיר שׁוּשָׁן נָבוֹכָה׃}
}
{
	\eX{
		The posts went out, being hastened by the king’s commandment,
		and the decree was given in Shushan the palace. And the king and
		Haman sat down to drink; but the city Shushan was perplexed.
	}
}
{
}
