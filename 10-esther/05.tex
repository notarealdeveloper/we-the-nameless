\Chapter{5}

\Verse{1}
{
	\hX{
		וַיְהִי בַּיּוֹם הַשְּׁלִישִׁי וַתִּלְבַּשׁ אֶסְתֵּר מַלְכוּת וַתַּעֲמֹד בַּחֲצַר בֵּית־הַמֶּלֶךְ הַפְּנִימִית נֹכַח בֵּית הַמֶּלֶךְ וְהַמֶּלֶךְ יוֹשֵׁב עַל־כִּסֵּא מַלְכוּתוֹ
		בְּבֵית הַמַּלְכוּת נֹכַח פֶּתַח הַבָּיִת׃
	}
}
{
	\eX{
		Now it came to pass on the third day, that Esther put on her
		royal apparel, and stood in the inner court of the king’s house,
		over against the king’s house: and the king sat upon his royal
		throne in the royal house, over against the gate of the house.
	}
}
{
}

\Verse{2}
{
	\hX{
		וַיְהִי כִרְאוֹת הַמֶּלֶךְ אֶת־אֶסְתֵּר הַמַּלְכָּה עֹמֶדֶת בֶּחָצֵר נָשְׂאָה חֵן בְּעֵינָיו וַיּוֹשֶׁט הַמֶּלֶךְ לְאֶסְתֵּר אֶת־שַׁרְבִיט הַזָּהָב אֲשֶׁר בְּיָדוֹ וַתִּקְרַב
		אֶסְתֵּר וַתִּגַּע בְּרֹאשׁ הַשַּׁרְבִיט׃
	}
}
{
	\eX{
		And it was so, when the king saw Esther the queen standing in
		the court, that she obtained favour in his sight: and the king
		held out to Esther the golden sceptre that was in his hand. So
		Esther drew near, and touched the top of the sceptre.
	}
}
{
}

\Verse{3}
{
	\hX{וַיֹּאמֶר לָהּ הַמֶּלֶךְ מַה־לָּךְ אֶסְתֵּר הַמַּלְכָּה וּמַה־בַּקָּשָׁתֵךְ עַד־חֲצִי הַמַּלְכוּת וְיִנָּתֵן לָךְ׃}
}
{
	\eX{
		Then said the king unto her, What wilt thou, queen Esther? and
		what is thy request? it shall be even given thee to the half of
		the kingdom.
	}
}
{
}

\Verse{4}
{
	\hX{וַתֹּאמֶר אֶסְתֵּר אִם־עַל־הַמֶּלֶךְ טוֹב יָבוֹא הַמֶּלֶךְ וְהָמָן הַיּוֹם אֶל־הַמִּשְׁתֶּה אֲשֶׁר־עָשִׂיתִי לוֹ׃}
}
{
	\eX{
		And Esther answered, If it seem good unto the king, let the king
		and Haman come this day unto the banquet that I have prepared
		for him.
	}
}
{
}

\Verse{5}
{
	\hX{וַיֹּאמֶר הַמֶּלֶךְ מַהֲרוּ אֶת־הָמָן לַעֲשׂוֹת אֶת־דְּבַר אֶסְתֵּר וַיָּבֹא הַמֶּלֶךְ וְהָמָן אֶל־הַמִּשְׁתֶּה אֲשֶׁר־עָשְׂתָה אֶסְתֵּר׃}
}
{
	\eX{
		Then the king said, Cause Haman to make haste, that he may do as
		Esther hath said. So the king and Haman came to the banquet that
		Esther had prepared.
	}
}
{
}

\Verse{6}
{
	\hX{וַיֹּאמֶר הַמֶּלֶךְ לְאֶסְתֵּר בְּמִשְׁתֵּה הַיַּיִן מַה־שְּׁאֵלָתֵךְ וְיִנָּתֵן לָךְ וּמַה־בַּקָּשָׁתֵךְ עַד־חֲצִי הַמַּלְכוּת וְתֵעָשׂ׃}
}
{
	\eX{
		And the king said unto Esther at the banquet of wine, What is
		thy petition? and it shall be granted thee: and what is thy
		request? even to the half of the kingdom it shall be performed.
	}
}
{
}

\Verse{7}
{
	\hX{וַתַּעַן אֶסְתֵּר וַתֹּאמַר שְׁאֵלָתִי וּבַקָּשָׁתִי׃}
}
{
	\eX{Then answered Esther, and said, My petition and my request is;}
}
{
}

\Verse{8}
{
	\hX{
		אִם־מָצָאתִי חֵן בְּעֵינֵי הַמֶּלֶךְ וְאִם־עַל־הַמֶּלֶךְ טוֹב לָתֵת אֶת־שְׁאֵלָתִי וְלַעֲשׂוֹת אֶת־בַּקָּשָׁתִי יָבוֹא הַמֶּלֶךְ וְהָמָן אֶל־הַמִּשְׁתֶּה אֲשֶׁר אֶעֱשֶׂה לָהֶם
		וּמָחָר אֶעֱשֶׂה כִּדְבַר הַמֶּלֶךְ׃
	}
}
{
	\eX{
		If I have found favour in the sight of the king, and if it
		please the king to grant my petition, and to perform my request,
		let the king and Haman come to the banquet that I shall prepare
		for them, and I will do to morrow as the king hath said.
	}
}
{
}

\Verse{9}
{
	\hX{וַיֵּצֵא הָמָן בַּיּוֹם הַהוּא שָׂמֵחַ וְטוֹב לֵב וְכִרְאוֹת הָמָן אֶת־מרְדֳּכַי בְּשַׁעַר הַמֶּלֶךְ וְלֹא־קָם וְלֹא־זָע מִמֶּנּוּ וַיִּמָּלֵא הָמָן עַל־מרְדֳּכַי חֵמָה׃}
}
{
	\eX{
		Then went Haman forth that day joyful and with a glad heart: but
		when Haman saw Mordecai in the king’s gate, that he stood not
		up, nor moved for him, he was full of indignation against
		Mordecai.
	}
}
{
}

\Verse{10}
{
	\hX{וַיִּתְאַפַּק הָמָן וַיָּבוֹא אֶל־בֵּיתוֹ וַיִּשְׁלַח וַיָּבֵא אֶת־אֹהֲבָיו וְאֶת־זֶרֶשׁ אִשְׁתּוֹ׃}
}
{
	\eX{
		Nevertheless Haman refrained himself: and when he came home, he
		sent and called for his friends, and Zeresh his wife.
	}
}
{
}

\Verse{11}
{
	\hX{וַיְסַפֵּר לָהֶם הָמָן אֶת־כְּבוֹד עשְׁרוֹ וְרֹב בָּנָיו וְאֵת כּל־אֲשֶׁר גִּדְּלוֹ הַמֶּלֶךְ וְאֵת אֲשֶׁר נִשְּׂאוֹ עַל־הַשָּׂרִים וְעַבְדֵי הַמֶּלֶךְ׃}
}
{
	\eX{
		And Haman told them of the glory of his riches, and the
		multitude of his children, and all the things wherein the king
		had promoted him, and how he had advanced him above the princes
		and servants of the king.
	}
}
{
}

\Verse{12}
{
	\hX{וַיֹּאמֶר הָמָן אַף לֹא־הֵבִיאָה אֶסְתֵּר הַמַּלְכָּה עִם־הַמֶּלֶךְ אֶל־הַמִּשְׁתֶּה אֲשֶׁר־עָשָׂתָה כִּי אִם־אוֹתִי וְגַם־לְמָחָר אֲנִי קָרוּא־לָהּ עִם־הַמֶּלֶךְ׃}
}
{
	\eX{
		Haman said moreover, Yea, Esther the queen did let no man come
		in with the king unto the banquet that she had prepared but
		myself; and to morrow am I invited unto her also with the king.
	}
}
{
}

\Verse{13}
{
	\hX{וְכל־זֶה אֵינֶנּוּ שֹׁוֶה לִי בְּכל־עֵת אֲשֶׁר אֲנִי רֹאֶה אֶת־מרְדֳּכַי הַיְּהוּדִי יוֹשֵׁב בְּשַׁעַר הַמֶּלֶךְ׃}
}
{
	\eX{
		Yet all this availeth me nothing, so long as I see Mordecai the
		Jew sitting at the king’s gate.
	}
}
{
}

\Verse{14}
{
	\hX{
		וַתֹּאמֶר לוֹ זֶרֶשׁ אִשְׁתּוֹ וְכל־אֹהֲבָיו יַעֲשׂוּ־עֵץ גָּבֹהַּ חֲמִשִּׁים אַמָּה וּבַבֹּקֶר אֱמֹר לַמֶּלֶךְ וְיִתְלוּ אֶת־מרְדֳּכַי עָלָיו וּבֹא־עִם־הַמֶּלֶךְ אֶל־הַמִּשְׁתֶּה
		שָׂמֵחַ וַיִּיטַב הַדָּבָר לִפְנֵי הָמָן וַיַּעַשׂ הָעֵץ׃
	}
}
{
	\eX{
		Then said Zeresh his wife and all his friends unto him, Let a
		gallows be made of fifty cubits high, and to morrow speak thou
		unto the king that Mordecai may be hanged thereon: then go thou
		in merrily with the king unto the banquet. And the thing pleased
		Haman; and he caused the gallows to be made.
	}
}
{
}
