\Chapter{6}

\Verse{1}
{
	\hX{בַּלַּיְלָה הַהוּא נָדְדָה שְׁנַת הַמֶּלֶךְ וַיֹּאמֶר לְהָבִיא אֶת־סֵפֶר הַזִּכְרֹנוֹת דִּבְרֵי הַיָּמִים וַיִּהְיוּ נִקְרָאִים לִפְנֵי הַמֶּלֶךְ׃}
}
{
	\eX{
		On that night could not the king sleep, and he commanded to
		bring the book of records of the chronicles; and they were read
		before the king.
	}
}
{
}

\Verse{2}
{
	\hX{וַיִּמָּצֵא כָתוּב אֲשֶׁר הִגִּיד מרְדֳּכַי עַל־בִּגְתָנָא וָתֶרֶשׁ שְׁנֵי סָרִיסֵי הַמֶּלֶךְ מִשֹּׁמְרֵי הַסַּף אֲשֶׁר בִּקְשׁוּ לִשְׁלֹחַ יָד בַּמֶּלֶךְ אֲחַשְׁוֵרוֹשׁ׃}
}
{
	\eX{
		And it was found written, that Mordecai had told of Bigthana and
		Teresh, two of the king’s chamberlains, the keepers of the door,
		who sought to lay hand on the king Ahasuerus.
	}
}
{
}

\Verse{3}
{
	\hX{וַיֹּאמֶר הַמֶּלֶךְ מַה־נַּעֲשָׂה יְקָר וּגְדוּלָּה לְמרְדֳּכַי עַל־זֶה וַיֹּאמְרוּ נַעֲרֵי הַמֶּלֶךְ מְשָׁרְתָיו לֹא־נַעֲשָׂה עִמּוֹ דָּבָר׃}
}
{
	\eX{
		And the king said, What honour and dignity hath been done to
		Mordecai for this? Then said the king’s servants that ministered
		unto him, There is nothing done for him.
	}
}
{
}

\Verse{4}
{
	\hX{וַיֹּאמֶר הַמֶּלֶךְ מִי בֶחָצֵר וְהָמָן בָּא לַחֲצַר בֵּית־הַמֶּלֶךְ הַחִיצוֹנָה לֵאמֹר לַמֶּלֶךְ לִתְלוֹת אֶת־מרְדֳּכַי עַל־הָעֵץ אֲשֶׁר־הֵכִין לוֹ׃}
}
{
	\eX{
		And the king said, Who is in the court? Now Haman was come into
		the outward court of the king’s house, to speak unto the king to
		hang Mordecai on the gallows that he had prepared for him.
	}
}
{
}

\Verse{5}
{
	\hX{וַיֹּאמְרוּ נַעֲרֵי הַמֶּלֶךְ אֵלָיו הִנֵּה הָמָן עֹמֵד בֶּחָצֵר וַיֹּאמֶר הַמֶּלֶךְ יָבוֹא׃}
}
{
	\eX{
		And the king’s servants said unto him, Behold, Haman standeth in
		the court. And the king said, Let him come in.
	}
}
{
}

\Verse{6}
{
	\hX{
		וַיָּבוֹא הָמָן וַיֹּאמֶר לוֹ הַמֶּלֶךְ מַה־לַּעֲשׂוֹת בָּאִישׁ אֲשֶׁר הַמֶּלֶךְ חָפֵץ בִּיקָרוֹ וַיֹּאמֶר הָמָן בְּלִבּוֹ לְמִי יַחְפֹּץ הַמֶּלֶךְ לַעֲשׂוֹת יְקָר יוֹתֵר
		מִמֶּנִּי׃
	}
}
{
	\eX{
		So Haman came in. And the king said unto him, What shall be done
		unto the man whom the king delighteth to honour? Now Haman
		thought in his heart, To whom would the king delight to do
		honour more than to myself?
	}
}
{
}

\Verse{7}
{
	\hX{וַיֹּאמֶר הָמָן אֶל־הַמֶּלֶךְ אִישׁ אֲשֶׁר הַמֶּלֶךְ חָפֵץ בִּיקָרוֹ׃}
}
{
	\eX{
		And Haman answered the king, For the man whom the king
		delighteth to honour,
	}
}
{
}

\Verse{8}
{
	\hX{יָבִיאוּ לְבוּשׁ מַלְכוּת אֲשֶׁר לָבַשׁ־בּוֹ הַמֶּלֶךְ וְסוּס אֲשֶׁר רָכַב עָלָיו הַמֶּלֶךְ וַאֲשֶׁר נִתַּן כֶּתֶר מַלְכוּת בְּרֹאשׁוֹ׃}
}
{
	\eX{
		Let the royal apparel be brought which the king useth to wear,
		and the horse that the king rideth upon, and the crown royal
		which is set upon his head:
	}
}
{
}

\Verse{9}
{
	\hX{
		וְנָתוֹן הַלְּבוּשׁ וְהַסּוּס עַל־יַד־אִישׁ מִשָּׂרֵי הַמֶּלֶךְ הַפַּרְתְּמִים וְהִלְבִּישׁוּ אֶת־הָאִישׁ אֲשֶׁר הַמֶּלֶךְ חָפֵץ בִּיקָרוֹ וְהִרְכִּיבֻהוּ עַל־הַסּוּס בִּרְחוֹב
		הָעִיר וְקָרְאוּ לְפָנָיו כָּכָה יֵעָשֶׂה לָאִישׁ אֲשֶׁר הַמֶּלֶךְ חָפֵץ בִּיקָרוֹ׃
	}
}
{
	\eX{
		And let this apparel and horse be delivered to the hand of one
		of the king’s most noble princes, that they may array the man
		withal whom the king delighteth to honour, and bring him on
		horseback through the street of the city, and proclaim before
		him, Thus shall it be done to the man whom the king delighteth
		to honour.
	}
}
{
}

\Verse{10}
{
	\hX{
		וַיֹּאמֶר הַמֶּלֶךְ לְהָמָן מַהֵר קַח אֶת־הַלְּבוּשׁ וְאֶת־הַסּוּס כַּאֲשֶׁר דִּבַּרְתָּ וַעֲשֵׂה־כֵן לְמרְדֳּכַי הַיְּהוּדִי הַיּוֹשֵׁב בְּשַׁעַר הַמֶּלֶךְ אַל־תַּפֵּל דָּבָר
		מִכֹּל אֲשֶׁר דִּבַּרְתָּ׃
	}
}
{
	\eX{
		Then the king said to Haman, Make haste, and take the apparel
		and the horse, as thou hast said, and do even so to Mordecai the
		Jew, that sitteth at the king’s gate: let nothing fail of all
		that thou hast spoken.
	}
}
{
}

\Verse{11}
{
	\hX{
		וַיִּקַּח הָמָן אֶת־הַלְּבוּשׁ וְאֶת־הַסּוּס וַיַּלְבֵּשׁ אֶת־מרְדֳּכָי וַיַּרְכִּיבֵהוּ בִּרְחוֹב הָעִיר וַיִּקְרָא לְפָנָיו כָּכָה יֵעָשֶׂה לָאִישׁ אֲשֶׁר הַמֶּלֶךְ חָפֵץ
		בִּיקָרוֹ׃
	}
}
{
	\eX{
		Then took Haman the apparel and the horse, and arrayed Mordecai,
		and brought him on horseback through the street of the city, and
		proclaimed before him, Thus shall it be done unto the man whom
		the king delighteth to honour.
	}
}
{
}

\Verse{12}
{
	\hX{וַיָּשׁב מרְדֳּכַי אֶל־שַׁעַר הַמֶּלֶךְ וְהָמָן נִדְחַף אֶל־בֵּיתוֹ אָבֵל וַחֲפוּי רֹאשׁ׃}
}
{
	\eX{
		And Mordecai came again to the king’s gate. But Haman hasted to
		his house mourning, and having his head covered.
	}
}
{
}

\Verse{13}
{
	\hX{
		וַיְסַפֵּר הָמָן לְזֶרֶשׁ אִשְׁתּוֹ וּלְכל־אֹהֲבָיו אֵת כּל־אֲשֶׁר קָרָהוּ וַיֹּאמְרוּ לוֹ חֲכָמָיו וְזֶרֶשׁ אִשְׁתּוֹ אִם מִזֶּרַע הַיְּהוּדִים מרְדֳּכַי אֲשֶׁר הַחִלּוֹתָ
		לִנְפֹּל לְפָנָיו לֹא־תוּכַל לוֹ כִּי־נָפוֹל תִּפּוֹל לְפָנָיו׃
	}
}
{
	\eX{
		And Haman told Zeresh his wife and all his friends every thing
		that had befallen him. Then said his wise men and Zeresh his
		wife unto him, If Mordecai be of the seed of the Jews, before
		whom thou hast begun to fall, thou shalt not prevail against
		him, but shalt surely fall before him.
	}
}
{
}

\Verse{14}
{
	\hX{עוֹדָם מְדַבְּרִים עִמּוֹ וְסָרִיסֵי הַמֶּלֶךְ הִגִּיעוּ וַיַּבְהִלוּ לְהָבִיא אֶת־הָמָן אֶל־הַמִּשְׁתֶּה אֲשֶׁר־עָשְׂתָה אֶסְתֵּר׃}
}
{
	\eX{
		And while they were yet talking with him, came the king’s
		chamberlains, and hasted to bring Haman unto the banquet that
		Esther had prepared.
	}
}
{
}
