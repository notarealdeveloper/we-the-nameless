\Chapter{20}

\Verse{1}
{
	\hDtn{כִּי תֵצֵא לַמִּלְחָמָה עַל אֹיְבֶךָ וְרָאִיתָ סוּס וָרֶכֶב עַם רַב מִמְּךָ לֹא תִירָא מֵהֶם כִּי יְהֹוָה אֱלֹהֶיךָ עִמָּךְ הַמַּעַלְךָ מֵאֶרֶץ מִצְרָיִם׃}
}
{
	\eDtn{
		“When you’ll go out to war against your enemies, and
		you’ll see horses and chariots, a people more numerous
		than you, you shall not fear them, because YHWH, your {\God},
		is with you, who brought you up from the land of Egypt.
	}
}
{
}

\Verse{2}
{
	\hDtn{וְהָיָה כְּקָרבְכֶם אֶל הַמִּלְחָמָה וְנִגַּשׁ הַכֹּהֵן וְדִבֶּר אֶל הָעָם׃}
}
{
	\eDtn{
		And it will be, when you approach the war, that the priest
		shall go over and speak to the people.
	}
}
{
}

\Verse{3}
{
	\hDtn{וְאָמַר אֲלֵהֶם שְׁמַע יִשְׂרָאֵל אַתֶּם קְרֵבִים הַיּוֹם לַמִּלְחָמָה עַל אֹיְבֵיכֶם אַל יֵרַךְ לְבַבְכֶם אַל תִּירְאוּ וְאַל תַּחְפְּזוּ וְאַל תַּעַרְצוּ מִפְּנֵיהֶם׃}
}
{
	\eDtn{
		And he shall say to them, ‘Listen, Israel, you’re
		approaching war against your enemies today. Let your heart
		not be weak. Don’t be afraid and don’t panic and don’t be
		scared in front of them,
	}
}
{
}

\Verse{4}
{
	\hDtn{כִּי יְהֹוָה אֱלֹהֵיכֶם הַהֹלֵךְ עִמָּכֶם לְהִלָּחֵם לָכֶם עִם אֹיְבֵיכֶם לְהוֹשִׁיעַ אֶתְכֶם׃}
}
{
	\eDtn{
		because YHWH, your {\God}, is the one going with you to fight
		for you with your enemies, to save you.’
	}
}
{
}

\Verse{5}
{
	\hDtn{וְדִבְּרוּ הַשֹּׁטְרִים אֶל הָעָם לֵאמֹר מִי הָאִישׁ אֲשֶׁר בָּנָה בַיִת חָדָשׁ וְלֹא חֲנָכוֹ יֵלֵךְ וְיָשֹׁב לְבֵיתוֹ פֶּן יָמוּת בַּמִּלְחָמָה וְאִישׁ אַחֵר יַחְנְכֶנּוּ׃}
}
{
	\eDtn{
		“And the officers shall speak to the people, saying, ‘Who
		is a man who has built a new house and has not dedicated
		it? Let him go, and let him go back to his house, in case
		he would die in the war and another man would dedicate it.
	}
}
{
}

\Verse{6}
{
	\hDtn{וּמִי הָאִישׁ אֲשֶׁר נָטַע כֶּרֶם וְלֹא חִלְּלוֹ יֵלֵךְ וְיָשֹׁב לְבֵיתוֹ פֶּן יָמוּת בַּמִּלְחָמָה וְאִישׁ אַחֵר יְחַלְּלֶנּוּ׃}
}
{
	\eDtn{
		And who is a man who has planted a vineyard and has not
		desanctified it? Let him go, and let him go back to his
		house, in case he would die in the war and another man
		would desanctify it.
	}
}
{
%	\footnote{
%		desanctified. This may relate to a law such as that in Lev 19:23–25,
%		whereby a newly planted tree goes through a period during which its
%		fruit may not be eaten, followed by a period of being holy (“all of its
%		fruit shall be holy”), and then a third period in which its period of
%		sanctification ends and one may eat it. In the present context, then, it
%		would refer to a man who has planted a vineyard but has not yet eaten
%		any of its fruit.
%	}
}

\Verse{7}
{
	\hDtn{וּמִי הָאִישׁ אֲשֶׁר אֵרַשׂ אִשָּׁה וְלֹא לְקָחָהּ יֵלֵךְ וְיָשֹׁב לְבֵיתוֹ פֶּן יָמוּת בַּמִּלְחָמָה וְאִישׁ אַחֵר יִקָּחֶנָּה׃}
}
{
	\eDtn{
		And who is a man who has betrothed a woman and has not
		taken her? Let him go, and let him go back to his house,
		in case he would die in the war and another man would take
		her.’
	}
}
{
}

\Verse{8}
{
	\hDtn{וְיָסְפוּ הַשֹּׁטְרִים לְדַבֵּר אֶל הָעָם וְאָמְרוּ מִי הָאִישׁ הַיָּרֵא וְרַךְ הַלֵּבָב יֵלֵךְ וְיָשֹׁב לְבֵיתוֹ וְלֹא יִמַּס אֶת לְבַב אֶחָיו כִּלְבָבוֹ׃}
}
{
	\eDtn{
		And the officers shall continue to speak to the people and
		shall say, ‘Who is a man who is afraid and weakhearted?
		Let him go, and go back to his house, so he won’t melt his
		brothers’ heart like his heart.’
	}
}
{
}

\Verse{9}
{
	\hDtn{וְהָיָה כְּכַלֹּת הַשֹּׁטְרִים לְדַבֵּר אֶל הָעָם וּפָקְדוּ שָׂרֵי צְבָאוֹת בְּרֹאשׁ הָעָם׃}
}
{
	\eDtn{
		And it will be, when the officers finish speaking to the
		people, that they shall appoint officers of the armies at
		the head of the people.
	}
}
{
}

\Verse{10}
{
	\hDtn{כִּי תִקְרַב אֶל עִיר לְהִלָּחֵם עָלֶיהָ וְקָרָאתָ אֵלֶיהָ לְשָׁלוֹם׃}
}
{
	\eDtn{
		“When you’ll approach a city to fight against it, then you
		shall call to it for peace.
	}
}
{
}

\Verse{11}
{
	\hDtn{וְהָיָה אִם שָׁלוֹם תַּעַנְךָ וּפָתְחָה לָךְ וְהָיָה כּל הָעָם הַנִּמְצָא בָהּ יִהְיוּ לְךָ לָמַס וַעֲבָדוּךָ׃}
}
{
	\eDtn{
		And it will be, if it will answer you with peace and open
		up to you, then it will be that all the people who are
		found in it shall become yours for a work-company and
		shall serve you.
	}
}
{
}

\Verse{12}
{
	\hDtn{וְאִם לֹא תַשְׁלִים עִמָּךְ וְעָשְׂתָה עִמְּךָ מִלְחָמָה וְצַרְתָּ עָלֶיהָ׃}
}
{
	\eDtn{
		And if it will not make peace with you, but it will make
		war with you, then you shall besiege it.
	}
}
{
}

\Verse{13}
{
	\hDtn{וּנְתָנָהּ יְהֹוָה אֱלֹהֶיךָ בְּיָדֶךָ וְהִכִּיתָ אֶת כּל זְכוּרָהּ לְפִי חָרֶב׃}
}
{
	\eDtn{
		And YHWH, your {\God}, will put it in your hand, and you
		shall strike all its males by the sword.
	}
}
{
}

\Verse{14}
{
	\hDtn{רַק הַנָּשִׁים וְהַטַּף וְהַבְּהֵמָה וְכֹל אֲשֶׁר יִהְיֶה בָעִיר כּל שְׁלָלָהּ תָּבֹז לָךְ וְאָכַלְתָּ אֶת שְׁלַל אֹיְבֶיךָ אֲשֶׁר נָתַן יְהֹוָה אֱלֹהֶיךָ לָךְ׃}
}
{
	\eDtn{
		Only, you shall take as spoil the women and the infants
		and the animals and everything that will be in the city,
		all its spoil, and you shall eat your enemies’ spoil that
		YHWH, your {\God}, has given you.
	}
}
{
}

\Verse{15}
{
	\hDtn{כֵּן תַּעֲשֶׂה לְכל הֶעָרִים הָרְחֹקֹת מִמְּךָ מְאֹד אֲשֶׁר לֹא מֵעָרֵי הַגּוֹיִם הָאֵלֶּה הֵנָּה׃}
}
{
	\eDtn{
		That is what you shall do to all the cities that are very
		distant from you, those that are not from these nations’
		cities.
	}
}
{
}

\Verse{16}
{
	\hDtn{רַק מֵעָרֵי הָעַמִּים הָאֵלֶּה אֲשֶׁר יְהֹוָה אֱלֹהֶיךָ נֹתֵן לְךָ נַחֲלָה לֹא תְחַיֶּה כּל נְשָׁמָה׃}
}
{
	\eDtn{
		Only from these peoples’ cities that YHWH, your {\God}, is
		giving you as a legacy shall you not let any soul live.
	}
}
{
}

\Verse{17}
{
	\hDtn{כִּי הַחֲרֵם תַּחֲרִימֵם הַחִתִּי וְהָאֱמֹרִי הַכְּנַעֲנִי וְהַפְּרִזִּי הַחִוִּי וְהַיְבוּסִי כַּאֲשֶׁר צִוְּךָ יְהֹוָה אֱלֹהֶיךָ׃}
}
{
	\eDtn{
		But you shall completely destroy them—the Hittite and the
		Amorite, the Canaanite and the Perizzite, the Hivite and
		the Jebusite—as YHWH, your {\God}, has commanded you,
	}
}
{
}

\Verse{18}
{
	\hDtn{לְמַעַן אֲשֶׁר לֹא יְלַמְּדוּ אֶתְכֶם לַעֲשׂוֹת כְּכֹל תּוֹעֲבֹתָם אֲשֶׁר עָשׂוּ לֵאלֹהֵיהֶם וַחֲטָאתֶם לַיהֹוָה אֱלֹהֵיכֶם׃}
}
{
	\eDtn{
		so they won’t teach you to do things like all their
		offensive things that they did for their gods, and you’ll
		sin to YHWH, your {\God}.
	}
}
{
}

\Verse{19}
{
	\hDtn{כִּי תָצוּר אֶל עִיר יָמִים רַבִּים לְהִלָּחֵם עָלֶיהָ לְתפְשָׂהּ לֹא תַשְׁחִית אֶת עֵצָהּ לִנְדֹּחַ עָלָיו גַּרְזֶן כִּי מִמֶּנּוּ תֹאכֵל וְאֹתוֹ לֹא תִכְרֹת כִּי הָאָדָם עֵץ הַשָּׂדֶה לָבֹא מִפָּנֶיךָ בַּמָּצוֹר׃}
}
{
	\eDtn{
		“When you’ll besiege a city many days, fighting against it
		to capture it, you shall not destroy a tree of it, moving
		an axe at it, because you’ll eat from it, so you shall not
		cut it down; because is a tree of the field a human, to go
		from in front of you in a siege?!
	}
}
{
}

\Verse{20}
{
	\hDtn{רַק עֵץ אֲשֶׁר תֵּדַע כִּי לֹא עֵץ מַאֲכָל הוּא אֹתוֹ תַשְׁחִית וְכָרָתָּ וּבָנִיתָ מָצוֹר עַל הָעִיר אֲשֶׁר הִוא עֹשָׂה עִמְּךָ מִלְחָמָה עַד רִדְתָּהּ׃}
}
{
	\eDtn{
		Only a tree that you’ll know that it isn’t a tree for
		eating: that one you may destroy and cut down so you may
		build a siege-work against the city that is making war
		with you until its fall.
	}
}
{
}
