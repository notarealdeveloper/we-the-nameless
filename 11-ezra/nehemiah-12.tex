	\hX{וּמַעֲשֵׂיָה וּשְׁמַעְיָה וְאֶלְעָזָר וְעֻזִּי וִיהוֹחָנָן וּמַלְכִּיָּה וְעֵילָם וָעָזֶר וַיַּשְׁמִיעוּ הַמְשֹׁרְרִים וְיִזְרַחְיָה הַפָּקִיד׃}
}
{
	\eX{
		And Maaseiah, and Shemaiah, and Eleazar, and Uzzi, and
		Jehohanan, and Malchijah, and Elam, and Ezer. And the singers
		sang loud, with Jezrahiah their overseer.
	}
}
{
}

\Verse{43}
{
	\hX{
		וַיִּזְבְּחוּ בַיּוֹם־הַהוּא זְבָחִים גְּדוֹלִים וַיִּשְׂמָחוּ כִּי הָאֱלֹהִים שִׂמְּחָם שִׂמְחָה גְדוֹלָה וְגַם הַנָּשִׁים וְהַיְלָדִים שָׂמֵחוּ וַתִּשָּׁמַע שִׂמְחַת
		יְרוּשָׁלַ͏ִם מֵרָחוֹק׃
	}
}
{
	\eX{
		Also that day they offered great sacrifices, and rejoiced: for
		God had made them rejoice with great joy: the wives also and the
		children rejoiced: so that the joy of Jerusalem was heard even
		afar off.
	}
}
{
}

\Verse{44}
{
	\hX{
		וַיִּפָּקְדוּ בַיּוֹם הַהוּא אֲנָשִׁים עַל־הַנְּשָׁכוֹת לָאוֹצָרוֹת לַתְּרוּמוֹת לָרֵאשִׁית וְלַמַּעַשְׂרוֹת לִכְנוֹס בָּהֶם לִשְׂדֵי הֶעָרִים מְנָאוֹת הַתּוֹרָה לַכֹּהֲנִים
		וְלַלְוִיִּם כִּי שִׂמְחַת יְהוּדָה עַל־הַכֹּהֲנִים וְעַל־הַלְוִיִּם הָעֹמְדִים׃
	}
}
{
	\eX{
		And at that time were some appointed over the chambers for the
		treasures, for the offerings, for the firstfruits, and for the
		tithes, to gather into them out of the fields of the cities the
		portions of the law for the priests and Levites: for Judah
		rejoiced for the priests and for the Levites that waited.
	}
}
{
}

\Verse{45}
{
	\hX{וַיִּשְׁמְרוּ מִשְׁמֶרֶת אֱלֹהֵיהֶם וּמִשְׁמֶרֶת הַטּהֳרָה וְהַמְשֹׁרְרִים וְהַשֹּׁעֲרִים כְּמִצְוַת דָּוִיד שְׁלֹמֹה בְנוֹ׃}
}
{
	\eX{
		And both the singers and the gatekeepers kept the ward of their
		God, and the ward of the purification, according to the
		commandment of David, and of Solomon his son.
	}
}
{
}

\Verse{46}
{
	\hX{כִּי־בִימֵי דָוִיד וְאָסָף מִקֶּדֶם (ראש) [רָאשֵׁי] הַמְשֹׁרְרִים וְשִׁיר־תְּהִלָּה וְהֹדוֹת לֵאלֹהִים׃}
}
{
	\eX{
		For in the days of David and Asaph of old there were chief of
		the singers, and songs of praise and thanksgiving to God.
	}
}
{
}

\Verse{47}
{
	\hX{
		וְכל־יִשְׂרָאֵל בִּימֵי זְרֻבָּבֶל וּבִימֵי נְחֶמְיָה נֹתְנִים מְנָיוֹת הַמְשֹׁרְרִים וְהַשֹּׁעֲרִים דְּבַר־יוֹם בְּיוֹמוֹ וּמַקְדִּשִׁים לַלְוִיִּם וְהַלְוִיִּם מַקְדִּשִׁים
		לִבְנֵי אַהֲרֹן׃
	}
}
{
	\eX{
		And all Israel in the days of Zerubbabel, and in the days of
		Nehemiah, gave the portions of the singers and the gatekeepers,
		every day his portion: and they made holy holy things to the
		Levites; and the Levites made holy them to the children of
		Aaron.
	}
}
{
}
