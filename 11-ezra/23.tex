		should no burden be brought in on the sabbath day.

{

\Verse{29}
{
	\hX{זכְרָה לָהֶם אֱלֹהָי עַל גּאֳלֵי הַכְּהֻנָּה וּבְרִית הַכְּהֻנָּה וְהַלְוִיִּם׃}
}
{
	\eX{
		Remember them, O my God, because they have made impure the
		priesthood, and the covenant of the priesthood, and of the
		Levites.
	}
}
{
}

\Verse{30}
{
	\hX{וְטִהַרְתִּים מִכּל־נֵכָרוָאַעֲמִידָה מִשְׁמָרוֹת לַכֹּהֲנִים וְלַלְוִיִּם אִישׁ בִּמְלַאכְתּוֹ׃}
}
{
	\eX{
		Thus I cleansed them from all foreigners, and appointed the
		wards of the priests and the Levites, everyone in his business;
	}
}
{
}

\Verse{31}
{
	\hX{וּלְקֻרְבַּן הָעֵצִים בְּעִתִּים מְזֻמָּנוֹת וְלַבִּכּוּרִים זכְרָה־לִּי אֱלֹהַי לְטוֹבָה׃}
}
{
	\eX{
		and for the wood offering at appointed times, and for the first
		fruits. Remember me, my God, for good.
	}
}
{
%	\footnote{
%		Footnote 13:31. Nehemiah's last words are not a triumph report but a plea:
%		Remember me. After all the lists, walls, reforms, blows, and locks, the book ends
%		with a man asking God to keep the account.
%	}
}
