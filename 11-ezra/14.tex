\Chapter{14}

\Verse{1}
{
	\hX{
		וַיְהִי כַאֲשֶׁר שָׁמַע סַנְבַלַּט וְטוֹבִיָּה וְהָעַרְבִים וְהָעַמֹּנִים וְהָאַשְׁדּוֹדִים כִּי־עָלְתָה אֲרוּכָה לְחֹמוֹת יְרוּשָׁלַ͏ִם כִּי־הֵחֵלּוּ הַפְּרֻצִים לְהִסָּתֵם
		וַיִּחַר לָהֶם מְאֹד׃
	}
}
{
	\eX{
		But it was, that when Sanballat, and Tobiah, and the Arabians,
		and the Ammonites, and the Ashdodites, heard that the walls of
		Jerusalem were made up, and that the breaches began to be
		stopped, then they were very angry,
	}
}
{
}

\Verse{2}
{
	\hX{וַיִּקְשְׁרוּ כֻלָּם יַחְדָּו לָבוֹא לְהִלָּחֵם בִּירוּשָׁלָ͏ִם וְלַעֲשׂוֹת לוֹ תּוֹעָה׃}
}
{
	\eX{
		And conspired all of them together to come and to fight against
		Jerusalem, and to hinder it.
	}
}
{
}

\Verse{3}
{
	\hX{וַנִּתְפַּלֵּל אֶל־אֱלֹהֵינוּ וַנַּעֲמִיד מִשְׁמָר עֲלֵיהֶם יוֹמָם וָלַיְלָה מִפְּנֵיהֶם׃}
}
{
	\eX{
		Nevertheless we made our prayer to our God, and set a watch
		against them day and night, because of them.
	}
}
{
}

\Verse{4}
{
	\hX{וַיֹּאמֶר יְהוּדָה כָּשַׁל כֹּחַ הַסַּבָּל וְהֶעָפָר הַרְבֵּה וַאֲנַחְנוּ לֹא נוּכַל לִבְנוֹת בַּחוֹמָה׃}
}
{
	\eX{
		And Judah said, The strength of the bearers of burdens is
		decayed, and there is much rubbish; so that we aren't able to
		build the wall.
	}
}
{
}

\Verse{5}
{
	\hX{וַיֹּאמְרוּ צָרֵינוּ לֹא יֵדְעוּ וְלֹא יִרְאוּ עַד אֲשֶׁר־נָבוֹא אֶל־תּוֹכָם וַהֲרַגְנוּם וְהִשְׁבַּתְנוּ אֶת־הַמְּלָאכָה׃}
}
{
	\eX{
		And our foes said, They shall not know, nor see, until we come
		in the midst among them, and kill them, and cause the work to
		cease.
	}
}
{
}

\Verse{6}
{
	\hX{וַיְהִי כַּאֲשֶׁר־בָּאוּ הַיְּהוּדִים הַיֹּשְׁבִים אֶצְלָם וַיֹּאמְרוּ לָנוּ עֶשֶׂר פְּעָמִים מִכּל־הַמְּקֹמוֹת אֲשֶׁר־תָּשׁוּבוּ עָלֵינוּ׃}
}
{
	\eX{
		And it was, that when the Jews that dwelt by them came, they
		said to us ten times, From all places whence you shall return to
		us they will be upon us.
	}
}
{
}

\Verse{7}
{
	\hX{וָאַעֲמִיד מִתַּחְתְּיוֹת לַמָּקוֹם מֵאַחֲרֵי לַחוֹמָה (בצחחיים) [בַּצְּחִיחִים] וָאַעֲמִיד אֶת־הָעָם לְמִשְׁפָּחוֹת עִם־חַרְבֹתֵיהֶם רמְחֵיהֶם וְקַשְּׁתֹתֵיהֶם׃}
}
{
	\eX{
		And I set in the lower places behind the wall, and on the higher
		places, I even set the people after their families with their
		swords, their spears, and their bows.
	}
}
{
}

\Verse{8}
{
	\hX{
		וָאֵרֶא וָאָקוּם וָאֹמַר אֶל־הַחֹרִים וְאֶל־הַסְּגָנִים וְאֶל־יֶתֶר הָעָם אַל־תִּירְאוּ מִפְּנֵיהֶם אֶת־אֲדֹנָי הַגָּדוֹל וְהַנּוֹרָא זְכֹרוּ וְהִלָּחֲמוּ עַל־אֲחֵיכֶם בְּנֵיכֶם
		וּבְנֹתֵיכֶם נְשֵׁיכֶם וּבָתֵּיכֶם׃
	}
}
{
	\eX{
		And I looked, and rose up, and said to the nobles, and to the
		rulers, and to the rest of the people, Don't be afraid of them:
		remember YHWH, that is great and fearsome, and fight for your
		brothers, your sons, and your daughters, your wives, and your
		houses.
	}
}
{
}

\Verse{9}
{
	\hX{וַיְהִי כַּאֲשֶׁר־שָׁמְעוּ אוֹיְבֵינוּ כִּי־נוֹדַע לָנוּ וַיָּפֶר הָאֱלֹהִים אֶת־עֲצָתָם (ונשוב) [וַנָּשׁב] כֻּלָּנוּ אֶל־הַחוֹמָה אִישׁ אֶל־מְלַאכְתּוֹ׃}
}
{
	\eX{
		And it was, when our enemies heard that it was known to us, and
		God had brought their counsel to nothing, that we returned all
		of us to the wall, everyone to his work.
	}
}
{
}

\Verse{10}
{
	\hX{
		וַיְהִי מִן־הַיּוֹם הַהוּא חֲצִי נְעָרַי עֹשִׂים בַּמְּלָאכָה וְחֶצְיָם מַחֲזִיקִים וְהָרְמָחִים הַמָּגִנִּים וְהַקְּשָׁתוֹת וְהַשִּׁרְיֹנִים וְהַשָּׂרִים אַחֲרֵי כּל־בֵּית
		יְהוּדָה׃
	}
}
{
	\eX{
		And it was from that time forth, that half of my servants worked
		at the work, and the other half of them held both the spears,
		the shields, and the bows, and the coats of mail; and the rulers
		were behind all the house of Judah.
	}
}
{
}

\Verse{11}
{
	\hX{הַבּוֹנִים בַּחוֹמָה וְהַנֹּשְׂאִים בַּסֶּבֶל עֹמְשִׂים בְּאַחַת יָדוֹ עֹשֶׂה בַמְּלָאכָה וְאַחַת מַחֲזֶקֶת הַשָּׁלַח׃}
}
{
	\eX{
		They that built on the wall, and they that bare burdens, with
		those that laded, everyone with one of his hands done in the
		work, and with the other hand held a weapon.
	}
}
{
%	\footnote{
%		Footnote 4:11. The builders work with one hand and hold a weapon with one hand. It
%		is one of the Bible's plainest pictures of life after exile: masonry with a sword.
%	}
}

\Verse{12}
{
	\hX{וְהַבּוֹנִים אִישׁ חַרְבּוֹ אֲסוּרִים עַל־מתְנָיו וּבוֹנִים וְהַתּוֹקֵעַ בַּשּׁוֹפָר אֶצְלִי׃}
}
{
	\eX{
		For the builders, everyone had his sword girded by his side, and
		so built. And he that sounded the trumpet was by me.
	}
}
{
}

\Verse{13}
{
	\hX{וָאֹמַר אֶל־הַחֹרִים וְאֶל־הַסְּגָנִים וְאֶל־יֶתֶר הָעָם הַמְּלָאכָה הַרְבֵּה וּרְחָבָה וַאֲנַחְנוּ נִפְרָדִים עַל־הַחוֹמָה רְחוֹקִים אִישׁ מֵאָחִיו׃}
}
{
	\eX{
		And I said to the nobles, and to the rulers, and to the rest of
		the people, The work is great and large, and we're separated
		upon the wall, one far from another.
	}
}
{
}

\Verse{14}
{
	\hX{בִּמְקוֹם אֲשֶׁר תִּשְׁמְעוּ אֶת־קוֹל הַשּׁוֹפָר שָׁמָּה תִּקָּבְצוּ אֵלֵינוּ אֱלֹהֵינוּ יִלָּחֶם לָנוּ׃}
}
{
	\eX{
		In what place therefore you hear the sound of the trumpet,
		resort you there to us: our God shall fight for us.
	}
}
{
}

\Verse{15}
{
	\hX{וַאֲנַחְנוּ עֹשִׂים בַּמְּלָאכָה וְחֶצְיָם מַחֲזִיקִים בָּרְמָחִים מֵעֲלוֹת הַשַּׁחַר עַד צֵאת הַכּוֹכָבִים׃}
}
{
	\eX{
		So we laboured in the work: and half of them held the spears
		from the rising of the morning until the stars appeared.
	}
}
{
}

\Verse{16}
{
	\hX{גַּם בָּעֵת הַהִיא אָמַרְתִּי לָעָם אִישׁ וְנַעֲרוֹ יָלִינוּ בְּתוֹךְ יְרוּשָׁלָ͏ִם וְהָיוּ־לָנוּ הַלַּיְלָה מִשְׁמָר וְהַיּוֹם מְלָאכָה׃}
}
{
	\eX{
		Likewise at the same time said I to the people, Let everyone
		with his servant lodge within Jerusalem, that in the night they
		may be a guard to us, and work on the day.
	}
}
{
}

\Verse{17}
{
	\hX{וְאֵין אֲנִי וְאַחַי וּנְעָרַי וְאַנְשֵׁי הַמִּשְׁמָר אֲשֶׁר אַחֲרַי אֵין־אֲנַחְנוּ פֹשְׁטִים בְּגָדֵינוּ אִישׁ שִׁלְחוֹ הַמָּיִם׃}
}
{
	\eX{
		So nor I, nor my brothers, nor my servants, nor the men of the
		guard that followed me, none of us put off our clothes, except
		that everyone put them off for washing.
	}
}
{
}
