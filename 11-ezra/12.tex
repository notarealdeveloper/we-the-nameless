\Chapter{12}

\Verse{1}
{
	\hX{וַיְהִי בְּחֹדֶשׁ נִיסָן שְׁנַת עֶשְׂרִים לְאַרְתַּחְשַׁסְתְּא הַמֶּלֶךְ יַיִן לְפָנָיו וָאֶשָּׂא אֶת־הַיַּיִן וָאֶתְּנָה לַמֶּלֶךְ וְלֹא־הָיִיתִי רַע לְפָנָיו׃}
}
{
	\eX{
		And it was in the month Nisan, in year twenty of Artaxerxes the
		king: wine was in front of him, and I lifted the wine and gave
		it to the king. And I had not been bad in front of him.
	}
}
{
}

\Verse{2}
{
	\hX{וַיֹּאמֶר לִי הַמֶּלֶךְ מַדּוּעַ פָּנֶיךָ רָעִים וְאַתָּה אֵינְךָ חוֹלֶה אֵין זֶה כִּי־אִם רֹעַ לֵב וָאִירָא הַרְבֵּה מְאֹד׃}
}
{
	\eX{
		Therefore the king said to me, Why is your face sad, seeing you
		aren't sick? this is nothing else but sorrow of heart. And I was
		very badly afraid,
	}
}
{
}

\Verse{3}
{
	\hX{וָאֹמַר לַמֶּלֶךְ הַמֶּלֶךְ לְעוֹלָם יִחְיֶה מַדּוּעַ לֹא־יֵרְעוּ פָנַי אֲשֶׁר הָעִיר בֵּית־קִבְרוֹת אֲבֹתַי חֲרֵבָה וּשְׁעָרֶיהָ אֻכְּלוּ בָאֵשׁ׃}
}
{
	\eX{
		And said to the king, Let the king live forever: why should not
		my face be sad, when the city, the place of my fathers' graves,
		lies waste, and the gates of it are consumed with fire?
	}
}
{
}

\Verse{4}
{
	\hX{וַיֹּאמֶר לִי הַמֶּלֶךְ עַל־מַה־זֶּה אַתָּה מְבַקֵּשׁ וָאֶתְפַּלֵּל אֶל־אֱלֹהֵי הַשָּׁמָיִם׃}
}
{
	\eX{
		Then the king said to me, For what do you make request? So I
		prayed to the God of the skies.
	}
}
{
}

\Verse{5}
{
	\hX{וָאֹמַר לַמֶּלֶךְ אִם־עַל־הַמֶּלֶךְ טוֹב וְאִם־יִיטַב עַבְדְּךָ לְפָנֶיךָ אֲשֶׁר תִּשְׁלָחֵנִי אֶל־יְהוּדָה אֶל־עִיר קִבְרוֹת אֲבֹתַי וְאֶבְנֶנָּה׃}
}
{
	\eX{
		And I said to the king, If it please the king, and if your
		servant have found favour in your sight, that you would send me
		to Judah, to the city of my fathers' graves, that I may build
		it.
	}
}
{
%	\footnote{
%		Footnote 2:5. Nehemiah asks to be sent to the city of his fathers' graves. Before
%		it is a building project, it is kinship and bones.
%	}
}

\Verse{6}
{
	\hX{וַיֹּאמֶר לִי הַמֶּלֶךְ וְהַשֵּׁגַל יוֹשֶׁבֶת אֶצְלוֹ עַד־מָתַי יִהְיֶה מַהֲלָכְךָ וּמָתַי תָּשׁוּב וַיִּיטַב לִפְנֵי־הַמֶּלֶךְ וַיִּשְׁלָחֵנִי וָאֶתְּנָה לוֹ זְמָן׃}
}
{
	\eX{
		And the king said to me, (the queen also sitting by him,) For
		how long shall your journey be? and when wilt you return? So it
		pleased the king to send me; and I set him a time.
	}
}
{
}

\Verse{7}
{
	\hX{וָאוֹמַר לַמֶּלֶךְ אִם־עַל־הַמֶּלֶךְ טוֹב אִגְּרוֹת יִתְּנוּ־לִי עַל־פַּחֲווֹת עֵבֶר הַנָּהָר אֲשֶׁר יַעֲבִירוּנִי עַד אֲשֶׁר־אָבוֹא אֶל־יְהוּדָה׃}
}
{
	\eX{
		Moreover I said to the king, If it please the king, let letters
		be given me to the governors across the River, that they may
		convey me over until I come into Judah;
	}
}
{
}

\Verse{8}
{
	\hX{
		וְאִגֶּרֶת אֶל־אָסָף שֹׁמֵר הַפַּרְדֵּס אֲשֶׁר לַמֶּלֶךְ אֲשֶׁר יִתֶּן־לִי עֵצִים לְקָרוֹת אֶת־שַׁעֲרֵי הַבִּירָה אֲשֶׁר־לַבַּיִת וּלְחוֹמַת הָעִיר וְלַבַּיִת אֲשֶׁר־אָבוֹא אֵלָיו
		וַיִּתֶּן־לִי הַמֶּלֶךְ כְּיַד־אֱלֹהַי הַטּוֹבָה עָלָי׃
	}
}
{
	\eX{
		And a letter to Asaph the keeper of the king's forest, that he
		may give me timber to make beams for the gates of the fortress
		that belonged to the house, and for the wall of the city, and
		for the house that I shall enter into. And the king granted me,
		according to the good hand of my God upon me.
	}
}
{
}

\Verse{9}
{
	\hX{וָאָבוֹא אֶל־פַּחֲווֹת עֵבֶר הַנָּהָר וָאֶתְּנָה לָהֶם אֵת אִגְּרוֹת הַמֶּלֶךְ וַיִּשְׁלַח עִמִּי הַמֶּלֶךְ שָׂרֵי חַיִל וּפָרָשִׁים׃}
}
{
	\eX{
		And I came to the governors across the River, and gave them the
		king's letters. Now the king had sent captains of the army and
		horsemen with me.
	}
}
{
}

\Verse{10}
{
	\hX{וַיִּשְׁמַע סַנְבַלַּט הַחֹרֹנִי וְטוֹבִיָּה הָעֶבֶד הָעַמֹּנִי וַיֵּרַע לָהֶם רָעָה גְדֹלָה אֲשֶׁר־בָּא אָדָם לְבַקֵּשׁ טוֹבָה לִבְנֵי יִשְׂרָאֵל׃}
}
{
	\eX{
		When Sanballat the Horonite, and Tobiah the servant, the
		Ammonite, heard of it, it grieved them exceedingly that there
		was come a man to seek the welfare of the children of Israel.
	}
}
{
}

\Verse{11}
{
	\hX{וָאָבוֹא אֶל־יְרוּשָׁלָ͏ִם וָאֱהִי־שָׁם יָמִים שְׁלֹשָׁה׃}
}
{
	\eX{So I came to Jerusalem, and was there three days.}
}
{
}

\Verse{12}
{
	\hX{
		וָאָקוּם לַיְלָה אֲנִי וַאֲנָשִׁים מְעַט עִמִּי וְלֹא־הִגַּדְתִּי לְאָדָם מָה אֱלֹהַי נֹתֵן אֶל־לִבִּי לַעֲשׂוֹת לִירוּשָׁלָ͏ִם וּבְהֵמָה אֵין עִמִּי כִּי אִם־הַבְּהֵמָה אֲשֶׁר
		אֲנִי רֹכֵב בָּהּ׃
	}
}
{
	\eX{
		And I arose in the night, I and some few men with me; and I had
		not told any man what my God had put in my heart to do at
		Jerusalem: nor was there any beast with me, save the beast that
		I rode upon.
	}
}
{
}

\Verse{13}
{
	\hX{
		וָאֵצְאָה בְשַׁעַר־הַגַּיְא לַיְלָה וְאֶל־פְּנֵי עֵין הַתַּנִּין וְאֶל־שַׁעַר הָאַשְׁפֹּת וָאֱהִי שֹׂבֵר בְּחוֹמֹת יְרוּשָׁלַ͏ִם אֲשֶׁר־[הֵם פְּרוּצִים] (המפרוצים) וּשְׁעָרֶיהָ
		אֻכְּלוּ בָאֵשׁ׃
	}
}
{
	\eX{
		And I went out by night by the gate of the valley, even in front
		of the Dragon Well, and to the Dung Gate, and viewed the walls
		of Jerusalem, that were broken down, and the gates of it were
		consumed with fire.
	}
}
{
}

\Verse{14}
{
	\hX{וָאֶעֱבֹר אֶל־שַׁעַר הָעַיִן וְאֶל־בְּרֵכַת הַמֶּלֶךְ וְאֵין־מָקוֹם לַבְּהֵמָה לַעֲבֹר תַּחְתָּי׃}
}
{
	\eX{
		And I went on to the gate of the fountain, and to the king's
		pool: but there was no place for the beast that was under me to
		pass.
	}
}
{
}

\Verse{15}
{
	\hX{וָאֱהִי עֹלֶה בַנַּחַל לַיְלָה וָאֱהִי שֹׂבֵר בַּחוֹמָה וָאָשׁוּב וָאָבוֹא בְּשַׁעַר הַגַּיְא וָאָשׁוּב׃}
}
{
	\eX{
		Then went I up in the night by the brook, and viewed the wall,
		and turned back, and entered by the gate of the valley, and so
		returned.
	}
}
{
}

\Verse{16}
{
	\hX{וְהַסְּגָנִים לֹא יָדְעוּ אָנָה הָלַכְתִּי וּמָה אֲנִי עֹשֶׂה וְלַיְּהוּדִים וְלַכֹּהֲנִים וְלַחֹרִים וְלַסְּגָנִים וּלְיֶתֶר עֹשֵׂה הַמְּלָאכָה עַד־כֵּן לֹא הִגַּדְתִּי׃}
}
{
	\eX{
		And the rulers did not know where I went, or what I did; and I
		had not yet told it to the Jews, nor to the priests, nor to the
		nobles, nor to the rulers, nor to the rest that did the work.
	}
}
{
}

\Verse{17}
{
	\hX{
		וָאוֹמַר אֲלֵהֶם אַתֶּם רֹאִים הָרָעָה אֲשֶׁר אֲנַחְנוּ בָהּ אֲשֶׁר יְרוּשָׁלַ͏ִם חֲרֵבָה וּשְׁעָרֶיהָ נִצְּתוּ בָאֵשׁ לְכוּ וְנִבְנֶה אֶת־חוֹמַת יְרוּשָׁלַ͏ִם וְלֹא־נִהְיֶה עוֹד
		חֶרְפָּה׃
	}
}
{
	\eX{
		And I said to them, You see the distress that we're in, how
		Jerusalem lies waste, and the gates of it are burned with fire:
		come, and let us build up the wall of Jerusalem, that we be no
		more a disgrace.
	}
}
{
}

\Verse{18}
{
	\hX{וָאַגִּיד לָהֶם אֶת־יַד אֱלֹהַי אֲשֶׁר־הִיא טוֹבָה עָלַי וְאַף־דִּבְרֵי הַמֶּלֶךְ אֲשֶׁר אָמַר־לִי וַיֹּאמְרוּ נָקוּם וּבָנִינוּ וַיְחַזְּקוּ יְדֵיהֶם לַטּוֹבָה׃}
}
{
	\eX{
		And I told them of the hand of my God that was good upon me; as
		also the king's words that he had spoken to me. And they said,
		Let us rise up and build. So they strengthened their hands for
		this good work.
	}
}
{
}

\Verse{19}
{
	\hX{
		וַיִּשְׁמַע סַנְבַלַּט הַחֹרֹנִי וְטֹבִיָּה הָעֶבֶד הָעַמּוֹנִי וְגֶשֶׁם הָעַרְבִי וַיַּלְעִגוּ לָנוּ וַיִּבְזוּ עָלֵינוּ וַיֹּאמְרוּ מָה־הַדָּבָר הַזֶּה אֲשֶׁר אַתֶּם עֹשִׂים
		הַעַל הַמֶּלֶךְ אַתֶּם מֹרְדִים׃
	}
}
{
	\eX{
		But when Sanballat the Horonite, and Tobiah the servant, the
		Ammonite, and Geshem the Arabian, heard it, they laughed us to
		sgrain, and despised us, and said, What is this thing that you
		do? will you rebel against the king?
	}
}
{
}

\Verse{20}
{
	\hX{וָאָשִׁיב אוֹתָם דָּבָר וָאוֹמַר לָהֶם אֱלֹהֵי הַשָּׁמַיִם הוּא יַצְלִיחַ לָנוּ וַאֲנַחְנוּ עֲבָדָיו נָקוּם וּבָנִינוּ וְלָכֶם אֵין־חֵלֶק וּצְדָקָה וְזִכָּרוֹן בִּירוּשָׁלָ͏ִם׃}
}
{
	\eX{
		And I answered them, and said to them, The God of the skies, he
		will prosper us; therefore we his servants will arise and build:
		but you have no portion, nor right, nor memorial, in Jerusalem.
	}
}
{
}
