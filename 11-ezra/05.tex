\Chapter{5}

\Verse{1}
{
	\hX{וְהִתְנַבִּי חַגַּי (נביאה) [נְבִיָּא] וּזְכַרְיָה בַר־עִדּוֹא נְבִיַּאיָּא עַל־יְהוּדָיֵא דִּי בִיהוּד וּבִירוּשְׁלֶם בְּשֻׁם אֱלָהּ יִשְׂרָאֵל עֲלֵיהוֹן׃}
}
{
	\eX{
		Then the prophets, Haggai the prophet, and Zechariah the son of
		Iddo, prophesied to the Jews that were in Judah and Jerusalem in
		the name of the God of Israel, even to them.
	}
}
{
}

\Verse{2}
{
	\hX{בֵּאדַיִן קָמוּ זְרֻבָּבֶל בַּר־שְׁאַלְתִּיאֵל וְיֵשׁוּעַ בַּר־יוֹצָדָק וְשָׁרִיו לְמִבְנֵא בֵּית אֱלָהָא דִּי בִירוּשְׁלֶם וְעִמְּהוֹן נְבִיַּאיָּא דִי־אֱלָהָא מְסָעֲדִין לְהוֹן׃}
}
{
	\eX{
		Then rose up Zerubbabel the son of Shealtiel, and Jeshua the son
		of Jozadak, and began to build the house of God that is at
		Jerusalem: and with them were the prophets of God helping them.
	}
}
{
}

\Verse{3}
{
	\hX{
		בֵּהּ־זִמְנָא אֲתָה עֲלֵיהוֹן תַּתְּנַי פַּחַת עֲבַר־נַהֲרָה וּשְׁתַר בּוֹזְנַי וּכְנָוָתְהוֹן וְכֵן אָמְרִין לְהֹם מַן־שָׂם לְכֹם טְעֵם בַּיְתָא דְנָה לִבְּנֵא וְאֻשַּׁרְנָא דְנָה
		לְשַׁכְלָלָה׃
	}
}
{
	\eX{
		At the same time came to them Tatnai, governor across the river,
		and Shetharboznai and their companions, and said thus to them,
		Who has commanded you to build this house, and to make up this
		wall?
	}
}
{
}

\Verse{4}
{
	\hX{אֱדַיִן כְּנֵמָא אֲמַרְנָא לְּהֹם מַן־אִנּוּן שְׁמָהָת גֻּבְרַיָּא דִּי־דְנָה בִנְיָנָא בָּנַיִן׃}
}
{
	\eX{
		Then said we to them after this manner, What are the names of
		the men that make this building?
	}
}
{
}

\Verse{5}
{
	\hX{וְעֵין אֱלָהֲהֹם הֲוָת עַל־שָׂבֵי יְהוּדָיֵא וְלָא־בַטִּלוּ הִמּוֹ עַד־טַעְמָא לְדָרְיָוֶשׁ יְהָךְ וֶאֱדַיִן יְתִיבוּן נִשְׁתְּוָנָא עַל־דְּנָה׃}
}
{
	\eX{
		But the eye of their God was upon the elders of the Jews, that
		they could not cause them to cease, until the matter came to
		Darius: and then they returned answer by letter concerning this
		matter.
	}
}
{
}

\Verse{6}
{
	\hX{פַּרְשֶׁגֶן אִגַּרְתָּא דִּי־שְׁלַח תַּתְּנַי פַּחַת עֲבַר־נַהֲרָה וּשְׁתַר בּוֹזְנַי וּכְנָוָתֵהּ אֲפַרְסְכָיֵא דִּי בַּעֲבַר נַהֲרָה עַל־דָּרְיָוֶשׁ מַלְכָּא׃}
}
{
	\eX{
		The copy of the letter that Tatnai, governor across the river,
		and Shetharboznai and his companions the Apharsachites, that
		were across the river, sent to Darius the king:
	}
}
{
}

\Verse{7}
{
	\hX{פִּתְגָמָא שְׁלַחוּ עֲלוֹהִי וְכִדְנָה כְּתִיב בְּגַוֵּהּ לְדָרְיָוֶשׁ מַלְכָּא שְׁלָמָא כֹלָּא׃}
}
{
	\eX{
		They sent a letter to him, in that was written thus; To Darius
		the king, all peace.
	}
}
{
}

\Verse{8}
{
	\hX{
		יְדִיעַ לֶהֱוֵא לְמַלְכָּא דִּי־אֲזַלְנָא לִיהוּד מְדִינְתָּא לְבֵית אֱלָהָא רַבָּא וְהוּא מִתְבְּנֵא אֶבֶן גְּלָל וְאָע מִתְּשָׂם בְּכֻתְלַיָּא וַעֲבִידְתָּא דָךְ אסְפַּרְנָא
		מִתְעַבְדָא וּמַצְלַח בְּיֶדְהֹם׃
	}
}
{
	\eX{
		Let it be known to the king, that we went into the province of
		Judea, to the house of the great God, that is built with great
		stones, and timber is laid in the walls, and this work goes fast
		on, and prospers in their hands.
	}
}
{
}

\Verse{9}
{
	\hX{אֱדַיִן שְׁאֵלְנָא לְשָׂבַיָּא אִלֵּךְ כְּנֵמָא אֲמַרְנָא לְּהֹם מַן־שָׂם לְכֹם טְעֵם בַּיְתָא דְנָה לְמִבְנְיָה וְאֻשַּׁרְנָא דְנָה לְשַׁכְלָלָה׃}
}
{
	\eX{
		Then asked we those elders, and said to them thus, Who commanded
		you to build this house, and to make up these walls?
	}
}
{
}

\Verse{10}
{
	\hX{וְאַף שְׁמָהָתְהֹם שְׁאֵלְנָא לְּהֹם לְהוֹדָעוּתָךְ דִּי נִכְתֻּב שֻׁם־גֻּבְרַיָּא דִּי בְרָאשֵׁיהֹם׃}
}
{
	\eX{
		We asked their names also, to make known to you, that we might
		write the names of the men that were the chief of them.
	}
}
{
}

\Verse{11}
{
	\hX{
		וּכְנֵמָא פִתְגָמָא הֲתִיבוּנָא לְמֵמַר אֲנַחְנָא הִמּוֹ עַבְדוֹהִי דִי־אֱלָהּ שְׁמַיָּא וְאַרְעָא וּבָנַיִן בַּיְתָא דִּי־הֲוָא בְנֵה מִקַּדְמַת דְּנָה שְׁנִין שַׂגִּיאָן וּמֶלֶךְ
		לְיִשְׂרָאֵל רַב בְּנָהִי וְשַׁכְלְלֵהּ׃
	}
}
{
	\eX{
		And thus they returned us answer, saying, We are the servants of
		the God of the skies and earth, and build the house that was
		built these many years ago, that a great king of Israel built
		and set up.
	}
}
{
}

\Verse{12}
{
	\hX{לָהֵן מִן־דִּי הַרְגִּזוּ אֲבָהָתַנָא לֶאֱלָהּ שְׁמַיָּא יְהַב הִמּוֹ בְּיַד נְבוּכַדְנֶצַּר מֶלֶךְ־בָּבֶל (כסדיא) [כַּסְדָּאָה] וּבַיְתָה דְנָה סַתְרֵהּ וְעַמָּה הַגְלִי לְבָבֶל׃}
}
{
	\eX{
		But after that our fathers had provoked the God of the skies to
		wrath, he gave them into the hand of Nebuchadnezzar the king of
		Babylon, the Chaldean, who destroyed this house, and carried the
		people away into Babylon.
	}
}
{
}

\Verse{13}
{
	\hX{בְּרַם בִּשְׁנַת חֲדָה לְכוֹרֶשׁ מַלְכָּא דִּי בָבֶל כּוֹרֶשׁ מַלְכָּא שָׂם טְעֵם בֵּית־אֱלָהָא דְנָה לִבְּנֵא׃}
}
{
	\eX{
		But in the first year of Cyrus the king of Babylon the same king
		Cyrus made a decree to build this house of God.
	}
}
{
}

\Verse{14}
{
	\hX{
		וְאַף מָאנַיָּא דִי־בֵית־אֱלָהָא דִּי דַהֲבָה וְכַסְפָּא דִּי נְבוּכַדְנֶצַּר הַנְפֵּק מִן־הֵיכְלָא דִּי בִירוּשְׁלֶם וְהֵיבֵל הִמּוֹ לְהֵיכְלָא דִּי בָבֶל הַנְפֵּק הִמּוֹ כּוֹרֶשׁ
		מַלְכָּא מִן־הֵיכְלָא דִּי בָבֶל וִיהִיבוּ לְשֵׁשְׁבַּצַּר שְׁמֵהּ דִּי פֶחָה שָׂמֵהּ׃
	}
}
{
	\eX{
		And the things also of gold and silver of the house of God, that
		Nebuchadnezzar took out of the temple that was in Jerusalem, and
		brought them into the temple of Babylon, those did Cyrus the
		king take out of the temple of Babylon, and they were delivered
		to one, whose name was Sheshbazzar, whom he had made governor;
	}
}
{
}

\Verse{15}
{
	\hX{וַאֲמַר־לֵהּ (אלה) [אֵל] מָאנַיָּא שֵׂא אֵזֶל־אֲחֵת הִמּוֹ בְּהֵיכְלָא דִּי בִירוּשְׁלֶם וּבֵית אֱלָהָא יִתְבְּנֵא עַל־אַתְרֵהּ׃}
}
{
	\eX{
		And said to him, Take these things, go, carry them into the
		temple that is in Jerusalem, and let the house of God be built
		in his place.
	}
}
{
}

\Verse{16}
{
	\hX{אֱדַיִן שֵׁשְׁבַּצַּר דֵּךְ אֲתָא יְהַב אֻשַּׁיָּא דִּי־בֵית אֱלָהָא דִּי בִירוּשְׁלֶם וּמִן־אֱדַיִן וְעַד־כְּעַן מִתְבְּנֵא וְלָא שְׁלִם׃}
}
{
	\eX{
		Then came the that Sheshbazzar, and laid the foundation of the
		house of God that is in Jerusalem: and since that time even
		until now has it been in building, and yet it is not finished.
	}
}
{
}

\Verse{17}
{
	\hX{
		וּכְעַן הֵן עַל־מַלְכָּא טָב יִתְבַּקַּר בְּבֵית גִּנְזַיָּא דִּי־מַלְכָּא תַמָּה דִּי בְּבָבֶל הֵן אִיתַי דִּי־מִן־כּוֹרֶשׁ מַלְכָּא שִׂים טְעֵם לְמִבְנֵא בֵּית־אֱלָהָא דֵךְ
		בִּירוּשְׁלֶם וּרְעוּת מַלְכָּא עַל־דְּנָה יִשְׁלַח עֲלֶינָא׃
	}
}
{
	\eX{
		And now, if it seem good to the king, let there be a search made
		in the king's treasure house, that is there at Babylon, whether
		it be so, that a decree was made of Cyrus the king to build this
		house of God at Jerusalem, and let the king send his will to us
		concerning this matter.
	}
}
{
}
