\Chapter{16}

\Verse{1}
{
	\hX{
		וַיְהִי כַאֲשֶׁר נִשְׁמַע לְסַנְבַלַּט וְטוֹבִיָּה וּלְגֶשֶׁם הָעַרְבִי וּלְיֶתֶר אֹיְבֵינוּ כִּי בָנִיתִי אֶת־הַחוֹמָה וְלֹא־נוֹתַר בָּהּ פָּרֶץ גַּם עַד־הָעֵת הַהִיא דְּלָתוֹת
		לֹא־הֶעֱמַדְתִּי בַשְּׁעָרִים׃
	}
}
{
	\eX{
		And it was when Sanballat, and Tobiah, and Geshem the Arabian,
		and the rest of our enemies, heard that I had built the wall,
		and that there was no breach left in it; (though at that time I
		had not set up the doors upon the gates;)
	}
}
{
}

\Verse{2}
{
	\hX{וַיִּשְׁלַח סַנְבַלַּט וְגֶשֶׁם אֵלַי לֵאמֹר לְכָה וְנִוָּעֲדָה יַחְדָּו בַּכְּפִירִים בְּבִקְעַת אוֹנוֹ וְהֵמָּה חֹשְׁבִים לַעֲשׂוֹת לִי רָעָה׃}
}
{
	\eX{
		That Sanballat and Geshem sent to me, saying, Come, let us meet
		together in some one of the villages in the plain of Ono. But
		they thought to do me mischief.
	}
}
{
}

\Verse{3}
{
	\hX{וָאֶשְׁלְחָה עֲלֵיהֶם מַלְאָכִים לֵאמֹר מְלָאכָה גְדוֹלָה אֲנִי עֹשֶׂה וְלֹא אוּכַל לָרֶדֶת לָמָּה תִשְׁבַּת הַמְּלָאכָה כַּאֲשֶׁר אַרְפֶּהָ וְיָרַדְתִּי אֲלֵיכֶם׃}
}
{
	\eX{
		And I sent messengers to them, saying, I'm doing a great work,
		so that I cannot come down: why should the work cease, while I
		leave it, and come down to you?
	}
}
{
}

\Verse{4}
{
	\hX{וַיִּשְׁלְחוּ אֵלַי כַּדָּבָר הַזֶּה אַרְבַּע פְּעָמִים וָאָשִׁיב אוֹתָם כַּדָּבָר הַזֶּה׃}
}
{
	\eX{
		Yet they sent to me four times after this sort; and I answered
		them after the same manner.
	}
}
{
}

\Verse{5}
{
	\hX{וַיִּשְׁלַח אֵלַי סַנְבַלַּט כַּדָּבָר הַזֶּה פַּעַם חֲמִישִׁית אֶת־נַעֲרוֹ וְאִגֶּרֶת פְּתוּחָה בְּיָדוֹ׃}
}
{
	\eX{
		Then sent Sanballat his servant to me in like manner the fifth
		time with an open letter in his hand;
	}
}
{
}

\Verse{6}
{
	\hX{כָּתוּב בָּהּ בַּגּוֹיִם נִשְׁמָע וְגַשְׁמוּ אֹמֵר אַתָּה וְהַיְּהוּדִים חֹשְׁבִים לִמְרוֹד עַל־כֵּן אַתָּה בוֹנֶה הַחוֹמָה וְאַתָּה הֹוֶה לָהֶם לְמֶלֶךְ כַּדְּבָרִים הָאֵלֶּה׃}
}
{
	\eX{
		In that was written, It is reported among the nations, and
		Gashmu says it, that you and the Jews think to rebel: for that
		cause you build the wall, that you may be their king, according
		to these words.
	}
}
{
}

\Verse{7}
{
	\hX{וְגַם־נְבִיאִים הֶעֱמַדְתָּ לִקְרֹא עָלֶיךָ בִירוּשָׁלַ͏ִם לֵאמֹר מֶלֶךְ בִּיהוּדָה וְעַתָּה יִשָּׁמַע לַמֶּלֶךְ כַּדְּבָרִים הָאֵלֶּה וְעַתָּה לְכָה וְנִוָּעֲצָה יַחְדָּו׃}
}
{
	\eX{
		And you have also appointed prophets to preach of you at
		Jerusalem, saying, There is a king in Judah: and now shall it be
		reported to the king according to these words. Come now
		therefore, and let us take counsel together.
	}
}
{
}

\Verse{8}
{
	\hX{וָאֶשְׁלְחָה אֵלָיו לֵאמֹר לֹא נִהְיָה כַּדְּבָרִים הָאֵלֶּה אֲשֶׁר אַתָּה אוֹמֵר כִּי מִלִּבְּךָ אַתָּה בוֹדָאם׃}
}
{
	\eX{
		And I sent to him, saying, There are no such things done as you
		say, but you make up them out of your own heart.
	}
}
{
}

\Verse{9}
{
	\hX{כִּי כֻלָּם מְיָרְאִים אוֹתָנוּ לֵאמֹר יִרְפּוּ יְדֵיהֶם מִן־הַמְּלָאכָה וְלֹא תֵעָשֶׂה וְעַתָּה חַזֵּק אֶת־יָדָי׃}
}
{
	\eX{
		For they all made us afraid, saying, Their hands shall be
		weakened from the work, that it be not done. And now, O God,
		strengthen my hands.
	}
}
{
}

\Verse{10}
{
	\hX{
		וַאֲנִי־בָאתִי בֵּית שְׁמַעְיָה בֶן־דְּלָיָה בֶּן־מְהֵיטַבְאֵל וְהוּא עָצוּר וַיֹּאמֶר נִוָּעֵד אֶל־בֵּית הָאֱלֹהִים אֶל־תּוֹךְ הַהֵיכָל וְנִסְגְּרָה דַּלְתוֹת הַהֵיכָל כִּי
		בָּאִים לְהרְגֶךָ וְלַיְלָה בָּאִים לְהרְגֶךָ׃
	}
}
{
	\eX{
		Afterward I came to the house of Shemaiah the son of Delaiah the
		son of Mehetabeel, who was shut up; and he said, Let us meet
		together in the house of God, within the temple, and let us shut
		the doors of the temple: for they'll come to kill you; yea, in
		the night will they come to kill you.
	}
}
{
}

\Verse{11}
{
	\hX{וָאֹמְרָה הַאִישׁ כָּמוֹנִי יִבְרָח וּמִי כָמוֹנִי אֲשֶׁר־יָבֹא אֶל־הַהֵיכָל וָחָי לֹא אָבוֹא׃}
}
{
	\eX{
		And I said, Should such a man as I flee? and who is there, that,
		being as I'm, would go into the temple to save his life? I'll
		not go in.
	}
}
{
}

\Verse{12}
{
	\hX{וָאַכִּירָה וְהִנֵּה לֹא־אֱלֹהִים שְׁלָחוֹ כִּי הַנְּבוּאָה דִּבֶּר עָלַי וְטוֹבִיָּה וְסַנְבַלַּט שְׂכָרוֹ׃}
}
{
	\eX{
		And, here, I perceived that God had not sent him; but that he
		pronounced this prophecy against me: for Tobiah and Sanballat
		had hired him.
	}
}
{
}

\Verse{13}
{
	\hX{לְמַעַן שָׂכוּר הוּא לְמַעַן־אִירָא וְאֶעֱשֶׂה־כֵּן וְחָטָאתִי וְהָיָה לָהֶם לְשֵׁם רָע לְמַעַן יְחָרְפוּנִי׃}
}
{
	\eX{
		Therefore was he hired, that I should be afraid, and do so, and
		sin, and that they might have matter for an evil report, that
		they might disgrace me.
	}
}
{
}

\Verse{14}
{
	\hX{זכְרָה אֱלֹהַי לְטוֹבִיָּה וּלְסַנְבַלַּט כְּמַעֲשָׂיו אֵלֶּה וְגַם לְנוֹעַדְיָה הַנְּבִיאָה וּלְיֶתֶר הַנְּבִיאִים אֲשֶׁר הָיוּ מְיָרְאִים אוֹתִי׃}
}
{
	\eX{
		My God, remember Tobiah and Sanballat according to these their
		works, and on the prophetess Noadiah, and the rest of the
		prophets, that would have put me in fear.
	}
}
{
}

\Verse{15}
{
	\hX{וַתִּשְׁלַם הַחוֹמָה בְּעֶשְׂרִים וַחֲמִשָּׁה לֶאֱלוּל לַחֲמִשִּׁים וּשְׁנַיִם יוֹם׃}
}
{
	\eX{
		So the wall was finished in the twenty and fifth day of the
		month Elul, in fifty and two days.
	}
}
{
}

\Verse{16}
{
	\hX{
		וַיְהִי כַּאֲשֶׁר שָׁמְעוּ כּל־אוֹיְבֵינוּ וַיִּרְאוּ כּל־הַגּוֹיִם אֲשֶׁר סְבִיבֹתֵינוּ וַיִּפְּלוּ מְאֹד בְּעֵינֵיהֶם וַיֵּדְעוּ כִּי מֵאֵת אֱלֹהֵינוּ נֶעֶשְׂתָה הַמְּלָאכָה
		הַזֹּאת׃
	}
}
{
	\eX{
		And it was, that when all our enemies heard of it, and all the
		nations that were about us saw these things, they were much cast
		down in their own eyes: for they perceived that this work was
		done of our God.
	}
}
{
}

\Verse{17}
{
	\hX{גַּם בַּיָּמִים הָהֵם מַרְבִּים חֹרֵי יְהוּדָה אִגְּרֹתֵיהֶם הוֹלְכוֹת עַל־טוֹבִיָּה וַאֲשֶׁר לְטוֹבִיָּה בָּאוֹת אֲלֵיהֶם׃}
}
{
	\eX{
		Moreover in those days the nobles of Judah sent many letters to
		Tobiah, and the letters of Tobiah came to them.
	}
}
{
}

\Verse{18}
{
	\hX{כִּי־רַבִּים בִּיהוּדָה בַּעֲלֵי שְׁבוּעָה לוֹ כִּי־חָתָן הוּא לִשְׁכַנְיָה בֶן־אָרַח וִיהוֹחָנָן בְּנוֹ לָקַח אֶת־בַּת־מְשֻׁלָּם בֶּן בֶּרֶכְיָה׃}
}
{
	\eX{
		For there were many in Judah sworn to him, because he was the
		son-in-law of Shechaniah the son of Arah; and his son Johanan
		had taken the daughter of Meshullam the son of Berechiah.
	}
}
{
}

\Verse{19}
{
	\hX{גַּם טוֹבֹתָיו הָיוּ אֹמְרִים לְפָנַי וּדְבָרַי הָיוּ מוֹצִיאִים לוֹ אִגְּרוֹת שָׁלַח טוֹבִיָּה לְיָרְאֵנִי׃}
}
{
	\eX{
		Also they reported his good deeds before me, and uttered my
		words to him. And Tobiah sent letters to put me in fear.
	}
}
{
}
