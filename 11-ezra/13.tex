	\hX{(אחרי) [אַחֲרָיו] הֶחֱזִיק מַלְכִּיָּה בֶּן־הַצֹּרְפִי עַד־בֵּית הַנְּתִינִים וְהָרֹכְלִים נֶגֶד שַׁעַר הַמִּפְקָד וְעַד עֲלִיַּת הַפִּנָּה׃}
}
{
	\eX{
		After him repaired Malchiah the goldsmith's son to the place of
		the Nethinim, and of the merchants, opposite the gate Miphkad,
		and to the going up of the grainer.
	}
}
{
}

\Verse{32}
{
	\hX{וּבֵין עֲלִיַּת הַפִּנָּה לְשַׁעַר הַצֹּאן הֶחֱזִיקוּ הַצֹּרְפִים וְהָרֹכְלִים׃}
}
{
	\eX{
		And between the going up of the grainer to the sheep gate
		repaired the goldsmiths and the merchants.
	}
}
{
}

\Verse{33}
{
	\hX{וַיְהִי כַּאֲשֶׁר שָׁמַע סַנְבַלַּט כִּי־אֲנַחְנוּ בוֹנִים אֶת־הַחוֹמָה וַיִּחַר לוֹ וַיִּכְעַס הַרְבֵּה וַיַּלְעֵג עַל־הַיְּהוּדִים׃}
}
{
	\eX{
		But it was, that when Sanballat heard that we built the wall, he
		was angry, and took great indignation, and mocked the Jews.
	}
}
{
}

\Verse{34}
{
	\hX{
		וַיֹּאמֶר לִפְנֵי אֶחָיו וְחֵיל שֹׁמְרוֹן וַיֹּאמֶר מָה הַיְּהוּדִים הָאֲמֵלָלִים עֹשִׂים הֲיַעַזְבוּ לָהֶם הֲיִזְבָּחוּ הַיְכַלּוּ בַיּוֹם הַיְחַיּוּ אֶת־הָאֲבָנִים מֵעֲרֵמוֹת
		הֶעָפָר וְהֵמָּה שְׂרוּפוֹת׃
	}
}
{
	\eX{
		And he spoke before his brothers and the army of Samaria, and
		said, What do these weak Jews? will they fortify themselves?
		will they sacrifice? will they make an end in a day? will they
		revive the stones out of the heaps of dust that are burned?
	}
}
{
}

\Verse{35}
{
	\hX{וְטוֹבִיָּה הָעַמֹּנִי אֶצְלוֹ וַיֹּאמֶר גַּם אֲשֶׁר־הֵם בּוֹנִים אִם־יַעֲלֶה שׁוּעָל וּפָרַץ חוֹמַת אַבְנֵיהֶם׃}
}
{
	\eX{
		Now Tobiah the Ammonite was by him, and he said, Even that they
		build, if a fox go up, he shall even break down their stone
		wall.
	}
}
{
}

\Verse{36}
{
	\hX{שְׁמַע אֱלֹהֵינוּ כִּי־הָיִינוּ בוּזָה וְהָשֵׁב חֶרְפָּתָם אֶל־רֹאשָׁם וּתְנֵם לְבִזָּה בְּאֶרֶץ שִׁבְיָה׃}
}
{
	\eX{
		Hear, O our God; for we're despised: and turn their disgrace
		upon their own head, and give them for a prey in the land of
		captivity:
	}
}
{
}

\Verse{37}
{
	\hX{וְאַל־תְּכַס עַל־עֲוֺנָם וְחַטָּאתָם מִלְּפָנֶיךָ אַל־תִּמָּחֶה כִּי הִכְעִיסוּ לְנֶגֶד הַבּוֹנִים׃}
}
{
	\eX{
		And do not cover their guilt, and let not their sin be blotted
		out from before you: for they have provoked you to anger before
		the builders.
	}
}
{
}

\Verse{38}
{
	\hX{וַנִּבְנֶה אֶת־הַחוֹמָה וַתִּקָּשֵׁר כּל־הַחוֹמָה עַד־חֶצְיָהּ וַיְהִי לֵב לָעָם לַעֲשׂוֹת׃}
}
{
	\eX{
		And we built the wall; and all the wall was joined together to
		the half of it: for the people had a mind to work.
	}
}
{
}
